## 0-1. 독법 + 요건사실론

### 민1 독법 -- "누가 누구에게 무엇을 청구?"

1. **청구권기초**를 먼저 잡고 읽는다. -- `누가 누구에게 무엇을 청구?` → `청구권 기초 조문`
2. 각 쟁점은 **조문 → 요건 ①②③ → 효과** 순서로 본다.
3. 그다음 **원칙·예외**와 **항변·재항변**을 붙여 본다.
4. 판례는 **어느 요건에서 결론이 갈렸는지** 중심으로 읽는다.
5. **대리 쟁점**이 등장하면 먼저 **당사자가 누구인지**(본인/대리인/상대방) 확정한 후 대리 유형(유권/무권/[[표현대리]])을 판단한다. → cf. §7-6 당사자 확정
6. 마지막에 **원고는 무엇을 주장하고 피고는 무엇으로 막는지**까지 모답형으로 닫는다.

### 요건사실론 기본 구조 (교수 강조)

| 단계 | 내용 | 역할 |
|------|------|------|
| **청구원인** | 원고가 주장·입증할 사실 (권리발생사실) | 원고 부담 |
| **항변** | 피고가 주장·입증할 사실 (권리장애·소멸·저지사실) | 피고 부담 |
| **재항변** | 원고가 항변을 깨기 위해 주장·입증할 사실 | 원고 부담 |

- 민1 사례형에서는 이 구조를 따라 **"원고 청구 → 피고 항변 → 원고 재항변"** 순서로 답안을 구성해야 한다.
- 교수님은 **요건사실론**을 수업 초반부터 반복 강조하며, 단순 정의 암기가 아니라 **공방 구조로 쟁점을 잡을 것**을 요구한다.

### 기출/사례 쟁점 묶음 흐름도

> 사례문제에서 쟁점이 묶여 나오는 패턴. 답안에서 쟁점 간 연결을 의식한다.

**[송영곤 사례] 미성년자 계약 + 속임수 + 취소 후 원상회복**
미성년자 갑이 나이를 속이고 을과 매매계약 체결 → 갑의 부모가 취소
→ §5 취소권 존부: 법정대리인 동의 없음 → 취소 가능
→ §17 속임수 항변: 을이 "갑이 능력자로 믿게 했다" → 취소권 배제?
→ 판례 기준: 단순 연령 사칭 ≠ 속임수 / 적극적 술책 필요
→ 취소 효과: §141 원상회복 — 미성년자는 현존이익 한도(§141 단서)

**[강혜림 사례] [[통정허위표시]] + 제3자 보호 + 전득자 지위**
갑·을 통정허위 매매(§108) → 을이 선의 병에게 매도 → 병이 정에게 전매
→ §108① 무효: 갑·을 간 매매 무효
→ §108② 제3자: 병이 선의 → 갑은 병에게 무효 주장 불가
→ 전득자 정: 절대적 구성(판례) — 병이 보호되면 정도 보호(정의 선의 불문)
→ 병이 악의인 경우: 정이 선의라면? → 절대적 구성에서도 병이 악의이면 보호 안 됨 → 정에게 전달되는 권리 자체가 무효

**[송영곤 사례] 착오(§109) + 사기(§110) 경합 + 제3자 보호**
을이 갑을 기망하여 착오에 빠뜨림 → 갑이 매매계약 체결 → 병에게 전매 완료
→ §109 착오취소: 동기의 착오 내용화 + 중과실 없음 → 취소 가능
→ §110 사기취소: 기망행위 + 인과관계 → 취소 가능
→ 경합 처리: 두 취소권 병존 — 유리한 것 선택 가능
→ 제3자 보호 비교: §109② 선의·무과실 / §110③ 선의·무과실 → 기준 유사하나 입증 분배 차이

**[강혜림 사례] §103 [[반사회질서]] + §746 [[불법원인급여]] + 이중매매**
갑이 을에게 매매(유효) → 갑이 다시 병에게 이중매매(배신적 악의자)
→ 을의 청구: 채권자대위(§404) → 갑의 병에 대한 말소청구권 대위행사
→ 병의 항변: §103 무효 시 §746 [[불법원인급여]] → 갑은 반환청구 불가
→ 을의 재항변: §746 단서 — 불법원인이 수익자(병)에게만 있는 경우 반환 가능
→ 배신적 악의자 법리: 병이 을의 존재를 알면서 매수 → 등기 무효 주장 가능(판례)

**[기출 빈출] 대리 3단 연결 — 유권대리 → [[표현대리]] → §135 전환**
갑(본인)의 대리인 을이 권한을 넘어 병과 거래 → 병이 갑에게 이행 청구
→ 1단계 유권대리: 대리권 범위 내? → 권한 유월 → [[무권대리]]
→ 2단계 [[표현대리]](§126): 기본대리권 + 정당한 이유 → 갑에게 효력 귀속
→ 갑의 재항변: 병의 과실(정당한 이유 부정)
→ 3단계 전환: 표현대리도 불성립 시 → §135 무권대리인 을에 대한 이행/손배 청구

| 구분 | 내용 |
|---|---|
| **진의** | 특정한 내용의 의사표시를 하고자 하는 **표의자의 생각** — 표의자가 진정으로 마음속에서 바라는 사항이 **아니다** |
| **표시** | 외부로 나타난 의사 |
| 진의 **=** 표시 | **유효** — 하자 없는 의사표시 |
| 진의 **≠** 표시 | 의사표시 **하자** — §107(비진의)·§108(통정허위)·§109(착오) |

- `[판례]` **"진의라 함은** 특정한 내용의 의사표시를 하고자 하는 표의자의 생각을 말하는 것이지, 표의자가 **진정으로 마음속에서 바라는 사항**을 뜻하는 것은 아니다"(대판 [[93다4480]])

### 법률행위 해석의 3단계

| 순서 | 해석 유형 | 내용 |
|---|---|---|
| **1** | **자연적 해석** | 당사자의 실제 의사(내심의 효과의사) 탐구 |
| **2** | **규범적 해석** | 당사자의 실제 의사를 확정할 수 없을 때 — 계약의 성질·내용·체결 경위 및 제반 사정을 토대로 **합리적 인간**이라면 어떻게 이해할 것인가에 의하여 확정 |
| **3** | **보충적 해석** | 계약의 전제·기초가 되는 사항에 관하여 쌍방이 공통으로 착오한 경우 — 당사자가 착오가 없을 때 **약정하였을 것으로 보이는 내용**으로 보충 |

- `[판례]` **보충적 해석**: "당사자가 그러한 착오가 없을 때에 약정하였을 것으로 보이는 내용으로 당사자의 의사를 보충하여 계약을 해석할 수 있다"(대판 [[2005다13288]])

### 답안 접근 순서 ★★★

| 순서 | 단계 | 검토 내용 |
|---|---|---|
| **①** | **해석** | 계약의 실제 목적물·의사합치를 먼저 확인 — 해석으로 해결되면 착오·사기를 검토할 필요 없다 |
| **②** | **착오 (§109)** | 해석으로 해결되지 않을 때 — 법률행위 내용의 중요부분에 착오가 있는지 검토 |
| **③** | **사기 (§110)** | 상대방 또는 제3자의 기망행위가 있으면 — §110 사기취소 검토 |
| **④** | **경합 처리** | 표시상 착오로 정리되는 경우 → 사기 법리로 가지 **않는** 구조가 안정적 |

- `[판례]` 새 판례파일은 의사표시 파트를 **해석 → 착오 → 사기 → 경합부정** 순서로 정리한다.

## §6-1. 비진의표시 (§107) ★★

### 조문 요건·효과

| 항 | 요건 | 효과 |
|---|---|---|
| **§107① 본문** | ① **의사표시**는 ② **표의자가 진의 아님을 알고** 한 것이라도 | **유효** |
| **§107① 단서** | 다만 ③ **상대방이 표의자의 진의 아님을 알았거나 알 수 있었을** 경우 | **소급적 무효** |
| **§107②** | 위 단서에 의한 무효는 ④ **선의의 제3자**에게 | **대항 불가** |

- 요건 ② "진의": 특정 내용의 의사표시를 하고자 하는 **표의자의 생각**이지, 진정으로 마음속에서 바라는 사항이 **아니다**.
- 요건 ③ "알았거나 알 수 있었을": **악의**뿐 아니라 **과실**(알 수 있었을)도 포함된다.

### 비진의표시 핵심 판례 비교

| 사안 유형 | 비진의표시 인정 여부 | 결론 |
|---|---|---|
| **근로자의 일괄 사직서 제출** | 경영방침에 따라 어쩔 수 없이 제출 → **비진의표시 O** | 사용자(회사)도 알았으므로 §107① 단서 → **소급적 무효** |
| **물의를 일으킨 자의 사직서 제출** | 사태 수습을 위해 스스로 제출 → **비진의표시 X** | 당시 최선이라 판단 → 진의 O → **유효** |
| **대출금 명의대여** | 법률상 효과를 받을 의사가 있었으므로 → **비진의표시 X** | 진의 O → **유효** |

- 대판 **[[97다8403]]**: **차명대출**에서 제3자의 의사는 "법률상의 효과는 자신에게 귀속시킴으로써 **주채무자로서의 책임**을 지겠다는 것으로 보아야" 한다 → 비진의표시 **부정**
- 대판 **[[96다18182]]**: **명의대여자의 채무부담 의사**가 있으므로 비진의표시에 해당하지 않고, 설령 해당하더라도 "**상대방**인 금고로서는 **알았다거나 알 수 있었다고 볼 수도 없다"**

### 소송 공방 구조 (§107 비진의표시)

**1. 청구권기초**: 원고(상대방)의 피고(표의자)에 대한 §107 본문 계약이행청구권
**2. 요건**: ① 의사표시 존재 (O) ② 표의자의 진의 아님 (O) ③ 원칙 유효 (O)
**3. 쟁점 — 상대방 악의·과실에 의한 무효 여부 (§107① 단서)**
- **판례** (대판 [[97다8403]]): "계약 내용이 진의와는 다르다고 할 수 없다" / 무효 주장 측(표의자)이 "상대방 악의·과실" 입증책임
**4. 포섭**: → 피고(표의자)가 §107① 단서 항변("상대방이 알았거나 알 수 있었다") → 원고 재항변("선의·무과실") → [제3자 등장 시] 소급적 무효라도 §107②에 의해 선의 제3자에게 대항 불가
**5. 결론**: 상대방 선의·무과실 → 유효 유지(인용) / 상대방 악의·과실 → 소급적 무효(기각, 단 선의 제3자 보호)

→ cf. **§5-3 법인 대표권 남용**: 대리인이 본인의 이익에 반하여 배임적 행위를 한 경우, 상대방이 알았거나 알 수 있었을 때 **§107① 단서 유추적용** → 본인에게 효력 불귀속(대판 [[86다카371]], 대판 [[2011다64669]], 대판 [[2016다3201]])

## §6-2. 통정허위표시 (§108) ★★★

### 조문 요건·효과

| 항 | 요건 | 효과 |
|---|---|---|
| **§108①** | ① **상대방과 통정**하여 ② **허위의 의사표시** | **소급적 무효** |
| **§108②** | 위 무효는 ③ **선의의 제3자**에게 | **대항 불가** |

- 요건 ① "통정": 당사자 **쌍방**이 의사표시가 진의가 아님을 서로 알면서 **합의**한 것
- 요건 ② "허위의 의사표시": 가장매매, 가장증여 등 **외형만 갖춘** 법률행위
- 요건 ③ "선의의 제3자": 허위표시 **당사자 및 포괄승계인 이외의 자**로서, 허위표시에 기하여 **새로운 법률상 이해관계**를 맺은 자

### 소송 공방 구조 (§108 통정허위표시)

**1. 청구권기초**: 원고(진정 권리자 갑)의 피고(을·전득자 병)에 대한 §108① 소급적 무효 확인 + 말소등기(또는 §741 부당이득반환)
**2. 요건**: ① 상대방과 통정 (O) ② 허위의 의사표시 (O) → 당사자 간 처음부터 소급적 무효
**3. 쟁점 — 선의 제3자 보호 여부 (§108②)**
- **판례** (대판 [[2003다70041]]): "§108② 제3자는 선의이면 족하고 무과실은 요건이 아니다" / 악의 주장 측(원고)이 악의 입증책임
**4. 포섭**: → 피고(병)가 §108② 선의 제3자 항변 → 원고가 "병은 악의"라고 입증 → 악의 입증 시 보호 배제
**5. 결론**: 병 선의 → 보호(기각) / 병 악의 → 보호 배제, 말소등기 또는 부당이득반환(인용)

| ---------------- | ------------------------------------------------- | ----------------------------------------------------- |
| **표시상의 착오**      | 표시 자체의 오기·오언                                      | **O**                                                 |
| **내용의 착오**       | 표시행위의 의미에 대한 착오                                   | **O**                                                 |
| **동기의 착오** (원칙)  | 의사표시의 동기에 착오                                      | **X** (원칙)                                            |
| **동기의 착오** (내용화) | 동기가 **표시**되거나 **유발**되어 법률행위의 내용으로 편입된 경우          | **O**                                                 |
| **시가 착오**        | 물건의 가치 판단 착오 — 대판 92다29337: 시가 착오는 **동기의 착오에 불과** | **X** (원칙). 다만 정도가 현저하면 예외적 인정(대판 97다44737: 85% 과다평가) |

### 동기의 착오 — 핵심 판례 ★★★

- **대판 [[2000다12259]]**: "동기의 착오가 법률행위의 내용의 중요부분의 착오에 해당함을 이유로 표의자가 법률행위를 취소하려면 그 **동기를 당해 의사표시의 내용으로 삼을 것을 상대방에게 표시**하고 의사표시의 해석상 법률행위의 내용으로 되어 있다고 인정되면 충분하고 당사자들 사이에 별도로 그 동기를 의사표시의 내용으로 삼기로 하는 합의까지 이루어질 필요는 없다"
- 같은 판결에서 **"내용의 중요부분"**: "보통 일반인이 표의자의 입장에 섰더라면 그와 같은 의사표시를 하지 아니하였으리라고 여겨질 정도로 그 착오가 **중요한 부분**에 관한 것이어야 한다"

### 동기착오가 §109로 보호받으려면 — 두 판례 요지 ★★★

| 판례 | 요지 |
|---|---|
| **대판 2000다12259** | 동기가 상대방에게 **"표시"**되어 법률행위의 내용으로 되어 있다고 인정되면 족하다 |
| **대판 85도167** | 매도인이 매수인의 매수목적(건축 목적)을 **알면서** 건축 가능한 것처럼 가장하여 착오를 **유발**한 경우 → 사기에 의한 의사표시로서 취소 가능 |

- **정리**: 동기착오 → ①  동기가 **표시**되어 내용으로 편입 → §109 취소 가능 / ② 상대방에 의하여 **유발**된 경우 → §110 사기취소도 가능

### 중대한 과실 판례

| 중대한 과실 **인정** (취소 X)               | 중대한 과실 **부정** (취소 O)         |
| ---------------------------------- | ---------------------------- |
| 공장설립 부지 매수자가 **관할관청에 확인하지 않은** 경우  | **공인중개사**를 통해 중개사 말만 믿은 경우   |
| 전문 보증기관이 채무자의 **보증요건을 확인하지 않은** 경우 | 관할관청의 **행정지도**를 믿고 계약 체결한 경우 |
| 토지대장·임야도를 **직접 확인하지 않은 경우** (개인거래) | 상대방에 의해 **유발된 착오**인 경우       |

- `[판례]` **대판 [[2000다12259]]** "착오에 의한 의사표시에서 취소할 수 없는 표의자의 **'중대한 과실'**이라 함은 표의자의 직업, 행위의 종류, 목적 등에 비추어 **보통 요구되는 주의를 현저히 결여**하는 것을 의미한다"
- `[판례]` **대판 [[2013다49794]]** [2]: "상대방이 표의자의 **착오를 알고 이를 이용**한 경우에는 착오가 표의자의 중대한 과실로 인한 것이라고 하더라도 표의자는 의사표시를 **취소할 수 있다**"
  - → **재재항변 사유**: 상대방이 "중과실" 항변을 하더라도, 원고가 "상대방이 착오를 알고 이용"을 입증하면 취소 가능

### §109 적용범위

- `[판례]` **대판 [[2013다49794]]**: "민법 제109조의 법리는 적용을 배제하는 취지의 별도 규정이 있거나 당사자의 합의로 적용을 배제하는 등의 특별한 사정이 없는 한 원칙적으로 **모든 사법상 의사표시에 적용**된다"

### 소송 공방 구조 (§109 착오)

**1. 청구권기초**: 원고(표의자)의 피고(상대방)에 대한 §109① 착오취소 + §741 원상회복(부당이득반환)
**2. 요건**: ① 법률행위 내용의 중요부분에 착오 (O/?) ② 표의자에게 중대한 과실 없을 것 (O/?) ③ 선의·무과실 제3자 부존재 (O/?)
**3-1. 쟁점 — 동기 불과 vs 내용화**
- **판례** (대판 [[2000다12259]]): "동기를 당해 의사표시의 내용으로 삼을 것을 상대방에게 표시하고 의사표시의 해석상 법률행위의 내용으로 되어 있다고 인정되면 충분" / 동기 표시→내용 편입 시 §109 취소 가능
**3-2. 쟁점 — 중과실 유무 vs 상대방 착오이용**
- **판례** (대판 [[2013다49794]]): "상대방이 표의자의 착오를 알고 이를 이용한 경우에는 중대한 과실로 인한 것이라도 취소 가능" / 상대방 착오이용은 중과실 항변의 재항변 사유
**4. 포섭**: → 피고 항변① "동기의 착오 불과" → 원고 재항변 "동기가 표시되어 내용 편입" → 피고 항변② "표의자 중과실" → 원고 재항변 "상대방이 착오를 알고 이용" → 피고 항변③ "§109② 선의·무과실 제3자 보호"
**5. 결론**: 내용화 인정 + 중과실 없음(또는 상대방 착오이용) → 취소(인용) / 동기 불과 또는 중과실 → 취소 불가(기각)

### 목적물 표시 착오 — 해석 우선

- `[판례]` **대판 [[93다2629]]**: "쌍방당사자가 모두 특정의 갑 토지를 계약의 목적물로 삼았으나 계약서상 그 목적물을 을 토지로 표시하였다 하여도 갑 토지에 관하여 이를 매매의 목적물로 한다는 **쌍방당사자의 의사합치**가 있은 이상 위 매매계약은 **갑 토지에 관하여 성립**한 것으로 보아야" 한다 — 을 토지에 관한 등기는 원인이 없이 경료된 것으로서 무효
  - → 답안 접근: 계약서 표시가 잘못되어도 **해석으로 먼저 해결**되는 사안

### 세액 착오 — 수정해석에 의한 착오취소 부정

- **대판 [[93다24810]]**: 매도인이 부담하여야 할 세금의 액수가 예상액을 초과한다는 사실을 알았더라면 매수인이 초과세액까지도 부담하기로 약정하였으리라는 **특별한 사정이 인정**될 때에는 매도인은 매수인에게 초과세액 상당의 청구를 할 수 있다고 **해석함이 당사자의 진정한 의사에 합치**할 것이므로, 매도인에게 세액에 관한 착오가 있었다는 이유만으로 매매계약을 **취소하는 것은 허용되지 않는다**
  - → 금액 차이가 사소한 경우 **수정해석**으로 해결 가능하면 착오취소 불허

## §6-4. 사기·강박 (§110) ★★★

### 조문 요건·효과

| 조문 항 | 요건 | 효과 |
|---|---|---|
| **§110① 전단** | (가) **사기에 의한 의사표시** | **취소** 가능 |
| **§110① 후단** | (나) **강박에 의한 의사표시** | **취소** 가능 |
| **§110②** | 제3자가 사기를 행한 경우 → **상대방이 그 사실을 알았거나 알 수 있었을** 때 | 취소 가능 |
| **§110③** | 선의·무과실의 제3자에게 대항 불가 | **제3자 보호** |

- 요건 ① "사기": **기망행위** + **2단의 고의**(㉠ 상대방을 **기망하려**는 고의 ㉡ 기망에 의해 **의사표시를 하게 하려는** 고의) + **착오 유발** + **인과관계** (기망 없었으면 의사표시를 하지 않았을 것)
- `[판례]` 기망으로 **동기의 착오**가 생긴 경우에도 §110에 의한 사기취소가 가능하다. 일반 착오(§109)와 달리 사기에 의한 취소는 **중과실이 있어도 취소 가능**하므로 표의자에게 유리하다.

### 부작위 기망 (고지의무 위반)

- 매도인이 매수인의 매수목적(건축 목적)을 **알면서** 건축이 가능한 것처럼 가장한 경우 → 사기죄의 구성요건인 **기망행위**에 해당(대판 [[85도167]]) (→ §6-5 착오·사기 경합 참조; §6-3 동기착오 판례와 동일 판례)
- 사기와 담보책임의 경합: "매수인이 매도인의 기망에 의하여 타인의 물건을 매도인의 것으로 알고 매수한다는 의사표시를 한 것은 만일 타인의 물건인줄 알았더라면 매수하지 아니하였을 사정이 있는 경우에는 매수인은 **민법 110조에 의하여 매수의 의사표시를 취소**할 수 있다"

### 제3자의 사기 (§110②) 판례

- **대판 [[96다41496]]**: "상대방의 **대리인** 등 동일시할 수 있는 자"는 §110②의 **제3자가 아니나**, "**단순한 피용자**"는 **제3자**에 포함
  - → 병(건축자재 납품업자)이 을과 동일시할 수 없는 제3자 → §110② 적용 → 을이 병의 기망 사실을 **"알 수 있었다"면 정의 사기취소 인정

### 강박에 의한 의사표시

- **대판 [[92다25120]]**: 수사기관 고소·고발은 원칙적으로 정당한 권리행사이나, **부정한 이익을 취할 목적**으로 이루어지거나 **목적이 정당하더라도 수단이 부당한 때**에는 위법한 **강박**에 해당
- **대판 [[92다7719]]**: "단지 법률행위 성립과정에서 강박이라는 불법적 방법이 사용된 데 불과하면" [[반사회질서]](§103) 무효가 아니라 **강박취소**(§110)로 처리

### 소송 공방 구조 (§110 사기·강박)

**1. 청구권기초**: 원고(피기망자/피강박자)의 피고(기망자/강박자)에 대한 §110① 사기·강박 취소 + §750 손해배상
**2. 요건**: ① 기망행위(또는 강박행위) 존재 (O/?) ② 착오 유발 + 인과관계 (O/?) ③ 선의·무과실 제3자 부존재 (O/?)
**3-1. 쟁점 — 기망행위 존부 (부작위 기망 포함)**
- **판례** (대판 [[85도167]]): 매수목적을 알면서 건축 가능한 것처럼 가장 → 기망행위 해당 / 고지의무 위반(부작위)도 기망 인정
**3-2. 쟁점 — 제3자 사기 시 상대방 인식 여부 (§110②)**
- **판례** (대판 [[96다41496]]): "상대방의 대리인 등 동일시할 수 있는 자"는 제3자가 아니나, 단순 피용자는 제3자에 포함 / 상대방이 제3자 사기를 알았거나 알 수 있었을 때 취소 가능
**4. 포섭**: → 피고 항변① "기망행위 부존재(단순 의견 표명·침묵)" → 원고 "부작위 기망(고지의무 위반)" → 피고 항변② "제3자 사기이고 상대방 선의(§110②)" → 원고 재항변 "상대방이 제3자 사기를 알았거나 알 수 있었다" → 피고 항변③ "선의·무과실 제3자(§110③) 보호"
**5. 결론**: 기망행위 인정 + 인과관계 인정 → 취소(인용), 중과실 있어도 취소 가능(§109보다 유리) / 기망 부존재 또는 제3자 사기 + 상대방 선의 → 취소 불가(기각). (→ §6-5 착오·사기 경합 참조)

## §6-5. 착오와 사기의 관계 ★★★

### 핵심 구조

| 비교축 | 착오 (§109) | 사기 (§110) |
|---|---|---|
| **진의-의사 관계** | 진의 **≠** 표시 (내심과 표시 **불일치**) | 진의 **=** 표시 (기망에 의해 **동기가 형성**되었지만, 의사 자체는 **일치**) |
| **의사흠결의 소재** | 표의자 **자신**의 인식 오류 | **타인**(기망자)에 의한 동기 형성 |
| **중과실 효과** | 중과실 있으면 취소 **불가** (§109① 단서) | 중과실 있어도 취소 **가능** |

### 경합 가능 영역

- **경합 가능**: 오직 **동기의 착오**에서만 — 동기가 기망에 의해 형성된 경우
  - 동기가 **표시**되어 §109의 요건도 충족하고, 동시에 상대방의 **기망**으로 §110의 요건도 충족하는 경우 → **양자 경합**
  - 이때 원고는 **§110 우선 적용**이 유리 (중과실 불문 취소 가능)

### 경합 부정 — 표시상 착오와 사기의 구별

- `[판례]` **대판 [[2004다43824]]**: "사기에 의한 의사표시란 타인의 기망행위로 말미암아 착오에 빠지게 된 결과 어떠한 의사표시를 하게 되는 경우이므로 거기에는 **의사와 표시의 불일치가 있을 수 없고**, 단지 의사의 형성과정 즉 의사표시의 **동기에 착오가 있는 것에 불과**하며, 이 점에서 고유한 의미의 착오에 의한 의사표시와 구분된다" — 신원보증서류에 서명날인한다는 착각에 빠진 상태로 연대보증의 서면에 서명날인한 경우 → 이른바 **표시상의 착오**에 해당하므로, 비록 제3자의 기망에 의해 일어난 것이라 하더라도 **§110이 아니라 §109(착오)로 처리**해야 한다
  - → **착오와 사기의 경합 부정**: 표시상 착오로 평가되면 §109만 적용

### 경합 판단 총정리표

| 착오 유형            | §109 취소                  | §110 취소                | 경합 여부                               |
| ---------------- | ------------------------ | ---------------------- | ----------------------------------- |
| **내용의 착오**       | O (중과실 없을 때)             | 사기 요건 충족 시 O           | **경합 가능** → §110 우선                 |
| **표시상의 착오**      | O (중과실 없을 때)             | 사기보다 착오가 본질이면 §109로 처리 | 판례: **§109만 적용** (경합 부정)            |
| **동기의 착오 (원칙)**  | **X** (동기 불과)            | **O** (기망으로 동기착오 유발 시) | 동기착오는 §109로 못 가지만 **§110으로는 취소 가능** |
| **동기의 착오 (내용화)** | O (동기가 표시+중요부분+중과실 없을 때) | O                      | **경합 가능** → §110 우선                 |

### 소송 공방 구조 (착오·사기 경합)

**1. 청구권기초**: 원고의 피고에 대한 §110① 사기취소 + §741 원상회복(또는 §750 손해배상)
**2. 요건**: ① 기망행위 존재 (O/?) ② 동기의 착오 유발 (O) ③ 중과실 유무 (§109에서는 장애사유, §110에서는 무관)
**3. 쟁점 — §109(착오) vs §110(사기) 어느 것을 적용할 것인가**
- **판례** (대판 [[2004다43824]]): 표시상 착오에 해당하면 §110이 아니라 §109로 처리. 동기착오가 기망에 의한 것이면 §110 적용 가능 / 경합 시 §110 우선(중과실 불문 취소 가능)
**4. 포섭**: → 피고 항변① "기망행위 부존재(단순 침묵)" → 피고 항변② "§109라면 표의자 중과실" → 원고 "§110 사기취소는 중과실 있어도 취소 가능 → §110 우선 적용"
**5. 결론**: 기망 인정 → §110 우선 적용, 중과실 불문 취소(인용) / 기망 부존재 → §109만 적용, 중과실 시 취소 불가(기각)

## §6-7. 의사표시 효력발생 (§111, §112)

### §111 (도달주의)

| 항 | 조문 원문 | 핵심 |
|---|---|---|
| **§111①** | 상대방이 있는 의사표시는 **그 통지가 상대방에 도달한 때**로부터 그 효력이 생긴다 | **도달** = 상대방이 **내용을 알 수 있는 객관적 상태** (요지가능성) |
| **§111②** | 의사표시자가 그 통지를 발송한 후 사망하거나 제한능력자가 되어도 의사표시의 **효력에 영향을 미치지 아니한다** | 발신 후 사망·제한능력자화 → 효력 유지 |

- `[판례]` **수령 거부 시**: 거부할 때 **도달된 것**으로 봄

### §112 (수령능력)

| 조문 원문 | 핵심 |
|---|---|
| 의사표시의 상대방이 의사표시를 받은 때에 **제한능력자**인 경우에는 의사표시자는 그 의사표시로써 대항할 수 없다. 다만 **법정대리인이 그 도달을 안 후**에는 그러하지 아니하다 | 수령 시 제한능력자 → 효력 불발생 / 법정대리인이 **안 후** → 효력 발생 |

- **시험 포인트**: §112는 §111의 도달주의와 세트로 출제

|---|---|
| ① | 제2매매가 §103 소급적 무효 → 매도인에게 **소유권 존속** |
| ② | 제1매수인은 **채권자대위권(§404)**으로 매도인을 대위하여 제2매수인 명의 **등기말소 청구** |
| ③ | 등기말소 후 매도인에게 소유권이전등기 이행 청구 |
| ④ | 다만 §746 불법원인급여 적용 시 → 매도인 자신의 반환청구와 물권적 청구권 행사도 제한 |

### §404 (채권자대위권) 요건

| 요건 | 내용 |
|---|---|
| ① | **채권자가** |
| ② | **자기의 채권을 보전하기 위하여** |
| ③ | **채무자의 권리를 행사** |

- **이중매매에서의 구조**: 제1매수인(채권자) → 매도인(채무자)의 등기말소청구권을 대위행사 → 제2매수인에 대한 등기말소
  - **불법급여자로 보지 않아** 소유권이 원주인(매도인)에게 복귀 → 제1매수인은 매도인에게 이전등기 청구

### 소송 공방 구조 (§103·§746·이중매매)

**1. 청구권기초**: 원고(제1매수인)의 피고(제2매수인)에 대한 §404 채권자대위권에 기한 매도인의 등기말소청구권 대위행사
**2. 요건**: ① 제2매매가 **§103 [[반사회질서]] 위반**으로 소급적 무효 (O/?) ② **§404 채권자대위** 요건 — 채권보전 필요성 + 채무자 권리 불행사 (O) ③ **§746 [[불법원인급여]]** 해당 여부 (?)
**3-1. 쟁점 — 이중매매의 §103 위반 여부**
- **판례**: 제2매수인이 매도인의 배임행위에 적극 가담한 경우 → 정의관념에 반하는 행위 → §103 소급적 무효 / 단순 이중매매만으로는 부족, 적극 가담 필요
**3-2. 쟁점 — §746 [[불법원인급여]] 적용 여부**
- **판례**: 제1매수인은 급부자가 아니라 채권자로서 §404에 의해 대위하는 것이므로 §746 적용 대상이 아니다 / 제1매수인은 급부자가 아닌 채권자 지위
**4. 포섭**: → 피고 항변① "적극 가담 없음, 단순 이중매매" → 원고 "제2매수인이 알면서 매수 + 매도인 배임에 적극 가담" → 피고 항변② "§746 불법원인급여로 반환청구 차단" → 원고 "§404 대위행사는 §746 적용 대상 아님"
**5. 결론**: 적극 가담 인정 → §103 소급적 무효 → §404 대위에 의한 등기말소(인용) / 적극 가담 부정 → 단순 이중매매는 유효(기각)

### §103·§746 주장·입증책임 구조 (공방 4단계)

| 단계 | 주장 주체 | 주장 내용 | 입증책임 |
|---|---|---|---|
| **① §103 무효** | 원고 (제1매수인) | "제2매매는 **반사회질서**(배임적 이중매매)로 무효" | **원고**: 제2매수인의 적극 가담 사실 |
| **② §746 항변** | 피고 (제2매수인) | "**불법원인급여** → 매도인도 반환청구 불가 → 대위행사도 차단" | **피고**: 급부자(매도인)도 불법에 관여한 사실 |
| **③ §746 단서 재항변** | 원고 | "**불법원인이 수익자에게만** 있다 → 반환 가능" | **원고**: 급부자의 불법성이 경미하거나 수익자에게만 불법원인 |
| **④ §404 대위** | 원고 | "§404 대위행사는 급부자의 반환청구가 아니므로 **§746 비적용**" | **원고**: 채권보전 필요성, 채무자의 권리 불행사 |

- **핵심**: 원고는 ④를 주장하면 ②·③을 건너뛸 수 있음 — §404 채권자대위는 §746의 적용 범위 밖(판례)

## §7. 대리 (§114-§136) — ★★★ [빈도 #2: 대리 119]

> **위치**: 법률행위 > 대리
> **같이 볼 사항**: [[대리권남용]] = §107①단서 유추(§6-1·§5-3 동일 법리) · [[무권대리]] 최고(§131) ↔ 제한능력자 최고(§15) 결론 반대 · 부재자관재인 §126 부정(§4) · 무권리자 처분(§7-7) · 당사자 확정(§7-6)
>
> **답안 순서**: ① **당사자 확정**(명의자 vs 행위자, §7-6) → ② **대리권 유무** 판단 → ③ [[무권대리]] 시 **[[표현대리]]**(§125/§126/§129) 검토 → ④ 표현대리 성립 후에도 **[[대리권남용]]**(§107① 유추) 항변 가능

### §7-1. 대리 총설

#### §114 (대리행위) 조문 원문
| 항 | 조문 원문 (요건 분리) | 효과 |
|---|---|---|
| **§114①** | 1) **대리인**이 2) 그 **권한 내**에서 3) **본인을 위한 것임을 표시**한 의사표시 | **본인에게 직접** 효력 발생 |
| **§114②** | 대리인이 본인을 위한 것임을 **표시하지 않은** 경우 | 원칙: **대리인 자신**에게 효력 발생 (다만 상대방이 본인을 위한 것임을 알았거나 알 수 있었으면 §114① 적용) |

- **현명주의**: 대리인은 본인을 위한 것임을 표시(현명)하여야 한다. 현명 없이 대리인 자기 이름으로 한 행위는 원칙적으로 대리인 자신의 행위로 효력이 발생한다.
- **대리권 입증책임**: 대리권의 존재를 주장하는 쪽에게 있다 (대판 [[2008다42195]]). 다만 등기가 마쳐진 경우에는 **등기의 추정력**에 의해 등기가 원인무효임을 주장하는 자가 반대사실의 입증책임을 부담 (대판 [[2009다37831]])[^민1-2008다42195]
- **판단 순서** (교수): ① 유권대리 해당 여부 → ② 무권대리이면 §126 [[표현대리]] 성립 여부 → ③ 표현대리 성립 시 **[[대리권남용]] 항변**(§107① 유추) 가능 여부[^민1-판단방법]
- **§117** (대리인의 행위능력): 대리인은 **행위능력자임을 요하지 아니한다**. 대리 파트에서 대리인 자신의 능력보다 **권한 유무**, **외관 형성**, **상대방 보호**가 핵심이다.

#### §116 (대리행위의 하자) — 대리인 기준(원칙) + 예외

| 조문 | 원칙 | 예외 |
|---|---|---|
| **§116①** | 의사표시의 효력이 의사의 흠결·사기·강박·선의/악의/과실에 의하여 영향을 받을 경우 → **대리인**을 기준으로 결정 | 특정 법률행위를 위임받아 **본인의 지시에 좇아** 행위한 경우 → **본인**도 기준 (§116② 유추) |

| 하자·사정 유형 | 기준자 | 예외 |
|---|---|---|
| **비진의·통정·착오·사기·강박** | **대리인** | 특정 법률행위 위임 + 본인 지시 좇은 경우 → 본인 기준 |
| **선/악의, 과실 유무** | **대리인** | (동상) |
| **궁박** | **본인** | 불공정한 법률행위(§104) 시 궁박만 본인 기준 |
| **경솔·무경험** | **대리인** | — |

### §7-2. 표현대리 ★★★ — 조항별 핵심

#### §125: 대리권 **수여 표시**에 의한 표현대리

> **조문 원문**: 제3자에 대하여 타인에게 대리권을 수여함을 표시한 자는 그 대리권의 범위 내에서 행한 그 타인과 제3자간의 법률행위에 대하여 책임이 있다. 그러나 제3자가 대리권이 없음을 알았거나 알 수 있었을 때에는 그러하지 아니하다.

- 요건:
  - ① **대리권 수여의 표시**: 본인이 제3자에 대해 대리권을 수여한 것처럼 표시
  - ② 대리인에 의한 **법률행위** (표시된 대리권 **범위 내**)
  - ③ 상대방의 **선의·무과실**
- 효과: **본인에게 효력** 귀속
- 구체 예시: **직함 사용 허락**(지점장·과장 직함), **명함 교부**, **위임장 교부 후 미회수**, **간판에 이름 게재** 등
- 불특정 다수에 대한 표시도 가능 (간판, 광고 등)

#### §126: 권한을 **넘은** 표현대리

> **조문 원문**: 대리인이 그 권한 외의 법률행위를 한 경우에 제3자가 그 권한이 있다고 믿을 만한 정당한 이유가 있는 때에는 본인은 그 행위에 대하여 책임이 있다.

- 요건:
  - ① **기본대리권** 존재
  - ② 권한을 **넘은** 행위
  - ③ 상대방의 **정당한 이유** (선의·무과실)
- 효과: **본인에게 효력** 귀속
- §126의 '정당한 이유'의 입증책임은 **상대방**에게 있다.
- **부재자관재인**의 권한초과 행위에는 §126이 **부정**된다 — 부재자를 위하는 범위라는 내재적 한계(→ cf. §4 부재자관재인).
- 법인 대표에도 §59②에 의해 §126이 **준용**된다(→ cf. §5-3 법인 대표권 남용).
- **§126은 현재 대리권을 가진 자**가 그 권한을 넘은 경우에 성립. **현재 아무 대리권이 없는 자**가 과거 대리권을 넘은 경우에는 성립하지 않음 (대판 [[2007다74713]])[^민1-2007다74713]
- 다만, §129 표현대리가 인정된 후 그 표현대리의 권한을 넘는 행위 → §126 **중첩 적용 가능** (대판 [[2007다74713]])[^민1-2007다74713]

**기본대리권 범위 판례표**

| 기본대리권 | 권한 외 행위 | §126 인정 여부 | 판례 |
|---|---|---|---|
| 아파트 임대·관리 | **매도** | O (유추적용) | 대판 92다52436 |
| 담보설정용 서류 교부 (2,000만원 한도) | **1억3,000만원 근저당** | O (2,000만원 한도 내 유효) | 대판 86다카754 |
| 일상가사대리권(처) | **남편 명의 연대보증** | X (보증은 이례적, 정당한 이유 불충분) | 대판 98다18988 |
| 경리부장 (경리사무) | **독자적 자금차용** | X (차용은 위임범위 밖, 상대방 과실) | 대판 88다카3250 |

**정당한 이유 판단 기준**
- 상대방이 **대리인에게 그 행위를 할 수 있는 대리권이 있다고 믿은 데** 정당한 이유가 있는지 (§126 원래)
- 본인 명의 모용의 경우: **행위자가 본인이라고 믿은 데** 정당한 이유가 있는지 (§7-7 참조)
- 판단 요소: ① 기본대리권의 내용·범위 ② 대리행위의 종류·규모 ③ 거래통념상의 이례성 ④ 상대방의 **확인 의무** 이행 여부

#### §129: 대리권 **소멸** 후의 표현대리

> **조문 원문**: 대리권의 소멸은 선의의 제3자에게 대항하지 못한다. 그러나 제3자가 과실로 인하여 그 사실을 알지 못한 때에는 그러하지 아니하다.

- 요건:
  - ① 과거에 **대리권이 존재**했을 것
  - ② 대리권 **소멸** 후 대리행위
  - ③ 상대방의 **선의·무과실**
- 효과: **본인에게 효력** 귀속
- 대리권 소멸 원인: **위임 철회**, **본인 사망**, **대리인 사망**, **기간 만료**, **법인 해산** 등
- 대리권 소멸 후 **복대리인을 선임**하여 복대리인이 대리행위를 한 경우에도 상대방이 선의·무과실이면 §129 [[표현대리]] 성립 (대판 [[97다55317]])[^민1-97다55317]
- §129 [[표현대리]] 인정 후 그 권한을 넘는 행위 → §126 **중첩 적용 가능** (대판 [[2007다74713]])[^민1-2007다74713]

#### 표현대리 3유형 비교표

| 유형 | 조문 | 상황 | 핵심 요건 | 효과 |
|---|---|---|---|---|
| **대리권수여 표시** | §125 | 대리권 수여한 적 없으나 **수여한 것처럼 표시** | ① **표시행위** ② 상대방 선의·무과실 | 본인에게 효력 |
| **권한 유월** | §126 | 대리권은 있으나 **범위 초과** | ① **기본대리권** 존재 ② 상대방 선의·무과실 | 본인에게 효력 |
| **대리권 소멸 후** | §129 | 대리권 **소멸** 후 대리행위 | ① **과거 대리권** 존재 ② 상대방 선의·무과실 | 본인에게 효력 |

### §7-3. 무권대리 (§130-§136) ★★★

#### §130 (무권대리의 효과)

> **조문 원문**: 대리권 없는 자가 타인의 대리인으로 한 계약은 본인이 이를 추인하지 아니하면 본인에 대하여 효력이 없다.

| 조문 | 요건 | 효과 |
|---|---|---|
| **§130** | 1) **대리권 없는 자**가 2) **타인의 대리인으로** 3) **계약을 한** 경우 | 본인이 **추인**하지 않으면 본인에 대하여 **효력 없음** (유동적 무효) |

#### §131 상대방의 **최고권** + §132 **철회권**

| 항 | 요건 | 효과 |
|---|---|---|
| **§131** (최고권) | 1) 상대방이 2) **상당한 기간**을 정하여 3) **본인에게 추인 여부의 확답을 최고** | 기간 내 확답 없으면 **추인 거절로 간주** |
| **§132** (철회권) | 1) 상대방이 **추인 있기 전**에 2) 계약 당시 대리권 없음을 **알지 못했을 것** (선의) | 상대방은 의사표시를 **철회** 가능. **본인의 추인 있을 때까지** 가능 |

#### cf. §3 제한능력자 상대방의 최고·철회권(§15)과 결론 차이 비교표

| 비교축 | 무권대리 (§131) | 제한능력자 (§15) |
|---|---|---|
| **최고 후 침묵** | **거절 간주** | **추인 간주** |
| **철회 가능 주체** | **상대방** (선의인 경우, 본인의 추인 전까지) | 제한능력자 **측**이 취소 행사 (상대방 철회가 아님) |
| **철회 시한** | **본인의 추인 있을 때까지** | — (취소권 제척기간 3년/10년) |
| **악의 상대방** | 철회 **불가** (§132) | 상대방이 제한능력자임을 안 경우 **철회 불가** (§16) |
| **취지** | 본인의 권리를 중시 → 침묵 시 거절 | 제한능력자 보호 → 침묵 시 추인 (법률관계 조속 확정) |

- `답안 포인트`: 최고에 대해 본인이 침묵하면 **추인 거절 간주**(§131)라는 점에서 제한능력자의 확답촉구(§15: 침묵 시 **추인 간주**)와 **정반대**임에 주의.

#### §133-§136 무권대리인의 책임 등

| 조문 | 요건 | 효과 |
|---|---|---|
| **§133** 본문 | 본인이 **추인**한 경우 | **소급하여** 대리행위 시에 효력 발생 |
| **§133** 단서 | 다만 **제3자의 권리를 해하지 못한다** | 추인의 소급효에 의한 제3자 권리 침해 방지 |
| **§135①** | 1) 대리권 없이 타인의 대리인으로 계약한 자 2) 본인의 **추인을 받지 못한** 때 | 상대방의 **선택**에 따라 ① **계약의 이행** 또는 ② **손해배상** 책임 |
| **§135②** | 1) 상대방이 대리권 없음을 **알았거나** 2) **알 수 있었을** 때 또는 3) 무권대리인이 **행위능력 제한**된 자인 때 | 책임 **면제** |
| **§136** | **단독행위**에 대해 대리권 없는 자가 행위 | 상대방의 **동의가 없으면** 효력 없음 |

- **면책 사유 정리**: ① 상대방 **악의**, ② 상대방 **과실**, ③ 무권대리인이 **제한능력자**.
- §135② 면책 사유의 **주장·증명책임**: **무권대리인**에게 있다 (대판 [[2018다210775]])[^민1-2018다210775]

#### §135 요건 문장형 분해

- ① **대리권 없는 자**가 **타인의 대리인으로서** 계약을 맺었을 것
- ② 본인의 **추인을 받지 못하였을** 것
- ③ 상대방이 대리권 없음을 **알지 못하였고 알 수도 없었을** 것 (선의·무과실) — 이를 갖추지 못하면 §135② 면책
- → 효과: 상대방의 **선택**에 따라 ① **계약 이행** 또는 ② **손해배상** / 무권대리인은 마치 자신이 계약의 당사자가 된 것처럼 계약에서 정한 채무를 이행할 책임 (대판 [[2018다210775]])
- → 채무불이행 시 **손해배상액의 예정**(§398)도 적용 (대판 [[2018다210775]])

#### §136 단독행위의 무권대리

- **요건**: 대리권 없는 자가 단독행위를 한 경우
- **효과**: 상대방의 **동의가 없으면** 효력 없음
- **계약과의 차이**: 계약은 유동적 무효(추인 가능), 단독행위는 동의 없으면 **확정적 무효**

### §7-4. 대리권 남용 ★★

- **법리**: 대리인이 대리권 범위 내의 행위를 하였으나 **본인의 이익이 아닌 자기 또는 제3자의 이익**을 위한 경우 → **§107① 단서 유추적용**(→ cf. §6-1 비진의표시, §5-3 법인 대표권 남용)
- 요건:
  - ① 대리인이 **자기 또는 제3자의 이익**을 위하여 대리권 범위 내 행위
  - ② 상대방이 대리인의 **배임적 의도를 알았거나 알 수 있었을** 때
- 효과: **소급적 무효** (§107① 단서 유추)
- `[판례]` 통설과 판례(대판 1987.11.10. [[86다카371]])는 **§107① 단서 유추적용설**을 취한다. 결국 상대방이 배임사실을 **알았거나 알 수 있었을 때**만 효력이 부정된다.
- `[판례]` 표현대리가 성립한 경우에도 대리인이 자신이나 제3자의 이익만을 꾀한 때에는 대리권남용이 문제되고, 상대방에게 고의·과실이 있으면 §107① 단서 유추로 무효(대판 1987.7.7. [[86다카1004]])
- `[판례]` **대판 [[2011다64669]]**: 대리인이 진의 아님을 알고 대리권 범위 내 행위를 하였으나 상대방이 그 배임적 의도를 **알았거나 알 수 있었던** 경우 → §107① 단서 유추 → 본인에게 효력 불귀속
- `[판례]` **대판 2018.4.26. [[2016다3201]] (친권남용·§107② 유추·선의 제3자 보호)**: 친권자가 미성년자를 대리하여 채무보증계약을 체결한 행위가 친권남용에 해당할 때, §107② 유추에 의해 이를 알지 못한 **선의 제3자**에게 대항할 수 없다. 선의·악의의 입증책임은 **무효 주장자(본인 측)에게 있다.
- `[판례]` 대리권남용으로 무효가 되더라도 **선의 제3자**에게 대항 불가(§107② 유추)(대판 2018.4.26. [[2016다3201]]).

### §7-5. 대리 공방구조 — 청구권기초 포섭형

**1. 청구권기초**: 원고(상대방)의 피고(본인 을)에 대한 §114 대리행위에 기한 계약이행청구권
**2. 요건**: ① 대리인 갑의 대리행위 존재 (O) ② 유효한 대리권 존재 (?) ③ 본인을 위한 것임을 표시 (O)
**3-1. 쟁점 — [[무권대리]] 여부 (§130)**
- **판례**: 무권대리는 본인이 추인하지 않으면 효력 없음 (§130) / 대리권 부존재 시 추인(§133) 또는 [[표현대리]](§125/§126/§129)로 구제
**3-2. 쟁점 — [[표현대리]] 성립 여부 (§125/§126/§129)**
- **판례**: 기본대리권 부존재 또는 상대방 악의·과실 시 [[표현대리]] 부정 / 외관 신뢰 보호의 한계
**4. 포섭**: → 피고(본인 을) 항변 "갑은 [[무권대리]](§130)" → 원고 재항변-A "추인(§133)으로 소급 유효" → 원고 재항변-B "[[표현대리]](§125/§126/§129) 성립" → 피고 "상대방 악의·과실 또는 기본대리권 부존재" → [본인 책임 불가 시] 원고가 무권대리인 갑 개인에게 §135 이행 또는 손배 청구로 전환 → 피고(갑) 항변 "상대방이 대리권 없음을 알았거나 알 수 있었다(§135②)"
**5. 결론**: 추인 또는 [[표현대리]] 인정 → 본인 책임(인용) / 모두 불인정 → 본인 면책, 무권대리인 §135 책임으로 전환(3단 구조)

### §7-6. 계약당사자 확정 문제 (타인 명의 사용) ★★

> **답안 순서**: ① 당사자 확정(명의자 vs 행위자) → ② 확정된 당사자 기준으로 대리 여부 판단 → ③ [[무권대리]]·[[표현대리]]·무권리자 처분 검토

#### 당사자 확정 기준 (대판 94다4912)[^민1-당사자확정]

| 단계 | 기준 | 결과 |
|---|---|---|
| **1단계** | 행위자와 상대방의 **의사 일치** 여부 | 일치하는 의사대로 확정 |
| **2단계** | 의사 불일치 시: 계약의 **성질·내용·체결 경위** 및 제반 사정을 토대로 **상대방이 합리적 인간이라면** 행위자·명의자 중 누구를 당사자로 이해할 것인가 | 규범적 해석으로 확정 |

#### 명의자가 당사자로 확정되는 경우 → **대리 법리 적용**

- ① 일치하는 의사가 **명의자**이거나
- ② **대출계약·보험계약** 등 **신용·자격**이 중요한 거래 → 규범적 해석상 **명의자**가 당사자
- → 행위자와 당사자의 **분리** 발생 → **대리 법리** 검토

| 명의 사용 유형 | 효과 | 판례 |
|---|---|---|
| **동의 받은 경우** | 유권대리 — 대리관계 표시 없어도 권한범위 내 행위이면 본인에게 효력[^민1-86다카1411] | 대판 86다카1411 |
| **무단 사용** | 무권대리(§130) → 표현대리(§126) 유추 가능 여부가 쟁점 | 대판 92다52436 |

#### 행위자가 당사자로 확정되는 경우 → **무권리자의 처분행위**

- ① 일치하는 의사가 **행위자**이거나
- ② **임대차계약** 등 **행위자의 개성이 중요**한 거래 → 규범적 해석상 **행위자**가 당사자
- → 행위자와 당사자의 분리 **없음** → 대리 법리 적용 안 됨
- → **무권리자의 처분행위** 문제 (§570 이하)[^민1-74다165]

### §7-7. 무권리자의 처분행위 ★★

> **같이 볼 사항**: 당사자 확정(§7-6) · [[통정허위표시]] 후 수익자의 처분(§6-2) · 재단법인 출연재산 성립 전 처분(§5-2) · §126 유추 부정(§7-2) · §108② 선의 제3자 보호

#### 개념

| 구분 | **무권대리** | **무권리자의 처분** |
|---|---|---|
| **행위 명의** | **타인의 이름**으로 법률행위 (현명) | **자기 이름**으로 법률행위 |
| **권한 흠결** | 대리권 없음 | 처분권(소유권 등) 없음 |
| **효과** | 유동적 무효 → 본인 추인 시 유효(§130·§133) | 원칙적 **무효** → 진정 권리자 추인 시 유효(§130 유추) |
| **상대방 보호** | 표현대리(§125·§126·§129), §135 무권대리인 책임 | §126 유추 **부정**(판례), §108② 선의 제3자 보호 문제 |

#### 효과

- **원칙**: 처분 대상 권리를 갖지 않은 자의 처분행위 → **무효** (처분권 없는 자의 물권변동은 효력 없음)
- **진정 권리자의 추인**: §130 유추 → 소급 유효
- **등기 이전된 경우**: 진정 권리자는 **말소등기청구** 가능 (§213 소유물반환 또는 §214 방해배제)

#### 핵심 쟁점 — §126 유추적용 **부정**

**본인 명의 모용 + §126 표현대리의 관계** (대판 [[92다52436]])[^민1-92다52436]

- §126 표현대리는 대리인이 **본인을 위한다는 의사**를 표시하거나 대리의사를 가지고 권한 외 행위를 하는 경우에 성립
- 본인의 성명을 **모용**하여 마치 본인인 것처럼 기망하여 본인 명의로 직접 법률행위를 한 경우 → §126 [[표현대리]] **성립 불가** (원칙)
- **예외**: ① 행위자에게 본인을 대리할 **기본대리권**이 인정되고 ② 기본대리권을 **넘는** 행위를 하였으며 ③ 상대방에게 **정당한 이유**가 있다면 → §126 법리 **유추적용** 가능[^민1-92다52436나]

> 정당한 이유의 내용 차이에 주의:
> - §126 원래: 상대방이 대리인에게 **대리권이 있다고 믿은 데** 정당한 이유
> - 본인 모용: 상대방이 행위자가 **본인이라고 믿은 데** 정당한 이유

#### 연결 쟁점

| 사례 유형 | 처리 | 참조 |
|---|---|---|
| **통정허위(§108) 후 수익자가 제3자에게 처분** | 수익자=무권리자 → 처분 무효, 다만 §108② 선의 제3자 보호 | §6-2 |
| **재단법인 설립 전 상속인이 출연재산 처분** | 법인성립시설(판례): 설립 전까지 상속인은 적법 소유자 → 처분 유효 | §5-2 |
| **부재자관재인 권한초과 처분** | §126 적용 불가(법원 선임이므로 본인의 수여행위 없음) → 무권대리로 무효 | §4 |
| **타인물매매(§570 이하)** | 매도인이 소유권 취득하여 이전하면 유효 / 불능 시 담보책임 | 기말 범위 |

|---|---|

| — | ② 항변: "§126 유추 — 을에게 처분권한이 있다고 믿었다" |

|---|---|---|
| **구성원 유무** | **사단법인** | 사람의 집합체 — 정관 + 사원총회 |
|  | **재단법인** | 재산의 집합체 — 출연재산 + 설립자의 정관 |
| **목적** | **영리법인** | 이익을 사원에게 분배 (상법상 회사) |
|  | **비영리법인** | 학술·종교·자선·사교 기타 영리 아닌 사업 목적 (§32) |

### §31~§33 법인 설립 조문 원문 + 요건번호

| 조문 | 요건 | 효과 |
|---|---|---|
| **§31** | 1) **법인**은 2) **법률의 규정에 의함이 아니면** 성립하지 못한다 | **법인법정주의** — 법률에 근거 없이는 법인격 취득 불가 |
| **§32** | 1) **학술, 종교, 자선, 기예, 사교 기타 영리 아닌 사업**을 목적으로 하는 2) **사단 또는 재단**은 3) **주무관청의 허가**를 얻어 | **법인**으로 할 수 있다 → **허가주의** |
| **§33** | **법인은** 1) 그 **주된 사무소의 소재지**에서 2) **설립등기**를 함으로써 | **성립**한다 → 설립등기가 **성립요건** |

- 요건 정리: 비영리법인의 설립 = ① 설립행위(정관 작성) + ② 주무관청 허가(§32) + ③ 설립등기(§33)

### 법인의 권리능력 범위

> **[판례]** 법인의 권리능력(행위능력)은 법인의 설립근거가 된 **법률과 정관상의 목적**에 의하여 제한되나, 그 **목적 범위 내의 행위**라 함은 법률이나 정관에 명시된 목적 자체에 국한되는 것이 아니라 그 목적을 수행하는 데 있어 **직접·간접으로 필요한 행위**는 모두 포함한다. **(대판 2007.1.26. [[2004도1632]])**

> **[판례]** 회사의 권리능력은 정관에 명시된 목적 자체에 국한되는 것이 아니라, 그 목적을 수행하는 데 있어 직접·간접으로 필요한 행위는 모두 포함되고 **목적수행에 필요한지의 여부**는 행위의 **객관적 성질**에 따라 판단할 것이고 행위자의 **주관적·구체적 의사**에 따라 판단할 것은 아니다. **(대판 1999.10.8. [[98다2488]])**

## §5-2. 재단법인 출연재산 귀속시기 — ★★★

### §47, §48 조문 원문 + 요건번호

| 조문 | 요건 | 효과 |
|---|---|---|
| **§47①** | 1) **생전처분으로 재단법인을 설립**하는 때 | 출연재산은 **법인이 성립한 때**로부터 법인의 재산이 된다 |
| **§47②** | 1) **유언으로 재단법인을 설립**하는 때 | 출연재산은 **유언의 효력이 발생한 때**로부터 법인에 귀속한 것으로 본다 |
| **§48** | 재단법인의 설립자가 1) 그 **명칭, 사무소 소재지 또는 이사임면의 방법**을 2) **정하지 아니하고 사망**한 때 | 이해관계인·검사의 청구에 의하여 **법원**이 이를 정한다 |

### 귀속시기 학설 비교

| 학설 | 귀속 시점 | 설립등기 전 상속인 처분 | 지위 |
|---|---|---|---|
| **출연시설** | 출연행위 시 | 상속인 처분 불가 (무권리자 처분) | 소수 |
| **법인성립시설** | 법인 설립등기 시 (§47) | 설립 전까지 상속인 처분 가능 | **판례·다수설** |
| **조건부 효력설** | 출연 시 → 성립으로 조건부 확정 | — | 소수 |

### 판례 요지

> **[판례]** 생전처분에 의한 재단법인 출연재산은 **법인이 성립한 때**부터 법인의 재산이 된다. 다만 **제3자와의 관계**에서 출연재산이 부동산이면 **등기를 마쳐야** 이를 대항할 수 있다.**(대판 [[78다481]])**
>
> - 요건 ①: 생전처분에 의한 재단법인 설립일 것
> - 요건 ②: 법인이 성립(설립등기)하였을 것
> - 요건 ③: 제3자 대항 — 부동산이면 이전등기 필요

### 학설 비판 (판례에 대한 비판)

판례(대판 [[78다481]])는 출연자와 법인 사이에서는 법인성립시설을 따르면서도, 제3자와의 관계에서는 등기를 요구하여 사실상 **대항요건주의**적 결론을 낸다. 이에 대해 학설은 다음과 같이 비판한다.

| 비판 논거            | 내용                                                                                                                |
| ---------------- | ----------------------------------------------------------------------------------------------------------------- |
| **성립요건주의 부합 문제** | 우리 민법은 물권변동에 **성립요건주의**(§186)를 취하고 있음에도, 판례가 당사자 관계와 제3자 관계를 나누어 등기를 대항요건처럼 운용하는 것은 **대항요건주의 이론 그 자체**이며 부당한 해석이다 |
| **법인성립시설의 일관성**  | 법인성립시설에 따르면 법인이 성립한 때 소유권이 당연히 이전하므로, 제3자와의 관계에서도 **별도 등기 없이 법인이 소유자**여야 논리적으로 일관된다                               |
| **결론**           | 학설은 **법인성립시설이 타당**하다고 보면서, 판례의 제3자 보호 부분은 비판적으로 검토한다                                                              |


### 설립 전 상속인의 출연재산 처분 문제

| 시점 | 출연재산 소유자 | 상속인 처분의 효력 | 법인의 권리 |
|---|---|---|---|
| **출연 ~ 설립등기 전** | 출연자(또는 상속인) | **유효** (상속인이 소유자) | 없음 (법인 미성립) |
| **설립등기 시** | **법인** (§47①) | 이미 처분된 부분은 대항관계 | 등기를 갖추어야 제3자에 대항 |
| **설립등기 후 + 이전등기 전** | 법인(내부적) / 제3자(외부적) | 제3자가 먼저 등기하면 법인 대항 불가 | 등기 경합 문제 |

> **[판례]** 설립 전 상속인이 **출연재산 부동산을 제3자에게 처분하고 등기**를 넘겨준 경우, 법인성립시설에 따르면 **상속인은 아직 적법한 소유자**이므로 그 **처분은 유효**하다. 법인은 성립 후 등기 없이는 **제3자에게 대항할 수 없다.**


- 사례형 답안 포인트: ① 귀속시기 학설 대립 → ② 법인성립시설(판례)에 따라 결론 → ③ 등기 필요 여부(대항요건) → ④ 등기 없이 **제3자가 취득한 경우 무권리자 처분** 문제로 연결 → cf. §7 [[무권대리]] 유추

## §5-3. 법인 대표권 제한·남용 — ★★

### §60 조문 원문 + 요건번호

| 조문 | 요건 | 효과 |
|---|---|---|
| **§60** | 1) 이사의 **대표권에 대한 제한**은 2) 이를 **등기하지 아니하면** | **제3자에게 대항하지 못한다** |

- 대표권 제한의 원인: **정관** 규정 또는 **총회결의**로 일정한 법률행위에 이사회결의·사원총회결의를 요구하는 것
- 등기 있는 경우: A법인은 상대방에게 대표권 제한 위반을 대항 가능 → 계약 **무효**
- 등기 없는 경우: 아래 판례 참조

#### 법령에 의한 대표권 제한

> **[판례]** 학교법인이 구 사립학교법 제16조·제28조의 규정에 의하여 **이사회의 결의**와 **감독청의 허가** 없이 타인으로부터 금원을 차용한 경우에 그 차용행위는 학교법인에 대하여 **효력이 없다**. **(대판 1998.12.8. [[98다44642]])**
>
> - **강행규정** 위반이므로 학교법인에 대하여 효력이 없다 (정관에 의한 대표권 제한과 달리 **등기 유무를 불문**하고 무효)



### 미등기 시 제3자 범위 — 제한설 vs 무제한설

| 학설 | 내용 |
|---|---|
| **제한설** | 보호의 필요성이 없는 **악의의 제3자**에게는 대항 가능 |
| **무제한설 (판례)** | 등기하지 않았다면 **선·악의 불문** 대항 불가 |

**[판례]** "정관에 의한 대표권의 제한은 이를 등기하지 아니하면 **선의의 제3자**에게는 물론 **악의의 제3자**에게도 대항하지 못한다(무제한설)." **(대판 1992.2.14. [[91다24564]]; 대판 1975.4.22. [[74다410]] 등)**

- 요건 ①: 정관에 의한 대표권 제한이 존재할 것
- 요건 ②: 대표권 제한의 **등기**를 하지 않았을 것
- 효과: 상대방의 선·악의 불문, 대항 불가 (무제한설)


### 대표권 남용 — §107① 단서 유추적용 → cf. §6-1 비진의표시

법인의 대표기관이 **객관적으로** 대표권 범위 내에 속하지만, **주관적으로** 법인의 이익이 아닌 **자기 또는 제3자의 이익**을 위하여 대표행위를 하는 것.

| 요건번호 | 요건 내용 |
|---|---|
| 요건 ① | 대리인(대표자)이 **자기 또는 제3자의 이익**을 위하여 대표행위를 하였을 것 |
| 요건 ② | 상대방이 대리인(대표자)의 **진의를 알았거나 알 수 있었을** 것 (악의·과실) |
| **효과** | 대리행위(대표행위)는 **본인(법인)에게 효력 없음** — §107① 단서 유추 |

> **[판례]** 대리인의 진의가 본인의 이익이나 의사에 반하여 자기 또는 제3자의 이익을 위한 배임적인 것임을 그 상대방이 **알거나 알 수 있었을 경우**에는 §107조 제1항 단서의 유추해석상 그 대리인의 행위는 **본인의 대리행위로 성립할 수 없다.** **(대판 1987.7.7. [[86다카1004]])**
>
> - 입증책임: **법인 측**이 상대방의 악의·과실을 입증하여야 한다

### 정관위반 vs 목적범위초과 vs 대표권남용 구분

| 유형 | 내용 | 법률효과 | 비고 |
|---|---|---|---|
| **정관 위반 (내부적 제한)** | 이사회결의 없이 대표행위 | 등기 없으면 제3자에 대항 불가 (§60) | 상대방 선·악의 불문(판례) |
| **목적범위 초과** | 법인의 권리능력 범위 밖의 행위 | **무효** — 권리능력 밖 | §126 표현대리 유추 문제 |
| **대표권남용** | 외형상 권한 내이나 사적 이익 추구 | 원칙 유효, 상대방 악의·과실이면 §107① 단서 유추 무효 | → cf. §6-1 |

## §5-4. 법인 불법행위능력 (§35) — ★★

### §35 조문 원문 + 요건번호

| 요건번호 | 조문 문언 | 판례 해석 |
|---|---|---|
| 요건 ① | **법인은** | 법인이 주체 |
| **요건 ①-1** | **(§34 전제)** | **정관으로 정한 목적의 범위 내의 행위**일 것. 목적범위 = 정관 명시 목적 + 직접·간접으로 필요한 행위 (객관적·추상적 판단, 74다310). 목적범위 외 행위 → §35 불성립, 절대적 무효 → 계약책임 불가, 부당이득(§741)만 가능 |
| 요건 ② | **이사 기타 대표자가** | 대표기관의 행위일 것 (이사·임시이사·청산인 등) |
| 요건 ③ | **그 직무에 관하여** | **외형설**(판례): 행위의 외형상 직무행위라고 인정할 수 있으면 족함 |
| 요건 ④ | **타인에게 가한 손해** | 일반 불법행위 요건 (고의·과실, 위법성, 손해, 인과관계) |
| **효과** | **법인이 배상할 책임**이 있다 | 법인 자신의 불법행위책임 (대위책임 아님) |

> **§34 조문**: "법인은 법률의 규정에 좇아 **정관으로 정한 목적의 범위 내에서** 권리와 의무의 주체가 된다."
> **판례** (대판 1974.11.26, [[74다310]]): "목적범위 내의 행위는 정관에 명시된 목적 자체 및 그 목적을 수행하는 데 직접 또는 간접으로 필요한 행위는 모두 포함되며, 목적 수행에 필요한지 여부도 행위의 **객관적 성질**에 따라 추상적으로 판단"

### 외형이론 (판례)

> **[판례]** 직무에 관한 것이라는 의미는 **행위의 외형상 법인의 대표자의 직무행위라고 인정할 수 있는 것**이라면 설사 그것이 **대표자 개인의 사리를 도모**하기 위한 것이었거나 혹은 **법령의 규정에 위배**된 것이었다 하더라도 위의 직무에 관한 행위에 해당한다고 보아야 한다. **(대판 2004.2.27. [[2003다15280]])**
### 피해자 악의·중과실에 의한 면책

> **[판례]** 피해자 자신이 그 행위가 대표자의 직무권한 내에서 적법하게 행하여진 것이 아님을 **알았거나 또는 중대한 과실로 인하여 알지 못한** 경우에는 법인에게 손해배상을 청구할 수 없다. 여기서 **중대한 과실**이란 거의 **고의에 가까운 정도의 주의를 결여**한 것을 말한다. **(대판 2004.3.26. [[2003다34045]])**

### 직무관련성 판례 보충

> **[판례]** 종중의 대표자가 종중 소유 부동산을 **개인 소유라 하여 매도**하고 계약금·중도금을 받은 후, 매수인이 종중 소유임을 알자 종중 대표자로서 **이전을 약속**하고 종중총회 결의서 등을 **위조**하여 등기이전을 해준 경우 — 매도 시 자체는 직무행위 외형 없으나, 매도 후 **대표자 지위에서 이전을 약속한 행위**는 외형상 직무에 관한 행위로 볼 수 있고, 이것이 이후 불법행위의 원인이 되었으므로 **종중의 불법행위책임 인정**. **(대판 1994.4.12. [[92다49300]])**

### 사원의 공동불법행위 — §35② + §760

> **[판례]** 법인의 대표자가 그 직무에 관하여 타인에게 손해를 가함으로써 법인에 손해배상책임이 인정되는 경우에, **대표자 개인**도 제3자에 대하여 손해배상책임을 면하지 못한다(§35①). 또한 사원도 대표자와 **공동**으로 불법행위를 저질렀거나 이에 **가담**하였다고 볼 만한 사정이 있으면 연대하여 손해배상책임을 진다. 다만 사원총회·이사회의 의결은 원칙적으로 **법인의 내부행위**에 불과하므로 그 사항의 의결에 찬성하였다는 이유만으로 제3자에 대한 불법행위책임을 부담한다고 할 수는 **없다**. **(대판 2009.1.30. [[2006다37465]])**

### §35 vs §756(사용자책임) 비교표

| 비교축 | **법인의 불법행위책임 (§35)** | **사용자책임 (§756)** |
|---|---|---|
| **적용 대상** | 대표기관 (이사, 임시이사, 청산인 등) | 피용자 (대표기관 이외의 일반 직원) |
| **직무 관련성** | 직무에 관하여 (외형설 — 폭넓게 인정) | 사무집행에 관하여 (외형설) |
| **면책 규정** | **면책 불가** (무과실 증명해도 책임) | **면책 가능** (선임·감독에 상당한 주의 증명 시, §756① 단서) |
| **책임의 성격** | 법인 **자신**의 불법행위책임 | 타인의 행위에 대한 **대위(보충적)** 책임 |
| **책임의 경합** | §35가 성립하면 §756은 배제 | §35 불성립 시 피용자이면 §756 성립 가능 |
| **대표자 개인책임** | §35 책임과 별도로 대표자에게 §750 불법행위책임 병존 (부진정연대) | 피용자에게 §750 책임 병존 |

## §5-5. 법인 공방구조 — 청구권기초 포섭형

### (1) 법인의 계약상 책임 공방

**1. 청구권기초**: 원고(상대방 을)의 피고(법인 A)에 대한 §59 대표행위에 기한 계약이행청구권
**2. 요건**: ① 대표이사 갑의 대표행위 존재 (O) ② 유효한 대표권 범위 내 (?) ③ 대표권남용 해당 여부 (?)
**3-1. 쟁점 — 대표권 제한의 제3자 대항력 (§60)**
- **판례**: 대표권 제한은 등기하지 않으면 선의·악의 불문 제3자에게 대항 불가 (§60, 무제한설) / 등기 미비 시 법인은 대표권 제한 주장 불가
**3-2. 쟁점 — 대표권남용 시 효력 (§107① 단서 유추)**
- **판례** (대판 [[2016다3201]]): 대표자가 사적 이익을 위해 대표권을 행사하고, 상대방이 이를 알았거나 알 수 있었다면 §107① 단서 유추 → 법인에 효력 불귀속. 입증책임은 법인 측 / 상대방 선의·무과실이면 유효 유지
**4. 포섭**: → 피고(법인 A) 항변① "정관상 대표권 제한 초과(§60)" → 원고 "등기 미비이므로 대항 불가" → 피고 항변② "대표권남용 + 상대방 악의·과실(§107① 단서 유추)" → 원고 "갑의 배임적 의도를 알지 못했고 알 수 없었다(선의·무과실)"
**5. 결론**: 등기 미비 + 상대방 선의·무과실 → 계약 유효(인용) / 대표권남용 + 상대방 악의·과실 → 법인에 효력 불귀속(기각)

### (2) 법인의 불법행위책임 공방

**1. 청구권기초**: 원고(피해자 병)의 피고(법인 A)에 대한 §35① 법인의 불법행위 손해배상청구권
**2. 요건**: ① 대표기관 갑의 행위 (O) ② 외형상 직무관련성 (?) ③ 불법행위 일반요건(위법행위+고의·과실+손해+인과관계) (O)
**3. 쟁점 — 직무관련성 판단 기준 (외형설)**
- **판례** (대판 [[2003다15280]]): 외형설 — 외형상 직무행위면 개인 사리·법령 위반이어도 직무관련성 인정. 다만 피해자가 악의·중과실이면 법인 면책 / 중과실 = "거의 고의에 가까운 정도의 주의 결여"
**4. 포섭**: → 피고(법인 A) 항변① "갑의 행위는 직무관련성 없음(개인적 사리)" → 원고 "외형상 직무행위(외형설)" → 피고 항변② "병은 직무행위 아님을 알았거나 중과실로 알지 못함" → 원고 "통상의 과실에 불과, 중과실 아님" + 대표자 개인(갑)에게 §750 별도 청구 가능(부진정연대)
**5. 결론**: 외형상 직무행위 + 피해자 선의·경과실 → 법인 §35① 책임(인용) / 피해자 악의·중과실 → 법인 면책(기각, 단 갑 개인 §750 책임은 별도)

### 부록: 법인 대표행위 하자 모답형 (조문·판례 구조)

> **[1단계: 계약상 책임 — §59·§60]**
> A법인의 대표자 갑은 법인의 사무에 관하여 법인을 대표하는데(§59①), 대표권의 제한은 이를 등기하지 않으면 제3자에게 대항하지 못한다(§60). 본 사안에서 정관상 제한이 등기되지 않았다면, 을의 선·악의를 불문하고 A법인은 대표권 제한을 주장할 수 없어 계약은 유효하다.
>
> **[2단계: 불법행위책임 — §35①]**
> 설령 정관 위반이 등기되어 계약이 무효가 되더라도, 갑의 행위가 외형상 직무행위라면 §35①에 의해 A법인은 손해배상책임을 진다.
>
> **[3단계: 대표권 남용 — §107① 단서 유추]**
> 대표자가 법인의 이익이 아니라 자기 또는 제3자의 이익을 위하여 대표권을 행사한 경우, 상대방이 그 배임적 의도를 알았거나 알 수 있었다면 법인에 효력이 귀속되지 않는다. → cf. §6-1 비진의표시

## §5-6. 비법인사단의 책임 — ★★

### 총유물 관리·처분 (§275, §276)

> **[판례]** 종중 소유의 재산은 종중원의 **총유**에 속하는 것이므로 그 관리 및 처분에 관하여 먼저 **종중규약**에 정하는 바가 있으면 이에 따라야 하고, 그 점에 관한 종중규약이 없으면 **종중총회의 결의**에 의하여야 하므로, 비록 종중 대표자에 의한 종중 재산의 처분이라고 하더라도 그러한 절차를 거치지 아니한 채 한 행위는 **무효**이다. **(대판 1996.8.20. [[96다18656]])**

- **총유물 관리·처분행위**: 총유물에 관한 매매계약 체결, 물적 담보 제공, 신축 건물 분양 등 → 규약 또는 총회결의 미비 시 **무효**

### 비법인사단 대표권 제한 — 정관에 의한 단순 대표권 제한

> **[판례]** ① 비법인사단의 경우에는 대표자의 대표권 제한에 관하여 **등기할 방법이 없어** §60의 규정을 **준용할 수 없고**, ② 비법인사단의 대표자가 정관에서 사원총회의 결의를 거쳐야 하도록 규정한 대외적 거래행위에 관하여 이를 거치지 아니한 경우라도, 이와 같은 사원총회 결의사항은 **비법인사단의 내부적 의사결정에 불과**하므로, ③ 그 거래 **상대방이 대표권 제한 사실을 알았거나 알 수 있었을 경우가 아니라면** 그 거래행위는 **유효**하다. ④ 대표권 제한 사실에 대한 상대방의 악의·과실은 이를 주장하는 **비법인사단 측이 주장·입증**하여야 한다. **(대판 2003.7.22. [[2002다64780]])**

- **총유물 관리·처분행위가 아닌** 단순 대표권 제한으로 본 경우: 타인의 채무를 보증하는 행위, 설계용역계약 체결, 대출계약 체결 등
- **법인과의 차이**: 법인은 §60에 의해 등기로 제3자 대항 가능하나, 비법인사단은 등기할 수 없으므로 **상대방 악의·과실을 비법인사단 측이 입증**해야 한다

### 비법인사단의 불법행위책임

- 법인의 불법행위책임(§35) **유추적용**(대판 [[2002다27088]])이므로 법인 사안과 동일하게 처리

## 3. 권리주체와 제한능력자 [빈도 #4: 행위능력 53]

> **같이 볼 사항**: 속임수(§17) · 확답촉구(§15) ↔ [[무권대리]] 최고(§131) 결론 반대 · 신의칙으로 취소 제한 불가(강행규정, §2-4-7) · 법정추인(§145)

> **위치**: 권리의 주체 > 제한능력자

### 3-1. 성년 (§4)

> **§4 [성년]** 사람은 **19세**로 성년에 이르게 된다.

- 만 19세 미만인 자 = **미성년자** → §5 이하 제한능력자 보호 적용
- 혼인에 의한 성년의제(§826의2)가 적용되면 미성년자가 아니므로 §5 적용 X

### 3-2. 미성년자의 법률행위 (§5)

> **§5① [미성년자의 법률행위] 본문**
> ① **미성년자**가 ② **법률행위**를 함에는 ③ **법정대리인의 동의**를 얻어야 한다.
> → 효과: 동의 없는 행위 → **소급적 무효** (취소하면 처음부터 무효, §141)

> **§5① 단서**
> 다만 **권리만을 얻거나 의무만을 면하는 행위**는 그러하지 아니하다.
> → 효과: 동의 불요, 단독행위 유효

> **§5②**
> 위 규정에 위반한 행위는 **취소**할 수 있다.
> → 취소권자: 제한능력자 본인 + 법정대리인 (§140)

- 요건 ① "미성년자": 만 19세 미만 (§4)
- 요건 ② "법률행위": 재산상의 법률행위에 한정. 사실행위(매장물발견, 가공, 점유취득 등)에는 적용 X
- 요건 ③ "법정대리인의 동의": 사전 동의(허락). 명시적일 필요 없이 **묵시적으로도 가능**
- 효과 "취소": 취소하면 처음부터 **소급적 무효** (§141). 현존이익 한도 반환 (§141 단서)

### 3-3. 묵시적 동의 판례

**대판 2007.11.16. 선고 [[2005다71659]],71666,71673**

> **[판례 요지]** ① 미성년자가 법정대리인의 동의 없이 체결한 **신용카드 이용계약**을 취소하는 것이 **신의칙에 위배된 것이라고 할 수 없다**. ② 제한능력자 보호 규정은 **강행규정**이므로 [[신의칙]](§2)만으로 취소권을 부정할 수 없다. ③ **법정대리인의 동의는 언제나 명시적이어야 하는 것은 아니고 묵시적으로도 가능한 것**이며, 묵시적 동의 여부는 ㉮ **미성년자의 연령**·**지능** ㉯ **직업**·**독자적 소득 유무** ㉰ **계약의 성질**·**체결경위**·**내용** 등을 **종합하여** 판단한다. ④ 법정대리인이 합리적으로 예상할 수 없는 **현저히 벗어나는 거래**에는 묵시적 동의가 미치지 않으며, **개별 거래별**로 동의 범위를 판단한다.

### 3-4. 피성년후견인 (§10)

> **§10 [피성년후견인의 행위와 취소]**
> ① 피성년후견인의 **법률행위**는 **취소**할 수 있다.
> ② 가정법원은 피성년후견인이 **단독으로** 할 수 있는 법률행위의 **범위를 정할** 수 있다.
> ③ 일용품의 구입 등 **일상생활에 필요**하고 그 **대가가 과도하지 않은** 법률행위는 피성년후견인이 **단독으로** 할 수 있다.

- 요건: 정신적 제약으로 사무처리능력이 **지속적으로 결여**된 사람 → 가정법원의 성년후견 개시 심판(§9)
- 효과: 법률행위 **원칙적** 취소 가능. 성년후견인의 동의가 있더라도 취소 가능 (동의한 대로 할 것이라는 기대 X)
- 성년후견인은 **동의권 X**, **대리권 + 취소권**만 보유(§938)
- 예외: ① 가정법원이 정한 범위 내 단독 가능(§10②) ② 일상생활 필요 행위(§10③) ③ 추인(§143)


### 3-5. 피한정후견인 (§13)

> **§13 [피한정후견인의 행위와 동의]**
> ① 가정법원은 피한정후견인이 **한정후견인의 동의**를 받아야 하는 행위의 **범위를 정할** 수 있다.
> ④ 동의가 필요한 행위를 피한정후견인이 **동의 없이** 한 경우 → **취소** 가능 (§140)

- 요건: 정신적 제약으로 사무처리능력이 **부족**한 사람 → 가정법원의 한정후견 개시 심판(§12)
- **부족** (한정후견) vs **지속적 결여** (성년후견): 정신적 제약의 경중으로 구분
- 가정법원이 동의를 받아야 하는 행위의 범위를 **탄력적으로** 정함 (§13①)
- 그 범위 밖의 행위 → 피한정후견인 **단독** 가능
- 일상생활에 필요하고 대가가 과도하지 않은 행위 → 단독 가능 (§13②)

### 3-6. 제한능력자 3유형 비교표

| 구분        | **미성년자** (§5)                      | **피성년후견인** (§10)                   | **피한정후견인** (§13)               |
| --------- | ---------------------------------- | ---------------------------------- | ------------------------------ |
| **원인**    | **만 19세** 미만 (§4)                  | 정신적 제약 → 사무처리능력 **지속적 결여**         | 정신적 제약 → 사무처리능력 **부족**         |
| **개시**    | 출생 시 당연                            | 가정법원 심판 (§9)                       | 가정법원 심판 (§12)                  |
| **법정대리인** | 친권자·미성년후견인 (§911, §928)            | 성년후견인 (§938)                       | 한정후견인 (§959의4)                 |
| **동의권**   | 법정대리인 **동의** 필요 (§5①)              | 동의권 **X** (대리권·취소권만)               | **가정법원이 정한 범위**에서 동의 필요 (§13①) |
| **위반 효과** | 취소 가능 (§5②)                        | 원칙 취소 가능 (§10①)                    | 동의 필요 **범위 위반 시 취소** (§13④)    |
| **단독 가능** | 권리만 얻거나 의무만 면하는 행위 (§5① 단서) + 용돈조항 | 법원이 정한 범위 + **일상생활 필요 행위** (§10②③) | 동의 필요 범위 밖 + 일상생활 필요 행위 (§13②) |

### 3-7. 취소와 추인 구조 (§140--§146)

#### (1) 취소의 효과 (§141)

- 취소하면 **처음부터** 소급적 무효 (§141 본문)
- 제한능력자는 **현존이익** 한도에서만 반환 (§141 단서)
- 의사무능력을 이유로 한 무효의 경우에도 §141 단서 **유추적용** (대판 2009.1.15. [[2008다58367]])

> **[판례]** 미성년자가 **신용카드 이용계약**을 취소하는 경우, 신용카드 이용계약이 취소되더라도 신용카드회원과 가맹점 사이에 체결된 **개별 매매계약**은 특별한 사정이 없는 한 **유효하게 존속**한다. 신용카드발행인이 가맹점에 대금을 지급함으로써 회원은 **매매대금 지급채무를 법률상 원인 없이 면제받는 이익**을 얻었으며, 이러한 이익은 **금전상의 이득**으로서 특별한 사정이 없는 한 **현존하는 것으로 추정**된다. **(대판 2005.4.15. [[2003다60297]] 등)**

#### (2) 추인 3유형

| 유형 | 요건 | 효과 | 답안 포인트 |
|---|---|---|---|
| **명시적 추인** (§143) | 취소의 원인이 **소멸된 후** 추인할 수 있는 자(§140)가 추인 | 처음부터 유효 (소급) | 법정대리인 추인은 원인 소멸 전에도 가능 |
| **묵시적 추인** (판례) | 취소 원인 소멸 후 추인으로 볼 수 있는 행위 (예: 전매행위) | 처음부터 유효 (소급) | 전매행위 = 묵시적 추인으로 연결 |
| **법정추인** (§145) | 취소할 수 있는 행위에 대해 **추인할 수 있는 때에** 아래 사유 발생 | 처음부터 유효 | 법정추인 사유는 추인할 수 있는 후 발생해야 함 |

#### (3) §145 법정추인 사유 (6가지)

> **§145 [법정추인]** 취소할 수 있는 법률행위에 대하여 다음 각 호의 어느 하나에 해당하는 사유가 있으면 **추인할 수 있는 때에** 한하여 추인한 것으로 본다:
> 1. **전부 또는 일부의 이행**
> 2. **이행의 청구**
> 3. **경개**
> 4. **담보의 제공**
> 5. 취소할 수 있는 행위로 취득한 **권리의 전부 또는 일부의 양도**
> 6. **강제집행**

- 핵심: 법정추인 사유는 반드시 **"추인할 수 있는 때"**(= 취소 원인 소멸 후) 이후에 발생해야 함
- 취소 원인이 소멸되기 전에 위 행위를 하더라도 법정추인 불성립

#### (4) 취소권의 소멸 (§146)

> **§146 [취소권의 소멸]** 취소권은 **추인할 수 있는 날로부터 3년** 내에, **법률행위를 한 날로부터 10년** 내에 행사하여야 한다.

- 제척기간 (소멸시효 아님)

### 3-8. 상대방 보호 (§15--§17)

#### (1) 확답촉구권 (§15)

| 촉구 상대방 | 요건 | 확답 미발송 시 효과 |
|---|---|---|
| **능력자가 된 본인** (§15①) | 1개월 이상 기간 정하여 촉구 | **추인** 간주 |
| **법정대리인** (§15②) | 1개월 이상 기간 정하여 촉구 | **추인** 간주 |
| 특별한 절차 필요한 행위 (§15③) | 기간 내 절차를 밟은 확답 미발송 시 | **취소** 간주 |

- 확답 기준: **발송** 여부 (도달 아님)
- cf. §7-4 [[무권대리]] 최고·철회권과 비교:
  - → cf. §7-4 [[[무권대리]] 상대방의 최고권]: §131에서는 본인이 침묵하면 **추인 거절 간주** ← §15에서는 침묵 시 **추인 간주** (결론 반대)

#### (2) 철회권·거절권 (§16)

- **추인 전**에 계약상대방은 의사표시를 **철회** 가능 (§16①)
- 단독행위는 **거절** 가능 (§16②)
- 단, 계약 당시 **제한능력자임을 알았던** 상대방 → 철회 불가 (악의 상대방 보호 X)

#### (3) 속임수 (§17)

> **§17 [제한능력자의 속임수]**
> ① 제한능력자가 **속임수**로써 자기를 **능력자로 믿게** 한 경우 → 그 행위를 **취소할 수 없다**.
> ② 미성년자나 피한정후견인이 속임수로써 **법정대리인의 동의가 있는 것처럼** 믿게 한 경우 → **취소할 수 없다**.

- **단순 침묵** = 속임수 불해당. **적극적 기망**이 있어야 함
- 피성년후견인은 §17② 적용 X (법정대리인 동의권 자체가 없으므로). 다만 §17① 적용 가능
- 속임수 유무는 **상대방**이 입증

[^속임수교재]: [《민법강의(26)》 p.75 | "속임수의 의미를 반드시 적극적인 기망수단을 쓴 경우로 좁게 한정할 이유는 없고, 제한능력자에게 속임수의 고의가 있고 또 그것이 모든 사정을 고려할 때 상대방이 오신할 만한 경우에는 속임수로 인정"]

### 3-9. 공방구조 -- 미성년자 매매계약 취소

**1. 청구권기초**: 원고(상대방)의 피고(미성년자)에 대한 §563 매매계약에 기한 대금지급청구권
**2. 요건**: ① 매매계약 성립 (O) ② 유효한 법률행위 (?) — 법정대리인 동의 여부
**3-1. 쟁점 — 미성년자 취소권 행사 vs 법정추인·묵시적 동의**
- **판례** (대판 [[2005다71659]]): 묵시적 동의 여부는 연령·지능·직업·소득·계약경위 종합 판단. [[신의칙]] 위반으로 취소권 부정 불가(강행규정) / 묵시적 동의 인정 여부가 핵심
**3-2. 쟁점 — §17 속임수에 의한 취소권 배제**
- **판례**: 적극적 기망행위 입증 필요. 단순 침묵은 속임수 불해당 / 속임수 고의 + 상대방 오신 필요
**4. 포섭**: → 피고(미성년자) 항변 "§5②·§140 취소(법정대리인 동의 부존재) → 소급적 무효(§141)" → 원고 재항변① "법정추인(§145 제1호) — 전부이행" (반박: "추인할 수 있는 때" 이후인지 확인) → 원고 재항변② "묵시적 동의(대판 [[2005다71659]])" → 원고 재항변③ "[[신의칙]](§2) 위반" → 배척(강행규정) → 원고 재항변④ "§17 속임수" → 적극적 기망 입증 필요
**5. 결론**: 법정대리인 동의 부존재 + 법정추인·묵시적 동의·속임수 모두 불인정 → 취소 유효, 대금청구 기각 / 묵시적 동의 또는 법정추인 인정 → 취소 불가, 대금청구 인용

## 2. 민법총칙 서론·신의칙 (§1, §2) [빈도 #5: 신의칙 30]

> **같이 볼 사항**: 금반언(§2-4-2) → 강행법규 위반 무효 시 적용 불가 · [[권리남용]](§2-4-5) → 민법3 배타적 사용수익권 포기 연결 · 제한능력자 취소권과 [[신의칙]](§2-4-7)

> **위치**: 민법총칙 서론 > 법원·[[신의칙]]

### 2-1. 민법의 법원 -- 제1조 (관습법 vs 사실인 관습)

> **제1조 (법원)** 민사에 관하여 법률에 규정이 없으면 **관습법**에 의하고 관습법이 없으면 **조리**에 의한다.

#### 관습법 vs 사실인 관습 비교표

| 구분 | **관습법** | **사실인 관습** |
|------|-----------|-----------------|
| **법적 성격** | 법적 확신을 얻은 사회규범 | 단순한 관행 |
| **효력** | **법령과 같은 효력** | 당사자 의사 **보충**에 그침 |
| **법원의 태도** | 법원이 **직권**으로 확정 | 원칙적으로 당사자 **주장·입증** |
| **강행규정과의 관계** | 헌법을 최상위로 하는 전체 법질서에 반하지 않을 것 | 강행규정 영역에서는 법적 효력 부여 불가 |

**관습법 성립 요건**: ① **장기간 반복된 관행**의 존재, ② 사회 구성원의 **법적 확신**, ③ 헌법을 최상위 규범으로 하는 **전체 법질서에 반하지 않을 것**.

> **§106 (사실인 관습)**: "법령 중의 선량한 풍속 기타 사회질서에 관계없는 규정과 다른 관습이 있는 경우에 당사자의 의사가 명확하지 아니한 때에는 그 관습에 의한다."
> - **사실인 관습의 근거 조문은 §106**이다.
> - §1의 관습법(법원으로서 법령과 동일한 효력)과 달리, §106의 사실인 관습은 **임의규정을 보충하는 효력**에 그친다. 강행규정 영역에서는 적용 불가.

#### 주요 판례

- **종중원 자격** (대판(전합) 2005. 7. 21, [[2002다1178]]): 종래 남성만 종중원으로 인정한 관습은 **남녀평등(양성평등)의 헌법원칙에 위반**되어 효력이 없으며, 성별 구별 없이 성년이 되면 조리에 의해 당연히 종중원이 된다.
- **제사주재자** (대판(전합) 2008. 11. 20, [[2007다27670]]): 가정의례준칙(성문법)에 제사주재자가 정해져 있다면, 이와 다른 내용의 관습법은 인정될 수 없다. -- 관습법은 성문법에 어긋날 수 없음.
- **[판례]** (대법원 1983. 6. 14. 선고 [[80다3231]]) 관습법은 사회의 법적 확신과 인식에 의하여 법적 규범으로 승인된 것으로서 법령과 같은 효력을 갖는다.
- **[판례]** (대법원 1983. 6. 14. 선고 [[80다3231]]) 사실인 관습은 법률행위 당사자의 의사를 보충하는 데 그치고, 강행규정 영역에서는 원칙적으로 법적 효력을 부여할 수 없다.

### 2-2. 법률관계와 호의관계

| 구분 | **법률관계** | **호의관계** |
|------|-------------|-------------|
| **의의** | 법에 의해 규율되는 생활관계 | 법적 구속력을 의도하지 않은 **무상**의 관계 |
| **예시** | 매매, 임대차, 고용 등 | 저녁 식사 초대, 이웃 아이 돌보기, **호의동승** |
| **계약책임** | 채무불이행 책임 발생 O | **계약상 청구권 발생 X** |
| **불법행위** | 제750조 적용 O | 보호의무 위반 시 **불법행위 책임(§750) 가능** |

#### 호의동승 판례

**무상으로 차에 동승했다는 사실만으로** 바로 가해자의 배상액이 감경되는 것은 아니나, **신의칙이나 형평의 원칙**에 비추어 감경할 만한 제반 사정이 있다면 배상액을 감경할 수 있다.

> **[판례]** 차량의 운행자가 아무런 대가를 받지 아니하고 동승자의 편의와 이익을 위하여 동승을 허락한 경우, 그 **운행 목적**, 동승자와 운행자의 **인적관계**, **동승 경위**, 특히 동승을 요구한 **목적과 적극성** 등 여러 사정에 비추어 가해자에게 일반 교통사고와 동일한 책임을 지우는 것이 **신의칙이나 형평의 원칙으로 보아 매우 불합리하다고 인정될 때**에는 그 배상액을 **경감**할 수 있으나, **단순히 호의로 동승하였다는 사실만** 가지고 바로 이를 배상액 경감사유로 삼을 수 있는 것은 아니다. **(대판 1996.3.22. [[95다24302]])**

### 2-3. 사적자치의 원칙

- **임의규정**: 민법의 대부분. 당사자 간 **약정이 우선** 적용되고, 약정이 없으면 민법(임의규정)이 **보충적**으로 적용된다.
- **강행규정**: 미성년자 보호, 임차인 보호 등. 당사자의 약정(특약)보다 **우선**하며, 이에 위반되는 약정은 **무효**이다.
- **실무적 유의점**: 계약서에 명시된 내용이 있다면, 설령 민법의 내용과 같더라도 **계약상 권리**로서 주장하는 것이 원칙이다.

### 2-4. 신의성실의 원칙 (제2조) -- ★★

#### 조문 원문 + 요건별 분리

> **제2조 (신의성실)**
> ① 권리의 행사와 의무의 이행은 **신의에 좇아 성실히** 하여야 한다.
> ② **권리는 남용하지 못한다.**

| 조문 | 요건 | 효과 |
|------|------|------|
| **§2①** | ① **권리의 행사**와 ② **의무의 이행**은 ③ **신의에 좇아 성실히** 하여야 한다 | 신의칙 위반 시 **권리행사 제한** 가능 |
| **§2②** | **권리는 남용하지 못한다** | **권리남용 금지** |

**성격**: 일반조항, **강행규정**, **직권조사사항** (당사자의 주장이 없어도 법원이 직권으로 판단)

**형식의 특수성**: 일반적 법조문과 달리 요건과 효과가 매우 **추상적**으로 규정. §103([[반사회질서]] 법률행위 무효)과 유사한 일반조항. -- **일반조항으로의 도피(남용)는 경계**해야 한다.

**기능**: ① **해석** 기능, ② **보충** 기능, ③ **수정** 기능

#### 2-4-1. 신의칙의 보충적 기능 (부수적 의무)

**고지의무 위반 (부작위에 의한 기망)**: 아파트 분양 시 인근에 공동묘지나 쓰레기 매립장이 조성되는 사실은 계약 체결 여부를 결정하는 데 **중요한 사항**이다. 분양자는 이를 수분양자에게 고지할 **신의칙상 의무**가 있으며, **침묵**은 사기에 의한 법률행위 취소의 이유가 되는 **기망행위**에 해당한다 (§110). → cf. §5 [의사표시·사기]

#### 2-4-2. 금반언의 원칙 (모순행위 금지의 원칙) -- ★★

**개념**: 자신의 **선행행위**와 모순되는 **후행행위**(권리행사)는 허용되지 않는다는 원칙.

**요건**:
- ① 선행행위로 인해 상대방에게 **정당한 신뢰 형성**
- ② 선행행위와 **모순되는 후행행위**
- ③ 후행행위로 인해 **상대방의 신뢰 침해**

**주요 판례**:

- **배당금 수령 후 소유권말소 청구 부정**: 목적물 경매 시 이의 없이 배당금 및 이사비용을 모두 챙겨놓고, 나중에 경매의 기초가 된 채권무효를 이유로 소유권이전등기 말소를 청구하는 행위는 **금반언에 반하여 부적법**하다.
- **무권대리인의 상속 후 무효 주장 부정**: 무권대리인이 자신의 대리행위 후 본인을 상속한 뒤, 본인의 지위에서 예전 자신의 대리행위가 무권대리라며 무효를 주장하는 것은 **금반언에 반한다**.

**적용의 한계 -- 강행법규 위반 무효**: 선행행위가 **강행법규에 위반하여 무효**인 경우, 무효를 주장하는 후행행위는 **[[신의칙]] 위반이 아니다**. 금반언을 이유로 무효 주장을 배척하면 **강행법규의 입법취지가 훼손**되기 때문이다.

> **예시**: ① 토지거래허가를 잠탈할 목적으로 증여 형식으로 행한 무상양도 = 확정적 무효 (강행규정 위반이므로 [[신의칙]] 위반 주장 배척). ② **미성년자**가 매매계약 후 스스로 취소하는 경우 = 미성년자 보호라는 **강행규정이 우선**. → cf. §2 [제한능력자 취소권과 신의칙]

> **[판례]** 토지거래계약허가제도는 **유상계약에만 한정**되어 적용되므로, 남편으로부터 **무상증여** 받은 토지에 대하여 토지거래계약허가를 받은 사안에서 처음부터 허가를 요하지 않는 경우에 해당하여 위반죄가 성립하지 않는다. **(대판 2009.5.14. [[2009도926]])**

#### 2-4-3. 실효의 원칙 -- ★★

**개념**: 권리자가 **상당 기간** 권리를 행사하지 않아, 상대방이 앞으로도 **권리행사를 하지 않을 것이라고 정당하게 신뢰**한 경우, 그 후 새삼스럽게 권리를 행사하는 것은 **신의칙에 반하여 허용되지 않는다**는 원칙.

**요건**:
- ① 권리자의 **상당 기간 권리 불행사**
- ② 상대방의 **정당한 신뢰** 형성 (앞으로도 행사하지 않을 것이라는 신뢰)
- ③ 권리행사가 **신의칙에 반하는** 결과를 초래

**적용 범위 + 판례**:

- **원칙**: 모든 권리에 적용될 수 있다.
- **소유권 등 항구적 권리**: 실효의 원칙 적용이 **어렵다**. -- 종전 소유자가 송전선 철거 청구를 하지 않았다고 해서 새로운 매수인의 철거 청구가 실효의 원칙에 반하는 것은 **아니다** [사건번호: 교재 OCR 판독 불가 — 원본 확인 필요]
- **형성권(해제권)**: 적용 **가능**. 해제권이 발생한 지 **1년 4개월**이 지나도록 행사하지 않고 오히려 대금 이행을 최고하는 등 **계약의 유효를 전제로 행동**하여 신뢰를 주었다면, 갑자기 새삼스럽게 예전의 사유로 해제권을 행사하는 것은 **실효의 원칙에 반한다**.

---

#### 2-4-4. 사정변경의 원칙 (사정변경에 의한 해제·해지) -- ★★

**개념**: 계약 성립 당시 기초가 된 **객관적 사정**이 당사자가 **예견할 수 없이 현저히 변경**되었고, 계약 구속력을 유지하는 것이 **신의칙에 현저히 반할 때** 계약의 효력을 소멸시키는 것.

**요건**:
- ① **예견 불가능한 현저한 사정변경**이 있을 것
- ② **당사자에게 책임 없는 사유**로 생긴 것일 것
- ③ **객관적** 기초사정의 변경일 것 (주관적 동기 변화만으로는 **부족**)
- ④ 계약구속을 유지하는 것이 **신의칙에 현저히 반하는** 결과를 초래할 것

**판례의 태도**: 대법원은 종전 부정적이었으나, 최근에는 「**계약준수의 원칙의 예외로서 계약해제가 인정될 수 있다**」는 입장이다(대판 2007.3.29. [[2004다31302]])
**주요 판례**:

- **부정 사례**: 부지 매수 후 음식점을 지으려 했으나 불가해진 경우 -- 이는 단순한 **주관적 사정**의 변경에 불과하여 사정변경 해제가 **인정되지 않는다** (객관적 사정의 변경이어야 함).
- **인정 사례**: 임원 또는 이사 지위에서 체결한 **계속적 보증계약**의 경우, **퇴사** 시 사정변경을 이유로 한 **해지권을 인정**한다.

#### 2-4-5. 권리남용 금지의 원칙 (§2②) -- ★★

> **제2조 ② 권리는 남용하지 못한다.**

**요건 (판례 입장)**: **객관적 요건**과 **주관적 요건**이 **모두** 필요하다.

| 요건 | 내용 |
|------|------|
| **① 객관적 요건** | 권리의 본래 **사회적 목적에 적합하지 않은** 행사. 권리자에게 **정당한 이익이 결여**됨. |
| **② 주관적 요건** | 오직 상대방을 해할 목적(**가해 의사**)으로 행사하는 경우. -- 이 요건은 **객관적 사정에서 추인**될 수 있다. |

**효과**: 권리남용으로 인정되면 그 권리행사는 **위법**한 것으로 되어, 권리를 '행사'한 것으로 되지 않는다. 따라서 권리행사를 전제로 하는 효과는 **발생하지 않는다**

> **→ cf. 민법3(물권법)**: 배타적 사용수익권 포기 + [[부당이득]] 인과관계 부정 쟁점에서도 **§2② [[권리남용]]** 검토됨 (민3 §2-4-8 참조)

**주요 판례**:

- **긍정 -- 건물 철거 청구 배척**정당한 사용 권한이 없는 자를 상대로 한 소유자의 철거 청구라 하더라도, 건물 철거 시 발생하는 **막대한 사회경제적 손실** 등 제반 사정을 고려할 때 지극히 부당하다면 신의칙에 기해 **철거 청구가 배척**될 수 있다.
- **긍정 -- 인륜 위반** 외국에 이민을 가 있어 급박한 사정이 없는 **딸**이 고령과 지병으로 고통을 겪는 **아버지**와 그를 부양하며 동거하는 **남동생**을 상대로 자기 소유 주택의 명도 및 퇴거를 청구하는 행위는 **인륜에 반하는 [[권리남용]]**에 해당한다.
- **부정 -- 송전선 철거**: 토지 소유자가 토지 상공에 송전선이 설치된 사정을 알면서 취득한 후 13년이 지나 철거를 구한 사안에서, 토지이용권 확보나 적절한 보상이 없는 점에 비추어 **권리남용에 해당하지 않는다**고 판시

> **학설과 판례의 차이**: 학설은 주관적 요건을 권리남용의 **부차적 요소**로 보지만, 판례는 **양 요건 모두 필요**하다고 하면서도 주관적 요건은 **객관적 사정에서 추인 가능**하다는 태도를 취한다.

## 4. 부재와 실종 (§22--§29) -- 축소 [빈도 #6: 권리능력 9]

> **위치**: 권리의 주체 > 부재자·실종

> 교수님이 민소법 쟁점이라 스킵한 것으로 보임 → 최소한의 조문·효과만 정리
### 4-1. 부재자 재산관리 (§22--§25) 핵심

#### §22 (부재자의 재산관리)

> **§22①** 종래의 주소나 거소를 떠난 자(**부재자**)의 재산관리에 관하여:
> ① **부재자**일 것 ② **재산관리인을 두지 아니한** 때 ③ **이해관계인 또는 검사의 청구**
> → 효과: **법원**이 재산관리에 관한 필요한 처분을 명함

- "부재자": 종래 주소·거소를 떠나 용이하게 돌아올 수 없는 자. **생사불명까지는 요구하지 않음**

#### §24 (관리인의 권한)

> **§24 본문** 관리인의 권한 = **§118 준용**: ① **보존행위** ② **목적물·권리의 성질을 변하지 않는 범위에서의 이용·개량행위**
> **§24 단서** 위 권한을 **초과하는 행위**(처분행위 등)를 하려면 **법원의 허가** 필요
> → 허가 없는 처분 = **무권대리로서 무효**

- 법원 허가가 있더라도 **부재자를 위하는 범위**(내재적 한계)를 넘으면 무효
- 이 경우 §126 표현대리는 부재자 보호 취지상 **부정**
- 사후 법원 허가 → **추인 효과** 가능 (대판 [[80다3063]])

#### 부재자 보호 취지 판례

**대판 [[69다719]]; [[91다11810]]**

> **[판례 요지]** ① 부재자재산관리인의 **선임결정이 취소되지 않는 한** 관리인의 권한이 **당연히는 소멸되지 아니한다**. ② 재산관리인의 처분행위에 기하여 경료된 등기는 **적법하게 경료된 것으로 추정**된다.

- 거래상대방은 관재인의 처분권한을 **엄밀히 조사**해야 함. 선의·무과실 항변 불인정
  - → cf. §6 [대리] 외관법리 파트에서 이 예외 별도 표기 필요


#### 공방 구조 — 부재자관재인 권한 초과 처분

> **사안**: 갑이 행방불명되자 법원이 을을 부재자재산관리인으로 선임하였다. 을이 법원의 허가 없이 갑 소유 부동산을 병에게 매도하고 이전등기를 마쳤다. 갑이 귀래한 후 병에게 부동산 반환을 청구한다.

**1. 청구권기초**: 원고(갑)의 피고(병)에 대한 §213 소유물반환청구권
**2. 요건**: ① 갑이 소유자 (O) ② 병이 점유자 (O) ③ 을의 처분이 갑에게 효력 없음 (?) — §118 권한 초과 → [[무권대리]]
**3. 쟁점 — §126 권한을 넘은 [[표현대리]] 적용 여부**
- **판례**: 부재자관재인은 법원 선임이므로 본인(갑)의 수여 행위 없음 → §126 적용 불가 / 법원 부여 관리권은 본인의 기본대리권 수여가 아님
**4. 포섭**: → 피고(병) 항변 "§126 [[표현대리]] — 을에게 처분권한이 있다고 믿었다" → 원고(갑) "부재자관재인은 법원 선임이므로 본인의 수여 행위 없음 → §126 적용 불가" + 병은 관재인의 처분권한을 엄밀히 조사해야 하므로 선의·무과실 인정 곤란
**5. 결론**: §126 적용 불가 → 을의 처분은 무권대리로 갑에게 효력 없음 → 소유물반환(인용)

### 4-2. 실종선고 (§27--§29) -- 간략

## §8. 무효와 취소 (§137-§146) — ★★★ [기말 범위]
> **위치**: 법률행위 > 무효와 취소

### §8-1. 무효 vs 취소 종합비교표

| 비교축 | 무효 | 취소 |
|---|---|---|
| **효력** | 처음부터 효력 없음 | 취소 시까지 유효, 취소 후 **소급적 무효** |
| **주장권자** | **누구나** | **취소권자** (제한능력자, 착오자, 사기·강박 피해자 등) |
| **추인** | 원칙적 불가 (예외: 무효행위의 추인 §139 → **새로운 법률행위**로 봄) | 추인 가능 → 확정적 유효 |
| **기간** | 기간 제한 **없음** | 취소권 제척기간 (§146: **3년/10년**) |
| **제3자보호** | 개별 규정 (§108②, §548① 등) | §109②, §110③ |
| **부분무효** | §137: 일부 무효→전부 무효 (일부만 유효할 의사 시 일부 유효) | — |
| **중복취소** | — | 이미 취소된 행위를 다시 취소 불가 |


### §8-2. §141 취소의 효과: "처음부터 **소급적 무효**"

> **조문 원문**: 취소된 법률행위는 **처음부터 무효인 것으로 본다**. 다만, 제한능력자는 그 행위로 인하여 받은 이익이 현존하는 한도에서 상환할 책임이 있다.

| 항 | 요건 | 효과 |
|---|---|---|
| **§141** 본문 | 법률행위가 **취소**된 경우 | **처음부터 소급적 무효** |
| **§141** 단서 | 제한능력자의 경우 | 받은 이익이 **현존하는 한도**에서만 상환책임 (**현존이익 반환**) |

- 취소의 효과는 **"소급적 무효"**로 통일하여 정리한다.
- 의사무능력을 이유로 한 무효의 경우에도 §141 단서를 **유추적용**하여 현존이익 한도 반환만 인정한다(대판 2009.1.15. [[2008다58367]]).[

### §8-3. §143 추인, §145 법정추인

### §9-1. 조건부 법률행위 (§147-§150)

#### 조건과 기한의 구별

| 구분 | 내용 | 핵심 차이 |
|---|---|---|
| **조건** | 장래의 **불확실한** 사실에 의존 (성취 여부 미정) | 성취 여부가 불확실 |
| **기한** | 장래의 **확실한** 사실에 의존 (도래 시기만 미정일 수 있음) | 도래 자체는 확실 |
| **단독행위 결부** | 원칙적 **불가** (취소, 해제, 상계 등). 상대방 동의 시 예외적 허용 | — |

#### 정지조건과 해제조건

| 구분 | 의의 | 조문 | 효과 |
|---|---|---|---|
| **정지조건** | 조건 성취 시 효력 **발생** | §147① | 조건 성취 전까지 효력 미발생 |
| **해제조건** | 조건 성취 시 효력 **소멸** | §147② | 조건 성취 시 효력 상실 |

#### 불법조건·기성조건·불능조건 (§151)

| 유형 | 효과 |
|---|---|
| **불법조건** (§151①) | 법률행위 **전체가 무효** (조건만 무효가 아님) |
| **기성조건(+) × 정지조건(+)** | 조건 없는 법률행위 → **유효** |
| **불능조건(-) × 해제조건(-)** | **유효** |
| 그 외 반대 조합 | **무효** |

- `암기`: 기성/불능조건 결합은 수학의 부호 곱셈(+,-)으로 처리.

### [Section E 종합] 대리·무효취소·부관 연결 포인트

1. **대리권 남용 → §107① 단서 유추**: 비진의표시(§6-1), 법인 대표권 남용(§5-3), 대리권 남용(§7-4)은 모두 **동일한 법리**(§107① 단서 유추)로 처리된다.
2. **[[무권대리]] 최고 vs 제한능력자 최고**: 침묵의 효과가 **정반대** — §131은 **거절 간주**, §15는 **추인 간주**.
3. **소급적 무효 통일**: 취소의 효과(§141)는 "처음부터 **소급적 무효**"로 통일한다.
4. **[[표현대리]] 3유형**: **수여표시**(§125) / **넘은**(§126) / **소멸**(§129)로 핵심 키워드를 구별한다.
5. **당사자 확정 → 대리 판단**: 타인 명의 사용 사안은 먼저 **당사자 확정**(§7-6) 후 대리 유형 판단. 명의자=당사자 → 대리, 행위자=당사자 → 무권리자 처분(§7-7).
6. **[[표현대리]] 성립 후 [[대리권남용]] 항변 가능**: 유권대리 → §126 → 대리권남용(§107① 유추) 순서로 판단 (대판 [[86다카1004]]).
7. **추인·철회·취소 효과 정리**:

| 행위 | 주체 | 시점 제한 | 효과 |
|---|---|---|---|
| **추인** (§133) | 본인 | 제한 없음 | 소급하여 유효 (다만 제3자 권리 불해) |
| **철회** (§132) | 선의 상대방 | 추인 **전**까지 | 계약 소멸 |
| **취소** (§140-§146) | 취소권자 | 추인할 수 있는 날로부터 **3년**, 행위 시로부터 **10년** | 소급적 무효(§141), 현존이익 반환(§141 단서) |
| **법정추인** (§145) | — (법률효과) | 추인할 수 있는 **때 이후** | 6가지 사유(전부·일부이행, 이행청구 등) 발생 시 추인 간주 |
