# 형법1 기출 풀이 논거 흐름

> 관련: [[형법1_서보학_중간_정리노트]], [[형법1_압축본]], [[목차_형법총론]], [[사례형_답안_플로우차트]]
> 독법: 죄명 특정 -> 객관적 구성요건 -> 주관적 구성요건 -> 위법성 -> 책임 -> 결론

---

## 풀이 프레임: 형법 사례형 기본 구조

```
1. 죄명 특정 (누가 누구에게 무슨 죄)
2. 객관적 구성요건 (행위.결과.인과관계)
3. 주관적 구성요건 (고의.과실)
4. 위법성 (§21 정당방위 -> §23 자구행위 -> §22 긴급피난 -> §24 피해자승낙 -> 추정적 승낙 -> §20 정당행위)
5. 책임 (책임능력 -> 위법성인식 -> 기대가능성)
6. 미수 (착수 여부 -> 장애/중지/불능)
7. 공범 (정범.공범 확정 -> 이탈.신분)
8. 죄수 (상상적/실체적 경합)
```

> **기출 유형 분류**[^유형]
> - **1번형**: 인과관계.착오 (방법의 착오, 개괄적 고의)
> - **2번형**: 고의.과실 (미필적 고의 판단)
> - **3.4번형**: 위법성조각 (정당방위.긴급피난.오상방위)

### 2025 중간 Q1 -- 인과관계 + 방법의 착오 한계사례 [1번형]

**사안**: 갑이 을을 살해하려 독물 투입 -> 제3자 A가 복용하여 사망[^25중1]

#### 갑의 을에 대한 살인미수

| 단계 | 검토 | 학설/판례 | 결론 |
|------|------|-----------|------|
| 객관적 구성요건 | 살인행위(독물투입) O, 결과 불발생 | -- | 미수 |
| 주관적 구성요건 | 살인의 고의 | -- | O |
| -> 미수 | 장애미수(§25) | 실질적 객관설 | **을에 대한 살인미수** |

#### 갑의 A에 대한 죄책 -- 학설 분기

| 단계 | 판례(법정적부합설) | 교수님(구체적부합설) |
|------|---------------------|----------------------|
| 인과관계 | 갑 행위 -> A 사망 상당? | 합법칙적 조건: O |
| 고의 전용 | **동일 구성요건 내 -> 고의 인정** | **구체적 객체 불일치 -> 고의 부정** |
| A에 대한 죄명 | **살인기수** (83도2813) | **과실치사** (§13 유추) |
| 을에 대해 | (별도 미수 불성립) | 살인미수 |
| 죄수 | 살인기수 단일 | 살인미수 + 과실치사 **상상적 경합** |

> [[구성요건적_착오]] 참조: 방법의 착오에서만 학설 결론이 갈림 (병발사례 3번)

##### 법정적 부합설 내부 분파 — 병발사례 (A상해+B사망)

| 분파 | 기준 | 결론 |
|---|---|---|
| **제1설**(단일이전·구성요건 기준) | 동일 구성요건 내에서만 고의 전용 | B 살인기수만 (A 미수 불인정) |
| **제2설**(경합설·죄질 기준) | 죄질 부합 범위 내 고의 전용 | A 살인미수 + B 살인기수 (상경) |

##### 피교사자 착오 → 교사자에 대한 착오 유형

| 피교사자 착오 | 교사자에게 | 근거 |
|---|---|---|
| 피교사자의 **방법**의 착오 | 교사자에게도 **방법**의 착오 | — |
| 피교사자의 **객체**의 착오 | 교사자에게는 **방법**의 착오 | **방법의 착오설**(다수설) |

#### 답안 뼈대

1. "갑의 을에 대한 살인미수(§25): 독물투입=실행착수, 결과불발생"
2. "갑의 A에 대한 죄책: (판례) 법정적부합설 -> 동일구성요건 내 고의 인정 -> 살인기수"
3. "(교수님설) 구체적부합설 -> 구체적 객체 불일치 -> 고의 조각(§13 유추) -> 과실치사"
4. "사안 포섭: 교수님설로 -- 살인미수+과실치사 상상적 경합"

### 2025 중간 Q2 -- 개괄적 고의 [2번형]

**사안**: 갑이 을을 폭행(제1행위) -> 사망으로 오인 -> 은폐를 위해 강에 투척(제2행위) -> 제2행위로 사망[^25중2]

#### 쟁점: 개괄적 고의의 법적 취급

| 학설 | 핵심 | 결론 | 지위 |
|------|------|------|------|
| **미수설** | 제1·제2행위 분리 | 살인미수 + 과실치사(실체적 경합) | 소수 |
| **개괄적 고의설** | 전체 행위의 개괄적 고의 | **살인기수** | — |
| **인과관계착오설** | 비본질적 차이 → 기수 | **살인기수** | **다수설** |
| **객관적 귀속설** | 전형적 행위로 귀속 가능 | **살인기수** | — |

| 비교축 | 판례(88도650) | 다수설(인과과정착오설) | 교수님(서보학) |
|---|---|---|---|
| **행위 평가** | "전 과정을 개괄적으로 보면" 하나의 행위 | 하나의 행위이되 인과과정에 착오 존재 | 고의의 문제가 아니라 **객관적 귀속**의 문제 |
| **결론** | **살인기수** | **살인기수** | **살인기수** |

- **판례**(88도650): "전 과정을 개괄적으로 보면 피해자의 살해라는 처음에 예견된 사실이 결국 실현된 것이기 때문에 살인죄의 죄책을 면할 수 없다"
- **교수님(서보학)**: 인과관계착오설 지지. 인과과정의 차이가 비본질적이므로 기수범 성립. 객관적 귀속의 관점에서도 동일 결론

> **시체은닉죄 검토**: 제2행위 시 피해자가 아직 생존 → 시체은닉 **불능미수**(§27) 검토 필요 (배점 높으면 기재)

> [[개괄적_고의]] 참조

#### 답안 뼈대

1. "개괄적 고의 사안: 제1행위(폭행)+제2행위(투척)의 법적 취급"
2. "(판례) 단일행위설: 포괄평가 -> 살인기수"
3. "(교수님설) 제1행위=살인미수, 제2행위=과실치사, 상상적 경합"

### 2025 중간 Q3 -- 정당방위(계속적 침해) + 긴급피난 [3.4번형]

**사안**: 성폭행 피해자가 반격[^25중3]

#### 풀이 흐름

| 단계 | 검토 | 학설/판례 | 결론 |
|------|------|-----------|------|
| 정당방위(§21) | 현재의 부당한 침해? | 계속적 침해: 성폭행=계속 중 | O |
| | 부당성(위법성) | 객관적 위법성론(통설/판례) | O |
| | 방위의사 | 필요설(판례) | O |
| | 상당성 | 적합성+최소침해성(필요성)+균형성 완화 | 사안 포섭 |
| 과잉방위(§21②) | 상당성 초과 시 | 질적 과잉방위 한정(교수님/다수설) | 감경/면제 |
| 야간면책(§21③) | 야간+공포·경악·흥분·당황 | **책임조각사유** | 벌하지 아니한다 |
| 긴급피난(§22) | 정당방위 불성립 시 보충 | 방어적 긴급피난: 균형성 완화 | 별도 검토 |

- **판례**(92도2540): "침해되는 법익의 종류, 정도, 침해의 방법, 침해행위의 완급과 방위행위에 의하여 침해될 법익의 종류, 정도 등 일체의 구체적 사정을 참작하여 **방위행위가 사회적으로 상당한 것**이어야 한다"[^정방-92도2540]
- **교수님(서보학)**: 과잉방위는 상당성 중 **필요성(최소침해성) 초과**로 제한. 보충성 불요

##### 질적 과잉방위 vs 양적 과잉방위

| 구분 | 내용 | §21② 적용 |
|---|---|---|
| **질적 과잉방위** | 방위수단·강도 초과 (예: 주먹으로 막을 수 있는데 쇠뭉치 사용) | **적용** |
| **양적 과잉방위** | 시간적 범위 초과 (침해 종료 후 계속 구타) | **원칙 부정** (현재성 소멸 → 정당방위 상황 자체 부정) |

- 교수님/다수설: 과잉방위는 **질적 과잉방위로 제한**. 양적 과잉방위는 현재성 소멸이므로 §21② 불적용[^정방-질양]

##### 사회윤리적 제한 3유형

| 유형 | 내용 | 제한 방법 |
|---|---|---|
| ① 책임무능력자의 침해 | 아동·심신장애자의 공격 | 회피·수비적 방어 우선, 공격적 방위 최후 |
| ② 밀접한 인적관계 | 부부·가족 등 공격 | 수비적 방어 우선 (파탄 관계 제외) |
| ③ 극히 경미한 침해 | 사소한 모욕·경미한 접촉 | 방위권 남용 → 정당방위 자체 부정 |

- 법질서수호 원리가 후퇴하는 경우 **단계적 방위**(회피→수비적 방어→공격적 방어) 요구[^정방-사윤]

##### 싸움과 정당방위 — 예외 3가지

- **판례**(2000도228): "서로 공격과 방어가 계속되는 것이므로 어느 한 쪽의 행위만을 분리하여 정당방위에 해당하는 것으로 볼 수 없다"
- **예외적 인정**(2001도5380)[^정방-싸움]:
  1. 상대방의 **새로운 공격** (예상 밖 무기 사용 등)
  2. **초과적 공격** (기존 싸움 범위를 현저히 넘는 공격)
  3. **일방적 공격 전환** (한쪽이 투쟁의사를 포기했음에도 계속 공격)

##### 도발과 정당방위

| 유형 | 정당방위 | 근거 |
|---|---|---|
| **의도적 도발** | **부정** | 부당한 침해 부존재 (83도1467) |
| **비의도적 도발** | 단계적 방위 범위 내 인정 | 회피→수비→공격 순서 |

> [[정당방위]], [[긴급피난]] 참조

#### 답안 뼈대

1. "§21 정당방위: 현재의 부당한 침해(계속적 침해=성폭행 계속 중) + 방위의사(필요설) + 상당성(92도2540: 사회적 상당성)"
2. "상당성 초과 시 -> **질적 과잉방위**(§21②): 임의적 감경/면제. 야간이면 §21③ 책임조각(벌하지 아니한다)"
3. "정당방위 불성립 시 -> §22 **방어적 긴급피난**: 위난유발자에게 향하는 피난이므로 균형성 완화(본질적으로 열등하지 않을 것)"
4. "(교수님 포인트) 긴급피난 이분설: 우월이익=위법성조각, 동가치이익=책임조각(상대방 정당방위 가능)"

### 2023 중간 Q1 -- 인과관계 + 미필적 고의 + 제3자 피해 [1+2번형]

**사안**: 갑이 독음식 투입 -> 대상이 아닌 갑의 아들이 건강식품을 꺼내 먹고 사망[^23중1]

#### 풀이 흐름

| 단계 | 검토 | 결론 |
|------|------|------|
| 인과관계 | 갑 행위 -> 아들 사망: 상당인과관계? | 가족이 먹을 가능성 -> 상당 O |
| 미필적 고의 | 갑이 아들 사망 결과를 용인? | 스펙트럼 판단: 인식+용인 여부 |
| -> 판례 기준 | "미필적 고의=결과발생 인식+용인" (94도2361) | 사안 포섭 |
| 죄명 | 고의 인정 시: 살인기수 / 부정 시: 과실치사 | |

### 2023 중간 Q2~3 -- 오상방위 + 자구행위 + 긴급피난 [3.4번형]

**(일부 자료 부족 -- 이미지 판독 한계)**[^23중23]

#### 풀이 프레임

| 쟁점 | 검토 순서 | 학설 분기 |
|------|-----------|-----------|
| 오상방위(위전착) | 객관적 침해 부존재 -> §21 적용 불가 -> 위전착 문제 | 6설 스펙트럼 |
| 자구행위(§23) | 보전(O) vs 실현(X) 구분 | 채권 보전 목적이면 인정 가능 |
| 긴급피난(§22) | 보충적 검토 | 보충성.균형성 |

##### 위전착 6학설 스펙트럼

| 학설 | 고의 처리 | 결론 | 지위 |
|---|---|---|---|
| 엄격고의설 | 위법성인식=고의요소 → 조각 | 과실범 | — |
| 소극적 구성요건표지이론 | 불법고의 조각(§13 직접 적용) | 과실범 | — |
| **엄격책임설** | **고의 유지**, §16 금지착오 처리 | 정당이유 O→무죄, X→**고의범** | **판례** |
| **법효과제한책임설** | 불법고의 O + 책임고의 조각 | **과실범** | **다수설** |
| **유추적용설** | **불법고의 자체 조각** (§13 유추) | **과실범** | **교수님** |

##### 핵심 3설 비교 (판례 vs 다수설 vs 교수님)

| 비교축 | 판례(독자이론) | 다수설(법효과제한책임설) | 서보학(유추적용설) |
|---|---|---|---|
| **착오의 성격** | §16 준용(독자적) | 제3의 독자적 착오 | 구성요건적 착오에 유사 |
| **고의** | 유지 | 불법고의 O + 책임고의 X | **불법고의 자체 조각** |
| **결론** | 정당이유 O→위법성 조각, X→고의범 | 과실범 | 과실범 |
| **악의가담자** | 간접정범만 | 간접정범·교사방조 모두 가능 | 간접정범만 |
| **상대방 정당방위** | 정당이유 O→불가, X→가능 | 항상 가능(위법 유지) | 과실 있는 경우만 가능 |

- **교수님(서보학)**: 위전착은 구성요건적 착오와 구조적으로 동일 → §13 유추적용 → 불법고의 조각. 체계적으로 가장 정합적
