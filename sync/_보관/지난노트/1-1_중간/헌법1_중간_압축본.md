## 1. 비례원칙 (§37②) ★★★ [빈출 #1]

- **4단계**: 목적정당성 → 수단적합성 → 침해최소성 → 법익균형성. 1개라도 부정 → 위헌
- **수단적합성**: 최적 수단 불요, **부분적 기여**면 족함
- **심사강도**: 인신·표현의 자유·형벌 = **엄격** / 사회적 기본권 = **완화**(입법재량)

| 부정 단계 | 판례 | 핵심 |
|---|---|---|
| 목적정당성 | 95헌가6등 | 동성동본 혼인금지 — 목적 상실 |
| 수단적합성 | 2022헌마356등 | 태아 성별 고지 — 조항 사문화 |
| 침해최소성 | 2013헌가6 | 필요적 면허취소 — 재량적 취소 대안 |

- **함정**: 비례원칙은 정당해산에도 적용 O / 지방자치권 심사에는 적용 X(본질적 내용 침해 여부)

> 📌 **답안 문구**
> - **4단계**: **목적정당성** → **수단적합성** → **침해최소성** → **법익균형성**, **하나라도** 충족하지 못하면 **위헌**
> - **판례**(95헌가6등): 동성동본 혼인금지 — 가부장적 가치관에 기초한 **목적 자체**가 **정당성 상실** → **위헌**
> - **판례**([[2013헌가6]]): 필요적 면허취소 — **재량적 취소**라는 **덜 침해적 대안** 존재 → **침해최소성 위반** → 위헌
> - **수단적합성**: **최적** 수단일 필요 없고, **부분적 기여**면 족함 (넓게 인정)
> - **심사강도**: **인신·표현의 자유·형벌** = **엄격** / **사회적 기본권** = **완화**(입법재량 존중)

## 2. 법치주의 ★★★ [빈출 #2]

### 법률유보 vs 의회유보
- 법률유보: 행정작용에 법률 **근거** 필요
- 의회유보(본질성이론): 본질적 사항은 국회 **직접** 결정, 포괄위임 **불가**
- [[98헌바70]] (TV 수신료): 수신료 금액 = 본질적 사항 → 국회 직접 결정 → **헌법불합치**

> 📌 **답안 문구**
> - **판례**([[98헌바70]]): "수신료 금액은 **본질적 중요사항**으로서 **국회가 직접 결정**해야 한다" → **헌법불합치**
> - **본질성이론**: **본질적 사항**은 국회가 **직접 입법**, 하위법령에 **포괄위임 불가**
> - **법률유보 vs 의회유보**: 법률유보 = 행정작용에 법률 **근거** 필요 / 의회유보 = **본질적 사항**은 국회 **직접** 결정

### 명확성원칙 ★★★
- 기준: **건전한 상식인** + 법관 보충적 해석으로 파악 가능하면 충족
- 형벌·표현의 자유 = **엄격** / 민사·수익적 = **완화**
- 관련 법조항 **전체** 유기적·체계적 종합 판단
- **함정**: 개괄조항·불확정 개념 절대 금지 (X) → 법해석으로 객관적 기준 얻으면 **허용**

> 📌 **답안 문구**
> - **판례**([[99헌마480]]): "**불온통신**" 금지 — **불명확**성으로 **표현의 자유** 침해 → **위헌**
> - **판단기준**: "통상의 **건전한 상식**을 가진 자"가 **법관의 보충적 해석**으로 의미 파악 **가능**하면 충족
> - **심사강도**: **형벌·표현의 자유** = **엄격** / **민사·수익적** = **완화**
> - **개괄조항**: **절대 금지 아님** → 법해석으로 **객관적 기준** 얻으면 **허용**

### 포괄위임금지 (§75) ★★★
- 처벌·조세법규 = **엄격** / 급부행정·전문기술 = **완화**
- **조례**: 포괄위임금지 **미적용** (지방의회 민주적 정당성)
- **공법인 정관**: 미적용
- **함정**: "조례 위임에도 엄격 적용" (X) → 포괄적인 것으로 족함 ([[92헌마264]])

> 📌 **답안 문구**
> - **판례**([[92헌마264]]): 조례에 대한 법률의 위임은 "**포괄적인 것으로 족하다**" — 지방의회의 **민주적 정당성**
> - **심사강도**: **처벌·조세**법규 = **엄격** / **급부행정·전문기술** = **완화** / **조례** = **포괄적** 위임 가능

### 소급입법금지 ★★
| | 진정소급 | 부진정소급 |
|---|---|---|
| 대상 | 완성된 사실 | 진행 중 사실 |
| 원칙 | **금지** (예외: 중대 공익) | **허용** (신뢰보호 제한) |
- 형벌 소급 = 예외 없이 금지 / 보안처분(전자발찌) = 소급 합헌
- 2008헌바141등 (친일재산): 진정소급이나 중대 공익이 압도 → 합헌

> 📌 **답안 문구**
> - **판례**(2008헌바141등): 친일재산 귀속 — **진정소급**입법이지만 **중대한 공익**이 **신뢰이익을 압도** → **합헌**
> - **원칙**: **진정소급** = 원칙적 **금지** (예외: **중대 공익** + 신뢰이익 미미) / **부진정소급** = 원칙적 **허용** (신뢰보호 제한)
> - **형벌 소급**: 예외 **없이** 금지 / **보안처분**(전자발찌) = 소급 **합헌**

### 신뢰보호원칙 ★★
- 3단계: 선행조치(신뢰 기초) → 신뢰에 따른 행위 → 이익형량(공익 vs 신뢰)
- **함정**: 모든 기대·신뢰 보호 (X) → **보호가치 있는 합리적 신뢰**만
- 위헌 법률 기초 신뢰 = **약한 보호**만

## 8. 관습헌법·통치행위 ★

- 관습헌법 5요건: 기본적 헌법사항 + 오랜 반복 + 항상성 + 명확성 + **국민적 합의**
- 성문헌법과 **동일 효력** → 변경은 §130 **헌법개정**으로만
- 합의성 **상실** 시 효력 상실 가능
- 통치행위: 고도의 정치적 결단 → 사법 자제, 단 **기본권 침해** 시 심사 가능

> **답안 문구**
> - **판례**([[2004헌마554]]): 서울이 수도라는 관습헌법 인정 -- 성문헌법과 동일 효력, 법률로 수도 이전 불가 → 위헌[^18]
> - **학설**: 관습헌법 성립요건 -- 국민적 합의 + 법적 확신 + 장기간 실효성 / 변경은 헌법개정 절차(§130) 필요[^19]

## 9. 공무원제도 (§7) ★ [7주차]

- **§7①**: 공무원 = **국민전체** 봉사자, 국민에 대하여 **책임**
- **§7②**: 공무원의 **신분**과 **정치적 중립성**은 법률이 정하는 바에 의하여 보장
- **직업공무원제**: **정치적 중립성** + **신분보장** + **능력주의**(채용·승진). 정치적 공무원·선출직 **제외**
- **정치활동 제한**: 정당 발기인·당원 **불가**(정당법 §22) / 정치운동·노동운동 제한
- **신분보장**: 정당 사유 없이 의사에 반한 해임 **금지** / 소청심사 + 행정소송

> 📌 **답안 문구**
> - **판례**(2009헌마705등): 공무원의 **집단적** 정책반대·방해 금지 → 침해최소성·법익균형성 충족 → **합헌**. 개인적·개별적 의사표현은 **허용**
> - **판례**([[2011헌바50]]): "공무 외의 일을 위한 집단 행위" → **한정 해석**("공익에 반하는 목적 + 직무전념의무 해태 + 공무 신뢰 손상") → 명확성원칙 **위반 아님**
> - **판례**([[2018헌마551]]): 초중등 교원 정당가입 금지 **합헌** / 대학교원 정당가입 금지 **위헌**
> - **판례**([[2012헌마459]]): 지방자치단체장은 **선출직**(임기 4년·3기) → 장기근속 전제 공무원연금 적용 **제외** → **합헌**

## 10. 경제질서 (§119) ★ [7주차]

- **§119①**: 경제상의 **자유와 창의** 존중 = **자유시장경제** 기본
- **§119②**: 경제**민주화**를 위한 **규제·조정** 가능 (독과점 방지·소득분배·경제주체간 조화)
- §119만으로 **구체적 기본권 도출 불가** — 헌법적 **지침**
- **사회적 시장경제질서**: 자유시장경제 기본 + 사회복지·사회정의를 위한 규제·조정 **용인**

> 📌 **답안 문구**
> - **판례**([[92헌바47]]): "우리 헌법상 경제질서는 사유재산제를 바탕으로 **자유경쟁을 존중**하는 자유시장경제질서를 **기본**으로 하면서도 **사회복지·사회정의**를 실현하기 위하여 국가적 **규제와 조정**을 용인하는 **사회적 시장경제질서**"
> - **판례**(99헌바76등): "§119①이 언급하는 '경제적 자유와 창의'는 직업의 자유, 재산권 등 경제에 관한 **기본권** 및 비례원칙에 의하여 비로소 **구체화**된다" → §119 자체에서 기본권 도출 **불가**
> - **판례**(2016헌바77등): 대형마트 영업 제한 → §119②에 따른 규제·조정 가능 → **합헌**
> - **판례**([[99헌마365]]): 국민연금 강제가입 → **사회연대성** 기초 소득재분배 → **합헌**
> - **소비자보호**(§124): 소비자불매운동 정당성 요건 — ①진실한 사실 기초 ②의사결정 자유 보장 ③위법 수단 불사용 ④제3자 권리 부당침해 X

## 11. 책임주의 ★ [6주차 — 노트 미반영]

- **자기책임원칙**: 자신의 고의·과실에 의한 행위에 대해서만 법적 책임. 귀속 불가 시 책임 **X**
- **헌법적 근거**: **법치국가 원리** + **§10 인간의 존엄과 가치**
- **형사법상 [[책임주의]]**: "**책임 없는 자에게 형벌을 부과할 수 없다**" — 법인에도 적용
- **책임과 형벌 간 비례**: 형벌의 양은 행위자의 **책임의 정도를 초과**해서는 안 됨

> 📌 **답안 문구**
> - **판례**([[2012헌가18]]): "**책임 없는 자에게 형벌을 부과할 수 없다**는 형벌에 관한 책임주의는 형사법의 기본원리로서, 헌법상 **법치국가**의 원리에 내재하는 원리인 동시에 헌법 **§10**의 취지로부터 도출되는 원리이고, **법인**의 경우도 자연인과 마찬가지로 책임주의원칙이 적용된다"
> - **양벌규정**: 종업원의 위법행위에 대해 법인에 형사책임을 묻으려면 법인의 **의사결정 및 행위구조상의 책임** 필요 ([[2010헌가19]] 등 [선고일 교재 소스 미포함—확인 필요]: 곧바로 처벌 = **위헌**)
> - **판례**([[2003헌가12]]): 형벌의 양은 행위자의 **책임의 정도를 초과**해서는 안 되고, 다양한 행위 유형을 하나의 구성요건으로 포섭하면서 **하한을 무겁게** 하면 **[[책임주의]] 위반**
> - **판례**(2020헌마1724등): 대북전단 살포 처벌 — 결과(위해·위험) 발생이 전적으로 **북한의 적대적 조치**에 달려 있으므로 살포행위 자체에 **비난 불가** → **위헌**

## 12. 적법절차원칙 ★ [6주차 — 노트 미반영]

- **헌법적 근거**: §12①2문 후단 + §12③ "**적법한 절차**"
- **적용 범위**: 형사절차에 한정되지 않고 **모든 입법작용·행정작용**에 광범위 적용

### 절차적 적법절차 핵심요소

| 요소 | 내용 |
|---|---|
| ① **독립된 중립기관의 통제** | 신체 자유 제한 시 강제처분 집행기관으로부터 **독립된 중립기관** 통제 (2020헌가1등) |
| ② **적절한 고지** | 처분 내용·사유의 사전 통지 |
| ③ **의견제출 기회** | 당사자에게 방어 기회 부여 |

> 📌 **답안 문구**
> - **적용 범위**: "형사절차상의 제한된 범위 내에서만 적용되는 것이 **아니라** 국가작용으로서 기본권 제한과 관련되든 아니든 **모든 입법작용 및 행정작용**에도 광범위하게 적용"
> - **판례**([[2016헌마364]]): 적법절차원칙이 구체적으로 어떤 절차를 어느 정도로 요구하는지는 "규율되는 사항의 **성질**, 관련 당사자의 **사익**, 절차의 이행으로 제고될 **가치**, 국가작용의 **효율성** 등 다양한 요소들을 형량하여 **개별적으로 판단**"

## 13. 기타 (사회국가·국제평화·탄핵)

- **사회국가**: 입법자 **광범위한 형성 자유** / §119에서 기본권 직접 도출 **불가**
- **국제평화**: 조약 = 국내법 효력 (헌법 하위) / 국회동의 조약 = 법률적 효력
- **탄핵**: 일반(1/3 발의·과반 의결) / 대통령(**과반 발의·2/3** 의결) / 헌재 **6인** 이상 인용

---

## 부록. 숫자 회독 포인트

- **6인** = 헌재 모든 결정 (위헌·탄핵·해산·권한쟁의)
- **2/3** = 헌법개정·탄핵(대통령)·제명·재의결(출석 2/3)
- **3/5** = 신속처리안건·무제한토론 종결
- **1/3** = 의사정족수·탄핵발의(일반)·무제한토론 요구
- **1/4** = 석방요구·임시회 요구
- 법률안 재의결 = 재적과반 출석 + **출석 2/3** (재적 2/3 아님!)
- 국회의장 선출 = **재적과반** 무기명투표 (출석과반 아님)
- 대법원장 6년 **연임 불가** / 대법관 6년 **연임 가능**
- 감사원장 4년 **1차 중임** (연임이 아니라 중임)
