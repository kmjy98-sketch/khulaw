### §1-3. 2025 기출 핵심 포인트 (신규 출제 경향)

1. **[[권리남용]] + 배타적 사용수익권 포기**: 토지 소유자가 도로로 제공한 경우, 상속인에 대해서도 독점적/배타적 사용수익권 행사 제한 (대판(전합) 2019.1.24, [[2016다264556]]) 
2. **점유의 상호침탈**: 점유를 침탈당한 점유자가 상대방으로부터 점유를 탈환한 경우, 상대방의 점유회수청구권 부정 (대판 2023.8.18, [[2022다269675]])
3. **부당이득반환과 [[등기부취득시효]]**: 무권리자가 받은 매매대금의 부당이득반환 -- 인과관계 부정 (대판 2022.12.29, [[2019다272275]])

### 기출/사례 쟁점 묶음 흐름도

> 기출문제에서 쟁점이 묶여 나오는 패턴. 답안에서 쟁점 간 연결을 의식한다.

**[2025 기출 제1문] 물권적 청구권 + [[권리남용]](배타적 사용수익권 포기) + [[부당이득]] + 상속**
갑이 도로로 제공한 토지 → 갑 사망 → 상속인 을이 인도 청구
→ §213 반환청구: 을이 소유자로서 점유자에 대해 인도 청구
→ 항변 — 배타적 사용수익권 포기: 갑이 도로 제공 → 독점적 사용수익권 포기(판례(전합) [[2016다264556]])
→ 상속인 을의 지위: 포기의 효력이 상속인에게도 미치는가? → 미친다(판례)
→ [[부당이득]]: 포기로 인도 불가 → 사용이익 부당이득반환 청구 가능 여부 → 인과관계 부정(판례)

**[2025 기출 제2문] [[중간생략등기]] + 토지거래허가 + 진정명의회복등기 + 등기청구권 양도**
갑→을→병 순차매매, 병이 직접 갑에게 이전등기 청구
→ [[중간생략등기]]: 3자 합의 시 유효(판례) → 합의 존부 검토
→ 토지거래허가구역: 국토법 허가 필요 → 강행규정 위반 시 무효
→ 진정명의회복등기: §214 유추 — 무효등기 말소 대신 직접 이전등기 가능(판례)
→ 등기청구권 양도: 채권적 등기청구권 양도 가능? → 부정(판례) — 등기청구권은 매매계약에 부종하는 권리

**[2025 기출 제3문] 물권변동시점 + [[유인성]](착오취소) + 무권리자처분 + [[등기부취득시효]] + 상호침탈**
→ 3-1: 등기시점이 매매 후 며칠 뒤 → §186 물권변동은 등기 시 발생
→ 착오취소(§109) → [[유인성]] → 물권 당연복귀 → 말소등기 필요
→ 3-2: 무권리자 병이 매도 → 을이 대금 지급 → [[부당이득]] 인과관계 부정(판례 [[2019다272275]])
→ [[등기부취득시효]](§245②): 10년 + 등기 + 소유의 의사 + 선의·무과실
→ 3-3: 점유의 상호침탈(§204) → 갑 침탈 → 을 탈환 → 을의 점유회수청구 부정(판례 [[2022다269675]])

**[2022 기출 제1문] 물권적 청구권(반환) + [[부당이득]](사용이익) + 과실수취권(§201) + 필요비상환(§203)**
갑 소유 X건물을 을이 무단점유 → 갑이 반환+사용이익 청구
→ §213 반환청구: 갑 소유권 + 을 무단점유 → 반환 인정
→ [[부당이득]]: 을의 사용이익 반환(§741) → 악의 점유자는 수익 전부 반환
→ §201 과실수취권: 선의 점유자라면 과실 수취 적법 → [[부당이득]] 발생 안 함
→ §203 필요비상환: 을이 건물 수선 → 소유자에게 상환 청구 → 유치권(§320) 행사 가능

**[2021 기출 제2문] 이중의 [[점유개정]] + [[선의취득]](§249) + 도품유실물(§250)**
갑이 동산을 을에게 매도([[점유개정]]) → 갑이 다시 병에게 매도(점유개정)
→ 이중 [[점유개정]]: 을이 먼저 점유개정 → 병은 점유 취득 불가? → 판례: 점유개정에 의한 [[선의취득]] 부정
→ §249 [[선의취득]]: 병이 현실인도를 받았다면 → 요건 충족 시 선의취득 가능
→ 도품·유실물(§250): 갑이 절도범이라면 → 2년 내 원소유자 회복 청구
→ §251: 공개시장/경매/동종물 영업자 → 대가변상 청구

**[전경운 사례집] 취득시효 + 제3자 처분 + 자주점유 추정 번복**
갑이 을 소유 토지를 20년 점유 → 시효완성 후 을이 병에게 매도+등기이전
→ 시효완성: §245① 요건 충족 → 등기청구권 발생
→ 제3자 처분: 시효완성 후 등기 전 을→병 이전 → 갑은 병에게 대항 불가(판례)
→ 구제: 갑이 병 명의 등기 이후 다시 점유 계속 → 재기산 시효 주장 가능
→ 자주점유 추정 번복: 점유취득 경위상 타주점유로 볼 사정이 있으면 추정 번복(대판(전합) [[97다8236]])

## §4. 부동산 물권변동 ★★★ [빈도 #1: 물권변동 483]

> **위치**: 물권변동 > 부동산 물권변동 (등기·[[중간생략등기]])
> **같이 볼 사항**: [[중간생략등기]](§4-5) → 토지거래허가·등기청구권 양도성(§4-4) · 진정명의회복등기(§4-6) · [[물권행위]] [[유인성]](§3-3)

### §4-1. §186·§187 조문 원문 + 해설

#### §186 (법률행위에 의한 부동산물권변동)

> "부동산에 관한 법률행위로 인한 물권의 득실변경은 **등기하여야** 그 효력이 생긴다."

| 항목        | 내용                                         |
| --------- | ------------------------------------------ |
| **의의**    | 한국 물권법의 핵심 원칙 — **등기요건주의(형식주의)**           |
| **미등기 시** | 물권변동 자체가 미발생. 채권행위(매매계약)는 유효하지만 물권적 효력 불발생 |

#### §187 (등기를 요하지 아니하는 부동산물권취득)

> "**상속, 공용징수, 판결, 경매** 기타 법률의 규정에 의한 부동산에 관한 물권의 취득은 등기를 요하지 아니한다. 그러나 등기를 하지 아니하면 이를 **처분하지 못한다**."

| 항목            | 내용                                            |
| ------------- | --------------------------------------------- |
| **본문**        | 상속·공용징수·판결·경매·법률규정에 의한 취득 → **등기 없이** 물권취득 가능 |
| **단서**        | **처분**(물권적 처분행위 = 이전·설정·소멸)에는 **등기 필요**       |
| **채권행위**      | 등기 없이도 매매계약 체결 등 채권행위는 유효                     |
| **§186과의 관계** | §186은 '법률행위에 의한' 변동, §187은 '법률행위에 의하지 않는' 변동  |

### §4-2. 등기의 효력 체계 ★★★

| 효력             | 내용                                  | 조문           | 핵심                         |
| -------------- | ----------------------------------- | ------------ | -------------------------- |
| **① 성립요건적 효력** | 법률행위에 의한 물권변동은 등기해야 효력 발생           | §186         | 미등기 = 물권변동 미발생             |
| **② 대항력**      | 등기를 해야 제3자에게 물권변동을 주장 가능            | §187 단서      | 비법률행위 취득도 처분 시 등기 필요       |
| **③ 순위확정적 효력** | 같은 부동산에 수 개의 등기가 있으면 접수순서에 따라 순위 결정 | §370, 등기법 §4 | 가등기의 순위보전 효력도 여기서 파생       |
| **④ 형식적 확정력**  | 등기관이 등기를 수리하면 실질적 심사 없이 등기부에 기재     | 등기법 §29      | 등기관은 형식적 심사권만 → 실체와 불일치 가능 |
| **⑤ 공신력**      | **부정**                              | —            | 등기부 신뢰한 선의자라도 무조건 보호 안 됨   |

> **공신력 부정의 의미**: 우리 민법은 등기의 공신력을 인정하지 않는다. 따라서 무효 등기를 신뢰하여 거래한 제3자는 보호받지 못하고, 개별적 보호 규정(§109②, §110③ 등 제3자 보호규정)에 의해서만 보호될 수 있다.
- **위조 등기서류에 의한 등기**: 실체적 권리변동을 수반하지 않는 **원인무효의 등기** → 부동산 공신의 원칙 부적용(§249는 동산에 한정) → 선의 제3자도 소유권 취득 불가
  - cf. 동산의 경우: §249 [[선의취득]] 가능 / 부동산의 경우: 공신의 원칙 없음 → 원소유자 소유권 유지

### §4-3. 등기의 추정력 ★★

#### (1) 의의 — 추정력이란 무엇인가

등기가 있으면 **그에 대응하는 실체적 권리관계가 존재하는 것으로 추정**되는 효력이다.

**왜 추정하는가 (개연성설·통설)**: 등기절차상 등기공동신청주의(부등법 §23)와 각종 서면 제출 요구가 실체적 권리관계의 존재를 상당 부분 보장하기 때문이다
**실전적 의미**: 등기가 있으면 그 등기가 무효라고 주장하는 쪽(=말소를 구하는 원고)이 무효사유를 **본증(반대사실의 증거)으로 입증**해야 한다. 반증(의심을 품게 하는 정도)으로는 부족하다 (대판 1992.10.27. [[92다30047]]).

#### (2) 본질 — 법률상 추정(권리추정)

- **법률상 추정**(통설·판례): 등기가 있으면 실체적 권리관계가 있다는 전제사실이 추정됨 → **증명책임이 전환**됨
- 원칙적으로 **권리추정**(소유권 귀속 등)에 해당
- 다만 판례는 범위를 확장하여 **사실추정**(대리권 존재, 계약조항 내용 등)에도 추정력이 미친다고 봄

#### (3) 추정력의 범위 — 종합 도식

```
등기 존재
  ├─ 물적 범위 (무엇이 추정되는가)
  │    ├─ ① 권리귀속 추정 ─── 등기명의인 = 소유자
  │    ├─ ② 절차 적법 추정 ── 이전등기 절차가 적법
  │    ├─ ③ 등기원인 추정 ── 원인행위(매매 등) 존재
  │    ├─ ④ 대리권 존재 추정 ─ 제3자 개입 시에도 적법
  │    ├─ ⑤ 계약조항 추정 ── 등기부 기재 특약 진정 성립
  │    └─ ⑥ 피담보채권 추정 ─ 담보물권 → 채권 존재
  │         └─ 예외: 근저당권은 피담보채권 존재를 주장자가 입증
  │
  ├─ 인적 범위
  │    └─ 당사자 + 제3자 모두에게 미침
  │
  ├─ 추정 부정 (추정력 없음)
  │    ├─ 표제부 등기 (물리적 성상)
  │    ├─ 가등기 (순위보전 목적)
  │    └─ 사망자 명의 등기 (원칙 무효)
  │
  └─ 추정 번복/강화
       ├─ 번복: 본증 필요 (반증 부족)
       ├─ 강화: 확정판결 기한 등기 → 명백한 증거 필요
       └─ 우선: 등기추정 > 점유추정(§200)
```

#### (3-1) 물적 범위 — 추정 유형 비교표

| 추정 유형 | 내용 | 입증책임 전환 | 판례 |
|-----------|------|:---:|------|
| **① 권리귀속** | 등기명의인 = 소유자 | 부정 주장자가 무효 입증 | 81다카870, 95다36725 |
| **② 절차 적법** | 이전등기 절차가 적법 | 부당 주장자가 입증 | 2007다91756 |
| **③ 등기원인** | 원인행위(매매 등) 존재 | 무효 주장자가 무효사유 입증 | 92다46059, 95다39526 |
| **④ 대리권** | 제3자 개입 시에도 적법 | 전 소유자가 무권대리/위조 입증 | 97다416 |
| **⑤ 계약조항** | 등기부 기재 특약 진정 성립 | 반증 없는 한 유효 | 91다13700 |
| **⑥ 피담보채권** | 담보물권 → 채권 존재 | 채무자가 부존재 입증 | 68다2329 |
| ⑥ 예외: **근저당** | 피담보채권 **비추정** | **존재 주장자가 입증** | 2009다72070 |

#### (3-2) 인적 범위

**제3자 + 당사자 모두**에게 추정력이 미침 (대판 2013.1.10, [[2010다75044]])
→ 전소유자가 말소를 구하려면 무효원인 사실을 주장·증명 (대판 2014.3.13, [[2009다105215]])

#### (4) 추정력이 인정되지 않는 경우

| 대상 | 이유 | 판례 |
|------|------|------|
| **표제부 등기** | 부동산의 물리적 성상은 토지대장 등이 우선 | — |
| **가등기** | 본등기 순위보전 목적 → 가등기 원인 존재 추정력 없음 | 79다239 |
| **사망자 명의 등기** | 원칙 무효 — 유효 주장자가 실체관계 부합 입증 | 2018다200730 |

#### (5) 추정력 번복과 강화 — 비교표

| 구분 | 기준 | 입증 수준 | 판례 |
|------|------|----------|------|
| **일반 등기** | 본증(반대사실 증거) 필요, 반증 부족 | 무효사유(위조/통정허위/착오) 주장·입증 | 92다30047 |
| **확정판결 기한 등기** | 일반 등기보다 **강화** | 일반적 경우를 넘는 **명백한 증거** | 2002다26252, 2023다223591 |
| **등기추정 vs 점유추정** | 등기추정이 **우선** | 등기 부동산에 §200 적용 안 됨 | 81다780 |
| **등기내용 악의 추정** | 취득자는 등기부 조사가 상례 | 악의 추정, 등기부 소유자로부터 매수 시 무과실 | — |

#### (6) 사례형 접근 — 청구권기초 포섭형

**1. 청구권기초**: 갑(진정 소유자)의 을(등기명의인)에 대한 §214 방해배제(등기말소) 청구

**2. 요건**: ① 갑이 소유자(?) ② 을의 등기가 방해에 해당(?) ③ 말소등기 청구 적격(O)

**3. 쟁점 — 등기의 추정력과 입증책임**

- **원칙**: 을 명의 등기가 있으므로 을이 적법한 소유자로 **추정** → 갑이 무효사유를 **본증으로 입증**해야
- **판례** ([[92다30047]]): "등기가 원인 없이 마쳐진 것이라고 주장하는 쪽에서 무효사유를 주장·입증"
- 을이 **확정판결 기한 등기**를 보유한 경우 → 추정력 강화 → 갑의 입증 수준 가중 ([[2002다26252]])

**4. 포섭**: 갑이 을의 등기가 위조/통정허위/[[무권대리]] 등에 의한 원인무효임을 본증으로 입증 → 추정력 번복 → 을의 등기는 실체관계에 부합하지 않는 무효 등기

**5. 결론**: 갑의 입증 성공 시 말소 청구 **인용**, 실패 시 **기각**

### §4-4. 등기청구권 + 소멸시효 ★★★

#### (1) 등기청구권의 의의

등기청구권이란 등기권리자가 등기의무자에 대하여 등기에 협력할 것을 청구할 수 있는 **실체법상의 권리**이다.

**조문 원문**

> **§563 (매매의 의의)**: "매매는 당사자 일방이 재산권을 상대방에게 이전할 것을 약정하고 상대방이 그 대금을 지급할 것을 약정함으로써 그 효력이 생긴다."
> **§568① (매매의 효력)**: "매도인은 매수인에 대하여 매매의 목적이 된 권리를 이전하여야 하며 매수인은 매도인에게 그 대금을 지급하여야 한다."

#### (2) 등기청구권의 종류

| 유형 | 근거 | 소멸시효 | 특징 |
|---|---|---|---|
| **채권적 등기청구권** | 매매계약 등 채권관계 (§563, §568①) | **적용** (10년, §162①) | 판례(대판(전합) 1976.11.6, **76다148**; 대판(전합) 1999.3.18, **98다32175**): 법률행위에 의한 등기청구권은 채권적 청구권 |
| **물권적 등기청구권** | 물권 자체 (진정명의회복 등) | **미적용** | 물권이 존속하는 한 소멸 X |
| **법률규정에 의한 등기청구권** | §187 등 | -- | 상속·수용 등에 의한 취득 후 등기 |

#### (3) 법적 성질 — 학설 대립 + 판례

**학설**:

| 학설                    | 등기청구권의 성질                        | 근거                                     | 유인성과 관계         |
| --------------------- | -------------------------------- | -------------------------------------- | --------------- |
| **채권적 청구권설 (판례/다수설)** | 매매계약(채권행위)에서 직접 발생하는 **채권적 청구권** | **물권행위 독자성 부정** → 채권행위가 직접 등기청구권 발생 근거 | **유인설과 논리적 연결** |
| **물권적 청구권설**          | 물권변동 합의(물권행위)에서 발생하는 **물권적 청구권** | 물권행위의 **독자성 인정** 전제 → 물권적 합의의 이행청구     | 독자성 인정설과 연결     |
| **법규정 청구권설**          | 법률의 규정에 의해 직접 발생                 | 등기를 갖추지 못한 자에게 법이 등기청구를 인정             | 독자성과 무관         |

**[판례]** 법률행위에 의한 등기청구권은 채권행위로부터 발생하는 **채권적 청구권**이다. 물권행위의 독자성을 부인하므로, 매매계약(채권행위)에서 등기청구권이 직접 발생한다 (대판(전합) 1976.11.6, **[[76다148]]**; 대판(전합) 1999.3.18, **[[98다32175]]**).

- **검토**: 채권적 청구권설(판례·다수설) 타당 — 유인설 하에서 물권적 합의를 별도로 관념할 수 없으므로, 채권행위에서 직접 등기청구권이 발생한다고 봄이 논리적으로 일관

> **모답형**: "등기청구권의 법적 성질에 관하여 채권적 청구권설, 물권적 청구권설, 법규정 청구권설의 대립이 있으나, 판례는 물권행위의 독자성을 부인하는 입장에서 법률행위에 의한 등기청구권은 **채권행위로부터 발생하는 채권적 청구권**이라 한다."

**채권적 청구권설이 타당한 이유**:

| 논거                | 내용                                                                                       |
| ----------------- | ---------------------------------------------------------------------------------------- |
| **유인설과의 논리적 일관성** | 판례가 물권행위의 **독자성을 부정(유인설**)하는 이상, 물권적 합의에서 등기청구권이 발생한다고 보는 **물권적 청구권설은 전제가 성립하지 않음**      |
| **법률구성 간명**       | 매매계약(채권행위)에서 직접 등기청구권이 발생 → 물권행위를 별도로 관념할 필요 없이 **하나의 계약에서 모든 권리의무 도출**                  |
| **실무적 처리 일관**     | 채권적 청구권이므로 ① 10년 소멸시효(§162①) 적용, ② 양도 시 채권양도 법리 적용(다만 성질에 의한 제한), ③ 대위행사 가능 → 체계적 일관성 확보 |

**등기청구권 양도 제한이 타당한 이유**:

| 논거 | 내용 |
|------|------|
| **이행의 신뢰관계** | 등기이전에는 매도인의 적극적 협력(인감증명·등기서류 교부)이 필요 → 특별한 신뢰관계 수반하는 권리의 성질에 의한 양도 제한(§449① 단서) |
| **매도인 이익 보호** | 매도인이 알지 못하는 제3자에게 등기의무를 이행하게 되면 매도인의 동시이행항변·상계항변 등이 사실상 무력화될 수 있음 |
| **통지만으로 불충분** | 통상의 채권양도(§450: 통지 또는 승낙)와 달리, 통지만으로는 대항력이 발생하지 않고 반드시 매도인(채무자)의 동의·승낙이 필요 |

#### (4) 소멸시효

① 원칙: 채권적 청구권 → 10년 소멸시효 (§162①)
→ ② 예외: 매수인이 목적물 인도받아 사용·수익 중 → 시효 불진행
→ ③ 재예외: 점유 상실 → 그 시점부터 다시 시효 진행

**[판례]** "매수인이 매도인으로부터 인도받아 사용, 수익하고 있는 경우" 소멸시효에 걸리지 않는다. 나아가 매수인이 부동산을 인도받아 사용·수익하다 적극적인 권리행사의 일환으로 다른 사람에게 처분하고 점유를 승계한 경우도 마찬가지이다.

> **기출 모답 논증 경로** (2011, 2013, 2014, 2017, 2023 반복 출제):
> ① 매매계약에 기한 소유권이전등기청구권은 §568① 재산권이전청구권으로서 채권적 성질
> ② 원칙: §162① 10년 소멸시효
> ③ 예외: 사용·수익 중이면 시효 불진행
> ④ 재예외: 점유 상실 시 다시 시효 진행
> ⑤ 사안 포섭

#### (5) 양도성 — 판례: 부정(소극)

**[판례]** 매매로 인한 소유권이전등기청구권은 그 **권리의 성질상 양도가 제한**되고, 그 양도에 채무자의 승낙이나 동의를 요한다. **통상의 채권양도와 달리** 양도인의 채무자에 대한 통지만으로는 대항력이 생기지 않으며, 반드시 **채무자의 동의나 승낙을 받아야 대항력**이 생긴다 (대판 2001.10.9, [[2000다51216]]).

| 항목 | 내용 |
|---|---|
| **양도 제한 근거** | 이행과정에 특별한 신뢰관계가 따르는 권리 — 채권의 성질에 의한 제한 (§449① 단서) |
| **동의/승낙의 법적 성격** | **대항요건** (성립요건 아님) — 통상 채권양도의 대항요건(§450: 통지 또는 승낙)과 달리 통지만으로 부족, 동의/승낙 필요 |
| **동의 없는 경우** | 양도 자체가 무효는 아니나, 채무자(매도인)에 대한 **대항력 불발생** → 양수인이 직접 이전등기 청구 불가 |

#### (6) 등기청구권을 통한 중간생략등기 우회 실현 문제

등기청구권의 양도성이 부정되므로, 3자 합의 없이 단순히 등기청구권을 양도하는 방식으로 중간생략등기를 우회 실현하는 것은 **불가능**하다.

| 중간생략등기 실현방법 | 구조 | 요건 |
|---|---|---|
| **① 적극적 이행청구권** | 갑→을→병에서 병이 갑에게 직접 이전등기 청구 | **3자 합의** |
| **② 채권자대위권** | 병이 을의 갑에 대한 등기청구권을 대위행사 → 을 명의 등기 → 병에게 이전 | 피보전채권 + 채무자 권리불행사 |
| **③ 계약인수** | 을이 갑과의 매매계약상 지위를 병에게 이전 → 병이 갑에게 직접 이전등기 | 3자 합의 |
| **④ 등기청구권 양도** | 을이 병에게 등기청구권 양도 → 병이 갑에게 직접 청구 | 갑(채무자)의 **동의/승낙 필요**(대항요건) — 동의 없으면 대항력 없어 청구 불가 |

**[판례]** 3자간의 합의가 없으면 소유권이전등기청구권을 최종양수인이 중간자로부터 양도받았다고 하더라도 최초 양도인이 그에 대해 동의하지 않는다면 소유권이전등기절차의 이행을 청구할 수 없다.
#### (6-1) 등기말소청구권(§214) — 요건사실 정리

소유권에 기한 방해배제청구권(§214)으로서의 **등기말소청구권** 요건사실:

| 구분 | 요건사실 | 입증책임 |
|---|---|---|
| **청구원인** | ① 원고가 해당 부동산의 **소유자**일 것 | 원고 |
| | ② 피고 명의의 **등기가 현존**할 것 | 원고 |
| | ③ 피고의 등기가 **원인무효**일 것 (위조·통정허위·등기원인 부존재 등) | 원고 |
| **항변** | ④ 등기의 **추정력** — 등기명의인은 적법한 권원 추정 | 피고 |
| | ⑤ **취득시효** 완성 (§245) | 피고 |
| | ⑥ 유효한 원인행위 존재 | 피고 |
| **재항변** | ⑦ 원인행위 무효·취소 사유 | 원고 |

**[모답형]**
> 갑은 X토지의 소유자로서(①), 현재 을 명의의 등기가 존재하며(②), 을의 등기는 원인무효이므로(③) §214에 기한 방해배제청구권으로 등기말소를 청구할 수 있다. 다만 을이 등기의 추정력(§200)을 항변으로 내세우면, 원고가 원인무효 사유를 입증해야 한다.

#### (7) 진정명의회복등기

**인정 근거 (요건 아님)**

- **직접 이전등기 허용** — [대판(전합) 1990. 11. 27, **[[89다카12398]]**]: "이미 **자기 앞으로 소유권을 표상하는 등기**가 되어 있었거나 법**률에 의하여 소유권을 취득**한 자가 진정한 등기명의를 회복하기 위한 방법으로는 **현재의 등기명의인을 상대**로 그 등기의 말소를 구하는 외에 '진정한 등기명의의 회복'을 원인으로 한 **소유권이전등기절차의 이행을 직접 구하는 것도 허용**되어야 한다"
- **동일 목적·동일 법적 성질** — [대판 2003. 3. 28, **[[2000다24856]]**]: "말소등기에 갈음하여 허용되는 진정명의회복을 원인으로 한 소유권이전등기청구권과 무효등기의 말소청구권은 어느 것이나 진정한 소유자의 등기명의를 회복하기 위한 것으로서, **실질적으로 그 목적이 동일**하고 두 청구권 모두 소유권에 기한 방해제거청구권으로서 그 **법적근거와 성질이 동일**하기 때문이다"
- **절차 간소화 (학자 설명)**: 말소등기 후 재등기하는 2단계 없이 직접 이전등기로 소유명의 회복 가능 — 판례가 '경제성'이라는 표현을 직접 사용한 것은 아님

| 항목 | 내용 |
|---|---|
| **의의** | 말소등기에 갈음하여 진정한 소유자 명의로 이전등기 |
| **법적 성질** | **물권적 청구권** — 소유권에 기한 방해배제청구권과 동일 |
| **요건** | ① 청구권자가 진정한 소유자일 것 (자기 앞 소유권 등기가 되어 있었거나 법률에 의해 소유권 취득), ② 상대방이 현재 등기명의인일 것, ③ 상대방 등기 원인 무효일 것 |
| **기판력** | 등기말소 청구 패소 → 소유권이전등기 청구 **불가** (실질적 목적·법적 성질 동일 → 동일 소송물) |

**[판례]** [대판 2001. 9. 20, **[[99다37894]]**] "말소등기에 갈음하여 허용되는 **[[진정명의회복]]**을 원인으로 한 소유권이전등기청구권과 **무효등기의 말소청구권**은 어느 것이나 진정한 소유자의 등기명의를 회복하기 위한 것으로서 **실질적으로 그 목적이 동일**하고, 두 청구권 모두 소유권에 기한 방해배제청구권으로서 그 법적 근거와 성질이 동일하므로, 비록 전자는 이전등기, 후자는 말소등기의 형식을 취하고 있다고 하더라도 그 **소송물은 실질상 동일**한 것으로 보아야 하고, 따라서 소유권이전등기말소청구소송에서 패소확정판결을 받았다면 그 **기판력은 그 후 제기된 진정명의회복을 원인으로 한 소유권이전등기청구소송**에도 미친다."

> **주의**: 중간 전전 양수인(3자 합의에 의한 [[중간생략등기]] 매수인)이 진정명의회복등기를 청구하는 것은 불가하다. 이전에 **소유권을 표상하는 등기**가 되어 있었거나, **법률에 의한 소유권**을 취득한 적이 없기 때문이다.

**I. 제1소송 — 갑 v. 을: 진정명의회복을 원인으로 한 소유권이전등기청구**

갑(원고, 진정 소유자): 진정명의회복등기청구 — "갑은 X 토지의 진정한 소유자이고(①), 을이 현재 등기명의인이며(②), 을의 등기는 원인무효이므로(③) 진정명의회복을 원인으로 소유권이전등기를 구한다"
→ 을(피고): [[선의취득]] 항변 — "을은 등기부상 소유자인 정을 신뢰하고 1억 원에 정상 매수하였으므로 선의취득 법리로 보호받아야 한다"
→ 갑: 재항변 — "§249의 선의취득은 동산에만 적용되고 부동산에는 적용 없다. 무권리자 정으로부터는 소유권을 취득할 수 없으므로 을의 등기는 원인무효이다"

> **[결론]** 정의 등기는 위조서류에 의한 원인무효이다. 부동산에는 §249 선의취득이 적용되지 않으므로 선의의 을도 무권리자 정으로부터 소유권을 취득할 수 없다. 진정명의회복등기청구 요건 ①②③ 모두 충족 → **인용**.
>
> 근거 발췌: "진정명의회복을 원인으로 한 소유권이전등기청구권과 무효등기 말소청구권은 소유권에 기한 방해배제청구권이라는 동일한 법적 성질을 갖는다"

**II. 제1소송 — 갑 v. 을: X 토지 인도청구**

갑(원고, 소유자): §213 소유물반환청구 — "X 토지를 점유하는 을에게 인도를 구한다"
→ 을(피고): 점유 부존재 항변 — "2024. 4. 1. 병이 Y 건물(X 토지 전부를 부지로 함)을 경락받아 점유한 이후 을은 X 토지를 점유하지 않는다. 현재 점유자는 병이다"

> **[결론]** §213 소유물반환청구권은 현재의 점유자를 상대방으로 하여야 한다. 2024. 4. 1. 병이 Y 건물을 경락받아 X 토지 전부를 점유한 이후 을은 X 토지 점유를 상실하였다. 을을 상대로 한 인도청구는 §213 요건(점유자를 상대로 청구) 불충족 → **기각**.
>
> 근거 발췌: "소유자는 그 소유에 속한 물건을 **점유한 자**에 대하여 반환을 청구할 수 있다"

**III. 제2소송 — 을 v. 갑: 유익비상환청구(§203②)**

**(1) 을의 점유자 지위 — 선의/악의**

을(원고): 선의점유 주장 — "을은 등기부상 소유자 정을 신뢰하고 1억 원에 정상 매수하였으므로 §197①에 의해 선의점유자로 추정된다"
→ 갑(피고): 악의점유 항변 — "을이 악의점유자라면 관련 청구에 영향이 있다"
→ 을: 선의 추정 재항변 — "§197①에 의해 점유자는 선의 추정; 을의 악의를 입증하는 구체적 사정이 없다"

> 을은 **선의점유자**이다(§197① 추정).

**(2) 유익비상환청구 — §203②**

을(원고): §203② 유익비상환청구 — "을은 X 토지 상업용지 개발에 3,000만 원을 지출하여 가액을 증가시켰고 그 증가가 현존하므로(당사자 다툼 없음), 유익비 3,000만원 상환을 구한다"
→ 갑(피고): 기간허여 신청 — "법원에 §203② 후문에 의한 상당한 상환기간 허여를 신청한다"

> **[결론]** §203② 유익비상환청구권은 선의·악의 점유자를 **불문**하고 가액증가 현존 시 인정된다. 당사자 간에 개발비용 = 가액 상승분 = 3,000만원임에 다툼이 없다. 갑은 지출액(3,000만원) 또는 증가액(3,000만원) 중 선택하여 상환(동액이므로 결과적으로 3,000만원) → **3,000만원 인용**. 법원은 갑의 신청에 의하여 상당한 기간을 허여할 수 있다(§203② 단서).
>
> 근거 발췌: "그 가액의 증가가 현존한 때에 한하여 회복자의 선택에 좇아 그 지출금액이나 증가액의 상환을 청구할 수 있다"

**(3) 유치권(§320) 행사 가능성**

을(원고): 유치권(§320) 행사 주장 — "§203②의 유익비상환청구권은 X 토지에 관하여 생긴 채권(§320① 요건 ①)이므로, 유치권을 행사하여 X 토지의 인도를 거부한다"
→ 갑(피고): 점유 상실 항변 — "을은 2024. 4. 1. 병의 Y 건물 경락 이후 X 토지를 점유하지 않는다. §320① 점유 요건 불충족; §328에 의해 점유 상실 시 유치권 소멸"

> **[결론]** 유치권 성립에는 ① 목적물에 관하여 생긴 채권, ② 변제기 도래, **③ 목적물 점유** 필요(§320①). 2024. 4. 1. 병의 경락 이후 X 토지 전부(Y 건물의 부지)가 병의 점유 아래 놓였고 을은 점유를 상실하였다. 점유 상실로 유치권 소멸(§328) → **유치권 행사 불인정**.
>
> 근거 발췌: "타인의 물건이나 유가증권을 점유한 자는 그 물건에 관하여 생긴 채권이 변제기에 있는 경우에는 … 유치할 권리가 있다" / "점유를 잃은 경우에는 유치권이 소멸한다"

### §4-5. 중간생략등기 ★★★

#### (1) 의의

등기가 최초 양도인으로부터 중간취득자를 거쳐 최종양수인에게 순차로 이전되어야 할 때, 중간취득자의 등기를 생략하고 **최초 양도인으로부터 직접 최종양수인**에게 하는 등기이다.

#### (2) 경료된 중간생략등기의 효력 — 학설 대립

| 학설 | 핵심 논거 | 효과 | 이행청구권 |
|---|---|---|---|
| **무효설 (상대적 무효)** | 성립요건주의하에서 중간자는 등기 없으므로 무권리자 → 최종양수인은 무권리자로부터 이전받은 것 → 물권변동 과정도 현재 상태도 공시 못함 → **무효**. 다만 중간생략등기를 기초로 제3자에게 이전등기가 된 경우 거래안전상 유효로 취급 (상대적 무효) | 원칙 무효 | X |
| **무조건유효설 (물권적 기대권설)** | 갑→을 간 물권적 합의 + 등기서류 교부 → 을이 **물권적 기대권** 취득 → 을이 병에게 양도하는 것은 물권적 기대권의 양도 → 병은 물권적 청구권으로 갑에게 직접 청구하여 중간생략등기 가능. **3자 합의 불요** | 무조건 유효 | O (갑에게 직접) |
| **합의조건부유효설 (판례·다수설)** | 3자(최초양도인·중간자·최종양수인)의 합의가 있으면 유효. 합의 방식: **명시적·묵시적·순차적** 모두 가능. 합의 없이 이미 경료된 경우에도 실체관계에 부합하면 유효 | 합의 시 유효 | O (합의 있을 때) |


**판례** (대판(전합) 1999.3.18, [[98다32175]]; 대판 2005.9.29, [[2003다40651]]):
> "3자의 명시적 혹은 묵시적 합의가 있거나, 합의가 없더라도 이미 적법한 중간생략등기가 경료되어 실체관계에 부합하면 유효"

- **합의의 방법**: 명시적·묵시적·순차적 모두 가능 (대판 1982.7.13, [[81다254]])
- **백지매도증서 교부**: 묵시적·순차적 합의 인정 가능 ([[81다254]]). 단, 백지매도증서+위임장+인감증명서 교부만으로는 합의 인정 불가 ([[91다5761]])
- **합의 없이 경료된 경우**: 적법한 중간생략등기가 이미 성립되어 있으면 유효 ([[79다847]]; [[2003다40651]])
#### (3) 적극적 이행청구권

**[판례]** 3자간 합의가 있는 경우, 최종 양수인이 최초 양도인에게 직접 자신에 대한 이전등기 협력을 청구할 수 있다 (**적극적 중간생략등기이행청구권 인정**).

#### (4) 단속규정 vs 효력규정

##### 부특법 §2 — **단속규정** (판례)

**[판례]** 부동산등기특별조치법의 입법 목적은 등기의 신속·정확한 이행을 촉진하기 위한 행정목적 규정이므로, 위반 시 형사제재를 받는 것은 별론으로 하고 **거래안전 보호를 위해 사법상 효력은 인정**된다 (**[[92다39112]]**).

##### 국토계획법 (토지거래허가구역) — **효력규정** (판례)

**[판례]** 토지거래허가구역 내에서는 각 매매계약 당사자가 **각각의 매매계약에 관해 토지거래허가**를 받아야 하며, 허가 없이 경료된 등기는 적법한 허가 없이 경료된 등기로서 처음부터 **확정적 무효**이다 (**[[96다22464]]**).

##### 비교표

| 구분 | 부등특법 §2 위반 | 국토계획법 (토지거래허가구역) 위반 |
|---|---|---|
| **법규 성격** | **단속규정** | **효력규정** |
| **이유** | 등기의 신속·정확한 이행 촉진이라는 행정목적 → 사법관계까지 뒤집지 않음 | 투기 방지·국토 이용의 공적 통제라는 강행적 공익 목적 → 허가 없는 거래는 **사법상으로도** 효력 불발생 |
| **중간생략등기 효과** | 사법상 **유효** (형사 처벌만) | A-C 간 직접 매매 부존재 → 등기 **확정적 무효** |
| **암기** | 단속 = 처벌O, 효력O | 효력 = 처벌O, 효력X |

#### (5) 3자간 합의 구조 — 공방 흐름

> **사안**: 갑→을→병 순차 매도. 병이 갑에게 직접 이전등기 청구.

##### [경우 1] 3자 합의 있는 경우

**1. 청구권기초**: 병(최종양수인)의 갑(최초양도인)에 대한 적극적 중간생략등기이행청구권
**2. 요건**: ① 갑→을, 을→병 순차 매매 성립(O) ② 3자(갑·을·병)의 합의(?) ③ 병의 대금 지급(O)
**3. 쟁점 — 3자 합의 존부**
- **학설**: [무효설(상대적 무효)] vs [무조건유효설] vs **[합의조건부유효설(판례·다수설)]**
- **판례** (대판(전합) 1999.3.18, [[98다32175]]): "3자의 명시적 혹은 묵시적 합의가 있거나, 합의가 없더라도 이미 적법한 중간생략등기가 경료되어 실체관계에 부합하면 유효"
- **검토**: 합의조건부유효설 타당 — 성립요건주의 하에서 3자 합의로 중간생략등기의 실체관계 부합 담보
**4. 포섭**: 갑·을·병 간 명시적/묵시적/순차적 합의 인정 → 병의 적극적 중간생략등기이행청구권 성립
**5. 결론**: **인용** (합의 인정 시 병 승소)

##### [경우 2] 3자 합의 없는 경우 — 우회 방법

**1. 청구권기초(우회 1)**: 병이 을의 갑에 대한 §568① 등기청구권을 §404 채권자대위로 행사
- **포섭**: 을 명의 등기 경유 → 이후 을→병 이전등기
**1. 청구권기초(우회 2)**: 을이 병에게 등기청구권 양도 → 병이 갑에게 직접 청구
- **쟁점**: 갑(채무자)의 동의/승낙 필요(대항요건) → 동의 없으면 대항력 없어 청구 불가
- **학설**: 채권양도 일반론에 따라 통지/승낙으로 대항(§450) vs 등기청구권은 성질상 양도 제한
- **판례**: 등기청구권 양도 시 채무자(갑)의 동의/승낙이 없으면 대항력 없어 직접 청구 불가
- **검토**: 타당 — 채권적 청구권이므로 양도 자체는 가능하나, 대항요건(§450) 불비 시 채무자에게 주장 불가

##### [경우 3] 갑의 대금 미수령 시

**3. 쟁점 — 갑의 동시이행항변권(§536)**
- **포섭**: 갑이 을로부터 대금 미수령 → 동시이행항변권으로 병의 직접 청구 거절 가능. 병이 채권자대위로 우회하더라도 갑의 항변은 을에 대한 것이므로 병에게도 대항 가능.

##### 부등특법·국토계획법 위반 시
- **부등특법 §2 위반 시**: 단속규정 → 사법상 유효, 형사처벌만 별론 ([[92다39112]])
- **토지거래허가구역 내**: 효력규정 → 확정적 무효, 각 매매계약별 허가 필요 ([[96다22464]])

### §4-8. 가등기·이중등기 ★★

#### (1) 가등기

##### 본등기 전 효력 — 판례: 소극설

| 항목              | 내용                                      |
| --------------- | --------------------------------------- |
| **소극설 (판례/통설)** | 가등기 자체로는 실체법상 효력 없음. **순위보전 + 경고적 효력**만 |
| **적극설 (소수)**    | 가등기 부동산에 대한 처분은 **청구권 침해 한도에서 상대적 무효**  |

**[판례]** 소극설의 입장을 따르므로, 가등기에는 **순위보전의 효력만** 존재하고 그 자체로 실체법상 효력을 가지지는 않는다.

**[판례·소극설]** "가등기만으로는 아무런 **실체법상 효력을 갖지 아니하고** 그 본등기를 명하는 판결이 확정된 경우라도 **본등기를 경료하기까지**는 마찬가지이므로, 소유권보존등기가 무효더라도 가등기권리자는 그 말소를 청구할 권리가 없다" (대판 2001.3.23. [[2000다51285]])
##### 본등기 후 효력 — 순위보전

**본등기의 순위는 가등기의 순위에 의한다** (부동산등기법 §91).

| 순서 | 등기 내용 | 순위 |
|:---:|---|---|
| ① 3/1 | 갑 **가등기** | 1순위 |
| ② 3/15 | 을 **본등기** | 2순위 |
| ③ 4/1 | 갑 가등기 → **본등기** 전환 | 갑 본등기 순위 = 3/1 (가등기 순위로 소급) → 을은 순위에서 밀림 |

- 본등기 시 **중간처분**(가등기 이후 본등기 전에 이루어진 처분)은 후순위로 되어 **실효**한다. 등기관은 가등기에 기하여 보전되는 권리 침해 등기를 **직권말소**해야 한다 (부동산등기법 §92①).
- 다만 물권변동의 효력은 **본등기 때** 발생하며, 가등기한 때로 소급하는 것은 아니다.

##### 가등기에 기한 본등기 방법

| 절차        | 내용                                                    |
| --------- | ----------------------------------------------------- |
| **원칙**    | 가등기권리자와 가등기의무자의 **공동신청** (부동산등기법 §23①)                |
| **예외**    | 가등기의무자의 승낙 또는 법원의 가처분 명령 있으면 **단독신청** 가능 (부동산등기법 §89) |
| **비협력 시** | 전 소유자가 본등기절차에 협력하지 않으면 → 협력에 대해 소 제기 → 승소 확정판결로 단독 신청 |

##### 가등기 추가 판례

**[판례]** 가등기는 청구권이 존재한다는 **추정력을 가지지 않는다**.

**[판례]** 가등기상의 권리를 양도한 경우에는, 양도인과 양수인의 공동신청으로 그 가등기상의 권리의 이전등기를 가등기에 대한 **부기등기** 형식으로 경료할 수 있다 (**[[98다24105]]**).

#### (2) 이중등기 — 판례: 절충설

| 유형 | 판례 태도 |
|---|---|
| **동일인 명의** | 실체관계 불문, **선순위 유효 / 후순위 무효** |
| **등기명의인 상이** | **절충설** — 원칙 절차법설(선등기 유효), 예외 1등기가 **원인무효**면 2등기 유효 |

**[판례]** "등기명의인을 달리하는 이중의 소유권보존등기가 존재하는 경우, 먼저 이루어진 소유권보존등기가 **원인무효가 되지 않는 한**, 뒤에 이루어진 소유권보존등기는 그 부동산의 매수인에 의하여 행해진 경우라도 **무효**이다" (**대판(전합) [[87다카2961]]·[[87다453]]**).

| 학설 | 내용 | 판단 기준 |
|---|---|---|
| 절차법설 | 선등기 유효, 후등기 무효 (실체관계 불문) | 1부동산 1등기기록주의(부동산등기법 §15) |
| 실체법설 | 진정한 소유자의 보존등기가 유효 | 실체관계 기준 |
| **절충설 (판례)** | 원칙 절차법설, **예외** 1등기 원인무효 시 2등기 유효 | 절차 + 실체 |

> **후행등기의 취득시효 주장**: 후행등기 명의인이 20년 점유로 점유취득시효를 완성했더라도, 후행 보존등기나 그에 기한 이전등기가 유효로 전환되지는 않는다. 다만 별도로 [[점유취득시효]] 완성을 원인으로 선행등기명의인에게 이전등기를 청구하는 방식은 가능하다.[

## §3. 물권변동 총론 [빈도 #1 보조: 물권변동 483]

### §3-1. 물권변동의 개념

### §3-3. 물권행위의 독자성과 무인성 ★★★

#### (1) 개념 정의

- **독자성**: 물권행위가 채권행위와 구별되는 **독립된 법률행위인지의**문제
- **[[무인성]]**: 물권행위의 효력이 그 원인인 **채권행위의 존부·효력에 영향을 받는지**의 문제

#### (2) 학설 비교표

|                  | 채권행위 무효·취소 시          | 제3자 보호     | 지위     |
| ---------------- | --------------------- | ---------- | ------ |
| **독자성+무인성 인정설**  | 물권행위 유효 → 부당이득반환만     | 주의적 규정     | 소수설    |
| **독자성만 인정설**     | 물권행위도 무효 → 소유권 복귀     | 필요적 규정     | 소수설    |
| **유인설 (판례/다수설)** | **물권행위도 무효 → 소유권 복귀** | **필요적 규정** | **판례** |

#### (3) 판례 태도 — 유인설 (독자성·무인성 모두 부정)

**[판례]** "우리 민법은 물권행위의 **독자성과 무인성을 인정하지 아니하므로**, 매매계약이 무효이거나 취소된 때에는 그에 터잡은 소유권이전등기도 원인무효의 등기가 되어 말소되어야 한다" (**대판 [[77다1872]]** 등 다수.)

#### (4) 유인설의 실전적 귀결

채권행위(매매계약) **무효·취소·해제** → **물권행위도 효력 상실**(유인설) → 소유권 매도인에게 당연 복귀 (§187 적용, 등기 없이) → 원소유자는 **말소등기청구/진정명의회복등기청구**로 회복 가능

#### (5) 이중매매에서 결론 차이

**사안**: 갑→을 매매 후 갑→병에게 이중매매, 병 등기 완료

**무인설에 의하면**:
→ 을의 [[물권행위]] 유효 → 병은 무권리자로부터 취득 → 등기 공신력 문제
→ 제1매수인 을의 구제: 을→갑 매매대금 **부당이득반환** 청구(§741)

**유인설(판례)에 의하면**:
→ 을의 등기청구권은 채권적 청구권 → 병이 먼저 등기하면 **병이 소유자**
→ 제1매수인 을의 구제: 을→갑 이행불능에 기한 **채무불이행 손해배상** 청구 

#### (6) §109② 제3자 범위

**[판례]** 취소 전 선의로 이해관계를 맺은 제3자뿐 아니라, **등기 말소 전** 선의로 이해관계를 맺은 제3자도 §109②의 보호 대상에 포함한다.

#### (7) 모답형 (조문-판례-포섭)

> **[조문]** §186에 의하면 부동산물권변동은 등기하여야 효력이 생긴다. 물권행위의 유인성이란 물권행위의 효력이 원인인 채권행위의 부존재·무효·취소·해제 등에 의해 영향을 받는다는 것이고, 무인성은 원인에 영향받지 않는다는 것이다.
>
> **[판례]** 판례([[75다1394]])는 "우리 법제가 물권행위의 독자성과 무인성을 인정하고 있지 않다는 점과 민법 제548조 제1항 단서가 거래의 안전을 위한 특별규정이라는 점을 생각할 때 계약이 해제되면 그 계약의 이행으로 변동이 생겼던 물권은 당연히 그 계약이 없었던 상태로 복귀한다"고 판시하였다. 다수설·판례에 의하면 원인행위 실효 시 등기 없이 물권이 당연 복귀한다.
>
> **[포섭·결론]** 따라서 채권행위가 무효·취소·해제된 경우 원소유자는 말소등기청구 또는 진정명의회복등기청구로 소유권을 회복하며, 부당이득반환만 청구할 수 있는 것이 아니다.
>
> **[반대설 비교]** 독자성+[[무인성]] 인정설에 의하면 채권행위가 무효·취소되어도 물권행위는 유효하므로 물권변동은 유지되고, **원소유자는 부당이득반환만** 청구할 수 있다. 그러나 이 견해에 의하면 원물반환이 불가하여 원소유자 보호가 미흡하고, §548① 단서(제3자 보호)가 주의적 규정이 되어 불필요해지는 문제가 있다.

> **§103 연결 (물권법 맥락)**: 원인행위인 매매계약이 §103([[반사회질서]] 법률행위)에 해당하여 무효이면, 유인성에 따라 물권변동도 무효 → 등기는 원인무효. 이 경우 §746([[불법원인급여]])과의 관계가 문제되며, 급여자의 불법성이 수익자보다 현저히 크지 않으면 부당이득반환청구 가능 (민법1 §6-8 참조).

## §5-1. 동산 물권변동의 성립요건 (제188조)

> **위치**: 물권변동 > 동산 물권변동 ([[선의취득]]·도품유실물)

> **제188조(동산물권양도의 효력, 간이인도)**
> ① 동산에 관한 물권의 양도는 그 동산을 **인도**하여야 효력이 생긴다.
> ② 양수인이 이미 그 동산을 점유한 때에는 당사자의 **의사표시**만으로 그 효력이 생긴다.

- 동산물권변동의 공시방법은 **점유(인도)**이고, 부동산물권변동의 공시방법인 등기와 대응한다.
- 제188조 제1항의 인도에는 현실인도뿐 아니라 간이인도(제188조 제2항), [[점유개정]](제189조), 반환청구권 양도(제190조)가 모두 포함된다.

## §5-2. 인도 방법 4종 비교표

| 유형 | 내용 | 조문 | 선의취득 가부 |
|---|---|---|---|
| **현실인도** | 직접 점유를 이전 | 제188조 제1항 | **O** |
| **간이인도** | 양수인이 이미 점유 중 → 의사표시만으로 효력 | 제188조 제2항 | **O** |
| **점유개정** | 양도인이 계속 직접점유, 양수인에게 간접점유를 취득시킴 | 제189조 | **X** (판례: **부정**) |
| **반환청구권 양도** | 제3자가 점유 중일 때 양도인의 반환청구권을 양도 | 제190조 | **O** |

- 점유개정은 양도인이 계속 점유하면서 양수인에게 간접점유를 취득시키는 방식이므로, 점유매개관계(임대차, 보관 등)가 필요하다. 
- 양도인이 직접점유자가 아니라 단순한 점유보조자 지위만 보유하는 경우에는 점유개정이 성립하지 않는다.

### 무과실 불추정 — 양수인 입증책임

- 제197조 제1항에 의해 평온·공연·선의는 추정되나, **무과실에 대해서는 추정규정이 없으므로 양수인이 입증책임을 부담한다.**
- **판례**: "무과실에 대해서는 추정규정이 없으므로, 선의취득자에게 무과실에 대한 입증 책임이 있다"

### 점유개정에 의한 선의취득 — 판례: **부정**

- **판례(대판 [[77다1872]], 대판 [[2004다37430]])**: **[[점유개정]]**은 관념적 점유이전방법 중에서 가장 불명확하고, 외부에서 거래행위의 존재를 전혀 인식할 수 없으므로, **진정한 권리자를 우선**적으로 보호하는 부정설이 타당하다.
- 간이인도(제188조 제2항)는 양수인이 이미 현실적 점유를 하고 있어 공시방법이 충족되므로 선의취득이 **긍정**된다.
### 이중의 점유개정

- 갑이 동산을 을에게 양도하면서 [[점유개정]] → 다음날 같은 동산을 병에게도 점유개정으로 양도한 경우:
  - 점유개정도 인도의 한 형태이므로 **제1양수인 을이 먼저 소유권을 취득**한다.
  - 제2양수인 병은 무권리자(갑)로부터 양수받은 것이 되나, **점유개정만으로는 선의취득이 부정**되므로 병은 소유권을 취득하지 못한다.
  - 병이 소유권을 취득하려면 현실인도 등 별도의 점유취득 방법이 필요하다.

#### 공방 구조 — 이중의 점유개정 사례형 (2021년 제2문 대응)

> 갑이 소유하는 동산을 을에게 점유개정으로 양도하고, 이후 같은 동산을 병에게도 점유개정으로 양도하였다. 병이 갑으로부터 현실인도를 받은 경우, 을이 병에게 소유물반환을 청구한다.

**1. 청구권기초**: 을(제1양수인)의 병(제2양수인)에 대한 §213 소유물반환청구권
**2. 요건**: ① 을의 소유권(?) ② 병의 점유(O) ③ 병의 점유 권원 부존재(?)
**3-1. 쟁점 — 이중의 [[점유개정]] 시 소유권 귀속**
- 점유개정도 인도의 한 형태(§189) → 선행 [[점유개정]] 시점에 을이 소유권 취득 → 이후 갑은 무권리자 → 병은 점유개정만으로는 소유권 취득 불가
**3-2. 쟁점 — 병의 §249 [[선의취득]] 성부**
- **학설**: [긍정설] vs **[부정설(판례)]**
- **판례** (대판 2003.2.11, [[2000다47602]]): "점유개정의 방법으로는 외부에서 거래행위의 존재를 전혀 인식할 수 없어 선의취득이 인정되지 않는다"
- **검토**: 부정설 타당 — 점유개정은 관념적 점유이전으로 공시 기능 부재
- **추가 검토**: 병이 갑으로부터 현실인도를 받은 경우 → §249 [[선의취득]] 가능. 다만 무과실은 양수인(병)이 입증해야 한다(판례).
**4. 포섭**: 을이 선행 점유개정으로 소유권 취득 → 병의 점유개정에 의한 소유권 취득 부정 → 병이 현실인도를 받았으므로 §249 [[선의취득]] 여부 검토 → 무과실 입증 여부에 따라 결론
**5. 결론**: 점유개정만으로는 [[선의취득]] **부정**. 현실인도 등 추가 인도 시 무과실 입증되면 병의 선의취득 **인정** → 을의 청구 **기각**. 무과실 미입증이면 을의 청구 **인용**.

### 선의취득의 효과

- 선의취득자는 동산에 관한 **물권을 확정적으로 취득**한다.
- 사후에 진정한 권리자가 나타나더라도 원칙적으로 유지된다(다만 도품·유실물 특칙 적용 가능).

## §5-4. 도품·유실물 특칙 (제250조·제251조)

### 제250조 원문

> **제250조(도품, 유실물에 대한 특례)**
> 전조의 경우에 그 동산이 도품이나 유실물인 때에는 피해자 또는 유실자는 도난 또는 유실한 날로부터 **2년 내**에 그 물건의 반환을 청구할 수 있다.

### 제251조 원문

> **제251조(도품, 유실물에 대한 특례)**
> 양수인이 도품 또는 유실물을 **경매나 공개시장에서 또는 동종류의 물건을 판매하는 상인에게서** 선의로 매수한 때에는 피해자 또는 유실자는 양수인이 지급한 **대가를 변상**하고 그 물건의 반환을 청구할 수 있다.

### 핵심 정리

| 항목               | 내용                                                |
| ---------------- | ------------------------------------------------- |
| **도품**           | 절도·강도에 의해 **점유자의 의사에 반하여** 점유를 박탈당한 물건            |
| **유실물**          | 점유자의 의사에 의하지 않고 점유를 이탈한 물건                        |
| **판단기준**         | **직접점유자의 의사**를 표준으로 판단 (간접점유자의 의사가 아님)            |
| **반환기간**         | 도난·유실한 날로부터 **2년** (제척기간)                         |
| **금전**           | 금전은 제250조 적용 **제외**                               |
| **제251조 무과실 요건** | 통설·판례: 제251조는 제249조를 전제로 하므로 선의뿐 아니라 **무과실까지 요구** |
| **대가변상의 법적 성질**  | 통설·판례: **대가변상청구권** → 반환 후에도 대가변상을 청구할 수 있다[       |

### 점유보조자 처분 — 도품 해당 여부

- **통설·판례(대판 1991.3.22, [[91다70]])**: **점유보조자**가 점유물을 임의 처분한 경우, 직접점유자의 의사를 기준으로 판단하면 점유이탈이 아니므로 **도품·유실물에 해당하지 않는다.** 위탁물 횡령과 동일하게 취급된다.
- 따라서 점유보조자 처분물의 양수인에게는 일반적 [[선의취득]] 요건만 검토하면 되고, 제250조·제251조의 특칙은 적용되지 않는다.

### 도품·유실물의 소유권 귀속 — 학설 대립

| 학설               | 내용                                                          |
| ---------------- | ----------------------------------------------------------- |
| **선의취득자귀속설(통설)** | 선의취득 요건을 갖추면 도품·유실물이라도 즉시 소유권이 선의취득자에게 귀속하되, 2년 내 반환청구권이 존재 |
| **원소유자귀속설(소수설)** | 도품·유실물의 소유권은 원소유자에게 잔존하고, 2년 경과 시 선의취득자에게 확정적으로 귀속          |

> **[쟁점]**: ① 도품인지(**직접점유자의 의사 기준**) → ② 2년 내인지(기산점: 도난일) → ③ 경매·공개시장·동종 상인에게서 유상취득인지 → ④ 제251조 요건 충족 시 대가변상 후 반환

- **학설**: 선의취득자귀속설(통설) — 도품·유실물이라도 [[선의취득]] 요건 충족 시 즉시 소유권 이전, 2년 내 반환청구권만 존재 vs 원소유자귀속설(소수설) — 소유권은 원소유자에게 잔존
- **판례**: 도품 여부는 **직접점유자의 의사에 반하여 점유를 이탈**했는지 기준. 간접점유자(소유자)의 의사만으로 도품 해당 불가(대판 2003.8.22, [[2003다23722]])
- **검토**: 통설(선의취득자귀속설) 타당 — §250은 선의취득의 예외적 제한이므로 좁게 해석. 도품 판단은 직접점유자 기준이 적절

## §6-1. 점유의 개념

> **위치**: 점유 > 점유권

- **점유**: 물건에 대한 **사실상의 지배**(제192조 제1항)
- 점유는 물권이 아니라 **사실상태**를 보호하는 제도이므로, 본권(소유권 등)의 유무와 관계없이 사실적 지배가 있으면 점유자로 인정된다.
- 점유자에게는 점유보호청구권(제204조~제206조), 과실수취권(제201조), 비용상환청구권(제203조) 등이 인정된다.

## §6-2. 점유의 종류

| 구분                      | 분류        | 내용                                                                   | 효과                               |
| ----------------------- | --------- | -------------------------------------------------------------------- | -------------------------------- |
| **자주점유 / 타주점유**         | 소유의 의사 유무 | **자주**점유: **소유자로서** 점유 / **타주**점유: **타인의 소유권**을 전제로 한 점유(임차인, 수치인 등) | **자주점유만 취득시효**의 요건 충족            |
| **직접점유 / 간접점유**         | 점유의 직접성   | 직접점유: 물건을 직접 지배 / 간접점유: 점유매개관계를 통해 간접 지배(임대인 등)                      | 간접점유자도 점유보호청구권 행사 가능             |
| **선의점유 / 악의점유**         | 본권에 대한 인식 | 선의: 본권이 있다고 오신 / 악의: 본권이 없음을 알거나 의심                                  | 선의 점유자는 과실수취권 인정(제201조)          |
| **하자 있는 점유 / 하자 없는 점유** | 취득 방법     | 폭력·은비에 의한 점유 = 하자 있는 점유                                              | 하자 있는 점유자는 선의라도 악의 간주(제201조 제3항) |

## §6-3. 점유의 추정 (제197조)

> **제197조**
> ① 점유자는 소유의 의사로 선의, 평온 및 공연하게 점유한 것으로 추정한다.
> ② 선의의 점유자라도 본권에 관한 소에서 패소한 때에는 그 **소가 제기된 때**부터 악의의 점유자로 본다.

### 자주점유 추정 — 판례

- 제197조 제1항에 의해 점유자는 **자주점유(소유의 의사로 점유)로 추정**된다.
- **판례**: 자주점유의 추정은 ① 점유 취득 원인인 **권원의 객관적 성질**로 판단하고, ② 권원의 성질이 분명하지 않으면 자주점유로 추정하되, ③ 타인 소유임을 알면서 **무단점유**한 사정이 입증되면 추정이 번복된다.
- **공유 관계**: 공유자 1인이 공유토지 전부를 점유하더라도, 다른 공유자의 지분비율 범위 내에서는 **타주점유자**이다.
## §6-4. 점유보호청구권 (제204조~제206조)

> **같이 볼 사항**: 상호침탈(§6-8) · 자력구제(§6-7, §209) · 본권항변 불가(§6-6, §208) · 간접점유자 보호(§6-5)

### 제204조 (점유의 회수)

| 항 | 요건 | 효과 |
|---|---|---|
| **제204조 제1항** | ① 점유자가 ② 점유의 **침탈**을 당한 때 | 물건의 **반환** 및 **손해배상** 청구 가능 |
| **제204조 제2항** | 침탈을 당한 날로부터 **1년** 내에 행사 | **제척기간** (소멸시효가 아님) |

### 제205조 (점유의 보유)

| 항             | 요건                                    | 효과                          |
| ------------- | ------------------------------------- | --------------------------- |
| **제205조 제1항** | ① 점유자가 ② 점유의 **방해를 받은 때**             | **방해의 제거** 및 **손해배상** 청구 가능 |
| **제205조 제2항** | **방해가 존속**하는 동안 또는 **방해 종료일로부터 1년** 내 | 행사 기간                       |

### 제206조 (점유의 보전)

| 요건                                   | 효과                               |
| ------------------------------------ | -------------------------------- |
| ① 점유자가 ② 점유의 **방해를** **받을 염려**가 있는 때 | **방해의 예방** 또는 **손해배상의 담보** 청구 가능 |

### 점유보호청구권의 성질

- 점유보호청구권은 점유라는 **사실적 지배** 자체를 보호하는 제도이므로, 본권(소유권 등)의 유무와 관계없이 점유자이면 행사할 수 있다.
- 다만 상대방은 **본권에 의한 항변**(제208조)이 가능하여, 방해자가 소유권 등 본권을 입증하면 점유보호청구가 기각될 수 있다.
- 소유자도 점유보호청구권을 행사할 수 있고(소유권에 기한 물권적 청구권과 병행 가능), 자력구제(제209조)도 제한적으로 허용된다.

#### 공방 구조 — 점유보호청구 사례형

##### [유형 1] 정상 침탈 — 피침탈자가 점유회수 청구

> 갑이 점유하던 부동산을 을이 침탈. 갑이 §204① 점유회수청구.

**1. 청구권기초**: 갑(피침탈자)의 을(침탈자)에 대한 §204① 점유회수청구권 + 손해배상청구권
**2. 요건**: ① 갑의 점유(O) ② 을의 침탈(O) ③ 제척기간 1년 이내(?)
**3-1. 쟁점 — 을의 본권 항변 허용 여부**
- **판례** (§208): 점유의 소에서 본권으로 항변 불가. 을은 별도 §213 소 제기해야.
**3-2. 쟁점 — 제척기간 도과 여부**
- §204②: 침탈을 안 날로부터 **1년** 내 행사 필요
- **포섭**: 갑이 1년 이내 행사 → 제척기간 충족
**4. 포섭**: 갑의 점유 + 을의 침탈 + 제척기간 내 행사 → 요건 충족. 본권 항변 불가(§208).
**5. 결론**: **인용** (본권 유무 불문)

##### [유형 3] 간접점유자의 점유보호

> 갑(임대인, 간접점유자) — 을(임차인, 직접점유자) — 병(침탈자). 병이 을의 점유를 침탈.

**1. 청구권기초**: 갑(간접점유자)의 병(침탈자)에 대한 §207①+§204① 점유회수청구권
**2. 요건**: ① 갑의 간접점유(O — 임대차에 의한 점유매개관계) ② 병의 침탈(O) ③ 제척기간 내(O)
**3. 쟁점 — 반환 상대방(갑 vs 을)**
- §207②: 원칙적으로 직접점유자 을에게 반환. 을이 반환받을 수 없거나 원하지 않으면 갑에게 반환 가능.
**4. 포섭**: 간접점유자 갑도 독립적으로 점유보호청구권 행사 가능 → 병에게 반환 청구
**5. 결론**: **인용** (원칙 을에게 반환, 예외 갑에게 반환)

##### [유형 4] 이중의 점유개정 + 선의취득 (2021 제2문) ★

> 갑 소유 동산을 을에게 양도([[점유개정]]) → 을이 다시 병에게 양도(점유개정) → 병이 갑에게 인도 청구.

**구조**: 갑(직접점유) →(1차 [[점유개정]])→ 을(간접점유) →(2차 점유개정)→ 병(간접점유)

**1. 청구권기초**: 병(양수인)의 갑(직접점유자)에 대한 §249 선의취득에 기한 인도청구권
**2. 요건**: ① 동산(O) ② 평온·공연·선의·무과실(?) ③ 양도인의 점유(O — 을 간접점유) ④ 인도(? — [[점유개정]])
**3-1. 쟁점 — 점유개정에 의한 [[선의취득]] 인정 여부**
- **학설**: [긍정설] vs **[부정설(판례)]**
- **판례** (대판 2003.2.11, [[2000다47602]]): "점유개정의 방법으로는 외부에서 거래행위의 존재를 전혀 인식할 수 없어 선의취득이 인정되지 않는다"
- **검토**: 부정설 타당 — 진정한 권리자 보호 우선
**3-2. 쟁점 — 이후 현실인도·간이인도 시 [[선의취득]] 가부**
- 이후 현실인도 등 외부 인식 가능한 점유 이전이 있으면 §249 [[선의취득]] 가능
**3-3. 쟁점 — 도품·유실물 해당 시(§250·§251)**
- 동산이 도품·유실물 → §250: 2년 내 회복 청구 / §251: 공개시장 등에서 선의 매수 시 대가 변상
**4. 포섭**: 병은 점유개정으로만 인도 → [[선의취득]] 부정. 이후 현실인도 등 추가 인도 있으면 선의취득 검토.
**5. 결론**: 점유개정만으로는 [[선의취득]] **부정**. 현실인도 등 추가 인도 있어야 인정.
[《전경운_민법_물총_26》 p.108-112]

> **자력구제(§209) 핵심 정리**:
> - **점유방위권** (§209①): 침해 진행 중 → 자력 방위
> - **점유탈환권** (§209②): 부동산 = **즉시**, 동산 = **현장/추적** → 탈환
> - 점유보조자도 점유주를 위해 자력구제 가능 (통설)
> - 상당성 초과 시 → 손해배상의무

## §6-5. 간접점유자의 보호 (제207조)

> **제207조 (간접점유의 보호)** 제204조 내지 제206조의 규정은 점유매개관계에 의한 간접점유에 준용한다.

| 항목 | 내용 |
|---|---|
| **의의** | 간접점유자(임대인·위탁자 등)도 직접점유자와 동일하게 점유보호청구권 행사 가능 |
| **요건** | ① 점유매개관계(임대차·위임·보관 등) 존재 ② 간접점유자가 점유침탈/방해를 당할 것 |
| **효과** | 간접점유자가 자기 이름으로 제204조~제206조의 청구권 행사 |
| **직접점유자와 병행** | 직접점유자와 간접점유자 모두 독립적으로 청구권 행사 가능 |

- **사례**: 갑(임대인)이 을(임차인)에게 건물을 임대 중, 병이 건물을 무단점거한 경우 → 을(직접점유자)은 물론 갑(간접점유자)도 병에 대하여 제204조 점유회수청구권 행사 가능

## §6-6. 본권에 의한 항변 (제208조) ★★

> **제208조 (점유보호청구권에 대한 항변사유의 제한)**
> 점유권에 기한 소에 대하여는 본권에 관한 이유로 항변하지 못한다.

### (1) 의의 — 점유의 소와 본권의 소의 분리

| 원칙 | 내용 |
|---|---|
| **점유의 소 → 본권 항변 불가** | 점유권에 기한 소에서 상대방이 "나는 소유자다"라고 항변 불가 |
| **취지** | 점유보호는 **사실상의 지배 자체**를 보호하는 제도 → 본권 유무와 무관하게 점유 침해를 시정하려는 것 |

### (2) 제208조의 적용 범위

| 구분 | 허용 여부 | 설명 |
|---|---|---|
| 점유의 소에서 본권 항변 | **불가** (원칙) | 점유침탈자가 소유권으로 항변 불가 |
| 점유의 소에서 **침탈이 불법 아님** 항변 | **가능** (통설) | 적법한 자력구제(§209)에 해당하는 경우 등, 침탈 행위 자체의 적법성 항변 |
| 본권의 소에서 점유권 항변 | **불가** (통설) | 소유권에 기한 소에서 "나는 점유자다"라는 항변만으로는 부족 |

### (3) 본권 항변이 허용되는 경우 — 학설

| 학설           | 내용                                                       |
| ------------ | -------------------------------------------------------- |
| **부정설 (통설)** | 제208조의 문언대로 **본권 항변은 일체 불가**. 본권자는 별도의 본권에 기한 소를 제기해야 함  |
| **제한적 긍정설**  | 본권이 명백하고 점유보호를 인정하면 현저히 부당한 결과가 되는 경우에 한하여 **예외적 항변 허용** |

### (4) 실전적 의미

- **점유침탈자가 소유자인 경우**: 소유자라도 자력구제(§209) 요건을 갖추지 않고 타인의 점유를 침탈하면 → 피침탈자(비소유자)가 점유회수청구를 할 수 있고, 침탈자(소유자)는 "나는 소유자다"라는 본권 항변 불가
- 소유자는 **별도로** 소유권에 기한 반환청구(§213)를 제기해야 함

## §6-7. 자력구제 (제209조) ★

> **제209조 (자력구제)**
> ① 점유자는 그 점유를 부정히 침탈 또는 방해하는 행위에 대하여 자력으로써 이를 **방위**할 수 있다.
> ② 점유물이 침탈되었을 경우에 부동산일 때에는 점유자는 침탈 후 **즉시**, 동산일 때에는 **현장에서 또는 추적하여** 이를 탈환할 수 있다.

### (1) 의의

자력구제권이란 **점유침해행위가 현재 행해지고 있거나 또는 행해진 지 얼마 안 된 경우** 점유자가 자력으로 방해를 막거나 탈환할 수 있는 권리이다.

> 점유보호청구권(§204~§206)은 점유의 침해가 **완료된 후**에 인정됨. 자력구제권은 침해가 **진행 중 혹은 완료 직후**에 인정된다는 점에서 구별.

### (2) 자력방위(§209①) vs 자력탈환(§209②) 비교표

| 구분 | 자력방위 (§209①) | 자력탈환 (§209②) |
|---|---|---|
| **시점** | 침탈·방해 행위 **진행 중** | 침탈 **완료 후** |
| **대상** | 침탈 또는 방해 행위 | 침탈된 점유물 |
| **방법** | 자력으로 **방어** (실력 행사) | 부동산: 침탈 후 **즉시** / 동산: **현장 또는 추적하여** 탈환 |
| **한계** | 필요 최소한의 실력 | 시간적 근접성 요구 (부동산=즉시, 동산=현장·추적) |
| **과도한 실력** | **불법행위** 성립 가능 (§750) | 동일 |

> **주의**: 자력탈환권(§209②)은 점유침해가 **"침탈"** 형태인 경우에만 인정된다. 방해 형태의 점유침해에는 탈환권이 아니라 **방위권(§209①)** 만 행사할 수 있다.
> 근거 발췌: "점유탈환권은 점유의 침해가 '점유물의 침탈'의 형태로 행해진 경우에 한하여 인정되며 기타의 형태로 인한 점유의 방해의 경우에는 인정되지 않는다"

### (3) 핵심 포인트

- **"즉시"의 해석** (대판 2017.9.7, [[2017도9999]]): 물리적 시간의 장단만이 아니라, 침탈자가 **확립된 점유를 취득**하여 자력탈환권의 행사를 허용하는 것이 오히려 법적 안정·평화를 해하거나 자력탈환권의 남용에 이르는 것은 아닌지도 함께 살펴 판단해야 한다.
- **"추적"의 의미**: 침탈행위는 종료되었으나 아직 현장을 완전히 벗어나지 않은 동안에 그것이 발견되어 침탈자를 따라가는 것. 침탈자의 주거에서 점유를 탈환하더라도 추적성은 상실되지 않는다(이영준).
- **자력구제 초과 시**: 불법행위(§750) 손해배상 책임 + 상대방의 점유회수청구(§204) 인정 가능

**[판례] 위법한 강제집행 후 2시간 이내 탈환 → 자력구제 해당** (대판 1987.6.9, [[86다카1683]])

갑이 점유이전금지가처분 집행 후 본안판결에 기하여 己(이미 적법하게 소유주들과 임대차계약 체결하고 점유 중)에 대한 명도집행을 단행한 것은 위법하고, 위법한 강제집행에 의한 부동산 인도는 **공권력을 빌려 점유를 침탈**하는 것이므로, 己이 강제집행 종료 후 **불과 2시간 이내**에 자력으로 점유를 탈환한 것은 §209의 자력구제에 해당한다.

### (4) 자력구제권자

| 주체 | 자력구제권 행사 가능 여부 |
|---|---|
| **직접점유자** | 가능 |
| **간접점유자** (대내적 — 직접점유자에 대한 경우) | **불가** (본권에 기한 청구권만 행사 가능) |
| **간접점유자** (대외적 — 제3자에 의한 직접점유 침해 시) | **다툼**: 긍정설(김상용, 이은영) vs **부정설**(곽윤직 등, 통설) |
| **점유보조자** | 점유주를 위하여 **자력구제권만은** 행사 가능 (통설) |
| **본권자(소유자 등)** | 원칙적 **불허**. 단, 급박한 사정이 있는 경우 정당방위·긴급피난 규정 유추적용으로 예외 인정 가능 (곽윤직 등 통설) |

> 근거 발췌: "간접점유자는 직접점유자에 대해서 점유보호청구권이나 자력구제권을 행사할 수 없고, 간접점유의 기초가 되는 법률관계, 즉 점유매개관계 또는 본권에 의거한 청구권을 행사할 수 있을 뿐이다"

## §6-8. 점유의 상호침탈 (2025 기출) ★★

### (1) 쟁점의 정리

점유를 침탈당한 자(갑)가 침탈자(을)로부터 점유를 다시 탈환한 경우(이른바 '점유의 상호침탈'), 을이 갑에 대하여 §204①에 따른 점유회수를 청구할 수 있는가?

> **전제**: 갑의 탈환이 §209② 자력구제의 요건(부동산=즉시, 동산=현장·추적)을 **충족하는 경우**에는 갑의 탈환 자체가 적법하여 애초에 "침탈"에 해당하지 않으므로 을의 §204 청구는 당연히 불가. **상호침탈 논의는 갑의 탈환이 §209② 요건을 충족하지 못한 경우에 한정**된다.
> 또한 §204③의 1년 제척기간도 별도로 충족해야 한다.
### (2) 학설

| 학설 | 주요 논거 |
|---|---|
| **부정설 (다수설·판례)** | ① 을의 청구가 인용되더라도 갑이 다시 §204로 회수하면 되므로 **소송상 비경제적**. ② 갑의 탈환은 **질서의 회복**으로 인정. ③ 비교법적으로도 상호침탈 시 점유회수청구권은 매우 제한적으로 인정됨 |
| **긍정설 (이영준)** | ① 점유회수청구권은 본권 유무와 무관하게(§208②) 인정되는 권리이므로, 결과적으로 본권 있는 자의 실력행사만 적법하게 되는 것은 부당. ② 부정설의 소송상 비경제성 문제는 탈취자가 **본안 항변이나 반소**로 해소 가능 |

> **부정설 내 소수의 요건 한정론**: 피탈취자의 회수청구권이 부정되는 것은 "탈취자가 도둑맞은 때로부터 **1년 내**에 도로 빼앗은 경우"에 한한다는 입장도 있다 (즉 탈환행위 자체의 적법성을 요구). 그러나 다수설과 판례는 이 한정 없이 부정한다.

**[판시]** "상대방으로부터 점유를 위법하게 **침탈당한 점유자**가 상대방으로부터 **점유를 탈환**하였을 경우(이른바 '점유의 상호침탈'), 상대방의 점유회수청구권이 받아들여지더라도 점유자가 상대방의 점유침탈을 문제 삼아 점유회수청구권을 행사함으로써 다시 자신의 점유를 회복할 수 있다면 상대방의 점유회수청구를 인정하는 것이 **무용**하다. 따라서 이러한 경우 점유자의 점유탈환행위가 §209②의 **자력구제에 해당하지 않는다고 하더라도** 특별한 사정이 없는 한 **상대방은** 자신의 점유가 침탈당하였음을 이유로 점유자를 상대로 §204①에 따른 **점유의 회수를 청구할 수 없다."**

> **[결론]** 피고의 점유탈환행위가 §209②의 자력구제 한계를 벗어난 것이더라도, **먼저 점유를 침탈한 원고는** 피고에 대하여 점유회수를 청구할 수 없다.

### (4) 자력구제(§209②)와의 관계

| 구분 | 내용 |
|---|---|
| 갑의 탈환이 §209② **해당** | 적법한 자력구제 → 을의 점유회수청구 당연 부정 |
| 갑의 탈환이 §209② **미해당** (시간 경과 등) | **판례**: 자력구제에 해당하지 않더라도, 상호침탈 법리에 의해 을의 점유회수청구 **부정** |

→ 판례는 자력구제 해당 여부와 **무관하게** 상호침탈 시 을의 §204 청구를 부정한다는 점이 핵심.

### (5) 공방 구조 (2025 기출 제3문-3 유형)

> **사안**: 갑이 X토지를 점유하고 있었는데 을이 이를 침탈하였다. 갑이 다시 을로부터 X토지를 탈환하였다. 을은 갑에 대하여 점유회수를 청구할 수 있는가?

**1. 청구권기초**: 을(최초 침탈자)의 갑(원래 점유자·탈환자)에 대한 §204① 점유회수청구권
**2. 요건**: ① 을의 점유(O — 침탈로 취득) ② 갑의 탈환(O) ③ 제척기간 내(O)
**3. 쟁점 — 상호침탈 시 최초 침탈자의 점유회수청구 인정 여부**
- **학설**: [긍정설(이영준)] vs **[부정설(다수설)]**
- **판례** (대판 2023.8.18, [[2022다269675]]): "먼저 점유를 침탈한 원고는 피고에 대하여 점유회수를 청구할 수 없다"
- **검토**: 부정설 타당 — 을의 청구를 인정해도 갑이 다시 §204①로 회복 가능하므로 무용한 순환. §209② 자력구제 해당 여부와 무관.
**4. 포섭**: 을이 먼저 갑의 X토지 점유를 침탈 → 갑이 탈환 → 상호침탈에 해당 → 을의 §204① 청구 부정
**5. 결론**: **기각** (갑의 탈환이 §209②에 해당하지 않더라도 동일)

### (6) 모답형

> **[쟁점]** 점유의 상호침탈 시 최초 침탈자의 점유회수청구권 인정 여부
>
> **[조문]** §204①은 "점유자가 점유의 침탈을 당한 때에는 그 물건의 반환 및 손해의 배상을 청구할 수 있다"고 규정한다.
>
> **[판례]** 판례(대판 2023.8.18, [[2022다269675]])는 "상대방으로부터 점유를 위법하게 침탈당한 점유자가 점유를 탈환하였을 경우, 상대방의 점유회수청구가 받아들여지더라도 점유자가 다시 점유회수청구권을 행사하여 점유를 회복할 수 있으므로 상대방의 점유회수청구를 인정하는 것은 무용하다"고 판시하였다.
>
> **[포섭·결론]** 을이 먼저 갑의 점유를 위법하게 침탈하였고 갑이 이를 탈환한 것이므로, 갑의 탈환이 §209②의 자력구제에 해당하지 않더라도, 을은 §204①에 따른 점유의 회수를 청구할 수 없다.

## §8. 취득시효 ★★ [빈도 #4: 소멸시효 101 연관]

> **같이 볼 사항**: 자주점유 추정(§6-3, §197) · 등기청구권 소멸시효(§4-4) · 시효완성 후 제3자 처분(§8-6) · 무권리자 처분(§7)

## §8-1. 부동산 점유취득시효 (제245조 제1항)

> **위치**: 소유권 > 취득시효

> **제245조 제1항**
> 20년간 부동산을 소유의 의사로 평온, 공연하게 점유하는 자는 **등기함으로써** 그 소유권을 취득한다.

| 요건 | 내용 |
|---|---|
| **① 20년간 점유** | 점유의 계속이 필요. 점유 승계(제199조)도 인정 |
| **② 소유의 의사(자주점유)** | 제197조 제1항에 의해 추정됨. 번복은 상대방 입증 |
| **③ 평온·공연** | 폭력·은비에 의하지 않은 점유 |
| **④ 등기** | 시효완성 후 등기를 해야 소유권 취득. 등기청구권이 발생 |

## §8-2. 등기부취득시효 (제245조 제2항)

> **제245조 제2항**
> 부동산의 소유자로 등기한 자가 10년간 소유의 의사로 평온, 공연하게 **선의이며 과실 없이** 그 부동산을 점유한 때에는 소유권을 취득한다.

| 요건 | 내용 |
|---|---|
| **자기 명의 등기** | 소유자로 등기되어 있어야 함 |
| **10년간 점유** | 등기한 때부터 10년 |
| **선의·무과실** | 제245조 제1항과 달리 추가로 요구됨 |

- **판례**: [[등기부취득시효]] 완성 후 등기가 말소되거나 타인 앞으로 이전되더라도, 시효완성의 효력에 영향 없음
- 무효인 중복등기(이중 보존등기)에 기하여 등기부취득시효를 주장하는 것은 불가 (1부동산 1등기기록주의)

## §8-3. 취득시효 유형 비교표

| | 부동산 점유취득시효 (제245조 제1항) | 부동산 등기부취득시효 (제245조 제2항) | 동산 취득시효 (제246조) |
|---|---|---|---|
| **기간** | **20년** | **10년** | 10년 |
| **점유 요건** | 소유의 의사·평온·공연 | 소유의 의사·평온·공연·선의·무과실 | 평온·공연·선의·무과실 |
| **등기 요건** | 시효완성 후 **등기로** 취득 | 자기 명의 **등기** 필요 | -- |
| **효과** | 등기청구권 발생 → 등기 시 소유권 취득 | 소유권 취득 | 소유권 취득 |

## §8-4. 자주점유 요건 — 3단계 판단

1. **1차 판단**: 점유 취득 원인인 **권원의 객관적 성질**로 자주점유 여부를 판단한다.
2. **2차 판단(추정)**: 권원의 성질이 분명하지 않으면 제197조 제1항에 의해 **자주점유로 추정**한다.
3. **3차 판단(번복)**: 타인 소유임을 알면서 **무단점유(악의의 무단점유)한 사정이 입증되면 추정이 번복된다.

- **타주점유에서 자주점유로의 전환**: 새로운 권원 또는 소유의사 표시가 필요하다.

## §8-5. 취득시효 완성으로 인한 등기청구권

| 항목 | 내용 |
|---|---|
| **성질** | **채권적 청구권** (판례·다수설) |
| **소멸시효** | **점유가 계속되는 한** 시효로 소멸하지 않음 (대판(전합) 1995.3.28, 93다47745) |
| **점유 상실 후** | 상실 시점부터 **10년** 경과 시 소멸시효 완성 |
| **양도성** | 매매에 의한 등기청구권과 달리 **양도제한 법리 적용 없음** → 자유롭게 양도 가능 |

#### 공방 구조 — 점유취득시효 사례형

> 갑이 을 소유 토지를 20년간 자주·평온·공연하게 점유하여 시효가 완성되었다. 갑이 을에게 소유권이전등기를 청구한다.

**1. 청구권기초**: 갑(시효취득자)의 을(소유자·등기명의인)에 대한 §245① 소유권이전등기청구권
**2. 요건**: ① 20년간 점유(O) ② 소유의 의사(자주점유)(?) ③ 평온·공연(O) ④ 등기 미경료(O)
**3-1. 쟁점 — 자주점유 인정 여부**
- **판례**: §197①에 의해 자주점유 추정 → 타인 소유임을 알면서 무단점유한 사정이 입증되면 추정 번복
- **포섭**: 을이 무단점유 사정을 입증하지 못하면 자주점유 추정 유지
**3-2. 쟁점 — 등기청구권의 소멸시효**
- **판례** (대판(전합) 1995.3.28, [[93다47745]]): "점유가 계속되는 한 시효로 소멸하지 않는다"
- **포섭**: 갑이 점유를 계속 중 → 소멸시효 불진행 → 을의 시효항변 배척
**4. 포섭**: 20년 자주·평온·공연 점유 + 자주점유 추정 유지 + 점유 계속으로 소멸시효 불진행 → 요건 충족
**5. 결론**: **인용** (소유권이전등기 이행)

## §8-6. 취득시효 완성 후 소유자의 제3자 처분

- **판례**: 시효완성 후 소유자가 제3자에게 처분·이전등기를 한 경우, **이중양도와 유사하게 취급**하여 시효완성자는 제3취득자에게 대항할 수 없다.
- 소유자가 시효완성 사실을 **알면서 처분**했다면 → **불법행위 성립** (제750조). 다만 채무불이행 책임은 계약관계가 아니므로 불가.
#### 공방 구조 — 시효완성 후 소유자의 제3자 처분 사례형

> 갑이 취득시효를 완성하였으나 등기 신청 전에 소유자 을이 병에게 처분하고 이전등기를 마쳤다. 갑이 병에 대해 대항할 수 있는가?

**1. 청구권기초**: 갑(시효취득자)의 병(제3취득자)에 대한 소유권 주장(시효완성에 기한 대항)
**2. 요건**: ① 취득시효 완성(O) ② 등기(X — 미경료) ③ 병에 대한 대항력(?)
**3. 쟁점 — 시효완성 후 제3자 처분 시 대항 가부**
- **판례**: 이중양도와 유사하게 취급 → 먼저 이전등기를 마친 병이 우선
- **검토**: 시효완성자는 등기청구권(채권적 청구권)만 취득하고 아직 물권변동 미발생 → 병의 등기 우선
**4. 포섭**: 갑 시효완성 → 등기 미경료 → 을이 병에게 처분 + 이전등기 → 병 등기 우선 → 갑은 병에 대항 불가
**5. 결론**: **기각** (병에 대한 대항 불가). 다만 을이 시효완성 사실을 알면서 처분하였다면 갑은 을에 대하여 §750 불법행위에 기한 손해배상 청구 가능(채무불이행 책임은 계약관계 부존재로 불가).

## §10. 과실수취권과 비용상환 ★

> **같이 볼 사항**: 물권적 청구권(§2-4) + [[부당이득]](§741) 세트 출제 · 유치권(§320) · 선의/악의 점유자 구분(§6-2)

## §10-1. 선의 점유자의 과실취득권 (제201조)

> **위치**: 소유권 > 점유자 이익보호

> **제201조**
> ① 선의의 점유자는 점유물의 과실을 취득한다.
> ② 악의의 점유자는 수취한 과실을 반환하여야 하며 소비하였거나 과실로 인하여 훼손 또는 수취하지 못한 경우에는 그 과실의 대가를 보상하여야 한다.
> ③ 전항의 규정은 폭력 또는 은비에 의한 점유자에 준용한다.

### 핵심 정리

| 항목 | 내용 |
|---|---|
| **선의의 과실취득** | 선의 점유자는 점유물의 과실(천연·법정·사용이익 포함) 전부를 취득 |
| **부당이득 불성립** | 선의 점유자가 과실을 취득하는 범위에서는 부당이득이 성립하지 않음 |
| **매매계약 취소** | 판례는 매매계약 취소의 경우에도 제748조 제1항의 특칙으로 **제201조 적용 긍정** |

### '선의'의 의미

- 과실수취권을 **포함하는 본권**(소유권·지상권·전세권·임차권 등)이 있다고 **오신**하는 것
- 과실수취권을 포함하지 않는 질권·유치권을 오신해도 제201조의 '선의'에 해당하지 않음

### 선의 → 악의 전환 시점

1. 적극적으로 과실취득권 없음을 알게 된 때 → **악의**
2. 본권에 관한 소에서 패소 → **소가 제기된 때**부터 악의 (제197조 제2항)
3. 선의라도 **폭력·은비**에 의한 점유자 → 악의 간주 (제201조 제3항)

### 무과실 요구 여부 — 판례: 요구

| 학설 | 내용 |
|---|---|
| **통설** | 과실 있어도 제201조 제1항 적용 |
| **소수설** | 과실로 오신한 점유자에게까지 과실취득권 부여는 부당 |
| **판례** | **오신에 오신할 만한 정당한 이유**가 있어야 과실취득권 인정 |

- **검토**: 판례(소수설과 동지) 타당 — 과실 있는 점유자에게까지 과실취득권을 부여하면 진정한 권리자 보호에 흠결. "오신할 만한 정당한 이유" 요구가 균형적

#### 과실수취권 — 판례 원문 + 타당성

**[판례 ①]** "민법 제201조 제1항에 의하면 선의의 점유자는 점유물의 과실을 취득한다고 규정하고 있는바, 건물을 사용함으로써 얻는 이득은 그 건물의 과실에 준하는 것이므로, **선의의 점유자는 비록 법률상 원인 없이 타인의 건물을 점유·사용하고 이로 말미암아 그에게 손해를 입혔다고 하더라도 그 점유·사용으로 인한 이득을 반환할 의무는 없다**" (대판 1996.1.26, **[[95다44290]]**).
[《전경운_민법_물총_26》 p.22]

**[판례 ②]** "제201조 제1항의 선의의 점유자란 과실수취권을 포함하는 본권(소유권·지상권·전세권·임차권 등)이 있다고 오신하고 오신할 만한 정당한 이유가 있는 점유자를 말한다" (대판 1995.8.25, **[[94다27069]]**; 대판 2000.3.10, **[[99다63350]]**).
[《전경운_민법_물총_26》 p.131]

**[판례 ③ 사용이익 유추적용]** 과실(§102)에 해당하지 않는 물건 자체의 사용이익(주택 거주 등)에도 §201①이 **유추적용**됨 (통설·판례).
[《전경운_민법_물총_26》 p.22 | "사용이익의 귀속이나 반환의무에 관해서는 과실수취권이나 반환의무에 관한 규정이 유추적용된다"]

**과실수취권 제도가 타당한 이유**:

| 논거 | 내용 |
|------|------|
| **선의점유자 신뢰 보호** | 본권이 있다고 정당하게 신뢰한 점유자가 과실을 수취한 것은 비난가능성이 없음 → 신뢰 보호가 형평에 부합 |
| **부당이득 법리와의 조화** | §201①은 §748①(선의수익자의 현존이익 반환)의 특칙 → 선의 점유자의 범위에서 부당이득 자체를 부정함으로써 신뢰 보호를 강화 |
| **악의자 반환의무의 정당성** | 본권 없음을 알면서 과실을 수취한 악의 점유자에게 전부 반환 + 보상의무를 부과하는 것은 부당이득 법리와 일관 |
| **무과실 요구(판례)의 타당성** | 단순히 과실로 오신한 자까지 보호하면 진정한 권리자의 이익을 과도하게 침해 → 오신에 정당한 이유 있는 무과실 점유자만 보호가 균형적 |

> **모답형**: "선의의 점유자는 점유물의 과실을 취득한다(§201①). 여기서 선의란 과실수취권을 포함하는 본권이 있다고 오신하고 오신할 만한 정당한 이유가 있는 것을 의미한다(대판 [[94다27069]]). 선의 점유자가 점유물을 사용하여 얻은 이익은 §201①이 §748①의 특칙으로 적용되어 부당이득이 되지 않는다(대판 [[95다44290]])."

### 농작물 소유권 — 판례: 경작자 귀속 (권원 불문)

- 제256조 단서: 정당한 권원에 의해 타인 토지에 경작한 농작물 → 토지와 독립된 물건
- **판례**: 아무런 권원 없이 경작한 경우에도 **명인방법 불요**, 경작자가 소유권 취득
- 토지 소유자 → 경작자에게 **토지 사용 기간 지료에 상당하는 부당이득반환**만 청구 가능

## §10-2. 비용상환 (제203조)

### 필요비 상환

- 점유자가 점유물의 보존에 관한 필요비를 지출한 때에는 회복자에게 그 상환을 청구할 수 있다 (제203조 제1항).
- **예외**: 선의 점유자가 과실을 취득한 경우(제201조 제1항)에는 통상의 필요비 청구 **불가** (제203조 제1항 단서)
- 특별의 필요비(임시비)는 상환 청구 가능

### 유익비 상환

- 점유자가 점유물의 개량을 위하여 지출한 금액 기타 유익비에 관하여는, 그 가액의 증가가 현존한 경우에 한하여 회복자의 선택에 좇아 **그 지출금액이나 증가액**의 상환을 청구할 수 있다 (제203조 제2항).
- 법원은 회복자의 청구에 의하여 상당한 상환기간을 허여할 수 있다.

### 부당이득과의 관계

- **판례**: 제203조가 정당한 법률관계가 없는 물건 점유자와 회복자 사이의 특별규정이므로, 제741조 부당이득으로는 비용반환을 청구할 수 없다.

#### 유익비상환청구권 + 유치권 연결 (2025 변시 문제)

| 단계      | 내용                                                      | 조문       |
| ------- | ------------------------------------------------------- | -------- |
| **1단계** | 점유자가 유익비 지출 + **가액증가 현존**                               | §203②    |
| **2단계** | 유익비상환청구권 발생 (선의·악의 **불문**)                              | §203②    |
| **3단계** | 유익비상환청구권 = "그 물건에 관하여 생긴 채권" → 유치권 성립                   | §320①    |
| **4단계** | 회복자(소유자)가 **기간허여** 신청 시 법원이 상당 기간 부여 가능                 | §203② 후문 |
| **5단계** | 기간허여 시 이행기 미도래 → 유치권 행사 **제한** (§320② — 변제기 도래 전 행사 불가) | §320②    |

- **핵심**: 유익비 지출 → §203② 상환청구권 → §320① 유치권 → 소유자의 §203② 후문 기간허여 신청으로 유치권 행사 제한 가능
- 상환범위: 회복자의 **선택**에 따라 지출금액 또는 증가액 중 택일
- **점유자 선악 불문**: §201(선의 점유자 과실취득)과 달리 §203 유익비는 악의 점유자도 청구 가능

**[모답형]**
> 을은 X토지의 점유자로서 3,000만 원을 투입하여 토지 가치를 증가시켰고 그 증가가 현존하므로(당사자 불다툼), §203② 유익비상환청구권이 인정된다. 유익비상환청구권은 그 물건에 관하여 생긴 채권으로서 §320① 유치권의 요건을 충족하므로 을은 유치권을 행사할 수 있다. 다만 갑이 §203② 후문에 의한 기간허여를 청구하여 법원이 허여하면, §320② 유추에 의해 그 기간 중 유치권 행사가 제한된다.

## §10-3. §213 소유물반환청구권과 과실수취권의 연결 ★ (2022 기출)

### 기본 구도

소유자 갑이 §213으로 점유자 을에게 **원물 반환**을 청구하면, 을이 점유 기간 동안 수취한 **과실(천연과실·법정과실·사용이익)의 반환 범위**는 을의 선의·악의에 따라 §201이 결정한다.

> **§201조 ①** 선의의 점유자는 점유물의 과실을 취득한다.
> **§201조 ②** 악의의 점유자는 수취한 과실을 반환하여야 하며 소비하였거나 과실로 인하여 훼손 또는 수취하지 못한 경우에는 그 과실의 대가를 보상하여야 한다.

### §201과 §748(부당이득)의 관계

| 구분 | 선의점유자 | 악의점유자 |
|---|---|---|
| **과실 반환 여부** | 반환 불요 — §201① 특칙 | 과실 반환 의무 — §201② |
| **부당이득과의 관계** | §201①이 §748①의 **특칙** — 선의 점유자 범위 내 부당이득 불성립 | §201②는 §748②의 특칙이 **아님** — 악의수익자는 이자 부가 반환 §748② |
| **이자·지연손해금** | 불요 | §748② 적용 → 이자 붙여 반환 |
| **매매계약 취소 시** | 판례: §201① 긍정 — "제748조 제1항의 특칙으로 제201조 적용"[^민3-201a] | 악의점유자로 전환된 시점부터 §201② |

[^민3-201a]: 근거 위치: [《민법의_기초이론_3_전경운_중간고사_합본》 L578-603 | "민법 제201조는 선의수익자의 반환범위에 관한 제748조 1항에 대한 특칙으로 선의점유자의 과실취득권을 인정한다"]

### 선의 → 악의 전환 시점과 과실 반환 범위

- **소 제기 전**: 선의점유자 → 과실 전부 취득, 반환 불요
- **소 제기된 때**: §197② 적용 → **소 제기 시**부터 악의로 전환, 이후 수취 과실은 §201② 반환의무
- **소 제기 전 수취 과실**: 선의 기간의 과실 → §201① 취득, 소급 반환 불요

### 청구-항변 2열 표 (§213 반환청구 + §201 과실 처리)

**[사안] 갑 소유 X건물을 을이 권원 없이 점유·사용 중. 갑이 을에 대해 X건물 인도 청구 및 과실(임료 상당 사용이익) 반환을 청구한다.**

갑(원고, 소유자): [청구①] §213 소유물반환청구 — "갑은 X건물의 소유자이고 을은 권원 없이 점유 중이므로 인도를 구한다"
→ 을(피고, 점유자): [항변①] §213 단서 — "을은 점유할 권리(임차권 등)가 있으므로 반환을 거부한다"
→ 갑: [재항변①] "계약은 해제·취소로 소멸하였으므로 을의 점유 권원은 소멸하였다"
갑: [청구②] §201② — "을은 악의점유자이므로 수취 과실(임료 상당 사용이익)을 반환하라"
→ 을: [항변②] §201① — "을은 선의점유자이므로 과실을 취득할 권리가 있다 — 반환 불요"
→ 갑: [재항변②] §197② — "소 제기 시부터 악의로 전환 — 소 제기 이후 수취 과실은 반환의무"
갑: [청구③] §741 — "선의점유 기간이 인정되더라도 사용이익 상당의 부당이득반환 청구"
→ 을: [항변③] §201① 특칙 — "§201① 범위 내에서는 [[부당이득]] 불성립 (판례·통설)"

### 무과실 요건 (판례 주의)

- §213 자체는 상대방의 **고의·과실 불요** (무과실 책임)
- 그러나 §201① 선의점유자의 **과실취득**은 판례상 **오신에 오신할 만한 정당한 이유** 필요
- 즉: "선의이나 오신에 과실이 있는 점유자"는 §201① 보호를 받지 못해 과실 반환의무 발생
- 
### 모답형 (§213 + §201 결합)

> 갑은 X건물의 소유자이고 을은 아무런 권원 없이 이를 점유하고 있으므로, 갑은 §213에 기하여 을에게 X건물의 인도를 청구할 수 있다.
>
> 나아가 점유 기간 동안 수취한 임료 상당 사용이익의 반환 범위는 §201에 따른다. 을이 본권이 있다고 오신할 만한 정당한 이유가 있어 **선의점유자**에 해당하면, §201①에 의하여 과실을 취득하고 부당이득도 성립하지 아니한다. 반면 을이 **악의점유자**이거나, 갑의 소 제기 이후(§197②)에는 수취한 과실을 §201②에 의하여 반환하여야 하고, 소비·훼손한 경우에는 그 대가를 보상하여야 한다. §201②는 §748②의 특칙이 아니므로, 악의 수익자로서 이자를 붙여 반환하는 §748② 역시 중첩 적용된다.

## §7-1. 제187조 원문

> **위치**: 소유권 > 무권리자 처분

> **제187조(등기를 요하지 아니하는 부동산물권취득)**
> 상속, 공용징수, 판결, 경매 기타 법률의 규정에 의한 부동산에 관한 물권의 취득은 등기를 요하지 아니한다. 그러나 등기를 하지 아니하면 이를 처분하지 못한다.

- 이 조문의 정확한 표현은 "법률행위에 의하지 않은 부동산물권변동"이다. "법률의 규정에 의한 물권변동"은 일부에 불과하다.

## §7-2. 적용 유형 5가지

| 유형 | 내용 | 등기 없이 취득 |
|---|---|---|
| **① 상속(포괄승계)** | 피상속인 사망 시 법률상 당연히 상속인에게 이전 (제997조). 회사합병도 포함 | O |
| **② 공용징수** | 수용개시일에 사업시행자가 소유권 취득 (토지보상법 제45조 제1항) | O |
| **③ 판결** | **형성판결**만 해당. 이행판결·확인판결은 해당 없음 | O |
| **④ 경매** | 매수인이 매각대금 완납 시 소유권 취득 (민사집행법 제135조) | O |
| **⑤ 기타 법률 규정** | 신축건물 원시취득, 법정지상권, 관습법상 법정지상권, 혼동, 소멸시효, 취득시효 등 | O |

### 형성판결만 해당 — 판례

- **대판 1998.7.28, [[96다50025]]**: 제187조의 "판결"은 **형성판결**만을 의미한다.
- 형성판결의 예: 공유물분할판결(제269조 제1항), 사해행위취소판결(제406조), 상속재산 현물분할판결(제1013조)
- 소유권이전 약정에 기한 화해조서·인락조서는 제187조에 해당하지 않는다.

### 재단법인 출연재산 — 판례

- **학설**: 출연시설 vs 법인성립시설(판례) vs 조건부효력설 — 귀속시기 3설 대립. 제3자 대항 관련: 등기필요설(판례) vs 등기불요설(다수설)
- **판례**: 출연자와 법인 사이 **대내적 관계**에서는 등기 없이도 법인 설립과 동시에 재산 귀속, **대외적 관계**(제3자 대항)에서는 제186조에 따라 **등기 필요** (대판 [[78다481]])
- **검토**: 법인성립시설(판례) 타당. 다만 제3자 대항에 등기를 요구하는 판례는 성립요건주의(§186)와 대항요건주의를 혼용하는 측면이 있어 다수설(등기불요설)의 비판도 유력

## §7-3. 제187조 단서 — 처분 제한

- 법률행위에 의하지 않고 취득한 물권도 **처분하려면 먼저 등기**해야 한다 (제187조 단서).
- 처분금지 위반 시 처분은 **무효** (채권적 효력까지 부인하는 것은 아님).
## §7-4. 예외 — 부동산 점유취득시효 (제245조 제1항)

- 법률행위에 의하지 않은 물권변동이라면 등기 없이 취득해야 하나, 점유취득시효는 예외로 **"등기함으로써"** 소유권을 취득하므로 제187조 본문의 예외에 해당한다.

## §9-1. 명인방법의 의의

> **위치**: 소유권 > 명인방법·물권소멸

- **명인방법**이란 **관습법상의 공시방법**으로서, 수목이나 미분리의 과실의 현재 소유자가 누구라는 것을 알 수 있게 하는 표지·표식을 말한다.
- **등기할 수 없는 물건**(수목, 미분리 과실 등)에 대한 **공시방법을 대체**하는 제도이다.



### 명인방법의 적용 대상

| 대상 | 내용 |
|---|---|
| **수목의 집단** | 입목등기 또는 명인방법으로 독립 부동산 인정 |
| **개개의 수목** | 명인방법을 갖추면 독립된 부동산 |
| **미분리의 과실** | 수목의 일부이지만, 명인방법을 갖추면 독립한 물건으로 거래 가능 |
| **무권원 경작자의 농작물** | 판례: 아무런 권원 없이 타인 토지에 경작한 경우에도 **명인방법 없이** 경작자가 소유권 취득 |


## §9-2. 물권의 소멸

| 소멸 원인 | 내용 | 등기 필요 여부 |
|---|---|---|
| **목적물 멸실** | 물건 자체가 소멸하면 물권도 소멸 | 말소등기 필요 |
| **혼동** (제191조) | 소유권과 제한물권이 동일인에 귀속 → 제한물권 소멸 | 제187조 적용, **등기 불요** |
| **소멸시효** | 소유권 외의 재산권은 소멸시효에 걸림 (제162조 제2항) | 제187조 적용, **등기 불요** |
| **존속기간 만료** | 지상권·전세권 등 약정 기간 도과 | 제187조 적용 |
| **권리의 포기** | 물권자의 일방적 의사표시 | **등기 필요** (법률행위에 의한 변동) |
| **피담보채권 소멸** | 저당권 등 담보물권의 부종성에 의한 소멸 | 말소등기 필요 |

### 물권변동 성질

- 혼동에 의한 물권소멸은 **법률행위에 의하지 않은 물권변동** → 제187조 적용 → **등기 없이 소멸**한다.
## §9-4. 포기

- 물권자가 일방적 의사표시로 물권을 포기하는 것은 **법률행위에 의한 물권변동**이므로, 부동산인 경우 **등기가 필요**하다 (제186조).
- 동산인 경우 **점유의 포기**(물건의 방기)로 소멸한다.

## §2. 물권 총론

> **같이 볼 사항**: 물권적 청구권(§2-4) → [[부당이득]](§10) + 과실수취권(§10-1) + 비용상환(§10-2) 세트 · 배타적 사용수익권 포기(§2-4-8)

> **위치**: 물권 총론 > 물권의 의의·물권적 청구권

### §2-1. 물권법의 의의, 법원, 특질

#### (1) 물권법의 의의

물권법은 각종 재화에 대한 **배타적 지배/이용 관계**를 규율하는 법이다. 자본주의 사적 소유를 근간으로 한다. 
#### (2) 물권법의 법원

| 법원 | 내용 |
|------|------|
| **성문법** | 민법 제2편 물권법 + 부동산등기법, 가등기담보법, 공간정보관리법 등 특별법 |
| **관습법** | §1에 따라 성문법을 보충하는 효력. **관습법상 법정지상권** 등 물권법에서 중요한 역할 (§185 물권법정주의와 관련) |
| **판례** | 성문법주의 국가이나, 오래된 민법 규정의 흠결을 보충하고 추상적 의미를 명확히 하는 **법형성적 기능** 수행 |

#### (3) 물권과 채권의 차이점

| 구분    | 채권법               | 물권법           |
| ----- | ----------------- | ------------- |
| 지배 원리 | **계약자유**의 원칙      | **물권법정주의**    |
| 규정 성격 | **임의규정** 대부분      | **강행규정** 대부분  |
| 내용    | 특정인에 대한 행위 **청구** | 물건에 대한 배타적 지배 |
| 공시    | 불요                | 등기/인도 필수      |

#### (4) 물권의 본질적 특질

| 특질 | 내용 |
|------|------|
| **재산권** | 특정 물건을 객체로 하나, 예외적으로 권리(채권질권, 지상권/전세권에 대한 저당권)도 객체 |
| **직접 지배권** | 타인의 행위 매개 없이 물건을 직접 지배하여 이익 향유 |
| **배타성 (일물일권주의)** | 하나의 물건 위에 양립할 수 없는 물권이 동시 성립 불가 --> 공시제도 필수 |
| **절대권 (대세권)** | 누구에게나 주장 가능, 침해 시 **물권적 청구권** 발생 |

#### (5) 물권법정주의 (§185)

> **§185 (물권의 종류와 내용)** 물권은 법률 또는 관습법에 의하는 외에는 임의로 창설하지 못한다.

- **의의**: 물권의 종류와 내용을 법률로 정하는 것에 한정하는 원칙 
- **성격**: **강행규정** -- **대판 1991.12.13, [[91다29446]]**: "§185는 강행규정이다" 
- **관습법상 물권 인정 여부**: 관습법에 의한 물권 창설 허용 (§185 문언상 "관습법에 의하는 외에는")
  - **대판 1962.4.18, 4294민상1103**: 관습법상 법정지상권 인정
  - **대판 2002.2.26, [[2001다64165]]**: 사인 토지에 대한 관습상 통행권은 부정

**물권의 종류 체계표**

| 대분류 | 종류 |
|--------|------|
| 점유권 | 점유권 (§192~§210) |
| 본권 -- 소유권 | 소유권 (§211~§278) |
| 본권 -- 용익물권 | 지상권, 지역권, 전세권 |
| 본권 -- 담보물권 | 유치권, 질권, 저당권 |
| 관습법상 물권 | 관습법상 법정지상권, 분묘기지권 |

### §2-2. 물건의 정의 (§98)

> **§98 (물건의 정의)** 본법에서 물건이라 함은 유체물 및 전기 기타 관리할 수 있는 자연력을 말한다.

#### (`1`) 건물의 성립 -- 원시취득

- **건물 성립 요건**: 최소한의 **기둥, 지붕, 주벽**을 갖추면 독립한 부동산으로서의 건물이 성립한다.
  - **대판 1997.7.8, [[96다36517]]**: "기둥, 지붕, 주벽을 갖추면 건물로 성립한다" [
- **건물의 원시취득**: 건물은 **건축주**(=공사비 지급자)가 등기 없이 원시취득한다.
  - **대판 2002.4.26, [[2000다16350]]**: "건물의 신축에 있어서 그 **건물의 소유권**은 도급인이나 건축허가 명의인이 아니라, 그 건축에 소요되는 **노력과 재료를 제공한 자**, 즉 자기의 노력과 재료를 들여 건물을 건축한 사람에게 원시적으로 귀속된다" 

#### (2) 종물 (§100)

> **§100 (종물)** (1) 물건의 소유자가 그 물건의 상용에 공하기 위하여 자기 소유인 다른 물건을 이에 부속하게 한 때에는 그 부속물은 종물이다. (2) 종물은 주물의 처분에 따른다.

- **요건**: ① 주물의 상용에 공할 것 ② 주물 소유자의 소유일 것 ③ 장소적 관계에 있을 것 ④ 독립성 유지

|------|-------------|------|
| 대판 1991.5.14, 91다2779 | 본채와 광/연탄창고/공동변소 --> **종물** | 교재 p.21 |

| **대판 2008.5.8, 2007다36933** | **타인 소유 물건은 종물 불가** | 교재 p.22 |

### §2-3. 물권의 효력: 우선적 효력

#### (1) 물권 상호간의 우선적 효력

- **시간적 선후에 의한 순위**: 먼저 성립한 물권이 후에 성립한 물권에 우선 (등기/인도의 선후로 판단)
- **제한물권 > 소유권**: 제한물권은 소유권의 일부 내용을 제한하는 것이므로 소유권에 우선

#### (2) 물권과 채권 간의 우선적 효력

- **물권 > 채권**: 물건에 대한 배타적 지배권인 물권이 단순 청구권인 채권에 원칙적으로 우선
- **예외**: 대항력 있는 주택임차권(주택임대차보호법), 대항력 있는 상가임차권 등

### §2-4. 물권적 청구권

#### §2-4-1. 의의 및 3유형

물권적 청구권이란, **물권의 내용의 실현이 전면적 또는 부분적으로 방해당하고 있거나 방해당할 위험이 있는 경우**, 물권자가 방해자에 대하여 물건의 반환, 방해제거, 방해예방을 청구할 수 있는 권리를 말한다.

**[전경운] 인정근거**: 물권에 **"물권으로서의 실효성"**을 주기 위한 데 있다. 물권의 침해 후 부당이득반환청구(§741)나 불법행위에 의한 손해배상청구(§750)만으로는 물권자의 보호에 불충분하기 때문이다. 즉 물권이 물건을 직접적·배타적으로 지배할 수 있는 절대권이기 때문에, 그 방해를 제거할 수 있는 절대적 보호가 부여된다.[^민3-물청-1]

> **§213 (소유물반환청구권)** 소유자는 그 소유에 속한 물건을 점유한 자에 대하여 반환을 청구할 수 있다. 그러나 점유자가 그 물건을 점유할 권리가 있는 때에는 반환을 거부할 수 있다.

> **§214 (소유물방해제거, 방해예방청구권)** 소유자는 소유권을 방해하는 자에 대하여 방해의 제거를 청구할 수 있고 소유권을 방해할 염려 있는 행위를 하는 자에 대하여 그 예방이나 손해배상의 담보를 청구할 수 있다.



#### 3유형 비교표

| 유형 | 조문 | 요건 | 효과 |
|------|------|------|------|
| **반환청구권** | §213 | ① 청구권자가 소유자 ② 상대방이 점유자 ③ 상대방에게 점유할 권리가 없을 것 | 물건의 반환 청구 |
| **방해배제청구권** | §214 전단 | ① 소유권에 대한 점유 이외의 방해 존재 ② 방해가 현재 계속 중 | 방해의 제거 청구 |
| **방해예방청구권** | §214 후단 | ① 소유권을 방해할 염려 있는 행위 존재 ② 방해가 장래에 발생할 위험 | 예방 또는 손해배상 담보 청구 |

**요건 공통사항**:

- 물권 침해의 **객관성, 위법성, 현재성** 필요
- 상대방의 **고의/과실 불요** (무과실 책임)
- §213 단서: 점유자가 점유할 **권리**가 있으면 반환 거부 가능 (미등기 매수인의 항변 등)



**판례**:

- **대판 1993.10.8, [[93다28867]]**: "**등기 말소청구도 방해제거**에 포함된다" 
- **대판 2007.6.15, [[2004다37904]]**: "불가량물질에 의한 **환경침해(임밋시온)도 간접적 방해에 해당**한다" 
- 대판 1993.5.14, [[93다4366]]: "정당한 이유가 있으면 방해제거를 거부할 수 있다"
- 대법원 1999.7.9, [[98다57457]]: "토지 소유자는 **건물 철거/대지 인도**만 청구 가능, 건물 점유자에 대한 **퇴거 청구 불가"**

#### §2-4-2. 점유권에 기한 물권적 청구권 (§204~§206)

> **§204 (점유의 회수)** (1) 점유자가 점유의 침탈을 당한 때에는 그 물건의 반환 및 손해의 배상을 청구할 수 있다. (2) 전항의 청구권은 침탈자의 특별승계인에 대하여는 그 승계인이 선의인 경우에는 행사하지 못한다. (3) 제1항의 청구권은 침탈을 당한 날로부터 1년 내에 행사하여야 한다.

> **§205 (점유의 보유)** (1) 점유자가 점유의 방해를 받은 때에는 그 방해의 제거 및 손해의 배상을 청구할 수 있다. (2) 전항의 청구권은 방해가 존속하는 동안 또는 방해가 종료한 후 1년 내에 행사하여야 한다.

> **§206 (점유의 보전)** 점유자가 점유의 방해를 받을 염려가 있는 때에는 그 방해의 예방 또는 손해배상의 담보를 청구할 수 있다.

**소유권 기한 vs 점유권 기한 비교표**

| 구분 | 소유권에 기한 청구권 (§213, §214) | 점유권에 기한 청구권 (§204~§206) |
|------|------|------|
| 근거 | 소유권 (본권) | 점유 사실 자체 |
| 요건 | 소유권 증명 필요 | 점유 사실만 증명 |
| 상대방 항변 | 점유할 권리(§213 단서) | 본권 항변 **불가**(§208 원칙), 침탈 적법성 항변만 가능 |
| 제척기간 | 없음 | **1년** (§204 III, §205 II) |
| 소멸시효 | 부정(다수설+판례) | 1년 제척기간 적용 |
| 손해배상 | 별도 불법행위/부당이득 | §204 I 자체에 손해배상 포함 |

#### §2-4-3. 법적 성질 -- 절충설 (판례)

**학설 대립**:

| 학설 | 내용 | 논거 | 실익 |
|------|------|------|------|
| ① **물권설** | 물권의 작용(효력) 그 자체이므로 **독립된 청구권이 아니다** | 물권에 당연 내재하는 효력 | 소멸시효 적용 여지 없음, 독립 양도 불가 |
| ② **채권설** | 상대방에 대한 특정 행위의 청구가 내용이므로 **채권적 청구권** | 채권과 같이 특정인에 대한 행위청구 | 소멸시효 적용 가능, 독립 양도 가능성 |
| ③ **절충설 (판례·통설)** | 물권의 효력을 기초로 생기는 **특수한 독립된 청구권**으로서, 물권에 부종 | 물권 아닌 독립 청구권이되 채권도 아님 | 소멸시효 부정(다수설), 독립 양도 불가 |

> **모답형**: "물권적 청구권의 법적 성질에 관하여 물권설, 채권설, 절충설의 대립이 있으나, 판례는 물권적 청구권은 물권의 효력으로부터 발생하며(대판 1984.9.25, **[[84다카148]]**) 채권적 청구권은 아니라 하여(대판 1994.8.12, **[[94다25155]]**) **절충설**의 입장을 따르고 있다."

**판례**: **절충설** 

- 대판 1984.9.25, **[[84다카148]]**: 물권적 청구권은 **물권의 효력으로부터 발생**한다.
- 대판 1994.8.12, **[[94다25155]]**: 물권적 청구권은 **채권적 청구권이 아니다**.

**[전경운] 결론**: "물권적 청구권을 물권에 의존하고 또한 채권에 준하는 독립한 청구권이라고 보는 것이 좋을 것이다. 즉 물권적 청구권은 물권의 효력으로 인정되는 **물권에 부종하는 청구권**이라고 보아야 할 것이다."[^민3-물청-2]

> 학설 대립 근거: 물권적 청구권이 물권으로부터 생긴다는 점에서 물권에 가깝고, 한편 물권자가 **침해자에 대하여** 갖는 청구권이므로 **대인적인 채권의 면**을 가지고 있기 때문이다. **[전경운]**[^민3-물청-2]

#### §2-4-4. 물권과의 불가분성

물권적 청구권은 **물권의 효력으로부터 발생하는 권리**이므로 물권과 운명을 같이하고, **물권과 분리하여 독자적으로 양도할 수 없다**. 

**이유**: 물권과 분리한 독자적 양도를 인정하면, 권리실현의 방해를 제거할 수 없는 물권의 성립을 용인하는 것이 되기 때문이다. 

**두 가지 귀결**:

1. **물권 이전 시 자동 수반**: 물권이 양도되면 양도인은 물권적 청구권을 상실하고 양수인이 이를 가지게 된다. 물권과 분리하여 별도로 양도할 수 없다. [
2. **물권 소멸 시 청구권 소멸**: 소유권 상실 등으로 물권이 소멸하면 물권적 청구권도 함께 소멸한다. 

**[판례] 소유권 이전 후 물권적 청구권 소멸** (대판 1980.9.9, [[80다7]])

소유자가 반환소송을 제기한 후에 그 목적물의 소유권을 제3자에게 이전한 경우에는, 그 제3자가 소송승계의 절차를 밟지 아니한 한, 그 청구는 기각된다.

> 근거 발췌: "소유자가 반환소송을 제기한 후에 그 목적물의 소유권을 제3자에게 이전한 경우에는, 그 제3자가 소송승계의 절차를 밟지 아니한 한, 그 청구는 기각된다"

> **[전경운]** 물권적 청구권은 어디까지나 물권에 **'종된 권리'**이고, 따라서 물권과 분리하여 물권적 청구권만이 양도될 수 없다. 또한 물권이 소멸하면 그 청구권도 소멸한다. 그러므로 물권의 소멸로 물권적 청구권이 소멸한 경우, 물권적 청구권이 이미 발생하였음을 들어 **이행불능의 법리에 따라 전보배상을 인정할 수는 없다** (대판(전합) 2012.5.17, **[[2010다28604]]**).[^민3-물청-3]

#### §2-4-5. 비용부담

**학설**:

| 학설 | 비용 부담자 | 논거 | 비고 |
|------|-----------|------|------|
| ① **적극적 행위청구권설** (다수설) | **상대방(침해자)** | 물권적 청구권은 상대방에 대한 적극적 행위 청구 → 이행비용은 채무자(상대방) 부담 | 판례 취지도 동일 |
| ② **인용청구권설** | **청구권자(물권자)** | 물권자가 스스로 제거하는 것을 상대방이 인용(수인)할 의무 → 비용은 청구권자 | 예외: 상대방이 침해원인을 야기한 경우 상대방 부담 |

> **모답형**: "물권적 청구권의 비용부담에 관하여, 다수설은 물권적 청구권이 적극적 행위청구권의 성질을 가지므로 그 비용은 상대방이 부담한다고 보며, 판례도 물권적 청구권이 적극적 행위청구권임을 분명히 하므로 같은 취지이다."

**판례**: 명백한 태도를 밝히지는 않았으나, **물권적 청구권이 적극적 행위청구권임을 분명히 하므로, 상대방이 비용을 부담**하게 될 것이다. [사건번호: 찌라시 소스에 미기재 — 원본 확인 필요]

- **검토**: 적극적 행위청구권설(다수설) 타당 — 물권적 청구권은 상대방에 대한 적극적 행위 청구이므로, 이행비용은 채무자인 상대방(침해자)이 부담함이 원칙

| 학설 | 소유권 기한 | 제한물권 기한 | 논거 |
|------|-----------|-------------|------|
| **부정설 (다수설)** | 시효 부적용 | 시효 부적용 | 물권 존속하는데 청구권만 시효 소멸 → 물권의 실질 상실. 침해 계속 시 청구권 부단 발생 → 시효 완성 여지 없음 |
| **일부 긍정설 (소수설)** | 시효 부적용 | **시효 적용** | 제한물권은 소유권과 달리 제한적 권리 → 소멸시효 대상이 될 수 있음 |
| **판례** | **시효 부적용** | (판시 없음) | 소유권에 기한 물권적 청구권은 소멸시효 적용 안 된다고 판시 |

> **모답형**: "소유권에 기한 물권적 청구권은 소멸시효의 적용을 받지 아니한다(판례). 물권이 존재하는데 물권적 청구권만 시효로 소멸한다면 물권의 실질을 상실하게 되므로 다수설이 타당하다."

- **검토**: 부정설(다수설·판례) 타당 — 물권이 존속하는데 물권적 청구권만 시효로 소멸하면 물권의 실질이 공동화됨. 침해가 계속되는 한 청구권이 부단히 발생하므로 시효 완성 여지도 없음

---

#### §2-4-7. 물권적 청구권의 이행불능과 전보배상 -- 부정 (판례)

- 물권적 청구권의 기초인 소유권이 소멸하여 말소등기가 불능이 된 경우, **말소등기의 이행불능을 이유로 한 §390 손해배상청구권(전보배상)을 행사할 수 없다** (판례).
- **논거**:
  - ① 채무불이행으로 인한 손해배상청구권은 본래의 **채권**이 동일성을 유지하며 내용이 확장/변경되어 발생하는 것
  - ② 물권적 청구권은 물권에 부종하는 특수한 청구권으로서 **채권과 차이**가 있고, 권리자인 소유자가 소유권을 상실하면 발생의 기반이 사라짐
  - ③ 따라서 존재 자체가 인정되지 않는데 청구권의 실현이 불능이라는 이유로 §390을 적용할 수 없음
  - ④ 다만 불법행위로 인한 손해배상이나 부당이득에 대한 청구는 가능


---

#### §2-4-8. 권리남용 (§2 II)

> **§2 (신의성실)** ① 권리의 행사와 의무의 이행은 신의에 좇아 성실히 하여야 한다. ② 권리는 남용하지 못한다.

##### (1) 요건

| 번호 | 요건 |
|------|------|
| ① | 형식적으로는 권리 범위 내의 행사일 것 |
| ② | 사회통념상 현저히 타당성을 결여하여 정의관념에 반할 것 |
| ③ | 남용의 의사 또는 남용의 결과가 인정될 것 |

##### (2) 판례

- **대판 2003.11.27, [[2003다40422]]**: "권리남용으로 되려면 주관적으로 그 i)권리행사의 목적이 **오직** 상대방에게 **고통을 주고 손해**를 입히려는 데 있을 뿐 ii)행사하는 사람에게 아**무런 이익이 없는 경우**이거나, iii)**객관적으로 사회질서에 위반되는 특별한 사정**이 있어야 한다" 
- **대판(전합) 2019.1.24, [[2016다264556]]; 대판 2019.11.14, [[2015다211685]]** (2025 기출 핵심): "토지 소유자가 그 소유의 토지를 도로, 수도시설의 매설 부지 등 **일반 공중을 위한 용도로 제공한 경우**에, 소유자가 토지를 소유하게 된 경위와 보유기간, 소유자가 토지를 공공의 사용에 제공한 경위와 그 규모, 토지의 제공에 따른 소유자의 이익 또는 편의의 유무, 해당 토지 부분의 위치나 형태, 인근의 다른 토지들과의 관계, 주위 환경 등 **여러 사정을 종합적으로 고찰**하고, 토지 소유자의 소유권 보장과 공공의 이익 사이의 비교형량을 한 결과, 소유자가 그 토지에 대한 **독점적/배타적 사용수익권을 포기한 것으로 볼 수 있다면**, 타인이 그 토지를 점유/사용하고 있다 하더라도 특별한 사정이 없는 한 그로 인해 토지 소유자에게 손해가 생긴다고 볼 수 없으므로, 토지 소유자는 그 타인을 **상대로 부당이득반환을 청구할 수 없고, 토지의 인도 등을 구할 수도 없다"** 
- **공중 통행 도로 -- 인도청구 [[권리남용]]**:
  - **어떤 토지가 개설경위를 불문하고 일반 공중의 통행에 공용되는 도로, 즉 공로가 되면 그 부지의 소유권 행사는 제약을 받게 되며**, 이는 소유자가 수인하여야만 하는 재산권의 사회적 제약에 해당한다. 따라서 공로 부지의 소유자가 이를 점유/관리하는 지방자치단체를 상대로 공로로 제공된 도로의 인도를 청구하는 것은 법질서상 원칙적으로 허용될 수 없는 '[[권리남용]]'이다 (대판 2021.10.14, [[2021다242154]]; 대판 2023.3.13, [[2022다293999]] 등). 
  - 다만 토지소유자가 도로로 제공한 경우가 아닌, 자연발생적/도로편입 등의 경우에는 **임료 상당의 부당이득반환청구권은 인정**될 수 있다 (대판 2024.2.15, [[2023다295442]]; 대판 2024.4.4, [[2023다295695]]). 

- **상수도시설 철거 -- [[권리남용]] 아님**:
  - 공중의 편의를 위한 상수도시설을 대지소유자가 소유권에 기하여 철거를 요구한 것은 **권리남용에 해당하지 않는다**.
- **고압송전탑 -- [[권리남용]] 아님**:
  - 고압송전탑과 송전선이 설치된 사정을 알면서도 토지를 취득하여 주택분양사업을 추진한 경우 **권리남용에 해당하지 않는다**.

#### §2-4-9. 공방 구조 (사례형 답안)

**[사례: 인접 토지 침범 건축 -- 2015 기출 유형]**

> 갑이 인접한 을 소유 토지의 철조망을 제거하고 토지를 침범하여 가옥을 신축하였다.

**1. 청구권기초**: 을(토지소유자)의 갑(침범자)에 대한 §213 소유물반환(대지 인도) + §214 방해제거(건물 철거) + §741 부당이득반환 / §750 손해배상
**2. 요건(§213)**: ① 을의 소유권(O) ② 갑의 점유(O) ③ 갑의 점유 권원 부존재(?)
**2. 요건(§214)**: ① 을의 소유권(O) ② 갑의 건물에 의한 소유권 방해(O)
**3-1. 쟁점 — 갑의 §213 단서 항변(점유 권원)**
- **포섭**: 갑이 계약 등에 의한 점유 권원을 주장 → 입증 실패 시 항변 배척
**3-2. 쟁점 — 갑의 §2 II [[권리남용]] 항변**
- **판례**: 물권적 청구권의 상대방의 고의/과실은 요건이 아니므로(무과실 책임), 갑에게 고의/과실이 없더라도 을의 청구는 원칙적으로 인용
- **포섭**: 갑이 권리남용에 해당하는 특별한 사정을 입증하지 못하면 항변 배척
**4. 포섭**: 을의 소유권 + 갑의 무권원 점유·침범 건축 → §213 대지 인도 + §214 건물 철거 + §741/§750 병행 청구 가능
**5. 결론**: **인용** (대지 인도 + 건물 철거). 갑이 점유 권원 또는 [[권리남용]] 특별사정 입증 시 기각 가능.

---

**[사례: 공로 통행 -- 2025 제1문 유형]**

> 갑은 토지의 일부가 마을 주민과 인근 공장 출입자 등의 통행을 위한 도로로 사용되고 있는 X토지를 그의 父 A로부터 상속받았다. 갑은 Z을 상대로 도로부분 X토지의 인도청구와 부당이득반환 청구를 하였다.

##### 문1: A가 통행로 사용을 허용한 사실이 없었던 경우

**1. 청구권기초**: 갑(상속인·소유자)의 Z(점유·관리자)에 대한 §213 소유물반환(인도) + §741 부당이득반환
**2. 요건(§213)**: ① 갑의 소유권(O — A로부터 상속) ② Z의 점유(O) ③ Z의 점유 권원(?)
**3. 쟁점 — Z의 [[권리남용]] 항변(§2 II)**
- **학설**: 소유권 행사가 권리남용이 되려면 주관적 요건(가해 의사) + 객관적 요건(사회적 타당성 일탈) 충족 필요
- **판례**: 공로 부지의 인도청구가 권리남용에 해당하려면, 소유자(또는 피상속인)가 도로로 제공한 사실이 있어야 한다
- **검토**: 타당 — 도로 제공 사실이 없으면 소유자의 인도청구는 정당한 권리행사이므로 [[권리남용]] 불해당
- **포섭**: A가 통행로로 제공한 사실이 없음 → [[권리남용]] 항변 배척
**4. 포섭**: 갑의 소유권 + A의 도로 제공 사실 부존재 → Z의 [[권리남용]] 항변 배척 → 인도청구 인용. 부당이득반환(임료 상당)도 인정 가능.
**5. 결론**: **인용** (인도 + 부당이득반환)

##### 문2: A가 통행로 사용을 제공하였을 경우

**1. 청구권기초**: 갑(상속인·소유자)의 Z에 대한 §213 인도 + §741 부당이득반환
**2. 요건**: (동일)
**3. 쟁점 — 배타적 사용수익권 포기 법리**
- **학설**: 소유자의 사용수익권 포기가 물권적 효력(제3자 대항)인지 채권적 효력(당사자 간)인지 견해 대립
- **판례**: 소유자가 토지를 일반 공중의 이용에 제공하여 배타적 사용수익권을 포기한 것으로 볼 수 있는 경우, 인도청구 및 부당이득반환청구 불가
- **검토**: 판례 타당 — 도로로 제공하여 공중이 이용하는 토지는 소유권의 본질(사용수익)이 사실상 제한됨. 인도·[[부당이득]] 모두 불가
- **상속인의 지위**: §1005 포괄승계 → 피상속인의 배타적 사용수익권 포기 효과가 상속인에게도 승계
**4. 포섭**: A가 도로로 제공 → 배타적 사용수익권 포기 → 갑(상속인)도 행사 제한
**5. 결론**: **기각** (인도청구 + 부당이득반환청구 모두 불가)

#### §2-4-10. 모답형 문장 정리

| 쟁점 | 모답형 문장 |
|------|----------|
| 물권적 청구권 의의 | "물권적 청구권이란, 물권의 내용의 실현이 전면적 또는 부분적으로 방해당하고 있거나 방해당할 위험이 있는 경우, 물권자가 방해자에 대하여 물건의 반환, 방해제거, 방해예방을 청구할 수 있는 권리를 말한다." |
| 법적 성질 | "물권적 청구권의 법적 성질에 관하여 물권설·채권설·절충설의 대립이 있으나, 판례는 물권적 청구권은 물권의 효력으로부터 발생하며 채권적 청구권은 아니라 하여 **절충설**의 입장을 따르고 있다." |
| 소멸시효 | "물권적 청구권의 소멸시효 적용 여부에 관하여 부정설(다수설)과 일부 긍정설의 대립이 있으나, 판례는 소유권에 기한 물권적 청구권은 소멸시효의 적용을 받지 아니한다고 한다." |
| 비용부담 | "물권적 청구권의 비용부담에 관하여 적극적 행위청구권설(다수설)과 인용청구권설의 대립이 있으나, 판례도 물권적 청구권이 적극적 행위청구권의 성질을 가지므로 그 비용은 상대방이 부담한다는 취지이다." |
| 전보배상 부정 | "물권적 청구권은 물권에 부종하는 특수한 청구권이므로, 그 이행불능을 이유로 §390에 기한 전보배상청구권은 인정되지 아니한다 (판례)." |
| 불가분성 | "물권적 청구권은 물권의 효력으로부터 발생하는 권리이므로 물권과 운명을 같이하고, 물권과 분리하여 독립 양도할 수 없다." |
| 권리남용 (배타적 사용수익 포기) | "토지 소유자가 그 소유 토지를 일반 공중을 위한 용도로 제공하여 배타적 사용수익권을 포기한 것으로 볼 수 있는 경우, 타인의 점유사용으로 인해 토지 소유자에게 손해가 생긴다고 볼 수 없으므로, 인도청구 및 부당이득반환청구가 허용되지 아니한다 (판례)." |
| 퇴거 청구 불가 | "토지 소유자는 건물 철거/대지 인도만 청구할 수 있을 뿐, 자기 소유 건물을 점유하는 자에게 건물 퇴거를 청구할 수 없다 (판례)." |
| 점유 상호침탈 | "점유의 상호침탈 시 최초 침탈자의 점유회수청구권에 관하여 부정설(다수설)과 긍정설(이영준)의 대립이 있으나, 판례는 상대방의 점유회수청구를 인정하는 것이 무용하므로 상대방은 §204①에 따른 점유의 회수를 청구할 수 없다고 한다." |
