# 민법3 기출 풀이 논거 흐름

> 관련: [[민법3_전경운_중간_정리노트]], [[민법3_압축본]], [[목차_민법물권]]
> 독법: 누가 누구에게 무엇을 청구? -> 조문 -> 요건 포섭 -> 항변 -> 재항변 -> 결론

---

## 풀이 프레임: 민법 사례형 기본 구조

```
1. 청구권기초 특정 (누가 누구에게 무엇을 청구?)
2. 청구 요건 검토 (조문 -> 요건 분해 -> 사안 포섭)
3. 항변 검토 (상대방의 방어 수단)
4. 재항변 검토 (항변에 대한 재반박)
5. 결론
```

> **세트 쟁점 자동 검토 규칙**[^세트]
> - [[물권적_청구권]] -> 부당이득(§741) + 과실수취권(§201)
> - [[중간생략등기]] -> 토지거래허가(국토법) + 등기청구권 양도성
> - [[선의취득]] -> 도품유실물(§250/§251) + 점유개정 부정
> - [[취득시효]] -> 자주점유 추정(§197) + 제3자 처분 + 재기산

### 2025 제1문 [25점] -- 물권적 청구권 + 권리남용 + 부당이득 + 상속

**사안**: 갑이 도로로 제공한 토지 -> 갑 사망 -> 상속인 을이 점유자에 대해 인도 청구[^25-1소스]

#### 청구 1: 을의 점유자에 대한 소유물반환청구 (§213)

| 단계 | 논점 | 판례/조문 | 결론 |
|------|------|-----------|------|
| 요건 1 | 을의 소유권 | 상속(§1005) | O |
| 요건 2 | 상대방의 점유 | -- | O |
| 요건 3 | 점유 권원 없음 | §213 단서 | -> 항변 검토 |

#### 항변: 배타적 사용수익권 포기

> **쟁점**: 갑이 도로로 제공 = 배타적 사용수익권 포기인가?
> - [[물권적_청구권]] 참조
> - 대판(전합) 2019.1.24, **2016다264556**: "토지 소유자가 그 소유의 토지를 도로 부지 등으로 무상 제공하여 인근 주민이나 일반 공중의 통행에 이용하게 한 경우, 특별한 사정이 없는 한 그 토지에 대한 **독점적이고 배타적인 사용수익권을 포기**한 것"[^25-1a]
> - **상속인에게도 효력**: 포기의 효력이 상속인(특정승계인 포함)에게도 미친다(판례)[^25-1b]

**결론**: 항변 인정 -> 을의 §213 청구 **기각**

#### 청구 2: 부당이득반환청구 (§741)

> **쟁점**: 인도 불가 시 사용이익의 부당이득반환 가능?
> - 대판 2022.12.29, **2019다272275**: 인과관계 부정 -> 부당이득 불성립[^25-1c]

**결론**: §741 청구도 **기각**

#### 답안 뼈대

1. "을은 상속(§1005)에 의해 X토지의 소유자이므로, 점유자에 대해 §213 반환 청구 가능"
2. "그러나 갑이 도로 부지 등으로 무상 제공하여 일반 공중의 통행에 이용 → **독점적이고 배타적인 사용수익권을 포기**한 것(전합 2016다264556) → 상속인 을에게도 효력 미침"
3. "부당이득(§741) 검토: 사용이익 반환 → 인과관계 부정(2019다272275) → 불성립"

### 2025 제2문 [40점] -- 중간생략등기 + 토지거래허가 + 진정명의회복등기 + 등기청구권 양도

**사안**: 갑->을->병 순차매매. 병이 갑에게 직접 이전등기 청구[^25-2소스]

#### 청구 1: 병의 갑에 대한 중간생략등기이행청구

| 단계 | 논점 | 판례/조문 | 결론 |
|------|------|-----------|------|
| 요건 1 | 갑->을, 을->병 순차매매 | -- | O |
| 요건 2 | 3자(갑.을.병) 합의 | 합의조건부유효설(판례) | ? |
| 요건 3 | 토지거래허가 | 국토법: 효력규정 | ? |

> **쟁점 1 -- 3자 합의 존부**: [[중간생략등기]] 참조
> - 대판(전합) 1999.3.18, **98다32175**: "명시적.묵시적.순차적 합의 모두 가능"[^25-2a]
> - 합의 인정 시 적극적 중간생략등기이행청구권 성립

> **쟁점 2 -- 토지거래허가구역**:
> - 대판 **96다22464**: "각 매매마다 허가 필요, 허가 없으면 확정적 무효"(효력규정)[^25-2b]
> - 갑-을 간 허가 + 을-병 간 허가 각각 확인 -> 하나라도 흠결 시 등기 무효

#### 청구 2: 진정명의회복등기 (§214 유추)

> 무효등기 말소 대신 직접 이전등기를 구하는 방법
> - 판례: §214 방해배제청구 유추 -> 진정명의회복등기 가능[^25-2c]

#### 쟁점 3: 등기청구권 양도성 — 부정(판례)

> 을이 병에게 등기청구권 양도 → 병이 갑에게 직접 청구 가능?
> - 대판 2001.10.9, **2000다51216**: "매매로 인한 소유권이전등기청구권은 그 권리의 **성질상 양도가 제한**되고, 그 양도에 채무자의 **동의나 승낙**을 요한다. 통지만으로는 대항력이 생기지 않는다"[^25-2d]
> - **양도 제한 근거**: 이행과정에 특별한 **신뢰관계** 수반 → §449① 단서(성질에 의한 제한)
> - **동의/승낙 = 대항요건**(성립요건 아님): 동의 없으면 양도 자체 무효는 아니나 갑에 대한 **대항력 불발생** → 병의 직접 청구 **불가**
> - [[등기청구권]] 참조

#### 답안 뼈대

1. "병은 갑에 대해 적극적 중간생략등기이행청구: 3자 합의 존부(전합 98다32175)"
2. "토지거래허가구역 -> 각 매매마다 허가 필수(효력규정, 96다22464) -> 무허가 매매는 확정적 무효"
3. "등기 무효 시 진정명의회복등기(§214 유추) 가능"
4. "등기청구권 양도: 성질상 제한, 채무자 동의 필요(2000다51216)"

### 2025 제3문 [35점] -- 물권변동시점 + 유인성 + 무권리자처분 + 등기부취득시효 + 상호침탈

**사안**: 3개 소문항. 물권변동 시점, 착오취소 후 물권 복귀, 무권리자 처분과 부당이득, 점유의 상호침탈[^25-3소스]

#### 3-1 [15점]: 물권변동시점 + 착오취소 -> 물권복귀

| 단계 | 논점 | 결론 |
|------|------|------|
| 물권변동 시점 | §186: 등기 시 물권변동 발생 | 매매계약일 아닌 등기일 기준 |
| 착오취소(§109) | 유인성: 원인행위(매매) 취소 -> 물권행위도 효력 상실 | 물권 당연복귀 |
| 등기 처리 | 말소등기 필요 (형식적 부합 회복) | -- |

> **모답**: "물권변동은 등기 시 발생(§186). 매매가 착오(§109)로 취소되면, 유인성에 의해 물권행위도 효력 상실 -> 물권은 당연히 복귀하나, 형식적 부합을 위해 말소등기가 필요하다."

#### 3-2 [10점]: 무권리자 처분 + 등기부취득시효 + 부당이득

| 단계 | 논점 | 판례/조문 | 결론 |
|------|------|-----------|------|
| 무권리자 처분 | 병이 무권리 상태에서 매도 | -- | 매도 무효 |
| 등기부취득시효 | §245 2.: 10년 + 등기 + 선의.무과실 | [[취득시효]] | 요건 충족 시 취득 |
| 부당이득 | 대금 반환: 인과관계 부정 | 대판 **2019다272275** | 부당이득 불성립 |

#### 3-3 [10점]: 점유의 상호침탈

| 단계 | 논점 | 판례 | 결론 |
|------|------|------|------|
| 갑이 을로부터 침탈 | §204 1. 점유회수청구 | -- | 갑 = 최초 피침탈자 |
| 을이 갑으로부터 탈환 | 상호침탈: 최초 침탈자의 §204 청구? | 대판 2023.8.18, **2022다269675** | **부정** |

> **모답**: "점유를 침탈당한 자가 상대방으로부터 탈환한 경우, 상대방(최초 침탈자)은 §204에 기한 점유회수청구를 할 수 없다(2022다269675). 무용한 순환 방지 취지."

### 2022 제1문 [50점] -- 물권적 청구권 + 부당이득 + 과실수취권 + 필요비상환

**사안**: 갑 소유 X건물을 을이 무단점유. 갑이 반환 + 사용이익 청구[^22-1소스]

#### 청구 1: §213 소유물반환

| 단계 | 논점 | 결론 |
|------|------|------|
| 요건 | 갑 소유 + 을 무단점유 + 점유 권원 없음 | 전부 인정 |
| 결론 | 반환 청구 **인용** | |

#### 청구 2: §741 부당이득 (사용이익) — 선악의 분기

**공방 2열 구조**:

| **원고 (갑·소유자)** | **피고 (을·점유자)** |
|---|---|
| §741 사용이익 부당이득반환 | — |
| — | §201① 선의점유자 과실취득 항변 |
| §197② 소 제기 시부터 악의 전환 → 이후 수익 반환(§201②) | — |
| §201① 특칙 범위 밖 부당이득(§748②) | §201①이 §748①의 **특칙** → 선의 범위 부당이득 불성립 |

- **판례**(94다27069): §201①의 선의란 **본권 오신** + **오신할 만한 정당한 이유**(무과실) 필요
- **판례**(95다44290): 선의 점유자는 법률상 원인 없이 타인 건물 점유·사용해도 이득 **반환 불요**
- **결론**: 악의 → §748② 전부 반환 / 선의(무과실) → §201① 과실취득 → 부당이득 X

#### 청구 3 (반소): 을의 §203 필요비상환 + §320 유치권

| 단계 | 논점 | 결론 |
|------|------|------|
| 을이 건물 수선 | §203①: 필요비 상환 청구(선악의 **불문**) | O |
| 유치권 | §320①: "물건에 관하여 생긴 채권" | 반환 거부 가능 |
| 기간허여 | §203② 후문: 법원의 상당 기간 부여 → §320② 유치권 제한 | 갑 신청 시 |

#### 답안 뼈대

1. "갑은 소유권자(§211)로서 무단점유자 을에 대해 §213 반환 청구 → **인용**"
2. "사용이익: 을이 본권 오신에 정당한 이유 있는 **선의점유자**(94다27069)이면 §201① 과실취득 → 부당이득 X(95다44290). **악의** 점유자이면 §748② 전부 반환"
3. "을의 방어: §203 필요비상환(선악의 불문) + §320 유치권 행사로 반환 거부. 다만 갑의 기간허여 신청 시 유치권 제한"

### 2021 제2문 [45점] -- 이중 점유개정 + 선의취득 + 도품유실물

**사안**: 갑이 동산을 을에게 점유개정으로 양도 -> 같은 동산을 병에게도 점유개정으로 양도[^21-2소스]

| 단계 | 논점 | 결론 |
|------|------|------|
| 제1양도(갑->을) | 점유개정(§189) = 인도 | 을이 소유권 취득 |
| 제2양도(갑->병) | 갑은 이미 무권리자 | 병은 원칙적으로 취득 불가 |

#### 쟁점 2: 병의 선의취득 (§249)

| 요건 | 포섭 | 결론 |
|------|------|------|
| 동산 | O | |
| 유효한 거래행위 | O | |
| 무권리자가 점유 | O (갑이 현실점유) | |
| 선의.무과실 | 양수인 입증 필요 | ? |
| **인도** | **점유개정에 의한 선의취득 -> 부정(판례 77다1872)** | **X** |

> 병이 현실인도를 받은 경우라면 -> 선의취득 가능[^21-2a]

#### 쟁점 3: 도품.유실물 (§250/§251)

| 조건 | 효과 |
|------|------|

#### 답안 뼈대

1. "갑->을 점유개정 = 인도(§189) -> 을 소유권 취득. 갑->병은 무권리자 양도"
2. "병의 선의취득(§249): 점유개정에 의한 선의취득 부정(77다1872). 현실인도 받아야 가능"
3. "갑이 절도범이면 §250 도품유실물 -> 2년 내 원소유자 회복 가능"

## B. 사례집 (송영곤 민사법사례연습2 물권법편)

### 사례집 1: 종물이론 + 지상권 + 물권적 청구권 [p.2~4]

**사안**: 갑이 을 소유 대지에 지상권 설정 후 X건물 신축 -> 저당권 설정 -> 경매 -> 병이 경락 -> 병이 정에게 매각 -> 을이 정에게 건물철거+대지인도 청구[^사례1]

#### 풀이 흐름

| 단계 | 논점 | 조문/판례 | 결론 |
|------|------|-----------|------|
| 을의 청구 | §213+§214: 대지인도+건물철거 | -- | 요건 충족 |
| 정의 항변: 지상권 | 병이 경매로 지상권 취득? | 종물이론(§100 2. 유추, §358) | O: 저당권+종된 권리 |
| 병->정 양도 시 | 지상권도 함께 양도? | §100 2. 유추(95다52864) | O: 다만 등기 필요(§186) |
| 지상권 이전등기 | 정이 미등기 | 84다카1131(전합) | **정은 지상권 미취득** |
| 을의 철거 가능? | 지상권 취득 가능한 지위 | 84다카1131 취지 | **철거 부정** (신의칙) |

> **핵심**: 경매에서 종된 권리(지상권)는 법률규정에 의한 취득(§187) -> 등기 불요. 그러나 병->정 양도는 법률행위(§186) -> 지상권 이전등기 필요. 미등기라도 철거 청구는 신의칙상 부정.

### 사례집 2: 미등기 부동산 보존등기 + 원인무효 + §214 [p.4~6]

**사안**: A(도급인)가 B(수급인) 명의로 건축허가 -> B가 자기 명의 보존등기 -> B의 채권자 C가 가압류 -> A가 B에게 보존등기 말소, 대한민국에게 소유권확인, C에게 가압류말소 청구[^사례2]

#### 풀이 흐름

| 청구 | 논점 | 결론 |
|------|------|------|
| A->B: 보존등기 말소 | 건물 소유권 원시 귀속: 당사자 합의 기준 -> A에게 귀속(§187) | B 등기는 원인무효 -> §214 말소 **인용** |
| A->대한민국: 소유권확인 | 등기명의인 상대 판결로 보존등기 가능(95다14817) | 확인이익 없음 -> **각하** |
| A->C: 가압류말소 | B 등기 말소 시 가압류도 당연 말소? | C는 무효등기 기초 가압류 -> **인용** |

> **핵심**: 도급인-수급인 간 건물소유권 귀속 = 합의 기준. 건축허가명의 =/= 소유권. 무효등기 기초 가압류는 효력 없음.

---

### 사례집 3: 선의취득 + 양도담보 + 도품 [p.17~19]

**사안**: X회사 총무과장 갑이 양도각서를 무단 작성하여 프레스 기계(병은행 양도담보 설정)를 을에게 매각, 을이 정에게 전매. 소유권 귀속 확정.[^사례3]

#### 풀이 흐름

| 단계 | 논점 | 조문/판례 | 결론 |
|------|------|-----------|------|
| 소유권 귀속 | 양도담보 -> 소유권은 병은행(신탁적 양도설) | -- | 병은행 = 소유자 |
| 을의 선의취득 | §249 요건: 선의.무과실 | 인도시 과실 O | **부정** |
| 정의 선의취득 | §249 요건: 을 창고에서 매수 | 선의.무과실 O, 현실인도 O | **긍정** |
| 도품 해당성 | 갑 = 점유보조자의 횡령 | §250: 직접점유자 의사 기준 | **도품 부정** |
| 최종 | | | **정이 소유권 취득** |

> **핵심**: 선의취득에서 "무과실"은 추정되지 않으므로 양수인이 입증. 점유보조자가 처분한 경우 = 직접점유자 의사에 의한 처분이므로 도품 아님.

### 사례집 4: 3자간 명의신탁 + 대위행사 + 부당이득 [p.121~123]

**사안**: 갑이 병에게서 X토지 매수 후 1/2지분을 동생 을 명의로 등기(3자간 명의신탁). X2토지가 LH에 수용. 갑이 을 상대 말소 + 병 상대 이전등기, 보상금 반환 청구.[^사례4]

#### 풀이 흐름

| 단계 | 논점 | 조문/판례 | 결론 |
|------|------|-----------|------|
| 명의신탁 유형 | 3자간 명의신탁(중간생략등기형) | 실명법 §4 | 약정 무효(§4-1) |
| 물권변동 | §4-2 본문: 물권변동도 무효 | -- | 소유권은 병에게 |
| 갑의 구제 | 병의 을에 대한 말소청구권을 채권자대위(§404) | -- | 을 등기 말소 |
| 갑->병 | 매매계약에 기한 이전등기 청구 | §568 1. | O |
| 시효 문제 | 갑이 계속 점유 -> 시효 불진행 | [[등기청구권]] | 시효 미완성 |
| 수용보상금 | 실명법 §4-3: LH 유효취득 | -- | 을에게 부당이득반환 청구 |

> **핵심**: 3자간 명의신탁은 약정+물권변동 모두 무효 -> 소유권은 매도인(병)에게 -> 신탁자(갑)는 대위행사로 우회. [[중간생략등기]]와 구별: 여기서는 실명법 위반이 핵심.
