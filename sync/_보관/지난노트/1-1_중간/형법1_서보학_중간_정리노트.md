##### 위전착 — 주관적·객관적 요소 처리 비교

| 학설 | 주관적 요소 (고의·위법성인식) | 객관적 요소 (정당화상황) | 결론 |
|---|---|---|---|
| 엄격고의설 | 위법성인식 = 고의의 일부 → 고의 조각 | — | 과실범 |
| 소극적 구성요건표지이론 | 소극적 구성요건에 대한 고의 → 조각 | 정당화사유 = 객관적 구성요건표지(소극적) | 과실범 |
| 엄격책임설 | 고의 유지, 위법성인식 = 별도 책임요소 | — | 정당이유 유무로 분기 |
| 법효과제한적 책임설(다수설) | 불법고의 유지 + 책임고의 조각 | — | 과실범 |
| 유추적용설(교수님) | 고의 자체 조각 (§13 유추) | — | 과실범 |
| 판례(독자이론) | 고의 유지 | 정당이유 있으면 위법성 자체 조각 | 정당이유 없으면 고의범 |

- 엄격고의설·제한고의설 비판: 위법성인식을 고의에 포함시키면 구성요건적 착오와 금지착오의 구별이 무의미해지고 현행 체계와 맞지 않는다.
- 소극적 구성요건표지이론 비판: 구성요건과 위법성의 단계적 구별이 해소되어 범죄론 체계가 붕괴된다.
- 엄격책임설(판례) 비판: 사실오인의 외형을 무시하고 금지착오와 동일하게 처리하면, 정당이유 없는 경우 고의범 처벌이라는 가혹한 결론에 이른다.
- 유추적용설(교수님)은 불법고의 자체를 조각하므로, 법효과제한적 책임설(불법고의 인정+책임고의 조각)보다 체계적으로 명쾌하다. 양 설 결론은 동일(과실범).

### 답안 운용 전략

- **위전착([[오상방위]]):** 판례(엄격책임설)는 **정당한 이유 없으면 고의범** 처벌, **교수님**(유추적용 제한책임설)은 **과실범 처벌** → 결론이 다름. 시험에서는 판례(엄격책임설) + 홍형철·다수설(법효과제한/유추적용) + 교수님 순서로 서술하되, 교수님설 및 다수설로 결론 도출.
- **구체적부합설(교수님) vs 법정적부합설(판례)**: [[방법의 착오]] 한계사례에서 결론이 다름. 교수님 설 먼저 서술 → 판례 입장 비교 → 답안에서 사안 포섭.
- **객관적귀속이론:** 보충적 기재. 인과관계는 상당인과관계설(판례)로 먼저 검토 → 중간개입사정 있으면 객관적귀속으로 보충.
- **김보양 사건:** [[정당방위]] 부정 → "**긴급피난을 별도 검토할 수 있는지 문제**된다"는 쟁점 제기 가능.

→ 과잉방위(§21②): 야간·공포·경악 → 벌하지 아니할 수 있다(임의적 감면)
→ [[오상방위]](§12): 침해의 정도를 오인했다면 → 오상과잉방위
→ 처리: [[오상방위]](위전착) + 과잉방위(§21②) 중첩 적용 문제

**[서보학 사례집] [[긴급피난]] 유형 비교 (공격적·방어적·예방적)**
자연재해로 인한 피난 / 가해자에 대한 반격 / 장래 위험 대비
→ 공격적 [[긴급피난]]: 무관한 제3자에게 위난 전가 → 균형성 엄격(본질적 우월)
→ 방어적 [[긴급피난]]: 위난유발자에 대한 반격 → 균형성 완화(열등하지 않으면 족함)
→ 예방적 [[긴급피난]]: 현재성 확장 문제 → 원칙상 공격적 기준 적용

### §21 조문 원문

### 과잉방위의 질적/양적 구별 [김성돈]

```
    방위
    강도
    (Y)
     ^
     |         ■■■■■■■■  ← 실제 방위 강도
  상당성       ■■■■■■■■
  기준선 ──── ■■■■■■
     |■■■■■■
     |──────────────────────────────────→ 시간(X)
         침해  침해    침해   침해
         시작  계속    계속   종료

[질적 과잉방위] Y축이 상당성 기준선(─)을 초과한 영역
               → 방위 강도 자체가 과도 (§21②③ 적용 가능)

[양적 과잉방위] X축이 '침해 종료' 이후 구간에서도 반격 계속
               → 현재성 결여 → 원칙적으로 정당방위 자체 부정
               예외: 침해 종료 직후 극히 짧은 시간 내 연속된
                     일련의 행위라면 과잉방위로 인정 가능
```

| 유형 | 내용 | 과잉방위 인정 |
|---|---|---|
| **질적 과잉방위** | 방위행위의 강도가 상당성 초과 (예: 주먹→쇠뭉치) | 인정 (§21②) |
| **양적 과잉방위** | 시간적 범위 초과 — 침해 종료 후에도 계속 반격 | 원칙 부정 (현재성 결여) |

- 예외: 제2의 폭행이 공포·흥분 등 심리적 긴장상태에서 제1의 폭행에 연속된 일련의 행위라면 전체를 과잉방위로 인정 가능(김성돈위법p64-65)

|---|---|---|
| **의도적 도발** | **부정** | 정당방위상황 결여 / 방위의사 결여 / 상당한 이유 불충족 |
| **비의도적 도발** | **단계적 판단** | 회피→수비적 방어→공격적 방어 순서를 거쳐야 |

### 모답형 — 정당방위

> **[조문]** §21①에 의하면 자기 또는 타인의 법익에 대한 현재의 부당한 침해를 방위하기 위한 행위는 상당한 이유가 있는 때에는 벌하지 아니한다.
>
> **[판례]** 현재성은 공격이 직접 임박했거나 막 시작되었거나 아직 계속되는 때 인정된다([[2020도6874]]). 보충성은 직접 요구되지 않으나, 사회윤리적 제한에 의해 극단적 불균형 시 상당성이 부정된다.
>
> **[포섭·결론]** 사안에서 현재의 부당한 침해가 존재하고 방위행위의 상당성이 인정되면 위법성이 조각된다.

### 사례형 답안 연습

#### [사례 6] 정당방위 + 과잉방위 + 부작위방조 

> 병은 양부 A가 성폭행하려고 하자, 너무 놀라 A를 밀어 넘어뜨린 뒤, 기절한 A의 목을 졸라 살해하였다. 부인 정은 그 과정을 알았으나 모른 체하였다.

**풀이**

I. 병의 죄책
1. 존속살해죄 구성요건 충족 (양부 떠밈+목 조름 → 포괄하여 일죄)
2. [[정당방위]]: 떠밈=현재 부당한 침해+상당성 → 정당방위 성립. 단 기절 후 목 조름=현재성 결여
3. 과잉방위(양적): 원칙 부정이나, 극히 짧은 시간 내 연속적 행위→일련의 과잉방위 인정
4. §21③: 야간+성폭행 위협→공포·흥분 → 벌하지 않는다 → 책임 조각

II. 정의 죄책
1. 보증인지위: 민법상 배우자 → 인정
2. 방조범설(판례): 작위의무 위반+작위정범 방치 → 존속살해방조죄

### 김성돈 교차검증 보강 — 위법성 영역 (정당방위 관련)

5. **정당방위와 긴급피난의 '상당한 이유' 차이**: [[정당방위]]=법확정의 원리(불법은 법에 양보할 필요 없음 → 보충성·균형성 완화), [[긴급피난]]=우월한 이익의 원칙(보충성·균형성 엄격).(김성돈위법p54)

9. **의도적 도발자의 [[정당방위]] 부정 근거**: ① 정당방위상황 결여 → 위법성 불조각, ② 상당한 이유 불충족 → 과잉방위 형 감면 가능, ③ 방위의사 결여 → 미수범 처벌. 근거에 따라 법효과가 달라진다.(김성돈위법p61-62)

| 쟁점 | 정리 | 원칙·예외 |

### 모답형 — 정당방위·긴급피난

> **[조문]** §21①에 의하면 **현재**의 **부당한 침해**를 **방위하기 위한 행위**는 **상당한 이유**가 있는 때에는 벌하지 아니한다. §22①에 의하면 현재의 위난을 피하기 위한 행위는 상당한 이유가 있는 때에는 벌하지 아니한다.
>
> **[판례]** 긴급피난은 정당방위와 달리 보충성(최후의 수단)과 법익균형이 엄격하게 요구된다. 정당방위에 대한 정당방위는 인정되지 않으므로, 상대방 반격이 문제되면 [[긴급피난]] 구조로 넘어간다. 이분설(다수설·교수님[서보학 형법총론])에 따르면 보호법익 우월이면 [[위법성조각]], 동가치이면 책임조각이다.
>
> **[포섭·결론]** 사안에서는 먼저 §21 정당방위의 현재성·부당성·상당성을 검토하고, 부정되면 §22 긴급피난의 보충성·법익균형을 순서대로 검토한다. 정당방위의 현재성은 침해가 직접 임박하거나 계속되는 경우에 인정되고, 긴급피난은 '위난'이라는 보다 넓은 개념을 사용하므로 계속적 위험상태 존속 시 현재성이 인정될 수 있다.

> **같이 볼 사항**: 법정적부합설(판례) vs 구체적부합설(교수님) 결론 차이 · [[개괄적 고의]](§7) · [[오상방위]]=위전착(§12)과 구별

### §15 조문 원문

> **제15조(사실의 착오)** ① 특별히 중한 죄가 되는 사실을 인식하지 못한 행위는 중한 죄로 벌하지 아니한다.
> ② 결과적으로 중한 죄에 해당하는 행위가 그 중한 결과에 대하여 예견할 수 없었을 때에는 중한 죄로 벌하지 아니한다.

### §13·§14·§15 조문 적용 관계

| 조문 | 원문 핵심 | 적용 |
|---|---|---|
| **§13** | 구성요건사실 미인식 → 고의 조각 | 과실범 규정 있으면 과실범 검토 |
| **§14** | 주의의무 태만 + 개별규정 필요 | 과실범 처벌의 일반원칙 |
| **§15①** | 특별히 중한 사실 미인식 → 중한 죄 불벌 | 추상적 착오(경→중): 경한 죄 한도 |
| **§15②** | 중한 결과 예견 불가 → 중한 죄 불벌 | 결과적 가중범의 제한 |

- **핵심**: §13·§15로 먼저 해결 → 안 되는 **한계사례**에서만 학설(법정적/구체적 부합설) 검토(분리정리 L100-106)

### 착오 분류 체계

| 분류 | 유형 | 내용 | 비고 |
|---|---|---|---|
| **구체적 사실의 착오** | 객체의 착오 | A를 B로 오인하여 B에게 결과 발생 | 학설 결론 동일 (쟁점 X) |
| | **방법의 착오** | A 노렸는데 빗나가 B에게 결과 발생 | **핵심 쟁점 ★★★** |
| **추상적 사실의 착오** | 경→중 (§15① 적용) | 경한 죄 고의 → 중한 결과 발생 | §15① 경한 죄 한도 처벌 |
| | 중→경 | 중한 죄 고의 → 경한 결과 발생 | 경한 죄 기수 |

### 구체적 사실의 착오 — 학설별 결론 비교

| 사례 | 구체적 부합설 | 법정적 부합설 (판례) |
|---|---|---|
| **객체의 착오**: A를 B로 오인하여 B 살해 | 살인기수 — **B에 대한 고의가 처음부터 존재** (B를 A로 오인했을 뿐 실제 공격 대상은 B → B에 대한 고의 인정. "고의 전용"이 아님) | 살인기수 |
| **방법의 착오**: A 노렸는데 빗나가 B 사망 | A 살인미수 + B 과실치사 (상상적 경합) | **B에 대한 살인기수** — 동일 구성요건 내이므로 고의 인정 |

> **[[객체의 착오]]**: 양 설 모두 살인기수. 구체적 부합설에서는 "고의 전용"이 아니라 **실제 공격한 B에 대한 고의가 처음부터 있는 것**으로 봄 (인식 객체 A와 실제 객체 B가 구성요건적으로 동가치 → 고의의 객체 특정에 영향 없음).
> **방법의 착오가 핵심 쟁점** — 여기서만 학설 간 결론이 갈림.

### 부합설 3종 비교표 (구체적 설명)

| 비교축 | 구체적 부합설 | 법정적 부합설 (판례) | 추상적 부합설 |
|---|---|---|---|
| **기준** | 인식한 **구체적 객체**와 결과 발생 객체 일치해야 고의 인정 | **동일 구성요건** 범위 내이면 고의 인정 | 구성요건 달라도 범죄사실 인식 있으면 고의 인정 |
| **객체 착오** | 고의 인정 (실제 공격 대상에 대한 고의가 처음부터 존재) | 고의 인정 | 고의 인정 |
| **방법 착오** | A 살인미수 + B 과실치사 (상상적 경합) | B에 대한 **살인기수** (동일 구성요건 내 고의 인정) | B에 대한 고의범 인정 |
| **논거** | 고의는 특정 객체에 대한 구체적 의사 → 빗나간 B에 대해 고의 불인정 | 고의는 구성요건 단위로 추상화하면 족함 → 동일 구성요건 내이면 고의 인정 | 범죄의사 자체를 넓게 봄 (현재 지지 X) |
| **비판** | 방법 착오에서 미수+과실 경합은 형량 높을 수 있음 | 행위자의 구체적 의사를 무시한다는 비판 | 고의 범위 지나치게 확대 |
| **답안 전략** | 판례 대비용 간략히 | **판례·다수설** — 답안 기본축 | 불필요 |

#### 검토 — 구체적 부합설 논거 상세

1. **행위자 의사의 개체적 특정성(고의의 개별화)**: 고의는 특정 객체에 대한 구체적 의사 → 노린 A가 아닌 빗나간 B에 대해 고의를 인정하는 것은 행위자의 실제 의사를 무시. (※ 객체의 착오는 실제 공격 대상에 대한 고의가 처음부터 있으므로 문제되지 않음 — **방법의 착오에서만 쟁점**)
2. **법적 안정성·예견가능성**: 미수(A)+과실치사(B) 상상적 경합으로 처리 → 인식 가능한 범위 내에서만 책임 → 비례원칙에 부합.
3. **비례원칙 측면**: 법정적 부합설은 동일 구성요건 내에서 자동으로 빗나간 결과에 고의를 인정 → 기수범 긍정 → 처벌범위 지나치게 확장.
4. **판례(법정적 부합설) 근거와 대비**: 판례(대판 1984.1.24, [[83도2813]])는 "갑을 살해할 목적으로 총을 발사하여 목적하지 아니한 을에게 명중되어 을이 사망한 경우에 을에 대한 살인의 고의가 있는 것"이라고 판시. 교수님 설은 고의는 구성요건 단위로 추상화될 수 없고 개별 객체에 대한 구체적 인식이 요건이라고 반박.

#### 학설 (판례 vs 다수설 vs 교수님 설)

| 비교축 | 판례 | 다수설 | 교수님 설 (서보학) |
|---|---|---|---|
| **기본 입장** | 법정적 부합설 | 법정적 부합설과 결론 동일 | **구체적부합설** [서보학 형법총론] |
| **객체 착오** | 살인기수 | 살인기수 | 살인기수 (실제 공격 대상에 대한 고의 — 양 설 동일) |
| **방법 착오** | B 살인기수 (83도2813) | 동일 | A 살인미수 + B 과실치사 (상상적 경합) |
| **논거** | 동일 구성요건 내이면 고의 인정 | — | 고의는 특정 객체에 대한 구체적 의사 → 빗나간 B에 고의 불인정 |

### 모답형 — 구성요건적 착오

> **[판례]** 판례는 법정적 부합설에 따라, 방법의 착오에서 행위자가 인식한 객체(A)와 실제 피격된 객체(B)가 동일한 구성요건 범위 내에 있으면 B에 대한 고의를 인정하여 B에 대한 살인기수가 성립한다고 본다.
>
> **[교수님설(서보학)]** 서보학은 구체적 부합설을 지지한다. 방법의 착오의 경우 행위자의 고의는 구체적으로 특정된 A에 대해서만 성립하므로, A에 대한 살인미수와 B에 대한 과실치사가 상상적 경합으로 성립한다 → 결론: **판례(법정적 부합설, B 살인기수)와 결론이 다름.** 답안에서 반드시 학설간 결론 차이를 명시할 것.
>
> **[포섭·결론]** [[방법의 착오]] 사안에서 판례를 따르면 B에 대한 고의범 기수, 서보학(구체적 부합설)을 따르면 A 살인미수+B 과실치사(상상적 경합). 채택하는 학설에 따라 결론이 달라지므로 학설 채택 이유를 명시한다.

### 사례문제 [서보학 기출 2025]

> 갑이 을을 살해하려고 독이 든 건강식품을 보냈으나, 을과 아들 A가 함께 먹어 중상해를 입었다. A는 치료 중 의사 경고를 어기고 사망하였다.

**풀이**: ① 을에 대한 살인미수(확정적 고의+결과 미발생) ② A에 대한 죄책: [[방법의 착오]] → 법정적 부합설(판례)=A에 대한 살인기수, 구체적 부합설=A에 대한 과실치사+을 살인미수 ③ A의 치료 거부: 피해자의 부주의만으로는 인과관계 단절 부정(판례)

### 사례형 답안 연습

#### [사례 3] 구성요건적 착오 — 객체의 착오

> 병이 C를 B로 오인해 C를 살해한 경우, 병의 죄책이 문제된다.

**풀이**

I. 논점: 구체적 사실의 [[객체의 착오]]

II. 학설
1. **구체적 부합설**: 인식사실(B 살해)과 발생사실(C 사망)이 **구체적으로 일치**하는 경우에만 고의 인정. 객체의 착오의 경우 고의 전용되어 C에 대한 살인기수.
2. **법정적 부합설**(판례): 동일 구성요건(살인) 내이므로 고의 전용 인정. C에 대한 살인기수.

III. 결론: 어느 학설에 따르더라도 C에 대한 살인기수. B에 대해서는 아무런 죄책 없음.

#### [사례 5] 가감적 구성요건요소에 관한 착오 + 부진정부작위범

> 갑의 장인 F는 말기암 환자로, 갑에게 죽음을 애원하였다. 갑은 아내 을과 함께 병원에 가서, F의 산소호흡기 코드를 뽑으려다 실수로 옆 병상의 환자 X의 코드를 뽑아 X가 사망하였다.

**풀이**

I. **갑의 X에 대한 죄책**
1. 가중적 구성요건 착오: 일반살인에 대한 고의가 없으므로 §15① 적용 → 경한 죄인 촉탁살인 범위에서 고의 전용
2. [[방법의 착오]]: 법정적 부합설 → 촉탁살인기수. 구체적 부합설 → **과실치사+촉탁살인미수 상경**
3. 판례: X에 대한 촉탁살인죄

II. **을의 죄책** — 부진정부작위범
1. 보증인지위: 민법상 F의 친족 → 어느 학설에 따르더라도 인정
2. 정범/공범 구별: 판례(방조범설) → 촉탁살인방조죄 (구체적 부합설이면 과실치사든 살인미수든 방조 X)
3. X에 대해: 작위의무 인정 불가 → 죄책 없음

III. 결론: 갑=X에 대한 촉탁살인죄, 을=F에 대한 촉탁살인방조미수죄

| 비교축         | 판례 (엄격책임설적·독자이론)      | 다수설 (법효과제한책임설)         | 교수님 (유추적용설)                                 |
| ----------- | ------------------- | ---------------------- | ------------------------------------------- |
| **오상방위 처리** | "정당이유 있으면 **위법성** 조각"(68도370) | 구성요건적 고의 인정 + 법적 효과 제한 | **유추적용 제한책임설** — §13 유추, 고의범 성립 조각 후 과실범 처벌 |

- **판례** — 정당이유 없으면 고의범. 정당이유 있으면 **위법성 조각**(적법).
- **엄격책임설과 판례의 차이**(정당이유 O일 때): 엄격책임설 = **책임만** 조각(위법 유지) → 교사방조 **가능**, [[정당방위]] **가능** / 판례 = **위법성** 조각(적법) → 교사방조 **불가**, 정당방위 **불가**
- **교수님 답**안: 2017, 2023 모의답안 기재는 법효과제한책임설로 표기되어 있으나, 서보학 저서 기준 입장은 유추적용 제한책임설. 법효과제한과 유추적용은 결론 동일(과실범 처벌)하므로 **시험장에서는 두 설 병렬 서술 후 결론 일치 확인**.(김혜선모의답안2023p4)

### 불능미수 개념 설명 (§27)

- **의의**: 실행의 착수는 있으나 수단 또는 대상의 착오로 **결과 발생이 불가능**한 경우
- **조문**: "실행의 수단 또는 대상의 착오로 인하여 결과의 발생이 불가능하더라도 위험성이 있는 때에는 처벌한다. 다만, 형을 감경 또는 면제할 수 있다"(§27)

#### 불능미수 요건

| 요건 | 내용 |
|---|---|
| ① **실행의 착수** | 구성요건 실현에 이르는 행위를 개시할 것 |
| ② **수단 또는 대상의 착오** | 행위자가 선택한 수단이 부적합하거나(수단의 불능), 대상이 존재하지 않는 경우(대상의 불능) |
| ③ **결과 발생의 불가능** | 착오로 인하여 객관적으로 결과가 발생할 수 없을 것 |
| ④ **위험성** | 결과 발생이 불가능하더라도 **위험성이 있을 것** — 이것이 불능미수의 가벌성을 근거짓는 핵심 요건 |

- **효과**: 처벌하되 형을 **감경 또는 면제** 가능 (임의적 감면)

#### 위험성 판단기준 — 학설

| 학설 | 판단기초 | 판단방법 | 비판 |
|---|---|---|---|
| **추상적 위험설(판례)** | 행위 당시 **행위자가 인식한 사정**을 기초 | 일반인이 객관적으로 결과 발생 가능성 판단 (사전판단) | 판단기초가 행위자 주관 → 객관성 부족 |
| **구체적 위험설** | 행위자가 인식한 사정 + **일반인이 인식할 수 있었던 사정** | 과학적 경험법칙에 의해 결과 발생 가능성 판단 (사후판단) | 사후적 관점은 항상 불가능 → 불능미수 인정범위 과소 |
| **객관적 위험설** | 행위 후 판명된 **모든 객관적 사정** | 과학적 법칙에 의해 판단 | 거의 모든 불능미수를 불벌 → 불능미수 규정 사문화 |

**[판례]** "피고인이 행위 당시에 인식한 사정을 놓고 이것이 객관적으로 법률적 판단을 하여 결과발생의 가능성이 있느냐를 따져야 한다" (대판 2005.12.8, **[[2005도8105]]**) → **추상적 위험설**

- **우연방위에 불능미수를 유추적용하는 이유**: 행위자에게 살해 고의(행위반가치)는 있지만, 객관적으로 [[정당방위]] 상황이 존재하여 결과반가치가 상쇄된다. 이는 행위자가 범죄를 시도했으나 객관적 사정으로 결과 발생이 불가능한 것과 구조가 같다. 따라서 §27을 유추적용하여 불능미수로 처벌하되 형을 감면한다.

### 모답형 — 오상방위·우연방위

> **[판례(엄격책임설적·독자이론)]** 판례([[68도370]], [[86도1406]])는 "착오에 정당한 이유가 있으면 **위법성**이 조각된다"는 입장이다. 정당한 이유가 없는 경우에는 고의범 또는 결과적 가중범의 성립을 인정한다. (엄격책임설적이나 "책임 조각"이 아닌 "위법성 조각"으로 표현 — 독자이론적 성격) → 결론: 정당이유 없으면 고의기수범 처벌
>
> **[다수설 (법효과제한책임설)]** 구성요건적 고의(불법고의)는 인정되나, 착오로 인하여 심정반가치(책임고의)가 조각되므로 고의의 법적 효과를 제한하여 과실범으로 처벌한다. → 결론: 과실치상
>
> **[교수님설(서보학·유추적용 제한책임설)]** 위전착은 구성요건적 착오와 구조적으로 동일하므로 §13을 유추적용하여 불법고의를 조각하고 과실범 처벌만 문제된다. → 결론: 과실치상
>
> **[포섭·결론]** 판례는 정당이유 없으면 고의기수로 결론이 다르다. 판례와 엄격책임설은 정당이유 없을 때 결론 동일하나, 정당이유 있을 때 "위법성 조각"(판례) vs "책임 조각"(엄격책임설)으로 갈린다. 유추적용 제한책임설·홍형철(법효과제한) 모두 과실범 처벌로 결론 일치. [[우연방위]](객관적 방위상황 존재, 방위의사 없음)는 §27(불능미수) 유추적용 여부를 별도로 검토한다.

| ① 허용되지 않는 위험의 **창출** | 행위가 법적으로 허용되지 않는 위험을 만들어야 함 | 허용된 위험 범위 내 행위 |
| ② 창출된 위험의 **실현** | 결과가 그 위험의 구체적 실현이어야 함 | 우연한 인과경로, 제3자 독자적 개입 |
| ③ 적법한 대체행위·**의무위반관련성** | 적법하게 행동해도 같은 결과가 발생했을 경우 | 90도2856: 정상 차선으로도 사고 불가피 |

#### 검토
- **교수님 포인트**: 객관적 귀속이론은 인과관계의 확장론이 아니라 **제한론**이다.(서보학총론p115)
- **교수님 포인트**: 허용된 위험은 사회적으로 유용한 활동에 수반되는 위험이 일반적으로 허용되는 경우이고, 이 범위 안의 불행한 결과는 원칙적으로 객관적 귀속이 부정된다.(서보학총론p116)
- 답안 순서: 판례=[[상당인과관계]] → 보충적으로 [[객관적 귀속]]

### 모답형 — 인과관계·객관적 귀속

> **[판례]** 판례는 상당인과관계설에 따라, **경험칙**상 **통상적**으로 그러한 행위에서 그러한 결과가 발생하는 것이 **상당하다고 인정**될 때 인과관계를 긍정한다([[90도2856]] 등). **적법한 대체행위**에서도 결과가 동일하게 발생하였을 것이라는 사정은 **[[상당인과관계]] 판단에 영향이 없다**.
>
> **[교수님설(서보학)]** 서보학은 객관적 귀속이론을 지지한다. ① 허용되지 않는 위험의 창출 여부 → ② 그 위험의 결과로의 실현 여부 → ③ 결과가 규범보호목적 범위 내에 있는지를 순서대로 검토하여 귀속 여부를 결정한다 → 결론: 판례(상당인과관계설)와 동일하게 귀속 인정·부정의 결론이 일치하는 경우가 대부분이다.
>
> **[포섭·결론]** 제3자의 독자적 개입이나 적법한 대체행위가 인정되면 인과관계(판례) 또는 [[객관적 귀속]](서보학·다수설)이 부정되어, 결과를 행위자에게 귀속시킬 수 없다.

### 사례형 답안 연습

#### [사례 1] 인과관계와 객관적 귀속 (14년 3회 변시 2문)

> 갑은 승용차를 운전하다가 B를 승용차로 치어 B가 중상해를 입었다. 이후 B는 구급차에 실려 병원으로 후송되던 중 구급차가 신호를 무시하고 지나가는 트럭에 부딪혀 전복되는 바람에 사망하였다. 갑의 행위와 B의 사망 사이의 인과관계에 대해 논하라.

**풀이**

I. 논점의 정리: 갑의 행위와 B의 사망 사이 인과관계와 객관적 귀속이 문제된다.

II. 학설 검토
1. 상당인과관계설(판례): 행위와 결과 사이에 개입한 사정에 관해 통상 예견이 가능한 경우 인과관계를 인정한다. 구급차 전복 사고는 **경험칙상 예견할 수 없으므로 상당인과관계를 인정할 수 없다.**
2. [[합법칙적 조건설]](다수설): **자연법칙적 인과관계는 인정**되나, 구급차 전복이라는 **독자적 개입에 의해 [[객관적 귀속]](위험실현)이 부정**된다.

III. 결론: 갑은 B에 대해 **업무상과실치상의 죄책**만 진다. 사망 결과에 대한 인과관계·객관적 귀속은 부정.

#### [사례 2] 합법적 대체행위이론

> 을이 트럭을 운전하던 중 H가 운전하던 자전거와 **교통법상 측면 간격을 유지하지 않은 채** 추월하다가 H가 사망하였다. **H가 만취상태**였기 때문에 을이 **충분한 측면 간격을 유지하며 추월했더라도** 동일한 사망의 결과가 발생했을 것이 확실한 경우, 을에게 치사죄가 성립하는지?

**풀이**

I. 을의 과실: 교통법 위반 → **객관적 주의의무 위반 인정**

II. 인과관계·[[객관적 귀속]]
1. 객관적 귀속이론(다수설): 주의의무를 다한 **합법적 대체행위**가 있더라도 같은 결과가 발생했을 것이 확실하면 **[[객관적 귀속]] 부정.**
2. 상당인과관계설(판례): 판례([[90도2856]])는 적법하게 운전했더라도 사고를 피할 수 없다면 **주의의무위반관련성이 없어 상당인과관계를 부정.**

III. 결론: 합법적 대체행위에 의해서도 결과 동일이 확실하므로 인과관계 부정. 을은 치사범 죄책 불성립.

### 김성돈 교차검증 보강 — 인과관계 영역

1. **형법 제17조와 객관적 귀속이론의 관계**: **제17조 전반부**("죄의 요소되는 위험발생에 연결")=행위귀속(위험창출), **후반부(**"그 결과")=결과귀속(위험실현). 조건설/상당인과관계설은 제17조 **문언과 접점이 없으나 객관적 귀속이론**은 제17조의 해석론으로 도출 가능.

2. **판단의 선명성**: 상당인과관계설은 사실확인과 규범평가를 '상당성' 하나로 혼용하지만, 객관적 귀속이론은 자연과학적 인과관계와 규범적 결과귀속을 엄격히 분리하는 이원적 접근법.
3. **적법한 대체행위 — 대법원 vs 객관적 귀속이론**: 대법원은 '주의의무위반과 결과 간의 인과관계'를 사실증명 차원에서 판단(무죄추정설 유사). 객관적 귀속이론은 주의규범의 보호목적이 결과 회피에 있었는지를 규범적 평가 차원에서 판단.

|---|---|---|

### 모답형 — 고의·미필적 고의

> **[조문]** §13(범의)에 의하면 구성요건사실을 인식하지 못한 행위는 벌하지 아니한다. 고의란 객관적 구성요건요소에 대한 인식과 의지이며, 위법성인식은 고의에 포함되지 않고 책임영역에 남는다.
>
> **[판례]** 판례([[94도1949]])는 미필적 고의에 관하여 결과발생의 가능성을 인식하고도 이를 감수·용인하는 의사가 있으면 미필적 고의를 인정한다. 용인이 없고 불발생을 신뢰하면 인식 있는 과실(§14)이다.
>
> **[포섭·결론]** 따라서 ②와 ③의 경계는 용인·감수 여부이며, 답안에서는 구성요건 단계의 고의와 책임 단계의 위법성인식을 분리하여 서술한다.

### 사례문제 [서보학 사례집 — 사례 8/10]

> 병이 심장이 약한 C를 향해 주먹을 휘두르는 순간, C가 느닷없이 쓰러졌다. 병은 C가 심장병으로 인해 사망한 것으로 알고 시신을 숨기기 위해 C를 인근야산에 매장하였다. 그러나 부검 결과 C는 매장으로 인한 질식사로 판명되었다. 병의 죄책은?

**풀이**: 제1행위(주먹)에 [[미필적 고의]] 인정 → 판례(단일행위설): 전 과정을 개괄적으로 보면 살인기수. 다수설(인과과정착오설): 인과과정의 비본질적 차이이므로 살인기수.(김성돈구성p114-115)

### 사례형 답안 연습

#### [사례 4] 개괄적 고의 (2025 중간 2문 유형)

> 갑이 을을 살해하려는 의도로 독초 달인 물을 준비하였는데, 타인 병이 마침 이를 마시고 쓰러졌다([[방법의 착오]]). 갑은 병이 사망한 것으로 착각하고 폐기물 쓰레기장에 유기하였는데(제2행위), 실제 사망 원인은 질식사였다.

**풀이**

I. 병에 대한 [[방법의 착오]](§15): 법정적 부합설(판례) — 동일 구성요건 내이므로 병에 대한 살인 고의 전용

II. 개괄적 고의의 법적 취급
1. 판례(단일행위설): 전 과정을 개괄적으로 보면 처음 예견된 사실이 실현된 것 → 살인기수
2. 다수설(인과과정착오설): 인과과정의 비본질적 차이 → 살인기수

III. 결론: 병에 대한 살인기수

- **판례([[68도370]], [[86도1406]], [[2023도10768]])**: "착오에 정당한 이유가 있으면 **위법성**이 조각된다." 정당이유 없으면 고의범. (엄격책임설적이나 "책임 조각"이 아닌 "위법성 조각"으로 표현 — 독자이론적 성격)
- **엄격책임설(순수 이론)**: "위전착은 §16의 금지착오에 해당하므로, 정당한 이유가 없는 한 고의책임이 인정되어 고의기수범이 성립한다." (판례와 달리 정당이유 있을 때 **책임**만 조각, 위법은 유지)
- **법효과제한책임설(지지: 홍형철)**: "위전착은 구성요건적 고의(불법고의)는 인정되나, 착오로 인하여 심정반가치(책임고의)가 조각되므로 그 법적 효과에 있어서만 고의가 조각된 것처럼 취급하여 과실범의 성부만이 문제된다."(쟁점정리 p62) 따라서 갑은 과실치상죄의 죄책을 진다.
- **유추적용 제한책임설(서보학·다수설)**: "위전착은 구성요건적 착오와 구조적으로 동일하므로 §13을 유추적용하여 불법고의를 조각하고, 과실범의 성부만이 문제된다." 따라서 갑은 과실치상죄의 죄책을 진다.

- 시험장 정리: **판례**는 "위법성이 조각된다"(엄격책임설적이나 독자이론). 정당이유 없으면 고의기수. **법효과제한책임설**(지지: 홍형철)·**유추적용 제한책임설**(서보학·다수설) 중심으로 서술하여 과실범 처벌로 결론 도출. 법효과제한과 유추적용은 결론 동일, 이론 구성만 다르다.

#### 모답형 — 위전착 (2단 병렬)

> **[판례(엄격책임설적·독자이론)]** 판례([[68도370]], [[86도1406]])는 "착오에 정당한 이유가 있으면 **위법성**이 조각된다"는 입장이다. 정당한 이유가 없는 경우에는 고의범 또는 결과적 가중범의 성립을 인정한다. → 결론: 정당이유 없으면 고의 상해죄 성립 (과실범으로 감경 없음)
>
> **[홍형철 지지설(법효과제한책임설)]** 고의불법(불법고의)은 인정되나, 착오로 인하여 심정반가치(책임고의)가 조각되므로 고의의 법적 효과를 제한하여 과실범으로만 처벌한다. → 결론: 고의 상해죄 불성립, 과실치상 가능
>
> **[교수님설(서보학·유추적용 제한책임설)]** §16이 아닌 §13을 유추적용하여 불법고의 자체를 조각하고, 과실범 성립 여부만 검토한다. → 결론: 고의 상해죄 불성립, 과실치상 가능
>
> **결론**: 판례는 정당이유 없으면 고의기수로 결론이 다르다. 법효과제한책임설(홍형철)과 유추적용 제한책임설(서보학)은 결론 동일(과실범 처벌)하나 이론 구성이 다르다. 판례와 엄격책임설은 정당이유 없을 때 결론 동일하나, 정당이유 있을 때 "위법성 조각"(판례) vs "책임 조각"(엄격책임설)으로 갈린다.

## §16. 정당행위 (§20) ★★ [일반·포괄·보충적 위법성조각사유]

<!-- p.72-76: 반반형법_25.md; 위법성론 25장 김성돈 p.001-060 -->

> 📍 위치: 범죄론 > 위법성론 > §16 정당행위
> **같이 볼 사항**: 위법성론 일반(§9) · 피해자의 승낙(§14) · 추정적 승낙 처리 · 쟁의행위 정당행위

### §20 조문 원문

> **제20조(정당행위)** 법령에 의한 행위 또는 업무로 인한 행위 기타 사회상규에 위배되지 아니하는 행위는 벌하지 아니한다.

### 의의 및 법적 성격

| 항목 | 내용 |
|---|---|
| **성격** | 일반적·포괄적·보충적 위법성조각사유 — 개별 사유(§21~24)로 포섭되지 않을 때 최종 적용 |
| **사회상규 위상** | 위법성 판단의 가장 기본적인 기준으로 명문화 (83도2224)[^§16-1] |
| **정당행위의 의미** | 적극적으로 용인·권장된다는 의미가 아니라, **범죄행위로서 처벌대상이 될 정도의 위법성을 갖추지 못하였다**는 것 (2018도1917)[^§16-2] |

### 세 가지 유형 비교표 ★★★

| 유형 | 요건·기준 | 주요 예시 | 관련 판례 |
|---|---|---|---|
| **① 법령에 의한 행위** | 법령에 근거한 행위일 것 | 현행범 체포(형소§212), 학교장 징계(초중등교육법§18①), 법원 감정인 감정(민소§335) | 2017도10634, 96도3376 |
| **② 업무로 인한 행위** | 사회적 정형성을 가진 업무의 범위 내 행위 | 기자 취재·보도(2011도639), 변호사 정당 변론 | 2011도639, 82도3248 |
| **③ 사회상규 불위배 행위** | 아래 5가지 판단기준 충족 | 소극적 방어행위(96도979), 수지침 시술(98도2389), 삼보일배 시위(2009도840) | 2017도2760 |

### 업무로 인한 행위 — 주요 유형

| 직업·업무 | 정당화 범위 | 한계 |
|---|---|---|
| **의사의 치료행위** | 환자 동의를 전제로 의료법에 근거한 진단·수술·처치 | 동의 없는 수술·의료법 위반 → 정당화 불가 (전합 2009도14407) |
| **변호사의 변론활동** | 의뢰인 이익을 위한 정당한 변론·법적 주장 | 허위 증거 제출·불법 수단 → 불가 |
| **판사·검사의 직무행위** | 재판·수사·공소제기 등 법령에 근거한 직무 수행 | 직무범위 일탈·위법한 수사 → 불가 |
| **교사의 징계행위** | 초중등교육법 §18① 기반의 교육적 징계 | 신체 고통 주는 체벌 → 불가 (동법§31) |

### 법령에 의한 행위 — 상관의 명령 ★

| 구분 | 내용 | 효과 |
|---|---|---|
| **적법한 명령** | 상관의 적법한 직무상 명령에 따른 행위 | §20 정당행위로 위법성 조각 |
| **위법한 명령** | 상관의 위법한 명령에 따른 범죄행위 | **위법성 조각 불가** (96도3376)[^§16-3] |

### 사회상규 — 판례 5가지 판단기준 ★★★

| 번호 | 요건 | 내용 | 판단 측면 |
|:---:|---|---|---|
| ① | **동기·목적의 정당성** | 행위의 동기나 목적이 정당할 것 | 행위 측면 |
| ② | **수단·방법의 상당성** | 행위의 수단이나 방법이 상당할 것 | 행위 측면 |
| ③ | **법익균형성** | 보호이익과 침해이익 사이의 균형 | 결과 측면 |
| ④ | **긴급성** | 행위의 긴급성 | 수단 상당성 고려요소 |
| ⑤ | **보충성** | 다른 수단이나 방법이 없을 것 | 수단 상당성 고려요소 |

- **종합판단**: 5가지 요건은 불가분적으로 연관되어 하나의 행위를 이루는 요소로서 종합적으로 평가 ([[2017도2760]])[^§16-4]
- **긴급성·보충성의 지위**: 독립 요건이 아니라 **수단 상당성 판단 시 고려요소**로 참작. "일체의 법률적인 적법한 수단이 존재하지 않을 것"을 의미하지는 않음 ([[2017도2760]])
- **정도**: 개별 사안에 따라 다를 수 있음 ([[2018도1917]])

### 교수님(서보학) 주요 입장 ★★★

| **의료행위 정당화** | §20 정당행위 구조로 파악. 설명·동의 전제 잘못 → 위전착 문제로 연결 | §24 피해자 승낙으로 처리 |

### 쟁의행위의 정당행위 요건 ★

- ① 주체 적격(단체교섭 주체) ② 목적 정당(근로조건 향상) ③ 사용자 단체교섭 거부 후 개시 ④ 법령 절차 준수 ⑤ 수단·방법이 폭력에 해당하지 않을 것 ([[2019도10516]])[^§16-7]
- 수급인에 대한 정당성이 도급인에게까지 자동 확장되지는 않으나, 사회상규 조항으로 위법성 조각 가능 ([[2015도1927]])

### 모답형 — 정당행위 ★★

> **[조문]** 형법 제20조에 의하면 법령에 의한 행위 또는 업무로 인한 행위 기타 사회상규에 위배되지 아니하는 행위는 벌하지 아니한다. §20은 개별 위법성조각사유(§21~§24)에 해당하지 않는 경우 최종·포괄적으로 적용되는 일반조항이다.
>
> **[유형 검토]** ① 법령에 의한 행위인지(법령상 근거 존재 여부), ② 업무로 인한 행위인지(사회생활상 정형적 업무 범위 내 행위 여부), ③ 사회상규에 위배되지 않는 행위인지 순서로 검토한다.
>
> **[사회상규 판단기준 — [[2017도2760]]]** "사회상규에 의한 정당행위를 인정하려면 ① 동기나 목적의 정당성, ② 수단이나 방법의 상당성, ③ 보호이익과 침해이익과의 법익균형성, ④ 긴급성, ⑤ 보충성의 요건을 갖추어야 한다." 5가지 요건은 불가분적으로 연관되어 종합 평가되며, ④긴급성·⑤보충성은 독립 요건이 아니라 ②수단 상당성의 고려요소로 참작된다.[^§16-4]
>
> **[상관의 명령]** 상관의 명령이 ① 직무범위 내, ② 법령상 요건 구비, ③ 적법한 방식·형식을 갖춘 경우 §20 법령에 의한 행위로 위법성이 조각된다. 명백히 위법한 명령에는 복종의무가 없으므로 이에 따른 행위는 §20으로 정당화되지 않는다([[96도3376]])[^§16-3].
>
> **[포섭·결론]** 사안에서 개별 위법성조각사유(§21~§24)가 모두 부정될 경우 최후로 §20을 검토한다. ①동기·목적의 정당성, ②수단·방법의 상당성, ③법익균형성, ④긴급성, ⑤보충성을 종합하여 사회상규에 위배되지 않으면 §20에 의하여 위법성이 조각된다.

## §13. 자구행위 ★★

> 📍 위치: 범죄론 > 위법성론 > §13 [[자구행위]]

### §23 조문 원문

> **제23조([[자구행위]])** ① 법정의 절차에 의하여 청구권을 보전하기 불능한 경우에 그 청구권의 실행불능 또는 현저한 실행곤란을 피하기 위한 행위는 상당한 이유가 있는 때에는 벌하지 아니한다.
> ② 전항의 행위가 그 정도를 초과한 때에는 정황에 의하여 형을 감경 또는 면제할 수 있다.

### 요건 분해 (3단계)

| 단계 | 요건 | 내용 |
|:---:|---|---|
| ① | 법정절차 보전 불능 | 법정 절차로는 청구권을 보전할 수 없을 것 |
| ② | 청구권 실행 곤란 | 도망·증거인멸 등으로 청구권 실현 불가능 또는 현저히 곤란해질 긴급상황 |
| ③ | 상당한 행위 | 청구권 보전을 위한 상당한 행위 |

### 보전 vs 실현 구분표

| | 보전 (자구행위 O) | 실현 (자구행위 X) |
|---|---|---|
| **행위** | 붙잡아 경찰에 인도 | 직접 강제로 채권 추심 |
| **성격** | 권리 **확보·보전** | 권리 **강제 실현** |
| **판례** | 2017·2023 중간기출 택시비·음식값 사례 (시험문제) | 84도2582 야간 침입 물건 반출 |

### 판례 요지

- 택시비에 대한 청구권: **도주하는 손님을 붙잡아 경찰에 인도** → [[자구행위]] 인정
- 음식값에 대한 청구권: **도주 손님을 제압하여 경찰 인도** → [[자구행위]] 인정
- **야간 침입 물건 반출**([[84도2582]]): 청구권의 보전이 아니라 **실현** → **[[자구행위]] 부정**
- `판례문구([[84도2582]])`: "피고인의 강제적 채권추심 내지 이를 목적으로 하는 물품의 취거행위를 형법 제23조 소정의 자구행위라고 볼 수 없다."
- **[[95도2970]]**: 채무자 물품 강제 반출은 상당성 초과 → [[자구행위]] 부정

#### 교재 보충 [《서보학_형법총론_18.pdf》]

- 자구행위는 청구권의 `보전`을 위한 **사후적 긴급행위**이고, [[정당방위]]·긴급피난보다 **보충성 원칙이 더 엄격하게** 요구된다. [p.221-222]
- 자구행위의 청구권은 채권적 청구권에만 한정되지 않고 물권적 청구권은 물론 **부부친권** 등도 포함하며, 법정절차에 의한 보전이 불가능하거나 현저히 곤란해야 한다. [p.222, p.224]

### 암기 문장

`자구행위는 청구권 보전 / 실현 아님 / 붙잡아 경찰 인도면 상당성 유리 / 이중의 긴급상황 / 야간 책임조각 없음`

### 긴급피난과의 연결

- 적법한 자구행위가 인정되면 → 상대방 반격은 정당방위가 아니라 **[[긴급피난]]** 구조
- 고의 자초위난이면 긴급피난도 부정

### 모답형 — 자구행위

> **[조문]** §23①에 의하면 법정의 절차에 의하여 청구권을 보전하기 불능한 경우에 그 청구권의 실행불능 또는 현저한 실행곤란을 피하기 위한 행위는 상당한 이유가 있는 때에는 벌하지 아니한다. 자구행위는 청구권을 실현하기 위한 것이 아니라 보전하기 위한 예외적 행위이다.
>
> **[판례]** 판례([[84도2582]])는 야간에 침입하여 물건을 반출한 행위는 청구권의 보전이 아니라 실현에 해당하여 자구행위를 부정하였다. 반면 택시비·음식값 사안에서는 붙잡아 경찰에 인도한 행위의 상당성을 인정하여 자구행위로 위법성이 조각된다고 보았다.
>
> **[포섭·결론]** 시간적 여유가 있거나 통상의 국가구제수단으로 충분한 경우 [[자구행위]] 부정. 적법한 자구행위가 인정되면 상대방 반격은 [[긴급피난]](§22) 구조.

### 사례문제 [서보학 모의답안 2023]

> 식당 주인 Z이 음식값을 안 내고 도망가려는 손님 C를 쫓아가 팔을 꺾어 제압한 뒤 경찰에 신고하였다.

**풀이**: ① 청구권(음식대금채권) 존재 ② 법정절차 곤란(도주 중) ③ 상당성(제압+경찰 인도) → [[자구행위]] 성립. C의 반격: Z의 자구행위가 적법 → [[정당방위]] 불가, [[긴급피난]] 검토 → 무전취식=고의 자초위난이면 긴급피난도 부정.(김혜선모의답안2023p5)

### 자구행위 보강 카드

| 항목        | 내용                            | 포섭 포인트                |
| --------- | ----------------------------- | --------------------- |
| **본질**    | 청구권의 `실현`이 아니라 `보전`           | 시간을 다투는 보전 상황인지 먼저 본다 |
| **허용근거**  | 법정 절차로는 권리보전이 어려운 긴급상황        | 즉시 집행 불가가 전제          |
| **반격 구조** | 자구행위가 정당화되면 상대방 반격은 긴급피난으로 연결 | 정당방위와 기계적으로 섞지 않는다    |

- 자구행위는 청구권을 실현하기 위한 것이 아니라 보전하기 위한 행위라는 점을 먼저 적어야 한다.

- 적법행위·자연현상에 의한 청구권 실행불능/곤란 → **[[긴급피난]]**으로 처리
- 보전불능·실행곤란은 **상대방의 귀책사유**로 인한 것이어야 함

| - [《김성돈_형법총론_위법성론_25》 §174 | "적법행위나 자연현상에 의한 청구권의 실행불능 또는 실행곤란을 피하기 위한 행위는 긴급피난이 될 뿐이다"] |

#### 도품탈환과 자구행위 [김성돈 §175-176]

- 자구행위는 **사후적 긴급행위** → 불법한 침해행위가 아니라 불법한 **침해상태**를 전제
- 침해행위가 진행 중이면 → **[[정당방위]]**(사전적 긴급행위)
- 침해행위 완료 → 원상회복의무 불이행상태 → **자구행위상황**으로 전환
- 상당 기간 경과 후 우연히 절도범을 만나 도품 탈환 → [[자구행위]] 가능
- 현장에서 추적하여 탈환 → 침해의 현재성 인정(다수설) → **[[정당방위]]** 성립

| - [《김성돈_형법총론_위법성론_25》 §175 | "일단 침해행위가 완료되어 원상회복의무의 불이행상태가 될 때 정당방위상황은 자구행위상황으로 바뀐다"] |

#### 이중의 긴급상황 [김성돈 §180]

- 자구행위가 가능하려면 청구권의 **실행과 보전에 대한 이중의 긴급상황**이 있어야 함
- 법정절차에 의한 보전이 불가능하더라도, 충분한 물적·인적 담보가 확보되어 있으면 → [[자구행위]] 불가

| - [《김성돈_형법총론_위법성론_25》 §180 | "자구행위가 가능하려면 청구권의 실행과 보전에 대한 '이중의 긴급상황'이 있어야 한다"] |

#### 보전수단의 범위 [김성돈 §181-184]

|---|---|

- 판례: 권리행사가 **사회통념상 허용된 범위** 내인지 여부로 판단

#### 자구의사 [김성돈 §186]

- 청구권의 실행불능 또는 현저한 실행곤란을 피하기 위한 의사(주관적 요건) 필요

## §14. 피해자의 승낙 ★

> 📍 위치: 범죄론 > 위법성론 > §14 피해자의 승낙

### §14-0. 조문·개요

**제24조(피해자의 승낙)** 처분할 수 있는 자의 승낙에 의하여 그 법익을 훼손한 행위는 법률에 특별한 규정이 없는 한 벌하지 아니한다.

| 구분 | 양해 | 승낙(§24) |
|---|---|---|
| **체계적 지위** | 구성요건해당성 배제 | 위법성조각 |
| **대상** | 구성요건 자체가 의사에 반한 침해를 전제하는 경우 (예: 주거침입) | 처분 가능한 법익의 포기 |
| **의사표시** | 자연적 의사로 족함 | 법적으로 유효한 승낙 필요 |
| **승낙 능력** | 사실적 이해만 있으면 됨 | 법익의 의미와 범위를 이해할 판단능력 필요 |

| 요건 | 내용 |
|---|---|
| ① 처분 가능한 법익 | 생명은 처분 불가 (촉탁살인 §252 별도 규율) |
| ② 승낙 능력 | 법익의 의미와 범위를 이해할 판단능력 |
| ③ 자유로운 의사 | 강요·사기에 의한 승낙 → 무효 (다수설 부정설) |
| ④ 행위 전 또는 행위 시 승낙 | 사후 승낙은 위법성조각 효과 없음 |
| ⑤ 승낙의 표시 | 명시적 또는 묵시적 |
| ⑥ 사회상규 위반 불가 | 윤리·도덕상 사회상규에 반하지 않아야 함 (판례 85도1892) |

---

### §14-1. 양해와 승낙의 구별 ★★

**[쟁점의 정리]** 피해자의 동의가 구성요건해당성을 배제하는 양해인지, 위법성을 조각하는 승낙인지 구별이 문제된다.

**[학설]**
- **구별설(다수설)**: 구성요건 자체가 의사에 반한 침해를 전제로 하는 경우(주거침입, 절도 등) → 동의는 구성요건해당성을 배제하는 양해. 그 외 처분 가능한 법익에 대한 동의 → 위법성조각사유인 승낙. 양해는 자연적 의사로 족하고, 의사표시의 하자도 원칙적으로 영향 없음(긍정설 — 판례).
- **불구별설(소수설)**: 양자 모두 위법성조각사유로 통일적으로 처리.

**[판례]**
- "일반인의 출입이 허용된 음식점에 영업주의 승낙을 받아 통상적인 출입방법으로 들어갔다면, 설령 행위자가 범죄 등을 목적으로 출입하였거나 영업주가 실제 출입 목적을 알았더라면 출입을 승낙하지 않았을 것이라는 사정이 인정되더라도 그러한 사정만으로는 사실상의 평온상태를 해치는 방법으로 들어갔다고 평가할 수 없으므로 침입행위에 해당하지 않는다." (대판 2022.3.24. **[[2017도18272]]** 전원합의체)
- "피해자의 묵시적인 동의가 있었다면 피고인의 주장이 후에 허위임이 밝혀졌더라도 피고인의 행위는 절도죄의 절취행위에 해당하지 않는다." (대판 1990.8.10. **[[90도1211]]**)

**[검토]** 양해의 사실적 성격을 고려할 때 의사표시의 흠결 또는 하자는 양해에 영향을 줄 수 없다는 긍정설(판례)이 타당하다. 주거침입죄 등 보호법익이 사실상 평온인 경우 객관적·외형적 행위태양이 기준이 된다.

**[모답형]**
> **[쟁점]** 갑이 을의 동의를 받아 을의 집에 들어간 경우, 주거침입죄(§319)의 성립 여부가 문제된다.
>
> **[논증]** 주거침입죄는 사실상 주거의 평온을 보호법익으로 하고, 구성요건적 행위인 '침입'은 사실상 평온상태를 해치는 행위 태양으로 주거에 들어가는 것을 의미한다([[2017도18272]] 전원합의체). 을이 동의한 이상 사실상 평온상태를 해치는 행위태양에 해당하지 않으므로, 갑의 행위는 구성요건해당성이 배제되어 주거침입죄가 성립하지 않는다.

---

### §14-2. 승낙의 유효요건 ★★

**[쟁점의 정리]** 피해자의 동의가 [[위법성조각]] 효과를 갖기 위한 유효요건을 갖추었는지, 특히 승낙 능력의 결여 또는 의사의 하자가 있는 경우 승낙의 효력이 문제된다.

**[학설]**
- **부정설(다수설)**: 승낙은 법적 효과가 귀속되는 의사표시이므로, 강요·기망·착오에 의한 승낙은 의사의 흠결 또는 하자로 무효. 승낙 능력은 법익의 의미와 범위를 이해할 판단능력이 요구되며, 미성년자·정신장애인의 경우 개별적으로 판단.
- **긍정설(소수설)**: 승낙도 사실적 성격이 있으므로 의사의 하자는 효력에 영향 없음.

**[판례]**
- "형법 §24의 규정에 의하여 위법성이 조각되는 피해자의 승낙은 개인적 법익을 훼손하는 경우에 법률상 이를 처분할 수 있는 사람의 승낙을 말할 뿐만 아니라 그 승낙이 윤리적·도덕적으로 사회상규에 반하는 것이 아니어야 한다." (대판 1985.12.10. **[[85도1892]]**)

**[검토 — 서보학]** 승낙은 법적 의미보다 **사실적 성격이 강하므로**, 기망 등 하자가 있어도 곧바로 무효라고 단정하지 않는다. 다만 **침해 내용의 본질을 오인시켜 실질적 자기결정이 박탈된 경우**에는 승낙의 효력이 부정된다. [《서보학_형법총론_18.pdf》 p.228]
- 따라서 단순한 동기의 착오(예: 대가 미지급)는 승낙을 무효로 하지 않으나, 침해의 종류·범위·위험성에 대한 본질적 오인을 야기한 기망은 승낙을 무효로 한다.
- **사후승낙은 인정되지 않는다** — 승낙은 행위 전 또는 행위 시에 존재해야 함. [《서보학_형법총론_18.pdf》 p.228]

**[모답형]**
> **[쟁점]** 갑이 을(13세)을 기망하여 동의를 얻어낸 경우, 유효한 승낙으로서 위법성이 조각되는지가 문제된다.
>
> **[논증]** 위법성이 조각되는 피해자의 승낙은 법률상 이를 처분할 수 있는 자의 승낙이어야 하고, 그 승낙이 사회상규에 반하지 않아야 한다([[85도1892]]). 을은 13세로 성적 자기결정의 의미를 충분히 이해할 판단능력이 결여되어 있어 승낙 능력이 없고, 갑의 기망에 의한 동의는 의사의 하자로 무효이다. 따라서 위법성은 조각되지 않는다.

---

### §14-3. 위법성조각 근거 ★★

**[쟁점의 정리]** 피해자의 승낙이 형법 §24에 의해 위법성을 조각하는 근거가 무엇인지, 그 한계가 어디까지인지 문제된다. 특히 생명·신체에 대한 중대한 침해에도 승낙이 위법성을 조각할 수 있는지가 핵심이다.

**[학설]**
- **법익처분권설(다수설)**: 개인은 자신의 법익을 자유롭게 처분할 수 있으므로 승낙이 있으면 법익침해 자체가 부정되어 위법성이 조각된다. 자기결정권이 근거. 다만 생명에 대한 처분(촉탁살인)은 §252로 별도 규율.
- **사회상당성설**: 사회적으로 상당한 범위 내에서만 위법성이 조각된다. 사회상규에 반하는 법익침해는 승낙이 있더라도 위법성 조각 불가.
- **절충설**: 법익처분권의 범위 내에서, 그리고 사회상당성이 인정되는 경우에 한해 위법성이 조각된다.

**[판례]**
- "형법 §24의 규정에 의하여 위법성이 조각되는 피해자의 승낙은 개인적 법익을 훼손하는 경우에 법률상 이를 처분할 수 있는 사람의 승낙을 말할 뿐만 아니라 그 승낙이 윤리적·도덕적으로 사회상규에 반하는 것이 아니어야 한다." (대판 1985.12.10. **[[85도1892]]** — 잡귀방출 폭행치사 사건)
- 위 판례는 사회상당성설적 요소를 승낙의 유효요건으로 결합하는 절충적 입장.

**[검토 — 서보학]** 피해자의 승낙에 의한 위법성조각은 §20 **정당행위**의 구조 안에서 파악한다. 즉 §24는 법익처분권을 기본으로 하되, 사회상규 위반 여부를 **§20③ 사회상규에 위배되지 아니하는 행위**의 기준(동기·목적, 수단·방법, 보호법익과 침해법익의 균형, 긴급성, 보충성)으로 종합 판단한다. [《서보학_형법총론_18.pdf》 p.232, 245]
- 판례([[85도1892]])가 "사회상규에 반하지 않아야 한다"고 요구하는 것과 결론이 일치한다.
- **의료행위(수술)의 정당화**도 §20 정당행위 구조로 파악하는 것이 기본이며, 설명·동의의 전제가 잘못된 경우 **위법성조각사유 전제사실의 착오**(위전착) 문제로 연결한다.

**[모답형]**
> **[쟁점]** 갑이 을의 승낙을 받아 을의 신체에 위해를 가한 경우, 피해자의 승낙(§24)으로 위법성이 조각되는지가 문제된다.
>
> **[논증]** 위법성이 조각되는 피해자의 승낙은 법률상 이를 처분할 수 있는 자의 승낙이어야 하고, 그 승낙이 윤리적·도덕적으로 사회상규에 반하지 않아야 한다([[85도1892]]). 법익처분권설에 따르면 자신의 신체에 대한 처분권 행사로 위법성이 조각되나, 승낙이 사회상규에 반하는 경우에는 그 효과가 부정된다. 사안에서 승낙의 경위·목적·방법을 종합할 때 사회상규에 반하는지 여부를 검토하여 결론을 도출한다.

---

### §14-4. 추정적 승낙 ★

**[쟁점의 정리]** 피해자의 현실적 승낙은 없으나 피해자가 사정을 알았더라면 승낙했을 것으로 합리적으로 추정되는 경우, 이를 근거로 위법성이 조각될 수 있는지 문제된다. 체계적 지위와 요건이 핵심 쟁점이다.

**[학설]**
- **초법규적 위법성조각사유설(다수설)**: 형법 §24의 피해자 승낙과는 구별되는 초법규적 위법성조각사유. 현실적 승낙을 구할 수 없는 긴급한 사정 등에서 인정.
- **§24 포함설(소수설)**: §24의 '승낙'에 추정적 승낙도 포함된다.

| - **정당행위설(서보학)**: 추정적 승낙이 인정되면 §24가 아니라 **§20 정당행위**로 위법성이 조각된다. 피해자의 승낙의 일종으로 취급하는 것은 적절하지 않다. [《서보학_형법총론_18.pdf》 p.232 | "추정적 승낙이 인정되면 형법 제20조 정당행위의 규정에 따라 위법성이 조각된다"] |

**[판례]** 추정적 승낙 독자적 판례 미확인 — 교수님 입장(정당행위 §20 처리) 적용.

**[검토]** 교수님 견해(정당행위설)에 따르면 추정적 승낙은 §24가 아닌 §20으로 해결. 다수설인 초법규적 위법성조각사유설과 결론에서는 위법성조각이라는 점이 동일하나, 법적 근거가 다르다. 시험에서 교수님 견해 적용 시 §20으로 귀결.

**[모답형]**
> **[쟁점]** 현실적 승낙 없이 타인의 법익을 침해하였으나 피해자가 알았더라면 승낙했을 것으로 추정되는 경우, 추정적 승낙으로 위법성이 조각되는지가 문제된다.
>
> **[논증]** 추정적 승낙은 피해자의 현실적 승낙은 없으나 피해자가 사정을 알았더라면 승낙했을 것으로 합리적으로 추정되는 경우를 말한다. 이를 §24의 피해자의 승낙의 일종으로 취급하는 것은 적절하지 않고, 추정적 승낙이 인정되면 §20 정당행위로서 위법성이 조각된다(서보학). 사안에서 피해자가 사정을 알았더라면 승낙했을 것으로 합리적으로 추정할 수 있다면 §20에 의해 위법성이 조각된다.

## 정당행위 (§20) ★★

> 📍 위치: 범죄론 > 위법성론 > 정당행위 §20
> **같이 볼 사항**: 피해자의 승낙(§14) · 추정적 승낙 · 위법성조각사유 검토순서

### §20 조문 원문

> **제20조(정당행위)** 법령에 의한 행위 또는 업무로 인한 행위 기타 사회상규에 위배되지 아니하는 행위는 벌하지 아니한다.

### 3유형

| 유형 | 내용 | 대표 예 |
|---|---|---|
| ① **법령에 의한 행위** | 법률이 허용·명령하는 행위 | 경찰관의 체포, 현행범 체포(형소법 §212) |
| ② **업무로 인한 행위** | 사회생활상 정당한 업무 수행 | 의사의 수술·치료 행위 |
| ③ **사회상규에 위배되지 않는 행위** | 5요소 종합 판단 — 아래 표 참조 | 추정적 승낙, 관행적으로 허용된 행위 |

- §20은 열거된 위법성조각사유로 해결되지 않는 경우를 최종적으로 포괄하는 **일반조항**이다. 위법성조각사유 검토 순서상 **최후의 관문**으로 기능한다.

### 사회상규 부합 행위 — 5요소 종합 판단 기준[^정당행위-서보학-p245]

| 요소 | 내용 |
|---|---|
| ① 동기·목적의 정당성 | 행위의 동기·목적이 사회적으로 허용될 수 있어야 함 |
| ② 수단·방법의 상당성 | 행위 수단이 사회통념상 허용 범위 안에 있어야 함 |
| ③ 보호이익과 침해이익의 균형 | 행위로 보호하는 이익이 침해하는 이익 이상이어야 함 |
| ④ 긴급성 | 위법성조각이 필요한 긴박한 상황이 전제되어야 함 |
| ⑤ 보충성 | 다른 적법한 수단으로 목적 달성이 불가능해야 함 |

- 5요소를 **종합하여** 사회상규 위반 여부를 판단한다. 어느 한 요소가 결여되어도 곧바로 정당행위 불성립이 되는 것은 아니고 전체적으로 평가한다.

### 상관의 명령과 §20

| 항목 | 정리 |
|---|---|
| **정당행위 인정 요건** | ① 직무범위 안의 명령 ② 법령상 요건 구비 ③ 적법한 방식·형식 |
| **효과** | 3요건 충족 → §20 법령에 의한 행위로 위법성 조각 가능 |
| **예외** | 명백히 위법·불법한 명령 → 복종의무 없음 → 정당행위 불성립[^정당행위-87도2358] |

### 교수님 입장 — §20 포괄구조

> **[서보학 교수님 핵심 입장]**: 피해자의 승낙(§24), 추정적 승낙, 의료행위 정당화를 모두 **§20 정당행위 구조 안에서 포섭**하여 사회상규 5요소로 종합 판단한다. 다수설이 §24를 독자적 위법성조각사유로 파악하는 것과 구별된다.

| 장면 | 교수님설 (서보학) | 다수설 | 근거 |
|---|---|---|---|
| **피해자의 승낙** | §20 정당행위 구조 안에서 파악. 사회상규 5요소로 종합 판단[^정당행위-서보학-p245] | §24 독자 위법성조각사유 | 판례(85도1892) "사회상규에 반하지 않아야 한다" 요건과 결론 일치 |
| **추정적 승낙** | §24 아닌 §20 정당행위로 위법성 조각[^정당행위-서보학-p232] | §24 유추 또는 초법규적 위법성조각 | §24는 현실적 승낙 전제 — 추정적 승낙은 §20③ 구조로 처리 |
| **의료행위 (수술)** | §20 정당행위 구조. 설명·동의 전제 오인 시 → **위전착** 문제 연결 | §20② 업무로 인한 행위 또는 §24 승낙 | 의료행위 정당화의 통일적 처리. 설명의무 위반 → 승낙 전제 흠결 → 위전착 |

- 핵심 실익: 추정적 승낙 장면에서 §24 유추가 아니라 **"§20 정당행위로서 위법성이 조각된다"**고 서술한다.

### 모답형 — 정당행위 §20

> **[조문]** §20에 의하면 법령에 의한 행위·업무로 인한 행위·사회상규에 위배되지 아니하는 행위는 벌하지 아니한다. 정당행위는 위법성조각사유의 최종 일반조항으로, 다른 위법성조각사유가 충족되지 않는 경우에도 사회상규 부합 여부를 종합 검토한다.
>
> **[판단기준]** 사회상규 부합 여부는 ① 동기·목적의 정당성, ② 수단·방법의 상당성, ③ 보호이익과 침해이익의 균형, ④ 긴급성, ⑤ 보충성을 종합하여 결정한다.
>
> **[포섭·결론]** 사안에서 5요소를 충족하면 §20 정당행위로 위법성이 조각되어 범죄가 성립하지 않는다.

| ④ | 고의 | 결과발생 가능성 인식·예견 + 용인 |
| ⑤ | 인과관계 | 작위의무 불이행 → 결과 발생 |

#### 보증인지위 발생 근거 — 학설

| 학설 | 기준 | 지위 |
|---|---|---|
| **형식설** | 법령·계약·선행행위·신의칙·조리 등 형식적 발생근거 | **판례** |
| **기능설** | 법익보호의무 + 위험감시의무로 실질적 구별 | 학설 |
| **결합설** | 형식+기능 병합 | 일부 학설 |

#### 부작위범의 정범·공범 구별

- 판례(방조범설): 작위의무에 위배해 작위정범의 범행을 방치했다는 부작위만으로는 실행행위로서의 작위와 동일시할 수 없다. 원칙적으로 방조범 성립.(도표추가본 L866-870)
- 예외: 작위정범이 이미 현장을 떠난 뒤 보증인이 사건경과를 지배하는 경우에는 부작위에 의한 정범 인정 가능.

### 결과범/거동범, 즉시범/계속범

| 구분 | 기준 | 예시 |
|---|---|---|
| **결과범** | 결과 발생이 구성요건 요소 → 인과관계 문제됨 | 살인, 상해 |
| **거동범** | 행위 자체로 구성요건 충족 | 주거침입, 무고 |
| **즉시범** | 법익 침해 즉시 종료 | 살인 |
| **계속범** | 법익 침해가 계속됨 | 감금, 체포 |

## §15. 과실범·결과적 가중범 (기말 보강) ★

> 📍 위치: 범죄론 > 구성요건론 > §15 과실범·결과적 가중범

### §14 과실범 — 기본 요건

| 요건 | 내용 |
|---|---|
| ① 객관적 주의의무 위반 | 예견의무(결과 예견 가능성) + 회피의무(결과 회피 가능성) |
| ② 주의의무 위반과 결과 사이 인과관계 | 상당인과관계(판례) / 객관적 귀속(다수설) |
| ③ 개별 처벌규정 | §14 단서: 법률에 특별한 규정 있는 경우에 한함 |
| ④ 신뢰의 원칙 | 다른 참여자의 적법 행위를 신뢰할 수 있으면 주의의무 제한 |

### §15② 결과적 가중범

> **제15조 ②** 결과적으로 중한 죄에 해당하는 행위가 그 중한 결과에 대하여 예견할 수 없었을 때에는 중한 죄로 벌하지 아니한다.

| 요건 | 내용 |
|---|---|
| ① 기본범죄에 대한 고의 | 기본범의 구성요건 충족 |
| ② 중한 결과 발생 | 기본범의 전형적 위험이 실현 |
| ③ 중한 결과에 대한 예견가능성(과실) | §15② — 예견 불가능하면 가중처벌 불가 |
| ④ 직접성의 원칙 | 중한 결과가 기본범의 **직접적** 위험 실현이어야 |

## 시험 직전 접근순서

> 📍 위치: 부록 > 접근순서

1. `인과관계 → [[미필적 고의]] → [[개괄적 고의]] → 구성요건착오`를 하나의 묶음으로 복습
2. `[[정당방위]] → [[긴급피난]] → [[자구행위]]`를 연결하여 비교표와 함께 외움
3. `[[오상방위]]`는 법효과제한적책임설 중심으로 고정
4. 답안 작성 순서는 항상 `객관적 구성요건 → 인과관계/[[객관적 귀속]] → 고의/착오 → 위법성` 고정
5. [[정당방위]]·[[긴급피난]] 비교표는 반드시 현재성 차이 포함하여 암기
6. 자구행위는 `청구권 보전 / 법정절차 곤란 / 상당성` 3단계

## 사례형 답안 작성 플로우차트

> 📍 위치: 부록 > 답안 플로우

### 전체 흐름

```
사례 읽기
  └─ ① 객관적 구성요건 확인
       └─ 결과범인가?
            ├─ Yes → ② 인과관계 검토 (상당인과관계설·판례)
            │         └─ 중간개입사정?
            │              ├─ Yes → ③ 객관적 귀속 검토 (보충적)
            │              └─ No  → ③ 고의 검토로
            └─ No  → ② 행위범 → 바로 고의로
  └─ ③ 고의 검토
       └─ 인식과 결과 일치?
            ├─ No  → ④ 구성요건적 착오 (§13·§15 → 학설)
            └─ Yes → ④ 고의 인정
  └─ ⑤ 위법성조각사유 검토
       └─ 정당방위?
            ├─ 현재성 X → 긴급피난 검토
            ├─ 전제사실 착오 → 오상방위 검토
            └─ Yes → 상당성·사회윤리적 제한
  └─ 긴급피난
       └─ 자초위난?
            ├─ 고의 → 긴급피난 부정
            └─ 과실 → 긴급피난 인정 가능
```

### 위법성조각사유 검토 순서 (시험장 고정)

| 순서 | 검토 사유 | 요건 핵심 | 넘어가는 조건 |
|:---:|---|---|---|
| 1 | 정당방위 (§21) | 현재+부당+상당 | 현재성 또는 부당성 부정 |
| 2 | 긴급피난 (§22) | 현재위난+보충+균형 | 고의 자초위난 |
| 3 | 자구행위 (§23) | 법정절차불능+청구권곤란+상당 | 청구권 없음 |
| 4 | 정당행위 (§20) | 법령·업무·사회상규 | — |
| 5 | 피해자 승낙 (초법규적) | 처분가능+능력+자유의사 | — |

### 쟁점 포착 체크리스트

| 확인 사항 | 해당 쟁점 |
|---|---|
| 고의는 있는데 다른 사람에게 결과 발생 | 구성요건적 착오 (방법 착오/객체 착오) |
| 제1행위에서 사망 오인 + 제2행위에서 실제 사망 | 개괄적 고의 |
| 결과 발생 가능성 인식 + 용인 여부 불분명 | 미필적 고의 vs 인식 있는 과실 |
| 방위상황이 없는데 있다고 오인 | 오상방위 (위전착) |
| 방위상황은 있는데 방위의사 없음 | 우연방위 |
| 정당방위가 막히면 | 긴급피난으로 순차 검토 |
| 적법한 자구행위에 대한 반격 | 긴급피난 구조 → 고의 자초위난 검토 |
| 적법하게 행동해도 같은 결과 | 적법한 대체행위이론 → 귀속 부정 |
| 보증인이 작위정범의 범행을 방치 | 부진정부작위범 → 방조범(판례) |

### 결과적 가중범의 공동정범 [보강메모]

- 이 쟁점은 중간범위 직접 소스가 아니라 쟁점정리 보강자료에서만 확인된다.
- 정리: ① 기본범죄에 공동가공의 의사, ② 중한 결과에 대한 예견가능성, ③ 기본행위를 공동으로 했으면 결과적 가중범의 공동정범 긍정.(쟁점정리 p57-58)
- 본 노트에서는 중간범위 직접 소스가 아님을 명시한 채 참고메모로만 둔다.
