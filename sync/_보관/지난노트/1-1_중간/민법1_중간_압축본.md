### 비진의표시 (§107) ★★

- **요건**: 표의자가 진의 아님을 **알면서** 의사표시
- **효과**: 원칙 **유효** / 상대방 **악의·과실** → 소급적 무효(§107① 단서)
- **판례**: ([[93다4480]]) 진의 = 특정 내용의 의사표시를 하고자 하는 표의자의 **생각**, 마음속 바람이 아님
- **포섭**: 차명대출([[97다8403]]) — 법률효과 귀속 의사 O → 비진의 **부정**
**공방**:

| 원고 | 피고 |
|---|---|
| 이행청구 | — |
| — | §107①단서: 상대방 악의/과실 |
| 선의·무과실 | — |

**§107① 단서 유추 3유형**: [[대리권남용]] = 법인대표권남용 = 비진의표시 — 모두 동일 법리

> 📌 **답안 문구**
> - **판례**([[93다4480]]): "**진의**라 함은 특정한 내용의 **의사표시를 하고자 하는 표의자의 생각**을 말하는 것이지, 표의자가 진정으로 마음속에서 바라는 사항을 뜻하는 것은 아니다"
> - **판례**([[97다8403]]): "법률상의 효과는 자신에게 귀속시킴으로써 **주채무자로서의 책임**을 지겠다는 것으로 보아야" → 비진의표시 **부정**
> - **판례**([[96다18182]]): "상대방인 금고로서는 **알았다거나 알 수 있었다고 볼 수도 없다**" → 명의대여자의 채무부담 의사 인정
> - **판례**(**일괄사직서**): 경영방침에 따라 **어쩔 수 없이** 제출 → 비진의표시 **O** / 사용자도 알았으므로 §107①단서 → **소급적 무효**
> - **판례**(**물의 사직서**): 사태 수습을 위해 **스스로** 제출 → 당시 최선이라 판단 → 진의 **O** → 비진의 **부정**
> - **학설(유추적용설)**: §107①단서를 [[대리권남용]]·법인대표권남용에 유추적용 — 상대방 **악의·과실** 시 본인에게 **효력 불귀속**

### 통정허위표시 (§108) ★★★

- **요건**: 쌍방 **통정** + 허위 의사표시 → **소급적 무효**
- **판례**: ([[2003다70041]]) §108② 제3자는 **선의이면 족하고 무과실 불요** / 악의 입증은 원고
- **판례**: ([[82다594]]) 채권 가장양도의 채무자는 새로운 이해관계 X → 제3자 **아님**
- **판례**: ([[2019다280375]]) 가등기 본등기 기초 매수인 → §108② 제3자 **아님**
**공방**:

| 원고 | 피고 |
|---|---|
| §108 무효·말소 | — |
| — | §108② 선의 제3자 |
| 피고 악의 입증 | — |

> 📌 **답안 문구**
> - **판례**([[2003다70041]]): "§108② 제3자는 **선의이면 족하고** 무과실은 요건이 **아니다**" / **악의** 입증은 **무효 주장 측**
> - **제3자 정의**([[94다12074]]): "허위표시의 당사자 및 포괄승계인 **이외의 자**로서, 허위표시에 의하여 외형상 형성된 법률관계를 토대로 **새로운 법률상 이해관계**를 맺은 자"
> - **판례**([[82다594]]): "채권의 가장양도에서 채무자는 가장양수인에 대하여 **채무를 부담하는 것이 아니기 때문에** 새로운 이해관계를 가지게 된 자가 **아니어서** §108② 제3자에 **해당되지 않는다**"
> - **판례**([[2019다280375]]): "전득자가 신뢰한 권리외관은 통모에 의한 **가등기 자체가 아니라 원인무효의 본등기**" → 제3자 **아님**
> - **판례**([[2001다11765]]): 금융기관의 **양해**하에 **채무부담 의사 없이** 형식적으로 이루어진 대출약정 → **통정허위표시에 해당**
> - **제3자 O**: 가압류채권자([[2003다70041]]), 허위 근저당의 경매 낙찰자, 전득자(선의)
> - **제3자 X**: 채무자([[82다594]]), 가등기→본등기 기초 매수인([[2019다280375]]), 포괄승계인

### 착오 (§109) ★★★

- **요건**: 법률행위 내용의 **중요부분**에 착오 + 표의자 **중과실 없음**
- **판례**: ([[2000다12259]]) 동기의 착오 → 동기가 **표시**되어 내용 편입 시 취소 가능. 합의까지 불요
- **판례**: ([[2013다49794]]) 상대방이 착오를 **알고 이용** → 중과실 있어도 취소 **가능**
**공방**:

| 원고 | 피고 |
|---|---|
| §109 취소 | — |
| — | 동기 불과 |
| 동기 표시·내용화 | — |
| — | 중과실 |
| 상대방 착오이용 | — |
| — | §109② 선의·무과실 제3자 |

| 착오 유형       | §109 취소                     |
| ----------- | --------------------------- |
| 표시상·내용 착오   | O                           |
| 동기 착오 (원칙)  | X                           |
| 동기 착오 (내용화) | O — 동기 **표시** 또는 상대방 **유발** |
| 시가 착오       | X (원칙). 85% 과다평가 등 현저시 예외   |

> 📌 **답안 문구**
> - **판례**([[2000다12259]]): "동기를 당해 의사표시의 **내용으로 삼을 것**을 상대방에게 **표시**하고 의사표시의 해석상 법률행위의 **내용으로 되어 있다고 인정되면 충분**하고 당사자들 사이에 별도로 **합의까지 이루어질 필요는 없다**"
> - **판례**([[2000다12259]]): "**보통 일반인**이 **표의자의 입장**에 섰더라면 그와 같은 의사표시를 **하지 아니하였으리라고** 여겨질 정도로 **중요한 부분**에 관한 것이어야 한다" (중요부분 판단기준)
> - **판례**([[2000다12259]]): "'**중대한 과실**'이라 함은 표의자의 직업, 행위의 종류, 목적 등에 비추어 보통 요구되는 주의를 **현저히 결여**하는 것"
> - **판례**([[2013다49794]]): "상대방이 표의자의 **착오를 알고 이를 이용**한 경우에는 **중대한 과실**로 인한 것이라도 **취소할 수 있다**" → 중과실 항변의 **재항변 사유**
> - **판례**([[2013다49794]]): "§109의 법리는 적용을 배제하는 별도 규정·합의가 없는 한 **모든 사법상 의사표시에 적용**된다"
> - **판례**([[93다2629]]): 쌍방당사자의 **의사합치**가 있으면 계약서 표시가 잘못되어도 합치된 목적물에 관하여 성립 → **해석 우선**, 착오취소 불요
> - **판례**([[92다29337]]): 시가 착오 = **동기의 착오에 불과** → 원칙 취소 불가 / ([[97다44737]]): 85% 과다평가 등 정도가 **현저**하면 예외적 인정
> - **판례**([[93다24810]]): 세액 차이가 사소하면 **수정해석**으로 해결 가능 → 착오취소 **불허**

### 사기·강박 (§110) ★★★

- **요건**: 기망행위 + **2단의 고의**(① **기망의 고의** ② 이로써 **의사표시를 하게 하려는** 고의) + 착오유발 + 인과관계
- **효과**: 취소 가능 (**중과실 있어도 취소 가능** — §109보다 유리)
- **판례**: ([[85도167]]) 부작위 기망(고지의무 위반)도 기망 인정
- **판례**: ([[96다41496]]) 제3자 사기(§110②) — **대리인 동일시 자 ≠ 제3자**, **단순 피용자 = 제3자**
**공방**:

| 원고 | 피고 |
|---|---|
| §110 취소 | — |
| — | 기망 부존재 |
| 부작위 기망 | — |
| — | §110② 상대방 선의 |
| 상대방 악의/과실 | — |

> 📌 **답안 문구**
> - **판례**([[85도167]]): 매도인이 매수인의 **매수목적을 알면서** 건축 가능한 것처럼 **가장** → **부작위 기망**(고지의무 위반)도 **기망행위에 해당**
> - **판례**([[96다41496]]): "상대방의 **대리인 등 동일시할 수 있는 자**"는 §110②의 제3자가 **아니나**, "**단순한 피용자**"는 제3자에 **포함**
> - **판례**([[92다25120]]): **부정한 이익**을 취할 목적이거나 목적이 정당하더라도 **수단이 부당**한 때에는 위법한 **강박**에 해당
> - **판례**([[92다7719]]): "단지 법률행위 성립과정에서 강박이라는 **불법적 방법이 사용된 데 불과**하면" §103 무효가 **아니라** §110 **강박취소**로 처리
> - **2단의 고의**: ㉠ 상대방을 **기망하려는 고의** ㉡ 기망에 의해 **의사표시를 하게 하려는 고의** — 둘 다 필요
> - **사기와 담보책임 경합**: 타인 물건인 줄 알았더라면 매수하지 않았을 사정 → §110에 의한 **취소 가능** (담보책임과 별도)

### 착오·사기 경합 ★★★

- **경합 가능**: **동기의 착오**(내용화)에서만 — §109 + §110 병존 → §110 우선(중과실 불문)
- **경합 부정**: 표시상 착오 → §109만 적용 ([[2004다43824]])
- **포섭**: 기망 인정 → §110 우선 / 기망 부존재 → §109만(중과실 시 취소 불가)

> 📌 **답안 문구**
> - **판례**([[2004다43824]]): "**사기에 의한 의사표시**란 타인의 기망행위로 말미암아 착오에 빠지게 된 결과 어떠한 의사표시를 하게 되는 경우이므로 거기에는 **의사와 표시의 불일치가 있을 수 없고**, 단지 의사의 형성과정 즉 의사표시의 **동기에 착오**가 있는 것에 불과하다"
> - **구별법**: 표시상 착오 → **§109만** 적용(경합 **부정**) / 동기착오(내용화) → §109+§110 **경합** → **§110 우선**(중과실 불문)
> - **실전 포인트**: 기망 인정 → **§110 우선** 적용(중과실 불문으로 유리) / 기망 부존재 → **§109만**(중과실 시 취소 **불가**)

## 2. 대리 ★★★ [빈출 #2: 119]

| 유형 | 조문 | 핵심 요건 |

- 3유형 공통: 상대방 **선의·무과실** / §126 정당한 이유 입증은 **상대방**

### 무권대리 (§130~§136)

- 본인 추인 없으면 **효력 없음** (유동적 무효)
- **최고 후 침묵**: §131 → **추인 거절** 간주 (≠ §15 제한능력자: 추인 간주 — **정반대**)
- **§135 무권대리인 책임**: 이행 또는 손배 / 면책: 상대방 악의·과실, 무권대리인 제한능력자

### 대리권 남용 ★★

- §107① 단서 **유추** — 대리인이 자기/제3자 이익 + 상대방 **악의·과실** → 효력 불귀속

| 요건 | 내용 |
|---|---|
| ① | 대리인이 **자기 또는 제3자의 이익**을 위하여 대리권 범위 내 행위 |
| ② | 상대방이 대리인의 **배임적 의도를 알았거나 알 수 있었을** 때 (악의·과실) |
| **효과** | **소급적 무효** (§107① 단서 유추) |
| **입증** | **본인 측**이 상대방 악의·과실 입증 |

- **§921 이해상반행위**와 구별: §921 = 행위의 **객관적 성질**상 이해대립 → **[[무권대리]]** / [[대리권남용]] = 외형상 권한 내이나 **주관적 배임** → **§107① 유추** — 순차 검토
- [[표현대리]](§125/§126/§129) 성립 **후에도** 대리권남용은 별도 문제 ([[86다카1004]])
- ([[2016다3201]]) 친권남용 → §107② 유추 → **선의 제3자 보호** / 입증은 무효 주장자

**[[대리권남용]] 공방**: 원고(§114 이행청구) → 피고(대리권남용 항변·§107① 유추) → 원고(선의·무과실 재항변) → [무효 시] §107② 선의 제3자 보호

### 대리 공방 3단 구조

원고(이행청구) → 피고([[무권대리]] §130) → 원고([[표현대리]] §125/§126/§129) → 피고(악의·과실) → [불성립] → §135 무권대리인에게 전환 + [표현대리 성립 시에도] → [[대리권남용]] 별도 검토

> 📌 **답안 문구**
> - **판례**([[86다카371]]): 통설·판례는 대리권남용에 **§107① 단서 유추적용**설 — "상대방이 **배임사실을 알았거나 알 수 있었을** 때"만 효력 부정
> - **판례**([[2011다64669]]): "대리인이 **진의 아님을 알고** 대리권 범위 내 행위를 하였으나 상대방이 그 **배임적 의도를 알았거나 알 수 있었던** 경우 → §107① 단서 유추 → 본인에게 **효력 불귀속**"
> - **판례**([[2016다3201]]): 친권남용 시 **§107② 유추** → **선의 제3자에게 대항 불가**. 선의·악의 **입증은 무효 주장자**(본인 측)
> - **판례**([[86다카1004]]): [[표현대리]] 성립한 경우에도 대리인이 자기/제3자 이익만 꾀한 때에는 **[[대리권남용]]**이 문제 → 상대방 **악의·과실** 시 §107① 단서 유추 **무효**

## 3. 법인 ★★ [빈출 #3: 90]

### 재단법인 출연재산 ★★★

- (전합 [[78다481]]) **법인성립시설** — 설립등기 시 귀속. 부동산 제3자 대항에 **등기** 필요
- 설립 전 상속인 처분 = 유효 / 설립 후 등기 미비 → 대항 불가

### 대표권 제한·남용 ★★

**법인 대표행위 4단계 체계** (교수님 자료):

| 단계 | 요건 | 포인트 |
|---|---|---|
| ① 현명 | 대표기관 명의 행위 | 현명 없으면 귀속 끊김 |
| ② 목적범위 | 권리능력 범위 내 | 초과 = **무효** (§126 유추 문제) |
| ③ 대표권 범위 | 법령/정관 제한 구별 | 정관 = 등기 미비 시 대항 불가 |
| ④ 남용 부재 | 상대방 악의·과실 없을 것 | §107① 유추 |

- **§60**: 정관 제한 → **등기 없으면** **선·악의 불문 대항 불가** (무제한설, [[91다24564]])
- **법령 제한**: 강행규정 → 등기 유무 불문 **무효** ([[98다44642]])
- **남용**: §107① 단서 유추 — 상대방 악의·과실 시 법인에 효력 불귀속 / 입증: **법인 측**

| 유형 | 법률효과 | 비고 |
|---|---|---|
| **정관 위반** | 등기 없으면 대항 불가 (§60) | 선·악의 불문 (무제한설) |
| **목적범위 초과** | **무효** — 권리능력 밖 | §126 유추 문제 |
| **대표권남용** | 원칙 유효, 악의·과실 시 §107① 유추 무효 | 입증: 법인 측 |

**법인 대표행위 공방**: 피고 항변①(정관 제한·§60) → 원고 재항변①(등기 미비 = 대항 불가) → 피고 항변②(대표권남용·§107① 유추) → 원고 재항변②(선의·무과실)

### §35 불법행위 ★★

- **외형설**: ([[2003다15280]]) **외형상** 직무행위면 개인사리·법령위반이어도 인정
- **면책**: 피해자 **악의·중과실**(거의 고의 수준) 시 법인 면책
- §35 = 면책 불가(법인 자신 책임) / §756 = 면책 가능(사용자 대위책임)

### 비법인사단 ★★

- 총유물 처분: 규약·총회결의 미비 → **무효** ([[96다18656]])
- 대표권 제한: 등기 불가 → §60 준용 불가 → 악의·과실은 **비법인사단 측** 입증 ([[2002다64780]])

> 📌 **답안 문구**
> - **판례**(전합 [[78다481]]): 생전처분에 의한 재단법인 출연재산은 "**법인이 성립한 때**"부터 법인의 재산. **제3자 대항**에는 부동산 **이전등기 필요**
> - **판례**([[91다24564]]): "정관에 의한 대표권의 제한은 이를 **등기하지 아니하면** 선의의 제3자에게는 물론 **악의의 제3자에게도 대항하지 못한다**" (**무제한설**)
> - **판례**([[98다44642]]): **법령**에 의한 대표권 제한(**강행규정**) → 등기 유무 **불문 무효**
> - **판례**([[98다2488]]): "목적수행에 필요한지의 여부는 행위의 **객관적 성질**에 따라 판단할 것이고 행위자의 **주관적·구체적 의사**에 따라 판단할 것은 아니다"
> - **대표행위 하자 모답형 3단계**: [1단계] §59·§60 — 정관상 제한이 등기되지 않았다면 선·악의 불문 대항 불가 → 계약 유효 / [2단계] §35① — 정관 위반 등기 시 계약 무효라도 외형상 직무행위면 손배 / [3단계] §107① 유추 — 대표자 사적 이익 + 상대방 악의·과실 → 법인에 효력 불귀속
> - **대표권남용 입증책임**: 상대방의 악의·과실은 **법인 측**이 입증 ([[86다카1004]])
> - **판례**([[2003다15280]]): "행위의 **외형상** 법인의 대표자의 **직무행위**라고 인정할 수 있는 것이라면 설사 대표자 개인의 **사리**를 도모하기 위한 것이었거나 **법령에 위배**된 것이었다 하더라도 **직무에 관한 행위에 해당**한다" (**외형설**)
> - **판례**([[2003다34045]]): 피해자의 '**중대한 과실**'이란 "**거의 고의에 가까운** 정도의 주의를 결여"한 것
> - **판례**([[92다49300]]): 종중 대표자가 종중 소유 부동산을 개인 소유라 하여 매도 후, **대표자 지위에서 이전을 약속**한 행위 → **외형상 직무행위** → 종중 **불법행위책임 인정**
> - **§35 vs §756**: §35 = **면책 불가**(법인 자신 책임) / §756 = **면책 가능**(사용자 대위책임, 선임·감독 상당 주의 증명 시)
> - **판례**([[96다18656]]): "종중 소유의 재산은 종중원의 **총유**에 속하는 것이므로 그 관리 및 처분에 관하여 먼저 **종중규약**에 정하는 바가 있으면 이에 따라야 하고, 그 점에 관한 종중규약이 없으면 **종중총회의 결의**에 의하여야 하므로, 비록 종중 대표자에 의한 종중 재산의 처분이라고 하더라도 그러한 절차를 거치지 아니한 채 한 행위는 **무효**이다"
> - **총유물 관리·처분행위 예시**: 매매계약 체결, 물적 담보 제공, 신축 건물 분양 → 규약·총회결의 미비 시 **무효**
> - **총유물 처분 vs 단순 대표권 제한**: 총유물 관리·처분 = **절대적 무효**(§275·§276) / 단순 대표권 제한(보증·대출 등) = 상대방 **악의·과실** 시에만 무효
> - **판례**([[2002다64780]]): "비법인사단의 경우에는 대표자의 대표권 제한에 관하여 **등기할 방법이 없어** §60의 규정을 **준용할 수 없고**, 사원총회 결의사항은 **내부적 의사결정에 불과**하므로, 상대방이 대표권 제한 사실을 **알았거나 알 수 있었을 경우가 아니라면** 그 거래행위는 **유효**하다. 악의·과실은 **비법인사단 측이 입증**"
> - **판례**([[2006다37465]]): 사원총회·이사회 의결에 찬성하였다는 이유만으로 제3자에 대한 불법행위책임을 부담한다고 할 수 **없다** (법인의 **내부행위**에 불과)

## 4. 제한능력자 ★★ [빈출 #4: 53]

### 미성년자 (§5)

- 법정대리인 동의 없는 법률행위 → **취소** → 소급적 무효(§141) → **현존이익** 한도 반환
- **속임수(§17)**: **적극적 기망** 필요, 단순 침묵 ≠ 속임수
- **묵시적 동의**: ([[2005다71659]]) 연령·지능·직업·소득·계약경위 종합 판단
- **신의칙으로 취소 제한 불가**: 강행규정 우선 → [[신의칙]]·금반언 **배척**

### 확답촉구 결론 반대

- §15 제한능력자 최고 → 침묵 = **추인 간주**
- §131 [[무권대리]] 최고 → 침묵 = **거절 간주**

> 📌 **답안 문구**
> - **판례**([[2005다71659]]): "법정대리인의 동의는 언제나 **명시적**이어야 하는 것은 아니고 **묵시적으로도 가능**한 것" — 묵시적 동의 여부는 ㉮**연령·지능** ㉯**직업·소득** ㉰**계약경위** 종합 판단
> - **판례**([[2005다71659]]): 미성년자의 신용구매 취소가 "**신의칙에 위배된 것이라고 할 수 없다**" — 제한능력자 보호는 **강행규정**이므로 [[신의칙]]·금반언으로 취소권 제한 **불가**
> - **판례**([[2008다58367]]): **의사무능력**을 이유로 한 무효의 경우에도 §141 단서(**현존이익** 한도 반환) **유추적용**
> - **판례**([[2003다60297]]): 신용카드 이용계약 취소 시 회원은 매매대금 지급채무를 법률상 원인 없이 면제받는 이익 → **금전상 이득**으로서 **현존하는 것으로 추정**
> - **§17 속임수**: 단순 침묵 ≠ 속임수, **적극적 기망행위** 필요. 입증: **상대방** 측
> - **취소권 포기 특약**: 사전 포기는 **강행규정 위반으로 무효**

## 5. 신의칙 ★★ [빈출 #5: 30]

| 원칙 | 핵심 | 제한 |
|---|---|---|
| **금반언** | 선행행위 모순 후행행위 금지 | 강행법규 위반 무효 시 X |

| **권리남용** | 객관+주관(추인 가능) | — |

> 📌 **답안 문구**
> - **금반언 한계**: 선행행위가 **강행법규에 위반하여 무효**인 경우, 무효 주장은 [[신의칙]] 위반이 **아님** — 강행법규 **입법취지** 훼손 방지
> - **금반언 판례**: 무권대리인이 본인을 **상속 후** 자기 대리행위가 무권대리라며 무효 주장 → 금반언에 **반한다**
> - **실효**: **소유권 등 항구적 권리**에는 적용 **곤란**. **형성권**(해제권)에는 적용 **가능** — 상당기간 불행사 + 계약 유효를 전제로 행동 + 갑작스런 행사 = 실효
> - **사정변경**([[2004다31302]]): "**계약준수의 원칙의 예외**로서 계약해제가 인정될 수 있다" — 요건: ①**예견불가** 현저한 변경 ②**객관적** 사정(주관적 동기만으로 **부족**) ③당사자 **무책** ④신의칙에 **현저히** 반함
> - **사정변경 인정**: **퇴사** 시 계속적 보증계약 → **해지권 인정** / **부정**: 부지 매수 후 음식점 불가 → **주관적 사정** 변경에 불과
> - **[[권리남용]]**: 판례는 **객관적 요건**(사회적 목적 부적합·정당이익 결여) + **주관적 요건**(가해의사) **모두** 필요. 주관적 요건은 **객관적 사정에서 추인** 가능
