# 민법 동계 1학년 진급시험 찌라시 (2022·2023·2024·2024재)

시험 직전 압축본. 회차 표기: 22/23/24/24재. 각 쟁점 ③함정(X지문)을 최우선으로 본다.

## 민법총칙 — 권리일반·신의칙·실종

- 신의칙: 채권자는 물상보증인에게 주채무자 신용상태 고지할 신의칙상 의무 없음. X지문: "고지의무를 부담한다"는 틀림 (2017다254051) (22-1)
- 강행법규 위반자가 스스로 무효 주장해도 신의칙 위반 아님. 신의칙상 고지의무는 계약 체결 시뿐 아니라 이행 과정에서도 유지. X지문: 실효원칙은 기간 경과만으론 부족, 상대방의 정당한 신뢰 필요 (24-39)
- 보호의무(반복: 24·24재): 병원은 입원환자 휴대품 도난방지 신의칙상 보호의무 있음 (2002다63275). X지문: 카지노사업자는 영업규제만으로 이용자 보호의무 인정 안 됨, 숙박업자는 안전배려 보호의무 부담함 (24-17 / 24재-39)
- 실종선고(반복: 24·23): 실종기간 만료 시 사망 의제(제28조), 취소 전엔 반증으로 효과 못 다툼. X지문: "실종선고 시부터 사망 의제"는 틀림 / "취소 전이라도 번복된다"는 틀림 (24-33 / 23-1)

## 민법총칙 — 제한능력·법률행위·착오·조건

- 미성년자 취소(반복: 23·22): 법정대리인이 매매대금 일부 이의 없이 수령=법정추인(제145조)→취소 불가. X지문: "취소할 수 있다", "미성년자 단독취소 불가", "취소는 선의 제3자에 대항 불가" 모두 틀림(취소는 절대효) (23-2 / 22-2)
- 착오(반복: 24·24재·23): 상대방이 착오를 알고 이용했으면 중과실 있어도 취소 가능. 화해계약은 분쟁 외 사항·당사자자격 착오면 취소 가능. 착오취소와 하자담보책임은 별개(2015다78703). 해제 후에도 착오취소 가능. X지문: "중과실 있으면 무조건 취소 불가" 틀림 (24-1 / 24재-6,9 / 23-6)
- 오표시무해: 쌍방 Y토지 의사인데 계약서에 X로 오기→계약은 Y토지에 성립. X지문: "X토지에 성립"은 틀림 (2629) (24재-6)
- 반사회질서: 매매목적물·대금은 사후 특정 기준이 정해져 있으면 족함. X지문: "체결 당시 구체적 확정 요한다"는 틀림 (2008다1842) (22-4)
- 무효일반(반복: 24·24재): 소집통지에 없던 사항도 구성원 전원 참석·의결하면 결의 유효. 불공정행위는 추인으로 유효화 불가·무효행위전환은 가능. 증여 등 무상행위는 불공정 논의 대상 아님. 다운계약서만으론 무효 아님. X지문: "전원 참석·의결해도 무효"는 틀림 (24-7 / 24재-8)
- 조건(반복: 24·24재): '조건성취 방해'는 방해 없었으면 성취됐을 정도여야 함. 정지조건부 사실은 효과발생 다투는 자가 증명. X지문: "성취가능성 현저히 낮은 경우도 포함"은 틀림 (2022다266645) (24-3 / 24재-15)

## 민법총칙 — 법인·종중

- 법인 불법행위(반복: 24·24재·23·22): 대표자 직무상 불법행위→법인은 제35조 책임, 제756조 사용자책임 아님(2009다57033). X지문: "사용자책임도 물을 수 있다"는 틀림 (22-5 / 23-3 / 24-34) ⚠ 22-5는 정답 ⑤
- 법인 채무불이행(반복: 24·24재): 적법 대표권 행위의 채무불이행책임은 법인에 귀속, 대표기관 개인책임은 제750조 불법행위 별도 성립해야 함(2017다53265). X지문: "불법행위 별도 성립 안 해도 개인책임 진다"는 틀림 (24-4 / 24재-3)
- 이사 해임(반복: 24·24재): 위임 유사관계로 원칙 해임 가능하나 정관에 해임사유 정하면 그 절차 따름. X지문: "정관에 사유·절차 정해도 신뢰파탄 정도 아니면 해임 불가"는 틀림 (2023다263537) (24재-2 / 24-34)
- 종중: 고유 종중은 자연발생적, 조직행위 불요. 총유재산 처분은 규약·총회결의 거쳐야 유효. X지문: "종중 임원은 선관주의의무 없다"는 틀림 (2017다231249) (24재-4)

## 민법총칙 — 대리·무권대리·표현대리

- 무권대리 추인·철회(반복: 24·24재): 추인은 명시·묵시 가능, 승계인에게도 가능. 무권대리인 책임(제135조)은 무과실책임. 손배예정 약정 있으면 제398조 적용. 철회 시 악의 입증책임은 본인. X지문: "제3자 기망·문서위조면 무권대리인 책임 부정"은 틀림 (24-6 / 24재-1,7,11)
- 내용변경 추인: 4억으로 바꾼 추인은 상대방 동의 없으면 무효. 권한초과 표현대리 정당이유는 대리행위 당시 기준. X지문: "이후 사정 종합 고려"는 틀림 (81다카549) (24재-7)
- 임의대리(반복: 23·22): 매매대리인은 중도금·잔금 수령권한 있음→대금 본인 미전달도 이행거절 불가. 매매대리권만으론 해제권 없음. 상대방 대리인이 기망하면 상대방 선·악의 불문 취소 가능(96다41496). X지문: "상대방이 알았거나 알 수 있었을 때만 취소"는 틀림 (23-8 / 22-8)
- 제3자 사기(반복: 24재·23): 제110조2항—상대방이 알았거나 알 수 있었을 때 취소. X지문: "안 때에 한하여"로 좁힘은 틀림(알 수 있었을 경우도 포함) (24재-5)
- 표현대리(23-7): 사후 정산 합의했다가 결렬되어도 무권대리 추인으로 봄. 제125·126·129조 중첩 주장 가능, 성명모용도 제126조 유추 (94다45098) (23-7)
- '선의' 보호 모아(반복: 24·23): 비법인사단 대표권제한 위반 거래는 상대방이 알았거나 알 수 있었던 경우 아니면 유효. 대리권남용은 제107조1항 단서 유추·선의 제3자에 무효 대항 불가. 준점유자 변제의 '선의'는 적극적으로 진정 권리자라 믿었음을 요함. X지문: "준점유자 선의에 믿음 불요"는 틀림 (24-5 / 23-4) ⚠ 정답논란: 23-4 정답표③(ㄴㄷ)과 해설(ㄱ긍정·ㄹ부정) 불일치, 재확인

## 민법총칙 — 소멸시효·제척기간

- 소멸시효 기산점(반복: 24·24재): 기산일은 변론주의 대상→당사자 주장 기산일 기준. 부작위채권은 위반행위 시(제166조2항), 부당이득은 성립 시. X지문: "본래 기산일 기준 계산"은 틀림(변론주의) / "매매대금채권은 동시이행항변 있으면 시효 진행 안 함"은 틀림(지급기일 후 진행) (94다35886) (24-8 / 24재-12)
- 보증금반환채권 시효(22-11): 임대차 종료 후 보증금 받으려 목적물 점유 중이면 시효 진행 안 함(2016다244224). 1개월 단위 관리비채권은 3년 단기시효(제163조) (22-11)
- 제척기간(22-12): 매매예약완결권은 예약체결일로부터 10년, 행사시기 약정해도 연장 안 됨. X지문: "행사할 수 있는 때로부터 10년 연장"은 틀림 (94다22682) (22-12)
- 미등기매수인 등기청구권 시효(23-14): 인도받아 사용·수익 또는 제3자에 처분·인도해도 권리 위에 잠자는 자 아님→시효 진행 안 함. X지문: "제3자 인도 시점부터 시효 진행"은 틀림 (23-14)

## 물권법 — 물권변동·중간생략등기·등기 추정력

- 중간생략등기(반복: 24·23): 전원합의 없으면 최종양수인이 직접 청구 불가하나 중간자 대위청구는 가능. 합의 있어도 매도인의 중간자에 대한 대금청구권 행사 제한 안 됨. X지문: "대위청구할 수 없다"(23) / "대금청구 제한된다"(24)는 틀림 (23-11 / 24-10)
- 등기 추정력(반복: 24·24재·23·22): 말소 청구하는 무효주장자(전등기명의인)가 무효사실 증명책임. 사망자 명의 신청 이전등기는 원인무효→유효주장자가 실체관계 부합 증명. 이전명의자는 전 소유자에 대해서도 적법 추정. 가등기는 구체적 등기원인 추정 안 됨. X지문: "등기원인 다르게 주장하면 추정력 깨짐", "전주에겐 추정력 안 미친다"는 틀림 (22-22 / 23-12 / 24-9 / 24재-16)
- 공유지분 포기(22-13): 상대방 있는 단독행위지만 도달만으론 효력 없고 등기해야 물권변동(제186조). X지문: "도달하면 곧바로 효력 발생"은 틀림 (2015다52978) (22-13)
- 가등기(23-13): 말소된 가등기 회복등기의무자=말소 당시 소유자(제3취득자). 본등기 등기의무자=가등기 당시 소유자(구별). X지문: "회복등기의무자는 가등기 할 때 소유자"는 틀림 (2006다43903) (23-13)

## 물권법 — 점유·점유자와 회복자

- 점유자와 회복자(반복: 24·24재·22): 선의 점유자라도 본권의 소 패소 시 소제기 때(소장부본 송달)부터 악의 의제(제197조2항). 필요비·유익비는 점유물 반환 시 청구 가능. 과실취득 점유자는 통상필요비 청구 불가. 악의 점유자는 소비한 과실 대가 보상. 선의·자주 점유자는 현존이익 한도 배상. X지문: "유익비를 반환 전에도 청구", "타주점유자 전부배상" 등 (24-11 / 24재-17 / 22-20)
- 점유보호(반복: 23·24재): 직접점유자가 임의 양도하면 간접점유자 점유 침탈 아님→점유회수의 소 불가. 사기로 명도해 준 것은 침탈 아님. 점유 회수 시 점유 계속 의제(제192조2항). X지문: "간접점유자가 점유회수의 소 제기 가능"은 틀림 (92다5300) (23-16 / 24재-19,24)
- 간접점유·상속점유(24재-24): 간접점유자는 직접점유자에 반환청구 가능, 못 받을 때 자기에게(제207조2항). 타주점유자로부터 상속한 점유는 타주점유. X지문: "지상권 설정 토지소유자가 불법점유자에 손해배상 청구 가능"은 틀림(물권적청구권만, 손배 불가) (24재-24)

## 물권법 — 취득시효

- 점유취득시효(반복: 24·24재·23·22): 20년 점유는 등기해야 소유권 취득(제245조). 시효완성자는 등기 전까진 소유자 아님→시효완성 후 양수인에 말소·진정명의회복 청구 불가. 시효완성 이전등기청구권 양도는 양도제한 법리 부적용→통지만으로 대항. 점유 상실 후 10년 미행사 시 등기청구권 시효소멸. X지문: "미등기 부동산은 등기 없이 취득", "반사회질서면 진정명의회복 청구 가능"은 틀림 (22-14,21 / 23-19 / 24-13 / 24재-13,20)
- 대상청구권(22-14): 시효완성 등기청구권 이행불능 시 대상청구하려면 이행불능 전 시효완성 권리주장·등기청구 했어야 함. X지문: "주장 안 했어도 대상청구 가능"은 틀림 (94다43825) (22-14)
- 사해행위취소 후 등기부취득시효(23-19): 사해행위취소는 상대적 효력→수익자 점유는 취득시효 기초 점유 아님 (2013다206313) (23-19)
- 분묘기지권(24재-18): 봉분 등 외형 갖추면 등기 없이 성립, 무단설치도 시효취득 가능. 승낙형 지료약정은 승계인에게도 미침. X지문: "지료약정이 경매 매수인에 안 미친다"는 틀림 (2017다271834) (24재-18)

## 물권법 — 선의취득

- 선의취득(반복: 23·22·24재): 제251조도 무과실이 당연 요건. 도품·유실물 특칙(제250·251조)에 위탁물 횡령·점유보조자 횡령은 불포함. 반환청구권 양도+대항요건으로 점유요건 충족. 점유개정으로는 선의취득 불가. X지문: "점유보조자 횡령물도 도품으로 대가변상 후 반환청구 가능"은 틀림 (91다70) (22-19 / 23-15 / 24재-19)

- 경매 담보책임(24재-34): 경매절차 무효로 소유권 못 얻으면 일반 부당이득은 가능하나 제578조 경매 담보책임은 인정 안 됨. X지문: "경매 담보책임도 물을 수 있다"는 틀림 (2003다59259) (24재-34)
