# 민법 하계 1학년 진급시험 찌라시 (2022·2023·2024 3개년)
인쇄용 시험 직전 압축본. 각 쟁점 ①요건골격 ②핵심판례 ③X지문 함정 순. (반복: 24·23·22)는 그 연도에 반복 출제된 빈출 논점.

## 1. 민법총칙 — 능력·주체·법인

- 미성년자·법정대리: 대리인은 행위능력자 요하지 않음(§117), 미성년자 대리행위 취소 불가 / 법정대리인은 허락 영업 취소 가능(§8②) / 공동친권자가 수인 미성년자 대리한 상속재산분할협의는 전원 추인 없으면 무효(§921).
  X지문: "미성년자가 대리인으로 한 행위 취소 가능"(취소 불가가 맞음) / "법정대리인은 허락영업 취소 못함". (92다54524) (24문2,22문1)
- 법정대리인 대리권 남용: 유흥비 목적·저가 매도를 상대방이 알았거나 알 수 있었으면 효과 본인에 안 미침(옳은 지문, 함정 아님). (22문1)
- 성년후견개시: 본인 의사 고려 의무(§9②). X지문: 본인 의사 고려 안 해도 된다는 취지. (23문2)
- 미성년자 신용카드: 이용계약 취소는 신의칙 위반 아님 / 부당이득 반환대상은 물건 자체 아님. (2005다71659, 2003다60297) (23문3)
- 실종선고: 실종기간 만료한 때 사망 간주(실종선고 시 아님, §28), 특별실종 기간은 위난종료일부터 1년. X지문: "실종선고 시 사망 간주". (24문3,23문4)
- 법인 권리능력·영리성: 목적에 간접 필요한 행위도 권리능력 범위 / 재단법인은 수익 분배 구성원 없어 영리법인 불가. (23문5)

## 2. 법인 불법행위책임 §35 (반복: 24·23·22)

- §35 요건: 사실상 대표자도 §35 대표자 / 대표권 남용(자기이익)이라도 §35 책임 가능 / 대표자는 권한 포괄위임 불가(§62) / 직무관련성은 상대방 악의·중과실일 때만 책임 부정.
  X지문: "직무관련성을 상대방이 단순 과실로 몰랐으면 책임 부정"(악의·중과실 요함이 맞음). (2002다27088) (24문4,22문2)
- 외형상 직무행위 기준 / 조합원의 간접적 손해는 §35 손해에 불포함 / 법인 불법행위 성립 시 대표기관도 부진정연대책임. (68다2320, 99다19384) (23문6)

## 3. 비법인사단·종중 (반복: 24·22)

- 비법인사단: 등기능력 인정(부등법 §26)·당사자능력 인정(민소 §52) / 채무보증(단순 채무부담)은 총유물 관리·처분 아님 / 정관상 결의 안 거친 대표행위는 상대방이 제한을 알았거나 알 수 있었으면 무효(§60 준용 불가).
  X지문: "을이 제한을 알았거나 알 수 있었어도 유효"(악의·과실이면 무효). (2004다60072전합, 2002다64780) (24문5,22문3)
- 종중 임원은 재산관리·처분에 선관주의의무 부담 / 불공정 분배결의는 무효. X지문: "종중 임원 주의의무 없다". (2017다231249) (23문7)

## 4. 물건·주물종물·법정지상권 종된권리성 (반복: 24·23·22)

- 법정지상권부 건물 매수(양수)인: 별도 등기 없이 당연취득 못 함, 지상권이전등기 청구만 가능(§100②는 §187 '법률규정' 아님) / 저당권 실행 경락인은 등기 없이 지상권 당연취득(§187).
  X지문: "매매로 양수한 자도 등기 없이 당연 취득"(양수=등기 필요 vs 경락=등기 불요 구분이 핵심). (84다카1131전합, 92다527) (24문6,23문8,22문4)
- 종물: 타인 소유 부속동산은 낙찰자가 당연취득 못 하고 선의취득 요건 필요. (2007다36933) (24문6)

## 5. 의사표시 — 강박·반사회질서·불공정·비진의 (반복: 24·22)

- 제3자 강박: 상대방(병)이 선의·무과실이면 취소 불가(§110②) → 증여 취소 못 함.
  X지문: "강박이면 반사회질서 무효", "증여도 불공정행위(§104) 대상", "강박 증여는 비진의표시". 모두 X(④ 정의 악의만으론 반사회질서 무효 안 됨). (2000다47361, 93다6409) (24문7,22문5)

## 6. 의사표시 — 반사회질서·불공정(개별) (반복: 23)

- 반사회질서: 공무원이 승인 관련 금원 받기로 한 증여 = 무효 / 강제집행 면탈 허위 근저당은 반사회질서 아니라 통정허위표시 / 양도세 회피 매매는 반사회질서 아님. (2007다63966) (23문10)
- 불공정(§104): 폭리 의도(주관적 요건) 필요, 계약 당시 기준(사후 불균형엔 적용 X) / 형사 성공보수약정 무효 / 수취거부 정당사유는 거부자가 증명. (2015다200111전합, 2013다40353) (23문9)

## 7. 통정허위표시 §108② 제3자 (반복: 24·23·22)

- 보호 제3자 O: 허위채무 진실로 믿고 이행한 보증인 / 본등기에 터잡아 선의로 이전등기 받은 양수인 / 파산관재인(선·악의는 총파산채권자 기준) / 가압류권자(등기상 이해관계인 승낙의무).
- 제3자 X(부정): 가장양도 채권자(가등기권자).
  X지문: "정이 선의여도 병(중간자)이 악의면 무효 주장 가능"(제3자 보호는 각자 기준, 정 선의면 갑은 정에게 무효 주장 불가). (2018다268538, 99다51258, 94da12074, 80다1403) (24문8,23문11,22문6)

## 8. 착오 (반복: 24·22)

- 적법 해제 후에도 착오 취소권 행사 가능(해제로 취소권 배제 안 됨) / 동기착오는 상대방이 제공·유발 시 표시 불문 취소 가능 / 착오 취소 시 상대방 불법행위책임 못 물음.
  X지문: "채무불이행 해제 후엔 착오 취소 불가". (91다11308) (24문9,22문7)

## 9. 대리·복대리·무권대리 (반복: 24·22)

- 임의대리인은 본인 승낙·부득이한 사유 없이 복대리인 선임 불가(§120), 위반 복임은 무권대리.
  X지문: "임의대리인 복임 후 효과가 본인에 당연 귀속". (24문10,22문8)
- 대리인이 기망하면 본인 선·악의 불문 취소 가능(대리인은 §110① 제3자 아님) / 가장매매 전득자 선의면 소유권 취득(§108②). (24문10,22문8)
- 무권대리 추인은 계약체결 시로 소급(§133) / 위임 종료 후에도 급박사정 시 존속(§128·§691) / 현명주의(§114). (23문12)
- 대리권 남용: 유권대리로 인정되면 남용 사정 상대방이 알 수 있었어도 유효 / 대리인의 이중매매 적극가담은 본인 인식 무관 무효. (23문12)
- §135 무권대리인 책임은 무과실책임(문서위조로 야기돼도 인정) / 철회하려는 상대방은 대리권 없음 몰랐다 주장만 하면 되고, 알았다는 증명책임은 본인에게.
  X지문: "철회 위해 상대방이 선의를 증명해야". (2017다213838, 2013다213038) (22문10)

## 10. 표현대리 §125·§126·§129 (반복: 24·22)

- 대리권 소멸 후 복대리인 선임·대리행위에도 §129 표현대리 성립 가능 / §129 인정 후 권한 넘는 행위엔 §126 성립 가능 / 성명모용은 §126 유추적용 가능.
  X지문: "대리권 소멸 후 복대리인 행위엔 §129 성립 불가". (97다55317, 2007다74713, 87다카273) (24문11,22문9)
- §125는 상대방 선의·무과실 시만 / §126 정당이유 판단 기준시는 대리행위 당시. (22문9)
- 무권대리 추인: 의제자백으로는 추인 안 됨 / 정산 합의는 결렬·미이행이어도 추인 효력 유지 / 권한초과+수여표시 표현대리 병합주장 가능. (81다648) (23문13)

## 11. 무효·무권리자처분추인·무효행위전환·불법원인급여 (반복: 24·23·22)

- 무권리자 처분 → 권리자 추인 가능(§130·§133 유추) / 불공정행위 무효라도 §138 무효행위 전환 가능 / 기간도과 상속포기도 협의분할로 효력 여지.
  X지문: "농지법 잠탈 명의신탁 이전은 불법원인급여라 진정명의회복 못 함"(불법원인급여 아니어서 청구 가능). (2017다3499, 2009다50308, 95다45545, 2013다218156전합) (24문12,23문14,22문11)

## 12. 취소·법정추인·일부취소 (반복: 23·22)

- 취소권자가 채권자로서 담보 제공받음 = 법정추인사유 O(§145 4호) / 강박 미해소 상태 추인은 무효 / 가분적 행위 일부취소 가능 / 행사기간 추인가능일부터 3년·법률행위일부터 10년(§146).
  X지문: "담보 제공받는 것은 법정추인 아님". (81다107, 97다44737) (23문15,22문12)

## 13. 토지거래허가·유동적 무효 (반복: 24·22)

- 협력의무 불이행은 손배청구만 가능, 매매계약 자체 해제 불가 / 타인 명의 도용 매수는 처음부터 확정적 무효 / 제3자 지위승계 합의해도 협력의무 이행청구 불가 / 유동적무효(허가 전)엔 중도금 이행지체로 해제 불가.
  X지문: "유동적무효 상태에서 이행지체로 해제 가능". (98다40459전합, 90다12243전합, 96다7762, 97다4357) (24문13,22문13)

## 14. 조건과 기한 (반복: 24·23·22)

- 조건 존재 여부는 사실인정 → 주장하는 자가 입증책임 / 불확정기한에서 사실발생 불가능 확정 시 이행기 도래 간주 / 채무면제(단독행위)도 불리하지 않으면 조건 가능 / 기한이익 상실 특약 유효.
  X지문: "채무면제엔 조건 못 붙임", "불확정기한 사실 불가능 시 이행기 도래 안 함". (2006다35766) (24문14,22문14)
- 도급 '검사 합격'은 순수수의조건 아님(불확정기한 또는 정지조건). X지문: 순수수의조건이라는 취지. (2004다21862) (23문16)

## 15. 소멸시효·제척기간 (반복: 24·22)

- 하자담보책임 손배청구권은 §582 제척기간+§162① 소멸시효 함께 적용(제척기간이 시효 배제 안 함) / 변론주의상 당사자 주장 기산일 기준 / 시효이익 포기 상대효 — 주채무자 포기해도 보증인은 시효소멸 원용 가능.
  X지문: "제척기간 적용되므로 소멸시효 적용 배제". (2011다10266) (24문15,22문15)

## 16. 소멸시효 — 보증·응소·후순위·보험금 (반복: 24·23)

- 주채무자 시효이익 포기해도 보증인은 시효완성 주장해 이행 거절 가능(§433) / 보험금청구권 기산점(객관적으로 알 수 없던 사정 고려) / 부정취득 목적 다수 보험계약 무효 시 부당이득반환청구권은 상사 5년 시효.
  X지문: "보험계약 무효 부당이득은 민사 10년 시효"(상사 5년). 응소 후 6월내 조치 시 응소 시 소급중단(O) / 후순위 담보권자는 선순위 시효완성 주장 불가(O). (2000다31168, 2019다277812, 2016다232597) (24문16,23문17)

  X지문: "을 점유취득시효 완성=실체관계 부합 → 말소청구 가능"(후행 보존등기는 부합으로도 유효화 안 됨, 말소 불가). 병 등기부취득시효 완성 시 갑은 병 명의 말소청구 가능(O). (2010다107064) (24문19,22문18)
- 가등기만으론 이전등기 청구할 법률관계 추정 안 됨 / 전 소유자 사망 후 그 명의 신청 이전등기는 추정력 부정 / 보존등기 명의자가 신축자 아니면 추정력 깨짐. X지문: "가등기로 본등기 청구권 추정". (79다239) (22문19)
- 점유: 점유매개관계는 직접점유자 반환 전엔 단절 안 됨 / 직접점유자 임의 양도는 간접점유자 점유 '침탈' 아님 → 점유회수의 소 불가. X지문: "간접점유자가 양수인에게 점유회수의 소 가능". (2019다205329, 92다5300) (23문19,23문20)

## 22. 주위토지통행권·상린관계 (반복: 24·22)

  X지문: "무단점유여도 자주점유 추정 안 깨짐", "2차 취득시효 주장 불가". (2002다57935) (24문23,22문23)

## 26. 선의취득 (반복: 24·23·22)

- 채무자 아닌 자 소유 동산 경락·선의취득 시, 원소유자는 채무자가 아니라 배당받은 채권자에게 배당금을 부당이득 반환청구 / 점유개정에 의한 선의취득 부정 / 도품 공개시장 매수·선의취득 후 반환 시 대가변상청구권 행사 가능(§251) / 거래행위 취소되면 선의취득 불가.
  X지문: "채무자에게 시가 상당액 부당이득 청구". (98다6800, 77다1872, 72다115) (24문25,22문25)

## 28. 공유 (반복: 24·22)

## 29. 구분소유적 공유 (반복: 24·23·22)

- 제3자 방해엔 자기 구분부분뿐 아니라 전체토지에 보존행위로 배제 청구 가능 / 경매 지분 취득 시 집행법원이 특정 구분목적물로 평가한 경우만 구분소유적 공유 승계, 아니면 1필지 전체 공유지분 취득 / 각자 특정 구분부분 단독 처분 가능 / 강제경매로 지분 취득 시 관습법상 법정지상권 취득 가능.
  X지문: "제3자 방해에 전체토지 배제청구 불가", "경매 시 구분소유적 공유 당연 승계". (93다42986, 2006다68810) (24문28,22문28)
- 구분소유적 공유지분 근저당권은 공유관계 해소 후에도 종전 지분비율대로 분할 토지 전부에 존속. (89다카24094, 2012다25944) (23문28)

## 30. 부동산 명의신탁 (반복: 24·23·22)

  X지문: "계약명의신탁 신탁자 지시 이전 약정 유효", "3자간 명의신탁에 경매취득 법리 적용 안 됨". (2014다63315, 2016다34007, 2011다89903, 2019다203811) (24문29,23문29,22문29)

## 31. 부합 (반복: 24·23·22)

  X지문: "증축부분 소유권 취득 못 함", "현재 가액 비율로 공유". (2000다63110, 2009다15602, 2006다39270) (24문30,23문30,22문30)

## 32. 지상권·관습법상 법정지상권 (반복: 24·23·22)

  X지문: "가등기담보 본등기 사안 법정지상권 취득", "미등기 매수인 신축 해제 시 대항 가능". (94다5458, 87다카2895) (24문31,22문31)
- 나대지 환매특약 등기 후 건물 신축·환매권 행사로 소유자 분리 시 관습상 법정지상권 애초부터 불성립(철거 운명 예상). X지문: "환매 사안 법정지상권 인정". (2010두16431) (23문31)

## 33. 지역권 (반복: 24·23·22)

  X지문: "1인 중단·정지는 다른 공유자에 효력 없음". (24문32,23문32,22문32)

## 34. 전세권·§304/§305 (반복: 24·23·22)

  X지문(가장 강한 함정): "토지소유자가 전세권자에게 퇴거청구 가능"(불가). (2006다14684) (24문33,23문33,22문33)

## 35. 동시이행관계 (반복: 24·23·22)

  X지문: "담보반환의무가 변제와 동시이행", "근저당 말소의무 동시이행 아님", "채권증서 반환이 동시이행", "수령지체자는 동시이행항변 못 함". (2019다247651, 2010다11323) (24문34,23문34,22문34)

## 36. 위험부담 (반복: 23·22)

- 매수인이 인수한 근저당 피담보채무 변제 게을리해 근저당 실행으로 매도인 소유권 상실 = 매수인 책임 사유 이행불능(매도인 과실 X) / 쌍방 무책 이행불능 시 기이행 급부는 부당이득 반환 / §538① 제2문 적용에 현실·구두 제공 필요.
  X지문: "매도인 책임 있는 사유로 인한 이행불능". (2007다8464) (23문35,22문35)

## 37. 계약 해제·원상회복 (반복: 24·23·22)

- 해제 전 제3자 처분으로 원물반환 불능 시 반환 가액은 처분 당시 대가·시가 상당액(+이득일부터 법정이자) / 합의해제 반환금전엔 받은 날부터 이자 가산의무 없음 / 원상회복청구권엔 과실상계 준용 안 됨 / 해제로 소멸 채권 양수해 급부받은 자는 원상회복의무 있음.
  X지문: "처분 당시 아닌 기준으로 반환", "합의해제 이자 가산해야", "원상회복에 과실상계 제한 가능". (2013다14675) (24문36,23문37,22문36)
- 무효 명의신탁 수탁자가 제3자와 매매·이전등기 후 그 매매 해제 시 수탁자는 제3자에게 원상회복 청구 가능(매매 유효). X지문: "수탁자는 원상회복 청구 못 함". (2008다94714) (23문36)

## 38. 이행지체·해제·이행제공·해약금 (반복: 24·22)

- 한 번 이행제공으로 상대방 이행지체 빠뜨린 후 최고하는 당사자는 제공 계속할 필요 없음(이행 준비만) / 소송제기는 이행 착수 아니므로 매수인은 계약금 포기하고 해제 가능 / 해제는 손배청구에 영향 없음(§551), 별도 배상 필요 / 이행기 전 이행거절 명백 시 이행제공·최고 없이 해제 가능(§544 단서).
  X지문: "제공 계속해야", "소제기로 착수돼 해제 불가", "수령 대금만 지급하면 해방". (96다35590, 2007다72274, 2000다22850) (24문37,22문37)

## 39. 예약·매매예약완결권 (반복: 24·23·22)

- 예약완결권은 형성권, 행사기간 약정 시 그 기간 내, 무약정 시 예약 성립부터 10년 내 행사, 제척기간 경과로 소멸 / 목적물·가액 확정·확정가능 안 되면 일방예약 성립에 영향 / 복수채권자 가등기 시 완결권 항상 공동행사 아님(예약 내용에 따름) / 재판상 행사는 소장 송달 시.
  X지문: "행사기간 10년 초과 약정해도 10년 경과로 소멸", "목적물 미확정도 영향 없음", "항상 공동 행사", "소장 제출 시 행사". (94다22682, 2017다42077, 93다4908, 2010다82530전합) (24문38,23문38,22문38)

## 40. 매매 계약금·해약금·과실수취·부당이득 (반복: 24·23·22)

- 계약금 일부(300만)만 지급 시 해약금 해제 기준은 약정 계약금(1,000만) → 600만 지급으로 해제 불가 / 동시이행 중에도 잔금지급청구권 소멸시효 진행 / 미등기 매수인 점유·사용해도 매도인 임료 상당 부당이득 청구 불가 / 대금 전부 지급 후 미인도 매수인은 과실수취권.
  X지문: "교부액(300) 배액 600 지급으로 해제 가능". (2014다231378, 90다9797, 95다12682, 93다28928) (24문39,23문39,22문39)

## 41. 매도인의 담보책임 (반복: 24·23·22)

- 강제경매 기초 등기가 원인무효여서 경매 무효 시 매수인은 §578①·② 담보책임 못 묻고 배당채권자에 일반 부당이득 반환청구 / 저당권·전세권 실행 담보책임(§575)은 가등기 본등기 소유권 상실 시도 준용 / 건축 불가 토지는 권리 하자 아닌 물건의 하자 / 확대손해 배상엔 매도인 귀책 필요 / 타인 권리 매매 이행불능 시 일반규정으로 해제·손배 가능.
  X지문: "경매 무효 시 §578 담보책임 물을 수 있다". (2003다59259) (24문40,23문40,22문40)

## 시험 직전 10초 체크 (헷갈리는 대비쌍)
1. 법정지상권 건물 양수(매매)=등기 필요 ↔ 저당권 실행 경락=등기 불요(§187).
2. 제3자 강박은 상대방 선의·무과실이면 취소 불가 ↔ 본인·상대방의 강박은 바로 취소 가능.
3. 통정허위표시 제3자 보호는 각자 기준 — 정 선의면 병 악의여도 무효 주장 불가 ↔ 제3자 전원 악의여야 무효 주장 가능.
4. 임의대리인 복임=원칙 불가(무권대리) ↔ 법정대리인 복임=원칙 가능.
5. 후행 보존등기는 실체관계 부합(점유취득시효 완성)으로도 유효화 안 됨 ↔ 일반 중간생략등기는 실체관계 부합으로 유효.
6. 보험계약 무효 부당이득반환은 상사 5년 시효 ↔ 일반 민사채권 10년.
7. 선의 점유자 본권 소 패소 시 '소 제기 시'부터 악의 ↔ '패소판결 확정 시'부터(X).
8. 담보반환의무는 변제와 동시이행 아님 ↔ 근저당 말소의무는 잔대금과 동시이행 O.
9. 계약금 일부 지급 시 해약금 기준은 약정 계약금(1,000만) ↔ 실제 교부액(300만)의 배액(X).
10. 예약완결권 행사기간 약정 시 그 기간(10년 초과해도 무방) ↔ 무약정 시 예약 성립부터 10년.

미수록: 23문5 영리·재단법인 세부, 22문19 등기 추정력 개별지문, 위험부담 §538 채권자위험부담 세부, 부합 부속물 개별 판례번호 등 1회성 지엽 지문.
