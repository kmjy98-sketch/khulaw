# LEET·LSAT 언어이해 — 글 전개 방식 통합 검토본

> 목적: 기존 「LEET 언어이해 — 글 전개 방식 정리본」을 검토해, LEET·LSAT 독해에서 실제로 쓰일 수 있는 글의 전개 방식을 더 빠짐없이 정리한다.  
> 핵심 결론: 기존본의 **소논문형 vs 대립형** 구도는 시험장 1차 판별용으로 유효하다. 다만 최종 정리본은 두 갈래만으로 끝내면 안 된다. 실제 지문은 **단일 이론 전개형, 논문형, 정의·분류형, 문제해결형, 역사발전형, 모형·가정형, 해석비평형, 법리·규범 적용형, 비교읽기형, 대립형**으로 세분해야 한다. 특히 사용자가 요청한 대로 **대립형은 마지막 장으로 배치**하고, 그 안에서 변증법 구조와 대립축 분류를 별도 정리하는 편이 좋다.

---

## 1. 기존 정리본 진단

### 1.1 유지할 부분

기존본에서 그대로 유지해도 되는 핵심은 다음이다.

| 항목 | 판단 | 이유 |
|---|---:|---|
| 소논문형 vs 대립형의 1차 판별 | 유지 | 시험장에서 첫 문단을 읽고 독해 모드를 전환하는 데 유용하다. |
| 소논문형에서 명사보다 동사·관계어를 추적 | 유지 | 자연과학·기술 지문은 용어 뜻보다 인과·조건·단계 방향이 정답을 가른다. |
| 대립형에서 화자 분리 | 유지 | 관점 혼동 오답 방어에 가장 직접적이다. |
| 유전자·신호전달·피드백 등 과정형 템플릿 | 유지·확장 | 방향성 추적 훈련에 좋다. 다만 유전자 복제·발현·시퀀싱을 더 분리해야 한다. |
| 대립축 표 | 유지·재편 | 분야별 지식 인덱스로 유용하다. 다만 “분야별 축”뿐 아니라 “보편 축”을 앞에 두면 더 강력하다. |

### 1.2 수정할 부분

기존본의 가장 큰 한계는 **지문 전개 방식을 두 개로 과압축**한다는 점이다. 실제 시험장에서는 “대립형이냐 아니냐”보다 먼저, 지문이 정보를 조직하는 엔진을 잡아야 한다.

수정 방향은 다음이다.

1. **소논문형을 하나로 뭉치지 말 것**  
   소논문형 안에는 과정형, 단일 이론형, 논문형, 개념정의형, 모형형, 문제해결형이 섞여 있다. 이들을 구분해야 문단 역할이 예측된다.

2. **논문형을 별도 추가할 것**  
   LEET·LSAT의 긴 지문은 실제 학술 논문의 축약판처럼 움직이는 경우가 많다. “문제 제기 → 선행 견해/연구의 한계 → 방법·자료 → 결과 → 해석 → 함의/한계”의 흐름을 별도로 훈련해야 한다.

3. **대립형은 마지막에 독립 장으로 둘 것**  
   대립형은 가장 중요하지만, 전체 글 종류의 하나가 아니라 여러 전개 방식 위에 덧씌워지는 “관점 충돌 구조”이기도 하다. 따라서 다른 전개 방식을 먼저 정리한 뒤 마지막에 대립형을 깊게 다루는 편이 낫다.

4. **과학·기술 과정형을 분야별로 더 분해할 것**  
   유전자 지문은 복제, 발현, 조절, 돌연변이, 시퀀싱, PCR이 서로 다른 흐름을 가진다. 통신·정보 지문은 송신자, 부호화, 채널, 잡음, 복호화, 오류정정, 피드백의 정보 흐름을 잡아야 한다.

## 2. 최종 분류 원칙 — 3층 구조

글 종류를 외우는 방식보다, 다음 3층으로 판단하는 것이 안정적이다.

| 층 | 묻는 질문 | 분류 |
|---|---|---|
| 1층: 글의 목적 | 이 글은 무엇을 하려는가? | 설명, 논증, 평가, 적용, 비교 |
| 2층: 전개 엔진 | 문단이 어떤 순서로 움직이는가? | 과정형, 이론형, 논문형, 문제해결형, 정의분류형, 역사발전형, 모형가정형, 해석비평형, 법리적용형, 대립형 |
| 3층: 분야 템플릿 | 그 엔진이 어느 분야의 재료로 구현되는가? | 생명과학, 통신·정보, 경제모형, 법리, 철학, 예술비평, 사회과학 등 |

시험장에서는 다음 순서로 판별한다.

> **첫 문단 30초 판별**  
> ① 지금 설명하는 대상은 현상·과정인가, 견해·논쟁인가?  
> ② 문단이 시간순·단계순으로 움직이는가, 개념 정의와 분류로 움직이는가, 연구 논문처럼 움직이는가?  
> ③ 저자가 평가하거나 대안을 제시하는가?  
> ④ 두 입장이 나오면 대립형 모드로 전환한다.

## 3. 글 전개 방식 전체 지도

대립형은 마지막 장에서 따로 깊게 다룬다. 여기서는 대립형을 제외한 기본 전개 엔진을 먼저 정리한다.

| 번호 | 전개 방식 | 대표 흐름 | 주로 나오는 분야 | 독해 핵심 | 대표 함정 |
|---:|---|---|---|---|---|
| 1 | 단일 이론 전개형 | 현상/문제 → 개념 → 원리 → 적용범위 → 함의 | 철학, 과학, 사회과학 | 이론의 핵심 명제와 적용 조건 | 적용범위 과장, 조건 누락 |
| 2 | 과정·메커니즘형 | 입력 → 단계 → 변환 → 산출 → 조절/예외 | 자연과학, 기술 | 방향·순서·조건 | 인과 역전, 단계 생략 |
| 3 | 논문형 | 문제 → 선행연구/한계 → 방법 → 결과 → 해석 → 한계 | 전 분야 | 연구 질문과 결론의 대응 | 자료와 해석 혼동 |
| 4 | 정의·분류형 | 개념 도입 → 기준 제시 → 하위 분류 → 경계 사례 | 법, 철학, 사회과학 | 분류 기준 | 기준 바꿔치기 |
| 5 | 문제해결형 | 문제/난점 → 원인 → 기존 해법 한계 → 새 해법 → 평가 | 법, 정책, 과학사, 기술 | 문제와 해법의 대응 | 해법이 다른 문제를 해결 |
| 6 | 역사발전형 | 초기 상태 → 전환 계기 → 변화 → 현재적 의미 | 역사, 과학사, 법사, 예술사 | 변화의 원인과 불연속점 | 시대·원인 뒤섞기 |
| 7 | 모형·가정형 | 가정 → 변수 → 작동 방식 → 예측 → 가정 완화/한계 | 경제학, 사회과학, 과학 | 가정과 결론의 연결 | 현실 사례를 모형 결론으로 오독 |
| 8 | 해석·비평형 | 대상/작품 → 기존 해석 → 새 해석/평가 → 근거 | 문학, 예술, 역사, 철학 | 해석 기준과 저자 태도 | 작품 사실과 해석 구분 실패 |
| 9 | 법리·규범 적용형 | 규범/원칙 → 요건 → 사례 → 예외/형량 → 결론 | 법학, 윤리, 정치철학 | 요건-효과, 예외, 형량 | 원칙과 예외 뒤섞기 |
| 10 | 비교읽기·융합형 | A 구조 파악 → B 구조 파악 → 관계 설정 | LSAT 비교읽기, LEET 복합 지문 | 두 글의 관계 | 지시어·관점 혼동 |

## 4. 단일 이론 전개형

### 4.1 기본 흐름

단일 이론 전개형은 특정 이론 하나를 중심으로 글이 움직인다. 반대 견해가 본격적으로 등장하지 않거나, 등장하더라도 보조적 배경에 그친다.

> **현상/문제 제시 → 이론의 핵심 개념 → 이론의 작동 원리 → 예시/적용 → 적용 범위·한계 → 함의**

### 4.2 문단 역할

| 문단 역할 | 읽을 것 | 메모 방식 |
|---|---|---|
| 도입 | 이 이론이 설명하려는 현상 | “설명 대상 = X” |
| 개념 정의 | 핵심 용어의 의미 | “A = …” |
| 작동 원리 | 어떤 조건에서 무엇이 발생하는가 | “조건 C → 결과 R” |
| 사례 | 원리의 구체화 | “사례는 원리의 어느 부분?” |
| 한계/예외 | 적용되지 않는 경우 | “~일 때는 불가/약화” |
| 함의 | 이론이 바꾸는 결론 | “따라서 기존 이해 수정” |

### 4.3 선지 함정

- **적용범위 확대**: 지문은 “특정 조건에서만”이라고 했는데 선지는 보편 법칙처럼 말한다.
- **핵심 개념의 위치 이동**: 이론의 전제였던 것을 결론처럼 바꾸거나, 결론을 전제처럼 바꾼다.
- **예시의 일반화**: 사례 하나를 이론 전체의 필수조건으로 만든다.
- **보조 설명의 중심화**: 주변 배경을 중심 주장처럼 만든다.

## 5. 과정·메커니즘형

### 5.1 범용 골격

기존본의 “출발점 → 감지/수용 → 매개 → 변환 → 산출 → 조절 → 이상”은 매우 유용하다. 다만 더 일반화하면 다음이다.

> **입력/자극 → 수용/탐지 → 매개/전달 → 변환/처리 → 출력/반응 → 피드백/조절 → 오류/예외**

### 5.2 읽는 법

과정형에서는 명사가 아니라 **동사, 방향, 조건**을 읽는다.

| 추적 대상 | 질문 | 마킹 |
|---|---|---|
| 방향 | 무엇이 무엇을 일으키는가? | A → B |
| 순서 | 무엇이 먼저이고 나중인가? | 1, 2, 3 |
| 조건 | 무엇이 있어야 작동하는가? | C 필요 |
| 억제 | 무엇이 어느 단계에서 막는가? | X ⊣ Y |
| 증폭 | 작은 원인이 어떻게 큰 결과가 되는가? | A ⇑ B |
| 피드백 | 결과가 다시 원인을 조절하는가? | R ↺ A |

### 5.3 대표 선지 함정

- **인과 역전**: A가 B를 만든다고 했는데, B가 A를 만든다고 바꾼다.
- **조건 역전**: A가 B의 필요조건인데, A만 있으면 B가 된다고 한다.
- **단계 생략**: 중간 매개 단계를 빼고 직접 원인처럼 만든다.
- **억제 지점 오류**: 억제제가 2단계에 작용하는데 4단계를 막는다고 한다.
- **피드백 방향 오류**: 음성 되먹임을 양성 되먹임처럼 읽게 만든다.

## 6. 논문형

### 6.1 논문형을 별도 분류해야 하는 이유

논문형은 단순한 설명문이 아니다. 연구자가 어떤 문제를 보고, 기존 설명의 한계를 지적하고, 자료나 방법을 통해 결론을 끌어내는 구조다. LEET·LSAT에서는 이 구조가 압축되어 나타난다.

### 6.2 표준 흐름

> **연구 문제/현상 → 기존 연구/통념 → 한계·공백 → 방법/자료 → 결과 → 해석 → 함의/한계**

### 6.3 논문형 하위 유형

| 하위 유형 | 흐름 | 핵심 독해 |
|---|---|---|
| 실증 연구형 | 질문 → 가설 → 자료/방법 → 결과 → 해석 | 자료가 실제로 지지하는 결론의 범위 |
| 실험 연구형 | 가설 → 실험 설계 → 변수 통제 → 결과 → 원인 추론 | 독립변수·종속변수·통제변수 |
| 이론 논문형 | 기존 개념 → 문제점 → 새 개념/모형 → 귀결 | 정의와 논증 단계 |
| 문헌 검토형 | 선행 견해들 → 공통점/차이 → 평가 → 정리 | 누가 무엇을 주장했는지 |
| 방법론 논문형 | 기존 방법 한계 → 새 방법 → 절차 → 장점/한계 | 방법이 해결하는 문제 |

### 6.4 논문형에서 자주 나오는 문제 포인트

| 발문 유형 | 물어보는 것 | 대응 |
|---|---|---|
| 주제 | 연구자가 결국 보인 것 | “문제-결과-해석”만 연결 |
| 구조 | 각 문단 역할 | 문제/한계/방법/결과/함의 태깅 |
| 추론 | 결과가 함의하는 것 | 자료가 허용하는 범위 안에서만 |
| 약화 | 연구 결론을 흔드는 변수 | 대안 원인, 표본 편향, 측정 오류, 통제 실패 |
| 강화 | 결론을 지지하는 추가 자료 | 같은 방향의 독립적 증거 |

### 6.5 논문형 함정

- **결과와 해석 혼동**: “관찰된 사실”과 “연구자의 설명”을 섞는다.
- **상관과 인과 혼동**: 자료는 함께 움직임만 보이는데 원인이라고 단정한다.
- **방법의 한계 누락**: 특정 표본·조건에서만 얻은 결과를 일반화한다.
- **기존 연구와 저자 입장 혼동**: 선행 연구의 주장을 저자 결론처럼 읽게 한다.

## 7. 정의·분류형

### 7.1 기본 흐름

> **개념 도입 → 기존 정의/통념 → 기준 제시 → 하위 유형 분류 → 경계 사례 → 정의의 의의**

### 7.2 출제 포인트

정의·분류형은 “용어를 아느냐”가 아니라 **분류 기준을 지킬 수 있느냐**를 본다.

| 읽을 것 | 질문 |
|---|---|
| 정의의 기준 | A가 A인 이유는 무엇인가? |
| 필요조건/충분조건 | 이 기준이 없으면 A가 아닌가, 이 기준만 있으면 A인가? |
| 경계 사례 | 애매한 사례를 어느 쪽으로 넣는가? |
| 분류 축 | 기준이 하나인가, 둘 이상인가? |
| 예외 | 정의를 수정하게 만드는 사례는 무엇인가? |

### 7.3 함정

- **기준 바꿔치기**: 지문은 기능 기준인데 선지는 발생 원인 기준으로 판단한다.
- **상위·하위 혼동**: 상위 개념의 특징을 하위 유형에 모두 적용한다.
- **필요조건의 충분조건화**: “A이려면 B가 필요”를 “B이면 A”로 바꾼다.
- **경계 사례 오독**: 지문이 애매하다고 한 사례를 명백한 사례로 처리한다.

---

## 8. 문제해결형

### 8.1 기본 흐름

> **문제/난점 → 문제의 원인 → 기존 해법의 한계 → 새 해법/대안 → 평가 → 남은 문제**

### 8.2 독해 핵심

문제해결형은 반드시 **문제와 해법의 대응**을 확인해야 한다.

| 단계 | 확인 질문 |
|---|---|
| 문제 | 정확히 무엇이 문제인가? |
| 원인 | 그 문제가 왜 생겼는가? |
| 기존 해법 | 무엇을 해결하려 했고 왜 부족했는가? |
| 새 해법 | 어떤 원인을 겨냥하는가? |
| 평가 | 성공 조건과 부작용은 무엇인가? |

### 8.3 함정

- **문제-해법 불일치**: A 문제를 해결하는 방안인데 B 문제 해결책처럼 제시한다.
- **원인-증상 혼동**: 증상을 원인으로 바꾼다.
- **기존 해법의 장점 삭제**: 저자는 부분 인정했는데 선지는 전면 부정으로 만든다.
- **새 해법의 조건 누락**: 특정 조건에서만 유효한 해법을 일반화한다.

---

## 9. 역사발전형·통시형

### 9.1 기본 흐름

> **초기 상태 → 변화 압력/전환 계기 → 중간 단계 → 새로운 체계 → 현재적 의미/평가**

### 9.2 읽는 법

역사발전형은 단순 연표가 아니다. 반드시 **무엇이 바뀌었고, 왜 바뀌었는지**를 잡아야 한다.

| 추적 대상 | 질문 |
|---|---|
| 시대 구분 | 몇 단계로 나뉘는가? |
| 변화 원인 | 내부 모순인가, 외부 충격인가? |
| 지속 요소 | 바뀌지 않은 것은 무엇인가? |
| 단절 요소 | 새 단계에서 폐기된 것은 무엇인가? |
| 평가 | 저자는 발전으로 보는가, 왜곡으로 보는가? |

### 9.3 함정

- **시대 착오**: 후대 개념을 전대 입장으로 제시한다.
- **원인 위치 오류**: 변화의 원인이 아니라 결과를 원인처럼 만든다.
- **연속/단절 혼동**: 저자가 연속성을 강조했는데 단절로 읽게 한다.
- **저자 평가 누락**: 역사적 설명과 규범적 평가를 구분하지 못하게 한다.

---

## 10. 모형·가정형

### 10.1 기본 흐름

> **현상 단순화 → 가정 설정 → 변수 정의 → 작동 원리 → 예측 → 가정 완화/한계**

경제학·사회과학·과학 지문에서 매우 흔하다. 모형은 현실 전체가 아니라 현실의 특정 측면을 보기 위해 만든 장치다.

### 10.2 반드시 메모할 것

| 요소 | 메모 예시 |
|---|---|
| 가정 | “완전정보”, “거래비용 없음”, “합리적 선택자” |
| 변수 | X 증가, Y 감소 |
| 관계 | X ↑ → Y ↓ / X와 Y는 양의 관계 |
| 예측 | 조건 C에서 결과 R |
| 한계 | C가 깨지면 R도 약화 |

### 10.3 함정

- **가정 삭제**: 가정이 성립할 때만 나오는 결론을 현실 일반으로 확장한다.
- **변수 방향 오류**: X 증가가 Y 증가인지 감소인지 바꾼다.
- **모형 목적 오독**: 예측 모형을 규범적 주장으로 읽는다.
- **내생성/상호작용 무시**: X가 Y를 만들지만 Y도 다시 X에 영향을 주는 구조를 단선화한다.

---

## 11. 해석·비평형

### 11.1 기본 흐름

> **작품/현상 제시 → 기존 해석 → 기존 해석의 한계 → 새 해석/비평 기준 → 근거 → 의의**

문학·예술·역사·철학 지문에서 자주 보인다.

### 11.2 독해 핵심

| 구분 | 확인 질문 |
|---|---|
| 대상 | 무엇을 해석하는가? |
| 기준 | 형식, 표현, 사회성, 역사성, 작가 의도, 독자 수용 중 무엇인가? |
| 기존 해석 | 무엇을 보았고 무엇을 놓쳤는가? |
| 새 해석 | 어떤 기준으로 재평가하는가? |
| 저자 태도 | 기존 해석을 전면 부정하는가, 보완하는가? |

### 11.3 함정

- **작품 사실과 해석 혼동**: 작품에 있는 사실을 해석자의 주장처럼 만들거나 반대로 한다.
- **해석 기준 바꾸기**: 형식주의 해석을 사회사적 기준으로 평가한다.
- **비판 강도 과장**: 보완을 전면 부정으로 만든다.
- **대상 혼동**: 작품 자체, 작가, 독자, 시대 중 무엇을 설명하는지 섞는다.

---

## 12. 법리·규범 적용형

### 12.1 기본 흐름

> **규범/원칙 → 요건 → 효과 → 예외 → 사례 적용 → 형량/결론**

법학 지문은 소논문형처럼 보이더라도 실제로는 요건-효과와 예외가 핵심인 경우가 많다.

### 12.2 읽는 법

| 추적 대상 | 메모 |
|---|---|
| 원칙 | 기본 규칙은 무엇인가? |
| 요건 | 어떤 사실이 충족되어야 하는가? |
| 효과 | 요건 충족 시 어떤 법적 효과가 생기는가? |
| 예외 | 어떤 경우에 원칙이 제한되는가? |
| 형량 | 충돌하는 가치가 무엇인가? |
| 적용 | 사례 사실이 어느 요건에 대응하는가? |

### 12.3 함정

- **원칙과 예외 뒤섞기**: 예외를 원칙처럼 제시한다.
- **요건 일부 충족을 전체 충족으로 처리**: A, B, C가 모두 필요한데 A만 보고 결론낸다.
- **규칙과 원리 혼동**: 엄격한 요건 판단과 가치 형량을 섞는다.
- **현행법과 당위론 혼동**: “현재 법은 X”와 “저자는 Y가 바람직하다”를 바꾼다.

## 13. 과학·생명과학 지문 전개 템플릿

자연과학 지문은 대개 과정형·논문형·모형형 중 하나다. 생명과학은 특히 **정보 흐름, 효소/단백질 작용, 신호 전달, 조절, 오류**가 반복된다.

### 13.1 유전자 복제형

#### 기본 흐름

> **복제 필요성 → DNA 이중가닥 분리 → 상보적 염기 결합 → 새 가닥 합성 → 오류 검출/수정 → 결과**

#### 시험장 골격

| 단계 | 논리 |
|---|---|
| 시작점 | 복제가 시작되는 위치가 있다. |
| 분리 | 기존 이중가닥이 풀려 주형이 된다. |
| 상보성 | A-T, G-C처럼 주형에 대응하는 새 염기가 붙는다. |
| 방향성 | 합성 방향이 정해져 있어 선도/지연 문제가 생길 수 있다. |
| 연결/수정 | 조각 연결, 오류 수정이 정확성을 높인다. |
| 산출 | 같은 유전정보를 가진 DNA가 만들어진다. |

#### 출제 함정

- 주형 가닥과 새 가닥을 뒤바꾼다.
- 상보 결합 규칙을 역으로 적용하게 한다.
- 효소가 작용하는 단계를 틀린다.
- 복제 방향성을 무시하게 한다.
- 오류 수정이 복제 전에 일어난 것처럼 만든다.

### 13.2 유전자 발현형

#### 기본 흐름

> **DNA 정보 → 전사 → RNA 처리 → 번역 → 단백질 → 형질/기능**

#### 시험장 골격

| 단계 | 읽을 것 |
|---|---|
| 전사 | 어떤 유전자가 RNA로 복사되는가? |
| 조절 | 전사가 켜지거나 꺼지는 조건은 무엇인가? |
| 번역 | RNA 정보가 단백질 서열로 바뀌는가? |
| 단백질 기능 | 만들어진 단백질이 어떤 반응을 일으키는가? |
| 표현형 | 세포나 개체 수준 결과가 무엇인가? |

#### 함정

- DNA 변화와 단백질 변화의 관계를 단선적으로 만든다.
- 발현 조절 단계와 단백질 기능 단계를 섞는다.
- 유전자 존재와 유전자 발현을 혼동한다.
- mRNA 양과 단백질 기능을 무조건 비례시킨다.

### 13.3 PCR·시퀀싱·실험기법형

#### PCR 흐름

> **가열로 DNA 분리 → 프라이머 결합 → 중합효소가 연장 → 반복 사이클 → 표적 DNA 증폭**

#### 시퀀싱 흐름

> **주형 준비 → 합성 반응 → 특정 지점에서 중단/표지 → 조각 분리 → 신호 판독 → 원래 서열 추론**

#### 함정

- 프라이머가 표적 구간을 정한다는 점을 놓친다.
- 증폭은 선형이 아니라 반복 사이클로 누적된다는 점을 놓친다.
- “표지된 조각”과 “원래 DNA”를 혼동한다.
- 관찰 신호에서 원서열로 역추론하는 방향을 뒤집는다.

### 13.4 세포 신호전달형

#### 기본 흐름

> **리간드/자극 → 수용체 결합 → 수용체 활성화 → 세포 내 전달 연쇄 → 증폭/분기 → 표적 반응 → 종료·피드백**

#### 핵심 포인트

| 포인트 | 설명 |
|---|---|
| 수용체 특이성 | 특정 신호는 특정 수용체를 통해 들어온다. |
| 신호 증폭 | 하나의 자극이 연쇄 반응을 통해 큰 반응이 된다. |
| 분기 | 하나의 신호가 여러 경로로 갈라질 수 있다. |
| 교차작용 | 서로 다른 경로가 같은 단백질이나 조절점을 공유할 수 있다. |
| 피드백 | 결과물이 앞 단계를 억제하거나 촉진할 수 있다. |
| 종료 | 분해, 재흡수, 탈인산화 등으로 신호가 꺼진다. |

#### 함정

- 신호가 수용체 안으로 “들어간다”고 오해하게 만든다. 실제로는 결합이 수용체 변화를 유발하고 내부 연쇄가 시작되는 구조가 많다.
- 증폭 구조를 단순 1:1 대응으로 만든다.
- 분기 경로 중 하나의 결과를 전체 경로 결과로 일반화한다.
- 피드백의 방향을 반대로 만든다.

### 13.5 생명과학 지문 공통 마킹

> **유전정보형**: DNA → RNA → 단백질 → 기능  
> **복제형**: 주형 → 상보 결합 → 합성 → 오류 수정  
> **신호형**: 리간드 → 수용체 → 전달연쇄 → 반응 → 종료  
> **조절형**: 기준값/조건 → 켜짐/꺼짐 → 결과 변화  
> **실험형**: 조작변수 → 측정값 → 해석 → 결론

## 14. 통신·정보·공학 지문 전개 템플릿

통신 지문은 생명과학의 신호전달형과 구조가 비슷하다. 다만 세포 대신 정보 시스템이 등장한다.

### 14.1 통신 기본 흐름

> **정보원 → 부호화/압축 → 변조 → 채널 전송 → 잡음/손실 → 수신 → 복조/복호화 → 오류정정 → 피드백**

### 14.2 구성 요소별 독해

| 요소 | 질문 | 함정 |
|---|---|---|
| 정보원 | 무엇을 보내려는가? | 원자료와 전송 신호 혼동 |
| 부호화 | 정보를 어떤 형식으로 바꾸는가? | 압축·암호화·부호화 혼동 |
| 변조 | 신호를 매체에 맞게 어떻게 싣는가? | 신호 내용과 운반파 혼동 |
| 채널 | 어떤 경로로 이동하는가? | 채널 용량과 실제 전송률 혼동 |
| 잡음 | 어디서 손상되는가? | 잡음 원인과 결과 혼동 |
| 복호화 | 받은 신호에서 정보를 어떻게 복원하는가? | 복조와 복호화 혼동 |
| 오류정정 | 오류를 어떻게 탐지·수정하는가? | 중복성을 비효율로만 오해 |
| 피드백 | 재전송·조정이 있는가? | 피드백 지연의 효과 누락 |

### 14.3 통신 지문의 대표 축

| 축 | 설명 | 선지 함정 |
|---|---|---|
| 신호 대 정보 | 신호는 정보의 물리적 운반체다. | 신호 세기 증가 = 정보량 증가로 오해 |
| 아날로그 대 디지털 | 연속값과 이산값의 차이 | 디지털이면 오류가 없다고 과장 |
| 압축 대 중복 | 효율성과 안정성의 긴장 | 압축이 항상 손실을 뜻한다고 단정 |
| 대역폭 대 잡음 | 전송 가능량과 품질의 관계 | 대역폭 증가가 항상 정확도 증가라고 단정 |
| 지연 대 처리량 | 빠른 반응과 많은 전송량의 긴장 | 처리량 높은 시스템을 지연도 낮다고 오해 |
| 암호화 대 오류정정 | 보안과 복원은 목적이 다르다. | 암호화가 오류를 고친다고 오해 |

### 14.4 네트워크·프로토콜형

> **데이터 생성 → 패킷화 → 주소 지정 → 라우팅 → 전송 → 재조립 → 오류 확인 → 재전송/혼잡 제어**

핵심은 “데이터가 한 덩어리로 이동하는가, 여러 조각으로 이동하는가”, “순서 보장과 신뢰성 보장이 어디에서 이루어지는가”이다.

### 14.5 제어·피드백 시스템형

> **목표값 → 센서 측정 → 제어기 비교 → 구동기 작동 → 출력 → 피드백 → 안정화/진동**

| 포인트 | 설명 |
|---|---|
| 음성 피드백 | 오차를 줄여 안정화한다. |
| 양성 피드백 | 변화를 증폭한다. |
| 지연 | 피드백이 늦으면 과잉 보정이나 진동이 생긴다. |
| 잡음 | 측정값이 실제 상태를 왜곡한다. |
| 안정성 | 시스템이 외란 후 원래 상태로 돌아오는가? |

---

## 15. 비교읽기·융합형

### 15.1 기본 흐름

비교읽기는 두 글을 한꺼번에 외우는 문제가 아니다. 각 글의 구조를 따로 잡은 뒤 관계를 정리하는 문제다.

> **A 글의 중심 주장/구조 → B 글의 중심 주장/구조 → 공통 주제 → 차이의 축 → 상호 평가 가능성**

### 15.2 관계 유형

| 관계 | 설명 | 문제 포인트 |
|---|---|---|
| 동의 | 같은 결론, 다른 근거 | 근거 차이 |
| 부분 동의 | 큰 방향은 같지만 범위나 조건이 다름 | 적용 범위 |
| 정면 대립 | 같은 쟁점에 반대 결론 | 대립축 |
| 원칙-사례 | A가 일반 원칙, B가 적용 사례 | 사례가 원칙의 어디에 해당하는가 |
| 이론-비판 | A가 이론, B가 한계 지적 | 비판 대상의 정확성 |
| 방법 차이 | 같은 현상, 다른 접근법 | 방법론 축 |
| 수준 차이 | 미시/거시, 개인/구조 등 분석 단위 차이 | 분석 수준 혼동 |

### 15.3 함정

- A 글의 용어가 B 글에서도 같은 뜻이라고 가정한다.
- B 글이 A 글 전체를 비판하는지, 일부만 비판하는지 놓친다.
- “전자의 견해”, “이러한 접근” 같은 지시어의 지칭 대상을 가장 가까운 명사로 착각한다.
- 두 글이 다른 문제에 답하고 있는데 같은 문제에 답한다고 본다.

# 마지막 장. 대립형

대립형은 가장 중요하므로 마지막에 따로 정리한다. 대립형의 본질은 “내용”보다 **입장의 위치 관계**다. 누가 무엇을 주장하고, 누구를 비판하며, 저자가 어느 정도 개입하는지 분리해야 한다.

---

## 16. 대립형 기본 구조

### 16.1 표준 흐름

> **배경/쟁점 → 입장 A → 입장 B 또는 반론 → 저자의 평가 → 조정/종합/잔여 쟁점**

### 16.2 대립형에서 먼저 물을 5문장

1. **쟁점은 무엇인가?**  
   두 입장이 실제로 같은 질문에 답하는지 확인한다.

2. **A는 무엇을 주장하는가?**  
   A의 결론과 근거를 분리한다.

3. **B는 A의 무엇을 비판하는가?**  
   결론을 비판하는지, 전제를 비판하는지, 방법을 비판하는지 확인한다.

4. **저자는 누구 편인가?**  
   지지, 보완, 중립, 양쪽 비판, 제3안 제시 중 하나다.

5. **최종 변화가 있는가?**  
   정·반·합처럼 새 관점으로 수렴하는지, 논쟁이 열린 채 끝나는지 본다.

---

## 17. 대립형의 하위 구조

| 유형 | 흐름 | 저자 태도 | 대표 함정 |
|---|---|---|---|
| 단순 양자 대립 | A 주장 → B 반박 | 한쪽 지지 또는 중립 | A 주장에 B 전제 섞기 |
| 정설-수정형 | 기존 정설 → 한계 → 수정 이론 | 수정 지지 | 기존 정설을 전면 폐기로 과장 |
| 변증법형 | 정 → 반 → 합 | 제3안 제시 | 합을 절충으로만 오해 |
| 논쟁 소개형 | A/B/C 견해 병렬 소개 | 중립 | 저자 입장 있다고 착각 |
| 비판-방어형 | A 비판 → A 방어/재구성 | A의 세련된 형태 지지 | 원래 A와 수정 A 혼동 |
| 양쪽 비판형 | A 한계 → B 한계 → 새 기준 | 기존 양쪽 모두 비판 | 저자를 A나 B로 귀속 |
| 방법론 대립형 | 같은 현상, 다른 연구 방법 | 방법 평가 | 결론 차이와 방법 차이 혼동 |
| 수준 대립형 | 미시 설명 vs 거시 설명 | 상보/우열 평가 | 분석 단위 혼동 |
| 가치 형량형 | 가치 A vs 가치 B | 균형/우선순위 제시 | 한 가치를 절대화 |

---

## 18. 변증법 구조 세분화

### 18.1 정·반·합은 세 가지로 나뉜다

| 세부형 | 구조 | 읽는 법 |
|---|---|---|
| 보완적 합 | A가 놓친 점을 B가 보완해 새 이론 C가 됨 | C가 A와 B 중 무엇을 각각 수용하는지 표시 |
| 초월적 합 | A/B가 공유한 전제 자체를 넘음 | “둘 다 틀린 이유”가 핵심 |
| 조건부 합 | 상황에 따라 A/B가 각각 타당 | 적용 조건을 분리 |

### 18.2 변증법형의 핵심 함정

- 합을 단순 절충으로 오해한다. 실제 합은 “반반 섞기”가 아니라 쟁점의 차원을 바꾸는 경우가 많다.
- 반론이 정설 전체를 부정한다고 과장한다. 많은 지문은 정설의 일부를 수정한다.
- 저자가 B를 소개했다고 B를 지지한다고 착각한다. 소개와 지지는 다르다.
- 저자가 A의 한계를 말했더라도 A의 모든 내용을 버리는 것은 아니다.

## 19. 대립형 축 분류 — 보편 축

분야별 학자명을 외우기 전에, 거의 모든 대립은 다음 보편 축 중 하나로 환원된다.

| 보편 축 | 한쪽 | 다른 쪽 | 읽는 질문 |
|---|---|---|---|
| 실재/구성 | 대상은 독립적으로 존재 | 대상은 인식·언어·사회가 구성 | “그것은 발견인가 구성인가?” |
| 보편/특수 | 일반 원리·법칙 | 개별 맥락·사례 | “일반화 가능한가?” |
| 내부/외부 | 내재적 구조·성질 | 외부 조건·환경 | “원인은 안에 있나 밖에 있나?” |
| 구조/행위 | 제도·구조가 결정 | 개인·행위자가 선택 | “누가 변화를 만드는가?” |
| 의도/결과 | 행위자의 의도 | 실제 결과·효과 | “평가는 무엇 기준인가?” |
| 규칙/원리 | 명확한 요건 | 가치·원칙의 형량 | “기계적 적용인가 판단인가?” |
| 사실/가치 | 기술적 설명 | 규범적 평가 | “무엇인가 vs 무엇이어야 하나?” |
| 원인/이유 | 자연적 인과 | 합리적 근거·정당화 | “왜 발생했나 vs 왜 정당한가?” |
| 환원/창발 | 부분으로 설명 | 전체 수준의 성질 | “부분 합인가, 전체의 새 성질인가?” |
| 정태/동태 | 고정 구조 | 변화 과정 | “구조인가 과정인가?” |
| 형식/내용 | 형식·절차 | 실질·내용 | “절차가 맞으면 충분한가?” |
| 효율/형평 | 총량·최적화 | 분배·공정성 | “더 커지는가, 더 공정한가?” |
| 자유/질서 | 자율성 | 안정·통제 | “개인 자유와 공동체 질서 중 무엇이 우선인가?” |
| 보안/공개 | 보호·통제 | 접근·투명성 | “닫아야 하나 열어야 하나?” |
| 예측/설명 | 맞히는 능력 | 원인 이해 | “예측 도구인가 진리 설명인가?” |

## 21. 대립형 저자 태도 분류

대립형에서 저자 태도는 정답을 가르는 핵심이다.

| 저자 태도 | 신호 | 정답 선지 특징 |
|---|---|---|
| A 지지 | “타당하다”, “설득력 있다”, “잘 보여준다” | A의 주장과 근거를 정확히 결합 |
| B 지지 | “그러나”, “한계를 드러낸다”, “대안” | A의 한계를 B가 어떻게 보완하는지 |
| 중립 소개 | 평가어가 거의 없음 | 논쟁 구조 자체가 중심 |
| 양쪽 비판 | “둘 다”, “공통된 한계” | A/B가 공유한 전제를 지적 |
| 조건부 인정 | “~한 경우에는”, “그러나 ~에서는” | 적용 범위가 정답 |
| 종합 제시 | “이를 종합하면”, “새로운 관점” | A와 B 중 무엇을 수용/기각했는지 |
| 유보 | “아직 불분명”, “추가 연구 필요” | 단정적 선지를 피함 |

---

## 22. 대립형 문제풀이 프로토콜

### 22.1 여백 표기

대립형이 보이면 즉시 다음처럼 적는다.

```text
쟁점 Q: ________?
A: 결론 / 근거 / 약점
B: 결론 / 근거 / A비판점
저자: 지지·비판·중립·종합·유보
축: 보편/특수, 규칙/원리, 실재/구성 등
```

### 22.2 선지 소거 순서

1. **주체가 틀린 선지 제거**  
   A의 견해를 물었는데 B의 말을 섞은 선지를 먼저 지운다.

2. **태도 강도가 틀린 선지 제거**  
   부분 인정인데 전면 찬성/전면 부정으로 과장한 선지를 지운다.

3. **쟁점이 다른 선지 제거**  
   A와 B의 실제 논쟁점이 아닌 내용을 들고 온 선지를 지운다.

4. **적용 범위가 틀린 선지 제거**  
   특정 조건의 주장을 일반 명제로 만든 선지를 지운다.

5. **최종 입장과 맞는지 확인**  
   저자가 합·유보·조건부 인정을 했는지 마지막 문단에서 확인한다.

## 23. 시험장 최종 알고리즘

### 23.1 첫 문단 판별

| 첫 문단 신호 | 전환 모드 |
|---|---|
| 현상, 원리, 과정, 장치 | 과정·메커니즘형 |
| 이론 하나, 개념 설명 | 단일 이론 전개형 |
| 연구, 자료, 실험, 결과 | 논문형 |
| 정의, 유형, 구분, 기준 | 정의·분류형 |
| 문제, 한계, 대안 | 문제해결형 |
| 과거에는, 이후, 변화 | 역사발전형 |
| 가정, 변수, 모형 | 모형·가정형 |
| 작품, 해석, 비평 | 해석·비평형 |
| 원칙, 요건, 예외, 형량 | 법리·규범 적용형 |
| 그러나, 반면, 비판, 학자 A/B | 대립형 |

### 23.2 독해 중 태깅

| 유형 | 태깅 |
|---|---|
| 과정형 | A → B → C, 억제는 ⊣, 피드백은 ↺ |
| 논문형 | 문제 / 한계 / 방법 / 결과 / 해석 / 함의 |
| 정의형 | 기준 1, 기준 2, 경계 사례 |
| 문제해결형 | 문제 P / 원인 C / 해법 S / 조건 K |
| 역사형 | 1기 / 전환 / 2기 / 현재 의미 |
| 모형형 | 가정 A / 변수 X,Y / 예측 R / 한계 L |
| 법리형 | 원칙 R / 요건 C / 효과 E / 예외 Ex |
| 대립형 | A / B / 저자 / 축 |

### 23.3 문제 유형별 역추적

| 발문 | 돌아갈 위치 |
|---|---|
| 주제 | 도입 문제 + 마지막 결론 |
| 구조 | 각 문단 첫·끝 문장과 전환어 |
| 정보 확인 | 해당 문장 + 바로 앞뒤 조건 |
| 추론 | 명시문장의 조건과 방향 |
| 평가 | 논증의 전제, 방법, 자료, 가정 |
| 적용 | 사례가 어떤 조건·단계·입장에 대응하는지 |
| 약화/강화 | 인과 사슬, 대안 원인, 통제 변수 |

## 24. 기존 정리본에 붙일 수정안 요약

기존 정리본에 바로 추가한다면 다음 순서가 가장 깔끔하다.

1. **0장: 큰 분류를 수정**  
   “글은 두 가지로 갈린다” 대신 “시험장 1차 판별은 소논문형 vs 대립형, 최종 전개 엔진은 10가지”로 변경.

2. **소논문형 장 확장**  
   소논문형 아래에 과정형, 단일 이론형, 논문형, 정의분류형, 모형가정형을 하위 항목으로 추가.

3. **빈출 메커니즘 장 확장**  
   유전자는 복제, 발현, PCR/시퀀싱, 신호전달을 분리. 통신은 정보원-부호화-채널-잡음-복호화-오류정정-피드백 구조 추가.

4. **대립형은 문서 후반으로 이동**  
   대립형 표준 템플릿, 변증법, 대립축 분류를 마지막 장에 두어 독립 완성도를 높인다.

5. **대립축은 보편축 → 분야별축 순서로 재편**  
   먼저 실재/구성, 보편/특수, 규칙/원리, 구조/행위 같은 보편축을 익히고, 그다음 철학·법학·경제·정치·과학·예술별 축을 붙인다.

## 25. 최종 결론

기존 정리본은 실전 매뉴얼로 사용할 수 있을 만큼 기본 방향이 맞다. 다만 그대로 쓰면 다음 세 가지 리스크가 있다.

1. **모든 비대립 지문을 소논문형으로 뭉개는 리스크**  
   논문형, 정의분류형, 모형형, 문제해결형이 서로 다른데 같은 방식으로 읽게 된다.

2. **과학·기술 지문에서 분야별 표준 흐름이 부족한 리스크**  
   유전자 복제, 유전자 발현, 신호전달, 통신 시스템은 서로 다른 방향성과 함정을 가진다.

3. **대립형을 단순 A vs B로만 처리하는 리스크**  
   실제 고난도 지문은 양자대립보다 정설-수정, 양쪽비판, 조건부 종합, 수준 대립, 방법론 대립이 많다.

따라서 최종본은 다음 한 문장으로 정리하면 된다.

> **LEET·LSAT 언어이해의 글 전개는 1차로 “정보 흐름형인가 관점 충돌형인가”를 판별하고, 2차로 과정·논문·정의·문제해결·역사·모형·해석·법리의 전개 엔진을 잡은 뒤, 마지막에 대립형이면 화자·쟁점·축·저자 태도를 분리해 읽는다.**
