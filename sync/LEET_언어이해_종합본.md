## 0. 시험장 최상위 알고리즘

> [!tip] 시험장 코어
> 지문을 받으면 같은 순서로 처리한다.
> - **첫 문단으로 글 종류·축 판별** -> 축 먼저 읽기 -> 판정 가능한 꼴(규칙·전제·함수)로 메모 -> 선지 8항목 검사 -> 소거
> - 내용을 다 이해하려 들지 말고, **선지가 본문의 관계를 보존하는지**만 빠르게 판정한다.
> - 한 문장 요약: 첫 문단으로 종류·축을 잡고, 축을 먼저 읽고, 판정 가능한 꼴로 메모한 뒤, 선지가 주체·관계·범위·태도를 보존하는지만 본다.
> - 고득점은 지식이 아니라 **방향을 안 뒤집고, 강도를 안 키우고, 주체를 안 섞는 것**에서 나온다.

| 단계 | 한 줄 행동 | 5초 체크 |
|---|---|---|
| **1 글 종류·축 판별** | 첫 문단 + 첫 문제 선지로 전개 엔진과 축을 못박는다 | 무엇과 무엇이 갈리는가 |
| **2 축 먼저 읽기** | A·B 내용보다 **갈리는 기준(축)**을 먼저 적는다 | 'A는 뭐, B는 뭐'를 길게 쓰지 않는다 |
| **3 판정 가능한 꼴로 메모** | 주장·근거·조건·양화·양상·변수만 표시 | 전부 기호화하지 않는다 |
| **4 선지 8항목 검사** | 주체·관계·조건·양상·층위·시간·평가·쟁점 중 무엇을 바꿨나 | 본문 관계를 보존하나 |
| **5 소거** | 본문보다 센 선지·주체 섞인 선지부터 제거 | **가능<->필연, 일부<->전부** |

> [!note] 시간 큰 그림 (70분·30문항)
> 평균 문항당 약 2분 20초. 단, 운영은 문항이 아니라 **지문 묶음 단위**로 한다. 지문 1개 = 첫 30초 판별 + 독해 + 묶인 문항 일괄 풀이. **축이 안 잡히는 고난도는 표시 후 손절**, 회수 단계에서 재검토한다.

### 0.1 지문 받자마자 5단계 (상세)

#### [1단계] 글 종류·축 판별 — 첫 30초

본문을 정독하기 **전에**, 첫 문단과 첫 문제 선지만으로 두 가지를 못박는다.

(가) 전개 엔진 — 글이 움직이는 방식:

| 전개 엔진 | 첫 문단 신호 | 먼저 잡을 것 |
|---|---|---|
| **논문형** | 연구 질문·기존 한계 제시 | 문제-방법-결과-해석 대응 |
| **과정·메커니즘형** | 단계·인과·작동 설명 | A이면 B 연쇄, 조건·억제·피드백 |
| **정의·분류형** | 개념 규정·유형 나눔 | 기준·경계 사례 |
| **문제해결형** | 문제 진단 -> 해법 | 문제와 해법의 대응 |
| **역사발전형·통시형** | 시대·단계 변화 | 시점·전후 순서 |
| **모형·가정형** | 가정 위 모델 전개 | 가정 안에서만 성립 |
| **법리·규범형** | 원칙·요건·예외 | 요건 충족·예외 해당 |
| **해석·비평형** | 텍스트·작품 해석 | 해석 층위·근거 |
| **비교읽기·융합형** | 두 글·관점 병치 | 공통 쟁점·차이 |
| **대립형** | A 주장 vs B 주장 | **쟁점 Q와 축** |

(나) 축 — 정보가 갈라지는 기준. 첫 문단에서 "무엇과 무엇이 갈리는가"를 한 줄로 적는다.

빈출 축: **실재/구성, 보편/특수, 구조/행위, 사실/가치, 규칙/원리, 효율/형평, 예측/설명, 상관/인과, 객관/해석**.

> [!warning] 고난도는 축을 숨긴다
> 고난도 지문은 내용을 많이 넣어 어렵게 만드는 게 아니라, **축을 숨기거나 두 축을 겹쳐** 어렵게 만든다. 축을 못 잡으면 정독해도 선지에서 흔들린다.

#### [2단계] 축 먼저 읽기 — A·B 내용 나열 금지

대립형이 나오면 곧바로 'A는 무엇, B는 무엇'을 길게 적지 않는다. 먼저 **갈리는 기준(축)**을 적고, 그 뒤에 결론·근거를 채운다.

```text
쟁점 Q: ________?
축: ________ vs ________
A: 결론 / 근거 / 약점
B: 결론 / 근거 / A 비판점
저자: 지지 / 비판 / 보완 / 종합 / 유보
```

> [!warning] 저자 위치 바꿔치기
> 저자의 위치(지지·비판·보완·종합·유보)를 반드시 표시한다. **저자 견해를 A나 B 견해로 바꿔치기하는 선지가 빈출 함정**이다.

#### [3단계] 판정 가능한 형식으로 메모 — 규칙·전제·함수 꼴

긴 지문을 전부 기호화하지 않는다. 다음만 표시한다 — **주장 / 근거 / 조건(A이면 B) / 양화(모든·어떤·없음·전부는 아님) / 양상(반드시·가능·알다·믿다·해야 한다·할 수 있다) / 변수(원인·결과·대조집단·측정값·예외)**. 이 단계에서 보조사의 논리 기능을 함께 반영한다(아래 0.3 표).

전개 엔진별 메모 최소형:

```text
[논문형]   Q 연구질문 / Old 기존한계 / M 방법·자료 / R 결과 / I 해석 / L 한계
[과정형]   A이면 B 이면 C 이면 D / 조건: C 필요 / 억제: X가 B를 막음 / 피드백: D가 A로 되돌아감
[대립형]   쟁점 Q / 축: ___ vs ___ / A 결론·근거 / B 결론·A비판 / 저자 위치
[법리형]   원칙 P / 요건 A 그리고 B 그리고 C / 예외 E / 사례 대응 / 결론
```

> [!note] 메모의 목적
> 핵심은 "줄글을 줄이는 것"이 아니라 **참·거짓을 판정할 수 있는 꼴**로 바꾸는 것이다. 조건문은 'A이면 B'로, 인과는 '원인이 결과를 일으킴'으로, 분류는 '기준에 따라 갈림'으로 적는다.

#### [4단계] 선지 8항목 검사 — `S-R-C-M-L-T-E-Q`

선지는 아래 8개 중 **하나를 바꿔** 오답이 된다. 선지마다 무엇을 건드렸는지 분류한다.

| 코드 | 검사 항목 | 질문 | 대표 오답 조작 |
|---|---|---|---|
| **`S`** | 주체(Source) | 누구의 말인가 | **저자 견해를 기존 견해로**, A 견해를 B 견해로 바꿈 |
| **`R`** | 관계(Relation) | 무엇이 무엇을 일으키거나 지지하나 | **인과 역전**, 근거-결론 뒤바꿈 |
| **`C`** | 조건(Condition) | 어떤 조건에서만 성립하나 | 필요조건을 충분조건화, 조건 누락 |
| **`M`** | 양상(Modality) | 가능·필연·대체로·항상 중 무엇인가 | **가능을 필연으로**, 일부를 전부로 과장 |
| **`L`** | 층위(Level) | 개인·제도·사회, 관찰·해석 중 어디인가 | 분석 수준 이동 |
| **`T`** | 시간(Time) | 전후·변화 단계가 맞나 | 시대착오, 원인·결과 시점 전도 |
| **`E`** | 평가(Evaluation) | 저자 태도 강도가 맞나 | 보완을 전면 부정으로, 유보를 지지로 과장 |
| **`Q`** | 쟁점(Question) | 같은 질문에 답하나 | 논점 이탈, 다른 문제의 답을 끼워 넣음 |

> [!warning] 무관 선지가 빈출 오답
> 본문 단어가 다 들어 있어도 **쟁점 Q를 벗어나면 오답**이다. 단어 매칭으로 고르지 않는다.

#### [5단계] 소거 — 센 선지부터 제거

본문과 선지의 **강도(양상·범위)**를 맞춘다. 본문보다 강한 선지가 가장 흔한 함정이다. 아래 순서로 제거한다.

1. **주체 오류 제거** — 누가 말했는지 틀린 선지(저자<->기존, A<->B).
2. **관계 오류 제거** — 인과·조건·근거-결론 방향이 틀린 선지(역·이).
3. **범위 오류 제거** — 일부·조건부를 전체·무조건으로 만든 선지.
4. **태도 오류 제거** — 보완·유보를 전면 찬반으로 과장한 선지.
5. **층위 오류 제거** — 개인<->제도, 관찰<->해석, 사실<->가치가 이동한 선지.
6. **마지막 비교** — 남은 두 선지 중 본문 구조를 더 잘 보존한 것을 택한다.

> [!check] 강도 맞추기 10초 기준
> - 본문이 **가능**인데 선지가 **반드시**면 제거
> - 본문이 **어떤(일부)**인데 선지가 **모든(전부)**이면 제거
> - 본문이 **주장·믿음**인데 선지가 **사실**로 단정하면 제거(주체 바꿔치기)

### 0.3 표지어·보조사 논리 기능표 (3단계 필수)

조건·양상·범위를 고정할 때 **보조사 하나**가 방향과 강도를 바꾼다. 이 표를 3단계에서 그대로 적용한다.

| 표지어 | 논리 기능 | 시험장 번역 | **빈출 함정** |
|---|---|---|---|
| **만 / 뿐 / 밖에** | 한정(오직) | 'A여야(만) B'는 A가 B의 필요조건 ('A만 B' = B이면 A) | **'A만 B'를 'A이면 B'(충분조건)로 오독** |
| **도** | 첨가 | 'A도 B'는 A를 포함해 다른 것도 B | 'A도'를 'A만'으로 뒤집기 |
| **조차 / 마저** | 극단 첨가 | 'A조차 B'면 나머지는 당연히 B(예상 밖·부정 맥락) | 특칭 강조를 전칭으로 키움 |
| **까지** | 척도 끝 | 범위를 A 끝까지 확장 | 범위 끝을 일반화로 비약 |
| **은 / 는** | 주제·대조 | 'A는 B'는 다른 것은 B 아닐 수 있음을 함축 | **대조를 전칭이나 한정으로 비약** |
| **마다** | 분배 전칭(각각=모든) | 'A마다 B'는 모든 A가 B | 특칭으로 약화 오독 |
| **(이)나** | 선택·근사 | 둘 중 하나 또는 대략 | 정확 수치로 단정 |
| **라도** | 양보 | 'A라도 B'(양보) — 충분조건 아님 | **양보를 충분조건으로 격상** |
| **반드시** | 필연 | 반례 하나면 깨진다 | **가능을 필연으로 키움** |
| **가능** | 가능(일 수 있다) | 사실로 바꾸지 말 것 | **가능을 사실로 단정** |
| **해야 한다 / 할 수 있다** | 의무 / 허용·능력 | 실제로 한다가 아님, 문맥에서 분리 | 당위를 사실로 바꿈 |
| **알다 / 주장하다** | 사실성 함축 / 사실성 없음 | '알다'는 보통 사실 함축, '주장·믿다'는 사실성 없음 | **주장·믿음을 사실로 바꿔치기** |

> [!note] 조건문 방향 10초 복습
> 'A이면 B' = A는 충분조건, B는 필요조건. 안전한 변형은 **대우('B 아니면 A 아니다')뿐**이다. 역('B이면 A')과 이('A 아니면 B 아니다')는 금지. 'A일 때에만 B'·'오직 A만 B'·'B 없이는 A 불가'·'A하려면 B 필요'는 모두 **B이면 A 또는 A이면 B 방향**을 가리키므로 'A이면 B'와 절대 섞지 않는다. **시험의 가장 그럴듯한 오답은 거의 역 또는 이다.**

### 0.4 손절·회수 운영 (시간 큰 그림)

| 구간 | 목표 | 행동 |
|---|---|---|
| **첫 30초** | 글 종류·축 판별 | 첫 문단 + 첫 문제 선지 확인 |
| **지문 독해** | 구조 지도 작성 | 문단 기능·축·전환점 표시 |
| **문항 풀이** | 선지 8항목 검사 | `S-R-C-M-L-T-E-Q` 순서로 소거 |
| **막힘 발생** | **손절** | **축이 안 잡히면 표시 후 다음 지문**으로 |
| **회수** | 남은 고난도 처리 | 표시한 축·조건 문항만 재검토 |

> [!warning] 손절이 시간을 만든다
> 60문항 안정권의 시간 자원은 **손절로 확보**한다. 한 지문에 매달려 묶인 다른 지문을 못 푸는 손실이 가장 크다. 축이 30초 안에 안 잡히면 표시하고 넘어가, 쉬운 지문을 먼저 확보한 뒤 회수 단계에서 돌아온다.

## 1. 글 종류(제재) 8분류와 종류별 알면 좋은 것

> [!tip] 시험장 코어
> - 제재마다 **독해 진입점(읽기 골격)**이 정해져 있다 — 표의 '한 줄 핵심'을 진입 시 떠올린다.
> - **법·법철학(매년 2~3지문)·경제(거의 매년)·생명과학**이 빈출 3축. 이 셋은 무조건 출제 가정.
> - 모든 제재 공통 1순위 점검: 선지가 본문의 **관계(주체·인과·조건·범위·태도)**를 보존하는가 — 단어 일치가 아니라 기능 일치.
> - 보조사는 본문이 깔아둔 신호: '~는'(대조, 전칭 비약 금지) / '~만·~여야'(한정=필요조건) / '~도·~조차'(첨가, '~만'으로 뒤집기 함정).
> - 1순위 오답은 항상 **양상(가능/필연)·수량(일부/모두)·조건(필요/충분)을 바꾼 선지**.

| 제재 | 빈도 | 한 줄 핵심(독해 진입점) | 1순위 함정 |
|---|---|---|---|
| **① 법·법철학** | **매년 2~3지문** | 원칙->요건->예외->형량. '해야/된다/안 된다'(의무·허용·금지) 추적 | **원칙·예외 전도**, 요건 일부만 충족 |
| **② 윤리·도덕철학** | 자주 | 행위 자체 평가(의무론) vs 결과 평가(공리주의) 축 | '그러하다'(사실)를 '그래야 한다'(당위)로 |
| **③ 인식론·과학철학** | 자주 | '안다(참 함축)' vs '믿는다/주장한다(참 보장 안 됨)' 분리 | 주장을 사실로, 가능을 필연으로 |
| **④ 정치·사회** | 자주 | 분석 단위 — 개인·행위 vs 구조·제도 | **층위 이동**(구조 설명을 개인 책임론으로) |
| **⑤ 경제** | **거의 매년** | 가정->변수->예측->한계. 모형 안에서만 성립 | 모형 결론을 현실 일반으로, 상관을 인과로 |
| **⑥ 과학(생명·물리·화학)** | **생명과학 빈출** | 입력->단계->변환->출력->피드백. 화살표 방향·조건 | **인과 역전·단계 생략**, 비례 단선화 |
| **⑦ 기술·공학** | 자주 | 절차의 순서가 불가역. 'A한 후 B' 시간 양상 | 단계 혼합, 두 방식 장단점 교차 |
| **⑧ 역사·문학비평·예술** | 자주 | 작품 사실 vs 해석자 주장 분리 / 연속 vs 단절 | 작품 사실과 해석 혼동, 시간 착오 |

> [!note] 타당성 검증 (2025 언어이해 30문항·10지문 확인)
> 한 해에 **8제재가 모두 출제**됐다 — 법 4지문(범죄소설·형법 / 사법심사 / 배아보호법 / 소크라테스 변론), 경제·생명과학·정보기술·역사·윤리철학·예술 각 1지문 이상. **법·경제·생명과학 빈출 3축이 그대로 확인**된다. 위 분류·진입점·함정 틀이 실제 기출에 그대로 적용된다(기출 예문은 각 제재 항목에 인라인 수록).

### 1.1 ① 법·법철학 (매년 2~3지문, 최빈출)

| 항목 | 내용 |
|---|---|
| **빈출 소재** | 위임명령·행정규칙, 재판매가격유지행위(공정거래법), 유류분 반환, 기본권 제한·비례성, 자연법 vs 법실증주의, 형식주의 vs 법현실주의 |
| **꼭 아는 배경개념** | 원칙(IM·금지)과 예외(조건부 허용), 요건-효과 구조, 입증책임의 소재, 무효(효력 없음), 형량(충돌 가치 비교) |
| **자주 나오는 구조** | 원칙 -> 요건 -> 효과 -> 예외 -> 사례 적용 -> 형량·결론 (법리 논문형) |
| **대표 선지 함정** | **원칙과 예외를 뒤섞음** / 요건 A·B·C 중 일부만 보고 결론 / '완화될 수 있다(가능)'를 '완화되어야 한다(필연)'로 강화 / 권장가격과 강제가격의 구분을 모호하게 |

> [!example] 기출 제재 (docx 4장)
> - **유류분 제도 (2023학년도 11월)**: 반환 청구 '권리(허용)'와 반환 의무자의 '의무'를 함께 다룸. 일응의 의무를 세운 뒤 예외 조건으로 의무 내용을 변경하는 조건부 의무 구조.
> - **위임명령·행정규칙 (2021학년도 9월)**: 포괄적 위임은 금지, 전문성 필요 시 구체성 요건 완화(조건부 허용), 위임 범위 벗어나면 무효. 함정은 '행정규칙은 위임이 있어야만 제정 가능'처럼 원칙(위임 없이 가능)과 예외를 뒤바꿈.
> - **재판매가격유지행위·공정거래법 (2025학년도 9월)**: 원칙적 금지지만 소비자 후생 증대 효과가 경쟁 제한 폐해보다 크면 허용. 정당한 사유의 입증책임은 사업자. '모든 가격 지정은 위법'은 조각 사유 무시 오답.

> [!note] 보조사 신호
> '구체적으로 범위를 정하지 않은 채 위임하는 것**은** 저촉된다'의 '은'은 **대조** — 범위를 정한 위임은 다를 수 있다는 함축. 이를 전칭('모든 위임은 위법')으로 비약시키는 선지가 함정. '정당한 사유가 있어**야만** 허용'은 한정 — 정당한 사유가 **필요조건**(있으면 무조건 허용이라는 충분조건 아님).

> [!example] 법·규범 — 배아보호법 [19~21] (한정·금지 조항 중첩)
> [지문] 독일법: 1주기에 난자 **3개까지만** 수정, 배아 **3개까지만** 이식, **이식할 수보다 많이 수정 금지**, 착상 전 채취 금지.
> [함정] 한정·금지('~까지만'·'~해서는 안')를 느슨하게 읽거나 **원칙-예외를 뒤바꿈**. (Q20은 '엄격한 기준'을 '이식할 배아 수 한도 내에서만 수정'으로 정확히 재진술했는지 묻는다.)
> [도구] 1장 ① 법(원칙·예외·한정) + 보조사 '만'(한정 = 필요·상한).

> [!example] 법철학 견해 대조 — 알베르트 대 사비니 [1~3] (주체 바꿔치기)
> [지문] 알베르트 = 법학을 **경험과학**(비판적 합리주의·반증가능성)으로. 사비니 = **규범교의적 학문**으로 옹호(규범적 교의가 법체계에 필수).
> [함정] 두 학자의 입장을 선지에서 **뒤섞기**(한쪽 주장을 상대에게 전가·왜곡). 누가 무엇을 주장하는지부터 두 칸으로 분리.
> [도구] 1장 ③ 인식론·법철학(견해 대조) + 3장 인식론적 간극(주장 주체 보존).

### 1.2 ② 윤리·도덕철학

| 항목 | 내용 |
|---|---|
| **빈출 소재** | 의무론 vs 공리주의, 덕윤리, 정서주의·이모티비즘, 권리 vs 전체 후생, 응보 vs 예방 |
| **꼭 아는 배경개념** | 행위 자체 평가 vs 결과 평가, 보편주의 vs 특수주의, 명제(참·거짓 가능) vs 감정 표출, 처벌 정당화 기준 |
| **자주 나오는 구조** | 통념 -> 반례 -> 기준 수정 (개념 재구성형) / 두 입장 형량 (가치 형량형) |
| **대표 선지 함정** | 의도와 결과를 동일시 / '무엇인가'(사실)를 '무엇이어야 하나'(당위)로 / 한 가치를 절대 우위로 과장(조건부 우위인데) |

> [!example] 기출 제재 (docx 3장)
> - **에이어의 정서주의·프레게-기치 문제 (2025학년도 6월)**: 전건 긍정 형식('살인이 나쁘다면 돕는 것도 나쁘다 / 살인은 나쁘다 / 따라서 돕는 것도 나쁘다')에서, 정서주의에 따르면 '살인은 나쁘다'가 명제가 아니라 감정 표출이라 논증이 성립하지 않는다는 난점. **사실/가치, 명제/표출의 구분**이 핵심.

> [!note] 보조사 신호
> '살인을 돕는 것**도** 나쁘다'의 '도'는 **첨가** — 살인 자체도 나쁘고 돕는 것도 나쁘다는 포함 함축. 이를 '돕는 것만 나쁘다'로 뒤집으면 오답.

> [!example] 견해 대조 — 공리주의와 권리 [13~15] (주체 바꿔치기)
> [지문] 피시킨(권리는 선험적 전제) · 라이언스(규칙공리주의도 규범적 힘 수용 못 함) · 브란트(규칙공리주의는 수용 가능) · 헤어(두 수준 이론으로 해소).
> [함정] **A의 주장을 B에 귀속**(누구 입장인지 뒤섞기), 또는 '규칙 유지'와 '규칙 준수'처럼 **유사어의 의미 이동**.
> [도구] 1장 ② 윤리철학(견해 대조) + 4.3 선지 소거(주체 오류 먼저).

> [!example] 윤리 견해 대조(존재->당위) — 흄 해석 [25~27] (추리논증 흄의 법칙과 직결)
> [지문] 흄의 'is-ought'를 셋이 다르게 해석 — 매킨타이어(필요·이익 관련 존재명제에선 도출 가능) / 헌터(정서의 **사실적 진술**에서 도출 가능) / 플류·허드슨(정서의 **표현**이라 도출 불가, 정서주의).
> [함정] 세 해석의 **미세한 차이를 뭉개거나 서로 귀속**. '정서의 진술(헌터)'과 '정서의 표현(플류)'을 같은 것으로 처리하면 오답.
> [도구] 1장 ② 윤리철학(견해 대조) + 추리논증 2.6 흄의 법칙(사실->당위 도약 차단).

### 1.3 ③ 인식론·과학철학

| 항목 | 내용 |
|---|---|
| **빈출 소재** | 합리론 vs 경험론, 토대주의 vs 정합주의, 심신문제(이원론·물리주의·기능주의), 과학적 실재론 vs 도구주의, 누적주의 vs 패러다임 전환, 귀납 vs 반증 |
| **꼭 아는 배경개념** | '안다'는 참을 함축(사실성), '믿는다·주장한다'는 참을 보장하지 않음 / 다중 실현 가능성 / 환원주의 vs 창발 / 이론은 진리인가 도구인가 |
| **자주 나오는 구조** | 기존 개념 -> 설명 실패 -> 새 개념·모형 -> 귀결 (이론 논문형) / 사고 실험·반례를 통한 반박 |
| **대표 선지 함정** | 인식의 주체·대상을 뒤섞음 / 특정 학자의 '주장'을 보편 '사실'로 둔갑 / 가능(다중 실현될 수 있다)을 필연으로 / 조건 누락한 무조건적 확장 |

> [!example] 기출 제재 (docx 2·3장)
> - **기능주의·중국어 방·확장 인지 (2024학년도 6월)**: 동일론(심적 상태=뇌 상태), 기능주의(=기능적 역할, 다중 실현 가능), 로랜즈의 확장 인지(인지가 신체 외부로 확장될 수 있음). 존 설의 '중국어 방'은 기능(구문)과 이해(의미)를 분리하는 사고 실험. 함정은 주체성을 외부 사물에 귀속('노트북이 기억한다' vs '주체가 노트북을 통해 기억한다'), 확장 성립 조건(주체와의 통합) 누락.
> - **앙드레 바쟁의 영화 이론 (2025학년도 9월)**: 바쟁의 '믿음'과 정신분석학적 이론가들의 '주장' 대비. 오인(인식의 실패)을 다루며, 선지는 인식의 주체·대상을 뒤섞거나 바쟁의 '신념'을 영화의 '객관적 속성'으로 단정.
> - **에이어의 도덕주의·논리학 (2025학년도 6월)**: 전건 긍정·후건 부정 같은 논증 형식의 타당성을 직접 검증.

> [!note] 보조사 신호
> 'A는 ~라고 믿었으나, B는 ~라고 주장한다'에서 '~는'의 **대조**가 곧 화자 분리 신호. '안다'와 '믿는다/여긴다/간주한다/주장한다/본다'를 동사 단위로 추적.

### 1.4 ④ 정치·사회

| 항목 | 내용 |
|---|---|
| **빈출 소재** | 자유주의 vs 공동체주의, 개인주의 vs 구조주의, 현실주의 vs 자유주의(국제정치), 기능론 vs 갈등론, 본질주의 vs 구성주의(정체성), 문화자본·상징권력 |
| **꼭 아는 배경개념** | 분석 단위(개인·행위 vs 사회·제도·구조), 무연고적 자아 vs 연고적 자아, 통합 vs 지배·불평등, 변화 주체(엘리트 vs 대중) |
| **자주 나오는 구조** | 개인 행위 -> 제도 -> 집합 결과 (제도분석) / 쟁점 -> A -> B·반론 -> 저자 평가 (대립형) |
| **대표 선지 함정** | **층위 이동**(구조 설명을 개인 책임론으로, 미시를 거시로) / 특수 조건을 보편 명제로 / 부분과 전체 혼동 |

> [!warning] 핵심 함정 — 분석 수준의 이동
> 사회 영역은 '규범(해야 한다)과 인센티브(이익을 극대화한다)의 논리'다. 가장 자주 조작되는 지점은 **분석 수준의 이동** — 개인의 선택을 설명한 대목을 제도·구조의 결정으로, 또는 그 반대로 옮긴다.

> [!note] 보조사 신호
> 'A는 구조에 의해 결정된다'의 '는'을 전칭으로 비약시키지 말 것 — 본문이 한 측면만 대조한 것일 수 있다.

> [!example] 모델 분류 적용 — 사법심사 여론 4모델 [10~12] (모델 조건 교차)
> [지문] 긍정적반응 / 반발 / 양극화 / 무반응 4모델, 각 **발동 조건**(관여도·정보량·시간 경과)이 다름.
> [함정] **한 모델의 속성을 다른 모델에** 갖다 붙이거나, 사례를 조건 일부만 보고 잘못된 모델로 분류. (Q12는 X국 (가)(나) 상황을 각 모델에 대입.)
> [도구] 1장 ④ 정치사회 + 2장 정의·분류형(기준·경계 사례).

### 1.5 ⑤ 경제 (거의 매년)

| 항목 | 내용 |
|---|---|
| **빈출 소재** | 기축통화·트리핀 딜레마, 시장 효율 vs 시장 실패, 완전합리성 vs 제한된 합리성, 정보비대칭(역선택·도덕적 해이), 효율성 vs 형평성, 외부효과(피구세 vs 코즈 협상) |
| **꼭 아는 배경개념** | 모형은 가정 안에서만 성립, 변수 종속성(증가율·기울기), 단기 효율 vs 장기 안정성, 인과적 필연성과 상관관계의 구분 |
| **자주 나오는 구조** | 현상 단순화 -> 가정 -> 변수 -> 예측 -> 한계 (모형·가정형) / 두 목표의 모순 (딜레마형) |
| **대표 선지 함정** | 모형 결론을 현실 일반 명제로 / **상관을 인과로** / 인과 방향 역전 / 변수의 비례·반비례 관계를 반대로 |

> [!example] 기출 제재 (docx 4장)
> - **트리핀 딜레마·브레턴우즈 (2022학년도 11월)**: 기축통화국이 유동성 공급하려면 적자를 봐야 하고(A), 적자 지속되면 신뢰도 하락(B)하여 두 목표 동시 달성 불가능. 인과 사슬 '경상수지 적자 -> 달러 공급 증가 -> 준비 자산 신뢰도 하락'. 함정은 신뢰도 하락을 적자의 원인으로 역전하거나, 환율·통화 가치 관계를 반대로 서술.
> - **클라이버의 법칙·기초 대사량 (2023학년도 11월)**: 대사량은 체중의 0.75제곱에 비례. 체중이 늘면 대사량도 늘지만 증가율(기울기)은 1보다 작아 '체중 당 대사량'은 감소. 함정은 기울기 0.75를 '체중 비례(1.0)'나 '반비례'로 오독하고, '대사량'과 '체중 당 대사량'을 혼동(범주 오류). (수리·생물 경계 제재)

> [!note] 보조사 신호
> '유동성을 공급하려면 적자를 봐**야** 한다'의 '여야/야'는 **한정** — 적자가 유동성 공급의 **필요조건**. 이를 '적자면 유동성이 공급된다'(충분조건)로 뒤집으면 오답.

> [!example] 경제 모형 — 솔로우 성장모형 [16~18] (조건부·인과 속도)
> [지문] '투자량 > 감가상각량이면 자본량 증가', 단 자본이 늘수록 **투자 증가 속도는 점차 감소**(감가상각은 자본에 비례).
> [함정] **모형 내 조건부를 무조건으로**, 또는 인과 '방향'은 맞혀도 '속도·수렴'을 혼동. ('자본 증가 -> 생산 필연 증가' 같은 양상 강화도 점검.)
> [도구] 1장 ⑤ 경제(모형은 가정 안에서만) + 3장 양상 대치(조건 -> 단정).

### 1.6 ⑥ 과학(생명·물리·화학) — 생명과학 빈출

| 항목 | 내용 |
|---|---|
| **빈출 소재** | 촉매·고분자 중합, 기초 대사량(상대 성장), 영상 안정화(OIS·DIS), 유전정보(DNA->RNA->단백질), 신호전달, 복제·PCR |
| **꼭 아는 배경개념** | 인과적 필연성(물리 법칙), 활성화 에너지·반응 속도, 환원주의적 설명(거시 물성 -> 미시 구조), 적절한 세기(단조 증가 아님), 음성·양성 피드백 |
| **자주 나오는 구조** | 입력 -> 단계 -> 변환 -> 출력 -> 피드백·오류 (과정·메커니즘형) / If-Then 조건문 연쇄 |
| **대표 선지 함정** | **인과 단계 누락·비약** / 비례 관계의 단선화·역전 / 단계 혼합 / 발현과 존재 혼동 / 피드백 방향 반전 |

> [!example] 기출 제재 (docx 4장)
> - **촉매·고분자 중합 (2025학년도 6월·2024학년도 6월)**: 개시제 분해 -> 불안정 원자 생성 -> 이중 결합 공격 -> 사슬 성장의 인과 기제. 거시 물성(단단함·녹는점)을 미시 분자 구조로 환원. 함정은 '촉매가 반응물의 화학적 성질을 변화시킨다'(실제로는 반응 경로·에너지만 변화)처럼 단계 비약, '흡착 세기가 강할수록 좋다'는 단선적 사고(적절한 세기 필요).
> - **클라이버의 법칙 (2023학년도 11월)**: 위 ⑤ 참조 — 수학적 모델링 기반 생물 제재.
> - **영상 안정화 OIS·DIS (2021학년도 6월)**: OIS는 렌즈 이동으로 빛 경로 굴절(물리적 보정, 화질 저하 없으나 범위 제한), DIS는 센서 이동·크롭으로 좌표 보정(소프트웨어, 범위 넓으나 화질·화각 손실). 함정은 두 방식 장단점을 교차시키거나, 보정과 촬영의 시간 순서를 왜곡.

> [!note] 보조사 신호
> 과정형에서는 보조사보다 동사·접속이 핵심이지만, '촉매**조차** 성질을 바꾼다'처럼 '조차'(극단 첨가)가 나오면 예상 밖 강한 단정이므로 본문 확인 대상.

> [!example] 과정·메커니즘 — 포르피린증 [4~6] (단계·대응 뒤섞기)
> [지문] 헴 합성은 **다단계 효소 경로**(델타아미노레불린산 -> … -> 헴). 특정 효소 결함 -> 그 기질 축적 -> 해당 포르피린증.
> [함정] **효소-기질-산물 대응을 뒤섞**거나 단계 순서를 비약. (Q6은 <보기> 표에 경로를 대입해 어느 단계 결함인지 추적.)
> [도구] 1장 ⑥ 과학(입력 -> 단계 -> 산물) + 3장 인과 재구성(단계 비약).

### 1.7 ⑦ 기술·공학

| 항목 | 내용 |
|---|---|
| **빈출 소재** | 블록체인 합의 알고리즘, 3D 모델링·렌더링 파이프라인, 통신 부호화·변조·오류정정, 제어·피드백 시스템 |
| **꼭 아는 배경개념** | 절차의 불가역적 순서, 각 단계 데이터가 다음 단계의 필요조건, 무결성, 작업증명, 트레이드오프 |
| **자주 나오는 구조** | A단계 -> B단계 -> C단계 (시제·절차형, 순서 불가역) |
| **대표 선지 함정** | **단계 혼합**(뒤 단계 작업을 앞 단계에서 한다고) / 시간 순서 왜곡 / 가능성의 과장(이론상 가능을 빈번한 것으로) / 인과 단절 |

> [!example] 기출 제재 (docx 4장)
> - **블록체인 합의 알고리즘 (2025학년도 9월)**: 과반수 연산력 가진 공격자가 없다면 데이터 변경 불가능. 해시값 찾는 연산을 수행해야만 블록 생성 가능(절차적 필연성). '데이터가 무단 변경되기 어렵다'는 성질이 무결성. 함정은 이론적으로 가능한 해킹을 현실적으로 빈번한 것으로, 또는 작업증명 없이 합의 가능한 것처럼 인과 단절.
> - **3D 모델링·렌더링 (2021학년도 12월)**: 모델링(정점 좌표) -> 시점 변환 -> 투영 -> 렌더링(화솟값)의 순서가 불가역. 렌더링 계산은 모델링 데이터에 의존. 함정은 렌더링 단계의 질감 처리를 모델링 단계에서 한다고 서술하는 단계 혼합.

> [!note] 보조사 신호
> '연산을 수행해**야만** 블록을 생성할 수 있다'의 '야만'은 **한정** — 연산 수행이 블록 생성의 필요조건. '공격자가 없**다면**'의 '~면'은 조건절이므로 무조건 단정으로 바꾸면 오답.

> [!example] 기술·정의 + 계산 — 개인정보 비식별화 k-익명성 [4~6]
> [지문] **동질집합 크기가 k 미만이면 삭제** -> 크기 k 이상 보장(재식별 확률 1/k 이하). l-다양성은 민감속성 값이 2종 이상.
> [함정] **k를 높일 때/낮출 때** 효과 방향 혼동(k 높이면 재식별 줄고·정보손실 늘고·잔존율 준다). '~미만 삭제'·'최소 2개' 같은 **경계·하한 조건**을 느슨하게 읽기.
> [도구] 1장 ⑦ 기술(정의·절차) + 보조사 '만·미만·이상'(경계) + 계산형 방향 점검.

| 항목 | 내용 |

> [!example] 기출 제재 (docx 3·4장)
> - **예술의 정의 (2021학년도 9월)**: 모방론·표현론·형식론이 반례에 의해 논파되는 과정. 뒤샹의 '샘'은 형식론의 필요조건(미적 형식)을 충족하지 않지만 예술로 인정받으므로 형식론은 예술의 필요조건이 아님이 증명됨(분석철학적 논증).
> - **아도르노의 예술관 (2023학년도 9월)**: 예술은 사회의 부조리를 드러내야 한다(당위), 대중예술은 '동일성(표준화)'을 강요해 비판 의식을 마비. 예술은 사회적 산물이면서 사회와 거리를 둬야 하는 역설(자율성). 함정은 아도르노가 비판한 것이 '기술적 완성도'가 아니라 '이데올로기적 기능'임을 간과, 또는 조화롭고 아름다운 예술을 아도르노에게 긍정적인 것으로 오인.
> - **헤겔 변증법·미학 (2022학년도 11월)**: 정-반-합의 지양, 직관(예술)·표상(종교)·사유(철학) 체계와 그 비판. 함정은 세 대응 관계를 뒤섞는 위상 교란, '종합'을 단순 '절충'이나 '병렬'로 왜곡.
> - **한비자와 노자 (2024학년도 11월)**: 한비자가 노자의 '도' 개념을 가변적·시비 판단의 근거로 재해석. 함정은 노자의 원래 사상과 한비자의 재해석을 구분 못하게 함('한비자는 도가 불변한다고 보았다'는 오답 — 한비자는 가변성 주장).

> [!note] 보조사 신호
> '한비자**는** 도가 가변적이라 보았다'의 '는'은 **대조**(노자와 갈림)의 신호. 화자별 입장을 '~는'으로 끊어 분리. '예술**조차** 동일성에 포섭된다'의 '조차'는 극단 첨가 — 가장 의외인 것까지 포함된다는 강한 단정.

### 1.9 제재 공통 — 보조사를 독해 신호로 쓰는 법

| 보조사 | 논리 기능 | 독해 신호 | 함정 |
|---|---|---|---|
| **은 / 는** | 주제·**대조** | 화자·입장 분리, '다른 것은 다를 수 있음' | 대조를 전칭이나 한정으로 비약 |
| **만 / 뿐 / 밖에 / 여야** | 한정(only) | 'A여야 B'에서 A는 **필요조건** | 'A만 B'를 'A이면 B'(충분조건)로 오독 |
| **도** | 첨가(also) | 'A도 B'면 다른 것도 B(포함 함축) | 'A도'를 'A만'으로 뒤집기 |
| **조차 / 마저** | 극단 첨가(even) | 가장 의외인 것까지 — 강한 단정, 본문 확인 | 예상 밖 단정을 무조건 일반으로 |
| **까지** | 척도 끝(up to) | 범위를 끝까지 확장 | 범위 과장 |
| **마다** | 분배 전칭(each) | '모든' 함축 | 특칭('어떤')으로 약화 오독 |
| **(이)나 / 라도** | 선택·양보 | '라도'는 양보(충분조건 아님) | 양보를 충분조건으로 |

> [!check] 1순위 점검 순서
> - **양상(가능/필연)·수량(일부/모두)·조건(필요/충분)**을 바꾼 선지가 모든 제재의 1순위 오답이다.
> - 보조사는 본문이 이미 깔아둔 한정·대조·첨가 신호 — 선지가 그 신호를 **반대로 뒤집었는지**를 먼저 점검한다.

## 2. 전개 방식 압축 지도

> [!tip] 시험장 코어
> - 첫 문단에서 단 하나만 가른다: 이 글이 '정보 흐름형'인가 '관점 충돌형'인가. 충돌형이면 즉시 **대립형 모드**.
> - 흐름형이면 전개 엔진 9개 중 하나로 좁힌다(과정 / 논문 / 정의분류 / 문제해결 / 역사발전 / 모형가정 / 단일이론 / 해석비평 / 법리규범). 열 번째 비교융합형은 두 글이 나란히 나올 때.
> - 유형이 정해지면 다음 문단이 무엇을 할지 예측된다. 내용 암기가 아니라 **선지가 그 관계를 보존했는지**만 검사.
> - **빈출 3대 엔진**: 과정·메커니즘형(자연과학·기술), 논문형(전 분야), 대립형(인문·사회). 이 셋을 먼저 자동화.
> - 대립형은 단 셋만: **화자 분리 · 쟁점 축 · 저자 태도**.

### 2.1 첫 문단 30초 판별 흐름

위에서 아래로 묻고, 먼저 걸리는 곳에서 멈춘다.

1. 두 입장·학자·"그러나/반면/비판"이 보이는가? -> **대립형**. (이 신호가 최우선. 보이는 즉시 다른 판별 중단.)
2. 연구·자료·실험·가설·결과를 말하는가? -> **논문형**.
3. 현상·장치·원리가 단계로 움직이는가? -> **과정·메커니즘형**.
4. 정의·유형·기준·구분을 세우는가? -> **정의·분류형**.
5. 문제·난점·한계·대안을 말하는가? -> **문제해결형**.
6. "과거에는·이후·전환·변화"로 시간이 흐르는가? -> **역사발전형**.
7. 가정·변수·모형을 설정하는가? -> **모형·가정형**.
8. 작품·해석·비평·평가가 대상인가? -> **해석·비평형**.
9. 원칙·요건·예외·형량이 보이는가? -> **법리·규범 적용형**.
10. 하나만 깔끔하게 잡히고 반대 견해가 없으면 -> **단일 이론 전개형**.
11. 두 글이 나란히 제시되면 -> **비교·융합형**(각 글을 따로 잡고 관계 설정).

> [!warning] 법학 지문 함정
> 단일이론형처럼 보여도 실제는 요건-효과·예외가 핵심인 **법리형**인 경우가 많다. "원칙·요건·예외"가 한 번이라도 보이면 법리형으로 읽는다.

### 2.2 전개 엔진 압축 표 (대립형 제외)

각 유형을 '핵심 흐름 + 마킹 포인트 + 대표 함정'으로 압축. '->'는 '그다음'으로 읽는다.

| 유형 | 핵심 흐름 | 마킹 포인트 | 대표 함정 |
|---|---|---|---|
| **과정·메커니즘형 (빈출)** | 입력·자극 -> 수용·탐지 -> 매개·전달 -> 변환·처리 -> 출력·반응 -> 피드백·조절 -> 오류·예외 | 명사 뜻이 아니라 동사·방향·순서·조건을 추적. 'A가 B를 일으킴', 순서 1·2·3, 'C가 있어야 작동', 억제 지점, 피드백이 원인을 줄이는지 늘리는지 | **인과 역전**, **단계 생략**(매개 빼고 직접 원인화), **조건 역전**(A가 필요조건인데 A만 있으면 B), 억제 지점 오류, **피드백 방향 반전** |
| **논문형 (빈출)** | 연구 문제 -> 선행 연구·통념 -> 한계·공백 -> 방법·자료 -> 결과 -> 해석 -> 함의·한계 | 연구 질문과 결론이 대응하는가. 자료(관찰)와 해석(설명)을 분리. 표본 범위, 독립·종속변수, 통제·대안 원인 | **결과와 해석 혼동**, **상관을 인과로 단정**, **표본을 모집단으로 일반화**, 방법 우수함을 결론의 참으로 확대, **선행 연구 주장을 저자 결론으로 둔갑** |
| **단일 이론 전개형** | 현상·문제 -> 핵심 개념 -> 작동 원리 -> 사례·적용 -> 적용 범위·한계 -> 함의 | 핵심 명제와 적용 조건. '조건 C에서 결과 R'. 한계·예외가 어디서 걸리는지 | **적용범위 확대**("특정 조건에서만"을 보편 법칙으로), 전제-결론 위치 바꾸기, **예시의 일반화**, 배경을 중심 주장으로 |
| **정의·분류형** | 개념 도입 -> 기존 정의·통념 -> 기준 제시 -> 하위 유형 분류 -> 경계 사례 -> 의의 | "용어를 아는가"가 아니라 분류 기준을 지키는가. 기준이 하나인지 둘 이상인지, 필요/충분조건인지, 애매 사례를 어디 넣는지 | **기준 바꿔치기**(기능 기준인데 발생 원인 기준으로), 상위·하위 혼동, **필요조건의 충분조건화**, 경계 사례를 명백 사례로 처리 |
| **문제해결형** | 문제·난점 -> 원인 -> 기존 해법의 한계 -> 새 해법·대안 -> 평가 -> 남은 문제 | 반드시 문제와 해법의 대응 확인. 새 해법이 어떤 원인을 겨냥하는지, 성공 조건과 부작용 | **문제-해법 불일치**, 원인·증상 혼동, 기존 해법 장점 삭제(부분 인정을 전면 부정으로), 새 해법 조건 누락·일반화 |
| **역사발전형·통시형** | 초기 상태 -> 변화 압력·전환 계기 -> 중간 단계 -> 새 체계 -> 현재적 의미 | 단순 연표 아님. 무엇이 왜 바뀌었는지, 지속된 것과 폐기된 것, 발전으로 보는지 왜곡으로 보는지 | **시대 착오**(후대 개념을 전대 입장으로), 원인·결과 위치 바꾸기, **연속/단절 혼동**, 역사적 설명과 규범적 평가 뒤섞기 |
| **모형·가정형** | 현상 단순화 -> 가정 설정 -> 변수 정의 -> 작동 원리 -> 예측 -> 가정 완화·한계 | 모형은 특정 측면용 장치. 가정과 결론의 연결, 변수 방향(X가 늘면 Y는?), 가정이 깨지면 결론도 약화 | **가정 삭제**(가정 성립 시 결론을 현실 일반으로 확장), 변수 방향 반전, **모형 목적 오독**(예측 모형을 규범 주장으로), 상호작용을 단선 인과로 단순화 |
| **해석·비평형** | 작품·현상 -> 기존 해석 -> 기존 해석의 한계 -> 새 해석·비평 기준 -> 근거 -> 의의 | 해석 기준이 무엇인지(형식·표현·사회성·역사성·작가 의도·독자 수용), 저자가 전면 부정인지 보완인지 | **작품 사실과 해석 혼동**, 해석 기준 바꾸기, **비판 강도 과장**(보완을 전면 부정으로), 대상 혼동(작품·작가·독자·시대) |
| **법리·규범 적용형** | 규범·원칙 -> 요건 -> 효과 -> 예외 -> 사례 적용 -> 형량·결론 | 요건-효과·예외·형량이 핵심. 요건이 모두 충족됐는지, 사례 사실이 어느 요건에 대응하는지, 충돌 가치가 무엇인지 | **원칙과 예외 뒤섞기**, **요건 일부 충족을 전체 충족으로**(A·B·C 모두 필요한데 A만 보고 결론), 규칙 판단과 가치 형량 혼동, **현행법과 당위론 혼동** |
| **비교·융합형** | A 글 중심 주장·구조 -> B 글 중심 주장·구조 -> 공통 주제 -> 차이의 축 -> 상호 평가 | 두 글을 한꺼번에 외우지 않음. 각 구조를 따로 잡은 뒤 관계 설정(동의·부분동의·정면대립·원칙-사례·이론-비판·방법차이·수준차이) | A 글 용어가 B 글에서도 같은 뜻이라 가정, B가 A 전체를 비판하는지 일부만인지 놓침, **지시어 오인**("전자의 견해"를 가까운 명사로 착각), 두 글이 다른 질문에 답하는데 같은 질문으로 봄 |

### 2.3 빈출 분야 템플릿 — 과정형 하위 (자연과학·기술)

과정형 중 다음 흐름이 반복 출제된다. 단계별 방향성과 함정이 다르므로 분리한다.

| 분야 흐름 | 핵심 흐름 | 대표 함정 |
|---|---|---|
| **유전 정보형** | DNA -> RNA -> 단백질 -> 기능·형질 | **유전자 존재와 발현 혼동**, 전사량과 단백질 기능을 무조건 비례시킴 |
| **DNA 복제형** | 주형 분리 -> 상보 결합 -> 새 가닥 합성 -> 오류 수정 -> 산출 | **주형 가닥과 새 가닥 뒤바꿈**, 상보 결합 규칙 역적용, 효소 작용 단계 오류, 오류 수정 시점(복제 전/후) 혼동 |
| **PCR·시퀀싱형** | 가열 분리 -> 프라이머 결합 -> 중합효소 연장 -> 반복 증폭 -> 표지·판독 -> 원서열 추론 | 프라이머가 표적 구간을 정한다는 점 누락, **증폭의 누적성 무시**, 관찰 신호와 원래 DNA 혼동, 역추론 방향 반전 |
| **세포 신호전달형** | 리간드·자극 -> 수용체 결합 -> 세포 내 전달 연쇄 -> 증폭·분기 -> 표적 반응 -> 종료·피드백 | 신호가 수용체 '안으로 들어간다'고 오해(실제는 결합이 변화를 유발), 증폭을 1대1로 단순화, 분기 경로 하나를 전체로 일반화, **피드백 방향 반전** |
| **통신·정보형** | 정보원 -> 부호화·압축 -> 변조 -> 채널 전송 -> 잡음·손실 -> 수신 -> 복조·복호화 -> 오류정정 -> 피드백 | 신호 세기 증가를 정보량 증가로 오해, 압축·암호화·부호화 혼동, 채널 용량과 실제 전송률 혼동, **암호화가 오류를 고친다고 오해**, 중복성을 비효율로만 이해 |
| **제어·피드백 시스템형** | 목표값 -> 센서 측정 -> 제어기 비교 -> 구동기 작동 -> 출력 -> 피드백 -> 안정화 또는 진동 | **음성 피드백(오차 감소·안정화)과 양성 피드백(변화 증폭) 반전**, 피드백 지연 효과 누락, 측정 잡음이 실제 상태를 왜곡함을 무시 |

### 2.4 대립형 — 핵심만

대립형의 본질은 '내용'이 아니라 **입장의 위치 관계**다. 누가 무엇을 주장하고 누구를 비판하며 저자가 어느 정도 개입하는지를 분리한다. 시험장에서는 다음 셋만 잡으면 된다.

> [!check] 화자 분리 — 여백에 즉시 적는다 (관점 혼동 오답 차단)
> - 쟁점 Q: 두 입장이 실제로 같은 질문에 답하는가?
> - A: 결론 / 근거 / 약점
> - B: 결론 / 근거 / **A의 어디를 비판하는가**(결론인가 전제인가 방법인가)
> - 저자: 지지 / 비판 / 중립 / 양쪽 비판 / 종합 / 유보 중 하나

> [!note] 쟁점 축 — A·B를 길게 적기 전에 '무엇으로 갈리는지' 한 줄 먼저
> 거의 모든 대립은 다음 보편 축 중 하나로 환원된다: 실재/구성, 보편/특수, 내부/외부, 구조/행위, 의도/결과, 규칙/원리, 사실/가치, 원인/이유, 환원/창발, 형식/내용, 효율/형평, 자유/질서, 예측/설명.

**변증법 3구조** — '정·반·합'은 단일하지 않다. 셋으로 갈린다.

| 변증법 세부형 | 구조 | 읽는 법 |
|---|---|---|
| **보완적 합** | A가 놓친 점을 B가 보완해 새 이론 C가 됨 | C가 A와 B 중 무엇을 각각 수용했는지 표시 |
| **초월적 합** | A와 B가 공유한 전제 자체를 넘어섬 | "둘 다 틀린 이유"가 핵심 |
| **조건부 합** | 상황에 따라 A·B가 각각 타당 | 적용 조건을 분리 |

> [!warning] 대립형 대표 함정
> - **합을 단순 절충(반반 섞기)으로 오해**. 실제 합은 쟁점의 차원 자체를 바꾸는 경우가 많다(특히 초월적 합).
> - **반론이 정설 전체를 부정한다고 과장**. 많은 지문은 정설의 일부만 수정한다.
> - **소개와 지지를 혼동**. 저자가 B를 소개했다고 B를 지지하는 것은 아니다.
> - A의 한계를 말했어도 A의 모든 내용을 버리는 것은 아니다.
> - **저자 태도 귀속 오류**. 양쪽 비판형인데 저자를 A나 B 한쪽으로 귀속시킨다.

**대립형 하위 구조 빠른 식별**

| 하위형 | 흐름 | 저자 태도 | 대표 함정 |
|---|---|---|---|
| **단순 양자 대립** | A 주장, B 반박 | 한쪽 지지 또는 중립 | A 주장에 B 전제 섞기 |
| **정설-수정형** | 정설, 한계, 수정 이론 | 수정 지지 | **정설 전면 폐기로 과장** |
| **변증법형** | 정, 반, 합 | 제3안 제시 | **합을 절충으로 오해** |
| **논쟁 소개형** | A·B·C 병렬 소개 | 중립 | 저자 입장 있다고 착각 |
| **비판-방어형** | A 비판, A 방어·재구성 | A의 세련된 형태 지지 | 원래 A와 수정 A 혼동 |
| **양쪽 비판형** | A 한계, B 한계, 새 기준 | 양쪽 모두 비판 | 저자를 A나 B로 귀속 |
| **가치 형량형** | 가치 A 대 가치 B | 균형·우선순위 제시 | 한 가치를 절대화 |

---

### 2.5 표지어·보조사로 전개를 잡는다

전개 방식과 화자 전환은 표지어가 신호한다. **보조사의 논리 기능**까지 읽어야 선지 조작을 잡는다.

| 표지어·보조사 | 신호 기능 | 함정 |
|---|---|---|
| **그러나·반면·하지만** | 전환·대립 진입 | 전환 뒤 입장이 **저자 결론인지 반대 견해인지** 분리 실패 |
| **따라서·그러므로·결국** | 결론·함의 도출 | 중간 결론을 최종 결론으로 오인 |
| **예컨대·가령** | 예시(근거 보조) | **예시를 원리 전체로 일반화** |
| **즉·다시 말해** | 환언(재진술) | 재진술을 새 주장으로 오인 |
| **만 / 뿐 / 밖에** | 한정(오직). 'A여야(만) B'는 A가 B의 **필요조건** | **'A만 B'를 'A이면 B'(충분조건)로 오독** |
| **도** | 첨가(또한). 'A도 B'는 A를 포함해 다른 것도 B | 'A도'를 'A만'으로 뒤집기 |
| **조차 / 마저** | 극단 첨가(가장 의외인 것까지). 'A조차 B'면 나머지는 당연히 B | 극단 사례를 일반 사례로 평탄화 |
| **까지** | 척도 끝(범위를 A 끝까지 확장) | 범위 끝점을 전체 범위로 오인 |
| **은 / 는** | 주제·대조. 'A는 B'는 '다른 것은 B가 아닐 수 있음'을 함축 | **대조를 전칭이나 한정으로 비약** |
| **마다** | 분배 전칭(각각=모든) | **특칭으로 약화 오독** |
| **(이)나** | 선택·근사 | 근사치를 정확값으로 처리 |
| **라도** | 양보(설령 그렇더라도). **충분조건이 아님** | 양보절을 충분조건으로 오독 |

---

### 2.6 한 줄 정리

> [!tip] 한 줄 정리
> 첫 문단에서 **정보 흐름형인가 관점 충돌형인가**를 가르고, 흐름형이면 9개 엔진 중 하나로 좁혀 '핵심 흐름·마킹·함정'을 적용한다. 충돌형이면 **화자 분리 · 쟁점 축 · 저자 태도** 셋만 잡고, 변증법은 **보완적 합 · 초월적 합 · 조건부 합** 셋으로 나눠 읽는다. 끝까지 검사할 것은 하나 — 선지가 본문의 관계(주체·인과·조건·범위·태도)를 보존했는가.

## 3. 선지 조작 패턴

> [!tip] 시험장 코어
> - 오답은 본문 어휘를 그대로 쓰되 **관계·범위·태도·주체**를 바꾼다.
> - 판정 질문: "본문에 나온 말인가"가 아니라 "그 말이 맡은 **기능이 같은가**".
> - 5대 조작만 외운다: 양상 대치 / 범위 조작 / 인과 재구성 / 인식론적 간극 / 메타인지 함정.
> - 소거 순서: 주체 -> 관계(인과·조건) -> 범위 -> 태도 -> 층위.
> - 마지막 둘이 남으면 **본문 구조를 더 보존한 쪽**이 정답.

| 조작 | 한 줄 | 핵심 신호어 |
|---|---|---|
| **양상 대치** | 가능을 필연으로, 조건을 단정으로 격상 | ~일 수 있다 -> 반드시 / ~면 -> 항상 |
| **범위 조작** | 어떤을 모든으로, 부분을 전체로 확장 | 어떤·일부·대체로 -> 모든·항상·전부 |
| **인과 재구성** | 화살표 역전·공통원인 무시·단계 비약 | ~때문에 / ~의 결과 / 따라서 |
| **인식론적 간극** | 주장·믿음을 사실로 격상 | 주장한다·여긴다 -> 밝혀졌다·이다 |
| **메타인지 함정** | 비교·지칭·전략 판단을 미세하게 비틂 | 전자·이러한 / 전략을 유지·수정 |

---

### 3.1 정답 선지의 일반형

> [!note] 정답은 본문을 **추상화하거나 제한**한다. 강한 단정보다 조건부·유보 표현이 정답 확률이 높다.

| 정답 유형 | 특징 | 통과 기준 |
|---|---|---|
| **추상화형** | 본문 표현을 더 추상적인 말로 치환 | **관계가 보존되면** 정답 가능 |
| **재배열형** | 여러 문단 정보를 묶음 | 순서·조건이 보존되어야 함 |
| **제한형** | 강한 표현 대신 조건부 표현 사용 | 지문의 유보와 일치하면 정답 |
| **구조형** | 문단 기능(배경/문제/반론/결론)을 물음 | 기능이 맞는지 확인 |
| **적용형** | 새 사례를 지문 원리에 맞춤 | 사례 요소가 어느 변수에 대응하는지 |
| **함의형** | 직접 표현은 없으나 구조상 따라 나옴 | 전제에서 필연 또는 강하게 지지되는지 |

> [!tip] 정답 감별 한 줄
> 정답은 본문보다 **약하거나 같고**, 오답은 본문보다 **강하거나 다르다**. 양상어·수량어가 본문보다 세지면 오답을 의심한다.

---

### 3.2 양상 대치 (가능->필연, 조건->단정)

> [!note] 지문의 양상 표현을 한 칸 격상해 진리 조건을 바꾼다. **가장 흔한 변형**.

| 세부 조작 | 설명 | 신호어 (이렇게 바뀌면 의심) |
|---|---|---|
| **가능의 필연화** | 'P일 수 있다'를 '반드시 P'로 | ~을 수 있다·~일지 모른다·개연성 -> 반드시·필연적·~일 수밖에 없다 |
| **조건의 단정화** | 'C면 P'를 '항상 P'로 (조건 삭제) | ~면·~경우에 -> 항상·언제나·무조건 |
| **빈도 과장** | '대체로·일부'를 '항상·모두'로 | 흔히·주로·대개 -> 늘·예외 없이 |
| **허용의 의무화** | '해도 된다'를 '해야 한다'로 | ~어도 된다·허용된다 -> ~어야 한다·의무가 있다 |
| **한계의 전면화** | '일부 한계'를 '전면 무효'로 | 다만·일부 미흡 -> 폐기·전면 부정 |

> [!warning] 즉시 소거 질문
> **"양상어가 본문보다 강해졌나?"** 본문이 '가능·시사·~수 있다'였는데 선지가 '반드시·항상'이면 거의 오답.

---

### 3.3 범위 조작 (전칭·특칭, 부분·전체)

> [!note] 명사가 가리키는 집합의 크기를 바꾼다. **보조사**가 이 조작의 표지가 된다.

| 세부 조작 | 설명 | 신호어 |
|---|---|---|
| **적용 범위 확대** | 특정 조건의 명제를 일반 명제로 | 어떤·일부 -> 모든·전부 |
| **적용 범위 축소** | 일반 주장을 특정 사례로 한정 | 모든·일반적으로 -> 그 경우에만 |
| **전칭·특칭 혼동** | '어떤 X는 P'를 '모든 X는 P'로 (또는 반대) | 어떤·있다 <-> 모든·마다 |
| **부분·전체 혼동** | 부분 속성을 전체 속성으로 둔갑 | 렌즈가 움직인다 -> 카메라가 움직인다 |
| **표본·모집단 혼동** | 제한 표본을 전체로 일반화 | 조사 대상에서 -> 일반적으로·전체 |
| **유사성 과장** | 일부 유사를 본질 동일로 | 비슷하다 -> 같다·동일하다 |
| **차이성 과장** | 차이 하나를 완전 대립으로 | 다른 점도 있다 -> 정반대·양립 불가 |

> [!warning] 즉시 소거 질문
> **"수량어가 바뀌었나? 부분이 전체로 커졌나?"**

보조사 함정 (범위·한정의 표지) — 표에 항상 대입한다:

| 보조사 | 논리 기능 | 대표 함정 |
|---|---|---|
| **만 / 뿐 / 밖에** | 한정(only). 'A여야(만) B'는 A가 B의 **필요조건** | 'A만 B'를 'A이면 B'(충분조건)로 오독. '밖에'는 부정과 결합('A밖에 없다'=오직 A) |
| **도** | 첨가(also). 'A도 B'는 **다른 것도 B**라는 함축 | 'A도'를 'A만'으로 뒤집기 |
| **조차 / 마저** | 극단 첨가(가장 의외인 것까지). 'A조차 B'면 나머지는 당연히 B | 부정·예상밖 맥락을 일반 긍정으로 처리 |
| **까지** | 척도 끝. 범위를 A 끝까지 확장 | 확장 끝점을 시작점·일부로 축소 |
| **은 / 는** | 주제·대조. 'A는 B'는 '다른 것은 아닐 수 있음' 함축 | 대조를 전칭·한정으로 비약 |
| **마다** | 분배 전칭(each=모든) | 특칭(어떤)으로 약화 오독 |
| **(이)나** | 선택·근사 | 근사치를 확정치로 |
| **라도** | 양보(even if). **충분조건 아님** | 양보를 충분조건으로 격상 |

> [!warning] 핵심
> **'만·여야'를 보면 그것은 필요조건이지 충분조건이 아니다.** 'A여야 B'에서 'A이면 B'를 끌어내면 오답.

---

### 3.4 인과 재구성 (역전·공통원인 무시·단계 비약)

> [!note] 인과 사슬의 방향을 바꾸거나 중간을 생략해 비약을 만든다. **과학·과정형 지문의 주력 함정**.

| 세부 조작 | 설명 | 신호어 |
|---|---|---|
| **인과 역전** | 'A가 B를 일으킨다'를 'B가 A를 일으킨다'로 | ~때문에·~의 결과·따라서 (방향 확인) |
| **상관의 인과화** | 함께 변한 것을 원인으로 단정 | 함께·동시에·비례하여 -> ~때문에·원인 |
| **결과의 원인화** | 결과를 원인처럼 제시 | 시간 순서 역전 |
| **매개 단계 생략** | 'A->중간->B'를 'A->B'로 단순화 | 곧바로·직접·따라서 (중간 조건 누락) |
| **공통원인 무시** | A가 B·C의 공통 원인인데 B가 C의 원인인 양 서술 | ~가 ~를 낳는다 (제3 원인 확인) |
| **피드백 방향 오류** | 억제<->촉진, 음성<->양성 되먹임 반전 | 줄인다 <-> 늘린다·증폭한다 |
| **단계 순서 바꿈** | 절차의 선후를 뒤섞음 | ~한 후에·먼저·앞서 (순서 확인) |

> [!warning] 즉시 소거 질문
> **"화살표 방향이 맞나? 중간 단계가 빠졌나?"** 상관을 본문이 인과라고 단정했는지도 확인.

---

### 3.5 인식론적 간극 (주장->사실)

> [!note] '사실'과 '주장·믿음' 사이의 간극을 이용한다. **주체를 뒤섞는 것**이 핵심.

| 세부 조작 | 설명 | 신호어 |
|---|---|---|
| **주장의 사실화** | 특정 학자의 '주장·믿음'을 보편 '사실'로 격상 | 주장한다·여긴다·본다 -> 밝혀졌다·입증되었다·이다 |
| **주체 바꾸기** | A 견해를 B 견해로 제시 | 누가 말했나 (학자명 대응) |
| **저자 귀속 오류** | 소개된 견해를 저자 주장으로 둔갑 | 저자가 지지했나, 소개만 했나 |
| **관점 혼합** | A 결론에 B 전제를 섞음 | 한 사람 입장으로 일관되나 |
| **관찰·해석 혼동** | 자료 결과와 연구자 해석을 뒤섞음 | 측정값인가 설명인가 |
| **사실·가치 혼동** | 'X이다'를 'X여야 한다'로 | 그러하다 -> 그래야 한다·바람직하다 |
| **원인·이유 혼동** | 발생 원인을 정당화 이유로 | 왜 생겼나 vs 왜 옳은가 |
| **방법·결론 혼동** | 방법이 우수하니 결론이 참이라고 | 방법이 무엇을 보장하나 |

> [!warning] 지식 vs 믿음
> '안다·밝혀지다·입증되다'는 참을 함축하지만, '믿는다·주장한다·여긴다'는 참을 보장하지 않는다. 선지가 **믿음 표지를 지식 표지로 바꿨으면** 오답.

> [!warning] 즉시 소거 질문
> **"이건 사실인가, 누군가의 주장인가? 누가 말했나?"**

---

### 3.6 메타인지 함정

> [!note] 독해 전략·비교·지칭 자체를 미세하게 비튼다. **최근 고난도 지문의 변별 포인트**.

| 세부 조작 | 설명 | 신호어 |
|---|---|---|
| **지시어 오인** | '이러한·전자의·이 과정'의 지칭 대상을 가장 가까운 명사로 단정 | 이·이러한·전자·후자·그 (실제 선행 내용 확인) |
| **비교 기준 변경** | A와 B를 서로 다른 기준으로 비교 | 비교 축이 같나 |
| **특성의 교차** | A의 장점을 B의 장점으로 옮김 | A는~ B는~ (대조 표지 확인) |
| **층위 이동** | 개인 설명을 제도 설명으로, 관찰을 해석으로 이동 | 분석 단위가 맞나 |
| **전략 판단 전도** | '수정해야 할 상황'에서 '유지'를, 또는 반대를 제시 | 전략을 유지·수정·점검 |
| **쟁점 이탈** | 논쟁 질문과 다른 질문에 답함 | 같은 물음에 답하나 |
| **형량의 절대화** | 가치 비교를 한 가치의 절대 우위로 | 조건부 우위인가 |
| **원칙·예외 전도** | 예외를 원칙처럼 제시 | 원칙적으로 vs 예외적으로 |

> [!warning] 즉시 소거 질문
> **"전자·이러한이 가리키는 게 정말 가장 가까운 명사인가, 앞 문장 전체 구조인가?"** 지칭 대상은 보통 직전 문장 전체이거나 앞 단락의 핵심 관점이다.

---

### 3.7 발문별 선지 처리

| 발문 | 먼저 볼 것 | 우선 소거 대상 |
|---|---|---|
| **주제·제목** | 마지막 회수 구조, 문제-결론 대응 | 너무 좁은 예시형 / 너무 넓은 배경형 |
| **구조** | 단락 기능 | 내용은 맞지만 **기능이 틀린** 선지 |
| **세부 일치** | 지문 위치와 조건 | 단어는 같은데 **관계가 다른** 선지 |
| **추론** | 명시 전제와 조건 | **가능성을 필연화**한 선지 |
| **적용(보기)** | 보기 요소와 지문 변수 대응 | 변수 매핑 오류 |
| **평가** | 근거의 취약점 | 대안 원인·표본 편향·통제 실패 무시 |
| **비교** | 공통 쟁점과 차이 축 | 한 글 용어를 **다른 글에 무단 이전** |
| **태도** | 평가어·양상어 | 중립을 지지·비판으로 과장 |

---

### 3.8 한 줄 결론

> [!check] 선지는 **양상·범위·인과·주체·지칭** 다섯 자리 중 하나를 바꿔 오답이 된다.
> - 단어 일치가 아니라 **그 단어가 본문에서 맡은 기능의 보존 여부**로 판정한다.
> - 본문보다 강해지거나(양상·범위), 방향이 뒤집히거나(인과·주체), 가리키는 대상이 어긋나면(지칭) 소거한다.

## 4. 시간 운영·소거·오답 루틴

> [!tip] 시험장 코어
> - 70분·30문항이면 문항당 약 2분 20초. 단 **문항이 아니라 지문 묶음 단위**로 운영한다.
> - 한 지문에 막히면 **손절**이 점수를 지킨다. 축이 30초 안에 안 잡히면 표시하고 다음 지문으로.
> - 선지는 **주체 -> 관계 -> 범위 -> 태도 -> 층위** 순서로 소거하고, 남은 둘은 **본문 구조를 더 보존한 쪽**을 택한다.
> - 오답노트는 문제 내용이 아니라 **선지 조작 방식**을 기록한다.

### 4.1 시간 운영 원칙 (지문 묶음 단위)

| 구간 | 목표 | 행동 |
|---|---|---|
| **첫 30초** | 유형·축 판별 | 첫 문단 + 첫 문제 선지 확인 |
| **지문 독해** | 구조 지도 작성 | 문단 기능, 축, 전환점 표시 |
| **문제 풀이** | 선지 조작 검사 | 아래 소거 순서로 처리 |
| **막힘 발생** | **손절** | 축이 안 잡히면 표시 후 다음 지문 |
| **회수** | 남은 고난도 처리 | 표시한 축·조건 문항만 재검토 |

> [!note] 형식(문항 수·시간)이 바뀌어도 비율은 유지한다. **쉬운 지문을 먼저 확보**한 뒤 회수 단계에서 어려운 것을 돌아본다.

### 4.2 지문 유형별 메모 최소형

유형이 잡히면 골격만 키워드로 채운다(문장으로 쓰지 않는다).

| 유형 | 채울 골격 |
|---|---|
| **논문형** | 연구질문(Q) / 기존설명·한계(Old) / 방법·자료(M·D) / 결과(R) / 해석(I) / 한계(L) |
| **과정형** | a 다음 b 다음 c 다음 d / 조건: c 필요 / 억제: X가 b를 막음 / 피드백: d가 a로 되돌아감 |
| **대립형** | 쟁점 Q / 축: ___ 대 ___ / A의 결론·근거 / B의 결론·A 비판점 / 저자 태도(지지·비판·보완·종합·유보) |
| **법리형** | 원칙 P / 요건 a 그리고 b 그리고 c / 예외 E / 사례 대응 / 결론 |

### 4.3 선지 소거 순서 (위에서 아래로)

1. **주체 오류**: 누가 말했는지 틀린 선지(주장자·학파 바꿔치기).
2. **관계 오류**: 인과·조건·근거-결론 방향이 틀린 선지.
3. **범위 오류**: 일부·조건부를 **전체·무조건**으로 키운 선지.
4. **태도 오류**: 보완·유보를 **전면 찬반**으로 과장한 선지.
5. **층위 오류**: 개인<->제도, 관찰<->해석, 사실<->가치가 이동한 선지.
6. **마지막 비교**: 남은 둘 중 본문 구조를 더 잘 보존한 것을 선택.

> [!warning] 선지는 **단어 일치가 아니라 관계 보존**으로 판단한다. 본문에 있는 단어라도 그 단어가 맡은 기능이 어긋나면 오답이다.

### 4.4 오답노트 — 내용이 아니라 조작을 적는다

문제를 베끼지 말고 다음만 기록한다.

> [!note]
> - 지문 유형(전개 엔진 / 축 / 문단 기능)
> - 발문 / 내가 고른 선지 / 정답 선지
> - **오답 조작 유형**(주체·관계·범위·태도·층위·양상 중 무엇)
> - 재발 방지 규칙 한 줄

### 4.5 점수대별 우선순위

| 현재 약점 | 먼저 보완 | 하지 말 것 |
|---|---|---|
| **시간 부족** | 첫 문단 판별·손절 기준 | 모든 문장 완전 이해 시도 |
| **세부 일치 약함** | 조건·범위·양상어 표시 | 단어 매칭으로 선지 선택 |
| **추론 약함** | 전제-결론 연결, 적용형 매핑 | 배경지식 동원 |
| **대립형 약함** | 쟁점 Q와 축 먼저 작성 | A·B 내용 나열만 |
| **과학형 약함** | 흐름(다음·조건·피드백) 메모 | 전문용어 뜻 암기 |
| **고득점 정체** | **오답 선지 조작 코드화** | 해설 읽고 납득만 하기 |

### 4.6 최종 체크리스트

> [!check] 지문 다 읽고 문제 들어가기 전
> - 전개 엔진을 잡았는가
> - 핵심 축을 하나 이상 적었는가
> - (논문형) Q·M·R·I·L 분리
> - (과정형) 흐름 방향·조건 표시
> - (대립형) 주체·쟁점·태도 분리

> [!check] 정답 고르기 직전
> - 선지의 주체가 맞는가
> - 인과·조건·단계 방향이 맞는가
> - **범위·양상어가 지문보다 세지 않은가**
> - 저자 태도를 과장하지 않았는가
> - 예시·배경을 중심 주장으로 착각하지 않았는가

## 5. 예문 은행 — 지문 유형별 선지 처리

> [!tip] 시험장 코어
> - 모든 예문은 **[지문 상황] -> [매력적 오답] -> [왜 틀리나] -> [정답 방향]** 4줄로 읽는다.
> - 출처 둘로 갈린다. (1) **분석본 기출 제재**(docx 4장) — 2011~2025 평가원·리트 실제 제재를 독해 함정의 예시로 인용(사건·연도·점수는 원자료에 없어 적지 않는다). (2) **형식 예시** — 골격만 보여주는 자작.
> - 영역 불문 **1순위 오답은 양상 대치·범위 비약·인과 역전·주체 전이** 넷이다. 아래 제재는 그 넷이 영역별로 어떻게 옷을 갈아입는지 보여준다.

### 5.1 인문·철학 — 주장과 사실, 관점의 분리

> [!example] 가) 정서주의와 논증 성립 — 에이어·프레게-기치 (출처: 분석본 기출 제재)
> - [지문 상황] '살인이 나쁘다면 살인을 돕는 것도 나쁘다(조건문). 살인은 나쁘다(전건). 따라서 살인을 돕는 것도 나쁘다.' 그런데 정서주의에 따르면 '살인은 나쁘다'는 참·거짓 가능한 명제가 아니라 감정 표출이라 논증이 성립하지 않는다는 난점이 쟁점.
> - [오답] '정서주의에서도 이 삼단논법은 타당하게 성립한다.'
> - [왜 틀리나] 지문의 핵심 논점(정서주의에선 전건이 명제가 아니어서 논증이 무너짐)을 정반대로 뒤집음. **주장(이론의 난점)을 결론으로 둔갑**.
> - [정답 방향] 지문이 '문제를 제기'한 것인지 '해결을 단정'한 것인지부터 가른다. 난점 분석형은 대개 '성립하지 않는다'가 결론.

> [!example] 나) 변증법의 위상 — 헤겔 미학 (출처: 분석본 기출 제재)
> - [지문 상황] 직관(예술)·표상(종교)·사유(철학)가 정-반-합으로 상위 범주로 나아가며, 비판자는 '예술의 감각적 특성이 철학 단계에서 소거되어 진정한 종합이 아니다'라고 지적.
> - [오답] '헤겔은 예술·종교·철학을 같은 위상의 병렬 단계로 보았다.'
> - [왜 틀리나] 대응 관계를 뒤섞고(**위상 교란**), 변증법적 '종합'을 단순 '병렬·절충'으로 **개념 재정의**.
> - [정답 방향] 대립형은 화자(헤겔 vs 비판자)를 분리하고, '종합=지양'의 정확한 뜻(상위 통일)을 보존한 선지를 고른다.

> [!example] 다) 개념의 전용 — 한비자와 노자 (출처: 분석본 기출 제재)
> - [지문 상황] 노자의 '도'는 불변하는 생성의 근원인데, 한비자는 이를 가변적이고 시비 판단의 근거가 되는 통치술로 재해석.
> - [오답] '한비자는 도가 불변한다고 보았다.'
> - [왜 틀리나] 노자의 원래 사상과 한비자가 재해석한 사상을 구분 못 하게 하는 **관점 혼재**(한비자는 도의 가변성을 주장).
> - [정답 방향] 'A를 빌려 B로 바꿔 쓴' 전용형 지문은 '원래 뜻'과 '바뀐 뜻'을 두 칸으로 나눠 적는다.

---

### 5.2 사회·법경제 — 원칙과 예외, 범주

> [!example] 가) 정당화 사유와 범주 혼동 — 재판매 가격 유지 (출처: 분석본 기출 제재)
> - [지문 상황] 재판매 가격 유지 행위는 원칙적으로 금지되나, 소비자 후생 증대 효과가 경쟁 제한 폐해보다 크면 예외적으로 허용되고, 그 입증 책임은 사업자에게 있다.
> - [오답] '모든 가격 지정 행위는 위법이다' / '권장 소비자 가격도 강제성이 있어 금지된다.'
> - [왜 틀리나] 정당화(조각) 사유가 있으면 위법이 아닌데 **예외를 삭제**했고, '권장 가격'과 '강제성 있는 가격'의 **범주를 혼동**.
> - [정답 방향] '원칙적으로'·'~인 경우' 표지가 붙은 규범은 무조건 규범이 아니다. 원칙-예외-입증주체를 세 칸으로 분리한다.

---

### 5.3 과학·기술 — 인과 단계와 특성 귀속

> [!example] 가) 인과 단계 비약 — 촉매와 고분자 중합 (출처: 분석본 기출 제재)
> - [지문 상황] '개시제 분해 다음 불안정 원자 생성 다음 이중결합 공격 다음 사슬 성장'의 연쇄. 촉매는 반응 경로(활성화 에너지)를 바꿀 뿐 반응물의 화학적 성질 자체를 바꾸지 않는다. 흡착은 적절한 세기가 필요하다.
> - [오답] '촉매는 반응물의 화학적 성질을 변화시킨다' / '흡착 세기는 강할수록 좋다.'
> - [왜 틀리나] **인과 단계 누락·비약**(경로만 바꾸는데 성질을 바꾼다고 함)과 **비례 관계의 단선화**(적절한 세기가 필요한데 강할수록 좋다고 함).
> - [정답 방향] 과정형은 흐름 화살표와 '무엇이 무엇을 바꾸는가'를 정확히 표시한다. '~수록 좋다'류 단조 비례 선지는 본문이 '적정값'을 말했는지 확인.

> [!example] 나) 특성 교차 — 영상 안정화 OIS·DIS (출처: 분석본 기출 제재)
> - [지문 상황] OIS는 렌즈를 움직여 빛 경로를 보정(화질 손실 없으나 범위 제한), DIS는 센서 이동·크롭으로 보정(범위 넓으나 화질·화각 손실)이라는 트레이드오프.
> - [오답] 'OIS는 보정 범위가 넓고 화각 손실이 없다.'
> - [왜 틀리나] OIS의 장점과 DIS의 장점을 뒤섞은 **특성 교차**. 보정이 촬영 전인지 후인지 **시제를 왜곡**하는 선지도 단골.
> - [정답 방향] 비교형은 두 대상을 표로 나눠 장단점을 각 칸에 고정하고, 한 대상의 속성을 다른 대상에 옮긴 선지를 소거.

---

### 5.4 의도·메타인지 — 최신 고난도 함정

> [!example] 가) 인과 동기와 목적 동기 — 독서 동기 (출처: 분석본 기출 제재)
> - [지문 상황] 슈츠의 '때문에 동기'(과거 원인)와 '위하여 동기'(미래 목적)를 구분.
> - [오답] "'위하여 동기'는 과거의 원인에 의해 행위가 결정됨을 뜻한다."
> - [왜 틀리나] 미래 목적(의도)을 과거 인과로 바꾼 **인과·목적 혼동**.
> - [정답 방향] '때문에(원인) / 위하여(목적)'를 시간 방향(과거 대 미래)으로 갈라 적는다.

> [!example] 나) 전략 수정 판단 — 독서 전략·메타인지 (출처: 분석본 기출 제재)
> - [지문 상황] 독자가 자기 인지 과정을 점검(메타인지)하며, '전략을 수정해야 할 상황'에서 적절히 조정하는 논리.
> - [오답] '이해가 막힌 상황에서도 기존 전략을 유지하는 것이 적절하다.'
> - [왜 틀리나] 전략을 바꿔야 할 신호에서 유지하라고 하는 **판단 자체의 오류 유도**(메타인지 함정).
> - [정답 방향] 메타인지형은 '상황 조건 -> 그에 맞는 전략'의 대응을 본문에서 확정한 뒤 선지의 대응이 맞는지 본다.

### 5.5 형식 예시 — 언어이해 독해 골격 (출처: 형식 예시, 자작)

> [!note] 소재 없이 독해 함정 골격만. 글 종류 표(1장)·선지 조작 표(3장)와 짝지어 읽는다.

| 지문 상황 골격 | 매력적 오답 | 왜 틀리나 | 정답 방향 |
|---|---|---|---|
| **'A는 X를 강조한다'(대조 보조사 는)** | '모든 학자가 X를 강조한다' | **대조를 전칭으로 비약** | 'A는'이 깔아둔 '다른 학자는 다를 수 있음'을 살린다 |
| **'조건 c가 충족되면 결과 r'** | '항상 r이 일어난다' | 조건부를 단정으로(조건 삭제) | 'c일 때만 r'인지, c의 충족 여부를 본문에서 확인 |
| **'저자는 갑 이론을 보완하려 한다'(유보·보완)** | '저자는 갑 이론을 전면 반박한다' | **태도 과장**(보완을 전면 반대로) | 저자 태도(지지·비판·보완·종합·유보)를 한 단어로 고정 |
| **'일부 사례에서 p가 관찰된다'(특칭)** | 'p는 보편 법칙이다' | 관찰(특칭)을 법칙(전칭)으로 | 관찰과 해석, 특칭과 전칭을 분리 |
| **'갑은 r이라고 주장한다'** | 'r은 사실이다' | **주장을 사실로**(주체 전이) | 주장자 입장으로만 처리, 사실로 비약 금지 |
