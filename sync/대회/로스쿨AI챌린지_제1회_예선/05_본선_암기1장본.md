# 핀테크 규제 1장 암기 — EU·GDPR·국내

**우선순위(기한)**: ①유출 72h(GDPR §33) ②BaFin 회신(ZAG §7 정식처분 前) ③혁신금융 연장=만료 3개월 전(특별법 §10②). 최대벌: GDPR **4%**, 무인가 **5년**(ZAG §63·신정법 §50).

**① EU 금융규제·BaFin**
- 송금=PSD2 부속서I 6호·§4(22) / 조회=AIS 8호·§4(16). 독일 ZAG §1①2문 6·8호.
- 인가 PSD2 §11(1)=ZAG §10①(BaFin 서면인가). 비EEA **패스포팅 불가→독일 현지법인+인가**.
- 무인가 제재: ZAG §7①(즉시중지·청산) + §63①4호(**5년 자유형/벌금**). 처분례 Brunnlitz 등(개인자금→자기계좌→해외=동일구조).
- BaFin 경고=청문前단계 → **기한내 회신·독일 영업 잠정중단**. 조회는 ZAG §34 **등록**(경량). 선불충전=EMD2 §2(2)[CJEU C-661/22: 보유자금=결제서비스].

**② GDPR**
- 역외 §3(2)(a) / 원스톱샵無(전문122)→독·프·스 **회원국별 개별**.
- 대리인 §27·DPO §37(1)(b)(위치정보≠Art9 특별범주)=§83④ **2%**.
- 투명성 §12~14(국문방침 위반)=§83⑤ **4%** [WhatsApp DPC 2.25억€].
- 목적제한 §5(1)(b)·6(4)(AI학습=새목적). 이전 §44~46·49 + 적정성 **(EU)2022/254 신용정보 제외**→SCC 필요=4% [Meta DPC **12억€** §46(1)].
- AWS=§28 DPA + Schrems II(C-311/18, 미국모회사→보유키 암호화). 유출 §33(**72h**·2주경과=도과)·§34(**미암호화→면제 차단**).
- 과징금: §83④ 1천만€/2%(27·33·34·37) / §83⑤ 2천만€/4%(5·6·12~22·44~49).

**③ 국내 금융·개인정보**
- 스크래핑 금지 신정법 **§22-9③** / 표준API **§22-9④**. 마이데이터 허가 §2(9-2)·§4 / 무허가 **§50②1호 5년·5천만**.
- 접근매체 전금 §6③·§49④[대법 2011도16167 양도=확정이전·2021도10861 보관] — 결정근거는 §22-9. 공인인증서 폐지(전자서명법 2020.12.10).
- AWS 클라우드: 전금감독규정 §14조의2 ①중요도 ②정보보호위 ④**3개월내 금감원보고** **⑦단서 개인신용정보 국내설치**(서울OK·프랑크푸르트 위반) §15①3호 망분리 / 개인정보보호법 §26 위탁(§26⑦) / 신정법 §17. (고시=현행성 재확인)
- 혁신금융 특별법 §4(2년)·**§10②(만료3개월전 연장)**→만료시 §4 본허가. 국내유출 개인정보보호법 §34(72h·1천명, 위자료 2018다222303).

**④ 로드맵** — 지금(2주): 유출통지·BaFin회신·연장신청·국외리전 격리·DPA/암호화/SCC·API착수. 3개월: EU인가구조·GDPR정비(대리인·DPO·현지어방침·SCC)·마이데이터 본허가·클라우드 절차·데이터 거버넌스.
