
# LEET 추리논증 95점권용 논리학·강화약화·선지판단 종합보고서 v2

## 0. 개정 원칙

이 판에서는 다음을 기준으로 다시 작성했다.

1. 통상표기 문제, 기호 표기 자체의 정당성 논의, 표기법 비교는 제외했다. 시험장에서 점수로 이어지지 않는 내용은 뺐다.
2. 깨지기 쉬운 수학기호를 쓰지 않고, `A`, `B`, `모든 A`, `어떤 A`, `A가 아니다`, `A이면 B`처럼 알파벳과 한국어로만 정리했다.
3. 강화/약화는 “OO/OX” 식의 불명확한 표기 대신, “타깃 주장 T를 더 믿게 만드는가, 덜 믿게 만드는가”라는 판정식으로 통일했다.
4. LSAT 공식 공개 Logical Reasoning 샘플의 선지는 한국어 시험에 적용 가능한 번역형·축약형으로 추가했다. 문항 원문 전체를 재수록하지 않고, 선지의 논리 기능을 한국어로 바꾸었다.
5. 한국어 양상, 필요조건, 충분조건 표지어를 별도 표로 넣었다. 특히 “할 수 있다”, “해야 한다”, “알다”, “주장하다”, “오직”, “만”, “않는 한”의 함정을 분리했다.
6. 드라이브의 LEET 풀이법, 강화약화, 양상논리학, LEET 추리논증 기출 정리의 실제 내용과 LSAC·SEP 등 공개 학술 자료를 대조하여, 기출 적용 가능한 것만 남겼다.

## 1. 이 보고서의 사용법

이 문서는 개념서가 아니라 시험장용 판단 매뉴얼이다. 모든 문제를 아래 4단계로 처리한다.

### 1.1 네 단계

1. 발문 먼저 본다.
   - 강화인가, 약화인가, 반드시 참인가, 추론 가능한가, 논증의 결함인가, 전제인가, 원리 적용인가를 5초 안에 정한다.
2. 타깃 주장 T를 한 문장으로 쓴다.
   - 결론이 여러 문장처럼 보여도 답은 보통 하나의 결론, 하나의 가설, 하나의 규범명제에 걸려 있다.
3. T의 종류를 분류한다.
   - 조건문인가, 일반화인가, 인과인가, 유비인가, 설명가설인가, 규범판단인가, 계산·배치 규칙인가.
4. 선지 E가 T와 어떤 관계인지 본다.
   - E가 T의 반례를 줄이면 강화.
   - E가 T의 대안설명을 줄이면 강화.
   - E가 T의 전제와 결론 사이의 빈칸을 메우면 강화.
   - E가 반례, 대체원인, 역인과, 표본편향, 측정오류, 적용조건 미충족을 만들면 약화.
   - E가 T가 아니라 주변정보를 건드리면 무관.

### 1.2 95점권의 핵심 습관

상위권은 논리기호를 많이 써서 맞히는 것이 아니라, **무엇을 기호화하지 않아도 되는지**를 안다. 긴 지문에서는 전부 쓰지 말고 다음만 표시한다.

- 주장: 글쓴이가 최종적으로 미는 말
- 근거: 주장을 받치는 말
- 조건: A이면 B, A일 때에만 B, A가 아니면 B
- 양화: 모든, 어떤, 없음, 전부는 아님
- 양상: 반드시, 가능, 알다, 믿다, 해야 한다, 할 수 있다
- 변수: 원인, 결과, 대조집단, 측정값, 예외

## 2. 기본 논리: 시험장에서 필요한 만큼만

### 2.1 논증의 최소 구조

논증은 “전제들이 결론을 얼마나 지지하는가”의 구조다.

- 전제: 받아들이라고 제시된 근거
- 결론: 전제로부터 받아들이라고 하는 주장
- 숨은 전제: 전제와 결론 사이를 이어 주지만 말로 드러나지 않은 다리
- 반례: 전제가 참인데 결론이 거짓이 되는 경우
- 강화: 그 반례 가능성을 줄이거나, 전제와 결론의 연결을 강하게 만드는 정보
- 약화: 그 반례 가능성을 늘리거나, 연결을 끊는 정보

### 2.2 조건문

`A이면 B`라고 하면 A가 충분조건이고 B가 필요조건이다. 말로 풀면 “A가 성립하는 모든 경우에는 B도 성립한다”이다.

| 자연어 | 읽는 법 | 반드시 가능한 말 | 하면 안 되는 말 |
|---|---|---|---|
| A이면 B | A가 있으면 B도 있다 | B가 아니면 A도 아니다 | B이면 A |
| A이면 B | A가 있으면 B도 있다 | B가 아니면 A도 아니다 | A가 아니면 B도 아니다 |
| A일 때에만 B | B가 성립하려면 A가 필요 | B이면 A | A이면 B라고 단정 |
| 오직 A만 B | B인 것은 A에 속한다 | B이면 A | A이면 B라고 단정 |
| A가 아니면 B | A가 없을 때 B | A가 아니면 B | A이면 B가 아니라고 단정 |
| A하지 않는 한 B | A가 없으면 B | A가 아니면 B | A가 있으면 B가 아니라고 단정 |

### 2.3 역, 이, 대우

- 원문: A이면 B.
- 대우: B가 아니면 A가 아니다. 원문과 항상 같이 간다.
- 역: B이면 A. 원문만으로는 안 된다.
- 이: A가 아니면 B가 아니다. 원문만으로는 안 된다.

시험에서 “가장 그럴듯한 오답”은 거의 역 또는 이다.

### 2.4 양화문

| 표현 | 시험장 번역 | 함정 |
|---|---|---|
| 모든 A는 B | A인 것은 빠짐없이 B | A가 실제로 존재한다는 말은 아닐 수 있다 |
| 어떤 A는 B | A이면서 B인 사례가 적어도 하나 | 대부분이라는 뜻이 아니다 |
| 어떤 A도 B가 아니다 | A이면서 B인 사례가 없다 | “일부는 아니다”와 다르다 |
| 모든 A가 B인 것은 아니다 | A이면서 B가 아닌 사례가 적어도 하나 | “아무 A도 B가 아니다”가 아니다 |
| A만 B | B이면 A | A이면 B가 아니다 |
| A도 B | A인 사례가 B임을 추가 | 전체 일반화가 아니다 |
| A조차 B | 예상과 반대되는 특칭 강조 | 전칭으로 키우지 말 것 |
| 대부분 A는 B | 절반 초과 또는 높은 비율 | 정확한 수치가 없으면 수리화 금지 |
| 적어도 n개 | n개 이상 | 정확히 n개 아님 |
| 많아야 n개 | n개 이하 | 정확히 n개 아님 |

### 2.5 범위 함정

“모든 학생이 책 한 권을 읽었다”는 두 가지로 갈라진다.

- 학생마다 책이 다를 수 있다: 각 학생에게 책이 하나씩 있다.
- 같은 책 한 권일 수 있다: 어떤 책 하나를 모든 학생이 읽었다.

선지에서 “동일한”, “각각”, “서로 다른”, “적어도 하나의 같은”이 붙으면 이 차이를 묻는 것이다.

## 3. 한국어 필요조건·충분조건 표지어

### 3.1 충분조건 표지어

충분조건 표지어는 “A가 오면 B까지 보장된다”는 말이다.

| 표지어 | 읽는 법 | 예시 | 시험장 처리 |
|---|---|---|---|
| A이면 B | A가 성립하면 B 성립 | 비가 오면 길이 젖는다 | A를 보면 B 체크 |
| A라면 B | A이면 B와 같음 | 법률행위라면 의사표시가 있다 | A를 보면 B 체크 |
| A인 경우 B | A이면 B | 고의가 있는 경우 책임이 무겁다 | 조건 충족 여부 확인 |
| A할 때 B | 문맥상 A이면 B | 계약이 해제될 때 원상회복한다 | 시간조건인지 법적조건인지 확인 |
| A만으로 B | A 하나로 B 충분 | 증거 X만으로 유죄 인정 가능 | 다른 조건 필요 없다는 뜻 |
| A하기만 하면 B | A가 충족되면 B | 신고하기만 하면 효력이 생긴다 | A가 좁은 쪽 |
| A는 B를 초래한다 | 인과적 충분성 주장일 수 있음 | 결핍은 증상 악화를 초래한다 | 인과문항으로 전환 |
| A는 B를 가능하게 한다 | A가 B의 가능조건 | 기술 X는 분석을 가능하게 한다 | 충분이 아니라 능력조건일 수도 있음 |

### 3.2 필요조건 표지어

필요조건 표지어는 “B가 없으면 A가 성립하지 않는다”는 말이다.

| 표지어 | 읽는 법 | 예시 | 시험장 처리 |
|---|---|---|---|
| A하려면 B가 필요 | A이면 B | 합격하려면 과락이 없어야 한다 | A를 보면 B 체크 |
| A이기 위해서는 B여야 | A이면 B | 법인이려면 설립등기가 필요하다 | B는 넓은 쪽 |
| B 없이는 A 불가능 | A이면 B | 동의 없이는 처분 불가 | B가 없으면 A 제거 |
| B가 전제되어야 A | A이면 B | 측정이 정확하려면 기기가 보정되어야 | 숨은 전제 후보 |
| A는 B를 요구한다 | A이면 B | 주장은 근거를 요구한다 | A가 B를 필요로 함 |
| B인 경우에만 A | A이면 B | 허가받은 경우에만 영업 가능 | “만” 뒤가 필요조건 |
| 오직 B일 때 A | A이면 B | 오직 요건 충족 시 처벌 가능 | 오직 뒤가 필요조건 |
| B가 아닌 한 A 아님 | A이면 B | 과실이 없는 한 책임 없음 | 부정 방향 확인 |

### 3.3 필요충분조건 표지어

| 표지어 | 읽는 법 | 처리 |
|---|---|---|
| A와 B는 동치다 | A이면 B이고, B이면 A | 양방향 모두 사용 |
| A는 B의 필요충분조건이다 | A이면 B이고, B이면 A | 한쪽만 쓰면 부족 |
| A인 경우 그리고 그 경우에만 B | A이면 B, B이면 A | 영어 if and only if형 |
| A일 때만 그리고 그때에만 B | A이면 B, B이면 A | “만”이 두 방향으로 작동 |
| A와 B가 정확히 일치한다 | A집합과 B집합이 같다 | 예외 하나만 있어도 거짓 |

### 3.4 한국어 조건문 함정

1. “A만 B”는 보통 `B이면 A`이다. “학생만 입장 가능”은 입장 가능하면 학생이라는 뜻이지, 학생이면 모두 입장 가능하다는 뜻은 아니다.
2. “A이면 B”에서 “A가 아니다”가 나오면 아무 결론도 못 낸다.
3. “A이면 B”에서 “B이다”가 나오면 A라고 못 한다.
4. “A하지 않는 한 B”는 기본적으로 A가 없으면 B다. A가 있으면 B가 반드시 없다는 뜻이 아니다.
5. “A는 B에 달려 있다”는 대개 B가 A의 조건이라는 뜻이지만, 구체적 방향은 지문 맥락으로 잡아야 한다.
6. “A가 있어야 B”와 “A만 있으면 B”는 반대 방향이다. 앞은 A가 필요조건, 뒤는 A가 충분조건이다.

## 4. 한국어 양상 표지어

양상은 “명제 내용 자체”가 아니라 그 명제를 어떤 태도로 말하는가이다. LEET에서는 양상논리 공리명을 묻지 않는다. 실제로 묻는 것은 다음 네 가지다.

1. 사실인가, 가능성인가.
2. 지식인가, 믿음인가.
3. 규범상 해야 하는가, 실제로 그렇게 되는가.
4. 능력이 있다는 뜻인가, 그럴 가능성이 있다는 뜻인가.

### 4.1 진리·필연 양상

| 표지어 | 뜻 | 선지 함정 |
|---|---|---|
| 반드시 | 모든 관련 경우에서 성립 | “대체로”와 바꾸면 약화 |
| 필연적으로 | 예외가 없다는 강한 주장 | 경험적 경향과 혼동 금지 |
| 불가피하다 | 피할 수 없음 | 비용이 크다는 말과 다름 |
| 일 수밖에 없다 | 다른 가능성 배제 | 근거가 없으면 과강도 선지 |
| 예외 없이 | 전칭 | 반례 하나면 무너짐 |
| 항상 | 전칭 시간·상황 | 한 사례로는 강화 약함 |
| 결코 아니다 | 강한 부정 | “거의 아니다”와 다름 |

### 4.2 가능 양상

| 표지어 | 뜻 | 선지 함정 |
|---|---|---|
| 할 수 있다 | 가능, 허용, 능력 중 하나 | 문맥으로 분리 |
| 가능하다 | 적어도 하나의 가능한 경우 | 실제 발생과 다름 |
| 일 수도 있다 | 가능성 제기 | 결론 확정 아님 |
| 배제할 수 없다 | 반대 가능성을 못 없앰 | 주장 강화가 아니라 약화일 수 있음 |
| 개연성이 있다 | 어느 정도 그럴 법함 | 필연 아님 |
| 가능성이 높다 | 확률적 우세 | “반드시” 아님 |
| 반드시 그렇지는 않다 | 전칭 부정 | “전혀 아니다” 아님 |

### 4.3 인식 양상

| 표지어 | 사실성 | 처리 |
|---|---:|---|
| 알다 | 사실성을 보통 함축 | “A가 P를 안다”면 P를 사실로 놓아도 됨 |
| 밝혀졌다 | 사실성 강함 | 반박 선지는 증거 신뢰성 공격 필요 |
| 입증되었다 | 사실성 강함 | “주장되었다”와 구별 |
| 확인되었다 | 사실성 강함 | 측정·절차가 쟁점이면 확인의 타당도 점검 |
| 관찰되었다 | 관찰 사실은 강함 | 해석은 별도 |
| 주장하다 | 사실성 없음 | 주장자 입장으로만 처리 |
| 생각하다 | 사실성 없음 | P가 참이라고 비약 금지 |
| 믿다 | 사실성 없음 | “믿는다”와 “안다” 구별 |
| 추정하다 | 잠정적 | 추가 증거가 필요 |
| 가정하다 | 사실성 없음 | 모형 내부 조건으로만 사용 |

### 4.4 당위 양상

| 표지어 | 뜻 | 선지 함정 |
|---|---|---|
| 해야 한다 | 의무 | 실제로 한다가 아님 |
| 의무가 있다 | 규범적 요구 | 가능하다는 뜻도 아님 |
| 허용된다 | 해도 된다 | 해야 한다가 아님 |
| 금지된다 | 하면 안 된다 | 실제로 안 한다가 아님 |
| 위법이다 | 규범 위반 | 나쁘다는 도덕평가와 구별 |
| 정당화된다 | 이유가 충분함 | 결과가 실제 발생한다는 뜻 아님 |
| 권리가 있다 | 청구·행위 가능성 | 반드시 행사한다는 뜻 아님 |

### 4.5 동적·능력 양상

| 표지어 | 뜻 | 선지 함정 |
|---|---|---|
| 할 수 있다 | 능력 또는 상황 가능 | 우연히 가능과 구별 |
| 가능하게 한다 | 조건을 마련 | 실제 발생 보장 아님 |
| 역량이 있다 | 주체 능력 | 법적 허용과 다름 |
| 기술적으로 가능 | 기술 조건 충족 | 경제성·규범성 별도 |
| 실현할 수 있다 | 능력 또는 수단 있음 | 실현한다는 결론 아님 |
| 통제할 수 있다 | 개입 가능성 | 원인이라는 결론은 추가 필요 |

### 4.6 양상 전환 오답

| 지문 | 오답 선지 형태 | 왜 틀리는가 |
|---|---|---|
| A일 가능성이 있다 | A이다 | 가능을 사실로 바꿈 |
| A여야 한다 | A이다 | 당위를 사실로 바꿈 |
| A가 P라고 주장한다 | P이다 | 주장자를 사실로 바꿈 |
| A가 P를 안다 | P가 아닐 수 있다 | 지식의 사실성을 무시 |
| A할 수 있다 | A해야 한다 | 능력을 의무로 바꿈 |
| A해도 된다 | A해야 한다 | 허용을 의무로 바꿈 |
| A가 불가피하다 | A가 바람직하다 | 필연을 가치평가로 바꿈 |
| A가 바람직하다 | A가 가능하다 | 가치판단을 가능조건으로 바꿈 |

## 5. 강화·약화의 통일 판정법

### 5.1 기본 정의

타깃 주장 T와 선지 정보 E가 있다.

- 강화: E를 알게 되면 T를 믿을 이유가 커진다.
- 약화: E를 알게 되면 T를 믿을 이유가 작아진다.
- 무관: E가 T의 근거관계, 반례, 대안설명, 적용조건을 건드리지 않는다.

강화는 “T를 증명”할 필요가 없다. 약화도 “T를 완전히 반박”할 필요가 없다. LEET와 LSAT의 강화/약화는 대부분 “정도”의 문제다.

### 5.2 첫 질문: 무엇을 강화·약화하는가

| 타깃 T의 종류 | 강화하는 정보 E | 약화하는 정보 E |
|---|---|---|
| A이면 B라는 조건문 | A인 사례가 B임을 보임, A인데 B가 아닌 경우를 제거 | A인데 B가 아닌 사례 제시 |
| 모든 A는 B라는 일반화 | 대표성 있는 A 사례들이 B임을 보임 | A인데 B가 아닌 반례 제시 |
| A가 B의 원인 | A 변화 뒤 B 변화, 대조군, 무작위화, 용량-반응, 메커니즘 | 역인과, 공통원인, 표본편향, 측정오류 |
| A와 B가 유사하므로 결론 C | 결론 C와 관련된 유사성 추가 | 결론 C와 관련된 차이 추가 |
| 가설 H가 현상 E를 설명 | H가 새 예측을 맞힘, 경쟁가설 제거 | 경쟁가설이 더 잘 설명, H의 예측 실패 |
| 규범상 A해야 한다 | 적용 규칙과 사실을 연결 | 규칙 적용요건 불충족, 예외조항 존재 |
| 주장 A는 타당하다 | 숨은 전제 보강, 논리 간극 메움 | 숨은 전제 부정, 반례 가능성 제시 |
| 통계로 결론 C | 표본 대표성, 충분한 크기, 비교가능성 | 표본 편향, 작은 표본, 다른 모집단 |

### 5.3 강화의 세 종류

1. 직접강화
   - 결론이 예측하는 바로 그 결과가 관찰된다.
   - 예: 이 약이 혈압을 낮춘다는 주장에 대해, 약 투여군의 혈압이 대조군보다 낮았다.

2. 간접강화
   - 결론을 위협하는 대안설명을 제거한다.
   - 예: 약 투여군과 대조군의 식습관, 연령, 운동량이 비슷했다.

3. 구조강화
   - 전제와 결론 사이의 다리를 놓는다.
   - 예: “가격을 낮추면 수요가 늘어난다. 따라서 매출이 늘어난다”에서, 수요 증가분이 가격 하락분보다 크다는 정보.

### 5.4 약화의 다섯 종류

1. 반례
   - A인데 B가 아닌 사례.
2. 대체원인
   - B는 A 때문이 아니라 C 때문일 수 있음.
3. 역인과
   - A가 B를 낳은 것이 아니라 B가 A를 낳았을 수 있음.
4. 표본·측정 공격
   - 자료가 편향되었거나 측정이 둔감함.
5. 적용조건 불충족
   - 논증이 성립하려면 필요한 조건이 사실은 충족되지 않음.

### 5.5 무관 선지의 전형

| 무관 선지 | 왜 무관한가 |
|---|---|
| 결론과 같은 주제이지만 다른 변수만 말함 | 타깃 T의 원인·결과·조건을 건드리지 않음 |
| 사례가 있지만 모집단이 다름 | 일반화 대상이 아님 |
| 결과와 같은 방향이지만 시간 순서가 없음 | 인과를 못 받침 |
| 원인을 말하지만 결과 변수가 없음 | 결론의 결과를 건드리지 않음 |
| 결과를 말하지만 원인 변수가 없음 | 비교 대상이 없음 |
| 가치판단을 말하지만 지문은 사실판단 | 양상 전환 |
| 일부 사례만 말하는데 결론은 전칭 | 강화가 너무 약하거나 무관 |
| 결론의 예외가 아니라 배경설명 | 반례가 아님 |

### 5.6 과학가설형 강화·약화

과학 지문에서는 다음 순서로 본다.

1. 가설 H: 무엇이 무엇을 설명한다고 하는가.
2. 예측 P: H가 참이면 어떤 관찰이 기대되는가.
3. 관찰 E: 실제로 무엇이 관찰되었는가.
4. 보조조건 A: 실험장치, 측정민감도, 표본, 전제조건이 제대로 갖추어졌는가.
5. 경쟁가설 R: 같은 E를 더 잘 설명하는 다른 가설이 있는가.

| 선지 기능 | 강화인가 | 이유 |
|---|---:|---|
| H가 예측한 새로운 관찰이 실제로 나왔다 | 강화 | 예측 성공 |
| H가 틀렸다면 나오기 어려운 결과가 나왔다 | 강한 강화 | 위험한 예측 성공 |
| 측정장비가 충분히 민감했다 | 강화 | “못 찾은 것”을 “없음”에 가깝게 만듦 |
| 대조군과 실험군이 원인 A 외에는 같았다 | 강화 | 대체원인 제거 |
| 경쟁가설 R이 같은 현상을 설명 못 한다 | 강화 | H의 상대적 설명력 증가 |
| H가 예측한 결과가 나오지 않았다 | 약화 가능 | 보조조건이 제대로였을 때 강함 |
| 실험군과 대조군의 표본이 애초에 달랐다 | 약화 | 선택편향 가능 |
| 결과 측정이 둔감했다 | 약화 | 음성 결과의 의미 감소 |
| 다른 원인 C가 결과 B를 만들 수 있다 | 약화 | 대체원인 |
| H가 결과 뒤에 사후적으로 끼워 맞춰졌다 | 약화 | 예측력이 낮음 |

### 5.7 강화/약화 선택지 판정 공식

선지를 볼 때 다음 문장에 끼워 넣는다.

- “이 선지가 참이면, 결론 말고 다른 설명이 줄어드는가?” 줄어들면 강화.
- “이 선지가 참이면, 결론이 예상한 현상이 더 잘 나타나는가?” 그렇다면 강화.
- “이 선지가 참이면, 결론의 적용조건이 충족되는가?” 그렇다면 강화.
- “이 선지가 참이면, 결론과 같은 결과가 다른 원인으로 설명되는가?” 그렇다면 약화.
- “이 선지가 참이면, 결론의 핵심 비교가 깨지는가?” 그렇다면 약화.
- “이 선지가 참이어도 결론의 원인, 결과, 조건, 범위가 그대로인가?” 그렇다면 무관.

## 6. LSAT식 번역형 선지 모음

아래는 LSAC 공식 공개 Logical Reasoning 샘플에서 확인되는 선지 기능을 한국어 시험용으로 번역·축약한 것이다. 문항 원문을 외우라는 뜻이 아니라, 선지가 어떤 논리 기능을 하는지 보라는 뜻이다.

### 6.1 견해불일치형: 순수연구의 가치

쟁점: 두 사람이 “순수연구의 가장 큰 가치가 어디에 있는가”를 다르게 본다.

| 번호 | 한국어 선지형 | 판정 포인트 |
|---:|---|---|
| 1 | 순수연구는 신기술을 제공한다는 점에서 가치가 있다 | 둘 다 인정하므로 불일치 아님 |
| 2 | 순수연구는 의학 지식의 경계를 확장한다 | 직접 충돌 지점 아님 |
| 3 | 순수연구는 생명을 구하는 것을 중요한 목표로 삼아야 한다 | 둘 다 일정 부분 동의 가능 |
| 4 | 순수연구의 가장 가치 있는 성과는 의학적 응용에 있다 | 정답형. 한쪽은 생명구호를 최고가치, 다른 쪽은 지식확장을 더 높게 봄 |
| 5 | 순수연구는 생명구호 기술 제공과 별개의 가치도 가진다 | 한쪽은 명시 동의, 다른 쪽은 부정하지 않음 |

**시험 적용:** “무엇에 동의하는가”가 아니라 “둘이 반드시 갈라지는 축”을 찾아야 한다. 가치 순위, 최상급, 가장 중요함이 보이면 불일치 후보가 된다.

### 6.2 유비추론 구조형: 웹 광고에서 인쇄 광고 추론

쟁점: 직접자료가 없는 인쇄광고 성과를, 직접자료가 있는 웹광고 성과로 추론한다.

| 번호 | 한국어 선지형 | 판정 포인트 |
|---:|---|---|
| 1 | 원인의 강도로 결과의 강도를 예측한다 | 원인 강도 문제가 아님 |
| 2 | 일반 사건의 빈도로 특정 사건 확률을 추론한다 | 통계 일반화가 아님 |
| 3 | 많은 구체사례로부터 통계 일반화를 이끈다 | 표본 일반화가 아님 |
| 4 | 직접증거가 있는 사례를 이용해 직접증거가 없는 유사사례를 추론한다 | 정답형. 유비추론 |
| 5 | 과거의 유사사건으로 미래를 예측한다 | 미래예측이 아님 |

**시험 적용:** “비슷한 두 사례 중 하나의 자료로 다른 하나를 판단”하면 유비추론이다. 강화는 관련 유사성을 추가하고, 약화는 관련 차이를 추가한다.

### 6.3 추론가능형: 교량 붕괴와 수학적 분석

쟁점: 사고 이후 기존 경험칙이 폐기되고 더 엄밀한 수학적 분석으로 전환되었다.

| 번호 | 한국어 선지형 | 판정 포인트 |
|---:|---|---|
| 1 | 1907년 이전 교량은 모두 대중에게 위험했다 | 과도한 일반화 |
| 2 | 설계자의 부재가 붕괴의 원인이었다 | 인과 단정 근거 없음 |
| 3 | 당시 분석법이 부적절해서 경험칙에 의존했다 | 동기 추론 근거 없음 |
| 4 | 더 엄밀한 분석만이 붕괴를 막을 유일한 방법이었다 | 유일성 과강도 |
| 5 | 당시 경험칙의 분석 수준은 공사 중 안전을 완전히 보장하기에 부족했다 | 정답형. 지문에서 따라오는 최소 결론 |

**시험 적용:** “유일한”, “모두”, “원인이다”가 들어가면 지문이 그 정도까지 말했는지 확인한다. 추론가능형 정답은 대개 더 약한 문장이다.

### 6.4 강화형: 초신성 뒤 중성자별이 보이지 않음

쟁점: 이론은 특정 크기의 초신성 뒤 중성자별이 남아야 한다고 하는데, 1987년 사례에서 관측되지 않았다. 따라서 이론이 틀렸다는 주장을 강화하려면 “관측 못 한 이유가 장비 한계가 아니다”를 보여야 한다.

| 번호 | 한국어 선지형 | 판정 포인트 |
|---:|---|---|
| 1 | 관측된 초신성 잔해 대부분 근처에는 중성자별이 있다 | 해당 크기·해당 사례를 직접 건드리지 못함 |
| 2 | 사용된 민감한 장비는 그 위치보다 더 먼 중성자별도 검출한 적이 있다 | 정답형. 장비 한계 대안설명 제거 |
| 3 | 1987년 초신성은 진행 중 관측된 첫 사례였다 | 검출 가능성에 무관 |
| 4 | 현 이론은 1987년 초신성의 여러 특징을 맞혔다 | 오히려 이론 강화 |
| 5 | 일부 중성자별은 초신성이 아닌 원인으로 생긴다 | 초신성이 중성자별을 남기는지와 무관 |

**시험 적용:** “없다”를 주장하려면 “찾을 수 있었는데도 못 찾았다”가 필요하다. 탐지 능력, 측정 민감도, 검정력이 강화 포인트다.

### 6.5 오류형: 민주주의와 정치적 자유

쟁점: 민주주의가 정치적 자유를 보장하지 않는 사례와, 민주주의가 아니어도 자유가 있는 사례를 들어 “민주주의는 자유를 증진하지 않는다”고 결론낸다.

| 번호 | 한국어 선지형 | 판정 포인트 |
|---:|---|---|
| 1 | 필요조건과 충분조건을 혼동했다 | 직접 혼동은 아님 |
| 2 | 자유 증가가 민주화를 초래할 수 있음을 고려하지 않았다 | 역인과이지만 결론 공격의 핵심은 아님 |
| 3 | 인과주장과 무관한 역사사례를 든다 | 사례는 어느 정도 관련 있음 |
| 4 | 민주주의가 필요조건도 충분조건도 아니어도 자유를 증진할 수 있음을 간과한다 | 정답형 |
| 5 | 개인적 관점에 근거했다 | 근거 없음 |

**시험 적용:** “A가 B의 필요조건이 아니다”와 “A가 B의 충분조건이 아니다”를 합쳐도 “A가 B를 촉진하지 않는다”는 결론은 안 나온다.

### 6.6 원리보강형: 약값 차등정책

쟁점: 제약사가 가난한 나라에는 낮은 가격, 부유한 나라에는 높은 가격을 매기는 정책이 정당한가.

| 번호 | 한국어 선지형 | 판정 포인트 |
|---:|---|---|
| 1 | 아픈 사람은 건강한 사람보다 더 고려받아야 한다 | 문제는 아픈 사람들 사이의 배분 |
| 2 | 부유한 기관은 취약자를 도울 의무가 있다 | 제약사의 일반 의무만 보강, 정책 비판과 직접 연결 약함 |
| 3 | 특별 배려는 소속 사회가 아니라 개인의 필요에 따라야 한다 | 정답형. 국가 평균이 아니라 개인 필요로 기준 전환 |
| 4 | 부유한 나라 사람들이 더 나은 의료 접근성을 가져서는 안 된다 | 오히려 차등가격을 지지 가능 |
| 5 | 의료 불평등이 부의 불평등보다 더 부당하다 | 논점 다름 |

**시험 적용:** 원리문항은 사실과 결론 사이의 규범 기준을 찾아야 한다. 좋은 원리는 “왜 그 사실이 결론을 정당화하는가”를 연결한다.

### 6.7 충분전제형: 형식시와 정치적 보수성

쟁점: “형식시를 쓰는 현대 시인은 정치적으로 보수적 행위를 한다”는 일반화를 반박하려면, 형식시를 쓰면서도 보수적 행위를 하지 않는 사례가 필요하다.

| 번호 | 한국어 선지형 | 판정 포인트 |
|---:|---|---|
| 1 | 페미니스트는 정치적으로 보수적이지 않다 | 사람의 성향과 행위의 성격을 연결하지 못함 |
| 2 | 자유시를 쓰는 시인은 보수적이지 않다 | 대상이 다름 |
| 3 | 정치적으로 진보적인 사람은 보수적 행위를 할 수 없다 | 정답형. 사례를 반례로 완성 |
| 4 | 때때로 비보수적 시를 쓰는 사람은 보수적 시를 쓰지 않는다 | 적용 대상이 불명확 |
| 5 | 정치적 결과는 형식보다 내용이 결정한다 | 해당 시의 내용이 주어지지 않음 |

**시험 적용:** 충분전제형은 결론이 반드시 나오도록 빈칸을 메운다. “사람이 진보적”에서 “행위가 비보수적”으로 넘어가는 다리가 필요하다.

### 6.8 필요전제형: 호수 퇴적층의 뼈

쟁점: 200만 년 전부터 150만 년 전까지 존재한 호수 바닥 퇴적층에서 조상 뼈가 나왔으므로, 그 시기에 그 지역에 살았다고 결론낸다.

| 번호 | 한국어 선지형 | 판정 포인트 |
|---:|---|---|
| 1 | 그 이전에 근처에 다른 호수가 없었다 | 결론에 필요 없음 |
| 2 | 호수에 먹을 물고기가 있었다 | 왜 거기 있었는지 설명일 뿐 필요 없음 |
| 3 | 아래 용암층에는 화석이 없었다 | 결론 기간과 직접 관련 없음 |
| 4 | 호수가 익사할 만큼 깊었다 | 뼈 유입 방식은 다양함 |
| 5 | 뼈는 호수가 마르기 전에 이미 퇴적층에 있었다 | 정답형. 아니면 시기 추론이 무너짐 |

**시험 적용:** 필요전제는 부정해 본다. 선지를 부정했을 때 결론이 무너지면 필요전제다.

### 6.9 역설해소형: 전조등 의무화

쟁점: 자발적으로 전조등을 켜는 운전자는 사고가 적다. 그런데 전조등 의무화는 전체 사고를 줄이지 못한다.

| 번호 | 한국어 선지형 | 판정 포인트 |
|---:|---|---|
| 1 | 자발적 사용자는 전체의 4분의 1이다 | 왜 의무화가 안 먹히는지 설명 부족 |
| 2 | 전조등 의무화 법은 집행하기 어렵지 않다 | 오히려 해소 가능성을 줄임 |
| 3 | 법적 의무가 없을 때 전조등을 켜는 사람은 매우 조심스러운 운전자뿐이다 | 정답형. 전조등 자체가 아니라 운전자 성향 효과 |
| 4 | 어떤 지역은 좋은 날씨에 전조등 사용이 불법이다 | 비교 상황과 무관 |
| 5 | 의무화 지역은 낮 시야가 자주 나쁘다 | 두 정보 모두를 설명하지 못함 |

**시험 적용:** 역설해소는 두 문장을 모두 살려야 한다. 한쪽만 설명하면 오답이다.

### 6.10 병렬오류형: 르네상스 화가와 붉은색

쟁점: “카르파초 작품 대부분은 풍부한 붉은색을 쓴다. 새 그림도 풍부한 붉은색을 쓴다. 그러므로 카르파초 작품일 것이다.” 이는 “대부분의 A는 B, 이 대상은 B, 그러므로 A일 가능성이 높다”라는 오류다.

| 번호 | 한국어 선지형 | 판정 포인트 |
|---:|---|---|
| 1 | 대부분의 화가는 한 매체만 썼고, 이 그림이 유화이므로 그 화가는 항상 유화를 썼을 것이다 | 구조 다름 |
| 2 | 르네상스에서 흔한 주제가 서양미술 전체에서도 흔할 것이다 | 표본 범위 일반화 오류 |
| 3 | 르네상스 작품은 대부분 의뢰작이므로 이 작품도 의뢰작일 것이다 | 대부분 A가 B, 이 대상은 A, 그러므로 B. 비교적 합리적 |
| 4 | 초기 피렌체 그림 대부분은 템페라이므로, 템페라 그림인 이 작품은 초기 피렌체 그림일 것이다 | 정답형. 대부분 A는 B, 이 B는 A |
| 5 | 후기 르네상스 그림 대부분은 유화이므로, 후기 르네상스 화가도 유화를 그렸을 것이다 | 구조 다름 |

**시험 적용:** 병렬논증은 소재가 아니라 골격을 맞춘다. `대부분 A는 B`에서 `이것은 B`를 보고 `A`로 가는 것이 후건긍정형 통계오류다.

## 7. LEET·PSAT 기출 적용 가능성 검토

### 7.1 직접 적용 가능성이 높은 것

| 개념 | LEET 적용 | PSAT 적용 | 비고 |
|---|---|---|---|
| 필요·충분조건 | 법조문, 원리 적용, 논증 전제 | 조건배열, 상황판단 법규형 | 최상위 빈출 |
| 양화 | 명제논리, 술어논리, 집합관계 | 언어논리, 조건분류 | 모든/어떤/없음/전부는 아님 |
| 양상 | 주장·입증·가능·당위 구별 | 법규형, 판단형 | “할 수 있다”와 “해야 한다” 구별 |
| 강화·약화 | 논증평가, 과학가설, 인과 | 언어논리 논증, 상황판단 정책 | 대안설명 제거가 핵심 |
| 유비 | 논증분석, 견해비교 | 사례적용 | 관련 유사성만 본다 |
| 계산논리 | 수리추리, 표·그래프 | 자료해석, 상황판단 | 앵커 수, 극값, 불변량 |
| 그룹화 | 배열, 속성, 진실거짓 | 조건배치 | 표는 최소화, 규칙은 최대화 |

### 7.2 간접 적용에 그치는 것

| 학술 개념 | 시험에서의 실제 역할 | 외울 필요 |
|---|---|---:|
| 확인이론 | 증거가 가설을 얼마나 지지하는지 판단 | 이름 암기 불필요 |
| 헴펠식 확증 | A이면서 B인 사례와 A이면서 B가 아닌 반례 구별 | 사례 판단만 필요 |
| 포퍼식 반증 | 보편명제는 반례 하나가 강력함 | 용어 암기 불필요 |
| 보조가설 문제 | 실험 실패가 곧 주가설 반박은 아님 | 매우 중요 |
| 설명추론 | 경쟁가설 중 더 잘 설명하는 것 선택 | 중요 |
| 베이지안식 지지 | 증거가 가설의 그럴듯함을 올리는가 | 수식 불필요 |
| 크립키 가능세계 | 필연/가능의 개념틀 | 공리명 암기 불필요 |

### 7.3 제거해도 되는 것

- 양상논리 공리명을 시험장에 외워 들어가는 것.
- 철학사적 표기법 차이를 길게 비교하는 것.
- 기호를 많이 쓰는 것 자체.
- “강화는 참 사례, 약화는 거짓 사례”처럼 모든 문항을 하나의 표로 처리하는 것.
- 표본, 측정, 대조군, 경쟁가설을 보지 않고 결론과 같은 방향의 정보만 고르는 것.

### 7.4 LEET 기출식 적용 예시

#### 예시 1. 가설추론형

가설: 지각 내부의 물 때문에 박테리아 증식이 가능하다.

- “지각 내부에도 물이 있다”는 정보는 강화다. 가설의 핵심 조건을 직접 보강한다.
- “박테리아가 외부에서 유입되었다”는 정보는 약화다. 내부 조건 때문이라는 설명을 대체한다.
- “그냥 추측이었다”는 정보는 약화라기보다 증거 지위 공격이다. 지지도가 낮아진다.
- “외부 유입이 불가능하다”는 정보는 강화다. 경쟁가설을 제거한다.

#### 예시 2. 근본원인 대 표면원인

주장: 한 시대 갈등은 표면적 사건이 아니라 근본적 원인으로 규정된다.

- “표면적 이념갈등이 독립이라는 목표 아래 결합했다”는 정보는 강화다. 표면원인의 독립적 설명력을 낮춘다.
- “계급갈등이 실제로 강했다”는 정보는 약화다. 표면원인의 설명력을 높인다.
- “근대화가 여러 영역에서 진행되었다”는 정보는 맥락에 따라 약화 또는 무관이다. 근본원인을 대체하는 설명인지가 핵심이다.

#### 예시 3. 암묵적 전제형

주장: 장애가 예상되는 태아의 낙태를 허용해서는 안 된다.
근거: 인간은 존엄하고, 미래 장애자의 삶의 가치를 부정하면 안 된다.

숨은 전제 후보는 “그 태아를 인간 또는 존엄의 주체로 보아야 한다”이다. 단순히 “장애인은 차별받아서는 안 된다”는 말은 이미 근거에 가까울 뿐, 태아와 결론 사이의 다리를 충분히 놓지 못한다.

## 8. 선지 패턴 은행

### 8.1 조건문 선지

| 선지형 | 판정 |
|---|---|
| A이면 B인데, A가 성립한다. 따라서 B다 | 가능 |
| A이면 B인데, B가 성립한다. 따라서 A다 | 안 됨. 역 오류 |
| A이면 B인데, A가 성립하지 않는다. 따라서 B도 아니다 | 안 됨. 이 오류 |
| A이면 B인데, B가 성립하지 않는다. 따라서 A도 아니다 | 가능. 대우 |
| A일 때에만 B인데, B다. 따라서 A다 | 가능 |
| A일 때에만 B인데, A다. 따라서 B다 | 안 됨 |
| 오직 A만 B인데, 어떤 것이 B다. 따라서 A다 | 가능 |
| 오직 A만 B인데, 어떤 것이 A다. 따라서 B다 | 안 됨 |
| A하지 않는 한 B인데, A하지 않았다. 따라서 B다 | 가능 |
| A하지 않는 한 B인데, A했다. 따라서 B가 아니다 | 안 됨 |

### 8.2 양화 선지

| 선지형 | 판정 |
|---|---|
| 모든 A는 B다. 어떤 C는 A다. 따라서 어떤 C는 B다 | 가능 |
| 모든 A는 B다. 어떤 B는 C다. 따라서 어떤 A는 C다 | 안 됨 |
| 어떤 A는 B다. 모든 B는 C다. 따라서 어떤 A는 C다 | 가능 |
| 어떤 A는 B다. 모든 C는 B다. 따라서 어떤 A는 C다 | 안 됨 |
| 어떤 A도 B가 아니다. 모든 C는 A다. 따라서 어떤 C도 B가 아니다 | 가능 |
| 모든 A가 B인 것은 아니다. 따라서 어떤 A는 B가 아니다 | 가능 |
| 어떤 A는 B가 아니다. 따라서 모든 A가 B인 것은 아니다 | 가능 |
| 대부분 A는 B다. 이 대상은 A다. 따라서 B일 가능성이 있다 | 약한 추론 가능, 필연 아님 |
| 대부분 A는 B다. 이 대상은 B다. 따라서 A일 가능성이 높다 | 모집단 크기에 따라 오류 가능 |
| A가 하나라도 B가 아니면, 모든 A는 B라는 말은 깨진다 | 가능 |

### 8.3 양상 선지

| 선지형 | 판정 |
|---|---|
| 지문은 A가 가능하다고만 한다. 선지는 A가 사실이라고 한다 | 오답 가능성 큼 |
| 지문은 A해야 한다고 한다. 선지는 A가 실제로 일어난다고 한다 | 오답 가능성 큼 |
| 지문은 A가 P라고 주장한다고 한다. 선지는 P가 참이라고 한다 | 오답 가능성 큼 |
| 지문은 A가 P를 안다고 한다. 선지는 P라고 한다 | 보통 가능 |
| 지문은 A가 P를 믿는다고 한다. 선지는 P라고 한다 | 안 됨 |
| 지문은 A할 수 있다고 한다. 선지는 A할 의무가 있다고 한다 | 안 됨 |
| 지문은 A해도 된다고 한다. 선지는 A해야 한다고 한다 | 안 됨 |
| 지문은 A가 불가피하다고 한다. 선지는 A가 바람직하다고 한다 | 안 됨 |
| 지문은 A가 바람직하다고 한다. 선지는 A가 실현 가능하다고 한다 | 안 됨 |
| 지문은 A의 가능성을 배제하지 못한다고 한다. 선지는 A가 가장 유력하다고 한다 | 과강도 |

### 8.4 강화 선지

| 선지형 | 강화 이유 |
|---|---|
| 실험군과 대조군은 원인 A를 제외하고 유사했다 | 대체원인 제거 |
| A가 증가할수록 B도 일정하게 증가했다 | 용량-반응 |
| A가 먼저 변하고 그 뒤 B가 변했다 | 시간 선후 보강 |
| A를 인위적으로 조작하자 B가 변했다 | 개입 증거 |
| A가 없을 때 B가 줄었다 | 원인 부재와 결과 부재 |
| B를 만드는 다른 원인 C가 배제되었다 | 경쟁가설 제거 |
| 측정장비는 B가 있었다면 검출할 만큼 민감했다 | 음성 결과의 의미 강화 |
| 독립 연구에서 같은 결과가 반복되었다 | 재현성 |
| 가설 H가 예측한 새로운 현상이 발견되었다 | 위험한 예측 성공 |
| 결론에 필요한 숨은 조건이 실제 충족되었다 | 논증 간극 보강 |

### 8.5 약화 선지

| 선지형 | 약화 이유 |
|---|---|
| A가 없는데도 B가 나타났다 | A 필요성 약화 |
| A가 있는데도 B가 나타나지 않았다 | A 충분성 약화 |
| B가 A보다 먼저 나타났다 | 역인과 가능 |
| A와 B 모두 C의 결과였다 | 공통원인 |
| 실험군은 원래 B가 높을 사람들이었다 | 선택편향 |
| 측정도구가 B를 정확히 잡지 못했다 | 측정오류 |
| 표본이 결론의 모집단과 다르다 | 일반화 약화 |
| 탈락자가 한쪽 집단에 몰렸다 | 생존자 편향 |
| H와 반대되는 새 예측이 맞았다 | 경쟁가설 강화 |
| 결론이 적용될 법적 요건이 충족되지 않았다 | 규범 적용 약화 |

### 8.6 무관 선지

| 선지형 | 무관 이유 |
|---|---|
| 결과 B와 비슷한 다른 결과 D를 말한다 | 종속변수가 다름 |
| 원인 A와 관련된 배경사를 말한다 | 원인 작동 여부와 무관 |
| 같은 주제의 도덕적 평가만 한다 | 사실 인과 주장과 무관 |
| 평균을 말하지만 결론은 개인 사례다 | 수준이 다름 |
| 개인 사례를 말하지만 결론은 집단 평균이다 | 수준이 다름 |
| 과거 자료를 말하지만 결론은 다른 제도 이후다 | 시점이 다름 |
| 한 지역을 말하지만 결론은 다른 지역이다 | 모집단이 다름 |
| 비용을 말하지만 결론은 효과 여부다 | 평가기준이 다름 |
| A의 장점을 말하지만 결론은 B와의 비교다 | 비교축 미충족 |
| 지문이 묻는 것은 원인인데 선지는 의도만 말한다 | 설명대상이 다름 |

## 9. 그룹·계산·자료형 논리

### 9.1 그룹 문제의 표준 절차

1. 대상 목록을 적는다.
2. 자리 또는 속성 목록을 적는다.
3. 확정 규칙과 금지 규칙을 분리한다.
4. “최소 하나”, “정확히 하나”, “많아야 하나”, “서로 다른”을 표시한다.
5. 강한 규칙부터 배치한다.
6. 경우가 둘로만 갈라지면 템플릿을 만든다.
7. 선지마다 새 표를 그리지 말고 기존 템플릿에서 가능성만 지운다.

### 9.2 그룹 문제 선지 패턴

| 선지형 | 처리 |
|---|---|
| 반드시 A가 1번이다 | 모든 가능한 표에서 확인 |
| A가 1번일 수 있다 | 가능한 표 하나만 찾으면 됨 |
| A와 B가 함께 올 수 없다 | 같은 표에 넣어 모순 확인 |
| A가 오면 B도 온다 | 조건문으로 처리 |
| A와 B 중 정확히 하나 | 둘 중 하나는 참, 둘 다 참/둘 다 거짓 불가 |
| A와 B 중 적어도 하나 | 둘 다 거짓만 불가 |
| A와 B 중 많아야 하나 | 둘 다 참만 불가 |
| A가 B보다 앞선다 | 순서만 확정, 인접 아님 |
| A가 B 바로 앞선다 | 인접까지 확정 |
| A와 B 사이에 하나가 있다 | 거리 조건 |

### 9.3 계산형 문제의 표준 절차

계산형은 산수 문제가 아니라 논리문제다. 먼저 “앵커”를 잡는다.

- 총합
- 비율의 분모
- 단위
- 최댓값 또는 최솟값을 만드는 방향
- 불변량
- 등호가 되는 조건
- 경우를 나누는 기준

### 9.4 계산형 선지 패턴

| 선지형 | 처리 |
|---|---|
| 최대 얼마인가 | 큰 값을 만드는 구조부터 고정 |
| 최소 얼마인가 | 작은 값을 만드는 구조부터 고정 |
| 항상 참인가 | 반례 하나 찾기 |
| 가능할 수 있는가 | 사례 하나 만들기 |
| 평균이 증가했다 | 총합과 개수를 같이 확인 |
| 비율이 증가했다 | 분자와 분모를 분리 |
| 두 배 이상이다 | 정확계산 전 상한·하한으로 컷 |
| 순위가 올랐다 | 값 증가와 순위 증가를 구별 |
| 전체는 감소, 비중은 증가 | 분모 감소 여부 확인 |
| A가 B보다 크다 | 정확값보다 대소관계 먼저 |

## 10. 발문별 풀이 알고리즘

### 10.1 강화 문제

1. 결론 T를 찾는다.
2. T가 조건문, 인과, 일반화, 유비, 규범 중 무엇인지 분류한다.
3. T를 공격할 대안설명을 먼저 예상한다.
4. 선지가 대안설명을 줄이면 강화.
5. 선지가 결과만 반복하면 약한 강화 또는 무관.
6. 선지가 다른 변수의 이야기를 하면 무관.

### 10.2 약화 문제

1. 결론 T를 찾는다.
2. T가 성립하려면 필요한 숨은 전제를 찾는다.
3. 그 숨은 전제를 부정하는 선지를 찾는다.
4. 인과라면 역인과, 공통원인, 표본편향, 측정오류를 먼저 찾는다.
5. 조건문이라면 A인데 B가 아닌 사례를 찾는다.
6. 규범문항이면 적용요건 불충족 또는 예외조항을 찾는다.

### 10.3 필요전제 문제

1. 결론을 찾는다.
2. 선지를 부정해 본다.
3. 부정했을 때 결론이 무너지면 필요전제.
4. 부정해도 결론이 버티면 필요전제 아님.
5. 너무 강한 선지는 대개 오답이다. 필요한 만큼만 있어야 한다.

### 10.4 충분전제 문제

1. 전제와 결론 사이의 빈칸을 찾는다.
2. 선지를 넣었을 때 결론이 반드시 따라오는지 본다.
3. 강해도 괜찮다. 충분전제는 결론을 보장하면 된다.
4. 결론의 주어, 범위, 양상이 그대로 연결되는지 확인한다.

### 10.5 오류 찾기 문제

1. 결론이 무엇인지 찾는다.
2. 전제가 결론을 보장하는지 묻는다.
3. 다음 오류 후보를 체크한다.
   - 필요조건과 충분조건 혼동
   - 역 또는 이 오류
   - 상관을 인과로 오해
   - 원인과 결과 역전
   - 대표성 없는 표본 일반화
   - 평균과 개인 혼동
   - 전체와 부분 혼동
   - 가능을 사실로, 당위를 사실로 바꿈
   - 대안설명 미배제
   - 결론보다 강한 선지 선택

### 10.6 원리 적용 문제

1. 원리의 조건부 구조를 찾는다.
2. 사례가 조건을 충족하는지 확인한다.
3. 예외조건이 있으면 먼저 본다.
4. 가치판단 문구에 끌리지 말고 적용요건을 본다.
5. “해야 한다”, “할 수 있다”, “금지된다”, “허용된다”를 분리한다.

## 11. 마지막 1주 암기표

### 11.1 조건문 10초표

| 보이면 | 즉시 생각 |
|---|---|
| A이면 B | A는 충분, B는 필요 |
| A일 때에만 B | B이면 A |
| 오직 A만 B | B이면 A |
| A하려면 B 필요 | A이면 B |
| B 없이는 A 불가 | A이면 B |
| A만으로 B | A이면 B |
| A하지 않는 한 B | A가 아니면 B |
| 모든 A는 B | A집합은 B 안쪽 |
| 어떤 A는 B | 겹치는 사례 하나 |
| 모든 A가 B는 아님 | A인데 B 아닌 사례 하나 |

### 11.2 양상 10초표

| 보이면 | 주의 |
|---|---|
| 가능하다 | 사실로 바꾸지 말 것 |
| 해야 한다 | 실제로 한다가 아님 |
| 할 수 있다 | 가능·허용·능력 중 문맥분리 |
| 알다 | 사실성을 보통 함축 |
| 믿다 | 사실성 없음 |
| 주장하다 | 사실성 없음 |
| 입증되다 | 증거 강함, 절차 공격 가능 |
| 배제할 수 없다 | 대안 가능성이 남음 |
| 반드시 | 반례 하나면 깨짐 |
| 대체로 | 예외 허용 |

### 11.3 강화·약화 10초표

| 결론 유형 | 먼저 찾을 것 |
|---|---|
| 인과 | 대조군, 역인과, 공통원인 |
| 실험 | 무작위화, 측정민감도, 탈락편향 |
| 일반화 | 표본 대표성, 반례 |
| 조건문 | A인데 B 아닌 사례 |
| 유비 | 결론 관련 유사점·차이점 |
| 설명가설 | 경쟁가설, 새 예측 |
| 규범 | 적용요건, 예외조항 |
| 통계 | 분모, 모집단, 기준시점 |

## 12. 최종 결론

LEET 추리논증 95점권을 목표로 할 때 필요한 것은 많은 기호가 아니라, 자연어를 구조로 바꾸는 안정적인 습관이다. 이 문서에서 반드시 체화해야 할 것은 네 가지다.

1. 조건문은 방향이다. “A이면 B”와 “A일 때에만 B”를 절대 섞지 않는다.
2. 양상은 강도다. 가능, 사실, 지식, 믿음, 의무, 허용, 능력을 섞지 않는다.
3. 강화/약화는 관계다. 결론과 같은 주제인지가 아니라, 결론의 반례·대안설명·적용조건을 건드리는지가 핵심이다.
4. 계산과 그룹도 논리다. 표를 크게 그리기 전에 앵커, 불변량, 극값 방향, 경우분기부터 잡는다.

최종 시험장 문장은 다음 하나로 충분하다.

**“발문을 보고, 타깃 주장을 잡고, 조건·양상·범위를 고정한 뒤, 선지가 반례와 대안설명을 줄이는지 늘리는지만 본다.”**
