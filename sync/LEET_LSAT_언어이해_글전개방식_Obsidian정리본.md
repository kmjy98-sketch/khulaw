# LEET·LSAT 언어이해 글 전개 방식

#LEET #LSAT #언어이해 #독해전략 #글전개 #구조독해

> [!summary] 핵심
> LEET·LSAT 언어이해는 먼저 **정보 흐름형인지 관점 충돌형인지**를 판별한다.  
> 그다음 정보 흐름형이면 **과정·논문·정의·문제해결·역사·모형·해석·법리** 중 어떤 전개 엔진인지 잡는다.  
> 관점 충돌형이면 마지막에 정리한 **대립형 독해 모드**로 전환해 **화자·쟁점·축·저자 태도**를 분리한다.

## 1. 시험장 판별 알고리즘

### 1.1 첫 문단 30초 판별

| 첫 문단 신호 | 전환 모드 | 우선 추적 대상 |
|---|---|---|
| 현상, 원리, 단계, 장치, 반응 | 과정·메커니즘형 | 순서, 조건, 인과, 피드백 |
| 하나의 이론, 개념, 원리 | 단일 이론 전개형 | 핵심 명제, 적용 조건, 한계 |
| 연구, 자료, 실험, 결과, 분석 | 논문형 | 연구 질문, 방법, 결과, 해석 |
| 정의, 유형, 구분, 기준 | 정의·분류형 | 분류 기준, 필요조건, 충분조건 |
| 문제, 한계, 난점, 대안 | 문제해결형 | 문제와 해법의 대응 |
| 과거에는, 이후, 변화, 전환 | 역사발전형 | 변화 계기, 단절, 연속성 |
| 가정, 변수, 모형, 예측 | 모형·가정형 | 가정, 변수, 결론의 의존성 |
| 작품, 해석, 평가, 비평 | 해석·비평형 | 해석 기준, 저자 평가 |
| 원칙, 요건, 예외, 형량 | 법리·규범 적용형 | 요건-효과, 예외, 판단 기준 |
| 그러나, 반면, 비판, A/B 견해 | 대립형 | 화자, 쟁점, 축, 저자 태도 |

> [!tip] 판별 순서
> 1. 대상이 **과정·현상**인지, **견해·논쟁**인지 본다.  
> 2. 문단이 **단계순**, **정의·분류순**, **연구 논문순**, **문제해결순**, **역사순** 중 어디에 가까운지 본다.  
> 3. 두 견해가 본격적으로 충돌하면 즉시 [[#16. 대립형]]으로 전환한다.

### 1.2 독해 중 태깅 규칙

| 유형 | 여백 표기 |
|---|---|
| 과정형 | `A → B → C`, 억제는 `⊣`, 피드백은 `↺` |
| 논문형 | `문제 / 한계 / 방법 / 결과 / 해석 / 함의` |
| 정의형 | `기준1 / 기준2 / 경계사례` |
| 문제해결형 | `문제 P / 원인 C / 해법 S / 조건 K` |
| 역사형 | `1기 / 전환 / 2기 / 현재 의미` |
| 모형형 | `가정 A / 변수 X,Y / 예측 R / 한계 L` |
| 법리형 | `원칙 R / 요건 C / 효과 E / 예외 Ex` |
| 대립형 | `A / B / 저자 / 축` |

### 1.3 문제 유형별 역추적

| 발문 | 돌아갈 위치 |
|---|---|
| 주제 | 도입 문제 + 마지막 결론 |
| 구조 | 각 문단 첫·끝 문장, 전환어 |
| 세부 정보 | 해당 문장 + 바로 앞뒤 조건 |
| 추론 | 명시 문장의 조건·방향·범위 |
| 평가 | 전제, 방법, 자료, 가정, 대안 원인 |
| 적용 | 사례가 어떤 조건·단계·입장에 대응하는지 |
| 약화·강화 | 인과 사슬, 대안 원인, 통제 변수, 적용 범위 |

## 2. 전체 분류 지도

대립형은 다른 전개 방식 위에 덧씌워질 수 있으므로 마지막에 따로 정리한다.

| 번호 | 전개 방식 | 대표 흐름 | 주로 나오는 분야 | 독해 핵심 | 대표 함정 |
|---:|---|---|---|---|---|
| 1 | 단일 이론 전개형 | 현상 → 개념 → 원리 → 적용 → 한계 | 철학, 과학, 사회과학 | 이론의 핵심 명제와 적용 조건 | 적용 범위 과장 |
| 2 | 과정·메커니즘형 | 입력 → 단계 → 변환 → 산출 → 조절 | 자연과학, 기술 | 방향·순서·조건 | 인과 역전, 단계 생략 |
| 3 | 논문형 | 문제 → 선행연구 한계 → 방법 → 결과 → 해석 | 전 분야 | 연구 질문과 결론의 대응 | 자료와 해석 혼동 |
| 4 | 정의·분류형 | 개념 → 기준 → 하위 분류 → 경계 사례 | 법, 철학, 사회과학 | 분류 기준 | 기준 바꿔치기 |
| 5 | 문제해결형 | 문제 → 원인 → 기존 해법 한계 → 새 해법 | 법, 정책, 과학사, 기술 | 문제와 해법의 대응 | 다른 문제를 해결하는 선지 |
| 6 | 역사발전형 | 초기 상태 → 전환 계기 → 변화 → 현재 의미 | 역사, 과학사, 법사, 예술사 | 변화의 원인과 불연속점 | 시대·원인 뒤섞기 |
| 7 | 모형·가정형 | 가정 → 변수 → 작동 → 예측 → 한계 | 경제학, 사회과학, 과학 | 가정과 결론의 연결 | 모형 결론의 현실 일반화 |
| 8 | 해석·비평형 | 대상 → 기존 해석 → 새 해석 → 근거 | 문학, 예술, 역사, 철학 | 해석 기준과 저자 태도 | 작품 사실과 해석 혼동 |
| 9 | 법리·규범 적용형 | 원칙 → 요건 → 사례 → 예외 → 결론 | 법학, 윤리, 정치철학 | 요건-효과, 예외, 형량 | 원칙과 예외 뒤섞기 |
| 10 | 비교읽기·융합형 | A 구조 → B 구조 → 관계 설정 | LSAT 비교읽기, LEET 복합 지문 | 두 글의 관계 | 지시어·관점 혼동 |

## 3. 단일 이론 전개형

### 3.1 기본 흐름

```text
현상/문제 제시
→ 이론의 핵심 개념
→ 이론의 작동 원리
→ 예시/적용
→ 적용 범위·한계
→ 함의
```

### 3.2 문단 역할

| 문단 역할 | 읽을 것 | 메모 방식 |
|---|---|---|
| 도입 | 이 이론이 설명하려는 현상 | `설명 대상 = X` |
| 개념 정의 | 핵심 용어의 의미 | `A = ...` |
| 작동 원리 | 어떤 조건에서 무엇이 발생하는가 | `조건 C → 결과 R` |
| 사례 | 원리의 구체화 | `사례 = 원리의 어느 부분?` |
| 한계·예외 | 적용되지 않는 경우 | `~일 때 불가/약화` |
| 함의 | 이론이 바꾸는 결론 | `기존 이해 수정` |

### 3.3 선지 함정

> [!warning] 함정
> - **적용 범위 확대**: 특정 조건에서만 성립하는 설명을 보편 법칙처럼 만든다.
> - **전제와 결론 전도**: 이론의 전제였던 것을 결론처럼 바꾼다.
> - **예시의 일반화**: 사례 하나를 이론 전체의 필수 조건으로 만든다.
> - **보조 설명의 중심화**: 배경 정보를 중심 주장처럼 만든다.

## 4. 과정·메커니즘형

### 4.1 범용 골격

```text
입력/자극
→ 수용/탐지
→ 매개/전달
→ 변환/처리
→ 출력/반응
→ 피드백/조절
→ 오류/예외
```

### 4.2 읽는 법

과정형에서는 명사보다 **동사, 방향, 조건**이 중요하다.

| 추적 대상 | 질문 | 표기 |
|---|---|---|
| 방향 | 무엇이 무엇을 일으키는가? | `A → B` |
| 순서 | 무엇이 먼저이고 나중인가? | `1, 2, 3` |
| 조건 | 무엇이 있어야 작동하는가? | `C 필요` |
| 억제 | 무엇이 어느 단계에서 막는가? | `X ⊣ Y` |
| 증폭 | 작은 원인이 어떻게 큰 결과가 되는가? | `A ⇑ B` |
| 피드백 | 결과가 다시 원인을 조절하는가? | `R ↺ A` |

### 4.3 대표 함정

> [!warning] 함정
> - **인과 역전**: `A → B`를 `B → A`로 바꾼다.
> - **조건 역전**: 필요조건을 충분조건처럼 만든다.
> - **단계 생략**: 중간 매개 단계를 빼고 직접 원인처럼 만든다.
> - **억제 지점 오류**: 억제제가 실제 작용하는 단계를 바꾼다.
> - **피드백 방향 오류**: 음성 되먹임을 양성 되먹임처럼 처리한다.

## 5. 논문형

### 5.1 표준 흐름

```text
연구 문제/현상
→ 기존 연구·통념
→ 한계·공백
→ 방법·자료
→ 결과
→ 해석
→ 함의·한계
```

### 5.2 하위 유형

| 하위 유형 | 흐름 | 핵심 독해 |
|---|---|---|
| 실증 연구형 | 질문 → 가설 → 자료/방법 → 결과 → 해석 | 자료가 실제로 지지하는 결론의 범위 |
| 실험 연구형 | 가설 → 실험 설계 → 변수 통제 → 결과 | 독립변수·종속변수·통제변수 |
| 이론 논문형 | 기존 개념 → 문제점 → 새 개념/모형 → 귀결 | 정의와 논증 단계 |
| 문헌 검토형 | 선행 견해들 → 공통점/차이 → 평가 | 누가 무엇을 주장했는지 |
| 방법론 논문형 | 기존 방법 한계 → 새 방법 → 절차 → 장점/한계 | 방법이 해결하는 문제 |

### 5.3 문제 포인트

| 발문 유형 | 물어보는 것 | 대응 |
|---|---|---|
| 주제 | 연구자가 결국 보인 것 | `문제-결과-해석` 연결 |
| 구조 | 각 문단의 기능 | 문제/한계/방법/결과/함의 태깅 |
| 추론 | 결과가 함의하는 것 | 자료가 허용하는 범위 안에서만 판단 |
| 약화 | 연구 결론을 흔드는 변수 | 대안 원인, 표본 편향, 측정 오류, 통제 실패 |
| 강화 | 결론을 지지하는 추가 자료 | 같은 방향의 독립적 증거 확인 |

### 5.4 함정

> [!warning] 함정
> - **결과와 해석 혼동**: 관찰된 사실과 연구자의 설명을 섞는다.
> - **상관과 인과 혼동**: 함께 움직임만 보였는데 원인이라고 단정한다.
> - **방법의 한계 누락**: 특정 표본·조건의 결과를 일반화한다.
> - **기존 연구와 저자 입장 혼동**: 선행 연구의 주장을 저자 결론처럼 만든다.

## 6. 정의·분류형

### 6.1 기본 흐름

```text
개념 도입
→ 기존 정의/통념
→ 기준 제시
→ 하위 유형 분류
→ 경계 사례
→ 정의의 의의
```

### 6.2 출제 포인트

정의·분류형은 용어 암기가 아니라 **분류 기준 유지 능력**을 본다.

| 읽을 것 | 질문 |
|---|---|
| 정의의 기준 | A가 A인 이유는 무엇인가? |
| 필요조건/충분조건 | 이 기준이 없으면 A가 아닌가, 이 기준만 있으면 A인가? |
| 경계 사례 | 애매한 사례를 어느 쪽으로 넣는가? |
| 분류 축 | 기준이 하나인가, 둘 이상인가? |
| 예외 | 정의를 수정하게 만드는 사례는 무엇인가? |

### 6.3 함정

> [!warning] 함정
> - **기준 바꿔치기**: 기능 기준을 원인 기준으로 바꾼다.
> - **상위·하위 혼동**: 상위 개념의 특징을 하위 유형 전체에 적용한다.
> - **필요조건의 충분조건화**: `A이려면 B 필요`를 `B이면 A`로 바꾼다.
> - **경계 사례 오독**: 지문이 애매하다고 한 사례를 명백한 사례로 처리한다.

## 7. 문제해결형

### 7.1 기본 흐름

```text
문제/난점
→ 문제의 원인
→ 기존 해법의 한계
→ 새 해법/대안
→ 평가
→ 남은 문제
```

### 7.2 독해 핵심

문제해결형은 반드시 **문제와 해법의 대응**을 확인한다.

| 단계 | 확인 질문 |
|---|---|
| 문제 | 정확히 무엇이 문제인가? |
| 원인 | 그 문제가 왜 생겼는가? |
| 기존 해법 | 무엇을 해결하려 했고 왜 부족했는가? |
| 새 해법 | 어떤 원인을 겨냥하는가? |
| 평가 | 효과, 부작용, 적용 조건은 무엇인가? |

### 7.3 함정

> [!warning] 함정
> - 문제는 `P1`인데 선지는 `P2`를 해결하는 해법을 정답처럼 제시한다.
> - 기존 해법의 한계를 새 해법의 한계로 바꾼다.
> - 해법의 적용 조건을 생략하고 일반 해결책처럼 만든다.
> - 원인을 제거하는 해법과 증상만 완화하는 해법을 섞는다.

## 8. 역사발전형·통시형

### 8.1 기본 흐름

```text
초기 상태
→ 기존 관행/통념
→ 전환 계기
→ 변화 과정
→ 새로운 체계
→ 현재적 의미
```

### 8.2 읽는 법

| 추적 대상 | 질문 |
|---|---|
| 시기 구분 | 몇 단계로 나뉘는가? |
| 전환 계기 | 무엇 때문에 바뀌었는가? |
| 연속성 | 바뀌어도 유지된 것은 무엇인가? |
| 불연속성 | 이전과 근본적으로 달라진 것은 무엇인가? |
| 현재적 의미 | 변화가 지금 어떤 함의를 갖는가? |

### 8.3 함정

> [!warning] 함정
> - 시대 순서를 바꾼다.
> - 후대의 개념을 전대에 투사한다.
> - 변화의 계기를 변화의 결과처럼 만든다.
> - 점진적 변화와 단절적 변화를 혼동한다.

## 9. 모형·가정형

### 9.1 기본 흐름

```text
현실 문제
→ 단순화 가정
→ 변수 설정
→ 모형 작동
→ 예측/결론
→ 가정 완화
→ 한계
```

### 9.2 핵심 독해

모형형에서는 결론이 **가정에 종속**된다. 따라서 가정이 바뀌면 결론도 바뀐다.

| 요소 | 확인 질문 |
|---|---|
| 가정 | 무엇을 단순화했는가? |
| 변수 | 무엇이 증가·감소하는가? |
| 관계 | 변수 사이의 관계는 양/음/비선형 중 무엇인가? |
| 예측 | 모형이 어떤 결과를 예측하는가? |
| 한계 | 현실의 어떤 요소를 배제했는가? |

### 9.3 함정

> [!warning] 함정
> - 가정이 제거된 현실에서도 같은 결론이 나온다고 한다.
> - 모형의 예측을 규범적 주장으로 바꾼다.
> - 변수의 방향을 반대로 읽게 한다.
> - 조건부 결론을 무조건적 결론처럼 만든다.

## 10. 해석·비평형

### 10.1 기본 흐름

```text
대상/작품 제시
→ 기존 해석
→ 기존 해석의 한계
→ 새 해석/평가 기준
→ 근거 분석
→ 의의
```

### 10.2 독해 핵심

| 구분 | 읽을 것 |
|---|---|
| 대상 사실 | 작품·사건·텍스트 자체에 관한 정보 |
| 해석 | 그 사실에 부여한 의미 |
| 평가 기준 | 어떤 기준으로 좋다/문제라고 보는가 |
| 저자 태도 | 기존 해석을 수용, 수정, 반박, 종합하는가 |

### 10.3 함정

> [!warning] 함정
> - 작품 속 사실과 비평가의 해석을 섞는다.
> - 기존 해석을 저자 입장으로 만든다.
> - 평가 기준을 바꿔 결론을 왜곡한다.
> - 저자가 부분 수정한 견해를 전면 부정으로 과장한다.

## 11. 법리·규범 적용형

### 11.1 기본 흐름

```text
원칙/규범 제시
→ 요건 설정
→ 사례 적용
→ 예외 또는 충돌 원칙
→ 형량/조정
→ 결론
```

### 11.2 핵심 독해

법리형은 **요건-효과 구조**와 **예외**가 핵심이다.

| 요소 | 질문 |
|---|---|
| 원칙 | 기본 규범은 무엇인가? |
| 요건 | 어떤 조건을 충족해야 하는가? |
| 효과 | 요건이 충족되면 어떤 법적·규범적 효과가 생기는가? |
| 예외 | 어느 경우에 원칙이 제한되는가? |
| 형량 | 충돌하는 가치 중 무엇을 우선하는가? |

### 11.3 함정

> [!warning] 함정
> - 원칙과 예외의 위치를 바꾼다.
> - 요건 일부만 충족했는데 효과가 발생한다고 한다.
> - 형량 판단을 기계적 규칙처럼 만든다.
> - 사례의 사실관계를 바꿔 원칙을 잘못 적용한다.

## 12. 과학·생명과학 지문 전개 템플릿

과학 지문은 대체로 **과정·메커니즘형**, **논문형**, **모형·가정형**으로 출제된다. 핵심은 지식 암기가 아니라 **흐름, 조건, 변수, 예외**다.

### 12.1 유전자 복제형

```text
DNA 이중나선 풀림
→ 주형 가닥 노출
→ 프라이머 결합
→ 중합효소 작동
→ 상보적 염기 결합
→ 새 가닥 합성
→ 오류 검출·수선
```

| 독해 포인트 | 함정 |
|---|---|
| 어느 가닥이 주형인가 | 원본 가닥과 새 가닥 혼동 |
| 합성 방향과 읽는 방향 | 방향 역전 |
| 프라이머·효소의 역할 | 보조 요소를 핵심 정보처럼 과장 |
| 오류 수선 단계 | 복제와 수선을 같은 단계로 처리 |

### 12.2 유전자 발현형

```text
DNA 정보
→ 전사
→ RNA 형성
→ 가공
→ 번역
→ 단백질 생성
→ 기능 발현
→ 조절
```

| 독해 포인트 | 함정 |
|---|---|
| 유전 정보와 단백질 기능의 연결 | DNA가 직접 기능한다고 표현 |
| 전사와 번역의 구분 | RNA 생성과 단백질 생성을 혼동 |
| 조절 단계 | 발현량 조절과 유전자 자체 변화를 혼동 |
| 돌연변이의 위치 | 변이가 어느 단계에 영향을 주는지 바꿔치기 |

### 12.3 세포 신호전달형

```text
신호 분자
→ 수용체 결합
→ 세포 내 전달
→ 증폭/분기
→ 표적 단백질 활성 변화
→ 세포 반응
→ 음성/양성 피드백
```

| 독해 포인트 | 함정 |
|---|---|
| 신호가 어디서 수용되는가 | 세포막 수용체와 세포 내 수용체 혼동 |
| 전달 경로의 분기 | 한 경로의 효과를 전체 효과로 일반화 |
| 증폭 | 작은 신호가 큰 반응을 만드는 구조 누락 |
| 피드백 | 음성 되먹임과 양성 되먹임 혼동 |

### 12.4 PCR·시퀀싱형

```text
표적 DNA 선정
→ 변성
→ 프라이머 결합
→ 합성/증폭
→ 산물 검출
→ 서열 해석
```

| 독해 포인트 | 함정 |
|---|---|
| 증폭 대상 | 전체 유전체와 표적 구간 혼동 |
| 프라이머 역할 | 프라이머를 결과물로 오해 |
| 검출과 해석 | 검출된 산물과 실제 원인 결론 혼동 |
| 오염·오차 | 방법의 한계 누락 |

### 12.5 과학 지문 공통 여백 표기

```text
현상 X
원인 후보: A / B
방법: M
결과: R
해석: A 지지? B 약화?
한계: L
```

## 13. 통신·정보·공학 지문 전개 템플릿

### 13.1 통신 시스템 기본형

```text
정보원
→ 부호화
→ 변조
→ 채널 전송
→ 잡음/왜곡
→ 수신
→ 복조
→ 복호화
→ 오류 검출·정정
→ 피드백
```

### 13.2 독해 포인트

| 요소 | 질문 |
|---|---|
| 정보원 | 무엇이 원래 메시지인가? |
| 부호화 | 메시지가 어떤 형식으로 바뀌는가? |
| 채널 | 어떤 매체를 통해 전달되는가? |
| 잡음 | 어느 단계에서 오류가 생기는가? |
| 복호화 | 수신자가 어떤 규칙으로 의미를 복원하는가? |
| 오류정정 | 오류를 탐지하는가, 복원하는가? |
| 피드백 | 수신 결과가 송신 방식에 영향을 주는가? |

### 13.3 대표 대립축

| 축 | 구분 | 함정 |
|---|---|---|
| 압축 vs 정확성 | 데이터량 감소와 정보 손실 위험 | 압축을 무조건 품질 향상으로 오해 |
| 암호화 vs 오류정정 | 보안과 복원은 목적이 다름 | 암호화가 오류를 고친다고 오해 |
| 아날로그 vs 디지털 | 연속값과 이산값 | 디지털을 왜곡 없음으로 과장 |
| 중앙집중 vs 분산 | 통제와 안정성의 trade-off | 분산 구조를 무조건 효율적이라고 판단 |
| 피드포워드 vs 피드백 | 사전 조절과 사후 조절 | 피드백 방향 혼동 |

### 13.4 공학 지문 공통 흐름

```text
기존 시스템의 한계
→ 설계 목표
→ 구성 요소
→ 작동 원리
→ 성능 개선
→ trade-off
→ 적용 한계
```

> [!warning] 공학 지문 함정
> 공학 지문은 장점만 묻지 않는다. 거의 항상 **성능 개선의 대가**, 즉 비용·복잡성·오류 가능성·적용 조건을 함께 묻는다.

## 14. 비교읽기·융합형

### 14.1 기본 흐름

```text
A 지문 구조 파악
→ B 지문 구조 파악
→ 공통 주제 확인
→ 차이 나는 쟁점 확인
→ 상호 관계 판단
```

### 14.2 A/B 관계 유형

| 관계 | 설명 | 선지 포인트 |
|---|---|---|
| 보완 | B가 A의 빈 부분을 채움 | B가 A를 부정하는 것은 아님 |
| 반박 | B가 A의 핵심 전제를 공격 | 공격 지점 확인 |
| 적용 | B가 A의 원리를 사례에 적용 | 원칙-사례 대응 |
| 확장 | B가 A의 논의를 더 넓은 범위로 확장 | 적용 범위 변화 |
| 제한 | B가 A의 일반화를 제한 | 조건·예외 확인 |
| 관점 전환 | 같은 대상을 다른 기준으로 봄 | 평가 기준 차이 |

### 14.3 비교읽기 메모

```text
공통 주제: ______
A: 주장 / 근거 / 태도 / 한계
B: 주장 / 근거 / 태도 / A와의 관계
관계: 보완·반박·적용·확장·제한·전환
```

## 15. 최종 체크리스트

### 15.1 기존 정리본 보완 판단

| 항목 | 판단 | 처리 |
|---|---|---|
| 소논문형 vs 대립형 | 유지 | 시험장 1차 판별용으로 사용 |
| 소논문형 | 확장 필요 | 단일 이론형, 과정형, 논문형, 정의형, 문제해결형, 모형형으로 분해 |
| 대립형 | 확장 필요 | 마지막 장에서 변증법·축분류·저자 태도까지 정리 |
| 과학 지문 | 확장 필요 | 유전자 복제, 발현, 신호전달, PCR/시퀀싱 분리 |
| 통신 지문 | 확장 필요 | 부호화, 채널, 잡음, 복호화, 오류정정, 피드백 추적 |
| 논문형 | 반드시 추가 | 문제-방법-결과-해석 구조가 빈출 |
| 법리형 | 추가 권장 | 원칙, 요건, 예외, 형량이 LEET에 중요 |
| 비교읽기 | 추가 권장 | LSAT RC와 LEET 복합 지문 대비 |

### 15.2 최종 압축 공식

> [!quote] 시험장 공식
> **정보 흐름형인가, 관점 충돌형인가?**  
> 정보 흐름형이면 `과정 / 논문 / 정의 / 문제해결 / 역사 / 모형 / 해석 / 법리` 중 하나로 태깅한다.  
> 관점 충돌형이면 `화자 / 쟁점 / 대립축 / 저자 태도`를 분리한다.

### 15.3 회독용 10문항

- [ ] 이 지문은 정보 흐름형인가, 관점 충돌형인가?

- [ ] 각 문단의 기능을 한 단어로 붙일 수 있는가?
- [ ] 조건, 예외, 한계가 표시되어 있는가?
- [ ] 과정형이라면 단계와 방향을 그릴 수 있는가?
- [ ] 논문형이라면 문제-방법-결과-해석을 분리했는가?
- [ ] 정의형이라면 분류 기준이 무엇인가?

## 16. 대립형

대립형은 가장 마지막에 따로 처리한다. 이유는 간단하다. 대립형은 독립 장르이면서 동시에 **논문형, 정의형, 문제해결형, 역사형 위에 겹쳐지는 관점 충돌 구조**이기 때문이다.

### 16.1 대립형 기본 흐름

```text
공통 쟁점 제시
→ 입장 A 제시
→ 입장 B 제시
→ 차이 나는 기준 확인
→ 저자의 평가/종합/유보
```

### 16.2 대립형 즉시 메모

```text
쟁점 Q: ________?
A: 결론 / 근거 / 약점
B: 결론 / 근거 / A 비판점
저자: 지지·비판·중립·종합·유보
축: 보편/특수, 규칙/원리, 실재/구성 등
```

### 16.3 대립형 하위 구조

| 하위 유형 | 흐름 | 핵심 독해 |
|---|---|---|
| 단순 대조형 | A 소개 → B 소개 → 차이 정리 | 비교 기준 |
| 논박형 | A 주장 → A 근거 → B의 반박 → 저자 판단 | 공격 지점 |
| 변증법형 | 정 → 반 → 종합 | 최종 종합이 단순 절충인지 새 기준인지 |
| 정설 수정형 | 기존 통설 → 반례/한계 → 수정 이론 | 기존 견해가 완전히 폐기되는지 부분 수정인지 |
| 다중 관점형 | A/B/C 관점 병치 → 평가 | 관점별 주장 혼동 방지 |
| 양쪽 비판형 | A 비판 → B 비판 → 제3안/유보 | 저자가 어느 쪽도 그대로 수용하지 않음 |
| 조건부 인정형 | A는 조건 X에서, B는 조건 Y에서 타당 | 적용 범위 |

### 16.4 변증법 구조 세분화

| 구조 | 표면 흐름 | 실제 독해 포인트 |
|---|---|---|
| 정-반-합 | A → B → C | C가 A와 B를 어떻게 보존·수정하는지 |
| 문제-대안-수정 | 문제 → 대안 → 대안의 한계 → 수정안 | 최종 입장은 대안 자체가 아니라 수정안 |
| 통념-반례-새 설명 | 통념 → 설명 불가능 사례 → 새 이론 | 반례가 통념의 어느 부분을 깨는지 |
| 양극단 비판-중도 | 극단 A → 극단 B → 조정 | 단순 평균이 아니라 판단 기준 변화 |
| 수준 이동 | 현상 수준 설명 → 구조 수준 설명 | 같은 쟁점을 다른 층위에서 재해석 |

> [!important] 변증법형의 핵심
> 최종 결론은 보통 `A와 B의 중간`이 아니다.  
> 대개는 **쟁점을 다시 정의하거나**, **상위 기준을 도입하거나**, **적용 조건을 나누는 방식**으로 나온다.

### 16.5 대립형 보편 축

| 보편 축 | A 쪽 | B 쪽 | 자주 나오는 함정 |

### 16.7 저자 태도 분류

| 태도 | 신호 | 독해 처리 |
|---|---|---|
| 명시적 지지 | “타당하다”, “설득력 있다” | 저자 입장으로 확정 |
| 부분 인정 | “일부 타당하지만” | 인정 범위와 비판 범위 분리 |
| 반박 | “그러나 이는”, “문제가 있다” | 공격 지점 표시 |
| 종합 | “이를 종합하면” | A와 B 중 무엇을 보존하는지 확인 |
| 유보 | “아직 불분명하다” | 단정적 선지 제거 |
| 조건부 인정 | “~한 경우에는” | 적용 조건이 정답 포인트 |

### 16.8 대립형 선지 소거 순서

1. **주체 오류 제거**  
   A의 견해를 물었는데 B의 말을 섞은 선지를 지운다.

2. **태도 강도 오류 제거**  
   부분 인정인데 전면 찬성·전면 부정으로 과장한 선지를 지운다.

3. **쟁점 이탈 제거**  
   실제 논쟁점이 아닌 내용을 들고 온 선지를 지운다.

4. **적용 범위 오류 제거**  
   특정 조건의 주장을 일반 명제로 만든 선지를 지운다.

5. **최종 입장 확인**  
   마지막 문단에서 저자가 합·유보·조건부 인정을 했는지 확인한다.
