- **3단계 대응 플로우** (부당특약 무효 → 이행불능 → 사정변경 해지)
- **율촌 매핑**: 부동산·건설 그룹 정원 변호사(국방부조달본부·방위사업청 출신·《공공조달계약법》 2016 저서) / 송광석 변호사(국방부 송무팀장 출신)

- **판례 통합**: 대법원 2025마6793 결정 / 대법원 2009. 1. 30. 선고 2006다31269 / 서울중앙지법 2020가합503239 (총 3건)
- **최신 입법 추적**: 2026. 3. 6. 시행 제3차 상법 개정 / 2026. 4. 2. 대법원 결정 / 2026 정기주총 정관 개정 통계 (코스피200 27개사 / 평균 찬성 88.7%)

## §III. §IV 재작성안 — 3개 후보

### 후보 A — 짧은 버전 (~700자)

**구조**: 도입 1문장 + 발제 통합 1단락 + 율촌 직결 결론 1문장

```
IV. 두 발제 — 다층 법리 통합 분석으로 공공계약 전문성을 다지다

기업금융법학회·규제법학회 활동을 통해 두 영역에서 발제·연구 경험을 누적했습니다.
두 발제는 "이해관계자 권리의 공정 분배 + 절차적 통제 장치"라는 공통 분석 틀을 공유합니다.

첫 번째 발제는 군부대 민간위탁 급식 용역의 전시 계속이행 조항을
헌법 §12·근로기준법 §7·산업안전보건법 §51·§52 ④·민법 §390 단서·국가계약법 §5·국방부 계약업무처리훈령 §44·통합방위법·행정기본법 §27 등 13개 법령과
대법원 96다34061·2012다74076 전원합의체·2020다254846·2023다269139 등 판례 7건을 통합 적용하여,
'부당특약 무효 선언 → 이행불능 선언 → 사정변경 해지'의 3단계 대응 플로우로 정리했습니다.

두 번째 발제는 2026. 3. 6. 시행된 제3차 상법 개정의 자기주식 소각의무 신설(상법 §341의4)과
대법원 2026. 4. 2. 자 2025마6793 결정을 분석하여, 적대적 M&A 방어 체계의 변동을 짚었습니다.
황현영 자료(2026 상사법학회 춘계학술대회) 등 1차 출처를 검증하여
코스피200 27개사 정관 개정 평균 찬성 88.7%의 시장 반응을 분석했습니다.

이러한 다층 법리 통합·1차 자료 검증 능력을 율촌의 부동산·건설 그룹과 기업법무·금융 그룹·공정거래 그룹의 결합 자문 사안에서 즉시 적용하고자 합니다.
```

→ **약 720자**. 핵심 발췌 + 율촌 직결 결론.
→ 강점: 간결·정량 근거(법령 13개·판례 7건·통계)
→ 약점: 두 발제의 학술적 깊이가 상대적으로 짧음

### 후보 B — 표준 버전 (~1,050자) ★ 추천

**구조**: 도입 + 공통 분석 틀 + 군부대 발제 1단락 + 자사주 발제 1단락 + 율촌 직결 결론

```
IV. 다층 법리 통합과 최신 입법 추적 — 공공계약 전문성의 기반

기업금융법학회·규제법학회 활동을 통해 두 영역에서 발제·연구 경험을 쌓아 왔습니다.
두 발제는 "이해관계자 권리의 공정 분배"와 "절차적 통제 장치"라는 공통 분석 틀을 공유하며,
이는 공공계약 분쟁이 행정·민사·헌법 영역에 걸쳐 어떻게 작동하는지를 통합적으로 보여줍니다.

군부대 민간위탁 계약의 전시 계속이행 조항 발제에서는 13개 법령과 7건의 판례를 통합 적용했습니다.
헌법 §12 강제노역 금지·근로기준법 §7·산업안전보건법 §51·§52 ④의 작업중지 의무가
국가계약법 §5의 부당특약 무효(대법원 2017. 12. 21. 선고 2012다74076 전원합의체) 법리와 결합되고,
민법 §390 단서의 이행불능과 사정변경 4요건(대법원 2007. 3. 29. 선고 2004다31302)을 통해
'부당특약 무효 선언 → 이행불능 선언 → 사정변경 해지(대법원 2020. 12. 10. 선고 2020다254846 원용)'의
3단계 대응 플로우를 도출했습니다. 통합방위법·징발법·행정기본법 §27을 결합하여
전시 군수지원의 1차 책임자가 국가임을 입법체계로 입증한 점은 율촌 부동산·건설 그룹의 국방·방위사업·공공계약 자문 영역과 직접 맞닿아 있습니다.

자사주·고려아연 발제에서는 2026. 3. 6. 시행된 제3차 상법 개정의 자기주식 소각의무 신설(§341의4)과
2026. 4. 2. 자 대법원 2025마6793 결정을 즉각 분석했습니다.
상호주 의결권 제한(상법 §369 ③) 적용 자회사 범위에 손자회사 의제(상법 §342의2 ③)를 결합하여
고려아연 → 선메탈홀딩스 → SMC → 영풍 순환 출자 구조에서 영풍 보유 고려아연 주식의 의결권 상실을 도출했습니다.
황현영 「자기주식 제도 개선 배경과 쟁점」(2026 상사법학회 춘계학술대회) 자료와
한국경제·정책브리핑 등 1차 출처를 검증하여, 코스피200 27개사 정관 개정 평균 찬성 88.7%의 시장 반응을 분석했습니다.

이러한 다층 법리 통합·최신 입법 추적·1차 자료 검증 능력을
율촌 부동산·건설 그룹의 공공조달계약 자문, 기업법무·금융 그룹의 회사법 자문,
공정거래 그룹 기업결합규제대응팀의 신고 자문이 결합되는 사안에서 즉시 적용하고자 합니다.
```

→ **약 1,050자**. 두 발제 균형 + 율촌 4그룹 직결.
→ 강점: 정량 근거(13개 법령·7건 판례·코스피200 27개사 통계) + 율촌 4그룹 매핑 + draft v1 framework 통합
→ 추천 이유: 율촌 5장 안팎 가이드 안에서 §IV가 적정 비중(~20%)

### 후보 C — 강조 버전 (~1,300자)

**구조**: 후보 B + 학술대회 참관 + 사전 게임 정책 통찰

```
IV. 두 영역의 다층 법리 통합 — 율촌 4그룹 협업 자문에 즉시 투입할 토대

기업금융법학회·규제법학회 활동을 통해 행정·공공계약과 회사법·M&A 두 영역에서 발제·연구를 누적했습니다.
2026 상사법학회 춘계학술대회를 참관하여 황현영 「자기주식 제도 개선 배경과 쟁점」 등 학계 최신 동향을 직접 접한 후
이를 자체 발제에 통합하는 학습·실무 결합 패턴을 형성했습니다.

두 발제는 "이해관계자 권리의 공정 분배"와 "절차적 통제 장치"라는 공통 분석 틀을 공유합니다.

[병사식당 민간위탁 발제 — 13개 법령·7건 판례 통합]
군부대 민간위탁 계약의 전시 계속이행 조항을 분석한 발제에서는,
헌법 §12 강제노역 금지·근로기준법 §7·산업안전보건법 §51·§52 ④의 작업중지 의무가

'①부당특약 무효 선언 → ②이행불능 선언 → ③사정변경 해지(대법원 2020다254846 원용)'의 3단계 대응 플로우를 도출했습니다.
통합방위법·징발법·행정기본법 §27을 결합하여 전시 군수지원의 1차 책임자가 국가임을 입법체계로 입증했고,
계약 체결 단계의 면책 조항·국가의 대체 인력 공급 의무·비상 식재료 현물 제공 규정의 사전 협의를 통한
구조적 패러다임 재설계를 정책 제언으로 도출했습니다.
이는 율촌 부동산·건설 그룹의 정원 변호사가 다루어 온 국방·방위사업·공공계약 영역과 직접 맞닿아 있습니다.

[자사주·고려아연 발제 — 6개 조문·3건 판례 + 시장 분석]
2026. 3. 6. 시행된 제3차 상법 개정의 자기주식 소각의무 신설(§341의4)과
2026. 4. 2. 자 대법원 2025마6793 결정을 즉각 분석했습니다.

고려아연(100%) → 선메탈홀딩스 → SMC(10.33%) → 영풍(25.42%) → 고려아연 순환 출자 구조에서
영풍이 보유한 고려아연 주식의 의결권 상실을 도출했습니다.
의결권 제한이 감사 선임(§409)·집중투표(§382의2·§542의7)·감사위원 분리선임(§542의12) 분모·분자에 미치는 효과까지 추적했고,
황현영 자료·한국경제·정책브리핑 등 1차 출처를 검증하여

이를 토대로 "자사주를 둘러싼 경영권 공방의 무대가 분쟁 발생 후 사후적 방어 게임에서 평시 정관 개정 단계의 사전 게임으로 전환되었다"는 정책 통찰을 도출했습니다.
```
