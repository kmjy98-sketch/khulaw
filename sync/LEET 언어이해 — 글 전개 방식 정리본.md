
> 📖 **용도** — 시험 전 가볍게 읽고, 실제 지문을 풀 때 머릿속에서 바로 꺼내 쓰는 실전 매뉴얼. 글을 만나면 "이 글이 어떤 틀로 전개되는가"를 먼저 식별하고 그 틀에 맞는 독해 전략으로 전환하는 것이 목표다. **내용 암기가 아니라 구조 식별이 핵심.**

1. 첫문제 선지, 통해서 유형 파악
2. 글 독해하면서 선지 찾기
3. 첫 문제 끝나면 두번째 문제 보면서 나머지 지문 읽기
4. 전체 지문 읽고 사례 주는 거 지문 어디에 해당하는 지 보고 추리논증식으로 정리

## 0. 큰 분류 — 글은 두 가지로 갈린다

LEET 언어이해 지문은 학문 분야가 무엇이든 **전개 방식**으로는 크게 두 가지다.

||**소논문형 (과정·이론 전개)**|**대립형 (변증법)**|
|---|---|---|
|**다루는 것**|객관적 현상·메커니즘·하나의 이론이 어떻게 작동하는가|주관적 관점들이 충돌·평가·수렴하는가|
|**자주 나오는 분야**|자연과학, 기술|인문학, 사회과학, 철학적 법학|
|**추적할 것**|정보의 **방향**(원인→결과, 단계 순서)|**화자**(누가 무엇을 주장하는가)|
|**결정적 신호어**|"때문에, 결과적으로, 유발한다, 다음 단계"|"그러나, 비판하는, 전통적으로, 옹호한다"|
|**최악의 함정**|**인과 역전**(결과를 원인이라 뒤집음)|**관점 혼동**(A 주장에 B 전제를 섞음)|

식별은 **첫 한두 문단**에서 끝낸다. 학자 이름·대립 어휘가 나오면 대립형, 현상·과정·단계가 나오면 소논문형이다.

### 보조 유형 — 알아두면 당황하지 않는 것

실제로는 위 둘이 대부분이지만, 변형 두 가지를 알아두면 좋다.

- **융합형**: 한 지문 안에 두 틀이 섞인다. 흔한 형태는 ① **대립 구도를 깔고 그 안에서 메커니즘을 설명**(예: 두 학파가 대립하는데, 그 쟁점이 특정 과정의 작동 방식), ② **앞부분은 이론을 전개하고 뒷부분에서 비판·대안이 등장**(소논문형 → 대립형). 식별되면 **앞 틀로 읽다가 전환 신호어("그러나", "비판이 제기된다")에서 틀을 바꾼다.** 최근 경향상 분야 융합 지문이 늘어 너무 칼같이 나눌 필요는 없다.
- **단일 견해 심화·통시형**: 대립 없이 **하나의 입장이나 현상을 시간순·논거 누적으로 파고드는** 글(법리의 역사적 변천, 한 사상가의 체계 등). 소논문형의 인문·사회 버전으로 보면 된다. 추적할 것은 "어떤 근거가 어떤 순서로 쌓이는가"와 "저자의 최종 입장".

## 1. 소논문형 표준 템플릿 — 명사가 아니라 동사를 좇는다

소논문형의 가장 큰 장벽은 **쏟아지는 전문용어**다. 핵심 원리는 단순하다.

> **전문용어(명사)는 기호로 치환하고, 동사·관계연산자에 마킹한다.** 예: "Phytoflagellum Florenza" → 그냥 'PF'. 뜻은 몰라도 된다. 중요한 건 PF가 **무엇을 하는가**(동사), **무엇 다음에 오는가**(순서), **무엇이 있어야 작동하는가**(조건)다.

LSAT은 양자역학이나 유전공학 **지식**을 묻지 않는다. 지문이 깔아놓은 **규칙을 논리 게임의 조건절처럼** 받아들여 연역하는지를 본다.

### 범용 골격 (모든 과정형에 공통)

어떤 메커니즘이든 아래 단계 중 일부로 환원된다. 여백에 이 흐름을 화살표로 그린다.

>[!note] 출발점 → 감지/수용 → 매개(전달) → 변환 → 산출(결과) → 조절 → 이상(고장 지점)

### 정보 흐름의 4가지 기본 관계

지문이 정보를 잇는 방식은 대개 넷 중 하나다. 이걸 알면 다음 문장을 예측하며 읽게 된다.

1. **인과** — X가 Y를 일으킨다 (그리고 Z는 작용하지 않는다)
2. **연쇄(단계)** — 1단계가 끝나야 2단계가 시작된다
3. **조건/위계** — A는 B의 필수조건이나, B는 C 없이도 성립한다 _(필요조건 ≠ 충분조건 구분이 함정)_
4. **기능적 유추** — X가 A에서 하는 역할 = Y가 B에서 하는 역할

### 소논문형이 노리는 두 함정

- **인과 역전**: 지문은 [원인 → 결과]를 깔았는데, 오답은 방향을 슬쩍 뒤집는다. 단어 조합이 본문과 완벽히 일치해도 **방향이 틀리면 오답.** → 읽으면서 인과에 **화살표 방향**을 반드시 메모.
- **약화 문항의 대안적 원인**: 지문이 "A 때문에 D가 일어났다"고 단정하면, 출제자는 "사실 X 때문이었다"는 **다른 원인**을 던져 약화시킨다. → A→D 사슬을 보면 **"이걸 무너뜨릴 제3의 원인은?"**을 미리 상상.

>[!note] 💡 **인과 결론 공략 5법** — ① 대안 원인 제시 ② 원인 있는데 결과 없음 ③ 결과 있는데 원인 없음 ④ 인과 방향 역전 ⑤ 근거 데이터 결함. 약화·강화 문항은 거의 이 다섯 안에서 움직인다.

## 2. 빈출 메커니즘별 흐름 패턴

표준 템플릿이 실제로 어떻게 나타나는지 유형별로 정리한다. **메커니즘을 배우는 게 아니라 흐름 골격과 함정만** 익힌다.
### ⓐ 유전자 복제·시퀀싱 (단계별 인과 연쇄)

대표: 생어 염기서열 분석법(Sanger). 목적(서열 분석)을 위한 **방법론적 절차**를 서술하는 전형.

>주형 DNA 준비 → 정상 재료(dNTP)에 '종결자'(ddNTP) 소량 섞음
→ 합성 중 종결자가 무작위로 끼면 그 지점에서 사슬 성장 중단
→ 길이가 제각각인 조각들 생성 → 길이순 분리 → 끝 지점 역추적해 서열 확인

- **핵심 논리**: "종결자가 결합하면 거기서 멈춘다"는 **한 줄 규칙**이 전부. 이걸 조건으로 연역.
- **발문 예시**: "특정 종결자만 투입하면 조각들의 공통점은?", "상보결합(A-T, G-C) 규칙으로 추론되는 원래 서열은?"
- **틀로 일반화**: '정상 흐름 + 의도적 개입 변수 → 그로 인한 결과'. 개입 변수가 어디서 무엇을 막는지가 논리의 심장.
### ⓑ 신호 전달 (방향성 추적형)

대표: Wnt/Wingless 농도구배. **인과의 방향**을 정확히 읽는지를 가늠하는 단골.

>특정 세포군이 신호 단백질 분비 → 조직으로 퍼지며 농도 차이(구배) 형성
→ 농도 높낮이에 따라 세포마다 다른 유전자 발현 → 조직 형태 결정

- **핵심 함정**: [분비/분포(원인) → 농도구배(결과)]인데, 오답은 "농도구배 때문에 분포가 생겼다"로 **역전**시킨다.
- **읽기 전략**: 명사 뜻 추적 금지. **원인↔결과를 잇는 연산자("때문에", "유발")에 마커**를 칠하고 벡터 방향을 고정.
### ⓒ 패러다임 전복형 (정설 → 변칙 → 새 메커니즘)

대표: 프리온/CJD. **고전적 수사학적 반전** 구조. — _실제 LSAT 기출(PrepTest 70)._

>배경 정설: "모든 병원체는 핵산(DNA/RNA)을 가진다"고 널리 가정됨
→ 변칙: CJD 감염원에서 핵산이 발견되지 않음 (가정이 깨짐)
→ 새 메커니즘: 잘못 접힌 단백질(프리온)이 정상 단백질을 같은 형태로 변형시켜 전파

- **구조 표지판**: **"가정되었다", "전통적으로 믿어졌다"** — 이 표현이 보이면 곧 그 가정이 **거짓으로 뒤집힐** 것이라는 예고. 가장 강력한 구조 신호어.
- **발문 예시**: "프리온 가설이 참일 때 가장 강하게 지지되는 진술은?" → 정답은 연역적: **"병원체가 번식에 반드시 핵산이 필요한 건 아니다"**(기존 전제의 부정).
- **틀로 일반화**: 인문·사회·과학 어디서나 통용. "오래 믿어진 X → 반례 → X의 수정/폐기".
### ⓓ 거시 인과 연쇄 (도미노형)

대표: CFC에 의한 오존층 파괴. **단일 원인 → 단계적 결과**의 직선 사슬. — _실제 LSAT 기출(PrepTest 78, Molina·Rowland)._

>CFC가 안정해서 성층권 도달 → 자외선이 분해 → 염소 원자 방출
→ 염소가 오존을 산소로 분해 (염소는 소모 안 되고 촉매로 재사용 → 무한 반복)

- **핵심 포인트**: 염소가 **촉매로 재생**된다는 점(원자 하나가 오존 수만 개 파괴). 이 '자기재생' 고리가 논리의 핵심.
- **약화 전략**: 지문이 A→B→C→D 단선 인과를 깔면, **대안 원인**(예: "그 시기 대형 화산 폭발로 성층권에 오존 파괴 물질이 대량 유입")을 던지는 선지가 정답. CFC의 독점적 인과력을 깨뜨림.
### ⓔ 그 외 빈출 메커니즘 — 골격만

세부는 달라도 **표준 골격(출발→수용→전달→반응→종료/조절)**의 변형이다.

- **효소·대사형**: 기질 → 활성부위 결합(특이성) → 에너지 장벽 낮춤 → 생성물 / _병목 단계_가 전체 속도 결정 / 억제제·활성제가 어디 작용하는지가 포인트
- **항상성·되먹임형**: 기준값 이탈 → 감지 → 보상 반응 → 회복(**음성 되먹임**) / 예외적으로 반응이 증폭되면 **양성 되먹임** / "되먹임 방향"이 함정
- **면역형**: 항원 인식 → 항원 제시 → T·B세포 활성화 → 공격(항체·세포독성) → **기억**(재감염 시 빠른 반응) / 과잉 시 알레르기·자가면역
- **신경전달형**: 전기신호(활동전위) → 축삭 말단 도달 → 칼슘 유입 → 신경전달물질 방출 → 다음 세포 수용체 결합(흥분/억제) → 재흡수·분해로 종료 / "전기→화학→전기" 전환이 핵심
- **기술 시스템형**: 입력 → 센서 감지 → 처리(알고리즘·회로) → 출력 → **피드백**(출력이 입력 조절에 재사용) → 오류(노이즈·지연·손실)가 어디서 생기나

## 3. 대립형 표준 템플릿 — 화자를 분리한다

>대립형은 상충하는 둘 이상의 관점이 충돌·평가되며 수렴하거나 논쟁으로 남는 **변증법적** 흐름이다. 법조 실무가 원고 vs 피고, 검찰 vs 변호인의 대립 논증이라는 점에서 시험의 정수.
### 변증법 3구조 (정·반·합)

실제 LSAT 독해 교육(Blueprint)에서 쓰는 분류다. 관점 수와 저자 개입으로 가른다.

1. **정(Thesis) — 단일 관점**: 도입부에 하나의 주요 관점 제시. 저자가 이를 지지하거나 외부 비판으로부터 방어하며 근거를 쌓는다.
2. **반(Antithesis) — 이중 관점**: 대립하는 두 관점 제시. 저자는 ① 한쪽 편들기 ② 반대쪽 편들기 ③ 중립적 관찰(논쟁 과정만 서술) 중 하나의 역할.
3. **합(Synthesis) — 제3의 종합**: 지배적 관점(정) → 비판/새 데이터(반) → 저자가 양쪽을 부분 수용·기각하며 **새 차원의 대안(합)** 제시. _예: 세포학 vs 생화학이 충돌하다 '분자유전학'으로 수렴 — 실제 LSAT 기출._
### VIEWSTAMP — 대립형에서 추적할 6요소

PowerScore의 표준 방법론. 읽으면서 이걸 추적하면 출제 포인트를 놓치지 않는다.

- **V**iewpoints (관점): 등장하는 모든 목소리(저자·비평가·전통주의자…)를 식별하고 **새 관점이 도입되는 전환점**을 표시. 문제 대부분이 여기서 나온다.
- **S**tructure (구조): 단락마다 무슨 성격의 정보(배경·반론·예시)인지 지도화.
- **T**one (어조): 저자가 중립적 관찰자인지, 냉소적 비판자인지, 열렬한 지지자인지 — 형용사·부사가 단서.
- **A**rguments (논증): 각 주체의 **전제와 결론을 분리**해 인식.
- **M**ain **P**oint (중심 주장): 특정 단락에 치우치지 않은 지문 전체의 결론.
### 이항대립 스키마 (LEET 실전)

이원준 강사 방법론. 인지심리학적으로, 작업기억은 정보를 낱개로 기억하면 과부하된다. 복잡한 학자들의 주장을 **[A vs ~A]** 이분 구조로 재조직하면 부담이 급감한다.

- 두 진영이 쓰는 **대립 어휘 세트**를 분류하면, 개념의 사전적 뜻을 몰라도 누가 누구를 비판하는지 도식화된다.
- **관점 혼동 함정 방어**: "갑(A)의 주장은?"을 묻는 문제에 을(B)·병(C)의 전제를 섞은 매력적 오답을 **기계적으로 소거**. 비판 주체가 지정된 문제는, 타당성을 따지기 전에 **그 주체의 입장이 아닌 선지부터 제거**.
### 대립형이 노리는 함정

**관점 혼동**: A 학자의 주장을 묻는데 B의 전제를 슬쩍 섞는 것. attitude·관점 문항의 가장 흔한 오답. → 여백에 **[A: …] [B: …] [저자: …]**로 화자별 입장을 분리 기록하면 방어된다.

## 4. 대립형에 따른 축 분류 — 결국 오래된 대립축의 변형

대립형 지문은 **인류 지성사에서 반복돼 온 대립축 하나를 구체적 사례에 투영한 것**이다. 축을 알아보면 "A 관점에서 B를 비판하면?" 같은 추론이 곧바로 풀린다. 아래는 분야별 핵심 축의 인덱스다. (상세 학자 계보·예시는 별도 「축 중심 검토본」 참조.)

**■ 철학·인식론**

| 축      | 한쪽 ↔ 다른 쪽                                       |
| ------ | ----------------------------------------------- |
| 존재론    | 실재론(**보편이** 실재) ↔ 유명론(보편은 이름뿐, **개인,특수**)       |
| 인식론 기본 | 합리론(**이성**·선험) ↔ 경험론(**감각**·후험)                 |
| 인식론 심화 | 토대주의(기초 신념 위 건축물) ↔ 정합주의(신념의 그물망)               |
| 지식의 정의 | JTB(정당화된 참인 믿음) ↔ **게티어 반례**(JTB여도 지식 아닐 수 있음)  |
| 심신문제   | **이원론**(정신≠물질) ↔ **물리주의**/기능주의(정신=뇌상태·기능)       |
| 자유의지   | **결정론** ↔ **자유의지** ↔ **양립가능론**(둘 다 성립)          |
| 언어철학   | 기술주의(**의미=속성묶음**) ↔ 지시주의(이름=**고정지시어**)          |
| 해석학    | **저자** 의도 ↔ **텍스트** 구조 ↔ **독자** 수용 (의미는 어디서 오나) |

**■ 윤리·규범철학**

| 축      | 한쪽 ↔ 다른 쪽                                   |
| ------ | ------------------------------------------- |
| 옳음의 근거 | 의무론(**행위** 자체) ↔ 공리주의(**결과**) ↔ 덕윤리(**품성**) |
| 판단 방식  | 보편주의(**원칙** 적용) ↔ 도덕 특수주의(**맥락마다** 다름)      |
| 가치     | 공리(**전체 행복**) ↔ 권리(**침해 불가능한 개인 권리**)       |

**■ 법학·법철학**(대충봐)

| 축      | 한쪽 ↔ 다른 쪽                                                      |
| ------ | -------------------------------------------------------------- |
| 법의 본질  | 자연법(**법=도덕** 연결) ↔ 법실증주의(**분리테제**)                             |
| 판결론    | 형식주의(**기계적** 삼단논법) ↔ 현실주의(**판사 성향** 우선)                        |
| 헌법·사법권 | 사법적극주의(**적극 해석**) ↔ 사법소극주의(**입법부** 존중)                         |
| 해석 방법  | **문언**(법문 그대로) ↔ **목적**(입법 취지) / **규칙**(요건-효과) ↔ 원리(**가치 형량**) |
| 가치 형량  | 법적 **안정성**(예측가능성) ↔ 구체적 **타당성**(개별 정의)                         |

**■ 경제·정책**

| 축       | 한쪽 ↔ 다른 쪽                                  |
| ------- | ------------------------------------------ |
| 시장관     | 시장효율(**가격기구**) ↔ 시장실패(**정부 개입** 필요)        |
| 인간관     | **완전합리성**(호모 에코노미쿠스) ↔ **제한된 합리성**(만족화)    |
| 정보      | **완전정보** ↔ **정보비대칭**(역선택·도덕적 해이) / 신호 ↔ 선별 |
| 가치      | **효율성**(전체 후생) ↔ **형평성**(분배·공정)            |
| 외부효과 해법 | 피구세(정부 과세) ↔ 코즈(권리 설정·협상)                  |

**■ 정치·사회**

| 축      | 한쪽 ↔ 다른 쪽                             |
| ------ | ------------------------------------- |
| 정치철학   | 자유주의(**무연고적** 자아) ↔ 공동체주의(**연고적** 자아) |
| 분석 단위  | 방법론적 개인주의 ↔ 전체주의(사회실재론)               |
| 국제정치   | **현실주의**(세력 균형) ↔ **자유주의**(국제기구·상호의존) |
| 사회선택   | 개인 선호 ↔ 집합 결정 (**애로우 불가능성**·순환·전략투표)  |
| 사회 작동  | 기능(통합 기여) ↔ 갈등(불평등 재생산)               |
| 불평등 원천 | **경제자원** ↔ **문화자본**·상징권력              |

**■ 과학·자연**

| 축      | 한쪽 ↔ 다른 쪽                                     |
| ------ | --------------------------------------------- |
| 과학철학   | 실재론(**이론=진리**) ↔ 반실재론/도구주의(**이론=예측 도구**)      |
| 과학의 변화 | 귀납적 **축적** ↔ **반증**(포퍼) ↔ **패러다임** 전환(쿤)      |
| 귀납의 문제 | **귀납 정당화** 가능 ↔ **흄의 회의**(과거가 미래를 보장 못 함)     |
| 시스템론   | **환원주의**(부분으로 분해) ↔ **창발주의**(전체는 부분합 이상)      |
| 진화론    | 계통점진주의(연속 축적) ↔ 단속평형설(정체 후 폭발)                |
| 기술관    | **기술결정론**(기술이 사회 지배) ↔ 사회구성론(SCOT, 사회가 기술 주조) |

**■ 역사·예술**

| 축      | 한쪽 ↔ 다른 쪽                    |
| ------ | ---------------------------- |
| 역사 변화  | 사건사(인물·사건) ↔ 구조사(장기 구조)      |
| 역사 서술  | **객관적 복원** ↔ **서술자 관점**의 구성  |
| 예술 본질  | 모방론 ↔ 표현론 ↔ 형식론 ↔ 제도론        |
| 예술 자율성 | 자율성(독립적 형식) ↔ 사회성(역사·정치와 연결) |

>[!note] **읽는 법**: 지문에서 두 진영이 보이면 → 위 표에서 어느 축인지 매핑 → 그 축의 전형적 쟁점("무엇을 기준으로 갈리는가")을 떠올리면 → 저자가 어느 쪽인지, 혹은 종합하는지를 빠르게 포지셔닝. 
**세 입장(↔↔)이 있는 축**(윤리 3분, 과학 변화 3분, 해석학 3분)은 LEET에서 특히 선지 함정이 잦으니 **셋을 명확히 분리**할 것.

## 5. 분야별 빈출 전개 템플릿 (경험적 경향)

각 분야가 자주 취하는 전개 틀이다. **공식 분류가 아니라 경향**이니 참고만.
****
- **법철학**: 정설(기존 법리) → 비판/한계 → 재구성·대안. _현행법이 무엇인지 vs 저자가 어떠해야 한다고 주장하는지 구분이 핵심 함정._
- **과학사**: 기존 이론 → 변칙 사례 → 새 패러다임 (= 패러다임 전복형)
- **경제·사회과학**: 중심 주장 + 근거 데이터 + 경쟁 관점. (모델→가정→반례→수정 형태도 있으나 고정은 아님)
- **자연과학(과정)**: 현상 → 메커니즘 단계 서술 → (때로) 인과 약화 문항 대비
- **인문·예술**: 단일 견해 심화 또는 두 해석의 대립. 의미가 저자·텍스트·독자 중 어디서 오는가가 단골 쟁점.
- **Q&A 구조**: 분야 불문 흔함 — 지문이 질문을 던지고 답하는 형태. 질문이 곧 중심 주장의 위치.

## 6. 두 유형 비교 + 비교읽기

### 핵심 비교표

| 차원         | 대립형 (변증법)                 | 소논문형 (과정·이론)                |
| ---------- | ------------------------- | --------------------------- |
| **평가 대상**  | 주관적 **관점·이념**적 마찰         | 객관적 현상·**인과 연쇄**            |
| **맵핑 전략**  | **화자 분리**                 | **정보 방향(**원인→결과) 추적         |
| **신호어**    | "그러나, 비판하는, 전통적으로, 옹호한다"  | "따라서, 그 결과, 유발한다, 다음 단계"    |
| **최악의 함정** | **관점 혼동** (A에 B 전제 섞기)    | **인과 역전** (결과를 원인이라 뒤집기)    |
| **돌파 전략**  | 이항대립 **구조화** + 저자 입장 포지셔닝 | **조건 사슬**(A→B→C) + 대안 원인 탐색 |

### 비교읽기

두 저자의 짧은 글 두 개가 묶여 나온다. 관계는 ① 동의 ② 정면 대립 ③ 한쪽이 원칙 제시·다른 쪽이 적용 등 다양.

- **최대 함정**: **참조 실패 + 근접성 편향**. "이 과정", "전자의 이론" 같은 지시어가 남발되는데, 뇌는 시간 압박 속에 **가장 가까운 명사**를 가리킨다고 착각한다. → 지시어가 정확히 무엇을 가리키는지 확인.
- **독해 순서**: 두 지문을 한 번에 읽고 문제로 가지 말 것. **첫 지문을 철저히 읽고 단락 역할을 여백에 태깅** → 두 지문의 관계를 염두에 두며 둘째 지문 읽기. 교차 지문 추론(A의 틀을 B의 사례에 적용)이 핵심.

>[2] **유형별 마킹**
    대립형: 여백에 [A vs B vs 저자] 화자 분리

>[3] 발문에서 **함정 대비**
    대립형: "이 주장의 주체가 누구?" → 관점 혼동 소거
    소논문형: "약화?" → 대안 원인 / 인과 방향 재확인
