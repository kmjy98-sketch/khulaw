## 2. 예선 당일 — 단계
1. **사건기록(PDF/HWP) + 문제 지시문 받기.** 지시문에서 *서면 종류·당사자 지위·분량·형식·제출방법*을 먼저 확인.
2. **기록을 한 폴더에 모으기**: 예 `7.대회/ai 대회/기록/{사건번호 사건명}/` (PDF·HWP 그대로, 폴더명에 대괄호 금지).
3. **E:\khulaw에서 Claude Code 실행** (구글드라이브 H: 대신 — 오프라인·싱크 안전).
4. **이렇게 지시**(경로·옵션만 바꿔서):
   > "START_HERE 읽고, `7.대회/.../기록/{사건}` 기록형 풀어줘. 서면=참고서면, 지위=원고측, 분량·형식=지시문대로(A4 ○매)."
   → 스킬이 자동: 추출(pdfplumber) → 사실정리 → 쟁점·조문·판례(MCP 검증) → 서면 작성 → 논리·포섭 5축 검토.
5. **중간 검토 (내가 직접 — 가장 중요)**:
   - "초기자료 보여줘" → 사실관계·쟁점표가 맞는지 확인
   - 판례·조문에 **`[검증필요]`** 있으면 → 내가 **종합법률정보(glaw.scourt.go.kr)** 에서 사건번호·판시 재확인 → 맞으면 확정, 아니면 교체/삭제
   - **요건 누락 없나 / 청구취지 안 바꿨나 / 주요 쟁점 다 다뤘나**(일부 집중 금지)
6. **서면 파일 만들기**: "지시문 서식대로 docx로 뽑아줘" → Claude Code가 docx 생성 + 면수 1차 확인.
7. **한글에서 마무리 (내가)**:
   - docx를 한글로 열기 → **지시문 서식** 맞추기(글꼴·여백·줄간격)
   - **분량(매수)을 한글에서 실측** — 넘으면 **자구만** 줄임(여백·줄간격·글꼴은 규정값이라 손대지 말 것)
   - **HWP/HWPX로 저장**
8. **제출 직전 체크**:
   - 파일명 규칙대로 (예 `연도-참가번호-분야-단계-지위`)
   - **본문에 학교·실명 노출 금지**(변호사명 옆 참가번호만)
   - 인용 판례·조문 **전부 검증됨**(`[검증필요]` 잔존 0)
   - 작성 명의·날짜·파일명이 지시문 표기와 글자 단위로 일치
9. **대회 홈페이지에 업로드** (마감시간 엄수).
