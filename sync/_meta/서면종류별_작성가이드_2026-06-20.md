# 서면 종류별 작성 가이드 (가인 기록형, 2026-06-20)

> 마스터 C-1·스킬 Phase 3의 **상세판**. 우수답안 구조를 추상화(원문 복사 아님). 마스터는 이 파일을 참조(단일근원).
> 분량·형식·서면 명칭은 **지시문 기준**. 조문은 작성 시 korean-law-mcp로 재확인.

## 공통 원칙 (모든 종류)
- **두괄식 결론 선제시**: 쟁점/죄목마다 결론(무죄/인용/기각)을 먼저 + 핵심 논거 ①②③ 압축한 총괄요지 문단 → 세부 전개
- **IRAC 변형 4단**: 법리(조문+판례) → 요건 정리 → "사안에서" 포섭 → 소결 (소절마다 반복)
- **다단계 예비방어**: 형사 "설령 ~하더라도" / 민사 "가사 ~로 보더라도" — 1차가 막혀도 다음 단계서 동일 결론
- **근거 명시**: 법리 단정마다 조문번호 + 판례(검증된 것만 본문 직접인용 — `판례탐색_전략` 준수)
- **번호체계 일관**: `1. > 가. > 1) > 가) > ①②③` (병렬 요건·논거는 ①②③)
- **소결-결론 이중 마무리**: 쟁점 끝 소결 + 문서 끝 전체 결론(구하는 재판 명시)
- **머리·말미 정형 엄수** / **쟁점 거울상**(형사 의견서↔변론요지서, 민사 원↔피) / **사안 포섭 필수**(법리만 적고 적용 누락 금지)
- **분량 우선순위화**: 장수 제한 내 핵심 쟁점에 분량 집중. 익명(참가번호만)·청구취지 변경 금지.

## 1. 형사 변론요지서 (변호인)
- **머리**: 제목 "변 론 요 지 서" → 사건·피고인 → "이 사건에 관하여 위 피고인의 변호인은 다음과 같이 변론합니다" → "- 다 음 -". **말미**: 작성일 → "피고인의 변호인 변호사 ○○○(참가번호)" → "○○지방법원 제○형사부 귀중"
- **본문**: ①죄명별 절 분할 ②각 죄 총괄요지(무죄 결론+논거 ①②③ 선제) ③구성요건 단계별 부정(객체·행위·고의·인과·동가치성 순) ④**증거능력 차단 블록**(위법수집·전문법칙·최량증거·자백보강·탄핵 — 증거 1건=1소절) ⑤예비적 "설령 ~하더라도"(위법성·책임 조각·예외요건 불충족·죄수/가중 부정) ⑥죄별 소결 → 전체 결론(무죄)
- **필수**: 입증책임=검사·합리적 의심 배제 미달 환기 / "사안에서" 포섭
- **흔한 누락**: 예비적 주장(구성요건만 다툼)·사안 포섭·입증책임 명시

## 2. 형사 의견서/논고요지서 (검사) — 변론요지서의 거울상
- **머리**: "의 견 서" → 사건·피고인 → 인사문 → "다 음". **말미**: 작성일 → "검사 ○○○" → "법원 귀중"
- **본문**: ①죄명별 ②유죄 총괄요지(구성요건 충족 결론 선제) ③구성요건 요건별 적극 포섭(증거 연결) ④증거능력 인정·증명력 충분(변호인 위법수집 주장 반박) ⑤위법성·책임조각 부존재 ⑥죄수·가중 → 소결 → 전체 결론(유죄·구형)
- **필수(레드팀·리허설 보강)**: 검사 **엄격증명 부담 명시** + 각 요건 도달 / 배임이면 **6요건 전부**(사무처리자·임무위배·재산상이익·**본인 손해**·고의·**불법이득의사**) / **구형 양정**(법정형·경합범 가중·양형요소) / 변호인 예상 항변 **선제 반박** / 착오송금류는 "전형적 착오송금" 단정 말고 수령시점 인식 쟁점 직시
- **흔한 누락**: 변호인 핵심 항변 반박·증거능력 적극 옹호·구형 양정

## 3. 민사 준비서면 (원고측)
- **머리**: "준 비 서 면" → 사건(번호+사건명)·원고(소송대리인)·피고 → "위 사건에 관하여 원고 소송대리인은 다음과 같이 변론을 준비합니다" → "다 음". **말미**: 작성일 → 원고 소송대리인 법무법인 ○○ 담당변호사 ○○○ → "○○지방법원 제○민사부 귀중"
- **본문**: ①사안개요+피고 항변 ①②③ 선제 목록화 ②본안전 항변 반박(제척기간·당사자적격·소적법) ③청구권 발생·귀속·존속 논증(요건 단계별) ④상대 항변(상계·소멸·공제·처분권) 반박 ⑤각 쟁점 소결 → 결론(청구취지대로 인용)
- **전략**: 항변 1개=절 1개로 대응 / **복수 법률구성 가정**("가사 ~로 보더라도") 각각 동일 결론 도출 / 계약조항을 조문처럼 인용해 문언해석으로 권한·지분 도출
- **필수**: 청구취지·청구원인 범위 내(새 청구 추가 금지) / 결론부 금액·이자 기산점 특정
- **흔한 누락**: 요건 단계 중 하나 누락·청구취지 연결(원상회복 방법 특정)·가정구성 일부만 다룸

## 4. 민사 준비서면 (피고측) — 원고측 거울상
- **본문**: ①청구 부인 총괄 ②본안전 항변 ③청구권 부존재·소멸 항변(시효·변제·상계·공제) ④원고 법률구성 반박(성질결정 달리) ⑤소결 → 결론(청구 기각)
- **필수**: 항변마다 요건·근거 / 본안전→본안 순서 / 사안 포섭·증거 연결 / 원고 재반박 선제 대비

## 5. 민사 소장 (입력자료로 흔하나 작성 과제 시)
- 청구취지(특정·이자 기산점) → 청구원인(요건사실: 권리근거→장애·소멸·저지 대비) → 입증방법 → 관할·당사자 → 결론

## 6. 가사 이혼 (우수답안 미수록 — 일반 법리 기반, 조문 재확인 필수)
- 청구취지(이혼·위자료·재산분할·친권/양육) → 파탄사유(재판상 이혼원인 **민법 §840 각 호별**, 유책배우자 제한·6호 보충성) → 위자료(**§843 준용 §806**) → 재산분할(**§839-2**, 재판상은 §843 준용: 대상재산 확정·기여도·청산/부양) → 친권자(**§909④**)·양육(**§837**·양육비)·면접교섭(**§837-2**, 자녀 복리 기준) → 결론. 준비서면이면 청구취지 변경 금지.

---

> **주의**: 검사 의견서·피고 준비서면·소장·가사는 우수답안 실물 부재 → 변론요지서/원고 준비서면의 거울상 + 일반 법리로 구성. **실제 출제 지시문이 항상 우선.**
