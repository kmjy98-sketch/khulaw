# ① 법학 발표·보고용 PPT 기본 디자인 포맷
16:9 (1280×720pt 가상 캔버스).

## A. 색 팔레트 — 절제된 학술톤
| 역할 | 이름 | HEX | 용도 |
|---|---|---|---|
| Primary | 잉크 네이비 | `#1B2A41` | 표지 배경·대제목·헤더 바 |
| Primary-Sub | 슬레이트 블루 | `#2E4A6B` | 소제목·강조선·표 헤더 |
| Accent | 버건디 레드 | `#7A2E2E` | 쟁점·결론 키워드(1슬라이드 1색만) |
| Accent-Sub | 머스타드 | `#A87C3D` | 판례·인용 표지(한정) |
| Text-Main | 본문 먹 | `#222831` | 본문 |
| Text-Sub | 회먹 | `#5A6472` | 캡션·출처·각주 |
| Line | 라이트 그레이 | `#D2D7DE` | 구분선·표 괘선 |
| BG-Base | 오프화이트 | `#F7F8FA` | 본문 배경 |
| BG-Panel | 페이퍼 | `#ECEEF2` | 인용 박스·판례 카드 |
| Positive | 딥 그린 | `#2F5D50` | 합헌·인용·다수의견(도표) |
| Negative | 다크 레드그레이 | `#6E3B3B` | 위헌·기각·반대의견(도표) |

원칙: 1슬라이드 강조색 1종(`#7A2E2E`). 채도 낮은 색만(인쇄·빔 양쪽 가독).

## B. 폰트
| 구분 | 국문 | 숫자/영문 |
|---|---|---|
| 제목 | Pretendard SemiBold / Noto Sans KR Bold | Inter SemiBold |
| 본문 | Pretendard / Noto Sans KR Regular | Inter Regular |
| 조문·인용 | Noto Serif KR(세리프로 시각 구분) | — |
| 각주 | Noto Sans KR Light 12–14pt | Inter Light |

대체 체인: `Pretendard → Noto Sans KR → Malgun Gothic → sans-serif`. 숫자는 항상 Inter(tabular)로 사건번호·연도 정렬. 위계는 색 아닌 굵기로.

## C. 크기 위계(pt): 표지 40–44 / H1 30–32 / H2 22–24 / 본문 18–20 / 보조 16 / 캡션 12–14.

## D. 레이아웃 그리드
여백 상72/하64/좌우80pt. 12컬럼·거터16(단일단=쟁점, 6+6=비교·반대의견, 4+4+4=요건·효과·결론). 베이스라인 8pt. 헤더 0–56pt(주제·과목 라벨), 좌측 4pt `#7A2E2E` 유형 색인 바. 푸터: 주제약칭·페이지(우)·출처/일자(좌) `#5A6472` 12pt. 콘텐츠 1120×560pt.

## E. 슬라이드 6종(+보조)
| 유형 | 구성 | 색 |
|---|---|---|
| ① 표지 | 네이비 풀배경, 흰 대제목, 하단 강조 바 | 다크 |
| ② 목차 | 좌 세로 번호리스트, 현재 섹션만 `#7A2E2E` | 라이트 |
| ③ 쟁점 | "쟁점" 칩(`#7A2E2E`/흰글자), 질문형 1문장+불릿 3–5 | 라이트 |
| ④ 판례 | 페이퍼 카드`#ECEEF2`, 사건명·번호(Inter)·판시(본명조 인용), 머스타드 좌 인용 바 | 카드형 |
| ⑤ 도표 | 표 헤더`#2E4A6B`/흰글자, 괘선`#D2D7DE`, 합헌/위헌=`#2F5D50`/`#6E3B3B` | 데이터 |
| ⑥ 결론 | 핵심 명제 큰 글씨, 결론 키워드만 `#7A2E2E` Bold | 라이트 |
| 간지/참고문헌 | 네이비 배경 섹션명 / 출처리스트 본명조 | — |

## F. 컴포넌트·변환
라벨 칩(반경4pt·패딩6×12). 인용박스(좌4pt 컬러바+`#ECEEF2`, 본명조). 표(외곽선 생략, 헤더만 채색, zebra 금지). 불릿(1단계 `–`, 도형·이모지 금지). **변환**: pptx=마스터1+레이아웃6종+테마10슬롯, Marp=`--primary:#1B2A41` CSS 변수+`<!-- _class: cover|issue|case -->`. 접근성: 대비 ≥4.5:1, 강조는 색+굵기 이중신호.
> 변환 대상 후보: 루트 `알고리즘담합_공정거래법_발제.pptx`+동명 .md, `sync\발제\` 발제문 다수.
