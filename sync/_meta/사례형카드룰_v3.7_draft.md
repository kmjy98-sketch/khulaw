## 운영 원칙 (2026-06-12, CLAUDE.md #17 반영)
- 신규/변경 룰은 **1청크 파일럿**으로 검증(앞/뒤/빈칸 직접 확인) → 통과 시에만 **전체 병렬 재작성**(워크플로우). 파일럿 통과 작업은 사례형·암기장 등 병렬 동시 가동. 파일럿 없이 전량 실행 금지.

## 0. 원문 강조 신호 (A2)
- OCR 소스의 `<u>…</u>`·`**…**` = 교재가 강조한 **판례 핵심 기재례/요건** → **계층 B·D 빈칸 타겟의 1순위**.
- 한자(甲乙丙丁)는 한글(갑을병정)로 치환(#37). 사건번호·조문은 anchor 보존(#34), korean-law-mcp 재확인.

## 1. 계층 구조 (사례당 / 별도 덱)

### 계층 A — 쟁점도출 (Basic, 사례당 1장) · **축약형**
- 앞: 원문 사례 지문(사실관계) + 설문(번호·점수). 결론 비노출.
- 뒤: 원문 "논점정리"의 ㉠㉡ **쟁점 + 결론 1줄**만. 포섭 이유는 계층 B로 위임.
- **축약 기준 = 민사례1 "논점정리" 수준**(이미 축약돼 있음). 더 늘리지 않음.
- 덱: `사례형::{과목}::쟁점도출`

### 계층 B — 포섭 cloze (Cloze, 쟁점당 1~3장) · **inferability 전수 보정**
- 빈칸 = 원문 `<u>/**` 강조 구간 안의 **법리 핵심어**(조문·요건·결론판단).
- **NLP 경계(B1) 전수 적용**:
  - 빈칸 끝은 체언(명사) **또는 결론술어**(성립/무효/부정 등). 조사·어미·연결술어(~므로/~한바) 제외.
  - **사안 고유명사(갑·을·병·X토지) 빈칸 금지** — 법리어만.
  - **빈칸 주변 3어절 내 정답 단서 금지**(유추 차단). 단서면 그 부분도 함께 빈칸.
  - 빈칸 2개는 **상호 독립**(한쪽 알아도 다른쪽 유추 불가).
  - 배점 큰 쟁점은 단어가 아니라 **논거 구절 통째**를 빈칸(논거 2~3개 현출 강제).
- 뒤: 정답 + 사건번호 + 출처 페이지.
- 덱: `사례형::{과목}::포섭` (또는 암기장-객관식으로 파생)

### 계층 C — 함정/검토누락 (Basic, 과목별 독립 덱)
- 소스: 고동성 사례풀이 주의사항(`고동성/_추출/`). 두문자 제외, 판례 원문 재확인.
- 앞: 상황 한 줄 / 뒤: 검토 쟁점·죄목 + 결론 + 누락 경고.
- 덱: `찌라시::함정::{과목}`

### 계층 D — 기재례 통암기 (Cloze, **비중↑** · **키워드 클로즈**)
- 정형 기재례(요건 정의문·청구취지·물상보증 계산문구 등) 통암기.
- **한 덩어리 빈칸이 아니라 핵심 키워드 다수를 각각 빈칸(키워드 클로즈)** — 실전 문구를 단어 단위로 인출. 한 기재례에 빈칸 3~6개.
- 빈칸 경계는 B1(NLP) 적용: 체언/결론어 종결, 조사·어미 밖. 대립개념은 서로 유추 불가하게(신뢰이익↔이행이익).
- **전체 답안 백지현출은 Anki 아님 → 종이 실전답안으로** (수기 방식).
- 덱: `사례형::{과목}::기재례`

# 파일럿 — 사례1 §126 표현대리 (민사례1 p.33-34) 신 v3.7 적용

원문(요약): 갑·을 A토지 균등공유. 갑이 분할등기를 을에게 맡기며 서류·인감 교부 → 을이 A토지 전부를 병에 매도(갑 지분은 무권대리)·이전등기.

### [계층 A] 쟁점도출 (Basic)
```
앞: 〔사례1 설문1, 15점〕 갑과 을은 A토지를 균등지분 공유. 갑은 균등현물분할을 을과
합의하고 공유물분할등기 신청을 을에게 맡기며 관련 서류와 인감도장을 교부하였다.
을은 그 서류·인감으로 A토지 전부를 병에게 2억원에 매도하고(갑 지분은 대리인으로
행세) 소유권이전등기를 마쳤다. 병은 A토지 소유권을 취득하는가?

뒤:
㉠ 갑 동의 없는 을의 공유물 전부 처분 → 처분자 지분범위 내 유효
㉡ 갑 지분 처분과 §126 표현대리 → 기본대리권(공법행위 대리권)O + 정당한 이유O
   ⇒ 병은 A토지 전부 소유권 취득
```
