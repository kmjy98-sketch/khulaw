### 1차 매핑 사용 원칙

- **법령·조문**: 1차 출처는 국가법령정보센터. 다른 사이트의 조문 인용은 반드시 이 사이트로 재확인.
- **판례**: 사건번호를 안다면 종합법률정보 직접 입력이 최단경로. 모르면 키워드+연도로 디렉토리 검색. 평석은 보조(법률신문), 본문은 반드시 종합법률정보로 재확인.
- **헌재 결정문**: 종합법률정보가 아닌 **헌재 지능형 통합검색**에서. 본문 풀텍스트 검색이 가능해 메인 사이트(ccourt.go.kr)보다 정확도 우수.
- **학술 논문**: KCI에서 등재 여부 1차 확인 → DBpia/KISS에서 원문 PDF(학교 구독). 학위논문은 RISS·국회도서관 무료.

## §4. 사이트 선택 의사결정 트리

```
질문 유형
│
├─ 조문 원문이 필요한가? ─→ 국가법령정보센터
│   └─ 개정 연혁 추적? ─→ 같은 사이트 "연혁" 탭
│       └─ 입법자 의사? ─→ 국회 의안정보시스템
│
├─ 판례 본문이 필요한가?
│   ├─ 대법원/하급심 ─→ 대법원 종합법률정보
│   │   └─ 미공개 ─→ 사법정보공개포털 신청
│   ├─ 헌재 결정 ─→ 헌법재판소 isearch
│   └─ 평석·동향 ─→ 법률신문 / 리걸타임즈
│
├─ 행정해석이 필요한가? ─→ 법제처 법령해석례
│   └─ 부처별 해석 ─→ 국가법령정보센터(행정규칙)
│
├─ 학술 자료가 필요한가?
│   ├─ 학위논문 ─→ RISS / 국회도서관
│   ├─ 학술지 등재 확인 ─→ KCI
│   └─ 학술지 원문 ─→ DBpia / KISS (학교 도서관 경유)
│
├─ 시험 자료가 필요한가?
│   ├─ 변호사시험 ─→ 법무부 게시판
│   └─ LEET ─→ leet.or.kr
│
└─ 외국·국제 자료가 필요한가?
    ├─ 외국법령 한국어 ─→ 세계법제정보센터
    ├─ 외국법령 영문 ─→ Cornell LII (US) / EUR-Lex (EU)
    ├─ 국제조약 ─→ UN Treaty / 외교부
    └─ 국제판례 ─→ ICJ / WTO / EUR-Lex
```
