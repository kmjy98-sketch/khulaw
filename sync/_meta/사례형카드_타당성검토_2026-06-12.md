## 1. 타당성 결론표

| 설계요소 | 결론 | 한줄 근거 | 4관점 합의/이견 |
|---|---|---|---|
| **① 키워드 빈칸**(포섭 cloze) | **O** (단, inferability 보정 필요) | 변시 배점 최고층(포섭 40~60%)을 직접 훈련. 수기 교훈 1번 "실전 현출용 기재례 낱말카드化"의 직접 구현. 현행 빌드가 이미 동작 중. | **L1·L3·L4 = O / L2 = △**. 핵심 이견: L2는 "현행 cloze는 빈칸 주변 문맥이 정답을 지목 → 인출이 아니라 독해(유창성 착각)"라 inferability<50% 보정 없이는 △. L1·L3·L4도 "빈칸이 단어로 퇴화하면 무효"라는 단서를 동일하게 인식 → **실질 합의: O이되 빈칸 위치 규칙 강제 필요**. |
| **② 목차**(쟁점 도출·암기) | **△** (단독 덱 X, 사례 단위 카드의 앞단으로 O) | 쟁점도출 배점은 5~10%지만 누락 시 하위 배점 전체 소실(수기 6번 "점수주워먹기"). 인출 자극(사안→목차)으로 active recall 순도 높음. 그러나 "목차만 알고 포섭 못 쓰는" 상태로 귀결 위험. | **L2 = O / L1·L3·L4 = △**. 이견 아님, 강조점 차이. L2는 "active recall 원형이라 견고"하다고 높게 평가, 나머지는 "현행 논점추출 뒷면이 포섭까지 담아 Cloze와 중복 → 목차만 인출하도록 뒷면을 결론 1줄로 축약해야 가치"라고 봄. **합의: 목차 카드 자체는 유지하되 뒷면을 "쟁점→결론 1줄"로 제한**. |
| **③ 전체 답하기**(답안 전체 현출) | **X** (Anki 카드로는 부적합) | 채점 단위 불명(Again/Hard/Good 분류 불가)·뒷면 400~800자로 회독이 "읽기"로 퇴화·SRS 간격 붕괴. 전체 현출은 종이 실전답안 훈련의 몫. | **4관점 만장일치 X**. L1·L3은 "포섭 cloze 5~8개를 다 맞히면 전체 답안은 자연 재구성됨"으로 대체 논거 제시. 예외 합의: **쟁점 1~2개·10~15점 단답 사례**(예: §133단서 채권양도 p.43)와 **형식 기재례**(청구취지·물상보증 계산문구)는 짧아서 Basic/Cloze 전체현출 가능. |

**4관점 종합 판정**: ①O + ②△(앞단 편입) + ③X(짧은 예외만). 단일 카드에 셋을 합치지 않고 **계층 분리**가 모든 관점의 공통 처방.

## 2. 권고 사례형 카드 설계

한 사례 = **3계층 + 조건부 1유형**. 각 계층을 **별도 Anki 덱**으로 분리해 FSRS 간격 오작동(L1 리스크3·L2 리스크2)을 차단한다.

### 계층 A — 쟁점도출 카드 (Basic, 사례당 1장)
- **앞면**: 사실관계 압축 3~5줄 + 설문(번호·점수·연도). **결론 비노출**.
- **뒷면**: 쟁점 목차만, 각 쟁점 끝에 결론 1줄. `㉠ 쟁점 → 결론 / ㉡ 쟁점 → 결론`. **포섭 이유는 넣지 않음**(계층 B로 위임).
- **예상분량**: 앞 3~5줄 / 뒤 4~6줄. iPad 1화면 무스크롤.
- **노트타입**: Basic.
- **inferability 확보**: 앞면이 사안, 뒷면이 목차 → 사안만 보고 쟁점을 못 떠올리면 실패. 문맥이 정답을 지목하지 않음.

### 계층 B — 포섭 논거 cloze (Cloze, 쟁점당 1~3장)
- **앞면**: 사안 포섭 문장(복문 가능). **빈칸 = 조문번호 / 요건명 / 결론 판단어**를 각각 독립 c1·c2·c3로 분리.
- **뒷면**: 빈칸 정답 + 사건번호 + 출처 페이지.
- **예상분량**: 1~3문장. iPad 1화면.
- **노트타입**: Cloze.
- **inferability 확보(핵심 보정, L2)**: ⓐ 사안 고유명사(갑·병·X토지)는 빈칸 대상 제외 — 법리 단어만 빈칸. ⓑ **"빈칸 주변 3단어 이내에 정답 단서 포함 금지"**를 02-card 프롬프트에 명문화. ⓒ 빈칸 2개는 상호 독립 지식(한쪽 알아도 다른쪽 유추 불가)으로. ⓓ `augment_cloze`는 사례형 포섭에서 **비활성화 또는 min_length 상향**(2글자 조사 파편 빈칸화 방지, L3 리스크2). ⓔ L4 보강: 배점 큰 쟁점은 빈칸을 단어가 아니라 **논거 나열 전체**로 잡아 "논거 2~3개" 현출을 강제(수기 공법 교훈 "포섭 배점이 법리보다 높음").

### 계층 C — 함정/검토누락 카드 (Basic, 사례 무관·과목별 독립 덱)
- **소스**: 고동성 사례풀이 주의사항 7과목 파일("☞누락 유의!!").
- **앞면**: 상황 한 줄(`절도 범행 중 공범 1인이 폭행한 경우 누락 쟁점은?`).
- **뒷면**: 검토 죄목/쟁점 목록 + 판례 결론 1줄 + 누락 시 손실 경고.
- **노트타입**: Basic. **별도 덱**(과목별 빈출 함정).
- **순환인용 차단(#2, L1 리스크2)**: 주의사항 파일은 본인 2차 가공물 → 조문은 법령정보센터 원문, 판례 문구는 원문/korean-law-mcp 재확인 후 카드화. **두문자는 제외**.

### 조건부 D — 기재례 통암기 cloze (Cloze, 배점 높은 쟁점·짧은 단답 사례만)
- 물상보증 구상 계산문구, 공소시효 도과, 청구취지 서식 등 **그대로 옮겨 쓰는 정형 문구**.
- 앞면 cloze, 빈칸은 대립 개념(신뢰이익↔이행이익)이라 서로 유추 불가.
- "전체 답하기"의 유일한 합법적 카드 형태(분량 3~5줄).

**카드폭증·채점부담 회피 명시**:
- 계층 A 1장 + 계층 B 3~8장 = **사례당 4~9장**(현행 61장/12사례 ≈ 5장/사례와 동일 수준 — 폭증 아님). 계층 A 뒷면 축약으로 오히려 총량 감소.
- 채점부담: 계층 A는 "목차 재구성 여부", 계층 B는 "빈칸 정답"으로 판정 단위가 작아 Again/Hard/Good 판단이 명확. 전체 답안 카드(③)를 배제했으므로 채점 모호성 제거.

### 계층 A (Basic 1장)
```
【앞】 〔사례 설문1, 15점〕 갑·을이 A토지를 균등지분 공유. 갑은 균등현물분할을

병은 A토지 소유권을 취득하는가?

【뒤】
㉠ 공유자 1인의 공유물 전부 처분 → 처분자 지분범위 내 유효(을 지분 유효)

㉢ §126 정당이유 → 인감·서류 교부로 본인 귀책 + 병 선의·무과실(O)
```

(포섭 근거 없음 = 목차 인출 전용)

### 계층 B (Cloze 3장, inferability 보정판)
현행 cloze는 `…처분공유자의 {{c1::지분범위 내에서는 유효}}한 처분행위`로 빈칸 앞이 정답을 지목한다. 보정:

```
효력 범위 근거조문: {{c2::공유지분}} 처분권 → 처분공유자 {{c1::지분범위 내}}만 유효.
〔뒤: c1 지분범위 내 / 93다1596 / 민사례1-p33〕

【B-2】 [§126 기본대리권 판단] 공유물분할등기 신청 대리권·인감증명 신청 같은
{{c1::공법행위}} 대리권도 §126의 {{c2::기본대리권}}에 해당한다.
〔뒤: c1 공법행위 / c2 기본대리권 / 77다1669 / 민사례1-p33〕

【B-3】 [§126 정당이유 포섭 — 논거 3개 통째 빈칸(L4 보강)]
{{c1::등기부상 공유자로 등기된 을이 갑의 인감·서류를 병에게 제시}} →
병이 권한 있는 자로 믿을 수밖에 없고 과실 없음 +
{{c2::갑이 을에게 서류·인감을 교부한 것이 본인 귀책}} →
을의 갑지분 처분은 {{c3::§126 표현대리}} 성립.
〔뒤: c1 신뢰의 정당성 논거 / c2 본인 귀책 논거 / c3 §126 표현대리 / 민사례1-p33〕
```

계층 A 뒷면·B 뒷면 정답에 `[[§126]]`, `[[표현대리]]`, `[[대판 …, 77다1669]]` 백링크. 단 **TSV cloze 빈칸 안과 표 안에는 백링크 금지**(#35) → 카드 본문이 아닌 뒷면 정리란/위키 동기화 시에만.

## 4. 암기장 카드 연계 (일반론/포섭/예외, 강약조절)

사례형 계층 B에서 **사안 고유 부분을 제거**하면 그대로 암기장 카드로 파생된다(현행 빌드 v4.2 `분리::사례집포섭` 태그가 이미 Cloze→`암기장-객관식`, Basic→`암기장-사례형` 분리 처리).

| 암기장 유형 | 사례형에서 파생 경로 | 예시(위 사례) | 강약 |
|---|---|---|---|
| **일반론** | 계층 B 빈칸 중 조문·요건 일반명제만 추출, 사안 삭제 | "공법행위 대리권도 §126 {{c1::기본대리권}}" | 약(반복 기초) |
| **포섭** | 계층 B 논거 빈칸(B-3)을 일반화 — "어떤 사정이 정당이유인가" | "인감·권리서류 교부 + 등기부 명의 → 정당이유 {{c1::긍정}}" | 강(배점 핵심) |
| **예외** | 계층 C 함정 + 판례 부정례 | "부부 일방의 타방 부동산 처분 → 정당이유 거의 {{c1::부인}}(2008다95861)" | 강(역방향 함정) |

**강약조절 원칙**: 난이도 태그(현행 A/B)를 그대로 활용 — A=사안 특유 판단·예외 판례(자주 출제·잘 틀림)는 FSRS 단축 간격, B=일반론·기초 요건은 표준 간격. 계층 C 예외카드는 별도 덱이라 직전 회독(수기 4번 "직전엔 주류 현출력 떨어짐") 시 집중 회독 대상으로 분리 운영.

## 5. 트레이드오프·사용자 결정 필요 사항

1. **계층 A 뒷면 축약 vs 현행 유지** — 현행 논점추출 뒷면은 포섭 논거까지 담아 정보 손실은 없으나 계층 B와 중복·목차 인출 순도 저하. 축약하면 목차 훈련 순도↑·총카드 수↓, 대신 한 카드에서 보던 정보가 A/B로 분산. **결정 필요**: 축약형으로 전환할지, 현행 상세형 병존할지.

2. **inferability 보정의 비용** — "빈칸 주변 3단어 단서 금지"는 LLM이 일관 준수 보장 불가(L2 리스크1) → 사례형 cloze 전수 수동 검토 필요. **결정 필요**: 보정을 전면 적용(수동검토 부담)할지, 배점 높은 A난이도 카드에만 선별 적용할지.

3. **`augment_cloze` 사례형 처리** — 자동 추가 빈칸이 단어 퇴화 유발(L3). **결정 필요**: 사례형 포섭 덱에서 augment 완전 비활성화 vs min_length 상향(예: 4자 이상).

4. **계층 C 소스 우선순위** — 미독 5과목(민소·형소·상·행·헌) 주의사항 파일 정독·검증 시점. **결정 필요**: 사례형 카드화와 동시 진행 vs 별도 찌라시 작업으로 분리.

5. **과목별 빈칸 설계 분기(L4 리스크3)** — 민법 패턴(요건→포섭→결론)을 공법(처분→근거조항→비례원칙 3단계)·환경법(특별법 조문위치→요건)에 그대로 이식 불가. **결정 필요**: 과목별 빈칸 원칙을 별도 프롬프트 분기로 명문화할지(민법 카드 완성 후 공법 착수 시점에 결정해도 무방).

6. **전체 답안 훈련 채널** — Anki 외부(종이 실전답안)로 분리 확정 시, 그 결과물(약점 사례)을 다시 계층 B 약점 카드로 환류하는 루프를 운영할지. **결정 필요**.

### 1. 각 설계 요소 타당성

---

**① 키워드 빈칸 (포섭 cloze)** — **O**

**근거**: 고동성 수기 핵심교훈 1번 — "사례형도 실전 현출용 기재례로 낱말카드化". 현행 카드(`민사례1_사례형_p031-060_cards.md`)의 포섭 cloze가 이 컨셉의 직접 구현이다.

현출훈련 기여 구조: (a) 빈칸 앞 문장이 사안 포섭의 흐름 자체이므로, 카드를 보는 순간 "갑의 이 행위 → §126 표현대리 성립"이라는 포섭 연결선을 반복 소환. (b) 빈칸 위치가 "판례 결론 문구" 또는 "요건 충족 여부 + 근거"에 집중되어 있으므로, 실전에서 답안지에 그대로 옮겨 쓸 수 있는 문장 수준의 단위를 반복 강화. (c) 사안 특유 판단(이 사건에서의 사실-법리 연결)만 cloze 대상으로 삼아 기본서 일반법리 반복을 제거 — 시험 현출력(속도·정확도)과 직결됨.

주의사항 통합 방식: 형사 주의사항 파일의 "☞주거침입 검토!!" 같은 누락 유의 포인트를 동일 phrasing으로 포섭 cloze에 삽입 가능. 예) `갑이 폭행하기 위해 진입한 경우 {{c1::주거침입죄}}를 누락하지 않는다.` — 함정 체크가 반복 학습에 자연 편입.

---

**② 목차 (쟁점 목차 도출·암기)** — **△**

**근거**: 고동성 수기 핵심교훈 4번 — "익숙한 쟁점도 머릿속에서 목차 끄집어내는 훈련, 안 익숙하면 직접 써보기". 목차 도출 자체는 현출훈련의 출발점이 맞다. 그러나 목차만 있는 카드(스켈레톤 카드)는 현행 논점추출 카드(앞면=사안+설문, 뒷면=쟁점 목록+결론 한 줄씩)가 이미 상당 부분 수행하고 있다.

현출훈련 기여 구조: (a) 쟁점 목록 끄집어내기 — 기여함. (b) 그러나 실전에서 목차만 외운 수험생은 "§126인 건 아는데 정당한 이유 포섭 문장이 안 나온다"는 문제로 귀결됨. 목차는 현출의 입구이고 기재례가 출구인데, 목차 전용 카드는 입구만 훈련한다. (c) 단, 과목별 함정 목차(형사 주의사항 파일의 섹션별 체크리스트 구조)는 "이 사안에 뭘 검토해야 하는가" 출제 패턴 훈련으로 가치 있다.

결론: 독립 카드보다 논점추출 카드의 뒷면 첫 줄에 "쟁점 목차 → 결론" 형태로 포함시키는 것이 효율적. 목차만 분리한 별도 카드는 현출훈련 ROI가 낮다.

---

**③ 전체 답하기 (답안 전체 현출)** — **△**

**근거**: 고동성 수기 핵심교훈 4번 후단 — "안 익숙하면 직접 써보기". 전체 답안 현출이 현출훈련의 최종 형태인 건 맞다. 그러나 카드 포맷으로 구현할 때 문제가 생긴다.

현출훈련 기여 구조: (a) 아이패드 환경으로 카드가 길어도 된다고 해도, 뒷면에 전체 답안을 넣으면 Anki SRS 메커니즘과 충돌 — "Again/Hard/Good/Easy"를 어디에 쓰는지 모호해짐. 전체 답안을 외웠는지 판정할 단위가 너무 커서 반복 주기 계산이 무의미해짐. (b) 전체 답안은 포섭 cloze 5~8개를 전부 맞혔을 때 자연스럽게 재구성되는 구조가 이상적임. 즉 포섭 cloze가 충분히 쌓이면 전체 답안 재구성 능력은 따라온다. (c) 단, "처음 접하는 사례 문제"나 "약점 사례"에 대해 실전 모의고사 형식으로 전체 답안을 써보는 훈련은 별도 세션으로 하는 것이 맞고, 이를 Anki 카드화하는 것은 용도가 다르다.

결론: Anki 카드로는 X. 단, 논점추출 카드 뒷면(현행 형식)에 "답안 흐름 요약(청구권 순서 + 각 쟁점 결론 한 줄)"이 포함되어 있으면 전체 흐름 재구성은 충분히 보완된다.

---

### 2. 권고 결합방식 — 구체적 카드 형태

**카드 유형 A: 논점추출 카드 (사례 단위)**

- 앞면: `〔사례/설문 번호, 점수〕 + 사안 요약 (3~5줄)`
- 뒷면 구성:
  1. 쟁점 목차 (번호 목록, 2~4개): `㉠ ... ㉡ ... ㉢ ...`
  2. 각 쟁점별 결론 한 줄 (판례 사건번호 포함)
  3. 청구-항변 2열표 (있을 때만)
  4. 함정 체크 박스 (해당 사례의 주의사항 파일 해당 포인트): `☞주거침입 누락 유의!! / 결과적가중범 공동정범 검토`
- SRS 단위: 사례 전체를 "사안 → 쟁점 목차 + 결론 흐름" 재구성으로 판정

**카드 유형 B: 포섭 cloze 카드 (판단 단위)**

- 앞면: 포섭 문장 전체, 빈칸은 판례 결론 문구 또는 요건 충족 판단 표현
- 뒷면: 빈칸 정답 + 사건번호 + 출처 페이지
- 길이: 문장 1개 (복문 가능, 사안 포섭 맥락 전체를 1문장 안에 포함)
- 빈칸 위치 원칙:
  - 판례가 있는 경우: 판례 결론 표현("표현대리가 성립한다", "가분채무로 봄이 상당하다")
  - 판례 없는 해석론: 핵심 요건 충족 여부 ("부정한다" / "요하지 않는다")
  - 함정 포인트: 누락되는 죄목, 오포섭 방향

**카드 유형 C: 함정 체크 카드 (주의사항 파일 기반)**

- 앞면: CASE 상황 묘사 한 줄 (`절도 범행 중 공범 1인이 폭행한 경우`)
- 뒷면: 검토 죄목 목록 + 판례 결론 한 줄 + ☞누락 유의 포인트
- 출처: 형·민 사례풀이 주의사항 파일에서 직접 추출, law-mcp 조문·판례 재확인 후 사용
- SRS 단위: "이 상황에서 뭘 검토해야 하는가" 즉답 여부로 판정

---

**카드 분리 원칙**: 사례 1개당 유형 A 카드 1장 + 유형 B 카드 3~8장. 유형 C는 과목별 주의사항 파일 전체에서 독립 덱으로 구성.

---

### 3. 이 관점(L1 현출훈련)의 핵심 리스크

**리스크 1 — 포섭 cloze 과의존으로 논점 발견력 저하**

포섭 cloze는 이미 쟁점이 식별된 상태에서 결론 문장을 강화한다. 실전에서 진짜 어려운 것은 "이 사안에서 §126이 문제된다는 걸 인식하는 것"인데, 카드만 반복하면 논점 발견 훈련이 빠질 수 있다. 대응: 유형 A 카드(논점추출)를 유형 B와 반드시 병행.

**리스크 2 — 주의사항 파일의 두문자·1차 가공본을 직접 카드화 시 순환인용**

고동성 주의사항 파일은 본인 정리물(2차 가공)이므로, 조문·판례 원문과 다를 수 있다. 유형 C 카드화 시 법령 조문은 법령정보센터 원문, 판례 문구는 판례 원문과 law-mcp로 재확인 필수. 두문자는 카드에서 제외.

**리스크 3 — Anki SRS 단위 불일치로 회독 간격 오산정**

유형 A(사례 단위)와 유형 B(문장 단위)가 같은 덱에 섞이면 "어렵다"의 기준이 달라 FSRS 간격이 오작동한다. 덱을 `사례형_논점추출` / `사례형_포섭cloze` / `사례형_함정체크` 3개로 분리해서 각각 독립 SRS 운영.

## L2 인지과학 관점
## L2 인지과학 관점 — 사례형 카드 설계 평가

### 1. 세 요소 각각의 타당성

**① 답안 키워드 빈칸 (다층 cloze)** — △ (조건부)

타당성이 있으나 inferability 문제가 심각하다. 현행 `민사례1_사례형_p031-060_cards.md`의 포섭 cloze를 보면, 빈칸 주변에 이미 사건번호·사안 요약·결론 방향이 그대로 노출되어 있다. 예: "갑-병 매매는 {{c1::민법 제125조의 표현대리}}가 성립한다" — '표현대리'를 제외한 나머지 문장이 정답을 지목한다. 이 상태에서 학습자는 단어를 인출하는 것이 아니라 주변 문맥을 읽고 채우는 것이다. Soderstrom & Bjork(2015)가 지적하는 유창성 착각(fluency illusion)이 정확히 여기서 발생한다: 카드를 넘길 때 "다 안다"고 느끼지만 실제로는 문맥 단서를 검색한 것이다.

인지과학적으로 cloze가 효과적이려면 빈칸이 **inferability < 50%** 조건을 충족해야 한다. 즉 빈칸 주변 문장만으로는 정답을 유추할 수 없어야 한다. 판례 문장 전체를 살려두면서 핵심 어구에 빈칸을 뚫으면 이 조건이 거의 항상 위반된다.

조건부 타당한 상황: 빈칸 2개 이상이 상호 의존 관계일 때(예: 요건과 효과를 동시에 비워서 둘 다 모르면 어느 쪽도 유추 불가). 또는 사안 포섭 문장을 제거하고 **법리 문장만** cloze로 뚫는 경우. 현재처럼 사안 정보가 그대로 살아있는 cloze는 암기 확인용이 아니라 독해 확인용으로 전락한다.

**② 목차 암기 카드** — O

고동성 수기의 핵심 교훈 4번: "익숙한 쟁점도 머릿속에서 목차 끄집어내는 훈련." 이것이 시험장 실패의 직접 원인이다. 목차 카드는 active recall의 원형 형태다: 자극(사례 상황 요약)만 주고 학습자가 쟁점 목차를 스스로 구성해야 하므로 inferability가 낮고 desirable difficulty가 높다. Karpicke & Blunt(2011)의 retrieval practice 효과가 여기에 그대로 적용된다.

현행 카드에서 논점추출 카드(앞면: 사례 설문, 뒷면: 쟁점 목차)가 이 역할을 하고 있는데, 이 포맷이 가장 견고하다. 단, 뒷면이 지나치게 상세하면 목차 수준이 아니라 포섭 내용까지 포함되어 목차 암기인지 내용 암기인지 경계가 흐려진다. 뒷면은 "㉠ 쟁점명 → 결론" 수준으로 제한해야 한다.

**③ 전체 답하기 (백지 Basic)** — X (독립 카드로는 비효율)

desirable difficulty는 극대화되지만 채점 불가 문제가 치명적이다. Anki 환경에서 학습자가 "내가 맞게 썼나"를 스스로 판단해야 하는데, 긴 답안을 뒷면과 대조할 때 생기는 인지 비용이 너무 크다. 복습 한 사이클에 3~5분이 소요되면 간격반복 스케줄 자체가 붕괴된다. 또한 백지 상태에서 전체 답안을 현출하는 작업은 카드 도구보다 **실제 문제풀이(직접 쓰기)** 방식이 더 적합하다 — 이것은 카드의 역할이 아니다.

다만 예외가 있다: 공법 기록형의 청구취지 등 **형식적 기재례** — 이것은 단락이 짧고 통암기 형태여서 백지 현출 분량이 3~5줄에 불과하다. 이 경우에 한해 Basic(앞: "행정처분 취소소송 청구취지 서식", 뒤: 전체 기재례)이 타당하다.

### 2. 권고 결합방식 — 구체적 카드 형태

3계층 분리 구조를 제안한다. 하나의 사례에서 카드 세트를 다음 순서로 생성한다.

**Layer 1 — 목차 카드 (Basic, 1장/사례)**

```
앞면:
[사례 요약 2~3줄 — 사안 핵심만, 결론 없음]
〔설문1, ○점〕 ○○청구의 타당성을 논하시오.
↓
뒷면:
㉠ [쟁점명] → [결론 1줄]
㉡ [쟁점명] → [결론 1줄]
㉢ [쟁점명] → [결론 1줄]
(포섭 이유 없음, 목차 틀만)
```

이 카드의 목적은 쟁점 도출 훈련이다. 앞면이 사안이고 뒷면이 쟁점 목차이므로 inferability가 낮다. 아이패드 환경에서 앞면을 보고 머릿속에서 목차를 구성한 다음 뒤집어 확인하는 흐름이 고동성 수기의 핵심 훈련과 일치한다.

**Layer 2 — 포섭 논거 cloze (Cloze, 쟁점당 1~3장)**

현행 포섭 cloze의 inferability 문제를 해결하는 방식:

```
기존 방식 (inferability 높음):
갑-병 매매는 {{c1::민법 제125조의 표현대리}}가 성립한다.
→ 문맥으로 정답 추론 가능

권고 방식 (inferability 낮음):
[표현대리] 대리권 수여 표시 → 상대방 선의·무과실일 때 성립근거 조문: {{c1::§125}}
포섭: 갑이 직함 사용 허락(대리권 수여 표시) + 병 선의·무과실 → {{c2::표현대리 성립}}, 이 경우에도 대리권 남용으로 {{c3::상대방 고의·과실 있으면 §107①단서 유추 무효}}
```

핵심 규칙:
- 빈칸은 **조문번호 + 요건명 + 결론 판단** 각각 독립 빈칸으로 분리. 판례 문장 전체를 살리지 않는다.
- 사안 사실(갑, 병, X토지 등 고유명사)은 빈칸 대상에서 제외. 법리 단어만 빈칸.
- 빈칸 2개가 상호 독립 지식을 묻는 경우 동일 cloze에 c1, c2로 뚫되, 한쪽을 알아도 다른 쪽을 유추할 수 없도록 설계.
- 판례 기재례 문장은 통암기 필요 부분만 별도 cloze로 추출 (포섭 문장과 혼합 금지).

**Layer 3 — 기재례 통암기 cloze (Cloze, 필요 쟁점만)**

```
앞면(cloze 방식):
무권대리인 손해배상(§135①)은 이행에 갈음하는 배상이므로,
상대방이 손해배상을 선택하면 {{c1::신뢰이익}}이 아닌 {{c2::이행이익}}을 청구할 수 있다.
```

여기서 c1과 c2는 서로 대립 개념이므로 한쪽을 알아도 다른 쪽을 모를 수 있다 — inferability 충족. 볼드는 c1, c2 위치에만 부여. 밑줄은 요건→효과 흐름 연결선 역할로 "§135① → {{c2::이행이익}}" 연결에만.

---

### 3. 카드 시각규칙 적용안

| 요소 | 적용 위치 | 근거 |
|---|---|---|
| **볼드** | 핵심 조문번호(§125, §135①) + 결론 판단 명사구(표현대리 성립, 이행이익)만 | Pop-out Effect — 카드 전체에서 2~3곳 이하로 제한 |
| 밑줄 | 요건→효과 인과 흐름 화살표 역할 구간만 ("대리권 수여 표시 → <u>§125 성립</u>") | Lorch(1995) 15% 이하 원칙 |
| 초록 강조 | 원칙 법리 결론 ("성립", "유효") | Dual Coding 비언어적 큐 |
| 빨간 강조 | 예외 판례 결론 ("부정", "무효", "정당한 이유 없음") | 위험 신호 메타인지 |
| 색상 규칙 | Layer 2 cloze에만 적용, Layer 1 목차 카드는 색상 없음 | 과잉 자극 방지 |

---

### 4. 이 관점의 핵심 리스크

**리스크 1 — Inferability 점검 자동화 불가**

cloze 카드를 대량 생성할 때 inferability를 카드 생성 시점에 기계적으로 점검할 수 없다. 현행 02-card 프롬프트가 판례 문장 전체를 보존하면서 핵심 어구에 빈칸을 뚫는 방식이면, 결과물의 대부분이 inferability 함정에 빠진다. 프롬프트 지시에 "빈칸 주변 3단어 이내에 정답 단서 포함 금지" 규칙을 명시해야 하는데, LLM이 이 제약을 일관되게 지키는지는 수동 검토 없이 보장할 수 없다.

**리스크 2 — Layer 1과 Layer 2의 내용 중복**

목차 카드(Layer 1) 뒷면에 "㉠ 표현대리 성립"이 있고, 포섭 cloze(Layer 2) 앞면에도 동일한 결론 방향이 노출되면 Layer 2 cloze는 Layer 1을 먼저 복습한 직후에는 inferability가 다시 높아진다. 해결: Layer 1과 Layer 2 카드의 Anki 덱을 분리하고 복습 시점을 어긋나게 스케줄링.

**리스크 3 — 유창성 착각의 메타인지 오류**

아이패드 환경에서 카드가 길어도 된다는 조건 때문에 카드 뒷면에 정보가 과밀해지면, 학습자는 뒷면을 "읽고 이해"하는 것으로 복습이 끝났다고 착각한다. Soderstrom & Bjork(2015)의 핵심 경고다: 뒷면을 읽는 행위는 learning이 아니라 performance다. 해결책은 뒷면을 확인하기 전에 반드시 손으로 또는 말로 먼저 현출하고 뒤집는 프로토콜을 운영 규칙으로 강제하는 것이다. 카드 설계만으로는 이 리스크를 제거할 수 없다.

### 2. 권고 결합 방식 (한 사례의 구체적 카드 구성)

사례 1건에 대해 **2층 구조**로 분리:

  - 예: `〔사례1 표현대리, 2014.10.모의〕 비법인사단 K종중 대표자 L이 M에게 위임장 발송 중 해임됨. M이 위임장 수령 후 N회사와 설계용역계약 체결. N회사의 청구 타당성?`

- 분량: 앞 3줄 / 뒤 4~6줄. iPad에서 스크롤 없이 1화면에 완결.

**2층 — 기재례 인출 (Cloze N장)**

- anki_deck_build_v4.py v4.2 `augment_cloze`로 추가 빈칸 보강 가능하나, 현재 사례형 포섭 cloze는 구절 단위라 MAX_ADD_BLANKS=4 상한 내에서 적절히 동작.

**카드 수 결산 (민사례1 사례1 기준):**
- Basic 1장 + Cloze 4장 = 5장. 현행 파일보다 Basic 카드 분량이 줄어드는 대신 목차 인출 훈련 순도가 높아짐.

**현행 빌드와 호환:**
- Basic 카드 뒷면 축약은 소스 md 수정만 필요(파이썬 코드 변경 불필요).
- anki_deck_build_v4.py의 v4.2 분리(`분리::사례집포섭` 태그)가 이미 Cloze를 `암기장-객관식`으로, Basic을 `암기장-사례형`으로 분리 처리 중이므로 덱 구조 그대로 유지.
- TSV+`#deck` 임포트로 두 층 모두 구현 가능. 사례형 덱(Basic)과 객관식 덱(Cloze)이 각각 분리 임포트됨.

**리스크 1: 목차 Basic 카드 품질**

**리스크 2: Cloze 빈칸 위치가 단어로 퇴화하는 경우**
augment_cloze가 추가 빈칸을 삽입할 때 2글자 단어를 선택하면 단어 암기 카드가 된다. good_kw 필터(len < 2 차단)가 있으나, 4자 이하 조사 끝 파편도 실제로 들어오는 경우가 있다. 사례형 포섭 Cloze는 "결론 구절 전체" 단위를 유지해야 기재례 현출 훈련이 된다. augment_cloze 적용을 사례형 포섭 카드에서는 비활성화하거나 min_length를 올리는 옵션이 필요하다.

**리스크 3: 전체 답안 카드 유혹**
아이패드에서 긴 카드가 잘 보이기 때문에 "어차피 되는데 전체 답안도 넣자"는 유혹이 생긴다. Anki는 채점 시스템이지 필기 훈련 도구가 아니다. 전체 답안 현출 훈련은 Anki 외부에서 별도로 운영해야 하며, 빌드에 전체답안 노트타입을 추가하면 관리 부담만 늘고 회독 데이터가 분산된다.

## L4 변시 채점구조 관점
## L4 변시 채점구조 관점 — 카드 설계 타당성 평가

### 전제: 변시 채점 배점 구조 매핑

변시 사례형 채점은 통상 **쟁점도출(5~10%) → 법리/일반론(20~30%) → 포섭·논거(40~60%) → 결론(5~10%)** 구조이고, 수기 핵심 교훈도 "포섭 배점이 법리보다 높으니 논거 2~3개"다. 카드가 어느 배점층을 훈련하는지를 기준으로 평가한다.

---

## 1. 세 설계 요소 타당성 평가

### ① 답안 키워드 빈칸(포섭 cloze) — O

**근거:**
- 현행 카드(방식 B)가 이미 이 방식을 구현하고 있고, 실제 배점 최고층인 포섭·논거를 직접 훈련한다.
- cloze 빈칸 위치를 "사안 특유 판단문 + 결론어" 에 두면, 수험생이 사실관계에서 법적 평가까지 도달하는 경로 전체를 반복 현출해야 한다. 예: `§107①단서 유추적용으로 갑-병 매매 {{c1::무효}}` 는 단순 단어 빈칸이 아니라 "대리권남용 → 상대방 고의/과실 → 유추적용 무효"라는 논리사슬의 결절점을 치는 것.
- 고동성 수기 핵심교훈 1항: "실전 현출용 기재례를 낱말카드화 → 다음날+3일 복습". 이는 포섭 cloze가 그 역할을 정확히 한다는 직접적 근거다.
- **리스크:** 빈칸이 지나치게 짧으면("무효", "이행이익" 수준) 문장 앞부분만 읽고 반사적으로 맞힐 수 있다. 논거 2~3개를 강제하려면 빈칸을 "논거 나열 전체"로 잡아야 한다. 현행 카드는 빈칸이 단어~구 수준에 집중되어 있어 포섭 훈련이 부분적이다.

### ② 목차(쟁점 목차 도출·암기) — O (단, 단독 카드로는 △)

**근거:**
- 수기 핵심교훈 4항: "익숙한 쟁점도 머릿속에서 목차 끄집어내는 훈련". 쟁점도출이 배점의 5~10%이지만, 누락 시 해당 쟁점의 하위 배점(법리+포섭+결론 전체)을 날린다. 수기 핵심교훈 6항 "점수주워먹기" 의 본질이 여기다.
- 현행 카드의 **논점추출** 카드(앞: 사실관계 설문 / 뒤: 쟁점목록 + 각 결론)가 이 기능을 한다. 사례 1(표현대리) 논점추출 카드에서 앞면이 "갑·을 공유, 을이 갑지분 처분…"이고 뒤면이 "①공유자1인 처분 → ②기본대리권 해당 → ③§126 표현대리 성립 → ④수량지정매매 해당여부"로 구성된 것이 그 예다.
- **단독 카드로 △인 이유:** 목차 카드만 반복하면 "쟁점 라벨은 알지만 그 아래 법리와 포섭 문장을 현출하지 못하는" 상태가 된다. 목차는 포섭 cloze 카드의 전단(트리거)으로 기능해야 실전과 동일한 인지 흐름을 훈련한다.
- 쟁점도출 배점이 실재하므로 목차 카드는 필요하다. 단, 쟁점 항목을 나열하는 데 그치지 않고 **"각 쟁점별 결론 1문장"** 까지 뒷면에 포함해야 배점 획득 훈련이 된다.

### ③ 전체 답하기(답안 전체 현출) — △

**근거:**
- 사례형의 본질이 "전체를 실전에서 현출"하는 것임을 부정하지 않는다. 단, **카드 설계로서는 비효율**이다.
- 아이패드 환경에서 길어도 되지만, 앞면에 사실관계(30~60줄)를 두고 뒷면에 전체 답안(A4 2~3장)을 두면 Anki 반복학습의 핵심인 "정확한 feedback"이 불가능하다. 부분적으로 맞고 부분적으로 틀렸을 때 Again/Hard/Good 을 어떻게 분류할 것인가?
- 전체 답안 현출은 **목차+포섭 카드를 충분히 회독한 뒤, 종이에 실전모의 답안을 써보는 단계**에서 해야 한다. 이를 카드로 대체하면 글쓰기 훈련 없이 "읽고 아는 느낌"만 반복된다.
- 예외적으로 **짧은 사례(10~15점, 쟁점 1~2개)** 에서는 앞: 사실관계 / 뒤: 논리사슬 3~4문장 전체 답 형태가 유효하다. 무권대리 채권양도 사례(p.43, 15점)처럼 쟁점이 "§133 단서 제3자 범위" 1개인 경우가 여기에 해당한다.

## 2. 권고 결합방식 — 구체적 카드 형태

### 유형 A: 쟁점도출 카드 (목차, 1사례당 1장)

```
【앞면】
사실관계 압축 (3~5줄) + 설문 (원문 그대로)
예: 갑이 을 공유지분에 대한 서류를 가지고 병과 매매계약. 을·병 사이 §126 성립 여부 및 수량 상이 시 법률관계는?

【뒷면】
검토 순서 + 각 쟁점 결론 1문장
①공유자 1인 처분 → 처분자 지분범위 내 유효
②§126 기본대리권 → 등기신청 대리권도 해당(○)
③§126 정당이유 → 인감·서류 교부로 귀책 있음(○) → 병 A토지 전부 소유권 취득
④면적 차이 → 정산합의 있어 갑·을의 반환의무(가분채무, 각 500만)
⑤수량지정매매 해당 여부 → 확보 목적 수량 아님 → §574 부적용
```

이 카드의 기능: 시험장에서 답안지 상단에 "목차 4~5개"를 먼저 쓰는 훈련. 쟁점 누락 방지(점수주워먹기).

---

### 유형 B: 포섭 cloze 카드 (빈칸 확장형, 쟁점당 1~2장)

현행 카드는 빈칸이 짧다. 아래처럼 **논거 나열 전체** 를 빈칸으로 잡아야 "논거 2~3개" 훈련이 된다.

```
【앞면】
이 사례에서 §126 표현대리 성립 요건은 어떻게 포섭하는가?
(사실: 을은 갑의 인감·등기서류를 소지하고 등기부상 공유자로 기재된 상태에서 병과 계약)

【뒷면(cloze 위치: 논거 3개 전체)】
①기본대리권: 공유물분할등기신청 대리권은 §126 기본대리권에 해당
②권한초과: 갑 지분 처분으로 수권범위 초과
③정당이유: 등기부상 공유자+인감·서류 소지→병으로서 권한 있는 자로 믿을 수밖에 없고(신뢰 정당) + 갑이 서류·인감 교부한 것이 본인 귀책 사유
→§126 표현대리 성립, 병 A토지 전부 소유권 취득
```

공법 적용 시: 논거가 "비례원칙 3단계(적합성·필요성·상당성) 각각 포섭" 또는 "기본권 제한 요건" 으로 확장된다. 빈칸을 3단계 각각에 두는 것이 포섭 배점 구조와 일치한다.

---

### 유형 C: 함정/누락 경고 카드 (점수주워먹기, 고동성 주의사항 직결)

고동성 사례풀이 주의사항 파일이 이 카드의 1차 소스다.

```
【앞면】
주거침입+절도 동시에 있는 사안에서 자주 누락하는 쟁점은?

【뒷면】
①주거침입 착수시기(판례: 주거에 '들어가는 행위' 개시 시)
②합동절도 성부(2인 이상 합동 → 폭처법 아닌 §331② 가중처벌 여부)
③주거침입과 절도의 죄수관계(견련범 → 상상적 경합)
누락 시 최소 5점 손실 경고
```

환경법 적용 시: 앞면에 "○○법 제△조에 해당하는 사안에서 먼저 확인할 것은?" → 뒷면에 해당 조문 위치 + 요건 + 개정 여부 체크포인트.

---

### 유형 D: 기재례 현출 카드 (수기 교훈 1항 직결)

```
【앞면】
물상보증인이 변제 후 채무자에게 구상할 수 있는 범위와 계산 순서는?

【뒷면】
①변제액 전액 + 이자 + 피할 수 없었던 비용 + 손해
②§370·§341 준용 → 수탁보증인의 사전구상권 유추 가능
③계산: 원금 X억 + 변제일부터 법정이자 연5% + 비용
(기재례: "갑은 을에게 원금 X억 및 이에 대한 변제일인 2025.3.1.부터 다 갚는 날까지 연 5%의 비율에 의한 금원을 지급할 의무가 있다")
```

---

### 결합 순서 (사례 1개당 카드 묶음)

```
[사례 N]
1. 유형 A (쟁점도출) × 1장 → 먼저 보고 목차 현출 시도
2. 유형 B (포섭 cloze) × 쟁점 수만큼 → 각 쟁점별 논거 3개 현출
3. 유형 C (함정 경고) × 필요시 → 해당 사례에 빈출 함정 있을 때만
4. 유형 D (기재례) × 배점 높은 쟁점에만
```

Anki 학습 흐름: 유형 A를 먼저 보고 틀리면(목차 누락) → 해당 쟁점의 유형 B 카드 더 반복. 유형 B에서 논거를 못 쓰면 → 유형 D 기재례 카드 추가.

## 3. 이 관점(L4 채점구조 관점)의 핵심 리스크

**리스크 1: 포섭 빈칸이 "판례 문구 암기"로 퇴화하는 위험**
현행 카드에서 빈칸 위치가 판례 결론어("무효", "기본대리권에 해당", "부당")에 집중되어 있다. 이는 "판례 결론을 아는 것"을 훈련하지 "사실관계 → 논거 전개 → 결론" 경로 전체를 훈련하지 않는다. 수기 핵심은 "기재례를 그대로 현출"인데, 이는 문장 전체를 쓸 수 있어야 함을 의미한다. 빈칸을 논거 나열 전체로 확장하지 않으면 실전에서 "결론은 알지만 답안을 못 쓰는" 상태에 머문다.

**리스크 2: 목차 카드와 포섭 카드가 분리되어 있어 실전 인지 흐름과 불일치**
시험장에서는 "사실관계 읽기 → 쟁점 파악 → 법리 접근 → 포섭 → 결론"이 연속 흐름이다. 카드가 유형 A(목차)와 유형 B(포섭)로 분리되어 별도로 반복되면, 이 연속 흐름의 훈련이 되지 않는다. 대안: 유형 A와 유형 B를 같은 덱의 연속 카드로 배치하되, 유형 A를 먼저 학습한 직후 유형 B로 넘어가는 순서를 고정한다.

**리스크 3: 공법·환경법 구조 차이 미반영**
민법 카드(방식 B)를 그대로 공법에 적용하면 포섭 구조가 맞지 않는다. 공법 사례형은 "처분 인정 → 근거조항 → 요건 충족 여부 → 비례원칙(3단계) → 위법성"으로 층위가 다르고, 배점의 상당 부분이 "비례원칙 3단계 각각의 포섭 논거"에 있다. 환경법은 "특별법 조문 위치 → 해당 요건 → 적용" 순서로 빈칸이 "조문 번호 + 요건 문구"에 집중되어야 한다. 과목별 빈칸 설계 원칙을 다르게 가져가지 않으면 민법 포섭 패턴을 다른 과목에 잘못 이식하게 된다.
