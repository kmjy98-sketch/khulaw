# 본선 암기 1장본 — 가인 기록형 서면 (v2, 2026-06-19)

> 외워서 본선에서 ①AI를 빠르게 통제하거나 ②AI 없이 직접 쓰는 뼈대. `본선_복붙마스터_v2.md`의 발췌 압축(수정은 마스터부터). v1 보존. A4 1장. (2026-06-19 테스트 반영: 청구취지·소결 표본·⑧법리앵커·복수피고 분기·분량 자기검증 추가.)

## ① 프로세스 (외울 순서)

0. **도구 선언**: 웹검색 되나? 안 되면 판례·조문은 `[검증필요]`만, 사실 포섭·논증으로 승부.
1. **문제 정독**: 사실관계 + 소장/공소장 + 별첨.
2. **쟁점·법리**: 쟁점 도출 → 쟁점별 조문·판례 검증(정밀 인용). ※사실관계 표는 필요할 때만 따로 뽑는다(`초기자료`).
3. **서면 작성**: 정형(④) + 다단계 번호, 각 논점 = 법리→포섭(사실 적용)→소결.
4. **형식 맞추고(⑥) → 점검 → 제출.**

## ② R 핵심 5

기록 한정(출처 괄호) / 실재 판례만(검증, 무검색=`[검증필요]`) / 원문 표지어·연속 인용 / 자기 생성물 재인용 금지 / 법원 문체("~입니다").

## ③ 자주 오류 5

합계 구성 명시 / 공부상 상태 모순 용어 금지 / 절차행위 대상 명시 / 주술 호응(대비 "~인 반면 ~") / 대시(—) 대신 "즉, A·B·C 중 어느 때에도".

## ④ 서면 정형 + 골격

- **정형**: 제목("준 비 서 면"/"변 론 요 지 서") → 사건·당사자·대리인 → "위 사건에 관하여 ~ 다음과 같이 변론을 준비합니다" → **- 다 음 -** → 본문 **1.→가.→1)→가)→①**(소표제는 결론 문장형) → 결론 정형 → 날짜 → 명의 → "○○법원 제○○부 귀중".
- **골격(한 줄)**:
  - 민사 준비서면(원): 청구원인 쟁점별 주장 → 예상 항변 반박 → "청구취지와 같은 판결을…"
  - 민사 준비서면(피): 청구원인 인부(인정/부인) → 항변 → 재반박 대응 → 결론
  - 형사 변론요지서(변): 공소사실별 → 증거능력·증명력 → 구성요건 부정 → 위법성·책임 조각 → (예비)정상 → "무죄를…"
  - 형사 의견서(검): 공소사실별 → 증거 → 구성요건 충족 → 예상 항변 반박 → "유죄·구형"
  - 가사 이혼: 청구취지(이혼·분할·위자·양육) → 파탄사유(§840 각 호) → 재산분할(기여도) → 친권·양육(자녀 복리) → 결론
- **공통**: 상대 최강 논거부터 반박, 불리 판례는 사실차이/후행판례로 적용 배제, 핵심은 다중 안전망("설령 ~하더라도"). **지위 미정이면 양측 모두** 작성. **복수 피고·복수 청구**: 피고별 대단원(1./2.) → 피고 내 주위적 가./예비적 나.

## ⑤ 인용 형식 / 검색처

- 판례 `대법원 2014. 5. 16. 선고 2011다24555, 24562 판결`(병합=콤마) / 기록 `[《문서명》 p.X | "발췌"]` / 사실 `(사실관계 제6항)`·`(별첨2 갑구 순위11번)`
- 검색: 조문 law.go.kr / 판례 glaw.scourt.go.kr(사건번호 직접 1순위) / 헌법 isearch.ccourt.go.kr / 행정해석 moleg.go.kr

## ⑥ 서면 형식 (가인 — 워드 작성→한글 수정)

- 제출 파일 **HWP/HWPX**. 워드(docx)로 쓰고 **한글에서 수정·저장·매수 실측**.
- A4 / 여백 상하좌우 20mm / 본문 맑은 고딕·명조 12pt(제목 14pt) / 줄간격 160% / 양쪽 맞춤.
- **20매 이내**(가변, 지시문 우선). 과소작성도 감점.
- 초과 시 여백·줄간격·글꼴 손대지 말고 **자구 압축**만.
- 분량 점검: 쟁점별 배분표 + 자수→매수 추정(약 1,200~1,400자/매), 최종 매수는 한글 실측.
