# 판례 탐색·인용 전략 (가인 기록형, 2026-06-20)

> 스킬 Phase 2·참고서면 C-4·마스터 검색처의 **상세판**. 우수답안 패턴 추상화 + 실무 검색 룰. 정확성(검증)이 최우선 — 날조 0.

## 1. 검색 순서 (위→아래)
1. **사건번호 직접조회(1순위)**: 번호가 있으면 korean-law-mcp로 직접 조회 → 판시·선고일·법원 1:1 확인
2. **키워드 축소검색**: 핵심어로 검색 후 좁힘 (키워드 2단어는 0건 흔함 → 단어 수 줄여 재시도)
3. **동의어·상위개념 확장**: 누출↔유출, 추심↔압류, 시효중단↔상위개념(증거능력 등)
4. **결과 상단 유관 사건명 훑기**: 연관 판례명·참조판례에서 대표·전원합의체 식별 (더 직접적·최신 판례 발견 잦음)
5. **보유자료 대조**: `sync/wiki/쟁점`·`outputs/02_cards`·동일사건 우수답안 (참고일 뿐, **원문 재확인**·순환인용 금지)
6. **WebSearch site 한정**: law.go.kr·glaw.scourt.go.kr 등 신뢰 도메인으로 한정

## 2. 판례 층화 (쟁점당 복수로 두께 확보)
- **정의판례 → 포섭판례 2단**: 법률용어 기준을 정면 설시한 판례로 세운 뒤 사실 포섭. 정면 판례 없으면 "명시 판례 없으나" + 유사·개정 전 동일개념 판례 취지 차용
- **원칙 → 예외 → 예외부적용 3단**(증거능력 등): 원칙(전합) → 예외 요건판례(현행성·긴급성·상당성, 2차증거 인과 희석) → 사안은 예외 미충족 포섭
- **위계 내림차순**: 전합 > 대법원 > 하급심(다수례로 정착성 보강) > 행정규칙·고시·예규·학설·기관결정
- **동일판례 다른 쟁점 재활용** + "위 ○.○.항에서 본 바와 같이" 내부 교차참조로 중복 절약
- 다수의견 불리 시 **전합 소수의견·유사제도 유추**(유리 방향만)로 흠결 보충하되 "소수의견"·"유추"임을 명시

## 3. distinguishing (유리한 구별) 패턴
당사자 지위 차이 / 보호법익·범죄성질 차이 / 제도 본질 차이 / 권리성질 분리 / "가사 ~하더라도" 복수분기 / 선례 ratio를 좁게 재구성해 사정거리 제한 / 상대 유리 법리 인정 후 "특별한 사정" 유보로 사안 포섭

## 4. 인용 표기
- **사건번호**: 본문 단정 끝 괄호 `(대법원 YYYY. M. DD. 선고 NNNN다NNNNN 판결)`. 복수는 쉼표 병렬 + "등". 병합사건 콤마(`…다24555, 24562`). 헌재 `(헌법재판소 YYYY. M. DD. 선고 YYYY헌마NNN 결정)`
- **취지 우선·직접인용 선별**: 대부분 "~판시한 바 있습니다"(취지요약+사건번호). **결정적 문구만** 따옴표 직접인용(원문 연속부분) + 직후 사건번호
- 학설(주석서 권·쪽·집필자)·고시·예규·기관결정도 위치까지 명시
- 노트 환원 시 #35 백링크(`[[대판 YYYY.M.DD, 사건번호]]`)로 변환 가능

## 5. 검증 (정확성 — 최우선)
- **2단 표기**: `검증완료`(번호·선고일·판시취지 1차소스/MCP 원문 대조 일치) / `부분검증`(번호·선고일 일부만, 또는 취지만 확인) / `검증필요`(확인 불가)
- **판시-사건 1:1 귀속**: 한 사건번호에 이질 판시 여러 개 묶지 말 것. 같은 법리 복수판례면 각 번호 개별 단정에 분리 표기
- 번호·선고일·법원·종류 korean-law-mcp 검증(#13), 불일치 시 `[불명확: 후보1/후보2]`(#6)
- 원문 미확보 시 `(원문 미포함)`(#5), 위치 추정 금지(#4). 검증 불가 단정은 삭제(#2)
- **검증완료만 본문 직접인용 / `[검증필요]` 후보 사건번호는 본문 노출 금지**(쟁점표·메모에만)

## 6. 무검색 폴백 (오프라인·MCP 불가)
보유자료의 확인된 판시만 "참고(미재검증)"로 사용 / 사건번호 불확실 시 **창작 말고 `[사건번호 확인필요]`** / 판례 의존↓·조문·요건 중심 전개("판례 취지상"·"일반적으로", 단정 회피) / 미검증은 `검증필요` 태그로 후속 큐 / 확인 불가 시 "소스에서 확인할 수 없습니다"

## 7. 주의 (날조·오류 차단)
- **과잉귀속**: 검색 상단이어도 쟁점과 무관하면 끌어오지 말 것(ratio가 본 쟁점을 다루는지 확인 후 귀속)
- **오인용**: A사건 번호에 B판시 붙이는 오류 금지(판시-사건 1:1 검증)
- **창작법리**: 가짜 판례·사건번호·조문·고시번호 = 최악. 그럴듯한 형식의 가짜 인용 주의
- 우수답안 verbatim 복사 금지(주최측 자산) / 하급심·소수의견을 확립 판례처럼 과장 금지 / 산출물 순환인용 금지(#46) / **유추는 유리 방향만**(불리 유추 = 죄형법정주의 위반)
