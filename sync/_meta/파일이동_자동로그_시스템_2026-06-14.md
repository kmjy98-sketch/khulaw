# 파일 이동·이름변경 자동 로그 시스템 (구축 보고 2026-06-15)

> 모든 파일/폴더 이동·이름변경·복사·trash 이동을 단일 마스터 로그(`.agent/file_ops_log/master.{csv,jsonl,md}`)에 자동 기록하는 표준 시스템.

---

## 1. 표준 매니페스트 형식

1작업 = 1행. 기존 이동 매니페스트(sha256·size·verified 패턴)와 정합되도록 정의.

| 필드 | 타입 | 의미 |
|---|---|---|
| `timestamp` | ISO 8601 | 로컬 시간, 초 단위 |
| `operation` | enum | move / rename / copy / delete-to-trash |
| `source_path` | str | 원본 절대경로 |
| `dest_path` | str | 대상 경로 또는 신규 이름 |
| `size_bytes` | int | 파일 크기 |
| `sha256` | str | 무결성 해시(이동 후 기준) |
| `task_id` | str | 세션 ID 또는 메모 |
| `reason` | str | 이동 사유 1줄 |
| `verified` | bool | 이동 전후 sha256 일치 여부 |

**3개 형식 병행 저장**:
- `.agent/file_ops_log/master.csv` — Excel·Google Sheet 호환(신규 생성 시 BOM)
- `.agent/file_ops_log/master.jsonl` — 기계 처리·재구성
- `.agent/file_ops_log/master.md` — 사람 가독(행 누적 시 `master_YYYY-MM.md` 분할 권고)

---

## 2. 헬퍼 스크립트

| 파일 | 환경 | 기능 |
|---|---|---|
| `.agent/scripts/log_file_op.py` | Python | sha256·size 계산 → 3개 형식 동시 append. `--execute` 시 이동 실행+전후 해시 검증 |
| `.agent/scripts/log_file_op.ps1` | PowerShell | 동일 기능(Windows 네이티브, `Get-FileHash`·`Move-Item`) |

**두 가지 사용 모드**:
- **방법 A (권장)**: `--execute` — 사전 sha256 → 이동/복사 → 사후 sha256 대조 → 로그를 원자적으로 처리
- **방법 B**: `mv`/`Move-Item` 으로 이동 후 `--execute` 없이 로그만 보충(대상 존재 시 자동 무결성 확인)

**안전장치**:
- 공유드라이브(`0.공유드라이브/`) 경로는 이동·쓰기 차단(#16-B) — exit 2
- 대상이 이미 존재하면 덮어쓰기 방지 후 중단
- sha256 불일치 시 경고 출력 + `verified=false` 기록

**검증 테스트(2026-06-15)**: 임시 파일 move 라운드트립 → csv/jsonl/md 3개 형식 정상 append, `verified=OK` 확인. 테스트 흔적은 `_trash/2026-06-15/`로 이동.
