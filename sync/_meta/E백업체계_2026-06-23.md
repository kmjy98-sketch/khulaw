## 4. 신설 절차 (★사용자 / ☆Claude Code)
### A. 클라우드(권장 — 오프사이트) : rclone copy → Google Drive 백업 폴더
1. ★ **rclone 설치**: `winget install Rclone.Rclone` (또는 rclone.org 다운로드 후 PATH).
2. ★ **remote 구성(OAuth)**: `rclone config` → `n`(new) → 이름 `gdrive` → `drive` → 브라우저 인증(사용자 직접, 글로벌 §5·§7). scope는 `drive`(전체) 또는 `drive.file`.
3. ☆/★ **백업 실행**: `.agent/scripts/backup_vault.ps1 -Target rclone -RcloneRemote "gdrive:법학볼트_백업"` (기본 `-DryRun`; 검토 후 `-Execute`).
4. ☆ **검증**: 실행 후 `backup_inventory.py` 재생성 대비 + rclone 로그 transferred/errors 확인.

### B. 외장 HDD(대안 — 인증 불요, 오프사이트는 분리보관 시)
1. ★ 외장 HDD 연결(예 `F:`).
2. ☆/★ `.agent/scripts/backup_vault.ps1 -Target robocopy -Dest "F:\법학볼트_백업"` (기본 `-DryRun`; `/MIR` 미사용).

### C. 텍스트(이미 존재) : git → GitHub
- 미커밋 변경 커밋 + push(외부서비스 → **명시 승인 후**, 글로벌 §5). `add -A` 금지(`.gitignore` 신뢰하되 비밀 재확인).
- (선택) `.git` 16GB 비대 정리 = 별도 과제(BFG/filter-repo로 과거 바이너리 제거 — 위험작업, 후속).
