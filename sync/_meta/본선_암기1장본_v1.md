# 본선 암기 1장본 — 기록형 서면 (v1, 2026-06-18)

> 외워서 본선에서 ①AI를 빠르게 통제하거나 ②AI 없이 직접 쓰는 뼈대. `본선_복붙마스터_v1.md`의 발췌 압축(수정은 마스터부터). A4 1장 분량.

## ① 프로세스 (외울 순서 — 이게 핵심)

0. **도구 선언**: 웹검색 되나? 안 되면 → 판례·조문은 전부 `[검증필요]`로만, 사실 포섭·논증으로 승부.
1. **기록 정독** (100면 넘으면 핵심 우선 + 표적 정독)
2. **사실관계 정리 5종** ← 가장 배점 큰 단계
   - A 기록목록표(순번·문서명·작성자·작성일·증거번호)
   - B 타임라인(시간순, 행마다 **출처** 병기, 다툼 사실 **★**)
   - C 당사자 2열 대비표(`원고/검사·피해자 측 | 피고/피의자 측`, 빈칸 `—`) + 다툼없는 사실은 위에 별도
   - D 증거 3분류(서증 / 인적 / 객관[CCTV·포렌식·의무기록])
   - E 진술 불일치표(같은 사실 문서 간 차이 → 신빙성·반대신문)
   - ※ "다툼 없음" 명시되면 C·E 생략
3. **쟁점(≤6) + 조문·판례 검증표** (쟁점 | 조문 원문발췌 | 판례 사건번호+판시 | 출처)
4. **서면**: 쟁점 → 법리 → **포섭(문장마다 기록 인용)** → 소결
5. **점검 후 제출**

## ② R 핵심 5 (외울 규칙)

1. **기록 한정** — 기록에 없는 사실 창작·가정 금지. 사실 주장마다 출처 괄호.
2. **실재 판례만** — 확인 안 된 판례·조문 인용 금지. 무검색이면 `[검증필요]`.
3. **원문 정합** — 직접 인용("…")은 연속 부분만. 풀어 써도 핵심 표지어 유지, 충분/필요조건 안 뒤집기.
4. **순환 인용 금지** — 내가 만든 요약을 다음 근거로 재인용 금지. 항상 원 기록·원 판결문.
5. **법원 문체** — "~입니다". "조사해보니/생각된다/~인 것 같다" 금지. 한자→한글.

## ③ 자주 잡힌 오류 5 (제출 전 점검)

- 합계 금액 **구성 명시**("원리금 등 합계 4억 6,900만" / "원리금 4억 6,900만"은 ✕)
- 공부상 상태와 모순 용어 ✕(지목 '답'을 "나대지" ✕ → "건물 없는 토지")
- 절차 행위 **대상 명시**("그 임의경매개시결정에 대하여 즉시항고하지 않았다")
- 주어-술어 호응(무주어 술어 ✕), 대비는 "위 사안은 ~인 반면 이 사건은 ~"
- 대시(—) 삽입구 ✕ → "즉, A·B·C 중 어느 때에도"

## ④ 서면 골격 (유형별 한 줄)

- **민사 소장**: 청구취지 → 청구원인(요건사실: 권리근거→장애·소멸·저지) → 입증방법 → 결론
- **민사 답변서·참고서면**: 청구취지 답변 → 청구원인 인부(인정/부인) → 항변 → 상대 반박 → 결론
- **형사 변호인의견서**: 공소사실 요지 → 쟁점별 의견[법리→포섭→소결] → 정상관계(양형) → 결론
- **가사 이혼**: 청구취지(이혼·재산분할·위자료·친권/양육) → 파탄사유(민법 제840조 각 호) → 재산분할(대상·기여도) → 친권·양육(자녀 복리) → 결론
- **검토의견서**: 질의 → 쟁점별 검토 → 결론·조치
- 공통: **상대 최강 논거부터 반박**, 불리 판례는 회피 말고 사실관계 차이로 적용 배제

## ⑤ 인용 형식 / 검색처

- 판례: `대법원 YYYY. M. DD. 선고 NNNN다XXXXX 판결` · 헌재: `헌법재판소 YYYY. M. DD. 선고 YYYY헌마XXX 결정`
- 기록: `[《문서명》 p.X | "발췌"]` (작성자·차수 병기)
- 검색: 조문 law.go.kr / 판례 glaw.scourt.go.kr(**사건번호 직접 1순위**, 키워드는 단어 줄여 재시도, 상단 유관 사건명 훑기) / 헌법 isearch.ccourt.go.kr / 행정해석 moleg.go.kr

## ⑥ 퓨샷 미니 (형식 표본 — 실제 인용은 검증 후)

- 타임라인: `| 2026.1.12 | 원고가 피고에게 4억 대여 ★ | 《소장》 청구원인 제2항 / 갑1 |`
- 쟁점표: `| 변제 여부 | 민법 제○○○조 "원문…" | 대법원 …다… 판결[검증요] | glaw |`
- 포섭 문장: "피고는 변제하였다고 주장하나, 이를 인정할 증거는 을나1뿐이고 그 내용은 …에 불과하므로(《답변서》 p.3), 변제 사실은 인정될 수 없습니다."
