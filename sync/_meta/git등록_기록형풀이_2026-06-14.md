## §6 push 권고

- **현재 push 안 함** (요청대로 로컬 커밋까지만).
- 리모트 미설정 상태. push하려면:
  1. 원격 저장소 생성 — **비공개(private) 필수**. 기록형 자료(고소장·진술조서·의무기록 등)와 학습 자료가 포함됨.
  2. `git remote add origin <URL>` → `git push -u origin master`
  3. push 전 재확인: 구글 드라이브가 GitHub 데스크톱 등 다른 클라이언트와 충돌하지 않는지, .gitignore 차단 범위가 충분한지.
- 외부 서비스 전송(push)은 명시 승인 필요 작업(CLAUDE.md 5장). 진행 시 별도 지시 요망.
