## 0. 두 갈래 소스
- **(가) 사례형 파생**: 사례형 B(포섭 cloze)에서 **사안 고유명사 제거 → 일반 명제화**. 자동 파생.
- **(나) 객관식/암기 교재**: 쟁점노트·신민사·논민소·헌법300·강성민·유니온·compact형총·반반형법 등. 직접 카드화.

## 1. 판례·법리 3분류 (강약 차등)
| 분류 | 내용 | 빈칸 방식 | 강약 |
|---|---|---|---|
| **일반론** | 개념·정의·기본 요건 | 핵심어 1~2개 얕게 | **약**(기초·반복) |
| **포섭용** | 사안 적용 논거·기준 | 논거 단위 빈칸(①②③ 넘버링) | **강**(배점핵심) |
| **예외용** | 예외판례·부정례·한계 | 결론(부정/예외) 빈칸 강조 + 원칙대비 | **강**(역방향 함정) |

## 2. 강약조절 신호 (구체)
- **원문 볼드/밑줄 = 강**(핵심 기재례→빈칸 다층), 평문 = 약(빈칸 최소).
- **요건 = 번호 부여(①②③④) + 키워드 클로즈**(요건명 각각 빈칸). 요건 개수 앞면 명시.
- **난이도 태그**: A(자주출제·예외·잘틀림)→강·짧은 간격 / B(기초 일반론)→약·표준 간격. (FSRS는 Anki, 우리는 태그만)

## 3. 카드 유형
- **요건/정의 cloze**: 키워드 클로즈(요건명·정의 핵심어 각각).
- **판례 일반론 cloze**: 결론 법리어 빈칸(원문 볼드 기준).
- **OX**(객관식 선지): 앞=선지 / 뒤=O·X + 근거 1줄. 함정선지는 결론술어 빈칸 변형 가능.
- **답안형식 정제문구**(반반형법형): 실전 답안에 그대로 현출하는 정제 문구를 뒷면에. 카드가 곧 답안 문장이 되도록(키워드 클로즈).

## 4. 빈칸 경계 (09 NLP)
체언/결론술어 종결, 조사·어미 밖, 성분 비걸침, 주변 단서 유추 차단. "없다/않는다" 결론이면 빈칸.
