# 적응형 학습 실연동 글루 스펙

## 목적
`_study_session_runner.SessionRunner`의 주입 훅(provider/panel/strengths/graph)을 **컨테이너 stub → 실 로컬 시스템**으로 바인딩. 파일럿(합성)·데모(cp949 가드 추가)는 검증 완료 — 본 문서는 실연동 구현 지침. PR#1 적응형 학습의 마지막 잔여(①).

## 어댑터 훅 4종 바인딩

### 1. `provider(node) → Problem(node, ptype, question, answer)`
- **소스**: `socratic-core` + `.agent/state/problem_index.json` + `outputs/02_cards_v37/*.md`(주제::태그)
- **매핑**: node(쟁점=`주제::`) → problem_index에서 해당 주제 문항 검색 → 있으면 그대로, 없으면 socratic-core가 카드에서 생성
- **ptype**: 카드 속성으로 결정 — OX/Cloze=`ox`/`cloze`(객관), 사례형=`case`
- **answer**: OX/Cloze=정답키(`grade_objective` 정확매칭용), case=`None`(panel 채점)
- **제약**: 문항은 카드/problem_index 소스에서만(#1), 생성 시 #13 생성후검증

### 2. `panel(problem, 답안) → (correct: bool, weaknesses: [{text, review_type}])`
- **소스**: `.claude/workflows/case-answer-panel-grade.js`(사례 전용)
- **매핑**: problem(사례)+답안 → 3채점관 패널 → correct(등급 다수결) + weaknesses(포섭 실패코드 E1뭉갬/E2결론직행/E3연결단절·약점 합집합)
- **제약**: 해설 원문 절대기준(#1, 뒤집기 금지), 채점은 초벌·참고(LLM 비결정성)

### 3. `strengths` (초기 node 강도) ← `learning.json` / `srs_log.json`
- **매핑**: srs_log 항목의 `ef`·`repetitions`·`lapses` → node 강도(0~1). 고안정=고강도(덜 출제) / `weak_points`=저강도(우선 출제)
- **갱신**: `finish()` 후 **사용자 확정 시에만** 기록(#16 silent write 금지) — `log_result.py --srs`

### 4. `graph` ← 실 신호 5종 (`build_graph` 입력 SIGNALS)
- `discover_related_issues`(render_case_answer_review.py) + `crossref_all_subjects.py` + `연계::` 태그 + wiki 백링크 + problem_index 공출현 → SIGNALS dict → `build_graph`(**과목분리 #35**)
- **+ co-fail 강화**: 세션 이력의 공동오답(`accumulate_cofail`) → `reinforce_edges`(학습자 혼동 클러스터 강화 = "신경망"이 개인에 적응하는 부분)

## finish() → SRS 제안 → 기록
`srs_proposals[{node, kind(study/review), review_type, 초기_due}]` → spaced-repetition. `review_type`별 초기 due는 `_srs_review_type.initial_due_offset`. **기록은 사용자 확정 시**(silent write 금지 #16, 로그 #16-C).

## 데이터 의존 (런타임 산출물 — 현재 비어있음)
실연동은 다음이 채워져야 작동: `problem_index.json`(문항 인덱스)·`learning.json`(강도·약점)·`srs_log.json`(이력)·실 쟁점그래프(5신호). → 카드→TSV/문항 빌드 1회 + 드릴 가동이 선결(공통 근본원인, [[신경망_ML_복습기법_연구_2026-06-25]] 참조).
