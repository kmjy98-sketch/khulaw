## 1. 옵시디언+안키 방법론 타당성 (외부 조사)

- 능동 인출·분산 반복은 확립된 학습과학(Roediger & Karpicke 2006). FSRS는 SM-2보다 정확(공식 벤치마크). "리뷰 20~30% 절감"류 수치는 블로그성 — 방향성만.
- 원자화는 맥락 선행 전제(Wozniak MIP). 법학 사례형은 "맥락이 곧 지식" → 과도한 원자화 위험. 현 `case_problem_card`(사안+설문 통째 보존)가 이미 이를 통제.
- "문제화로 카드화를 대체"는 절반만 옳음: 통째 빈칸화=퇴보(가짜 회상), 사례형 쟁점생성 드릴=옳음.
- 구조 보완책: AnkiConnect ID매핑(=apkg guid가 이미 대체), Advanced URI block 딥링크(저비용·보류), Image Occlusion(체계도 소수). 라이브 양방향 플러그인 전환=기각(비용·충돌).

## 3. 사례형 채점 — 해설 기준 LLM 패널 채점

- **방식(확정)**: 해설 원문 전체를 제시하고 LLM이 답안과 비교. 필드분해·키워드매칭·판례번호매칭 **없음**. 해설=절대 기준(#1, 뒤집기 금지). 감점엔 해설 발췌(#3), 해설 외는 무가점. 헌법 결론-예외는 후순위.
- **채점관 = LLM**(파이썬 매처 아님). 루브릭 가중치는 LLM의 관점.
- **패널**: 채점관 3명 병렬 → 등급 다수결 + 약점 합집합 + 불일치 표출. 실증 가치: 합의=신뢰, 약점 합집합=완전성, 노이즈 필터. (불일치는 강한 grounding에선 드물지만, 검증 실행에서 2:1 갈림→`검토필요` 표출됨.)
- **구현·검증**: `.claude/workflows/case-answer-panel-grade.js` end-to-end 성공.

## 9. 적응형 학습 루프 (2026-06-23 신규 설계·파일럿)

**문제의식**: SRS·패널이 약점 "리스트"만 주고 능동 인출(문제 풀이)을 안 줌. `socratic-core`는 이미 문제를 주는데 그 둘이 배선 안 됨.

**설계(사용자 확정)** — "신경망" = 쟁점 그래프 위의 전파 활성화(가중 그래프+노드 강도+헤비안식 강화, 진짜 NN 아님):
- 노드=쟁점, 엣지=연관쟁점(가중), 강도=아는 정도.
- 틀리면 → 약한 1-hop 연관쟁점 강화(≤`related_k`) + 본인 재드릴. 맞으면 강도↑.
- baseline 큐로 범위 내 전 쟁점 ≥1회("한바퀴씩"), 마스터 제외.
- **cutoff**: 같은 쟁점 fails≥N → 무한드릴 중단하고 **"이 파트 공부하라" 리턴**(교재/wiki 위치) — 토끼굴 차단.
- 채점: **OX/Cloze=정확매칭**(`grade_objective`), **사례=패널**(`case-answer-panel-grade`).

**파일럿(검증)**: `.agent/scripts/_study_engine.py`(StudyEngine) + 테스트 6종 + `_demo_study_session.py`. 합성 데이터로 전 로직(전파활성화·cutoff·baseline·채점분기) 검증. 순수 로직만 — 실연동 후속.

**실연동 5개 연결점(전부 기존 자산):** ①엣지=`discover_related_issues`+`crossref`+`연계::` → `쟁점_graph.json` 생성기 ②전달=`socratic-core` ③채점=`grade_objective`/패널 워크플로 ④강도=`learning.json`+`srs_log`(갱신은 사용자 확정) ⑤공부권고 위치=wiki/`alignment`. 실 state가 H:\·gitignore → 실연동은 로컬.
