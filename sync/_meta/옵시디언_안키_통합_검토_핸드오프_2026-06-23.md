## 1. 옵시디언+안키 방법론 타당성 (외부 조사)

- 능동 인출·분산 반복은 확립된 학습과학(Roediger & Karpicke 2006). FSRS는 SM-2보다 정확(공식 벤치마크). "리뷰 20~30% 절감"류 수치는 블로그성 — 방향성만.
- 원자화는 맥락 선행 전제(Wozniak MIP). 법학 사례형은 "맥락이 곧 지식" → 과도한 원자화 위험. 현 `case_problem_card`(사안+설문 통째 보존)가 이미 이를 통제.
- "문제화로 카드화를 대체"는 절반만 옳음: 통째 빈칸화=퇴보(가짜 회상), 사례형 쟁점생성 드릴=옳음.
- 구조 보완책: AnkiConnect ID매핑(=apkg guid가 이미 대체), Advanced URI block 딥링크(저비용·보류), Image Occlusion(체계도 소수). 라이브 양방향 플러그인 전환=기각(비용·충돌).

## 3. 사례형 채점 — 해설 기준 LLM 패널 채점

- **방식(확정)**: 해설 원문 전체를 제시하고 LLM이 답안과 비교. 필드분해·키워드매칭·판례번호매칭 **없음**. 해설=절대 기준(#1, 뒤집기 금지). 감점엔 해설 발췌(#3), 해설 외는 무가점. 헌법 결론-예외는 후순위.
- **채점관 = LLM**(파이썬 매처 아님). 루브릭 가중치는 LLM의 관점.
- **패널**: 채점관 3명 병렬 → 등급 다수결 + 약점 합집합 + 불일치 표출. 실증 가치: 합의=신뢰, 약점 합집합=완전성, 노이즈 필터. (불일치는 강한 grounding에선 드물지만, 검증 실행에서 2:1 갈림→`검토필요` 표출됨.)
- **구현·검증**: `.claude/workflows/case-answer-panel-grade.js` end-to-end 성공.

## 5. ⚠️ 잔여 문제·리스크 감사 ("다른 문제 없는지")

1. **빌더 guid 패치 로컬 미검증** — 컨테이너에 genanki·카드파일 없음. 로컬에서 ①빌드 후 `_apkg_report` 총 19,629장 유지 ②카드 수정→재임포트 회독 보존 ③중복 0 확인 필수. `seq`는 in-place 편집엔 안정하나 카드 **삽입/삭제/구조변경 시 밀림**(필요 시 `<!-- uid: 약어-NNNN -->`로 고정).
2. **해설 OCR 무결성** — 사례집 OCR은 "미교정"(#34 anchor 위조 위험). 채점 기준인 해설이 OCR 오류를 담을 수 있음 → 고비중 채점 전 해설 원문 확인 권장. ("해설은 틀리지 않는다"는 내용 차원이고 OCR 손상은 별개 리스크.)
3. **LLM 채점 비결정성** — 같은 답안이 실행마다 등급 다를 수 있음(수동 3/3 △ vs 워크플로 2:1). 패널이 완화하나 제거 못함 → 채점은 "초벌·참고". 불일치는 `검토필요`로 표출.
4. **SRS 실기록 미통합** — 워크플로는 복습등록안까지만(silent write 금지 #16 준수). `srs_scheduler.add_item(review_type=)` 통합 미구현. 실기록은 사용자 확정+로컬(state json H:\).
5. **`log_file_op.py` H:\ 하드코딩** — 컨테이너 실행 시 또 `H:\내 드라이브` 리터럴 경로 오염(이번에 1회 발생·정리함). **컨테이너에서 파일이동 헬퍼 실행 금지.**
6. **outline_recall 이중 due(#4 미결)** — 문서상 D+1(쟁점못찾음)·D+3(목차누락) 모호. 현재 D+3 채택, 사용자 확정 대기.
7. **PR #1 범위 비대** — guid 파일럿으로 시작했으나 폐기파일·패널워크플로·핸드오프·스킬편집이 누적. 머지 전 PR 설명 갱신 또는 분리 검토.
8. **딥링크(Q3)·헌법 결론-예외** — 둘 다 설계만, 미구현(보류).
9. **상태파일 부재 검증 항목** — `problem_index.json` 충전도 등은 로컬에서만 확인 가능(컨테이너에 state json 없음·gitignore).
10. **`render_case_answer_review.py` 혼동 소지** — `provisional_grade`(coverage)는 채점 본체 아님(SKILL에 명시). 잔존하므로 오해 주의.
