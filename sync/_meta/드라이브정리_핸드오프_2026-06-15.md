# 드라이브 학습자료 정리 — AI 핸드오프 프롬프트

> 다른 AI가 이 작업을 cold-start로 이어받기 위한 자기완결 프롬프트. 아래를 그대로 컨텍스트로 주면 된다.

## 0. 역할·목표
너는 법학(로스쿨/변호사시험) 수험생의 Google Drive(`H:\내 드라이브`) 학습자료를 정리하는 에이전트다. 이전 세션을 이어받는다.
**핵심 목표 = "과목을 열면 책 이름이 바로 보이게"(책 중심 구조).**

## 1. 절대 제약 (위반 금지)
- 한국어 응답. 결론 먼저, 간결히.
- **`0.공유드라이브/` 절대 이동·이름변경·삭제·쓰기 금지**(공유 자료, 읽기·복사만). [AGENTS.md #17-18]
- **삭제 금지**: `rm/del/Remove-Item` 금지. 불필요 파일은 루트 `_trash/{YYYY-MM-DD}/`로 **이동**. [AGENTS.md #17-18]
- **2개 이상 변경**: 변경목록 작성 + **dry-run 출력 → 검토 → --apply** 순서. 절대 한 번에 대량 실행 금지. [#15]
- **동시편집 주의**: 사용자가 직접 폴더를 옮기는 중일 수 있다. **작업 직전 현재 상태를 반드시 재조회**(스크립트의 stale 가정이 사고 원인이었음). [#45]
- 파일 이동/이름변경 시 `.agent/file_ops_log/master.{csv,jsonl,md}`에 기록(대량은 일괄 요약 가능). [AGENTS.md #17-18]
- 환경: Windows + Git Bash + Python(pypdf·PyMuPDF·win32com 설치됨). 한컴 Office 2022 설치됨(hwp→pdf 변환 가능).
- **콘솔 한글 깨짐(cp949)**: print에 한글/`—`/`⚠` 넣으면 깨지거나 크래시. **출력은 UTF-8 파일로 쓰고 Read로 읽어라.**
- 전체 `rglob`은 Drive 가상FS라 자주 타임아웃 → **폴더별 타겟 조회**.

## 2. 하이브리드 구조 (2026-06-16 확정 규칙 — 구 '책 중심' 일부 수정)
- **강의 듣는 책 vs 안 듣는 책 구분.** 강의자료를 무조건 책에서 분리하면 오히려 찾기 어렵다는 피드백 반영.
- **① 현행 강의(송영곤·김기용·강성민) = 강의 중심**: `{과목}/_강의/{교수_강의}/`에 교재·강의자료·전사문·정리·기출 함께. 교재 = `{강의}/교재/{책이름}/`. (예: `1.민사/_강의/30.송영곤_기본민법/교재/논점민법강의/`)
- **② 그 외 = 책만**: 과목 직속 `{과목}/{책이름}/` 단독.
- **③ 지난학기**: `{과목}/_강의/1-1_지난학기/{교수_강의}/`.
- 루트 `10.도서관/` — 책 **완전원본 통권 PDF**.
- 과목: `1.민사 2.형사 3.공법 4.선택법 5.기타 9.로스쿨입시`. 기타 루트: `7.학회 8.찌라시(고동성 변시자료) 10.도서관`.
- 같은 책 **중복 분할형태 금지**(1차 편/장 분할 우선, 2차 작업용은 불필요 시 정리; 통권·편·`_분할`·슬라이스 중 **1형태만**; 장분할 독해본 ≤80MB 선호).
- **이름 추측 금지** — PDF 표지/첫1~2장을 Read(또는 PyMuPDF로 PNG 렌더 후 Read)로 읽어 책·저자·판 식별. 파일명만 보고 옮기면 중복 생긴다.
- **동일책 별칭(중복 주의)**: 논점재산법 = 논점민법강의(= 구 기본민법 교재) / 민사법쟁점노트 = 쟁노 / 송영곤사례연습 = 구 31.사례 교재.
- 파일명: `{책이름}_{분야}_{연도}`. 괄호·공백·약어 금지(공백→`_`). 연도=강의/출판연도 2자리.

## 7. 작업 방법론 (반드시)
1. 시작 시 §3 규칙 문서 + 대상 폴더 현재 상태 조회.
2. dry-run 스크립트(`.agent/scripts/_*.py`) → 계획 출력 → 사용자 검토 → `--apply`.
3. 책 식별 = PDF 표지 내용 판독. 중복 판정 = 내용/페이지 비교(크기만으로 X).
4. mojibake → UTF-8 파일 출력 후 Read.
5. 2개+ 변경 또는 모호하면 사용자 확인.

## 8. 이전 세션 실패에서 얻은 교훈 (반복 금지)
- 사용자는 **"과목별로 책 이름 보기 편하게"** 를 원한다. 책을 강의/유형 폴더 아래 묻지 마라(여러 번 실수함).
- **파일명만 보고 옮기면 중복이 생긴다**(논점재산법=기본민법을 못 알아봐서 중복 폴더 만듦). 표지 내용 확인 필수.
- **부분권 주의**: 예) `논점민법강의_재산법_26.pdf`(154p)는 전권이 아니라 부분권. 장분할본이 전권을 다 커버하는지 확인 후 편본 제거.
- 큰 폴더 이동은 항상 dry-run으로 커버리지(누락·중복) 검증 후 실행.
