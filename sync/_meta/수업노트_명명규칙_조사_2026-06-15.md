## §0 요약 (먼저 읽기)

- **핵심 발견**: 현재 워크스페이스에 **"주차(회차) 단위 수업노트"를 위한 일관된 명명이 없다.** 기존 "정리노트"는 모두 **시험 단위(중간/기말) 집계물**이고, 회차 단위는 전사문·RAG 추출물에만 존재한다.
- **지배 패턴**: `{과목}{호}_{강사}_{시기}_{유형}[_{변형}].md` (언더스코어 구분). 예) `민법1_강혜림_기말_정리노트.md`.
- **권고**: **옵션 B** 채택 — 기존 언더스코어 컨벤션을 계승하되 수업노트 계열에 한해 `W{NN}`(주차, 0패딩) + 표준 frontmatter 추가. 기존 파일 재명명 없음(마이그레이션 부담 ≈ 0).
- **결정 필요(§6)**: ①수업노트 저장 폴더 위치 ②frontmatter 키 언어(영문/한글) ③"1-1" 학기 라벨 정합성.

## §1 기존 패턴 분석 (실측 샘플)

### 1-A. 정리노트 계열 — 시험 단위 집계 (지배 패턴, 가장 많음)

| 파일명 | 분해 |
|---|---|
| `민법1_강혜림_기말_정리노트.md` | 과목호\_강사\_시기\_유형 |
| `민법1_강혜림_기말_정리노트_도표추가본.md` | …\_변형 |
| `민법1_강혜림_중간_암기장.md` | 유형=암기장 |
| `민법3_전경운_판례모음집.md` | 시기 생략, 유형=판례모음집 |
| `형법1_서보학_중간_정리노트_도표추가본.md` | 〃 |
| `헌법1_이진_기말_함정포인트_반복정리.md` | 유형 복합 |
| `헌법1_이진_중간_정리노트_도표추가본.md` | 〃 |

- **구조**: `{과목}{호}_{강사}_{시기}_{유형}[_{변형}].md`
- 과목호: `민법1 민법3 형법1 헌법1` (과목 약칭 + 학기 차수)
- 강사: `강혜림 전경운 서보학 이진`
- 시기: `중간 | 기말` (없으면 전체)
- 유형: `정리노트 | 암기장 | 학설판례_암기 | 판례모음집 | 객관식문제 | OX선지_암기 …`
- 변형(suffix): `도표추가본` 등
- 구분자: 언더스코어 `_` 통일. 한글 파일명. 확장자 `.md`.
- **성격**: 시험 대비 집계물이지 **수업 회차별 노트가 아님.**

### 1-B. 회차/part 수업정리 계열 — 세션 단위 (전사·RAG 한정)

| 파일명 | 분해 |
|---|---|
| `2-04_민법_송영곤_기본민법_수업정리_part04행위능력1_미성년자_법정대리인.md` | seq\_과목\_강사\_교재\_수업정리\_part{NN}{단원} |
| `5-10_민법_윤동환_기본강의_10회차_(필기)_p001-006.md` | seq\_과목\_강사\_교재\_{N}회차\_유형\_페이지 |

- **구조**: `{책ID}-{NN}_{과목}_{강사}_{교재}_{회차표지}_{단원키워드}.md`
- seq 접두(`2-04`, `5-10`)로 책별·회차 정렬. 회차 번호 + 단원 키워드 병기.
- **시사점**: 워크스페이스에 이미 **회차(part/N회차) 정렬 접두 관습**이 존재 → 수업노트 명명의 선례.

### 1-C. 전사문 계열 — ASCII 슬러그

| 파일명 | 분해 |
|---|---|
| `civ_kang_m1_1-1` (폴더) → `civ_kang_m1_1-1_corr.md` | subj\_instr\_book\_{주}-{교시} |
| `국제법_1-1_transcript.txt` | 과목\_{주}-{교시}\_transcript |

- 영문 슬러그(`civ kang m1`) + `{주}-{교시}` 좌표. 검색은 쉬우나 가독성 낮음.

### 1-D. 교안/슬라이드 계열 — 주차 접두

| 파일명 | 분해 |
|---|---|
| `10주_헌법기초이론-2.pptx` | {N}주\_단원 |
| `이진_헌법원리1_3주.pptx` | 강사\_과목\_{N}주 |

- **주차 접두 관습 존재.** 단, `10주`가 `1주`보다 앞서는 **0패딩 미적용 정렬 깨짐** 문제 관측.

### 1-E. sync 볼트 atomic 쟁점노트 — 토픽 단위

| 경로 | 분해 |
|---|---|
| `sync/노트/민법/총칙/의사표시_착오.md` | 과목/단원/쟁점 |
| `sync/노트/민법/총칙/표현대리.md` | 〃 |

- **구조**: `{과목}/{단원}/{쟁점}.md` (폴더 계층 + 쟁점명). frontmatter `tags:` 보유.
- 백링크·카드화 친화(atomic). 단 회차/강사/날짜 메타 없음 → 수업 흐름 추적 불가.

### 1-F. 워크플로우 정합

- `.agent/workflows/lecture-notes.md` = "수업노트 정리 워크플로우" 이미 존재. 출력은 frontmatter(`tags:`) + 각주 근거 구조.
- `study-notes/generate.py` 는 `--out {경로/파일명.md}` 를 **호출자가 지정**(자동 명명 규칙 없음) → 명명 표준을 사람이 정해 줘야 함.

## §3 권고안: **옵션 B** (1개 선정)

### 선정 사유

1. **기존 지배 컨벤션 계승** — `{과목호}_{강사}_…` 언더스코어·한글 파일명을 그대로 유지하여 학습 곡선 0. 정리노트(1-A)와 한 가족으로 읽힘.
2. **정렬 문제 해결** — 교안(1-D)에서 관측된 `10주<1주` 깨짐을 `W{NN}` 0패딩으로 제거. 파일 탐색기·Obsidian 모두 주차순 정렬.
3. **백링크 최적** — `[[민법1_강혜림_W03_의사표시]]`. 주제어가 끝에 있어 `[[…W03` 까지 입력 후 주제로 자동완성. #35 백링크 규칙과 충돌 없음(본문 내 `[[§XXX]]`·쟁점·판례 백링크는 그대로 사용).
4. **AI·카드·위키 친화** — 표준 frontmatter가 `study-notes`·카드화·위키 roll-up의 입력 메타를 제공. atomic 쟁점노트(1-E)로 분해 시 `subject/topic`이 그대로 분류 키.
5. **마이그레이션 0** — 신규 수업노트에만 적용. 기존 정리노트·암기장 재명명 없음 → 진행 중 D-task와 파일 충돌(#45) 없음, #16-C 이동로그 발생 없음.

### 명명 템플릿

```
{과목호}_{강사}_W{NN}_{주제}.md
```

- `과목호`: `민법1 민법3 형법1 헌법1` (기존 약칭 유지)
- `강사`: `강혜림 전경운 서보학 이진`
- `W{NN}`: 주차 2자리 0패딩 (`W01`…`W15`). 보강/특강은 `W03b` 식 접미.
- `주제`: 그 주차 핵심 단원/쟁점 1개(짧게). 복수면 대표 1개 + frontmatter `topics`에 나열.
- 구분자 `_`, 확장자 `.md`, 한글.

### 표준 frontmatter (권장: 영문 키 + 한글 값)

```yaml
---
subject: 민법1          # 과목호
instructor: 강혜림       # 강사
week: 3                 # 정수(파일명 W03과 일치)
date: 2026-09-15        # 실제 수업일 (정밀 조회용)
topic: 의사표시          # 대표 주제
topics: [의사표시, 착오]  # 그 주차 다룬 단원(선택)
type: 수업노트
tags: [민법, 총칙, 수업노트]
---
```

- 영문 키 권장 사유: 기존 `sync/노트`의 `tags:`·Dataview·study-notes 도구와 정합. (한글 키 선호 시 §6에서 선택 가능 — Obsidian 자체는 한글 키도 동작.)
- 본문 헤더: `# {과목호} W{NN} {주제}` 로 시작. 근거 각주는 lecture-notes 워크플로우 규칙(#3) 준수.

### 백링크·태그 권고

- 본문 내: `[[§107]]`(§10 이상만), `[[표현대리]]`, `[[대판 2008.9.11, 2008다32501]]` — #35 그대로.
- 표·각주·코드블록 안에는 백링크 금지(#35).
- tags: `과목 / 단원 / 수업노트` 3종 기본. 주차 태그는 frontmatter `week`로 대체(태그 폭발 방지).

## §6 사용자 결정 필요 항목

1. **저장 폴더 위치** — 셋 중 택1:
   - (가) 강사 폴더 하위 `1.민사/…/10.강혜림_민법1/수업노트/` (자료와 근접, 백링크는 볼트 밖)
   - (나) 볼트 집중 `sync/수업노트/{과목호}/` (백링크·Dataview 최적) — **권장**
   - (다) 기존 `sync/노트/{과목}/` 와 혼재 (단 atomic 쟁점노트와 성격 다름 → 비권장)
2. **frontmatter 키 언어** — 영문(`subject`…, 도구 정합) **권장** vs 한글(`과목`…, 가독성).
3. **"1-1" 학기 정합성** — 4과목(강혜림·전경운·서보학·이진)은 폴더상 `1-1_지난학기`에 위치. 본 과제는 이들을 "1-1학기"로 지칭 → 학기 라벨이 *현재*인지 *지난*인지 확정 필요(파일명/frontmatter `semester` 필드 포함 여부 결정).
4. **주제 다단원 주차 처리** — 한 주에 단원 2개 이상일 때 파일 1개(대표주제+`topics`) vs 파일 분할(`W03a`/`W03b`).
5. **교안 0패딩 정정** 여부(§4, 선택·별건).
