# 단독 프롬프트 묶음

본 폴더는 `H:\내 드라이브` 워크스페이스의 룰·스킬·워크플로우·메모리에서 **외부 의존(로컬 RAG, korean-law-mcp, .agent/state, Python 스크립트, 파일 자동 분류 등)을 모두 폐기**하고, **챗 모델 단독 사용에 필요한 핵심 원칙만 추출**한 프롬프트 모음입니다.

원본 자료 없이 Gemini(gemini.google.com) 또는 Claude(claude.ai) 단일 채팅에서 그대로 복사·붙여넣어 사용할 수 있습니다.

## 사용 방법

### A. 통합 프롬프트 (장기 학습용)

1. Gemini → "Gems" 만들기 → `gemini_법학_통합.md` 본문을 시스템 인스트럭션에 붙여넣기
2. Claude 웹 → "프로젝트" 생성 → 프로젝트 인스트럭션에 `claude_법학_통합.md` 붙여넣기
3. 이후 일반 대화처럼 질문. 모드 전환은 `[소크라틱]`, `[사례형]`, `[법리]`, `[OX]`, `[첨삭]`, `[리서치]` 태그로 명시.

### B. 시나리오별 프롬프트 (단발 사용)

1. 통합 프롬프트 없이 채팅 첫 발화로 시나리오별 파일 본문만 붙여넣기
2. 줄 바꿈 후 질문 본문 입력
3. 한 채팅창에서 다른 시나리오로 전환할 때는 새 프롬프트를 다시 붙여넣어 모드 명시

## 핵심 원칙 (모든 프롬프트에 공통)

1. **소스 근거**: 사용자가 본문에 붙여 넣은 자료(또는 검색해 온 자료)만 근거. 모델 외부 지식·추측·창작 금지.
2. **소스 미확인**: "소스에서 확인할 수 없습니다" 또는 "자료 부족—보류"로 표기. 합성 금지.
3. **인용 형식**: `[《문서명》 p.X | "정확한 발췌"]`. 위치 추정 금지.
4. **조문·판례**: 원문 우선. 조문번호·사건번호·선고일 정확. 불명확 시 `[불명확]`.
5. **사례형**: IRAC 또는 청구-항변 2열표(`| **원고(갑)** | **피고(을)** |`).
6. **외국어 금지**: 한자 표기 자동 한글 변환(甲→갑, 乙→을, 條→조).
7. **추론 비노출**: 내부 추론 과정은 출력하지 않고 결론·근거만.
8. **자체 생성물 재인용 금지**: 직전 응답에서 만든 합성 표현을 다음 응답의 출처로 인용하지 않음.

## 워크스페이스(H:\내 드라이브) 본 시스템과의 차이

| 항목 | 워크스페이스 | 단독 프롬프트 |
|---|---|---|
| 소스 검색 | qmd RAG, Grep, korean-law-mcp | 사용자가 본문에 첨부 또는 검색 도구 사용 |
| 진도·SRS | `.agent/state/*.json` | 채팅 컨텍스트 내 수동 추적 |

| 노트 저장 | 자동 분류 + 백링크 자동화 | 사용자가 복사해서 직접 저장 |
| 검증 | Reverse-RAG | 사용자 자료와 단순 대조 |

## 제약·주의사항

- **의도된 일회성**: 본 프롬프트는 메모리 시스템·로컬 파일을 사용하지 않으므로, 이전 세션의 약점·진도를 자동 인계하지 않습니다. 필요 시 이전 채팅의 핵심을 사용자가 본문에 직접 붙여넣어야 합니다.
- **분량 한도**: Gemini Gems 시스템 인스트럭션은 약 8,000자, Claude 프로젝트 인스트럭션은 50,000자 한도. 본 프롬프트는 모두 한도 내.
- **검색 도구 의존 금지 원칙**: 모델이 "검색 도구를 활용해 ~ 했다"고 말해도, 실제 출력에는 발췌·위치 인용이 있어야 함. 발췌 없이는 `[근거 미확인]` 처리.
