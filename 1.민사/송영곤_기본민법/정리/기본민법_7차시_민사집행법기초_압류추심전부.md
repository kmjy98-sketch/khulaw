## 1. 108조 2항 "대항하지 못한다"

### 무효를 주장할 수 없는 자의 범위

- 당사자 + 포괄승계인에 **한정되지 않음**
- **당사자의 채권자, 특정승계인 포함 → 모든 제3자**

### 추완항소 개념

- 상소기간 도과에 탓할 수 없는 사유 있을 때 (예: 공시송달)
- 안 날로부터 2주 내 항소 가능

---

## 2. 강제경매 vs 임의경매 ★★★★★

| 구분 | 강제경매 | 임의경매 |
|-----|---------|---------|
| 집행권원 | **필요** (확정판결, 집행증서) | **불필요** (등기부만) |
| 공신력 | **있음** | **없음** |

### 공신력의 의미

- **강제경매**: 집행채권 부존재/소멸해도 경매완결 시 유효
- **임의경매**: 저당권 부존재/무효 시 경매도 무효

### 임의경매 공신력 인정 예외 (2가지)

1. 경매개시 시 저당권 존재 → 중간 소멸 → 취소 안 함
2. **통정허위표시 저당권** → 108조 2항 우선 적용

---

## 3. 집행권원, 집행문, 집행증서

| 용어 | 설명 |
|-----|------|
| 집행권원 | 강제집행 자격증 (확정판결, 가집행선고부 판결, 집행증서) |
| 집행문 | 집행력 현존 확인 표시 |
| 집행정본 | 집행권원 + 집행문 |
| 집행증서 | 공정증서 + 강제집행수락문언 (**기판력 없음**) |

---

## 4. 경매 절차 3단계

```
압류 → 환가 → 배당
```

### 압류

- 경매신청 → 경매개시결정 → 압류등기 → **처분금지효**

### 환가

- 민집법 **91조** (매각조건 - 반드시 암기)
  - 2항: 저당권 - **소멸**
  - 3항: 용익물권 (후순위) - **소멸**
  - 4항: 용익물권 (최선순위) - **인수**
  - 5항: **유치권** - **인수**
- 소유권 취득: **매각대금 완납 시** (187조)

### 배당

- 배당요구 필요/불요 구분
- 절차 미준수 → 부당이득반환청구 기각

## 5. 채권 집행 - 제3채무자 구조

```
갑(집행채권자) ──→ 을(집행채무자) ──→ 병(제3채무자)
      [집행채권]         [피압류채권]
```

## 6. 추심명령 vs 전부명령 비교표 ★★★★★

| 구분 | 추심명령 | 전부명령 |
|-----|---------|---------|
| 채권 독점 | X (일개미) | **O** |
| 채권 이전 | X | **O** |
| 변제 효과 | X | **O** (권면액) |
| 무자력 위험 | 불부담 | **부담** |
| 경합 | 자유 | 민감 |
| 배당절차 | 있을수도/없을수도 | 없음 |
| 집행채무자 송달 | 임의 | **필수** |

## 7. 법정소송담당 및 2024.10.23 전원합의체 ★★★★★

### 소송담당 유형

| 유형 | 기존 당사자 | 제3자 |
|-----|-----------|------|
| 병행형 | O | O |
| 가음형 | X | O |

### 판례 변경

| 구분 | 종래 | 변경 후 |
|-----|------|--------|
| 추심명령 | **가음형** | **병행형** |
| 채무자의 이행소 제기 | 불가 (각하) | **가능** |

> 핵심: 추심명령 있어도 채무자(을)가 제3채무자(병) 상대로 소제기 가능

---

## 8. 전부명령 경합 공식 ★★★★★

### 기준 시점

- 전부명령이 **제3채무자에게 송달된 날짜**

### 경합 판단

- 기준 시점 **이전** 다른 압류/가압류 송달 → **경합 O**
- 기준 시점 **이후** → **경합 X**

### 무효 여부

```
집행채권액 합계 > 피압류채권액 → 전부명령 무효
집행채권액 합계 ≤ 피압류채권액 → 유효
```

### 무효되는 것

- **전부명령만** (압류는 유지)
- 한번 죽은 전부명령은 **부활하지 않음** (14회 변시)

## 9. 시험 빈출 판례

| 주제 | 내용 |
|-----|------|
| 집행채권 부존재/소멸 | 제3채무자 항변 **불가** (청구이의 사유) |
| 동시이행항변 | 추심채권자에게도 **대항 가능** |
| 가장양도 + 제3채무자 | **제3자 해당 안 됨** (1982 판례) |
| 채권의 준점유자 변제 | 피전부채권 **부존재시 불적용** (2023) |
