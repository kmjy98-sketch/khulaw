## 1. 물권적 청구권 [A급]

### 1-1. 법적 성질 — 판례: 절충설

| 쟁점 | 판례 태도 | 요지 |
|---|---|---|
| 법적 성질 | **절충설** | 물권의 효력에서 파생하는 특수한 독립적 청구권. 채권적 청구권은 아님 |
| 소멸시효 | 소유권 기한 — **부정** | 물권 존속 중 청구권만 소멸하면 물권의 실질 상실. 제한물권은 판결 미확인 |
| 비용부담 | **적극적 행위청구권** | 상대방이 비용 부담. 판례는 명시적 판결은 없으나 적극적 행위청구권임을 분명히 함 |
| 전보배상 | **부정** | 물권적 청구권의 이행불능으로 인한 §390 손해배상 인정 불가. 부당이득반환·불법행위는 가능 |

- 근거 위치: [《찌라시》 쟁점1 | "판례 역시 물권적 청구권은 물권의 효력으로부터 나오며, 채권적 청구권은 아니라고 판시"]

### 1-2. 주요 판례

| 판례 | 요지 | 소스 |
|---|---|---|
| 대판 1993.10.8, 93다28867 | 등기 말소청구도 방해제거에 포함 | 교재 p.31 |
| 대판 2007.6.15, 2004다37904 | 불가량물질에 의한 환경침해(임밋시온)도 간접적 방해 | 교재 p.31 |
| 대판 1993.5.14, 93다4366 | 정당한 이유 있으면 방해제거 거부 가능 | 교재 p.31 |
| 대판 2003.11.27, 2003다40422 | 권리남용으로 되려면 특별한 사정 필요 | 교재 p.31 |
| 대법원 1999.7.9, 98다57457 | 토지 소유자는 건물 철거·대지 인도만 청구 가능, **건물 점유자에 대한 퇴거 청구 불가** | 목차볼드 p.79 |
| 대법원 2020.5.21, 2018다287522 (전합) | 공유자의 건물 점유는 자기 소유 건물 점유로 봐야 함 — 퇴거 청구 불가 원리 확장 | 목차볼드 p.79 |

### 1-3. 찌라시 Case 정리

| Case | 요지 |
|---|---|
| Case 1 | 미등기 매수인이 인도받아 사용 → §213 단서 항변 가능 |
| Case 2 | 인접 토지 침범 건축 → §213 대지인도 + §214 건물철거 |
| Case 3 | 소유권 소멸로 말소불능 → 이행불능 손해배상(§390) 불가 |
| Case 4 | 건물 소유자의 토지 점유 → 철거·인도만 가능, 퇴거 청구 불가 |
| Case 5 | 공중 통행 도로 → 소유권 행사 제약, 권리남용 |
| Case 6 | 상수도시설·고압송전탑 → 권리남용에 해당하지 않음 |

## 2. 등기청구권 [A급]

### 2-1. 판례 태도

| 쟁점 | 판례 태도 | 요지 |
|---|---|---|
| 법적 성질 | **채권적 청구권설** | 물권행위 독자성 부인, 채권행위에서 발생 |
| 소멸시효 | **원칙 10년, 예외 부정** | 매수인이 인도받아 사용·수익 중이면 시효 부정. 적극적 권리행사 일환으로 처분·점유승계한 경우도 동일 |
| 양도성 | **소극(부정)** | 신뢰관계 전제 채권 → 매도인의 승낙·동의 없으면 양수인이 직접 청구 불가 |

- 근거 위치: [《찌라시》 쟁점2 | "판례는 물권행위의 독자성을 부인하며 채권행위로부터 발생하는 채권적 청구권으로 본다"] [《찌라시》 쟁점2 | "매수인이 매도인에게 가지는 소유권이전등기청구권은 … 인도받아 사용, 수익하고 있는 경우 소멸시효에 걸리지 않는다"]

### 2-2. 진정명의회복등기

| 쟁점 | 판례 태도 | 요지 |
|---|---|---|
| 인정 여부 | **긍정** | 말소등기에 갈음하여 진정명의회복을 원인으로 한 소유권이전등기 청구 허용 |
| 법적 성질 | **물권적 청구권** | 소유권에 기한 방해배제청구권과 동일 |
| 요건 | ① 이전 자기 명의 등기 or ② 법률에 의한 소유권 취득, ③ 상대방 등기 원인무효 | |
| 기판력 | 등기말소 청구 패소 → 소유권이전등기 청구 **불가** | 실질적 목적·법적 성질 동일 → 동일 소송물 |

## 6. 등기의 추정력 [B급]

### 6-1. 판례 태도

| 쟁점 | 판례 태도 | 요지 |
|---|---|---|
| 추정의 성질 | **법률상 추정** | 동산 점유 추정력(§200)과의 균형 |
| 물적 범위 | 등기 원인에도 미침 | 등기에 의해 등기원인이 진실로 존재하고 절차가 적법했다고 추정 |
| 인적 범위 | 제3자 + 당사자 사이 | 매매 원인 등기 → 계약 유효 추정, 말소 청구자가 무효 증명 책임 |
| 추정 번복 | 반증 필요 | 등기원인 계약서가 진정하지 않음이 증명되면 추정 깨짐 |

- 근거 위치: [《찌라시》 쟁점6 | "통설과 판례는 … 법률상 추정으로 보고 있다"]
