# 채권집행 — 추심과 전부

> **핵심 요약**: 추심명령(채권 행사 권한만, 무자력위험 불부담) vs 전부명령(채권 이전, 무자력위험 부담). 전부명령 경합 시 무효(부활 X). 2024.10 전합 — 추심명령 시 채무자 소제기 가능(병행형).

## 1. 채권 강제집행의 3자 구조

```
갑(집행채권자) --[A채권]--> 을(집행채무자) --[B채권]--> 병(제3채무자)
```

---

## 2. 추심명령 vs 전부명령 비교 ★★★★

| 구분 | 추심명령 | 전부명령 |
|------|---------|---------|
| **본질** | 채권 행사 권한만 부여 | 채권 자체 이전 (대물변제 유사) |
| **채권 독점** | **X** (다른 채권자 배당 참가 가능) | **O** (독점적 만족) |
| **채권 이전** | X | **O** (채무자→채권자) |
| **변제 효과** | 추심 후 신고 시 | 확정 시 권면액만큼 **당연 소멸** |
| **무자력 위험** | **불부담** (다른 재산 집행 가능) | **부담** (변제된 것 간주) |
| **경합 영향** | 자유 (안분배당) | **민감** (경합 시 전부명령 무효) |
| **채무자 송달** | 임의적 | **필수적** (효력발생요건) |

---

## 3. 추심명령 상세

### 법정소송담당

- 추심채권자가 제3채무자를 상대로 소 제기 = 채무자의 권리 행사

### 2024.10.23 전원합의체 ★★★★

| | 내용 |
|---|------|
| **종래** | 추심명령 = **가음형** (채무자 소제기 불가 → 각하) |
| **변경** | 추심명령 = **병행형** (채무자도 소제기 **가능**) |

### 제3채무자 항변

| 가능 | 압류 당시 채무자에게 대항 가능한 사유 (동시이행항변 등) |
|------|------------------------------------------------------|
| **불가** | **집행채권 부존재/소멸** (청구이의소 사유) |

### 추심 경합

- 같은 채권에 여러 추심명령 → 순위 **없음**, 먼저 추심해도 독점 아님

---

## 4. 전부명령 상세 ★★★★

### 권면액

- = 표면에 드러난 금액
- 예: 집행채권 5억, 피압류채권 10억 → 5억 전부 → 집행채권 **소멸** + 갑이 병에 5억 채권 취득

### 요건

1. **경합 없을 것**
2. 피압류채권액 ≥ 집행채권액 합계

### 송달·효력발생

| 항목 | 내용 |
|------|------|
| 송달 | 제3채무자 + **집행채무자** 모두 필수 |
| 즉시항고 | **1주일** 불변기간 |
| 효력발생 | **제3채무자 송달일**에 소급 |

---

## 5. 전부명령과 경합 ★★★★

### 기준 시점

- 전부명령이 **제3채무자에게 송달된 날**

### 경합 판단

| 상황 | 결론 |
|------|------|
| 기준시점 **이전** 다른 압류/가압류 송달 | **경합 O** |
| 기준시점 **이후** 송달 | **경합 X** |

### 경합 시 무효 여부

- 집행채권액 합계 > 피압류채권액 → 전부명령 **무효**
- 집행채권액 합계 ≤ 피압류채권액 → 전부명령 **유효**

### 경합 효과

| 항목 | 내용 |
|------|------|
| 무효 범위 | **전부명령만** 무효 (압류 유지) |
| 부활 가능? | 경합 해소해도 **부활 X** (14회 변시) |
| 시효중단 | 압류 살아있으므로 **유지** |

---

## 6. 채권 준점유자 변제 (470조) ★★

| 상황 | 적용? |
|------|-------|
| 피압류채권 **존재** + 전부명령 무효 | **O** (제3채무자 면책) |
| 피전부채권 자체 **부존재** | **X** (2023.7) |

## 7. 복습 포인트

- [ ] 추심명령: 채권 이전 X, 무자력 위험 **불부담**
- [ ] 전부명령: 채권 이전 O, 무자력 위험 **부담**, 권면액 소멸
- [ ] 2024.10.23 전합: 추심명령 있어도 채무자 소제기 **가능** (병행형)
- [ ] 전부명령 경합: 제3채무자 송달일 기준, 합계 > 피압류 → **무효**
- [ ] 무효 전부명령 **부활 X** (경합 해소해도)
- [ ] 집행채권 부존재: 제3채무자 항변 **불가** (청구이의소)
