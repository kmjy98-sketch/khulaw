# 소멸시효 완성효과와 포기

> **핵심 요약**: 포기는 **완성 후** 구간에서 발생하며, 법률행위(효과의사 필요). 승인(관념의 통지)과 태생이 다름. 2025.7 전합에서 추정의 법리 폐기. 사전포기 불가(184조), 유치권·비용상환청구권만 예외.

## 1. 시효 완성의 효과

### 기본 구조

```
기산일① ──── 기간 ──── 완성일
                         ↓ (이후 구간)
                    포기 가능 구간
```

- **항변**: 피고가 "기산일 기준 완성일 이후에 소제기됨" 주장
- **재항변**: 원고가 "중단 사유 있었다" 또는 "포기했다" 반박

### 소멸시효 완성의 법적 효과

- 채권이 **소멸** (다수설·판례)
- 다만 포기를 통해 **재시작** 가능

---

## 2. 포기 (제184조) ★★★★★

### 정의

- **시효 완성의 이익**을 당사자의 의사에 의해 **버리는 법률행위**
- 효과의사 필요 (승인과 결정적 차이)

### 사전 포기 불가 (184조 1항)

> "소멸시효의 이익은 미리 포기하지 못한다"

| 권리 | 사전 포기 가능? |
|------|---------------|
| 소멸시효 이익 | **X** |
| **유치권** | **O** (판례) |
| **비용상환청구권** (임차인) | **O** (판례) |
| 부양료 청구권 | **X** |
| 유류분 | **X** |
| 상속 | **X** (피상속인 사망 후 3개월 내) |

### 사후 포기 요건

| 요건 | 내용 |
|------|------|
| ① 처분 권한 | 있어야 함 |
| ② **시효 완성 인지** | 시효가 완성되었음을 **알고** 포기 |
| ③ **효과의사** | 이익을 버리겠다는 의사 |

- 근거: 전사문 "시효가 완성됐다는 걸 인지하고 ... 아이 그래도 그냥 이거는 제가 포기하고 갚을게요. 이게 포기"

---

## 3. 2025.7 전원합의체 판결 ★★★★★ (출제 확실)

### 종전 판례 (1967.2 → 일본 최고재판소 유래)

- **추정의 법리**: 시효 완성 후 채무 승인 → 시효이익 **포기로 추정**
- 이를 기반으로 수십 년간 판례군 형성

### 변경 (2025.7 전합)

- **추정의 법리 폐기**
- 승인과 포기는 **성질이 다름** → 승인만으로 포기 추정 불가
- 기존 추정 기반 판례 다수 폐기

### 변경 근거

- ① 포기 = **법률행위** (효과의사 필요), 승인 = **관념의 통지** → 질적으로 다름
- ② 추정의 법리는 일본 판례를 무비판적으로 수용한 것
- ③ 승인 사실만으로 포기 의사를 추정하는 것은 논리적 비약
- 근거: 전사문 "포기에 관한 추정의 법리를 다 뒤집어 버렸어 ... 일본 최고 재판소의 입장이었어"

### 시험 대비

- 15회 변시 출제 가능 (7월 선고 → 전합은 시험범위 포함)
- 미출제 시 **16·17회 100% 출제**
- 근거: 전사문 "안 낼 수가 없는 거거든요"

---

## 4. 포기의 인적 범위

### 원칙: 포기한 사람만

- 중단과 달리 **플러스 알파 없음**
- 포기자에게만 효과, 다른 채무자에 영향 X

### 예외: 승계인

- 포기 당시 이해관계 없었으나 → 나중에 **법률관계를 통해 시효원형권 취득**한 자
- → 전권리자의 시효이익 포기를 **물려받음**
- 근거: 전사문 "딱 하나밖에 없거든요 ... 100% 시험에 안 나올 수가 없지"

---

## 5. 포기 후 재진행

- 포기 = 세상 끝 **아님**
- 포기 후 → **익일(또는 당일)**부터 시효 **다시 진행**
- cf. 중단은 178조 근거, 포기는 해석·판례 근거
- 근거: 전사문 "포기했다고 끝나는 거 아니야. 포기가 되면 그다음날부터 다시 시작된다"

---

## 6. 포기로 인정된/인정 안 된 사례

### 인정된 사례 (대표)

- 상계 항변 (시효완성 채권으로 상계 주장 → 포기 추정... but 2025 전합 후 재검토)

### 포기 vs 승인 혼동 주의

- 겉으로 드러난 행동이 유사 → 판례 잡다
- 대표적 5~6가지만 시험에 출제 가능

---

## 7. 신의칙에 의한 시효 원용 제한

- 시효 완성 주장이 **신의칙 위반**인 경우 → 원용 불허
- 예: 채무자가 시효 완성 전 "반드시 갚겠다"며 채권자의 시효중단 조치를 방해했던 경우
- 별도 법리로 포기와 구별

---

## 8. 복습 포인트

- [ ] 포기 = **법률행위** (효과의사 필요), 승인 = 관념의 통지
- [ ] **사전 포기 불가** (184조), 유치권·비용상환만 예외
- [ ] 2025.7 전합: **추정의 법리 폐기** → 100% 출제
- [ ] 포기 인적범위: **포기자만** (승계인 예외 1개)
- [ ] 포기 후 = 끝 아님, **재진행**
- [ ] 신의칙: 별도 법리
