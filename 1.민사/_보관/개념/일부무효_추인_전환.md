# [[일부무효]] 추인 전환

## 1. 일부무효 (137조) ★★★★

### (1) 법조문

> 일부 무효 → **전부 무효** (원칙)
> 무효부분 없어도 의욕 인정 → **나머지 유효** (단서)

### (2) 적용 전제 (2024.7 판례)

1. 법률행위 **분할 가능**
2. 나머지가 **독립된 법률행위**로 존속 가능

### (3) 처리 순서

| 순서 | 기준 |
|:----|:----|
| 1차 | 당사자 **현실적 합의** |
| 2차 | 137조 원칙: **전부 무효** |
| 3차 | 단서: **가정적 의사** → 일부 유효 |

---

## 2. [[일부취소]] ★★★

### (1) 요건

1. 법률행위 **가분적** / 목적물 일부 특정 가능
2. **가정적 의사** 인정

### (2) 일부취소 인정

- 지자체 토지수용 과다지급 (85%) → **과다부분만** [[착오취소_사기강박_경합.md|착오취소]]

### (3) 일부취소 부정 (전부취소)

- 금전소비대차 + 근저당: 경제적·사실적 **일체**
- 임차권양도 + 권리금: 하나가 **조건**

---

## 3. 강행법규 위반 일부무효 ★★★

### (1) 처리

| 순서 | 기준 |
|:----|:----|
| 1차 | 명문규정 (약관법 16조: 일부유효 원칙) |
| 2차 | 137조: **전부무효** |
| 3차 | 입법취지상 전부무효가 **반하면** → 일부무효 |

### (2) 판례

- 이사 자기거래 무승인: **이자만 무효** (회사 보호)
- 법조브로커 성공보수: **성공보수만 무효**

---

## 4. [[무효행위_추인_전환.md|무효행위 추인]] (139조) ★★★

### (1) 법조문

> 무효는 추인해도 **효력 안 생김**
> 무효 **알고** 추인 → **새로운 법률행위**

### (2) 요건

| 요건 | 내용 |
|:----|:----|
| 무효원인 **소멸** | 103/104조 → 추인 대상 X |
| **무효임 인식** | 모르면 새 행위 불인정 |

### (3) 효과

- **소급효 X**: 추인시부터 새 행위
- 채권적 소급효는 **합의** 가능

### (4) 김재규 사건 ★★★

- 강박 취소 → 취소로 **무효**
- 재고문 후 추인 시도 → 무효원인(비상계엄) **미소멸**
- 추인 **무효** → 재산 유족 반환

---

## 5. [[무효행위_추인_전환.md|무효행위 전환]] (138조) ★★★

### (1) 법조문

> 무효 법률행위가 **다른 행위 요건** 구비
> **무효 알았으면** 다른 행위 의욕 인정 → **다른 행위 효력**

### (2) 신분행위 3대장 ★★★★

| 원래 | 전환 후 |
|:----|:-------|
| 타인 자녀 출생신고 | **입양** |
| 혼외자를 혼인중 출생자 신고 | **인지** |
| 기간 도과 상속포기 | **상속재산분할** |

### (3) 재산법적 전환

- 알박기 104조 무효 → 정상가격 매매로 **전환**
- 임금 가음 무효 → 채권양도는 유효 (**담보** 목적)

---

## 6. 일부무효 주요 판례 ★★★

### (1) 토지거래허가 사건

| 사실관계 | 토지+건물 일괄매매 → 토지거래허가 미획득 |
|:---------|:-----------------------------------------|
| 쟁점 | 건물만 먼저 이전등기 청구 가능? |
| **판례** | 토지 없이 건물만 매매할 의사 **입증 시**만 가능 |
| 그 외 | 토지 허가 후 **함께** 이전 |

### (2) 지자체 토지수용 (일부취소 인정)

- 감정오류로 85% 과다 지급
- 돈 = 가분적, 양 당사자 가정적 의사 인정
- → **과다부분만 착오취소** 인정

## 7. 김재규 사건 상세 ★★★★

### (1) 사실관계

| 단계 | 내용 |
|:-----|:-----|
| 1979.10.26 | 박정희 대통령 시해 → 김재규 체포 |
| 보안사 고문 | 재산 국가헌납 각서 |
| **1차 공판** | "고문으로 인한 것" → **취소 주장** = 유효 |
| 2차 공판 (재고문 후) | 1차 진술 **철회** → 추인 시도 |
| 유족 소송 | 반환청구 |

### (2) 대법원 판시

| 쟁점 | 판단 |
|:-----|:-----|
| 1차 공판 취소 | 강박에 의한 취소 → **유효** |
| 2차 공판 | 취소된 행위(=무효) 추인 시도 |
| 무효원인 소멸? | 비상계엄 해제(1981.1.21) 전 → **미소멸** |
| **결론** | [[무효행위 추인]] **무효** → 재산 **유족 반환** |

## 8. 재산법적 전환 상세 ★★★

### (1) 알박기 사건 (104조 + 138조)

| 사실관계 | 1억 토지를 20억에 매매 |
|:---------|:----------------------|
| 104조 판단 | 불공정행위 **무효** |
| 전환 (138조) | 무효 알았으면 정상가격 매매 의욕 → **1억5천 매매로 전환** |
| **결과** | 18억5천 반환 명령 |

### (2) 임금 가음 사건 (2012.3월 판례)

| 사실관계 | 사용자가 제3채권 양도하여 임금 **퉁치기** 시도 |
|:---------|:---------------------------------------------|
| 판단 | 근로기준법 위반 → 가음 약정 **무효** |
| **전환** | 채권양도는 유효 (임금채권 **담보** 목적) |
