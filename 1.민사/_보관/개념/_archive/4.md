# 4

## 1. 핵심 개념

### [재판상 청구와 시효중단 - 주요 판례 분석]

**1. 청구 변경과 시효 중단 (채권자대위 -> 양수금)**:

- **사안**: 채권자대위소송(피대위권리 행사) 중 채권자가 피대위권리 자체를 양수받아 양수금 청구로 소 변경(교환적 변경).
- **소 변경 시점이 시효 완성 후**라면?
- **판례**: 소송물이 실질적으로 동일(피대위권리=양수금채권)하므로, **최초 대위소송 제기 시**에 시효중단 효과 발생 (소급효 인정).
- 근거: 전사문 "소송물이 사실상 같죠... 종전 채권자 대의 소송에 의한 시효 중단 효과는 양수금 청구 소송에 고대로 미친다."

**2. 소 각하/취하와 6개월 내 재산 (170조 2항)**:

- **반복된 재소**: 소 각하 후 6개월 내 다시 소 제기 -> 또 각하 -> 다시 6개월 내 제기 -> 최종적으로 적법하면 최초 소 제기 시로 소급하여 중단 인정. (인해전술 가능).
- **사망자 상대 소 제기**:
  - 원칙: 사망자 상대 소는 부적법, 판결도 무효 -> 시효 중단 X.
  - 예외: **당사자 표시정정**으로 상속인으로 피고를 바꾼 경우 -> 상속인에 대한 적법한 소 제기로 인정 -> 170조 2항 적용 가능. (표시정정 없이 각하되면 170조 적용 불가).
- 근거: 전사문 "표시 정정이 이루어진 것과 같은 특별한 사정이 없게 되면... 시효 중단 효과가 발생하지 않는다."

**3. 추심소송과 중복제소 (2025 전원합의체 변경)**:

- **쟁점**: 채무자(을)가 제3채무자(병) 상대로 소 제기 중, 채권자(갑)가 압류·추심명령 받고 추심의 소 제기 시 관계.
- **종전**: 을은 원고적격 상실 -> 을의 소 각하.
- **변경 (2025 전합)**:
  - 을의 원고적격 **유지됨** (상실 X).
  - 갑의 추심소송은 **중복제소**에 해당하여 각하됨 (을이 먼저 제기했으므로).
  - 기판력: 을이 받은 판결의 효력은 갑(추심채권자)에게도 미침.
- 근거: 전사문 "지금 변경된 거에 따르면... 을은 원고 적격을 잃지 않아요... 갑이 제기한 소송이 오히려... 중복 재소가 돼 버려요."

### [최고 (Demand) 심화]

**1. 재판상 청구 각하 후 최고 효력 (170조 적용 배제 사안)**:

- **사안**: 시효 완성 **후** 소 제기 -> 각하/취하 -> 6개월 내 재소.
- **판례**: 시효 완성 후 소 제기이므로 170조(재판상 청구 중단) 적용 불가. 단, **최고로서의 효력**은 인정.
- **논리**: 선행 소송(최고 효력) -> 6개월 내 후속 소송(재판상 청구). 이를 **거듭된 최고**의 법리로 해결.
  - 주의: 선행 소송 제기 시점이 **최고 시점**으로 간주됨.
- 근거: 전사문 "재판상 청구 자체가 시효 완성된 다음에 들어가 있으니까... 최고라고 하는 애가... 붙들어 주다 보니까... 최고로서 효력을 인정해 주겠다."

**2. 반복된 최고 (거듭된 최고)**:

- 여러 번 최고가 있더라도 시효 중단 효력은 **재판상 청구 등 확정적 사유**가 발생한 시점으로부터 **소급하여 6개월 내**에 있는 최고에만 인정.
- 그 이전의 최고는 효력 상실.

**3. 소송고지에 의한 최고**:

- 소송고지서가 법원에 **접수된 때** 시효중단(최고) 효력 발생. (상대방 도달 시 아님).
- 6개월 기산점: 소송고지 사건의 **판결 확정 시** (종료 시)부터 6개월 내 권리행사 필요.
- 근거: 전사문 "소송 고지서가... 법원에 접수될 때 그때에 그 시효중단 과가 발생한다."

### [압류·가압류·가처분 (Seizure etc.)]

**1. 시효중단 시기**:

- **신청 시**에 소급하여 발생 (168조 2호). (단, 집행절차 착수가 있어야 함).
- 유체동산 가압류 시 집행불능(물건 부존재)으로 끝나면 -> 효력 없음(또는 집행불능 통지 시 소멸).

**2. 일부 청구 기재 시**:

- 신청서에 **기재된 청구금액(일부)**에 대해서만 시효 중단.
- 예: 원금만 기재하면 이자채권은 중단 X. (채권계산서 제출 시 누락하면 안 됨).
- 근거: 전사문 "신청할 때 원금만 기자하면... 이자 채권은 시효 중단이 안 된다."

**3. 효력발생 범위 (176조 - 물상보증인 등)**:

- 물상보증인/제3취득자 재산 압류 -> 주채무자에게 **통지**해야 주채무 시효 중단.
- **반대 해석**: 주채무자 재산 압류 -> 보증인에겐 **통지 불요** (주채무 절대효 440조 아님, 그러나 보증채무 부종성 또는 169조 해석으로 당연 효력).
- **주의**: 주채무자에 대한 압류는 보증인에게 당연 효력(통지 불요). 보증인에 대한 압류는 주채무자에게 통지 필요.
- 근거: 전사문 "주채무자에 대한 채권... 통지를 하지 않더라도... 시효가 중단된다."

**4. 취소 시 효력 (175조)**:

- **권리자의 청구(취하)** 또는 **법률 규정 미준수**로 취소된 경우 -> 시효중단 효력 **소급 소멸**.
- **175조 적용 제외 (중단 효력 유지 또는 178조 2항 적용)**:
  - **추심권만 포기**하고 압류 유지한 경우 -> 중단 효력 유지.
  - **제소명령 불이행**으로 취소된 경우 -> 175조 적용 X (권리행사 의사 없다고 볼 수 없음) -> 6개월 내 재소 시 유지 가능성.
  - **무잉여(남을 가망 없음) 취소** -> 175조 적용 X.
- 근거: 전사문 "제소 명령 신청에 따르지 않아 가지고 취소된 경우 여기는 포섭이 안 된다... 무잉여 취소... 이것도 해당되지 않는다."

## 2. 판례 정리

### [175조 적용 여부 (취소 사유)]

| 취소 사유 | 175조 적용 (중단효 소급소멸) | 비고 |
|-----------|----------------------------|------|
| **권리자 취하** | O (원칙) | 압류 신청 자체를 취하한 경우 |
| **추심권만 포기** | X | 압류는 존속하므로 중단 유지 |
| **제소명령 불이행 취소** | X | 적법한 권리행사였음 (절차적 취소) |
| **3년 간 본안 미제기 취소** | X | 권리행사 의사 있음 |
| **무잉여 경매 취소** | X | 법률 규정 취소이나 175조 사유 아님 |

- 근거: 전사문 "법률의 규정에 따르지 않아... 취소된 경우... 제한적으로만 적용이 된다." (객관적 권리행사 의사 결여 등).

## 5. 복습 포인트

- [ ] [채권자대위] 대위소송 중 피대위채권 양수 후 소 변경 시 최초 대위소송 시점으로 시효중단 소급.
- [ ] [사망자 소송] 상속인으로 **표시정정**을 해야만 170조 재소(6개월) 특례 적용 가능. 정정 없이 각하되면 적용 불가.
- [ ] [추심소송] 2025 전원합의체 변경: 채무자의 원고적격 유지됨. 추심채권자의 후소는 중복제소 각하. (기존: 채무자적격 상실 각하).
- [ ] [압류 통지] 물상보증인 압류 -> 주채무자 통지 필요. 주채무자 압류 -> 보증인 통지 불요.
