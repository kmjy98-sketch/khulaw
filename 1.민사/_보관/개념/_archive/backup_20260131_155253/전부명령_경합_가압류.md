# 전부명령 경합 가압류

## 1. 전부명령

### (1) 개념

> 피압류채권을 **지급에 갈음**하여 채무자→압류채권자에게 이전

- **채권 이전** + **변제** (권면액만큼)

### (2) 권면액

= 표면에 드러나 있는 금액

**예시**:

- 집행채권 5억, 피압류채권 10억 → 5억 전부
- 집행채권 5억 **소멸** + 갑이 병에 대해 5억 채권 **취득**

### (3) 요건 ★

1. **경합 없을 것**
2. 피압류채권액 ≥ 집행채권액 합계

### (4) 송달·효력발생

| 송달 | 제3채무자 + **집행채무자** 모두 필수 |
|:----|:-------------------------------|
| 채무자 즉시항고권 | **1주일** 불변기간 |
| 효력발생시점 | **제3채무자 송달일**에 소급 |

### (5) 효력

| 항목 | 내용 |
|:----|:----|
| 채권 이전 | 통지/승낙 불요 (법원 결정) |
| 변제 | 권면액만큼 **당연 소멸** (추심 무관) |
| **무자력 위험** | 전부채권자 **부담** |

---

## 2. 전부명령과 경합 ★★★★

### (1) 기준 시점

= 전부명령이 **제3채무자에게 송달된 날**

### (2) 경합 판단

| 경합 O | 기준시점 **이전** 다른 압류/가압류 송달 |
|:------|:--------------------------------|
| 경합 X | 기준시점 **이후** 송달 |

### (3) 경합 시 무효 여부

```
집행채권액 합계 > 피압류채권액 → 전부명령 무효
집행채권액 합계 ≤ 피압류채권액 → 전부명령 유효
```

### (4) 경합 효과

- 무효되는 것: **전부명령만** (압류 유지)
- 한번 무효된 전부명령: 경합 해소해도 **부활 X** (14회 변시)
- 시효중단: 압류 살아있으므로 **유지**

## 3. 채권 준점유자 변제 ★★

|:------------------------------|:--------|
| 피전부채권 자체 **부존재** | **불적용** (2023.7) |

## 4. 108조 2항 제3자 추가 사례

### 사례: 가장양도 + 압류추심 (2014)

```
을 --[보증금채권 가장양도]--> 병 <--[압류추심]-- 정
```

→ 정 = 108조 2항 **제3자 O**

### 사례: 가장양도에서 변제 안 한 채무자 (1982) ★

- 채무자(피고회사) = 108조 2항 **제3자 X**
- 이유: 통모 외관에 기초해 **새로운 이해관계** 맺은 것 아님
