# 통정허위표시 제3자 범위 사례

> 교재: 송영곤, 기본민법 (172p~)
> 원본: 6차시_수업정리_의사표시_통정허위표시.md

## 1. 108조 2항 - 제3자의 범위

### 1.1 제3자의 정의

- 당사자와 포괄승계인 **이외의 자**
- 허위표시에 의해 외형상 형성된 법률관계를 토대로 **새로운 이해관계**를 맺은 자
- 등기·인도 등 **완전한 권리취득 불요**
- **근거**: 《교재》 172p

### 1.2 548조 1항 단서(해제)와 비교

| 구분 | 108조 2항 (통정허위) | 548조 1항 단서 (해제) |
|-----|----------------------|----------------------|
| 완전권리취득 | **불요** | **필요** (등기 등) |
| 선의 규정 | O (선의만 보호) | X (선악 불문 보호) |

---

## 2. 제3자 해당/비해당 사례

### 2.1 제3자 해당 사례 (9가지)

1. 가장매매 매수인으로부터 목적 부동산 매수한 자
2. 소유권이전청구권 보전 위한 가등기권자
3. 파산관재인 (선의 판단: **총 채권자** 기준)
4. 채권의 양수인
5. (누락)
6. 임대차보증금 담보 목적 전세권에 저당권 설정한 자
7. **건설공제조합** (구상권 사례) ★★★
8. 허위 근저당권 기한 경매의 매수인
9. 채권의 [[가압류_[[가압류_가처분_[[가압류_가처분_보전처분.md|보전처분]].md|가처분]]_보전처분.md|가압류]]권자

### 2.2 제3자 비해당 사례 (4가지)

| 사례 | 이유 |
|------|------|
| **매수자금 대여자** | 병(가장매수인)과 거래가 아니라, 실질적으로는 **갑(본인)과 거래**한 것임 |
| 계약 인수한 자 | 채권·채무를 포괄적으로 이전받음 (포괄승계인 유사) |
| 채권 압류·[[추심명령_전부명령_비교.md|전부명령]]권자 | 집행법상 권리자에 불과 (새로운 이해관계 X) |
| (추가) | 상속인 (포괄승계인) |

## 3. 선의의 의미와 증명책임

| 항목 | 내용 |
|------|------|
| **선의** | 앞서간 거래가 통정허위표시임을 **모르는 것** (소극적 부지) |
| **무과실** | **불요** (과실 있어도 선의면 보호됨) |
| **증명책임** | 제3자의 **선의 추정** → 악의 입증책임은 무효 주장자(표의자)에게 있음 |
| **전득자 보호** | 108조 2항, 449조 2항 → 악의 제3자로부터 선의 전득한 자도 보호됨 (엄폐물의 법칙) |
