# 법률행위해석 당사자확정

# 민법강의 수업정리 Part 29 (법률행위해석·당사자확정)

## 1. 법률행위 해석

### (1) 개관

- 법률행위 해석 = **의사표시 해석**
- 최종 해석 주체: **법원**
- 대상: 원칙적으로 **표시행위**의 객관적 의미

> 계약서에 "해석권은 김갑동에게" 기재해도 → 법원에 온 이상 **법원이 최종 해석권**

### (2) 자연적 해석

당사자들이 **실제 합의한 바** 확인되면 → 합의대로 해석

> 사실상 일치에서 의욕된 것은 **문언의 일반적 의미에 앞선다**

#### 무기밀매상 예시

| 문언 | 실제 합의 | 해석 |
|:----|:---------|:----|
| "피아노 100대" | 기관단총 | **기관단총 매매** → 제103조 **무효** |

#### 오표시 무해의 원칙

- 자연적 해석 가능 → **착오 문제 발생 안 함**
- 예: X토지 합의했으나 Y토지 지번 잘못 기재 → **X토지 매매**로 해석

---

### (3) 규범적 해석

당사자 합의 확인 안 되면 → **상대방 시각**에서 해석

> 합리적인 거래 당사자라면 이 문언을 어떻게 받아들였을까?

#### 1차 자료: 계약서 (처분문서)

- **사실상 증명력** (추정력): 기재대로 법률행위 있었다고 추정
- 반대 사정 확인 시 번복 가능

#### 고려 요소

| 요소 | 내용 |
|:----|:----|
| 계약서 | 1차 자료, 추정력 |
| 권리 제한 조항 | 엄격 해석 (2014.2.26) |
| 예문 (부동문자) | 당사자 구속력 없을 수 있음 |
| 복수 계약서 | **나중 작성**이 우선 |
| 관습 | 제106조 (사실인 관습) |
| 신의칙 | |
| 임의규정 | 제105조 |

---

### (4) 관습법 vs 사실인 관습

| 구분 | 관습법 | 사실인 관습 |
|:----|:------|:----------|
| 법적 확신 | O | X |
| 증명책임 | 판사 직권 | **주장하는 자** |
| 역할 | **법원** | 해석 보조 자료 |

---

### (5) "최대한 노력한다" 문구

- **원칙**: 법적 의무 아님 (립서비스)
- **예외**: 경우에 따라 법적 구속력 인정 가능
- 14회 변시 출제

### (6) 보충적 해석

- **계약 성립 후** 흠결(구멍) 메우는 작업
- 계약 성립 여부 판단에는 관여 X

| 계약 유형 | 적용 |
|:---------|:----|
| 전형적 계약 | **임의규정** |
| 비전형 계약 | **보충적 해석** |

#### 가정적 의사

= 합리적 사람이 흠결을 어떻게 메웠을까 → **판사가 추론**

## 2. 계약 당사자의 확정

### (1) 기준

1. **자연적 해석**: 합의 있으면 합의대로
2. **규범적 해석**: 상대방 시각

> 처분문서(계약서) → **명의자가 당사자**되는 경우 대부분

### (2) 2023.6.15 판례

- "매수인 김갑동 **외 3인**" 기재
- 나머지 3인 마음대로 채울 수 있나? → **아니다**
- 상대방 입장에서 **특정 가능한 자**만 당사자

---

## 3. 차명계좌 (금융실명제)

### (1) 예금주 결정

| 시기 | 예금주 |
|:----|:------|
| 금융실명제 **이전** | 출연자(갑) |
| 금융실명제 **이후** | **명의자(을)** |

### (2) 예외: 출연자가 예금주 되려면

- 금융기관 + 갑 사이 **명확한 합의**
- 을의 예금반환청구권 배제 **서면 계약서**
- 실무상 거의 불가능

### (3) 내부관계: 명의신탁

- 갑-을 내부관계 = **명의신탁**
- 금융실명법 = **단속규정** (효력규정 X)
- 명의신탁 약정 **유효**
- 을은 갑 요구 시 **예금채권 양도의무**

### (4) 명의자 무단 인출

- **불법행위** (횡령) → 손해배상책임

---

## 4. 명의신탁 유형

### (1) 중간생략 명의신탁

```
매도인(갑) → 매매 → 신탁자(을) ← 명의신탁 → 수탁자(병)
              등기: 갑 → 병
```

### (2) 계약 명의신탁

```
매도인(갑) → 매매 → 수탁자(병) ← 자금 + 명의신탁 → 신탁자(을)
              등기: 갑 → 병
```

> 등기부만 보면 두 경우 **구별 불가**

## 5. 서명대리와 권한유월 (사례 13번)

### (1) 서명대리 (유효)

| 요건 | 포섭 |
|:----|:----|
| 당사자 | 을 (명의자) |
| 갑의 행위 | 대리 (서명대리) |
| 대리권 범위 | 수권 범위 내 ✓ |
| 결론 | **유효한 대리** |

### (2) 서명대리 + 권한유월

| 사실관계 | 내용 |
|:--------|:----|
| 갑 | 을 아파트 **관리권**만 위임받음 |
| 갑의 행위 | 집주인 행세 + **매각** |
| 병 | 갑을 등기명의인 을로 믿고 매수 |

### (3) [[표현대리_126조_유추적용.md|제126조 유추적용]]

| 분석 | 내용 |
|:----|:----|
| 직접 적용 X | 병이 갑을 **을 본인**으로 오인 (지위 오인) |
| 유추 적용 O | 선의 제3자 보호 측면 동일 |

| 요건 | 포섭 |
|:----|:----|
| 기본 대리권 | 관리권 ✓ |
| 권한유월 | 매매 ✓ |
| 정당한 이유 | 수년간 임차인 + 갑이 계속 집주인 행세 ✓ |
| 본인 귀책 | 을이 갑에게 관리 전권 위임 ✓ |

**결론**: 제126조 유추적용 → 병은 을에게 **소유권이전등기 청구 가능**
