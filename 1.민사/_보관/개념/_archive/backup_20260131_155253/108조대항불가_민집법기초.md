# 108조대항불가 민집법기초

## 1. 108조 2항 "대항하지 못한다"의 의미 ★★

### (1) 인적 범위

> 무효를 주장할 수 없는 자 = **모든 제3자** (당사자/승계인에 한정 X)

| 포함되는 자 | 예시 |
|:----------|:----|
| 당사자 | 갑, 을 |
| 포괄승계인 | 상속인 |
| **특정승계인** | 병 (갑으로부터 매수) |
| **채권자** | 갑의 금전채권자 |

### (2) 사례 16번 (29p)

```
갑 --[통모가등기]--> 을 --[본등기]--> 을 --[매각]--> 정(선의)
         |
    갑 --[매각]--> 병 --[등기]
```

- 병이 추완항소로 을 패소 확정
- 병이 정 상대로 말소 청구 → **기각**
- 이유: 병도 108조 2항 적용 대상

---

## 2. 추완항소 (민소법)

| 원칙 | 판결정본 송달 후 **2주** 내 항소 |
|:----|:------------------------------|
| 예외 | 탓할 수 없는 사유 시 → 안 날부터 **2주** 내 가능 |

|:--|:----|

## 4. 강제경매 vs 임의경매 ★★★

| 구분 | 강제경매 | 임의경매 |
|:----|:--------|:--------|
| 집행권원 | **필요** (집행정본) | **불필요** |
| 첨부서류 | 집행정본 | 등기부등본 |
| **공신력** | **O** | **X** |

---

## 5. 집행권원

| 종류 | 설명 |
|:----|:----|
| 확정판결 | "피고는 원고에게 1억 지급하라" |
| 가집행선고부 판결 | 확정 전 집행 가능 |
| **집행증서** | 공정증서 + 강제집행수락문언 |

> 집행권원 + 집행문 = **집행정본**

---

## 6. 공신력 상세 ★★★

### (1) 강제경매 - 공신력 O

- 집행채권 부존재/소멸해도 → 경매절차 완결 시 **유효**
- 매수인 소유권 취득 **인정**

### (2) 임의경매 - 공신력 X

- 저당권 부존재/무효 → 경매절차도 **무효**
- 매수인 소유권 취득 **부정**

### (3) 임의[[민사집행법_경매_공신력.md|경매 공신력]] **예외** (2가지)

1. 경매 개시 시 저당권 존재 → 중간 소멸 → 이해관계인 취소 안 함
2. **[[통정허위표시_요건_효과.md|통정허위표시]] 저당권** → 매수인이 108조 2항 선의 제3자

---

## 7. 복습 포인트

- [ ] "대항하지 못한다" = 당사자+특정승계인+채권자 **모두 포함**
- [ ] 강제경매: 집행권원 **필요** + 공신력 **O**
- [ ] 임의경매: 집행권원 **불필요** + 공신력 **X**
- [ ] 108조 2항 > 임의경매 공신력 부정 법리
