| 요건 | 내용 |

## 2. 불능의 개념

**불능**: 단순히 물리적·절대적 차원이 아닌, **사회생활의 경험법칙** 또는 **거래상 관념**에 비춰 채권자가 채무자의 이행을 기대할 수 없는 경우

### (1) 원시적 불능 vs 후발적 불능

| 구분 | 시점 | 예시 |
|:----|:----|:----|
| **원시적 불능** | 계약 체결 **당시** 이미 불능 | 도자기가 이미 깨져 있음 |
| **후발적 불능** | 계약 체결 **후** 불능 발생 | 이행 과정에서 도자기 깨짐 |

### (2) 전부 불능 vs 일부 불능

| 구분 | 효과 |
|:----|:----|
| 전부 불능 | 계약 전체 무효/해제 |
| **원시적 일부불능** | **[[법률행위_일부무효_일부취소.md|제137조]]** [[법률행위_일부무효_[[법률행위_일부무효_일부취소.md|일부취소]].md|일부무효]] |
| **후발적 일부불능** | 남은 급부로 계약 목적 달성 **가능 여부**에 따라 |

### (3) 후발적 일부불능 판례 (95.7.25)

| 사실관계 | 결론 |
|:--------|:-----|
| 상가 분양 (건물 + 토지 지분) | |
| 건설사 부도 → 건물 미건축 | |
| 매수인: "토지 지분만이라도" | **불가** |

> **대법원**: 남은 급부(토지 지분)만으로 **계약 목적(상가 분양) 달성 불가**

## 3. 적법성: 강행법규

### (1) 개념

**강행법규**: 선량한 풍속 기타 사회질서에 관한 규정을 구체화한 조문

- 강행법규 위반 → **무효**
- 일부 위반 → **제137조 일부무효**

### (2) 효력규정 vs 단속규정

| 구분 | 위반 시 효과 |
|:----|:-----------|
| **효력규정** | **무효** |
| **단속규정** | 사법상 **효력 유지** |

> 실무: 단속규정 vs 효력규정 논의는 **거의 무의미**. **개별 판례**로 판단

### (3) 무효로 본 주요 사례

| 사례 | 효력 |
|:----|:----|
| 부동산 중개수수료 **한도 초과분** | 무효 |
| 불가능한 공기 강제 + 지연손해금 | 무효 |
| 사찰 주지 지위 **금전 대가** 양도 | 무효 |

### (4) 유효로 본 주요 사례

| 사례 | 효력 |
|:----|:----|
| 명의신탁 (부동산실명법 위반) | **유효** |
| 세금 면탈 목적 다운계약서 | **유효** |
| 강제집행 면탈 목적 | **유효** |
| 형사사건 성공보수 약정 | ~~유효~~ (2015년 판례) |

### (5) 2024.4.25 판례 (유사수신행위)

> 형사 처벌 대상이라는 사정만으로 **사법적 효력이 당연히 무효는 아님**

## 4. 제103조: 반사회적 행위

### (1) 세 가지 유형 (대법원)

| 유형 | 설명 | 예시 |
|:----|:----|:----|
| **ㄱ** | 행위 **내용 자체** 반사회적 | 살인 청부, 살 1kg 2억 판매 |
| **ㄴ** | 내용 OK, **강제·조건 부가** | 도박자금 목적 대여 |
| **ㄷ** | **동기 불법** | 불법 동기가 표시된 경우 |

### (2) 동기 불법

| 요건 | 효과 |
|:----|:----|
| 불법 동기 + **표시/인식** | **무효** |
| 불법 동기 + 미표시/미인식 | **유효** |

> 예시: 도박자금으로 빌림 → 상대방이 **알면** 무효, **모르면** 유효

### (3) 예외: 보험금 부정 취득 목적

- 생명보험 계약을 **보험금 부정 취득 목적**으로 체결
- 상대방(보험회사) 인식 여부 **무관하게 무효**

### (4) 효과

| 효과 | 내용 |
|:----|:----|
| **절대적 무효** | |
| **추인 불가** | [[무효행위_추인_전환.md|제139조]] 적용 X |
| **제746조 연결** | 불법원인급여 |

## 5. 제104조: 불공정한 행위

### (1) 요건

**급부와 반대급부의 현저한 불균형** + 궁박·경솔·무경험 이용

### (2) 적용 범위

| 적용 O | 적용 X |
|:-------|:------|
| **유상거래**만 | 무상거래 (증여) |
| | **경매** |

> 경매: 유찰 반복 시 시가 30%까지 낙찰 → 제104조 적용하면 모든 경매 무효 위험
