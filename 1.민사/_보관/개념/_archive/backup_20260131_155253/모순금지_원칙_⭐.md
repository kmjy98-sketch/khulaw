# 2. 모순금지 원칙 ⭐

| 구조       | 설명                    |
| ---------- | ----------------------- |
| 선행행위 A | 상대방에게 신뢰 제공    |
| 후행행위 B | A와 모순된 행위         |
| 효과       | B 행위의 효력 제한/부정 |

**적용되는 경우** (부정):

- 무권대리인이 본인 지위 취득 후 무권대리 주장
- 취득시효 관련 판례

**적용 안 되는 경우** (후행행위 인정):

1. 강행법규 위반 약정의 무효 주장 → 인정
2. 의사무능력자의 무효 주장 → 인정
3. 미성년자의 취소권 행사 → 인정
4. 상속의 사전포기 후 상속권 주장 → 인정
