# 5. 복습 포인트

- [ ] [채권자대위] 대위소송 중 피대위채권 양수 후 소 변경 시 최초 대위소송 시점으로 시효중단 소급.
- [ ] [사망자 소송] 상속인으로 **표시정정**을 해야만 170조 재소(6개월) 특례 적용 가능. 정정 없이 각하되면 적용 불가.
- [ ] [추심소송] 2025 전원합의체 변경: 채무자의 원고적격 유지됨. 추심채권자의 후소는 중복제소 각하. (기존: 채무자적격 상실 각하).
- [ ] [압류 통지] 물상보증인 압류 -> 주채무자 통지 필요. 주채무자 압류 -> 보증인 통지 불요.
