# 2. 관습법

| 요소                 | 내용                                                         |
| -------------------- | ------------------------------------------------------------ |
| **개념**             | 사회의 거듭된 관행 + 법적 확신 → 법적 규범으로 승인          |
| **성립요건** (4가지) | ① 관행의 존재 ② 일정기간·지역 계속 ③ 법적 확신 ④ 헌법 불위배 |
| **성립시기**         | 관습이 행해진 때로 소급 (법원의 확인은 사후적)               |
| **효력상실**         | 사회구성원이 더 이상 규범으로 받아들이지 않을 때             |

> **인정된 관습법**: 분묘기지권, 관습법상 법정지상권, 명인방법, 양도담보
