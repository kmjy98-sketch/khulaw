# 7차시 수업정리 민사집행법 전부명령

> 교재: 송영곤, 기본민법 (175~178p) + 민사집행법 기초 자료
> 원본: 7-1, 7-2, 7-3 교정본

---

## 1. 108조 2항 "대항하지 못한다"의 의미

### 1.1 인적 범위 (175~178p)

**무효 주장 불가자**:

1. 당사자 및 포괄승계인
2. **당사자의 채권자, 특정승계인 포함**
3. **모든 제3자**가 무효 주장 불가

- 근거: 《교재》 175p, 사례 16번

---

## 2. 민사집행법 체계

### 2.1 구조

| 편 | 내용 |
|---|-----|
| 1부 | 강제집행 (강제경매) |
| 2부 | 담보권 실행 (임의경매) |
| 3부 | 보전처분 (가압류, 가처분) |

---

### 2.2 강제경매 vs 임의경매 ★★★

| 구분 | 강제경매 | 임의경매 |
|-----|---------|---------|
| 집행권원 | **필요** | **불필요** |
| 필요서류 | 집행정본 | 등기부등본 |
| 공신력 | **있음** | **없음** |

**공신력 의미**:

- 강제경매: 집행채권 부존재/소멸해도 매수인 소유권 취득
- 임의경매: 저당권 부존재/무효 → 매수인 소유권 취득 **못함**

**임의경매 공신력 예외** (2가지):

1. 경매 개시 시 저당권 존재 → 중간 소멸 → 이해관계인 취소 안 함
2. **통정허위표시로 저당권 설정** → 매수인이 108조 2항 선의 제3자

---

## 3. 부동산 강제집행 절차

### 3.1 압류 → 환가 → 배당

**경매 개시 결정**:

- 경매 절차 개시 + 압류 **동시 결정**
- 법원 → 등기관에 촉탁 → 갑구에 경매개시결정 기입 (=압류등기)

**처분금지효**:

- 의미: 채무자는 부동산 처분 금지
- 위반 시: **상대적 무효** (경매 신청자·배당참가자에게만 효력 주장 불가)

---

### 3.2 매각 조건 (민집법 91조) ★★★

| 조항 | 내용 | 소멸/인수 |
|-----|------|---------|
| 91조 2항 | 저당권 | **소멸** |
| 91조 3항 | 용익물권 (선순위 저당권 있으면) | **소멸** |
| 91조 4항 | 최선순위 용익물권 | **인수** |
| 91조 5항 | **유치권** | **인수** |

**매수인 소유권 취득 시점**: **매각대금 완납 시** (187조)

---

## 4. 채권에 대한 강제집행 ★★★★★

### 4.1 제3채무자 구조

```
갑 ──[집행채권]──→ 을 ──[피압류채권]──→ 병(은행)
   (집행채권자)     (집행채무자)        (제3채무자)
```

---

### 4.2 추심명령 vs 전부명령 ★★★★★

| 구분 | 추심명령 | 전부명령 |
|-----|---------|---------|
| 채권 독점 | X | **O** |
| 채권 이전 | X | **O** |
| 변제 효과 | X | **O** (권면액만큼 소멸) |
| 제3채무자 무자력 위험 | **불부담** | **부담** |
| 경합 | 자유 | **민감** (무효 가능) |
| 배당절차 | 있을 수도/없을 수도 | **없음** |
| 집행채무자 송달 | 임의 | **필수** |

---

## 5. 추심명령 상세

### 5.1 법정소송담당

- **개념**: 거래 당사자 아닌 제3자가 원피고가 되는 현상
- **종류**: 법정소송담당(추심명령, 채권자대위) / 임의적 소송담당

### 5.2 2024.10.23 전원합의체 ★★★★★

| 구분 | 종전 | 변경 후 |
|------|-----|--------|
| 유형 | 가음형 | **병행형** |
| 채무자 소제기 | 원고적격 흠결 → 각하 | 원고적격 **인정** |

> "압류추심명령이 있더라도 채무자가 제3채무자를 상대로 이행의소를 제기할 당사자적격을 상실하지 아니한다"

---

## 6. 전부명령 상세

### 6.1 경합의 의미

**기준**: 전부명령이 **제3채무자에게 송달된 날짜**

```
경합 O: 기준 시점 이전에 다른 채권자의 압류/가압류 결정 송달
경합 X: 기준 시점 이후에 송달
```

### 6.2 경합 시 무효 여부

```
집행채권액 합계 > 피압류채권액 → 전부명령 무효
집행채권액 합계 ≤ 피압류채권액 → 전부명령 유효
```

**무효 효과**:

- 전부명령만 무효 (압류는 영향 없음)
- 시효중단 효과 유지
- 한번 죽은 전부명령은 **부활 안 됨**

---

### 6.3 채권의 준점유자에 대한 변제, ★★★

| 상황 | 적용 여부 |
|------|----------|
| 피압류채권 **존재** + 전부명령 무효 | 적용 O |
| 피압류채권 **부존재** | 적용 X |

---

## 7. 가압류/가처분

### 7.1 가압류

- **목적**: 금전채권 보전
- **신청자**: 금전채권자

### 7.2 가처분

- **목적**: 특정채권 보전
- **처분금지가처분**: 가장 기초적, 시험 빈출
