# 8차시 수업정리 착오 조건기한 일부무효

## 1. 109조와 110조의 관계 ★★★★★

### 1.1 통설 vs 판례

| 구분 | 내용 |
|-----|------|
| **통설** | 109조와 110조는 **선택관계** |
| **판례** | **109조가 특칙** → 110조 적용 배제 |

**판례 취지**: 제3자 기망으로 착각에 빠져 서명 → 사기(110조) 아닌 **착오(109조)** 적용

---

### 1.2 A문서/B문서 사건 ★★★★

**개념**: A문서인 줄 알고 B문서에 서명날인 + 제3자 기망 개입

| 논점 | 내용 |
|-----|------|
| ① 109조 특칙 | 갑이 알았는지 **따지지 않음** (110조 2항 적용 X) |
| ② 표시착오 | 동기착오 X, **표시착오**로 봄 |
| ③ 중요부분 | **경제적 이익 차이** 기준 |

**중요부분 판단 사례**:

| 사례 | 결론 |
|-----|------|
| 신원보증 vs 연대보증 | 중요부분 O |
| 차용금보증 vs 구상금보증 | 중요부분 X (경제적 부담 차이 없음) |

---

### 1.3 109조와 다른 조문의 경합

**580조(담보책임)와 경합**:

| 견해 | 내용 |
|-----|------|
| 통설 | 580조 성립 시 109조 배제 |
| **판례 (2018)** | **선택** 가능 |

**해제와 취소의 경합**:

- 해제로 소급 소멸된 계약도 **취소 가능** (판례)
- 실익: 551조 → 착오취소 인정 시 손해배상책임 면함

## 2. 사기·강박 (110조)

### 2.1 요건

| 요건 | 내용 |
|------|------|
| 의사표시 존재 | - |
| **이단의 고의** | ① 착오에 빠뜨리려는 의사 + ② 의사표시하게 만드는 의사 |

**제3자에서 제외되는 자**:

- 상대방의 대리인
- 상대방과 동일시할 수 있는 자

## 3. 조건 (147~151조) ★★★

### 3.1 개념

- **정의**: 법률행위 효력의 발생·소멸을 **장래 불확실한 사실**에 의존케 하는 부관
- 표시 필요 (마음속에만 있으면 동기에 불과)

### 3.2 조건의 종류

| 종류 | 내용 | 효력 |
|------|------|------|
| 정지조건 | 조건 성취 시 효력 발생 | - |
| 해제조건 | 조건 성취 시 효력 소멸 | - |
| 순수수의조건 | 일방 의사에만 달림 | **무효** |
| 기성조건 | 법률행위 당시 이미 성취 | 정지조건=조건 없음, 해제조건=**무효** |
| 불능조건 | 성취 불가 확정 | 정지조건=**무효**, 해제조건=조건 없음 |
| 불법조건 | 선량한 풍속 위반 | **법률행위 전체 무효** |

### 3.3 조건 성취 방해 (150조) ★★★★

| 조항 | 내용 |
|------|------|
| 150조 1항 | 불이익 받을 자가 **신의칙 위반**하여 성취 방해 → 성취된 것으로 주장 가능 |
| 150조 2항 | 이익 받을 자가 **신의칙 위반**하여 성취 → 불성취로 주장 가능 |

**2022년 판례**: 방해 없어도 성취 가능성 **현저히 낮은 경우** → 150조 1항 적용 X

## 4. 기한 (152~153조)

### 4.1 불확정기한 vs 정지조건 ★★★

**구별 기준 (판례)**:

- 사실 발생 않으면 채무이행 안 해도 됨 → **정지조건**
- 불발생 확정되어도 이행해야 함 → **불확정기한**

### 4.2 기한의 이익 (153조)

- **원칙**: 채무자 이익 추정 (153조 1항)
- **포기**: 상대방 이익 해하지 않는 범위에서 가능 (153조 2항)

---

## 5. 일부무효 (137조) ★★★★

### 5.1 법조문

> 법률행위의 일부분이 무효인 때에는 그 **전부를 무효**로 한다.
> 다만, 그 무효부분이 없더라도 법률행위를 하였을 것이라고 인정될 때에는 나머지 부분은 무효가 되지 아니한다.

### 5.2 처리 순서

| 순서 | 기준 |
|------|------|
| 1차 | 당사자 **현실적 합의** → 합의대로 처리 |
| 2차 | 137조 적용 → **전부 무효**가 원칙 |
| 3차 | 단서: **가정적 의사** 탐지 → 나머지 살릴 수 있음 |

### 5.3 일부취소 ★★★★

**가능 요건**:

1. 법률행위 **가분적** 또는 목적물 일부 **특정 가능**
2. 나머지 유지하려는 **가정적 의사** 인정

**불가 → 전부취소**:

- 각 계약이 **경제적·사실적 일체**로 행해짐
- 하나가 다른 하나의 **조건**이 됨
