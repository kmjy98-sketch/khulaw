# 강행법규위반 정관 기본재산처분

# 민법강의 수업정리 Part 18 (강행법규 위반 사례 · 정관 · 재단법인 기본재산)

## 1. 강행법규 위반 사례 분석 (사례 5번)

### (1) 사실관계 요약

| 항목 | 내용 |
|:----|:-----|
| 법인 | A학교법인 (사립학교) |
| 대표자 | 갑 |
| 행위 | 처 을의 사업자금 목적으로 병 은행에서 1억 대출 |
| 위반 | 사립학교법상 5천만 원 초과 채무부담 시 **관할청 허가** 미이행 |
| 병 은행 | 사립학교법 제한 및 을 사업자금 용도 모두 **선의** |

### (2) 사립학교법 위반의 효력

> "**강행법규** 위반 → **무효**" (판례 확립)

---

## 2. [[일부무효_추인_전환.md|일부무효]] ([[일부무효_추인_전환.md|제137조]])

### (1) 쟁점

5천만 원까지 자유 대출 가능 → 1억 대출 시 **전부 무효**? **일부 무효**?

### (2) 판단 기준

> "강행법규의 **입법취지**를 고려하여 판단"

**사립학교법 취지**: 법인의 **재무건전성** 보호

→ 5천만 원은 유효, 초과 5천만 원만 무효 (**일부무효**)

### (3) 모순행위 금지와의 관계

> "강행법규 위반자가 사후에 무효 주장 → **모순행위 아님**"
> (제한능력자, 의사무능력자의 취소/무효 주장과 동일)

---

## 3. 제35조 vs 제126조 — 강행법규 위반 시 (특A급)

### (1) 쟁점

강행법규 위반으로 대표행위 무효 시 → 상대방이 법인에 책임을 물을 수 있나?

| 청구 근거 | 인정 여부 | 이유 |
|:---------|:---------|:-----|
| **제35조 제1항** (불법행위) | **O** | 직무집행행위로 인정 |
| **제126조** (표현대리) | **X** | 가치평가 모순 방지 |

### (2) 제126조 부정 논거

1. 특별법(사립학교법)이 **무효**로 선언
2. 민법(제126조)으로 우회하여 **유효**로 부활 → 동일 법체계 내 **가치평가 모순**
3. 특별법 취지(재무건전성 보호) 훼손

> - 근거: 전사문 part23 "특별법에서 무효라고 주장했던 거는... 일반 조항인 민법을 우회해 가지고... 가치평가의 모순"

### (3) 사례 적용

| 청구 | 결과 |
|:----|:-----|
| 유효 5천만 원 | 금전소비대차계약에 따라 반환 청구 가능 |
| 무효 5천만 원 | 제126조 X → 제35조 불법행위 + 부당이득 청구 |

**주의**: 무효 부분에서는 **대표권 남용 법리 검토 불요** (계약 책임 자체가 없음)

## 4. 정관의 의의와 해석

### (1) 정관의 성격

| 항목 | 내용 |
|:----|:-----|
| **의의** | 법인의 정체성 (두뇌) |
| **성격** | 자치법규 |
| **해석 방법** | 법규해석의 방법 |

### (2) 정관 해석 판례 (2000.11.24.)

**사안**: 사단법인 정관에 "회장 중임 금지" 규정

- 보선 회장이 "땜빵이므로 중임 제한 적용 안 됨" 주장
- 대의원 총회에서 다수 결의로 "보선 회장 중임 가능" 결의

**판시**:

- 정관은 **법규해석**으로 해석
- 법규해석 결과와 다른 내용으로 다수 결의해도 → **구속력 없음**
- 보선 회장도 중임 제한 대상에 **포함**

## 5. 정관의 변경

### (1) 사단법인 정관 변경

| 요건 | 내용 | 조문 |
|:----|:-----|:-----|
| **의결기관** | 사원총회 (전권 사항) | — |
| **의결정족수** | 총사원 **3분의 2** 이상 | — |
| **허가** | 주무관청 허가 필요 | — |
| **한계** | 정관에 "변경 불가" 규정 있어도 **전 사원 동의** 시 변경 가능 | — |

### (2) 재단법인 정관 변경 (빈출)

| 조문 | 내용 | 허가 시기 |
|:----|:-----|:---------|
| **제45조 제1항** | 정관에 변경 방법 규정 있으면 → 변경 가능 | 사후 허가 |
| **제45조 제2항** | 정관에 규정 없으면 → **명칭·사무소 소재지**만 변경 가능 (목적달성/재산보전 필요 시) | 사후 허가 |
| **제46조** | **목적** 변경 → 목적 달성 불가 시 주무관청 허가로 변경 | **사전 허가** |

> **핵심**: 목적 변경은 **사전 허가**, 기타는 **사후 허가**

## 6. 재단법인 기본재산 처분

### (1) 논리 구조

```
재단법인 재산 = 정관 필수적 기재사항
   ↓
재산 변동 = 정관 변경
   ↓
정관 변경 = 주무관청 허가 필요
   ↓
∴ 기본재산 처분 = 주무관청 허가 필요
```

### (2) 허가 시기

> "처분 시까지 받으면 족하다" (사전 허가 불요)

**소송 시**: **사실심 변론종결시**까지 허가받으면 OK

### (3) 주무관청 허가가 **불요**한 처분행위

| 유형 | 이유 |
|:----|:-----|
| **지상권 설정** | 처분행위이나 허가 불요 (판례) |
| **저당권 설정** | 처분행위이나 허가 불요 (판례) |
| **명의신탁재산 반환** | 원래 법인 재산 아님 |

### (4) 허가가 **필요**한 행위

| 유형 | 비고 |
|:----|:-----|
| 기본재산 **처분** (매도 등) | 원칙 |
| 기본재산 **편입** | 들어오는 것도 허가 필요 |
| **소멸시효 이익 포기** | 채무 부담 효과 발생 |

### (5) 경매 시 처리

**원칙**: 경매도 **주무관청 허가 필요** (매매와 본질 동일)

**절차**:

1. 허가 없는 학교법인 토지 경매 시
2. 집행법원은 **경매 중단 불요**
3. "허가 없음 → 소유권 취득 불가 가능성" **공지** 후 진행
4. **매각허가결정** 시까지 허가 받으면 유효
