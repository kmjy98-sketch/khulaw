# 민법강의 수업정리 Part 21 (종중 성립·조직)

## 1. 종중의 개념과 성립

### (1) 종중의 개념

**정의**: 공동선조 후손들이 모여 제사를 지내고 선조 재산을 관리하는 **비법인사단**

| 항목 | 내용 |
|:----|:-----|
| 목적 | 공동선조 제사, 종(宗) 재산 관리 |
| 성질 | **비법인사단** |
| 재산 | **총유** |

### (2) 종중의 성립 요건

| 구분 | 내용 |
|:----|:-----|
| 성립 방식 | **자연 발생적** (피로 맺어짐) |
| 설립 행위 | **불요** (교회와 다름) |
| 조직행위 | **불요** |
| 서면 규약 | **불요** |
| 상시 대표자 | **불요** |

> 교회: 설립행위 + 조직행위 필요 vs 종중: 혈연으로 자동 성립

---

## 2. 종원(宗員) 자격

### (1) 자격 요건

| 요건 | 내용 |
|:----|:-----|
| 연령 | **성년** 필수 |
| 성별 | **제한 없음** (대법원 2005.7 판례) |
| 가입 | 자동 (의사 무관) |
| 탈퇴 | **불가** (성 변경 제외) |

### (2) 주요 판례

| 판례 | 내용 |
|:----|:-----|
| **대법원 2005.7** | 여성도 종원 가능 (관습법 위헌) |
| **대법원 2022.5** | 성 변경 시 → 변경한 쪽 종중 종원 됨 (절차 불요) |

### (3) 종원 자격 관련 법리

| 행위 | 효력 |
|:----|:-----|
| 후손 아닌 자에게 종원 자격 부여 | **무효** |
| 강제 자격 박탈 (할종-割宗) | **무효** |
| 타가 출계 (친양자 등) | 기존 종중 탈퇴 **유효** |

---

## 3. 소종중과 대종중

| 구분 | 설명 | 비법인사단 여부 |
|:----|:-----|:--------------|
| **소종중** | 특정 공동선조 중심 | **O** |
| **대종중** | 소종중들의 연합체 | **X** (비법인사단 아님) |

> 공동선조가 누구냐에 따라 종중 동일성 판단

---

## 4. 제사주재자 (제사 담당자)

### (1) 종중의 제사주재자 = 종손

| 항목 | 내용 |
|:----|:-----|
| 자격 | **적장자** 쪽 남자 자손 |
| 서자 | **불가** |
| 여성 | **불가** (변경 없음) |

### (2) 일반 제사주재자 (종중 外) — 판례 변천

| 시기 | 기준 |
|:----|:-----|
| 1기 | 남자 자손 (관습법) |
| 2기 | 합의 → 없으면 남자 자손 (조리) |
| **현재 (3기)** | **합의** → 없으면 **최연장자** (성별·적서 불문) |

> ※ 종중 제사주재자는 여전히 남자 적장자 쪽 종손

---

## 5. 대표기관 (대표자)

### (1) 문장·종장 vs 대표자

| 구분 | 문장/종장 | 대표자 |
|:----|:---------|:------|
| 성격 | 집안 어르신 (사회적 명칭) | 법적 대표권 보유 |
| 상시 존재 | O | **X** (필요시 선임) |
| 소집권 | O | — |

### (2) 대표자 선임

- **평소**: 대표자 없음
- **필요시**: 종원 모여 의결로 선임
- **소장 첨부**: 종중회의록 (대표자 선임 증빙)

### (3) 특정인 대표자 고정 규약

> **대법원 2024.12.24**: 특정 종손 계열만 대표자 되는 규약 → **제103조 위반 (무효)**

---

## 6. 종중 회의

### (1) 소집권자

- 문장/종장 (집안 어르신)
- 대표자 (선임되어 있는 경우)

### (2) 소집 방법

| 항목 | 내용 |
|:----|:-----|
| 통지 대상 | 국내 거주 + 알고 있는 종원 전원 |
| 회의 사항 | 사전 기재 필요 |

### (3) 절차 위반 효과

| 하자 유형 | 효력 |
|:---------|:-----|
| 소집권 없는 자의 소집 | 원칙 무효 (예외 有) |
| 소집 통지 누락 | 원칙 무효 (예외 有) |
| 회의 목적 미기재 사항 결의 | 합리적 추론 가능하면 유효 |
| 종원 아닌 자 참여 | 원칙 무효 (예외 有) |

> 각 하자별로 원칙/예외 암기 필요 (88~89페이지)

---

## 7. 불공정한 종중 결의

### (1) 효력

| 사유 | 효력 |
|:----|:-----|
| 현저히 불공정한 결의 | **무효** (제103조) |
| 선량한 풍속 위반 | **무효** |

**사례**: 종산 100억 매각 → 혼인 남성 5억, 비혼 여성 5천만 원 → **무효**

### (2) 사후 구제 절차

| 단계 | 내용 |
|:----|:-----|
| 1 | **결의무효확인** 소송 제기 |
| 2 | 승소 판결 받음 |
| 3 | **새 종중 회의**에서 공정하게 재결의 |

> **직접 이행청구 불가** → 종중회의 거치지 않고 바로 돈 달라 → **각하**

## 9. 복습 포인트

- [ ] 종중 성립: **자연 발생적**, 설립행위·조직행위·서면규약 불요
- [ ] 종원: **성년**, 성별 무관, 탈퇴 불가 (성 변경만 예외)
- [ ] 문장/종장 ≠ 법적 대표자 (집안 어르신일 뿐)
- [ ] 대표자: 필요시 선임, 소장에 **종중회의록** 첨부
- [ ] 특정인 대표 고정 규약: **제103조 위반 무효**
- [ ] 불공정 결의: 무효 → 결의무효확인 소송 → 재결의 필요
- [ ] 직접 이행청구: **각하**
- [ ] 종중 분열: **불인정**
