# 소멸시효 중단 — 승인과 재진행

> **핵심 요약**: 승인은 관념의 통지(처분능력 불요). 중단의 인적범위 = 절대적 효력 사유가 핵심. 재진행(178조) 시점은 중단사유별 상이. 가압류는 유지되는 동안 수레바퀴 정지.

## 1. 승인 (제177조, 168조 3호) ★★★★

### 기본 구조

| 항목 | 내용 |
|------|------|
| **정의** | 채무자가 권리 존재를 인정하는 표시 (관념의 통지) |
| **성질** | 준법률행위 (포기와 다름!) |
| **방식** | 특별한 방식 불요, 명시적/묵시적 모두 가능 |

### 승인 능력 (177조)

- **처분 능력** 불요 → 관리·보존 권한 정도면 충족
- 미성년자: 원칙 유효 (취소 가능)
- 피성년후견인: 관리능력 없어 **승인 효력 X**
- 근거: 전사문 "처분권은 있을 필요가 없다 ... 관리 보존할 수 있는 관리 권한 정도는 있어야 되고"

> 177조는 **프랑스 민법**에서 유래

### 승인 인정 사례

- **채권 목록 제출** (회계감사): 승인 O
- **사전 승인**: 시효 완성 전 미리 승인 약정 = **무효** (시효배제특약 금지)

### 승인 vs 포기 구별 ★★★★★

| 구분 | 승인 | 포기 |
|------|------|------|
| **성질** | 관념의 통지 (준법률행위) | **법률행위** (효과의사 필요) |
| **시점** | 시효 **완성 전** | 시효 **완성 후** |
| **비유** | 육두품 (중산층) | 성골·진골 (귀족) |

- 대법원이 태생적으로 다르다고 일관 판시
- 2025.7 전합 판결의 핵심 근거 중 하나
- 근거: 전사문 "포기는 법률행위이다 ... 승인은 관념의 통지 ... 태생이 달라"

## 2. 중단의 인적 범위 ★★★★★

### 원칙: 당사자와 승계인 (제169조)

- 시효중단은 **당사자 및 승계인** 간에만 효력 (상대효 원칙)
- 승계인 = 특정승계인 + 포괄승계인 모두 포함

### 복수 채무자 출제의 핵심 ★★★★★

> **출제 패턴**: 채무자 복수 → 한 명에 중단 조치 → 다른 채무자에 효력?

- 근거: 전사문 "소멸시효가 메인으로 나오면 40점 정도 ... 일대일로 내면 작은 논점 10점짜리 ... 채무자를 복수로 끌고 오지"

**채무자 복수 유형**:

| 관계 | 성격 |
|------|------|
| **연대채무** | 지위 동등, 묶여 있음 |
| **부진정연대채무** | 지위 동등, 느슨한 묶임 |
| **불가분채무** | 지위 동등 |
| **주채무자-보증인** | 지위 상이 |

---

### 연대채무 절대적 효력 (암기법) ★★★★★

> **시혼면 변공대 경상 지청**

| 약어 | 사유 |
|------|------|
| 시 | 시효완성 |
| 혼 | 혼동 |
| 면 | 면제 |
| 변 | 변제 |
| 공 | 공탁 |
| 대 | 대물변제 |
| 경 | 경개 |
| 상 | 상계 |
| 지 | 이행지체 |
| 청 | **이행청구** |

- **이행청구 = 절대효**: A에게 전화(갚아라) → BC에게도 갚으라 한 것과 같은 효과
- **부담부분에 한하는 사유**: 시·혼·면·상

### 부진정연대채무 절대효

- **변·공·대·상**만 절대효
- **이행청구(시효중단)**: **상대효** → 한 명에 청구해도 다른 자 무관
- 근거: 전사문 "부진정 연대채무는 ... 이행청구는 절대적 효력이 없다 ... 변공대상만"

### 보증채무 절대효 ★★★★★

| 방향 | 효력 |
|------|------|
| **주채무자 → 보증인** | **모두 효력** (시효이익 포기만 제외) |
| **보증인 → 주채무자** | **4가지만**: 변제·공탁·대물변제·상계 |

- 근거: 전사문 "주채무자에게 생긴 사유는 보증인한테 다 효력을 미쳐요 ... 반대로 보증인에게 생긴 사유는 딱 네 가지만"

### 압류·가압류에서의 인적 확장

- 연대채무자 1인에 대한 압류 → 다른 연대채무자에 **최고의 효력** 인정
- 6개월 내 후속조치 시 시효중단 가능
- **176조**: 다른 채무자에 **통지** → 중단효 인적 범위 확장

## 3. 시효의 재진행 (제178조) ★★★★★

### 기본 구조

1. **178조 1항**: 중단까지 경과한 시효기간 **산입하지 않음** (0으로 리셋)
2. 중단사유 **종료** 시 → 기산일② 등장 → 기간 더하기 → 완성일②

### 재진행 시점 (중단사유별)

| 중단 사유 | 재진행 시점 (기산일②) |
|----------|---------------------|
| **재판상 청구** | **판결 확정** 시 (178조 2항) |
| **승인** | 승인 시점 (또는 익일) |
| **부동산 압류** | **배당표 확정** 시 |
| **채권 압류** | **해·종·소** (해제/종료/피압류채권소멸) |
| **최고** | 후속 중단사유 종료 시 |

### 채권 압류 재진행 (해·종·소) ★★★★

| 약어 | 내용 |
|------|------|
| **해**(제) | 신청 취하, 결정 취소 |
| **종**(료) | 추심 완료, 전부명령 확정 |
| **소**(멸) | 피압류채권 실효, 소멸시효 완성 |

### 가압류 특수성 ★★★★★

- 가압류 **유지되는 동안** → **계속 시효중단** (수레바퀴 정지)
- 본안승소판결 확정되어도 가압류 유지 시 → 시효 **재진행 안 함**
- 재진행 시점: **가압류가 취소/해제된 때**
- 근거: 전사문 "가압류인 상태에서는 절대로 수레바퀴가 움직이지 않는다"

### 165조와의 결합

- 재판상 청구로 중단 + 165조 1항 → **기간 10년으로 연장**
- 기산일② = 판결 확정일, 기간 = 10년

## 4. 복습 포인트

- [ ] 승인 = **준법률행위** (관념의 통지), 처분능력 **불요**
- [ ] 승인 vs 포기: **태생이 다름** → 2025.7 전합 핵심
- [ ] 연대채무: **시혼면 변공대 경상 지청** 절대효
- [ ] 부진정연대: **변공대상**만 절대효, 이행청구 = 상대효
- [ ] 보증: 주→보 **전부** (포기 제외), 보→주 **변공대상**만
- [ ] 178조: 중단까지 기간 **0으로 리셋**
- [ ] 가압류 = 유지 동안 **시효 멈춤** (수레바퀴 정지)
- [ ] 재판상 청구 재진행 = **판결 확정** 시점
- [ ] 채권 압류 재진행 = **해·종·소**
