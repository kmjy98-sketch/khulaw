# 민법강의 수업정리 Part 19 (경매와 주무관청 허가 · 비법인사단)

## 1. 부동산 경매 절차 개관

| 단계 | 내용 | 핵심 |
|:----|:-----|:-----|
| **① 압류** | 경매 신청 → 경매개시결정 → 압류등기 | 처분금지 효과 |
| **② 환가** | 입찰 → 최고가매수신고인 → **매각허가결정** → 대금 납입 | 소유권 이전 |
| **③ 배당** | 경매비용 공제 → 우선변제권자 → 일반채권자 | 평등주의, 안분배당 |

### 핵심 용어

- **경매개시결정**: 법원이 경매 요건 충족 시 → "경매 개시 + 압류" 결정
- **압류등기**: 경매개시결정 기입등기 (줄인 말)
- **매각허가결정**: 최고가매수신고인에게 매수 자격 부여
- **우선변제권**: 저당권자 등 → 일반채권자보다 먼저 배당
- **평등주의·안분배당**: 일반채권자는 순서 동일, 채권액 비례 배당

## 2. 경매와 주무관청 허가

### (1) 원칙: 경매도 허가 필요

> "주무관청의 허가를 요하는 처분에는 **경매도 포함**"

**허가 시점**:

- 경매개시 요건 X (경매 시작에는 불요)
- **소유권 취득 요건** O (**매각허가결정** 시까지)

**절차**:

1. 집행법원 → 허가 없음 공지 (**특별매각조건**)
2. 경매 진행
3. **매각허가결정** 시까지 허가 서류 제출
   - 제출 O → 속행
   - 제출 X → **매각불허가** → 경매 취소

### (2) 저당권 설정 시 허가와 경매

| 경매 유형 | 허가 효력 | 이유 |
|:---------|:---------|:-----|
| **[[민사집행_경매와배당.md|임의경매]]** (저당권 실행) | 저당권 설정 시 허가로 **대체** | [[임의경매]] 예정 포함 |
| **[[민사집행_경매와배당.md|강제경매]]** (집행권원) | **별도 허가 필요** | 저당권 허가 ≠ [[강제경매]] 허가 |

> - 근거: 전사문 part24 "강제경매로 들어오면 별도 허가가 필요해. 주무관청의 허가는 임의경매에 관해서 허가를 해 준 거지"

### (3) 강제경매 허가 예외 (93.7. 판례)

> "매각대금이 **전부 선순위 저당권자**에게 배당 → 임의경매와 결과 동일 → 저당권 설정 시 허가로 **대체 가능**"

## 3. 무단처분의 효력

### (1) 효력

| 항목 | 결론 |
|:----|:-----|
| 채권적 효력 | **무효** |
| 물권적 효력 | **무효** |

→ 일반 처분, 강제경매 모두 **무효**

### (2) 무효 주장과 신의칙

**원칙**: 신의칙에 반하지 않음 (모순행위 금지 아님)

**모순행위 아닌 3대장**:

1. 제한능력자의 취소
2. 의사무능력자의 무효 주장
3. **강행법규 위반 후 무효 주장**

### (3) 사후추인 불가 — 원칙

> "무단처분 후 법인이 추인해도 **유효 안 됨**" (주무관청 허가 잠탈)

### (4) 예외적 추인 인정 (판례)

**요건**:

1. 기본재산을 **보통재산**으로 변경하는 **정관 변경**
2. 그 정관 변경에 대해 **주무관청 허가**
3. 그 후 **추인**

→ 추인 시점부터 **유효** (소급효 X)

## 4. 비법인사단 (非法人社團)

### (1) 의의

| 항목 | 내용 |
|:----|:-----|
| 정의 | 주무관청 허가 + 법인 등기 **없이** 존재하는 사람의 단체 |
| 법인격 | 없음 (법인격 없는 사단) |
| 권리 주체 | **비법인사단 자체**가 권리·의무 주체 (구성원 아님) |

### (2) 비법인사단 vs 조합

| 구분 | 비법인사단 | 조합 |
|:----|:----------|:-----|
| 단체성 | **강함** | 약함 |
| 권리 주체 | 단체 자체 | 조합원 전체 |
| 등기 | 비법인사단 이름 가능 | 조합원 명의 **합유등기** |
| 소송 | 비법인사단이 당사자 | 조합원 전체 (고유필수적 공동소송) |

**주의**: 명칭에 좌우되지 않음 (노동조합 → 비법인사단)

### (3) 성립 요건

1. **규약** (정관에 해당)
2. **의사결정기관** + **집행기관**
3. **다수결의 원칙**
4. 구성원 변경 시에도 **단체 존속**

**종중 특례**: 규약 서면화, 대표자 선임 **불요**

- 이유: 혈연으로 엮여 있음 → 요건 완화

## 5. 비법인사단의 법적 지위

### (1) 기본 원칙

> "민법상 **사단법인에 관한 규정**을 **유추적용**"

### (2) 유추적용 가능 규정

| 규정 | 내용 |
|:----|:-----|
| **제35조 제1항** | 불법행위 책임 (종중, 노동조합, 주택조합) |
| **제56조** | 사원 지위 양도·상속 |
| **제63조** | **임시이사** 선임 가능 (2009.11.19. 전합) |
| **제71~75조** | 사원총회 소집·결의 절차 |
| 해산·청산 규정 | 유추적용 |

### (3) 유추적용 불가 규정

| 규정 | 이유 |
|:----|:-----|
| **제60조** (대표권 제한 등기) | 비법인사단은 **등기 없음** |
| **제70조 제3항** (법원 허가 총회 소집) | 차석/발의자가 직접 소집 가능 |

> **중요**: 비법인사단 총회 소집 시 **법원 허가 불요** (소집권자가 응하지 않으면 차석/발의자가 직접)

## 6. 복습 포인트

- [ ] **경매 절차**: 압류 → 환가 → 배당
- [ ] **매각허가결정**: 주무관청 허가 데드라인
- [ ] **임의경매 vs 강제경매**: 저당권 설정 시 허가로 대체 가능 여부
- [ ] **무단처분**: 채권·물권 모두 무효, 추인 원칙 불가
- [ ] **예외적 추인**: 기본재산→보통재산 변경 + 주무관청 허가 + 추인
- [ ] **비법인사단 vs 조합**: 단체성 강도, 권리 주체
- [ ] **제60조 적용 불가**: 비법인사단은 등기 없음
- [ ] **총회 소집**: 법원 허가 불요, 차석/발의자 직접 가능
