# [[전부명령]] 무효 경합

## 1. 전부명령의 무효 사유: 압류의 경합

### 1.1 경합 판단 기준

- **기준 시점**: 전부명령이 **제3채무자에게 송달된 때**
- **경합 여부**:
 	- 집행채권액 합계 > 피압류채권액 → **압류 경합 발생** → **전부명령 무효**
 	- 집행채권액 합계 ≤ 피압류채권액 → 경합 없음 → 전부명령 유효

### 1.2 경합 시 처리

- 이미 다른 채권자의 압류, [[가압류_[[가압류_가처분_[[가압류_가처분_보전처분.md|보전처분]].md|가처분]]_[[보전처분]].md|가압류]] 명령이 제3채무자에게 송달되어 있는 상태에서 전부명령이 송달되면 그 전부명령은 **효력이 없다(무효)**.
- **무효의 효과**:
 	- 전부명령만 무효가 되고, 압류 명령으로서의 효력은 남는다.
 	- 따라서 배당 절차(안분배당)로 넘어가게 된다.
 	- 확정된 전부명령은 부활하지 않는다.

## 2. 채권의 준점유자에 대한 변제 (470조) 적용 여부

- **상황**: 전부명령이 송달되었으나 실체법상 무효인 경우(예: 경합), 제3채무자가 선의로 전부채권자에게 변제했다면?
- **적용**: **적용된다**. (제3채무자 면책)
- **단, 피압류채권 자체가 부존재하는 경우**: 준점유자 변제 법리 적용 **X** (채권이 없으므로 준점유도 성립 불가)
