# [[사기강박]] 조건 기한

## 1. 사기·강박 (110조)

### (1) 요건

| 요건 | 내용 |
|:----|:----|
| **[[착오취소_사기강박_경합.md|이단의 고의]]** | ① 착오에 빠뜨리려는 의사 + ② 의사표시하게 하는 의사 |
| 기망 **위법성** | 사회생활상 용납 수준이면 취소 불가 |

### (2) 110조 2항 (제3자 기망) ★★★★

> 상대방이 **알았거나 알 수 있었을 경우**에만 취소 가능

**제3자 제외 범위**:

- 상대방 대리인
- 상대방과 동일시할 수 있는 자

## 2. 조건 (147~151조)

### (1) 개념

> 법률행위 효력의 발생·소멸을 **장래 불확실한 사실**에 의존

- **표시 필요**: 마음속에만 있으면 조건 X → **동기**

### (2) 조건 종류

| 종류 | 효과 |
|:----|:----|
| [[사기강박_조건_기한.md|정지조건]] | 성취 시 **효력 발생** |
| [[사기강박_조건_기한.md|해제조건]] | 성취 시 **효력 소멸** |
| 순수수의조건 | **무효** |
| [[사기강박_조건_기한.md|기성조건]](정지) | 조건 없는 것 / 기성(해제) → **무효** |
| 불능조건(정지) | **무효** / 불능(해제) → 조건 없는 것 |
| 불법조건 | **법률행위 전체 무효** |

### (3) 조건 성취 방해 (150조) ★★★★

| 조항 | 내용 |
|:----|:----|
| 1항 | 불이익자가 **신의칙 위반** 방해 → **성취** 간주 |
| 2항 | 이익자가 **신의칙 위반** 성취 → **불성취** 간주 |

> 2022 판례: 방해 없어도 성취 가능성 **현저히 낮은 경우** → 150조 1항 X

### (4) 148조 해석 (조건부 권리 보호) ★★★

- [[해제조건]] 성취 → 소유권 복귀
- 조건 **등기 있으면** 제3자 대항 가능
- **등기 없으면** 손해배상만

### (5) 147조 3항 (소급효)

- 당사자 의사표시로 **소급효 부여** 가능

## 3. 기한 (152~153조)

### (1) 개념

> 법률행위 효력을 **장래 확실한 사실**에 의존

### (2) [[사기강박_조건_기한.md|불확정기한]] vs [[정지조건]] ★★★

| 기준 | 처리 |
|:----|:----|
| 불발생해도 이행 **필요** | **[[불확정기한]]** |
| 불발생 시 이행 **불필요** | **정지조건** |

### (3) 147조 vs 152조 비교

| 조건 | 기한 |
|:----|:----|
| 147조 3항: 소급효 **가능** | 152조: 3항 **없음** (소급효 X) |

### (4) 기한의 이익 (153조)

- **원칙**: 채무자 이익 추정 (1항)
- **포기**: 상대방 이익 해하지 않는 범위 (2항)

---

## 4. 148조 판례 상세 (92.5월 해제조건부 증여) ★★★

### (1) 사실관계

- 해제조건부로 부동산 증여
- 수증자가 조건 성취 전 제3자에게 처분

### (2) 등기 유무에 따른 효과

| 조건 등기 유무 | 제3자 대항 | 구제 방법 |
|:---------------|:-----------|:----------|
| **등기 O** | **가능** | 제3자에게 반환청구 |
| **등기 X** | 불가 | 수증자에게 **손해배상**만 |

---

## 5. 불확정기한 판례 (2009.5.14) ★★★

### (1) 사실관계

- 조합 탈퇴자: 새 조합원 가입 시 출자금 정산받기로 약정
- 새 조합원 **미가입 확정**

### (2) 판단

| 쟁점 | 결론 |
|:-----|:-----|
| 불발생 확정 시 이행 필요? | **O** (이행해야 함) |
| 성격 | **불확정기한부** (정지조건 X) |

> 정지조건이면 불발생 시 이행 불필요했을 것
