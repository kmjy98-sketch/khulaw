# 민법강의 수업정리 Part 17 (특별대리인 · 직무대행자 · 대표권 남용 사례)

## 1. 법인 대표기관 대체 정리

| 유형 | 선임 요건 | 조문 | 권한 범위 |
|:----|:---------|:-----|:---------|
| **임시이사** | 이사 부재/결원 + 손해 염려 | 제63조 | 현상유지적 (보전·관리) |
| **특별대리인** | 법인과 이사의 이해상반 | 제64조 | 해당 행위에 한정 |
| **직무대행자** | 직무집행정지 가처분 | — | 상무(통상 업무), 긴급 시 법원 허가 |

> **시험 빈출**: 제63조(임시이사)와 제64조(특별대리인) 요건 섞어서 출제

---

## 2. 특별대리인 (제64조)

**선임 사유**: 법인과 이사의 **이익 상반** 시

**효과**: 해당 이해상반행위에 대해 → 이사 대표권 X → 특별대리인이 법인 대표

**cf. 친권자**: 제921조 이해상반행위 → 특별대리인 선임 (동일 구조)

---

## 3. 직무대행자 — 직무집행정지 가처분 (빈출)

### (1) 의의

**상황**: 이사가 위법행위 계속 → 이해관계인이 **직무집행정지 가처분** 신청

**효과**: 법원이 인용 시

- 해당 이사 → **모든 권한 정지** (직위는 유지)
- **직무대행자** 선임 → 법인 대표

### (2) 가처분 신청 상대방

| 피신청인 | 가능 여부 |
|:--------|:---------|
| **이사 개인** | O |
| **법인** | X |

> - 근거: 전사문 part22 "법인을 상대로 하면 안 됩니다. 법인을 상대로 하는 게 아니라 대표이사 개인을 상대로"

### (3) 조합 청산인 (암기)

> "조합의 청산인에 대해서는 직무집행정지 가처분 신청을 할 수 없다."

### (4) 임기 진행과의 관계

| 쟁점 | 결론 |
|:----|:-----|
| 가처분 기간 동안 임기 중단? | X (임기 진행에 영향 없음) |
| 가처분 중 잔여 임기 도과 시 | 그대로 **퇴임** |

> - 근거: 전사문 part22 "가처분이라고 하는 거는 이사의 지위를 부정하는 게 아니라... 직무 집행만 정지한다"

### (5) 직무대행자의 권한

| 항목 | 내용 |
|:----|:-----|
| **상무(통상 업무)** | 처리 가능 |
| **긴급 사무** | 법원 허가 필요 |
| **위반 시** | 선의 제3자에 손해배상 책임 |

### (6) 직무집행정지 이사 · 후임 이사 · 직무대행자 관계

| 상황 | 법인 대표권 |
|:----|:----------|
| 직무집행정지된 이사 | **권한 전무** (행위 = 절대적 무효) |
| 후임 이사 선임 | 직무대행자 존속 시 → **후임 이사도 대표권 X** |
| 가처분 취소/실효 시 | 직무대행자 권한 종료 → 후임 이사 대표권 발생 |

> - 근거: 전사문 part22 "후임자를 선임해도 직무대행자의 그 지위가 남아 있으면 법인을 대표하는 사람은 오로지 직무대행자밖에 안 된다."

### (7) 가처분 실효

**실효 사유**: 가처분 채권자가 본안 소송(총회결의 취소/무효/부존재확인) 승소 확정 시

→ 목적 달성으로 가처분 당연 효력 상실

## 4. 사원총회 — 소집 절차

### (1) 소집 통지 (제71조)

| 항목 | 내용 |
|:----|:-----|
| **기간** | 1주간 전 |
| **기재 사항** | 회의 목적 사항 |
| **방식** | 정관에 정한 방법 |

### (2) 서면 결의 불가 (2024년 판례)

> "법률이나 정관의 정함 없이 소집·개최 절차 없이 서면만으로 총회 결의 → **무효**"

### (3) 소집 철회·취소

- 가능함
- 단, **소집 절차와 동일한 방식 불요**

---

## 5. 사원총회 — 결의 사항

### (1) 총회 전권 사항 (정관으로도 박탈 불가)

| 사항 | 의결정족수 |
|:----|:----------|
| **정관 변경** | 총사원 **3분의 2** 이상 |
| **해산 결의** | 총사원 **4분의 3** 이상 |

### (2) 결의 사항의 범위

**원칙**: 통지된 사항에 한정

**예외**: 통지 사항에서 **합리적으로 추론 가능**한 사항도 결의 가능

> **판례 (종중 사건)**: "종산 매도대금 부정지출 책임 추궁" 안건 → 관련자 해임 + 후임자 선임 결의 **유효**
>
> - 근거: 전사문 part22 "부정 지출이 확인이 되면 걔를 자르고 후임자를 선출하는 거는 합리적으로 추론할 수 있다"

## 6. 대표권 남용 사례 분석 (사례 4번)

### (1) 사실관계 요약

| 항목 | 내용 |
|:----|:-----|
| 법인 | A재단법인 (비영리 공익) |
| 대표자 | 갑 |
| 행위 | 처 을의 사업자금 조달 목적으로 병 은행에서 1억 대출 |
| 정관 | 채무부담행위 시 이사회 결의 필요 (갑 미이행) |
| 병 은행 | 이사회 결의 미이행 알았으나 문제 삼지 않음 / 을 사업자금 용도는 선의 |

### (2) 논점 구조

```
① 권리능력 범위 (간단히)
   ↓
② 대표권 제한 — 제41조(정관 기재), 제60조(등기)
   ↓
   ├─[미등기 시] → 법인 = 차주 → ③ 대표권 남용 검토
   │                              (선의·무중과실 → 법인 책임 유지)
   │
   └─[등기 시] → 법인 대항 가능 → 계약 책임 X
                              → ④ 제35조 제1항 (불법행위)
                              → ⑤ 제741조 (부당이득)
```

### (3) 등기 여부에 따른 결론

| 등기 여부 | 병 은행의 청구 |
|:---------|:-------------|
| **미등기** | 금전소비대차계약에 기해 1억 원 반환 청구 가능 |
| **등기** | 계약 책임 X → 제35조 또는 제741조로 청구 |

### (4) 등기 시 — 불법행위(제35조) vs 부당이득(제741조)

| 청구 근거 | 장단점 |
|:---------|:------|
| **제35조 제1항** | 과실상계 (은행 담당자가 이사회 결의 미이행 알면서 문제 삼지 않음) → **대폭 감액** |
| **제741조 부당이득** | 법인 선의·악의는 **대표기관(갑) 기준** → 갑 악의 = **제748조 제2항** (원금 + 이자) |

→ **현실적 선택**: 부당이득 청구 (제741조 + 제748조 제2항)
