## 1. 원리금채권의 소멸시효 — 분석 프레임

### 핵심 원칙: 원금·약정이자·지연이자는 **반드시 분리 분석**

| 채권 | 발생 구간 | 시효 기간 | 비고 |
|------|----------|----------|------|
| **원금** | 변제기(점) | 일반 10년 / 상사 5년 | 점 단위 분석 |
| **약정이자** | 금전 교부일 ~ 변제기(띠) | 매월 지급 → 163조 1호 **3년** | 독자적 세계 — 원금과 분리 |
| **지연이자** | 변제기 익일 ~ 지급완료(띠) | 원본과 동일 | 원금 따라다님(원칙) |

### 분석 팁 (출제 패턴)

```
① 원금 완전 소멸 → 약정이자·지연이자 검토 불요 (183조, 주된 권리 소멸 → 종된 권리 소멸)
② 원금 중단 → 지연이자 통상 함께 부활 (기산일 늦고, 기간 동일)
③ 약정이자는 항상 별도 분석 (기간 3년, 발생 구간 다름)
④ 예외: 가압류 청구채권액에 원금만 기재 → 지연이자에 혜택 미급
```

## 2. 사례 1: 원리금채권 종합 — 제5회 변시 기출

### 사실관계

| 일시 | 사건 |
|------|------|
| 2009.12.1 | 갑은행 → 을에게 1억 대여 (이자 월 1%, **매월 말일 지급**, 변제기 2010.10.31) |
| — | 병: 연대보증 |
| 2013.5.1 | 갑 → 정에게 원리금채권 전부 양도 (대항요건 미구비) |
| 2013.12.20 | 갑이 을 상대 대여금 청구 (전소) |
| — | 을: "정에게 양도됐으므로 기각" 주장 → **묵시적 승낙**으로 봄 → 기각 확정 |
| 2015.12.30 | 전소 기각 판결 확정 |
| 2016.1.4 | 정이 을 상대 양수금 청구 (본소) |

### 분석

#### (1) 원금 — 소멸시효 항변

- 기산일: 2010.10.31 (변제기)
- 기간: 상사 5년 → **완성일: 2015.10.31 0시**
- 본소 소제기: 2016.1.4 → 완성 **후** → 항변 이유 있음 ✅

#### (2) 약정이자 — 소멸시효 항변

- 발생: 2009.12.2 ~ 2010.10.31 (띠)
- 매월 말일 분할 지급 → **163조 1호, 3년**
- 최초 소멸: 2012.12.2 / 최종 소멸: **2013.10.31**
- 본소 소제기: 2016.1.4 → 전부 완성 → 항변 이유 있음 ✅

#### (3) 지연이자 — 소멸시효 항변

- 발생: 2010.11.1 ~ (계속)
- 기간: 원본과 동일(5년)
- 소멸 시작: 2015.11.1 ~ (계속)
- **그러나**: 원금 소멸시효 완성(2015.10.31) → 183조에 의해 지연이자도 소멸
- 항변 이유 있음 ✅

#### (4) 재항변 — 170조 2항 (전소 기각 후 6개월 내 신소)

- 전소(갑 → 을) 기각 확정: 2015.12.30
- 본소(정 → 을) 소제기: 2016.1.4 → **6개월 내** ✅
- **갑의 소제기일(2013.12.20)의 시효중단 효과를 정이 전용** 가능

| 채권 | 갑 소제기일(2013.12.20) 기준 | 결과 |
|------|---------------------------|------|
| **원금** | 완성일(2015.10.31) **이전** | **중단 → 부활** ✅ |
| **약정이자** | 최종 소멸(2013.10.31) **이후** | **이미 소멸 → 불가** ❌ |
| **지연이자** | 원금 부활 → 183조 역적용 | **중단 → 부활** ✅ |

> **결론**: 정은 원금 1억 + 지연이자는 받을 수 있으나, 약정이자는 받지 못함

## 3. 사례 2: 가압류와 시효중단의 물적 범위 — 2025 법전 모의

### 사실관계

| 일시 | 사건 |
|------|------|
| 2005.3.2 | 병 → 을 매매계약(X건물 5억) |
| 2006.1.3 | 을 → 갑 전매계약(X건물) |
| — | 갑·을 계약 해제 → 을의 매매대금 반환의무 6억, 변제기 2006.11.30 |
| 2007.5.30 | 갑: 을의 병에 대한 이전등기청구권 **가압류** (청구채권액: **원금 6억만 기재**) |
| 2022.9.10 | 을의 이의신청 → 3년간 본안소송 미제기 → 가압류 취소 |
| 2022.12.1 | 갑 → 을 소제기 (원금 6억 + 지연이자 4억8천 = 10억8천) |

### 분석

#### (1) 원금 6억

- 변제기: 2006.11.30
- 기간: 10년 → 완성일: 2016.11.30
- **그러나** 가압류(2007.5.30) → 시효 정지(가압류 존속 중 시효 진행 안 함)
- 가압류 취소(2022.9.10): 175조 해당 여부?
  - 3년 본안소송 미제기로 인한 취소 → **175조 비적용** (권리포기 의사 아님)
  - **중단 효과 유지** → 178조 1항: 취소 익일(2022.9.11)부터 재진행
  - 완성예정: 2032.9.11 → 소제기(2022.12.1) 시점: 한참 전 → **원금 부활** ✅

#### (2) 지연이자 4억8천

- 발생: 2006.12.1 ~ 2022.12.1 (16년치)
- 기간: 원본과 동일 10년
- **핵심**: 가압류 청구채권액에 **원금만 기재** → 지연이자에 가압류 중단 혜택 **미급**
- 따라서 지연이자는 **소제기(2022.12.1) 기준**으로 별도 판단
- 소제기일로부터 10년 역산: 2012.12.1 이전 발생분 → 소멸시효 완성
- **2012.12.2 이후** 발생분 → 10년치 = **3억** 부활

> **결론**: 원금 6억 + 지연이자 **3억** = 9억 인용 (청구 10억8천 중 1억8천 탈락)

## 4. 사례 3: 응소와 시효중단 — 핵심 요건

### 응소 인정 요건 (재판상 청구 준용)

```
① 단순 응소 ✗ → 적극적 권리주장 필요 (답변서에 "채권 존재" 명시)
② 답변서 제출시 기준 (변론시 ✗) — 법원 기일 지정에 좌우되면 부당
③ 시효 완성 전에 응소행위 필요
④ 시효중단 주장은 별도 항변 필요 (주요 사실 → 사실심 변론종결까지)
```

### 응소 불인정 사례 ⭐

| 원고 | 이유 |
|------|------|
| **물상보증인** | 의무자 아님 → 시효원용권자일 뿐 |
| **저당부동산 제3취득자** | 의무자 아님 → 시효원용권자일 뿐 |

> 응소로 시효중단 인정 → **의무자(채무자)가 제기한 소송**에서만 가능

## 5. 사례 4: 일부청구와 시효중단

### 전부청구로 평가되는 경우 (외우기)

| 판례 | 사안 | 이유 |
|------|------|------|
| 92.4.14 | 신체훼손 → 금액 미확정, 감정 후 확장 예고 | 전부 청구 의사 객관적 명시 |
| 2011 | 불법행위 손배 → 지연손해금도 동일 법리 | — |

### 명시적 일부청구

- **일부 ↔ 잔부 커넥션 단절**
- 잔부: 별소 또는 청구취지 변경 신청서 접수시 별도 판단

### 묵시적 일부청구

- **일부 ↔ 잔부 커넥션 유지**
- 시효중단 효과: 잔부까지 확장

### 일부청구 + 증액 예고 후 미증액

```
① 소송 종료 전 실제 증액 → 처음부터 전부에 시효중단 ✅
② 소송 종료까지 미증액 → 잔부는 최고(174조)로 봄
   → 판결 확정 후 6개월 내 후속조치 필요
③ 증액 예고 후 명시적 삭제 → 그래도 최고 효력 유지 (2022 판례)
```

## 6. 사례 5: 170조 2항 — 전소 기각 후 신소

### 적용 구조

```
전소 기각 확정 → 6개월 내 신소 제기
→ 전소 소제기시 시효중단 효과 부활
```

### 적용 사례

| 유형 | 설명 |
|------|------|
| **채권양도 + 대항요건 미구비** | 양도인 전소 기각 → 양수인 6개월 내 신소 → 양도인 소제기일 전용 |
| **소송인수 + 탈퇴** | 갑 소제기 → 병 인수참가 → 갑 탈퇴 → 병 기각 확정 → 갑 6개월 내 신소 → 갑 최초 소제기일 부활 |

## 7. 기타 사례 쟁점 정리

### 대항요건 미구비 양수인의 권리

| 항목 | 인정 여부 |
|------|----------|
| 양수금 청구 소송 | ✗ (장래이행소 부적법 → 각하) |
| **시효중단** | ✅ (불완전 권리행사이나 중단 인정) |
| **저당권부 채권 → 임의경매 신청** | ✅ |
| 경매 배당금 보유 | ✅ (이의 없으면 적법) |

### 어음·수표와 원인채권

| 행위 | 원인채권 중단? |
|------|--------------|
| 어음·수표 채권 행사 | ✅ (지급확보 도구 → 원인채권 멈춤) |
| 원인채권 행사 | ✗ (어음·수표 멈추지 않음) |
| 어음채권으로 압류·가압류 | ✅ (어음 중단 → 원인채권도 중단) |
| 어음채권으로 배당요구 | ✅ (압류에 준하여 처리) |

### 행정소송과 시효중단

| 소송 유형 | 시효중단 |
|----------|---------|
| 무효확인 소송 | ✅ (부당이득반환청구권의 권리행사) |
| 취소소송 (원칙) | ✗ |
| 취소소송 (예외) | ✅ — 부당이득반환 실현 수단인 과세처분 취소소송 (92 전합) |
| 배상명령 신청 (형사) | ✅ (소제기와 동일 효력) |
