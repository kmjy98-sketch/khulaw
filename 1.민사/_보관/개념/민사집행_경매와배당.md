# 민사집행 — 경매와 배당

> **핵심 요약**: 강제경매(집행권원 필요, 공신력 O) vs 임의경매(불필요, 공신력 X). 매각조건(91조)—저당권 소멸, 유치권 인수. 처분금지효는 상대적 무효.

## 1. 민사집행법 체계

| 편 | 내용 |
|----|------|
| 1부 | 강제집행 (강제경매) |
| 2부 | 담보권 실행 (임의경매) |
| 3부 | 보전처분 (가압류/가처분) |

---

## 2. 강제경매 vs 임의경매 ★★★

| 구분 | 강제경매 | 임의경매 |
|------|---------|---------|
| **집행권원** | **필요** (집행정본) | **불필요** |
| 첨부서류 | 집행정본 | 등기부등본 |
| **공신력** | **O** | **X** |

### 집행권원

| 종류 | 설명 |
|------|------|
| 확정판결 | "피고는 원고에게 1억 지급하라" |
| 가집행선고부 판결 | 확정 전 집행 가능 |
| **집행증서** | 공정증서 + 강제집행수락문언 |

> 집행권원 + 집행문 = **집행정본**

---

## 3. 공신력 상세 ★★★

### 강제경매 — 공신력 O

- 집행채권 부존재/소멸해도 → 경매절차 완결 시 **유효**
- 매수인 소유권 취득 **인정**

### 임의경매 — 공신력 X

- 저당권 부존재/무효 → 경매절차도 **무효**
- 매수인 소유권 취득 **부정**

### 임의경매 공신력 **예외** (2가지)

1. 경매 개시 시 저당권 존재 → 중간 소멸 → 이해관계인 취소 안 함
2. **통정허위표시 저당권** → 매수인이 108조 2항 **선의 제3자**

---

## 4. 부동산 강제집행 절차

```
압류 → 환가(경매) → 배당
```

### 경매 개시 결정

- 압류 명령과 동시 발령
- 부동산 등기부에 '경매개시결정' 기입등기 = 압류 효력 발생

### 처분금지효

- 채무자 부동산 처분 금지
- 위반 시 **상대적 무효** (경매절차 관계인에게만 대항 불가)

---

## 5. 매각조건 (민집법 91조) ★★★

| 조항 | 권리 | 처리 | 비고 |
|------|------|------|------|
| 2항 | **저당권** | **소멸** | 순위 무관, 무조건 소멸 (소멸주의) |
| 3항 | 용익물권 | **소멸** | 선순위 저당권보다 후순위인 경우 |
| 4항 | 최선순위 용익물권 | **인수** | 말소기준권리보다 앞 (인수주의) |
| 5항 | **유치권** | **인수** | 매수인은 유치권자에게 변제 책임 |

### 매수인 소유권 취득 시기

- **매각대금 완납 시** (187조 법률규정에 의한 물권변동 → 등기 없이 취득)

---

## 6. 108조 2항 "대항하지 못한다" ★★

### 인적 범위

> 무효를 주장할 수 없는 자 = **모든 제3자** (당사자/승계인에 한정 X)

| 포함 | 예시 |
|------|------|
| 당사자 | 갑, 을 |
| 포괄승계인 | 상속인 |
| **특정승계인** | 병 (갑으로부터 매수) |
| **채권자** | 갑의 금전채권자 |

### 108조 2항과 경매 관련 사례

| 사례 | 결론 |
|------|------|
| 가장양도 + 압류추심 (2014) | 추심채권자 = 108조 2항 **제3자 O** |
| 가장양도에서 변제 안 한 채무자 (1982) | 채무자 = **제3자 X** |

---

## 7. 보전처분 개관

| 구분 | 목적 | 피보전권리 |
|------|------|----------|
| **가압류** | 금전채권 보전 | 금전채권 |
| **가처분** (처분금지) | 특정채권 보전 | 이전등기청구권 등 |
| 점유이전금지가처분 | 명도소송 전 점유자 변경 방지 | — |

---

## 8. 복습 포인트

- [ ] 강제경매: 집행권원 **필요** + 공신력 **O**
- [ ] 임의경매: 집행권원 **불필요** + 공신력 **X**
- [ ] 91조: 저당권 **무조건 소멸**, 유치권 **인수**
- [ ] 매수인 소유권 = **매각대금 완납 시** (등기 불요)
- [ ] "대항하지 못한다" = 당사자+특정승계인+채권자 **모두 포함**
