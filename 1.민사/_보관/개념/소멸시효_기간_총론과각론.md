# 소멸시효 기간 — 총론과 각론

> **핵심 요약**: 민사 10년, 상사 5년, 163조 3년, 164조 1년. 상사시효는 일방 상인이면 적용. 판결 확정 시 단기시효도 10년 연장(165조). 보증채무·구상금·경개는 각자 독립.

## 2. 3년 단기시효 (제163조) ★★★★★

| 호 | 내용 | 핵심 포인트 |
|----|------|------------|
| **1호** | 이자·부양료·급료·사용료 (1년 이내 정기급부) | 반복적 급부 + 1년 이내 간격 필요 |
| 2호 | 의사·약사 채권 | — |
| **3호** | **도급 공사대금** (수급인) | 666조 저당권설정청구권도 3년 |
| **5호** | 변호사·법무사 등 보수 | 세무사·중개사 **제외** → 10년 |
| **6호** | 생산자·상인의 **상품 대가** | ⚠️ 5년 아님! |

### 1호 심화: 이자 지급방식에 따른 차이 ★★★★

| 약정 내용 | 시효 |
|----------|------|
| **매월 말일 지급** | **3년** (163조 1호 = 정기급부) |
| **변제기에 원금과 일괄 지급** | 3년 아님 → 민사 10년/상사 5년 |

- 근거: 전사문 "어떤 계약서를 보니까 매월 말일 날 10% 해 가지고 이자를 지급한다 ... 전자는 3년이지만 후자는 3년이 아닙니다"

> **사례형·기록형 팁**: 이자 지급 약정은 매우 중요한 단서! 놓쳐서는 안 됨

### 5호: 전문직 보수

| 해당 (3년) | 변호사, 변리사, 법무사, 공인회계사, 공증인 |
|-----------|----------------------------------------|
| **해당 X (10년)** | 공인중개사, 세무사 |

- 근거: 전사문 "공인 중개사, 세무사 이거는 적용이 안 되고요 ... 뭐 공익적 어쩌고 하면서 10년으로 해 주죠"

### 6호: 상인 상품대가 ★★★★★

> ⚠️ "상인이 물품을 팔았다 → 상법 64조 5년" 으로 빠지기 쉬움 → **3년**이 정답!

- 근거: 전사문 "상인이 물품을 팔았다. ... 그러면 상인 어, 5년 이렇게 가는 경우가 아주 비비제. 자, 그건 그 챔피할 필요 없고 ... 계속 수정을 해야 됩니다"

### 기타 3년 판례

| 사례 | 시효 | 이유 |
|------|------|------|
| 전기요금 **위약금** (한전) | **5년** (상사) | 사용료 아님, 상인의 채권 |
| **금융리스료** | **5년** | 물품대금 대출이지 사용료 아님 |
| 정수기 **대여료** | **3년** | 말 그대로 빌려주는 것 = 사용료 |
| 우수현상광고 당선 공사 | **3년** | 원래 공사대금 시효 준용 |

- 근거: 전사문 "금융 리스는 말이 리스이지 단순히 빌리는 게 아니라 어, 그 어, 매수 자금을 빌려주는 거 ... 정수기 리스 말 그대로 정수기를 빌려 주는 거죠. 그러니까 그거는 사용료의 포섭이 될 수 있다"

## 4. 상사시효 (상법 제64조) ★★★★★

### 기본 구조

- **본문**: 상행위로 인한 채권 → 5년
- **단서**: 다른 법령에 이보다 단기 → 그 기간 (예: 163조 6호 3년)

### 적용 범위

| 논점 | 결론 |
|------|------|
| 쌍방 상인 필요? | **일방만** 상인이면 5년 적용 |
| 보조적 상행위 포함? | **O** |
| 상인의 추정 | 상인이 하는 행위 → 영업을 위한 것으로 **추정** |
| 추정 번복 | 상행위와 무관함을 상대방이 입증 |

- 근거: 전사문 "일방 일방만에 상행이 해당되면 64조에 포섭이 된다 ... 하나은행에서 여러분들한테 마통 계산을 해 줘 가지고 어 대출금 채권을 갖고 있는 거는 그거는 5년"

### 5년짜리 아닌 것 (10년) ★★★★

| 사례 | 시효 | 이유 |
|------|------|------|
| 불법행위 손배 | **10년** | 상행위 무관한 위법행위 |
| 상법 401조 (이사→제3자 책임) | **10년** | **채무불이행** 책임 (766조 X) |
| 이사·감사→회사 임무해태 | **10년** | 위임관계 채무불이행 |
| 업무집행지시자 책임 | **10년** | 채무불이행 |
| 근로자 주의의무 위반 | **10년** | 근로계약 → 채무불이행 |
| 의사 퇴직금 | **10년** | 의제상인 아님 |
| 변호사 급여 | **10년** | 의제상인 아님 |

> **핵심 법리**: 상법 규정 자체가 채무불이행 책임 → 766조 적용 X → 10년. 그러나 750조(불법행위) 배제하는 것은 아님 → **옵션 관계** (기록형 빈출)

- 근거: 전사문 "이거는 불법행 책임이 아니라 채무불행 책임이라는 거야 ... 766조가 정리되지 않는다 ... 10년이다 ... 그렇다고 해서 750조를 배제한다는 의미 아니다. 회사 입장에서는 옵션 관계"

### 사업자금 차용 (빈출) ★★★★★

| 요건 | 내용 |
|------|------|
| ①대주 인식 | 차주가 사업용으로 빌린다는 것을 인지 |
| ②차주 사업 | **자기 사업**으로 사용 → 두 요건 AND 충족 시 5년 |

**핵심 주의**: 회사를 설립하여 대표이사로 취임한 경우

- 상인 = **회사** (대표이사 ≠ 상인)
- 개인 이름으로 빌려 회사에 투입 → **10년** (개인 비상인 거래)
- 회사 이름(A주식회사 대표자 갑)으로 빌리면 → **5년**

- 근거: 전사문 "갑이라는 사람이 회사를 차려 가지고 대표 이사로 취임을 했을 때 상인은 회사야. 회사가 상인이고 대표의사는 상인이 될 수가 없어요"

### 상거래 실효 후 부당이득

| 결론 | 기준 |
|------|------|
| **5년** | 상거래와 같은 정도로 신속 해결 필요성 O |
| **10년** | 그러한 필요성 X |

> 기준이 매우 애매 → 파기환송 사건 다수 (12회 변시 선택형 출제)

## 5. 보증채무·구상권·면책적 채무인수 ★★★★

### 보증채무 소멸시효

- 주채무와 **각자 독립** (각자 도생)
- 예: 주채무 10년(민사) + 보증채무 5년(보증보험회사) 가능

### 면책적 채무인수

| 항목 | 결론 |
|------|------|
| 시효기간 | 원래 기간 **그대로 유지** |
| 중단 효과 | 채무인수 = **승인**(168조 3호) → 시효 중단 |
| 재진행 | 178조 1항 → 인수 **익일**부터 다시 진행 |

- 근거: 전사문 "면적 채무 인수는 원래의 그 소멸시효 기간이 그대로 유지가 된다 ... 채무 인수의 의사 표시는 시효 중단 사유 중에 승인에 해당"

### 구상권

| 유형 | 시효 |
|------|------|
| 수탁 보증인 구상권 (보증보험 등) | 보증인이 상인 + 영업 위한 것 → **5년** |
| 일반 보증인 구상권 | **10년** |
| **물상보증인 구상권** | 일률적으로 **10년** (물상보증인 지위 무관) |

- 근거: 전사문 "물산보증인이 채무자에 대해서 갖고 있는 그 구상권은 ... 민법에 의해서 인정된 별개의 독립된 권리이고 소멸 시효는 인률적으로 민법상 일반 채권 즉 10년"

## 6. 경개·준소비대차 ★★★★

**공통점**: 구채무 소멸 + 신채무 생성
**차이점**: 경개 = 동일성 X, 준소비대차 = 동일성 O

### 신채무의 소멸시효

> 경개·준소비대차 **그 자체의 성격**에 따라 다시 결정

**판례** (시험 빈출):

- 일용직 임금(1년) → 사장님이 "빌린 것으로 하자" → 사장님 상인 → **5년**
- 근거: 전사문 "경계 또는 준소비 대차로 어 성립되는 신체무의 소멸시는 경계 혹은 소비대차 계약 약정의 성질에 따라서 다시 결정이 된다"

## 7. 시효 연장 (제165조) ★★★★★

### 165조 1항: 판결 확정 시 10년 연장

- 단기시효 채권이라도 판결 확정 → **10년**으로 연장
- 178조 2항과 결합: 기산일 = 판결 확정 시점

### 적용 범위

| 대상 | 확정 판결 | 지급명령 | 조정·화해 |
|------|----------|---------|----------|
| 적용? | **O** (기판력 O) | **O** (기판력 X, 집행력 O) | **O** |

- 근거: 전사문 "확정된 지금 명령은 기발력이 없지만 어 시 연장 효과는 있다"

### 165조 3항: 기한 미도래 채권

- 판결 확정 당시 **변제기 미도래** → 시효 연장 **없음**
- 예: 소송비용 상환 청구권 → 후속절차(확정신청) 필요 → 기한 미도래 유사 → 연장 X
- 근거: 전사문 "소송비용 청곡 거래는 민법 165조항이 정되지 아니한다"

### 직접청구권 (상법 724조)

| 항목 | 내용 |
|------|------|
| 성질 | 피보험자 채무의 **병존적 인수** |
| 시효 | **766조** 적용 (보험법 2년 X) |

- 근거: 전사문 "직접 청구권도 불법 행위적 성격이 있다 ... 766조 어 불법 행위에 따른 것이 적용되는 것이지 그 상법 660이 ... 적용되는 게 아니다"

## 9. 복습 포인트

- [ ] 민사 10년, 상사 5년, 163조 3년, 164조 1년
