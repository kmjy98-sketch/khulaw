# 민법강의 수업정리 Part 28 (강박의사표시·부동산이중매매)

## 1. 강박에 의한 의사표시와 반사회적 행위

### (1) 변호사 서면의 정형화

| 순서 | 주장 | 조문 |
|:----:|:-----|:-----|
| 1 | 반사회적 행위 | **제103조** |
| 2 | 불공정한 행위 | **제104조** |
| 3 | [[비진의_의사표시_진의의_의미.md|비진의 의사표시]] | **[[비진의_의사표시_진의의_의미.md|제107조]]** |
| 4 | 강박 | **제110조** |

### (2) 제103조 적용 여부

| 대법원 입장 | 내용 |
|:-----------|:----|
| **원칙** | 강박이라는 불법적 방법 사용 = **제103조 포섭 불가** |
| 국가 강박도 동일 | 보안사 고문도 마찬가지 |
| **예외** | 의사결정 여지 **완전 박탈** 시에만 무효 |
| 실제 인정 | **0건** (립서비스) |

### (3) 제104조 적용 여부

- 제104조 = **유상행위에만** 적용
- 강제헌납 = **무상행위(증여)** → 적용 불가

### (4) [[제107조]]([[비진의 의사표시]]) 적용 여부

| 구분 | 내용 |
|:----|:----|
| **표의** | 계약서: "증여하겠습니다" |
| **진의** | 특정 내용의 의사표시를 **하고자 하는 생각** |
| 속마음 | "살아남기 위해 어쩔 수 없이" |

> **대법원**: 진의 = 표시하려는 생각, 마음속 바람 ≠ 진의
> → **비진의 아님**

### (5) 제110조(강박) 적용: 취소권의 한계

| 기산점 | 기간 |
|:------|:-----|
| 취소원인 안 날 | **3년** |
| 법률행위 시 | **10년** |

> 80년 고문 → 정권교체 후 소송 가능 = **이미 3년 도과** → 패소

## 2. 부동산 이중매매: 반사회적 무효론

### (1) 기본 구조

- 갑 → 을: 1차 매매 (등기 미이전)
- 갑 → 병: 2차 매매 + 등기 이전

### (2) 원칙: 유효

- 이중매매 = **자유경쟁 원리**상 문제없음
- 을: **이행불능에 따른 책임**만 (계약해제 or 손해배상)

### (3) 예외: 무효 요건

| 요건 | 내용 |
|:----|:----|
| ① 계약 진척 | 갑이 을로부터 **중도금까지** 받음 (배임적 요소) |
| ② 적극 가담 | 병이 갑의 **배임행위에 적극 가담** |

> **단순 인지** = 부족, **적극 가담** 필요

### (4) 제1양수인 구제: 채권자대위권

1. 을이 갑의 **말소등기청구권 대위행사** → 병 등기 말소
2. 갑 명의 회복
3. 을이 갑에게 **이전등기청구**

---

## 3. 반사회적 무효론의 문제점

### (1) 기판력 악용

| 상황 | 결과 |
|:----|:----|
| 병이 갑 상대 소송 → 승소 **확정** | 기판력 발생 |
| 을이 채권자대위권 행사 | 전소 기판력에 **저촉** |
| 결과 | **기각** |

> 병이 법을 알면 **기판력이라는 방패**로 채권자대위권 무력화

### (2) 거래안전 침해

- 병 → 정(선의 제3자)에게 재매도
- 정: 물권변동 요건 중 **처분권원 흠결**
- 결과: 정 **소유권 취득 불가**
- 수십 번 전전유통해도 **전부 소유권 취득 불가**

### (3) 제746조와의 관계

| 문제 | 갑·병 매매 = 제103조 위반 → 불법원인급여? |
|:-----|:-----------------------------------------|
| 대법원 | **입장 없음** |
| 학설 ① | 제3자(을) 귀속 재산 → 제746조 배제 |
| 학설 ② | 병의 불법성 > 갑 → 제746조 단서 적용 |
| 학설 ③ | 제746조 "불법" ≠ 제103조 |

## 4. 대체 이론

### (1) 사해행위취소론

- 을이 직접 갑·병 거래 취소
- **문제점**: 피보전채권 = **금전채권** 필요
  → 을의 이전등기청구권 = **특정채권** → 불가

### (2) 제3자 채권침해(불법행위)론

- 갑·병 짜고침 = 을에 대한 **불법행위**
- 원상회복으로 등기 이전 청구
- **문제점**: 불법행위 원상회복 = **손해배상** 원칙
