## 0. 시험장 5단계 행동과 발문 처리

### ▶ 시험장 코어

> 모든 문제를 같은 5단계로 처리한다. 발문을 보고 → 타깃 주장을 한 문장으로 줄이고 → 조건·양상·범위를 표지어로 고정하고 → 선지가 무엇을 건드리는지 분류하고 → 강도를 맞춘다.

| 단계 | 한 줄 행동 | 5초 체크 |
|---|---|---|
| 1 발문 판별 | 강화·약화·반드시참·추론가능·필요가정·충분가정·오류·원리적용·계산/그룹 중 무엇인가 | 발문 동사부터 본다 |
| 2 타깃 주장 T 확정 | 평가 대상을 **한 문장**으로 줄인다(결론·가설·규범명제·조건문 중 하나) | 답은 보통 결론 하나에 걸려 있다 |
| 3 표지어로 조건·양상·범위 고정 | `만`·`오직`·`없이는`·`않는 한`·`반드시`·`가능`·`알다`·`주장하다`·`해야 한다`·`할 수 있다`를 먼저 본다 | 보조사 하나가 방향을 바꾼다 |
| 4 선지 기능 판정 | 선지 E가 연결고리·반례·대안원인·표본·측정·양상전환·적용조건 중 무엇을 건드리는가 | T를 안 건드리면 무관 |
| 5 강도 맞추기 | 지문보다 센 선지를 제거한다 | 가능↔필연, 일부↔전부, 주장↔사실 |

> **최종 압축 한 문장**: 발문을 보고, 타깃 주장을 잡고, 조건·양상·범위를 고정한 뒤, 선지가 반례와 대안설명을 줄이는지 늘리는지만 본다. 고득점은 논리 용어 암기가 아니라 **방향을 뒤집지 않고, 강도를 키우지 않고, 주체를 섞지 않는 것**에서 나온다.

### 0.1 5단계 행동 절차 (상세)

#### [1단계] 발문 판별 — 5초 안에 유형 확정

발문의 동사·명사가 유형을 지정한다. 본문을 읽기 **전에** 무엇을 요구받는지 먼저 못박는다. 유형을 틀리면 맞는 선지를 골라도 오답으로 처리된다(예: 약화 문제를 강화로 풀기).

| 발문 신호 | 유형 |
|---|---|
| "강화하는", "지지하는", "뒷받침하는" | 강화 |
| "약화하는", "반박하는", "의문을 제기하는" | 약화 |
| "반드시 참인", "참일 수밖에 없는" | 반드시 참 |
| "추론할 수 있는", "도출되는" | 추론 가능 |
| "전제로 반드시 필요한", "가정하고 있는" | 필요가정 |
| "추가하면 결론이 따라 나오는" | 충분가정 |
| "논증의 문제점/결함", "비판으로 적절한" | 오류 찾기 |
| "원리를 적용하면", "사례에 비추어" | 원리 적용 |
| "배치·순서·참/거짓", "최소·최대" | 계산·그룹 |

#### [2단계] 타깃 주장 T 확정 — 한 문장으로

결론이 여러 문장처럼 보여도 평가 대상은 보통 **하나의 결론, 하나의 가설, 하나의 규범명제, 하나의 조건문**이다. T를 한 문장으로 못 줄이면 아직 못 읽은 것이다. 동시에 T의 종류를 분류해 둔다 — 조건문인가, 일반화인가, 인과인가, 유비인가, 설명가설인가, 규범판단인가, 계산·배치 규칙인가. 종류에 따라 4단계에서 찾을 공격 포인트가 달라진다.

#### [3단계] 표지어로 조건·양상·범위 고정

긴 지문에서 전부 기호화하지 않는다. 다음만 표시한다 — **주장 / 근거 / 조건(A이면 B 계열) / 양화(모든·어떤·없음·전부는 아님) / 양상(반드시·가능·알다·믿다·해야 한다·할 수 있다) / 변수(원인·결과·대조집단·측정값·예외)**. 이 단계에서 **보조사의 논리 기능**을 반드시 반영한다(아래 0.3 표).

#### [4단계] 선지 기능 판정

선지 E가 T와 어떤 관계인지를 기능으로 분류한다.

| E가 하는 일 | 판정 |
|---|---|
| T의 반례 가능성을 줄인다 | 강화 |
| T의 대안설명을 줄인다 | 강화 |
| 전제와 결론 사이 빈칸을 메운다 | 강화(연결고리) |
| 반례·대체원인·역인과·표본편향·측정오류·적용조건 미충족을 만든다 | 약화 |
| T가 아니라 주변정보를 건드린다 | **무관(빈출 오답)** |

#### [5단계] 강도 맞추기 — 센 선지 제거

지문과 선지의 **강도(modality·범위)**를 맞춘다. 지문보다 강한 선지가 가장 흔한 함정이다.

- 지문이 **가능성**인데 선지가 **필연(반드시)**이면 → 제거
- 지문이 **일부(어떤)**인데 선지가 **전부(모든)**면 → 제거
- 지문이 **주장·믿음**인데 선지가 **사실**로 단정하면 → 제거(주체 바꿔치기)
- 필요가정 문제에서 **필요 이상으로 강한** 선지는 대개 오답이다

### 0.2 발문 유형 한눈표 — 유형별 핵심 동작 매핑

| 유형 | 발문 신호 | 핵심 동작 한 줄 | 1순위로 찾을 것 |
|---|---|---|---|
| **반드시 참** | "반드시 참인" | 지문에서 **연역적으로 강제**되는 것만 고른다 | 대우·양화 추론으로 닫히는 선지 |
| 추론 가능 | "추론할 수 있는" | 지문이 지지하면 통과(반드시참보다 느슨) | 지문과 모순 없는 선지 |
| **강화** | "강화·지지·뒷받침" | T의 **대안설명을 줄이는** 선지 | 대안설명 차단, 연결고리 보강 |
| **약화** | "약화·반박·의문" | T의 **숨은 전제를 부정**하는 선지 | 반례·역인과·공통원인·표본·측정 |
| **필요가정** | "전제로 반드시 필요한" | 선지를 **부정하면 결론이 무너지는지** 본다 | 부정 시 결론 붕괴 / 너무 센 선지 배제 |
| **충분가정** | "추가하면 결론이 따라 나오는" | 넣으면 **결론이 반드시 따라오는지** 본다 | 전제-결론 빈칸, 주어·범위·양상 일치(세도 됨) |
| **오류 찾기** | "문제점·결함·비판" | 전제가 결론을 **보장하는지** 묻는다 | 필요/충분 혼동, 역·이, 상관→인과, 부분→전체 |
| **원리 적용** | "원리를 적용하면" | 사례가 원리의 **조건을 충족·예외인지** 본다 | 적용요건, 예외조항, 의무/허용/금지 분리 |
| **계산·그룹** | "배치·순서·최소·최대" | 표 그리기 전 **앵커·불변량·극값·경우분기** | 확정정보 먼저, 경계값부터 |

> **필요가정 vs 충분가정 핵심 대비**: 필요가정은 "**없으면 안 되는** 최소 다리" — 부정하면 결론이 무너진다. 너무 강한 선지는 필요가정이 아니다. 충분가정은 "**넣으면 결론을 보장하는** 다리" — 강해도 무방하다. 부정 테스트는 필요가정에만 쓴다.

> **강화·약화 유형별 1순위(결론 종류로 갈린다)**: 인과 → 대조군·역인과·공통원인 / 실험 → 무작위화·측정민감도·탈락편향 / 일반화 → 표본 대표성·반례 / 조건문 → A인데 B 아닌 사례 / 유비 → 결론 관련 유사점·차이점 / 설명가설 → 경쟁가설·새 예측 / 규범 → 적용요건·예외조항 / 통계 → 분모·모집단·기준시점.

### 0.3 표지어·보조사 논리 기능표 (3단계 필수)

조건·양상·범위를 고정할 때 **보조사 하나**가 방향과 강도를 바꾼다. 이 표를 3단계에서 그대로 적용한다.

| 표지어 | 논리 기능 | 시험장 번역 | **빈출 함정** |
|---|---|---|---|
| 만 / 뿐 / 밖에 | 한정(오직) | 'A여야(만) B'는 A가 B의 **필요조건** ('A만 B' = B이면 A) | 'A만 B'를 'A이면 B'(충분조건)로 오독 |
| 도 | 첨가 | 'A도 B'는 A를 포함해 **다른 것도 B** | 'A도'를 'A만'으로 뒤집기 |
| 조차 / 마저 | 극단 첨가 | 'A조차 B'면 나머지는 당연히 B(예상 밖·부정 맥락) | 특칭 강조를 **전칭으로 키움** |
| 까지 | 척도 끝 | 범위를 A 끝까지 확장 | 범위 끝을 일반화로 비약 |
| 은 / 는 | 주제·대조 | 'A는 B'는 **다른 것은 B 아닐 수 있음**을 함축 | 대조를 전칭이나 한정으로 비약 |
| 마다 | 분배 전칭(각각=모든) | 'A마다 B'는 모든 A가 B | 특칭으로 약화 오독 |
| (이)나 | 선택·근사 | 둘 중 하나 또는 대략 | 정확 수치로 단정 |
| 라도 | 양보 | 'A라도 B'(even if) — **충분조건 아님** | 양보를 충분조건으로 격상 |
| 반드시 | 필연(반드시 P) | 반례 하나면 깨진다 | 가능을 필연으로 키움 |
| 가능 | 가능(P일 수 있다) | 사실로 바꾸지 말 것 | 가능을 사실로 단정 |
| 해야 한다 / 할 수 있다 | 의무 / 허용·능력 | 실제로 한다가 아님, 문맥에서 분리 | 당위를 사실로 바꿈 |
| 알다 / 주장하다 | 사실성 함축 / 사실성 없음 | '알다'는 보통 사실 함축, '주장·믿다'는 사실성 없음 | 주장·믿음을 사실로 바꿔치기 |

> **조건문 방향 10초 복습**: 'A이면 B' = A는 충분·B는 필요(대우 'B 아니면 A 아니다'만 안전, 역 'B이면 A'·이 'A 아니면 B 아니다'는 금지). 'A일 때에만 B'·'오직 A만 B'·'B 없이는 A 불가'·'A하려면 B 필요' = **B이면 A 또는 A이면 B 방향에 주의** — 'A이면 B'와 절대 섞지 않는다. 시험의 가장 그럴듯한 오답은 거의 **역 또는 이**다.
