## 3. 과학철학 — 귀납·확증·반증·인과

### ▶ 시험장 코어

과학 지문은 지식을 묻지 않고 **검증 구조**를 묻는다. 선지가 무엇을 하는지만 본다.

| 개념 | 한 줄 핵심 | 출제 축(강화/약화) |
|---|---|---|
| 귀납 대 연역 | 연역은 전제가 참이면 결론도 참 보장, 귀납은 사례에서 일반으로 가며 보장 없음 | 귀납은 항상 **반례·표본**으로 약화 가능 |
| 확증(증거→가설) | 증거가 가설을 더 믿게 만들면 확증, 덜 믿게 만들면 반확증 | 가설이 예측한 관찰이 실제로 나오면 강화 |
| 반증(포퍼) | 보편명제는 입증 불가, **반례 한 건이면 무너진다** | '못 찾았다'를 '없다'로 만들려면 탐지능력이 핵심 |
| 패러다임(쿤) | 정상과학은 변칙을 누적하다 위기에서 전환 | 변칙 한 건만으론 폐기 안 됨, 대안 패러다임 필요 |
| 베이즈 직관 | 사전 그럴듯함 + 증거의 우도 = 사후 그럴듯함 | 가설일 때만 잘 나오는 증거일수록 강한 강화 |
| 인과추론 | 상관은 인과가 아니다 | **대체원인·역인과·공통원인·교란·대조실패** 5종 |
| 최선의 설명(귀추) | 여러 가설 중 가장 잘 설명하는 것 채택 | 경쟁가설 제거가 강화, 더 나은 경쟁가설이 약화 |
| 미결정성 | 같은 증거를 여러 이론이 똑같이 설명할 수 있다 | 증거만으론 결론 못 가른다 |

한 문장 압축: **과학 선지는 "가설이 예측한 게 나왔는가, 다른 설명이 줄었는가, 음성 결과가 진짜 음성인가"만 묻는다.**

---

### 3.1 귀납 대 연역

연역은 전제가 참이면 결론이 반드시 참이다(타당성 문제). 귀납은 관찰한 사례에서 보지 않은 경우로 넘어가므로 결론이 보장되지 않는다(지지의 정도 문제).

| 구분 | 연역 | 귀납 |
|---|---|---|
| 보장 | 전제 참이면 결론 참 | 결론은 그럴듯할 뿐 |
| 약화 방식 | 전제 거짓 또는 형식 오류 | 반례, 표본 편향, 표본 부족 |
| 시험 표지 | '반드시', '필연적으로' | '대체로', '관찰된 바로는', '경향이 있다' |

출제: 지문이 귀납으로 얻은 '대체로 A는 B'를 선지가 **'반드시 A는 B'(전칭·필연으로 강화)**로 키우면 과강도 오답. 귀납 결론은 반례 하나로 약화되지만 완전히 무너지지는 않는다(정도가 줄 뿐). 연역 결론은 **반례 한 건이면 타당성 자체가 깨진다**.

### 3.2 가설검증과 확증

확증은 "증거 E가 가설 H를 얼마나 지지하는가"의 문제다. 구조는 항상 같다.

1. 가설 H: 무엇이 무엇을 설명한다고 하는가.
2. 예측 P: H가 참이면 어떤 관찰이 기대되는가.
3. 관찰 E: 실제로 무엇이 관찰되었는가.
4. 보조조건 A: 장비 민감도, 표본, 전제조건이 제대로 갖춰졌는가.
5. 경쟁가설 R: 같은 E를 더 잘 설명하는 다른 가설이 있는가.

| 선지 기능 | 강화/약화 | 이유 |
|---|---|---|
| H가 예측한 새 관찰이 실제로 나왔다 | 강화 | 예측 성공 |
| **H가 틀렸다면 나오기 어려운 결과가 나왔다** | **강한 강화** | 위험한 예측 성공(가설일 때만 잘 나오는 증거) |
| 경쟁가설 R이 같은 현상을 설명 못 한다 | 강화 | H의 상대적 설명력 증가 |
| H가 예측한 결과가 나오지 않았다 | 약화 | 보조조건이 제대로였을 때 특히 강함 |
| **H가 결과 뒤에 사후적으로 끼워 맞춰졌다** | **약화** | 예측력이 없으면 지지가 약함 |

함정: '예측에 성공했다'는 강화이지만, **결과를 보고 나서 가설을 맞춘 것(사후 조정)**은 강화가 아니다. '관찰되었다'는 사실성을 함축하지만 '주장되었다'는 그렇지 않다(인식 양상 구별).

### 3.3 반증주의(포퍼)

핵심 한 줄: 과학 명제의 자격은 입증가능성이 아니라 **반증가능성**이다. 어떤 결과로도 반박될 수 없는 주장은 과학이 아니다.

| 명제 종류 | 한 사례의 무게 |
|---|---|
| 보편명제(모든 A는 B) | 확증 사례 백 건도 입증은 못 함, **반례 한 건이면 거짓** |
| 존재명제(어떤 A는 B) | 사례 한 건이면 입증, 반증은 매우 어려움 |

출제 포인트:
- '모든 A는 B'를 약화하려면 **A인데 B가 아닌 사례 한 건**이면 충분하다. 그 한 건이 강화 선지보다 무겁다.
- '없다'를 주장하려면 "**찾을 수 있었는데도 못 찾았다**"가 필요하다. 탐지 능력·측정 민감도·검정력이 강화 포인트다. 장비가 둔감했다면 음성 결과(못 찾음)의 의미가 사라진다.

**보조가설(뒤엠) 함정 — 매우 중요:** 예측이 빗나가도 그것이 곧 주가설 반박은 아니다. 실험장치·측정조건 같은 **보조가설이 틀렸을 수 있기** 때문이다. 따라서 "예측 실패가 가설을 반증한다"는 선지는 **보조조건이 정상이었다는 정보가 함께 있을 때만** 강한 약화가 된다.

### 3.4 패러다임(쿤)

핵심 한 줄: 정상과학은 패러다임 안에서 퍼즐을 풀다가, **변칙(설명 안 되는 현상)**이 쌓이면 위기에 빠지고, **대안 패러다임**이 나타나면 전환된다.

| 단계 | 내용 | 시험 함정 |
|---|---|---|
| 정상과학 | 기존 틀로 퍼즐 풀이 | — |
| 변칙 | 틀로 설명 안 되는 관찰 | 변칙 한 건을 곧 '폐기 사유'로 비약 금지 |
| 위기·전환 | 변칙 누적 + 대안 등장 | **대안 없으면 전환 안 됨**(반증주의와 대비) |

출제: 포퍼식(반례 한 건이 결정적)과 쿤식(변칙이 쌓여도 대안 없으면 유지)을 **대비**시켜 묻는다. "변칙이 관찰되었으므로 이론은 즉시 폐기되어야 한다"는 쿤 관점에서 과강도다. 패러다임 전환은 증거만으로 강제되지 않는다(미결정성과 연결).

### 3.5 베이즈 확증 직관

수식은 필요 없다. 세 가지 직관만 본다.

| 요소 | 시험장 의미 |
|---|---|
| 사전 그럴듯함 | 증거 보기 전 가설이 얼마나 그럴듯한가 |
| 우도 | **가설이 참일 때** 그 증거가 나올 확률 |
| 사후 그럴듯함 | 증거를 본 뒤 가설이 얼마나 그럴듯한가 |

핵심: 증거가 강하게 강화하려면 **'가설이 참일 때는 잘 나오지만, 가설이 거짓이면 잘 안 나오는 증거'**여야 한다. 아무 가설에서나 똑같이 나오는 증거는 가설을 거의 구별하지 못하므로 강화가 약하다(미결정성·무관 선지와 연결).

출제: "그 증거는 경쟁가설에서도 똑같이 기대된다"는 선지는 **강화를 무력화**한다(우도가 양쪽에서 같음). 반대로 "그 증거는 H가 아니면 나오기 매우 어렵다"는 **강한 강화**다.

### 3.6 인과추론

핵심 한 줄: **상관은 인과가 아니다.** 'A 때문에 B'를 주장하면 다음 다섯 공격을 먼저 떠올린다.

| 인과 결론 공략 5법 | 약화하는 정보 |
|---|---|
| 대체원인 | B는 A가 아니라 다른 C 때문일 수 있다 |
| 역인과 | A가 B를 만든 게 아니라 B가 A를 만들었을 수 있다 |
| 공통원인(교란) | A와 B가 서로 원인·결과가 아니라 둘 다 X의 결과다 |
| 대조 실패 | A가 없는 비교집단과 비교하지 않았다 |
| 측정 결함 | B가 실제로 변한 게 아니라 측정 방식만 바뀌었다 |

| 강화하는 정보 | 이유 |
|---|---|
| A가 없는 비교집단에서는 B가 안 나타났다 | 대조군 보강 |
| A를 인위적으로 조작하자 B가 변했다 | 개입 증거 |
| A가 증가할수록 B도 일정하게 증가했다 | 용량-반응 |
| A가 먼저 변하고 그 뒤 B가 변했다 | 시간 선후 |
| B를 만드는 다른 원인이 통제되었다 | 경쟁가설 제거 |
| A가 B를 일으키는 중간 기제가 확인되었다 | 메커니즘 제시 |

함정: '함께 나타난다(상관)'만으로 인과를 단정하는 것이 전형적 오류. **시간상 먼저라는 이유만으로 원인이라고 보는 것**도 오류(공통원인 가능).

### 3.7 최선의 설명 추론(귀추)

핵심 한 줄: 관찰된 현상을 여러 가설이 설명할 수 있을 때, **가장 잘 설명하는 것**을 잠정 채택하는 추론. 결론은 보장이 아니라 잠정적이다.

좋은 설명의 조건:
1. 현상을 직접 설명한다.
2. 비슷한 현상도 함께 설명한다.
3. **경쟁가설보다 예외가 적다.**
4. 가설이 참이면 예상되는 새 관찰이 실제로 나온다.

| 선지 기능 | 강화/약화 |
|---|---|
| 경쟁가설이 설명 못 하는 현상을 이 가설이 설명한다 | 강화 |
| 가설의 작동 기제가 발견되었다 | 강화 |
| **더 적은 가정으로 같은 현상을 설명하는 경쟁가설이 있다** | **약화** |
| 가설이 적용 안 되는 곳에서도 같은 현상이 나타났다 | 약화(독점적 설명력 깨짐) |

함정: 귀추 결론은 '유일하게 옳다'가 아니라 '현재 가장 낫다'이다. 선지가 '이 가설이 참임이 증명되었다'로 키우면 과강도. **경쟁가설을 빠뜨리고 결론낸 논증**은 약점이 크다.

### 3.8 미결정성

핵심 한 줄: 같은 증거를 **서로 다른 이론이 똑같이 잘 설명**할 수 있어서, 증거만으로는 어느 이론이 옳은지 결정되지 않는다.

출제 연결:
- 귀추의 약점: 경쟁가설이 같은 증거를 똑같이 설명하면, 그 증거는 가설을 **구별하지 못한다**(베이즈로 보면 양쪽 우도가 같음).
- 강화·약화 판정: "그 관찰은 두 이론 모두에서 똑같이 기대된다"는 **무관 또는 강화 무력화** 선지의 전형이다.
- 약화 도구: 어떤 가설을 약화하려면 단순히 다른 설명이 '가능하다'를 넘어, **그 다른 설명이 더 낫거나 같다**는 점을 보여야 결정력이 생긴다.

### 3.9 과학철학 표지어·양상 함정 통합표

과학 지문은 양상·보조사의 강도를 미세하게 바꿔 오답을 만든다.

| 지문 표현 | 오답 선지 변형 | 왜 틀리는가 |
|---|---|---|
| A일 가능성이 있다 | A이다 | 가능을 사실로 바꿈 |
| A일 수 있다(조건부) | 항상 A이다 | 조건을 빼고 단정 |
| 대체로 A는 B | 반드시 A는 B / 모든 A는 B | 귀납 경향을 전칭·필연으로 강화 |
| A가 P라고 주장한다 | P가 사실이다 | 주장을 사실로(인식 간극) |
| P가 확인·입증되었다 | (반박하려면) 증거 신뢰성 공격 필요 | 사실성 함축이라 단순 부정 불가 |
| A가 B와 함께 나타났다 | A가 B의 원인이다 | 상관을 인과로 |
| A가 B보다 먼저다 | A가 B의 원인이다 | 선후를 인과로(공통원인 가능) |
| 변칙이 관찰됨 | 이론을 즉시 폐기해야 한다 | 쿤: 대안 없으면 전환 안 됨 |
| 측정에서 검출 안 됨 | 대상이 존재하지 않는다 | 장비 민감도 확인 필요('못 찾음'≠'없음') |

#### 보조사 함정(과학 지문 빈출)

| 보조사 | 논리 기능 | 과학 지문 함정 |
|---|---|---|
| 만 / 뿐 / 밖에 | 한정(오직) | 'A 조건에서만 B가 나타난다'는 A가 B의 **필요조건**, 'A이면 B'(충분)로 뒤집지 말 것 |
| 도 | 첨가(또한) | '대조군에서도 B가 나타났다'는 A 없이도 B 가능 → 인과 **약화**, 이를 'A만'으로 좁히지 말 것 |
| 조차 / 마저 | 극단 첨가 | '가장 민감한 장비로조차 검출 안 됨'이면 나머지 장비는 당연히 검출 못 함 → 음성 결과 강화 |
| 까지 | 척도 끝 | '먼 거리까지 검출한 적 있다'는 탐지 범위를 끝까지 확장 → '못 찾음=없음' 강화 |
| 은 / 는 | 주제·대조 | '이 조건에서는 B다'는 다른 조건은 다를 수 있음 함축, 전칭으로 비약 금지 |
| 마다 | 분배 전칭(모든) | '실험마다 같은 결과'는 모든 시행 → 재현성 강화, 특칭('어떤 실험은')으로 약화 오독 금지 |
| (이)나 | 선택·근사 | 'A나 C가 원인'은 원인 후보가 둘, 하나로 단정 금지 |
| 라도 | 양보(even if) | 'A라도 B'는 A가 충분조건이 아님, 'A이면 B'로 강화 금지 |
