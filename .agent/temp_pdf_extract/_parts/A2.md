## 2. 양상논리학

### ▶ 시험장 코어
- 양상 = 명제 P에 얹힌 화자의 태도·강도. P가 참인지가 아니라, P를 **반드시/가능/안다/해야/할 수 있다 중 어느 강도로** 말하는가다. LEET는 공리명을 안 묻고 **양상 종류 구분**과 **양상 전환의 정당성**만 묻는다.
- 5종 구분: **진리(필연·가능) / 인식(앎·믿음) / 당위(의무·허용·금지) / 능력(동적)**.
- **제1원칙**: 선지가 양상을 바꾸면 일단 오답 의심 — 특히 **가능을 사실로(P일 수 있다 → P이다)**, **당위를 사실로(P여야 한다 → P이다)**, **능력을 의무로(P할 수 있다 → P해야 한다)**, **허용을 의무로(P해도 된다 → P해야 한다)**. 전환은 지문에 근거(증거·규범·능력제약·모형화 선언)가 명시될 때만 정당.
- **제2원칙**: 같은 표지('할 수 있다', '-어야 한다')가 문맥에 따라 인식/당위/능력으로 갈린다. **표지를 양상유형에 1:1로 고정하면 그 자체가 함정**이다.

---

### 2-1. 형식 골격 — 가능세계 의미론

양상은 '가능세계(possible world)'로 푼다. 모델은 세 요소 W, R, V로 본다.

| 요소 | 한국어 풀이 | 역할 |
|---|---|---|
| W | 가능세계들의 집합 | 현실 포함, 가정해 볼 수 있는 세계 전부 |
| R | 접근가능성 관계 | 한 세계에서 '닿을 수 있는' 세계가 어디까지인가 |
| V | 평가 | 각 세계에서 명제가 참인지 거짓인지 정해 주는 것 |

진리조건(기호 없이 한국어로):
- **필연(P) = 현재 세계에서 접근 가능한 모든 세계에서 P가 참**이다. (예: 물리법칙, 인과적 필연)
- **가능(P) = 현재 세계에서 접근 가능한 적어도 한 세계에서 P가 참**이다. (예: 기술의 잠재 기능, 예외 상황)

핵심 직관: '필연'은 '모든 세계', '가능'은 '한 세계라도'. 그래서 **필연이면 가능은 자동으로 따라오지만, 가능에서 필연은 따라오지 않는다.**

### 2-2. 기초 공리 K / D / T (한국어로)

공리는 '가볍게 읽고 넘긴다'. 시험은 공리명을 묻지 않는다. 단, 아래 **T가 당위 해석에서 깨진다**는 점만은 함정으로 직결되니 반드시 챙긴다.

| 공리 | 한국어 진술 | 예시 | 비고 |
|---|---|---|---|
| K (분배) | '필연적으로 (P이면 Q)'이고 '필연적으로 P'이면, '필연적으로 Q'다 | 총각이면 독신인 것이 필연이고 필연적으로 총각이면, 필연적으로 독신이다 | 기본 분배, 거의 모든 체계에 있음 |
| D | 필연이면 적어도 가능은 해야 한다 (필연(P)이면 가능(P)) | — | 모순된 의무를 배제하는 쪽 |
| **T** | 필연이면 실제로 그렇다 (필연(P)이면 P) | H2O가 물인 것이 필연이면, H2O는 실제로 물이다 | **필연 해석에선 자연스럽다** |

**T의 붕괴 — 가장 중요한 한 줄**: 같은 강도를 '당위'로 읽으면 T는 깨진다. '친구들은 항상 사이좋게 지내야 마땅하다'가 참이라고 해서 '친구들은 실제로 항상 사이좋게 지낸다'가 따라오지 않는다. 즉 **'P해야 한다'에서 'P이다'를 끌어내는 선지는 오답**이다(당위→사실 비약, 아래 흄의 법칙과 직결).

요지: 같은 강도(필연/당위)라도 **해석이 무엇이냐에 따라 쓸 수 있는 공리가 달라진다.** 그래서 LEET는 공리가 아니라 '어떤 양상인지'를 묻는다.

### 2-3. 양상 5종 표

| 양상 | 관심 | 필연 쪽 의미 | 가능 쪽 의미 | 대표 함정 |
|---|---|---|---|---|
| **진리(Alethic)** | 논리적·형이상학적·물리적 필연·가능 | 모든 접근세계에서 참(반드시) | 한 세계라도 참(그럴 수 있다) | **'이다'를 '해야 한다'로 바꾸기**(사실→규범)는 거의 오답 신호 |
| **인식(Epistemic)** | 화자의 지식·증거에 비추어 P가 확실/가능한가 | 안다 = P를 사실로 함축 | 믿는다·주장한다 = P의 참 보장 안 함 | **주장·가설을 '입증/확인'처럼 사실로 취급**. 사실성 표지 있을 때만 P를 참으로 |
| **당위(Deontic)** | 규범(법·규칙·도덕)상 의무/허용/금지인가 | 의무 = P 해야 함, 금지 = P 하면 안 됨 | 허용 = P 해도 됨 | **의무를 사실처럼**, **허용을 의무로** 바꾸기. T를 당위에 무비판 적용 금지 |
| **능력/동적(Dynamic)** | 주체의 능력·성향·상황이 P를 가능하게 하는가 | — | 능력 = 주체 a가 P를 실현할 힘이 있다 | **능력을 의무로**, 능력을 단순 인식적 가능과 혼동. '복권 당첨 가능성'은 있어도 '당첨할 능력'은 아니다 |

인식 양상 보충(시험 빈출):
- **안다(K) → P를 함축**: 'a가 P를 안다'면 P를 사실로 놓아도 된다(사실성, factivity).
- **믿는다/주장한다(B) → P를 함축하지 않음**: 'a가 P를 믿는다/주장한다'는 P의 참을 보장하지 않는다.
- 정리는 기호 대신 'A:P'(주체 위주)로. 학설 지문은 'A·B·C 중 누구 입장인지' 패러프레이징으로 흔드니 **누구의 양상인지**를 먼저 박는다.

### 2-4. 한국어 표지어 압축표 (보조사 결합형 주의 포함)

표지를 외우되, **표지 1개 = 양상 1개로 고정하지 않는다**(제2원칙). 같은 형태가 문맥으로 갈린다.

| 양상 | 한국어 표지 | 시험장 처리 |
|---|---|---|
| 필연 | 반드시, 필연적으로, 불가피하다, 일 수밖에 없다, 예외 없이, 항상, 결코 아니다 | '대체로·항상' 같은 경험적 경향과 혼동 금지. 근거 없으면 **과강도 선지** |
| 가능 | 할 수 있다, 가능하다, 일 수도 있다, 개연성이 있다, 가능성이 높다, **배제할 수 없다** | 가능 ≠ 실제 발생, 가능 ≠ 필연. '**배제할 수 없다**'는 강화가 아니라 **약화**일 수 있음 |
| 인식-지식 | 알다, 밝혀졌다, 입증되었다, 확인되었다, 관찰되었다 | 사실성 강함 → P를 참으로 둠. 반박하려면 **증거 신뢰성**을 쳐야 함 |
| 인식-믿음 | 생각하다, 여기다, 간주하다, 주장하다, 보다, 추정하다, 가정하다 | 사실성 없음 → **주장자 입장으로만** 처리. P가 참이라 비약 금지 |
| 당위-의무 | -어야 한다, 의무가 있다, 해야 한다 | 의무 ≠ 실제로 한다 |
| 당위-허용 | -어도 된다, 허용된다, (규범 의미의) 할 수 있다 | 허용 ≠ 의무 |
| 당위-금지 | -어서는 안 된다, 금지된다, 위법이다 | 규범 위반 ≠ 실제로 안 한다, ≠ '나쁘다'(도덕평가) |
| 능력 | 할 수 있다, 가능하게 한다, 역량이 있다, 기술적으로 가능, 실현할 수 있다 | 능력 ≠ 실제 실현, 능력 ≠ 법적 허용 |

**보조사 결합형 — 양상에 보조사가 붙으면 한정·첨가가 겹쳐 강도가 달라진다(고빈도 함정)**:

| 결합형 | 분해 | 시험장 처리 |
|---|---|---|
| **해야'만' 한다 / -어야만** | 당위 + 한정(만) | '오직 그것만이 의무·요건' = **필요조건**. 'P해야만 Q성립'은 P가 Q의 필요조건이지 충분조건이 아니다. **'P하면 Q'(충분)로 오독 금지** |
| **할 수'도' 있다** | 가능 + 첨가(도) | '그것도(다른 것과 함께) 가능' = 가능성을 **추가** 제기할 뿐. 그 선택지로 **확정**된 게 아니다. 'A도 가능'을 'A만 가능'으로 뒤집기 금지 |
| **-어야 한다고 본다 / 주장한다** | 당위 + 인식(믿음) | 화자가 '의무라고 믿는다'일 뿐, 의무가 실제 성립함도 P가 실제임도 아님. **이중으로 약한 강도** |
| **할 수밖에 없다 / -ㄹ 수밖에** | 가능 형태 + 한정(밖에+부정) | 표면은 '할 수 있다'지만 '밖에 없다' 결합으로 **다른 가능성 배제 = 필연**으로 강해짐. 가능으로 약하게 읽으면 오독 |
| **조차/마저 + 양상** (예: a조차 P할 수 없다) | 극단 첨가 + 양상 | '가장 의외인 것까지' 그러하므로 나머지는 당연히 그러함. 주로 부정 맥락의 전칭 함축 |
| **-라도 (P라도 Q)** | 양보 + 양상 | 양보는 **충분조건이 아니다**. 'P라도 Q'는 'P이면 Q'가 아님. 충분조건으로 비약 금지 |

(보조사 일반 규칙은 표지어 종합표 참조. 여기선 양상과 결합해 강도를 바꾸는 경우만 모았다.)

### 2-5. 양상 전환 오답 표 (직결 빈출)

선지가 지문의 양상을 한 칸 옮기면 거의 오답이다. 옮긴 방향을 보고 즉시 판정한다.

| 지문 양상 | 오답 선지 형태 | 왜 틀리는가 (전환 방향) |
|---|---|---|
| **A일 가능성이 있다** | A이다 | **가능 → 사실** |
| **A여야 한다** | A이다 | **당위 → 사실** (T의 당위 붕괴) |
| A가 P라고 주장한다 | P이다 | 믿음/주장 → 사실 (사실성 없음) |
| A가 P를 안다 | P가 아닐 수 있다 | 지식의 **사실성을 무시** |
| **A할 수 있다** | A해야 한다 | **능력 → 의무** |
| **A해도 된다** | A해야 한다 | **허용 → 의무** |
| A가 불가피하다 | A가 바람직하다 | 필연 → 가치평가 |
| A가 바람직하다 | A가 가능하다 | 가치판단 → 가능조건 |
| A일 수 있다(가능) | A이다(필연·사실) | 가능 → 필연 (양상 키우기) |

**전환이 정당화되는 4가지 명시 단서**(이게 지문에 있으면 전환을 허용):
1. "규범 준수는 항상 보장된다" 같은 **이상화 전제**(명시 필요)
2. "입증/확인/알다"처럼 **사실성 표현**
3. "법적으로 가능 / 물리적으로 가능"처럼 **가능의 종류 고정**
4. "이론적으로 정의한다 / 환원한다"처럼 **모형화 선언**

### 2-6. 논쟁적 원리 — OIC와 흄의 법칙

시험은 이 둘을 '항상 성립하는 공리'로 쓰지 않는다. **'합의된 원리가 아니다'라는 점 자체가 함정 포인트**다.

| 원리 | 요지 | 시험장 처리 |
|---|---|---|
| **OIC (해야 함은 할 수 있음을 함의)** | "P해야 한다면 P할 수 있어야 한다" | 직관적이나 **항상 성립하는 원리로 합의된 것은 아니다**(맥락주의·반례 논쟁). 독해에선 '이상화 전제'로 기능할 수 있을 뿐. **'의무가 있으니 능력도 있다'를 당연시하는 선지는 의심** |
| **흄의 법칙 (존재에서 당위 못 끌어냄, is-ought)** | "존재(있다)로부터 당위(해야)를 도출할 수 없다" | **규범 전제 없이 규범 결론이 나오면 정당화 공백(도약)**이 생긴다는 경고로 정리. 사실 전제만으로 '해야 한다' 결론을 내는 논증은 **숨은 규범 전제가 필요**(가정·강화 문제에서 빈출) |

방향 정리(혼동 주의):
- **흄의 법칙** = 사실 → 당위 도출 금지(상향 비약 차단).
- **T의 당위 붕괴**(2-2) = 당위 → 사실 도출 금지(하향 비약 차단).
- 둘은 반대 방향이지만 결론은 같다: **사실과 당위 사이를 근거 없이 건너뛰는 선지는 친다.**

한국어 모달 보충:
- **'-겠-'**: 담화에 따라 **의지**("기필코 합격하겠다") 또는 **추측·추론**("비가 오겠다" — 관찰 증거 기반 추론)으로 갈린다. 추론 기반 정보 표지로도 다뤄진다.
- **'-(으)ㄹ 수 있다'**: **인식적 가능**("비가 올 수 있다")과 **능력 가능**("나는 수영을 할 수 있다")으로 갈린다. 주어 성격·담화 목적으로 판별한다.
