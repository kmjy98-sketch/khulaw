## 6. 논리게임(그루핑·배치·순서)

### ▶ 시험장 코어

| 단계 | 행동 | 한 줄 요령 |
|---|---|---|
| 1 | 유형 판별 | 순서·배열 / 그룹·짝짓기 / 배치(속성) 중 무엇인지 먼저 정한다 |
| 2 | 축 잡기 | **가장 고정된 정보**를 행 또는 열로 둔다. 순서가 있으면 순서를 가로축 |
| 3 | 조건 분류 | 확정조건 / 금지조건(부정) / 연결조건(블록·조건문) / 분기조건 으로 갈라 적는다 |
| 4 | 처리 순서 | **확정 먼저 → 연쇄(블록·앵커) → 마지막에 경우분기**. 강한 규칙부터 |
| 5 | 선지 검증 | 모든 경우를 펼치지 않는다. **물어본 선지를 죽일 만큼만** 경우를 만든다 |

- 선지 양상 구분이 핵심: **반드시 참**=모든 경우 표에서 성립 / **가능**=경우 하나만 찾으면 끝 / **불가능**=어느 경우에도 모순.
- 선지마다 새 표를 그리지 않는다. 확정 템플릿에서 **가능성만 지운다**.

---

### 6.1 먼저 유형을 정한다

표를 그리기 전에 문항이 어느 유형인지 정한다. 축을 잘못 잡으면 표가 꼬여 시간이 사라진다.

| 유형 | 내용 | 대표 축 |
|---|---|---|
| **순서·배열형** | 자리, 순위, 시간표, 줄서기 | 순서(위치)를 가로축 |
| **그룹·짝짓기형(연결·묶기)** | A를 B에 1대1 또는 1대다 대응, 같은 조·같은 팀으로 분류 | 고정 집합을 세로축, 대응 대상을 가로축 |
| **배치·속성형** | 개체에 색·직업·지역·점수 같은 속성을 붙임 | 개체를 세로축, 속성을 칸 안에 |

진실·거짓형(발화자 중 일부만 참)과 최소·최대·비율형은 계산형에 가깝다 — 이 섹션의 표 작성 원리는 공유하되, 양상 판정과 분기 처리에 집중한다.

---

### 6.2 표 잡는 법 (축 선택)

기준축을 잘못 잡는 것이 1순위 실점 원인이다.

- 순서가 있으면 **순서를 가로축**으로 둔다.
- 개체(사람·대상)가 고정되어 있으면 **개체를 세로축**으로 둔다.
- 장소·시간·물건 중 하나가 1대1 대응이면 그것을 중심축으로 둔다.
- 범주가 세 개 이상이면 **두 축만 먼저 잡고** 나머지는 칸 안에 적는다.
- '서로 다르다 / 같다 / 인접 / 앞 / 뒤 / 바로 전 / 적어도 / 많아야'는 별도로 표시한다.

예: 개체 a,b,c를 자리 1,2,3에 앉히는 순서형이면 가로축=자리(1,2,3), 세로축은 두지 않고 각 자리 칸에 개체를 적는다. 개체 a,b,c를 그룹 A,B에 나누는 묶기형이면 세로축=그룹(A,B), 각 칸에 소속 개체를 적는다.

### 6.3 조건 처리 순서 (확정 먼저 → 연쇄 → 경우분기)

**모든 경우의 수를 다 펼치지 않는다.** LEET·PSAT 모두 대부분 선지 검증형이다. 물어본 선지를 죽일 만큼만 경우를 만든다.

| 순서 | 처리할 조건 | 설명 |
|---|---|---|
| 1 | **확정조건** | 'a는 1번이다'처럼 위치·소속이 즉시 박히는 조건. 가장 먼저 표에 고정 |
| 2 | **금지조건(부정)** | 'a는 2번이 아니다', 'a와 b는 같은 조가 아니다'. 칸에 X로 표시 |
| 3 | **연결조건(블록·조건문)** | 'a와 b는 붙는다(블록)', 'a가 오면 b도 온다(조건문)'. 강한 연결부터 묶음 |
| 4 | **분기조건** | 둘로만 갈리는 조건. **마지막에** 경우를 나눈다. 경우가 둘이면 템플릿 2개 |

요령: 강한 규칙(확정·블록)부터 배치하면 칸이 빠르게 줄어들어 분기 수가 작아진다. 경우가 둘로만 갈라지면 두 템플릿을 만들고, 선지는 두 템플릿 위에서만 확인한다.

---

### 6.4 앵커 · 금지쌍 · 블록 (세 가지 핵심 장치)

| 장치 | 정의 | 표 처리 | 함정 |
|---|---|---|---|
| **앵커** | 위치·소속이 한 곳으로 못박히는 개체 | 즉시 칸에 고정하고 그 칸을 다른 개체에서 배제 | 앵커를 늦게 잡아 분기를 키움 |
| **금지쌍** | 같이 못 오는 두 개체 (a와 b는 같은 조 불가) | 한 칸에 넣으면 모순 — 둘을 갈라놓는 분기 생성 | 금지쌍을 조건문으로 착각 |
| **블록** | 반드시 붙는 묶음 (a와 b는 인접) | a-b 또는 b-a 덩어리로 이동시키며 자리 탐색 | '앞선다'(순서만)와 '바로 앞선다'(인접=블록) 혼동 |

거리 조건 'a와 b 사이에 하나가 있다'는 a_b 형태의 **간격 블록**으로 처리한다(사이 칸 1개 고정, 방향은 미정이면 분기).

### 6.5 그룹 선지 패턴 — 양상별 판정

선지의 **양상**(반드시 / 가능 / 불가능)에 따라 검증법이 정반대다. 여기서 틀리면 표를 맞게 그려도 오답이다.

| 선지형 | 양상 | 처리 |
|---|---|---|
| **반드시 a가 1번이다** | 반드시 참 | **모든 가능한 표**에서 성립해야 참. 반례 표 하나면 거짓 |
| **a가 1번일 수 있다** | 가능 | **가능한 표 하나만** 찾으면 참 |
| **a와 b는 함께 올 수 없다** | 불가능 | 같은 표에 넣어 **모순**이 나면 참(금지쌍) |
| a가 오면 b도 온다 | 조건문 | a를 넣은 모든 경우에서 b가 따라오는지 확인 |
| a와 b 중 정확히 하나 | 양상 결합 | 둘 다 참·둘 다 거짓이면 불가. 한쪽만 참 |
| a와 b 중 적어도 하나 | 양상 결합 | **둘 다 거짓만 불가**. 한쪽이라도 참이면 만족 |
| a와 b 중 많아야 하나 | 양상 결합 | **둘 다 참만 불가**. 한쪽만 또는 둘 다 거짓 허용 |
| a가 b보다 앞선다 | 순서 | 순서만 확정, **인접 아님** |
| a가 b 바로 앞선다 | 순서+블록 | **인접까지 확정**(블록) |
| a와 b 사이에 하나가 있다 | 거리 | 간격 블록(사이 1칸) |

핵심 대비:
- **반드시 참** 선지는 **반례 한 개**로 깬다. **가능** 선지는 **사례 한 개**로 세운다. 방향이 반대다.
- '적어도 하나'는 둘 다 거짓만 막고, '많아야 하나'는 둘 다 참만 막는다 — 이 둘을 뒤집는 함정이 **빈출**.

### 6.6 보조사가 만드는 조건 (게임 룰 번역표)

문제 조건은 보조사 한 글자로 논리가 바뀐다. 조건문에 박힌 보조사를 정확히 번역해야 표가 맞는다.

| 표지 | 기능 | 조건 번역 | 함정 |
|---|---|---|---|
| **만 / 뿐 / 밖에** | 한정(only) | 'a여야(만) 1번'은 a가 1번의 **필요조건**(1번이면 a, a라고 1번은 아님) | **'a만 1번'을 'a이면 1번'(충분조건)으로 오독** |
| **도** | 첨가(also) | 'a도 A조'면 a 외에 **다른 것도 A조**에 있음 | 'a도'를 'a만'으로 뒤집어 단독으로 봄 |
| **조차 / 마저** | 극단 첨가(even) | 'a조차 탈락'이면 나머지는 당연히 탈락 | 예상밖 극단 사례를 일반 사례로 평탄화 |
| **까지** | 척도 끝 | 범위를 a 끝까지 확장 | 끝점 포함 여부 누락 |
| **은 / 는** | 주제·**대조** | 'a는 1번'은 **다른 것은 1번이 아닐 수 있음**을 함축 | **대조를 전칭이나 한정으로 비약** |
| **마다** | 분배 전칭(each) | '조마다 두 명'은 **모든 조**가 두 명 | 특칭('어떤 조는')으로 약화 오독 |
| (이)나 | 선택/근사 | 'a나 b가 1번'은 둘 중 하나(배타 여부는 별도 확인) | — |
| 라도 | 양보(even if) | 'a라도 가능'은 충분조건 아님 | 양보를 충분조건으로 격상 |

---

### 6.7 실전 운영 원칙

1. 표는 한 번만 그린다. 선지마다 새 표를 그리지 말고 **확정 템플릿에서 가능성만 지운다**.
2. 경우가 둘로 갈리면 두 템플릿을 동시에 들고 간다. 셋 이상이면 더 강한 확정조건을 찾아 먼저 박는다.
3. '반드시 참' 발문이면 **깨는 표**(반례)를, '가능' 발문이면 **세우는 표**(사례)를 노린다.
4. 금지쌍·블록·앵커를 표 옆에 약물로 적어두고, 분기 직전 다시 훑어 위반을 거른다.
5. 머리로 굴리지 않는다 — **가장 고정된 정보**를 축으로 박고 손으로 표를 채운다.
