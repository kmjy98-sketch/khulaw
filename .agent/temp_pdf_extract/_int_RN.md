## 0. 시험장 5단계 행동과 발문 처리

> [!tip] 시험장 코어
> 모든 문제를 같은 5단계로 처리한다.
> - **1 발문 판별** — 강화/약화/반드시참/추론/필요가정/충분가정/오류/원리/계산 중 무엇인지 동사부터 본다.
> - **2 타깃 주장 T 확정** — 평가 대상을 한 문장(결론·가설·규범명제·조건문 중 하나)으로 줄인다.
> - **3 표지어 고정** — 조건·양상·범위를 보조사로 못박는다(`만`·`반드시`·`가능`·`주장하다` 등).
> - **4 선지 기능 판정** — 선지가 연결고리·반례·대안원인·표본·양상전환 중 무엇을 건드리는지 분류. T를 안 건드리면 무관.
> - **5 강도 맞추기** — 지문보다 센 선지를 제거한다(**가능<->필연 / 일부<->전부 / 주장<->사실**).

> [!note] 기출 정합성 (2025 추리논증 40문항 확인)
> 실제 추리논증은 대부분 **<보기> ㄱㄴㄷ '있는 대로 고른 것'** 형식이고, 주류는 **강화·약화 / 규칙·예외 적용 / 견해·원리 분석**이다. 형식논리·양상은 단독 문항보다 이 유형들 **속에 녹아** 있다. 본 추리본의 도구(양상 전환·강화약화 5종·조건과 쌍조건·논리게임 강한 단서)가 그대로 적용된다. 각 보기를 '무슨 논리 조작인가'로 번역하는 것이 핵심.

> [!note] 최종 압축 한 문장
> 발문을 보고, 타깃 주장을 잡고, 조건·양상·범위를 고정한 뒤, 선지가 반례와 대안설명을 줄이는지 늘리는지만 본다. 고득점은 논리 용어 암기가 아니라 **방향을 뒤집지 않고, 강도를 키우지 않고, 주체를 섞지 않는 것**에서 나온다.

| 단계 | 한 줄 행동 | 5초 체크 |
|---|---|---|
| **1 발문 판별** | 발문이 요구하는 유형을 먼저 확정 | 발문 동사부터 본다 |
| **2 타깃 주장 T 확정** | 평가 대상을 **한 문장**으로 줄인다 | 답은 보통 결론 하나에 걸려 있다 |
| **3 표지어로 조건·양상·범위 고정** | `만`·`오직`·`없이는`·`반드시`·`가능`·`주장하다` 등을 먼저 본다 | **보조사 하나가 방향을 바꾼다** |
| **4 선지 기능 판정** | 선지가 연결고리·반례·대안원인·표본·양상전환·적용조건 중 무엇을 건드리는가 | T를 안 건드리면 무관 |
| **5 강도 맞추기** | 지문보다 센 선지를 제거한다 | 가능<->필연, 일부<->전부, 주장<->사실 |

### 0.1 5단계 행동 절차 (상세)

#### [1단계] 발문 판별 — 5초 안에 유형 확정

> [!warning] 유형을 틀리면 맞는 선지를 골라도 오답 처리된다
> 발문의 동사·명사가 유형을 지정한다. 본문을 읽기 **전에** 무엇을 요구받는지 먼저 못박는다(예: 약화 문제를 강화로 풀기).

| 발문 신호 | 유형 |
|---|---|
| **"강화하는", "지지하는", "뒷받침하는"** | 강화 |
| **"약화하는", "반박하는", "의문을 제기하는"** | 약화 |
| **"반드시 참인", "참일 수밖에 없는"** | 반드시 참 |
| **"추론할 수 있는", "도출되는"** | 추론 가능 |
| **"전제로 반드시 필요한", "가정하고 있는"** | 필요가정 |
| **"추가하면 결론이 따라 나오는"** | 충분가정 |
| **"논증의 문제점/결함", "비판으로 적절한"** | 오류 찾기 |
| **"원리를 적용하면", "사례에 비추어"** | 원리 적용 |
| **"배치·순서·참/거짓", "최소·최대"** | 계산·그룹 |

#### [2단계] 타깃 주장 T 확정 — 한 문장으로

> [!note] T는 보통 하나의 결론·가설·규범명제·조건문이다
> 결론이 여러 문장처럼 보여도 평가 대상은 하나다. **한 문장으로 못 줄이면 아직 못 읽은 것**이다. 동시에 T의 종류(조건문·일반화·인과·유비·설명가설·규범판단·계산규칙)를 분류해 둔다 — 종류에 따라 4단계 공격 포인트가 달라진다.

#### [3단계] 표지어로 조건·양상·범위 고정

> [!note] 전부 기호화하지 말고 이것만 표시한다
> 주장 / 근거 / 조건(A이면 B 계열) / 양화(모든·어떤·없음·전부는 아님) / 양상(반드시·가능·알다·믿다·해야 한다·할 수 있다) / 변수(원인·결과·대조집단·측정값·예외). 이 단계에서 **보조사의 논리 기능**을 반드시 반영한다(아래 0.3 표).

#### [4단계] 선지 기능 판정

선지 E가 T와 어떤 관계인지를 기능으로 분류한다.

| E가 하는 일 | 판정 |
|---|---|
| **T의 반례 가능성을 줄인다** | 강화 |
| **T의 대안설명을 줄인다** | 강화 |
| **전제와 결론 사이 빈칸을 메운다** | 강화(연결고리) |
| **반례·대체원인·역인과·표본편향·측정오류·적용조건 미충족을 만든다** | 약화 |
| **T가 아니라 주변정보를 건드린다** | **무관(빈출 오답)** |

#### [5단계] 강도 맞추기 — 센 선지 제거

> [!warning] 지문보다 강한 선지가 가장 흔한 함정
> - 지문이 가능성인데 선지가 **필연(반드시)**이면 -> 제거
> - 지문이 일부(어떤)인데 선지가 **전부(모든)**면 -> 제거
> - 지문이 주장·믿음인데 선지가 **사실**로 단정하면 -> 제거(주체 바꿔치기)
> - 필요가정 문제에서 **필요 이상으로 강한** 선지는 대개 오답이다

### 0.2 발문 유형 한눈표 — 유형별 핵심 동작 매핑

| 유형 | 발문 신호 | 핵심 동작 한 줄 | 1순위로 찾을 것 |
|---|---|---|---|
| **반드시 참** | "반드시 참인" | 지문에서 **연역적으로 강제**되는 것만 고른다 | 대우·양화 추론으로 닫히는 선지 |
| **추론 가능** | "추론할 수 있는" | 지문이 지지하면 통과(반드시참보다 느슨) | 지문과 모순 없는 선지 |
| **강화** | "강화·지지·뒷받침" | T의 **대안설명을 줄이는** 선지 | 대안설명 차단, 연결고리 보강 |
| **약화** | "약화·반박·의문" | T의 **숨은 전제를 부정**하는 선지 | 반례·역인과·공통원인·표본·측정 |
| **필요가정** | "전제로 반드시 필요한" | 선지를 **부정하면 결론이 무너지는지** 본다 | 부정 시 결론 붕괴 / 너무 센 선지 배제 |
| **충분가정** | "추가하면 결론이 따라 나오는" | 넣으면 **결론이 반드시 따라오는지** 본다 | 전제-결론 빈칸, 주어·범위·양상 일치(세도 됨) |
| **오류 찾기** | "문제점·결함·비판" | 전제가 결론을 **보장하는지** 묻는다 | 필요/충분 혼동, 역·이, 상관->인과, 부분->전체 |
| **원리 적용** | "원리를 적용하면" | 사례가 원리의 **조건을 충족·예외인지** 본다 | 적용요건, 예외조항, 의무/허용/금지 분리 |
| **계산·그룹** | "배치·순서·최소·최대" | 표 그리기 전 **앵커·불변량·극값·경우분기** | 확정정보 먼저, 경계값부터 |

> [!warning] 필요가정 vs 충분가정 핵심 대비
> - **필요가정**: "없으면 안 되는 최소 다리" — 부정하면 결론이 무너진다. **너무 강한 선지는 필요가정이 아니다.** 부정 테스트는 여기에만 쓴다.
> - **충분가정**: "넣으면 결론을 보장하는 다리" — **강해도 무방하다.**

> [!note] 강화·약화 1순위 — 결론 종류로 갈린다
> 인과 -> 대조군·역인과·공통원인 / 실험 -> 무작위화·측정민감도·탈락편향 / 일반화 -> 표본 대표성·반례 / 조건문 -> A인데 B 아닌 사례 / 유비 -> 결론 관련 유사점·차이점 / 설명가설 -> 경쟁가설·새 예측 / 규범 -> 적용요건·예외조항 / 통계 -> 분모·모집단·기준시점.

### 0.3 표지어·보조사 논리 기능표 (3단계 필수)

> [!warning] 보조사 하나가 방향과 강도를 바꾼다
> 조건·양상·범위를 고정할 때 이 표를 3단계에서 그대로 적용한다. 시험의 가장 그럴듯한 오답은 거의 **역 또는 이**다.

| 표지어 | 논리 기능 | 시험장 번역 | **빈출 함정** |
|---|---|---|---|
| **만 / 뿐 / 밖에** | 한정(오직) | 'A여야(만) B'는 A가 B의 필요조건 ('A만 B' = B이면 A) | **'A만 B'를 'A이면 B'(충분조건)로 오독** |
| **도** | 첨가 | 'A도 B'는 A를 포함해 다른 것도 B | 'A도'를 'A만'으로 뒤집기 |
| **조차 / 마저** | 극단 첨가 | 'A조차 B'면 나머지는 당연히 B(예상 밖·부정 맥락) | **특칭 강조를 전칭으로 키움** |
| **까지** | 척도 끝 | 범위를 A 끝까지 확장 | 범위 끝을 일반화로 비약 |
| **은 / 는** | 주제·대조 | 'A는 B'는 다른 것은 B 아닐 수 있음을 함축 | 대조를 전칭이나 한정으로 비약 |
| **마다** | 분배 전칭(각각=모든) | 'A마다 B'는 모든 A가 B | 특칭으로 약화 오독 |
| **(이)나** | 선택·근사 | 둘 중 하나 또는 대략 | 정확 수치로 단정 |
| **라도** | 양보 | 'A라도 B'(양보) — 충분조건 아님 | **양보를 충분조건으로 격상** |
| **반드시** | 필연 | 반례 하나면 깨진다 | **가능을 필연으로 키움** |
| **가능** | 가능(P일 수 있다) | 사실로 바꾸지 말 것 | **가능을 사실로 단정** |
| **해야 한다 / 할 수 있다** | 의무 / 허용·능력 | 실제로 한다가 아님, 문맥에서 분리 | 당위를 사실로 바꿈 |
| **알다 / 주장하다** | 사실성 함축 / 사실성 없음 | '알다'는 보통 사실 함축, '주장·믿다'는 사실성 없음 | **주장·믿음을 사실로 바꿔치기** |

> [!check] 조건문 방향 10초 복습
> - 'A이면 B' = A는 충분·B는 필요. 안전한 변형은 **대우('B 아니면 A 아니다')뿐**.
> - **금지**: 역('B이면 A'), 이('A 아니면 B 아니다').
> - 'A일 때에만 B'·'오직 A만 B'·'B 없이는 A 불가'·'A하려면 B 필요'는 'A이면 B'와 절대 섞지 않는다.

## 1. 기초 논리학 — 조건문·양화·논증구조·오류

> [!tip] 시험장 코어
> - 조건문은 **방향**이다: 'P이면 Q'(P가 충분)와 'P일 때에만 Q'(Q가 **필요조건**)를 절대 안 섞는다.
> - 양화는 **범위**다: 모든·어떤·없음·전부는아님 네 문장을 구분만 하면 끝.
> - 논증은 주장·근거·**숨은전제(다리)** 셋으로 쪼갠다 — 정답은 근거 반복이 아니라 다리를 메우거나 끊는다.
> - 안전한 변형은 **대우 하나뿐**. 가장 그럴듯한 오답은 거의 역·이 오류.
> - 대표 오류는 **필요-충분 혼동·상관-인과 혼동·양상/범위 비약**으로 환원된다.

| 보면 | 즉시 변환 | 절대 금지 |
|---|---|---|
| **'P이면 Q'** | P는 충분, Q는 필요 / 안전한 변형은 '대우' **하나뿐** | '역'(Q이면 P), '이'(P 아니면 Q 아니다) |
| **'P여야(만) Q' · 'P일 때에만 Q' · '오직 P만 Q'** | Q이면 P (P가 **필요조건**) | 'P이면 Q'로 단정 |
| **'P하지 않는 한 Q'** | P 아니면 Q | 'P이면 Q 아니다'로 단정 |
| **모든·어떤·없음·전부는아님** | 네 문장을 절대 안 섞는다 | 어떤<->모든, 일부부정<->전부부정 뒤집기 |
| **보조사 만/뿐/밖에** | 한정(only) -> 뒤집어 읽기 | '만'을 **충분조건**으로 오독 |
| **보조사 도/조차/마저** | 첨가('다른 것도 Q') | '도'를 '만'으로 뒤집기 |

### 1.1 조건문 — 방향이 전부다

> [!tip] 'P이면 Q'는 이 네 줄로만 읽는다
> - P가 성립하면 Q도 성립한다. (P는 충분조건)
> - Q가 아니면 P도 아니다. (**대우** — 항상 같이 간다)
> - Q라고 해서 P라고 할 수는 없다. (역은 보장 안 됨)
> - P가 아니라고 해서 Q가 아니라고 할 수는 없다. (이는 보장 안 됨)

> [!warning] 가장 그럴듯한 오답은 거의 **역**(Q이면 P) 또는 **이**(P 아니면 Q 아니다)다. 안전하게 쓸 수 있는 변형은 **대우 하나뿐**이라고 외운다.

#### 역·이·대우 정리

| 이름 | 형태 | 원문과의 관계 |
|---|---|---|
| **원문** | P이면 Q | — |
| **대우** | Q가 아니면 P가 아니다 | **항상 같이 참** |
| **역** | Q이면 P | 원문만으로 보장 안 됨 |
| **이** | P가 아니면 Q가 아니다 | 원문만으로 보장 안 됨 |

#### 조건문 추론 판정표

| 주어진 추론 | 판정 |
|---|---|
| **P이면 Q, P 성립 -> 따라서 Q** | 가능 |
| **P이면 Q, Q 성립 -> 따라서 P** | **안 됨(역 오류, 후건긍정)** |
| **P이면 Q, P 아님 -> 따라서 Q 아님** | **안 됨(이 오류, 전건부정)** |
| **P이면 Q, Q 아님 -> 따라서 P 아님** | 가능(대우) |
| **P일 때에만 Q, Q 성립 -> 따라서 P** | 가능 |
| **P일 때에만 Q, P 성립 -> 따라서 Q** | 안 됨 |
| **P하지 않는 한 Q, P 안 함 -> 따라서 Q** | 가능 |
| **P하지 않는 한 Q, P 함 -> 따라서 Q 아님** | **안 됨** |

### 1.2 한국어 필요·충분조건 표지어

> [!note] 방향을 헷갈리게 하는 것은 난도가 아니라 **표지어**다. 표지어만 보고 즉시 방향을 고정한다.

#### 충분조건 표지어 ('이것만 오면 뒤가 따라온다')

| 표지어 | 변환 | 처리 |
|---|---|---|
| **P이면 Q / P라면 Q / P인 경우 Q** | P이면 Q | P 보면 Q 체크 |
| **P할 때 Q** | (문맥상) P이면 Q | 시간조건인지 법적조건인지 확인 |
| **P만으로 Q / P하기만 하면 Q** | P이면 Q | P 하나로 Q 충분하다는 주장 |
| **P는 Q를 초래한다 / 보장한다** | (인과적) P이면 Q | 인과문항으로 전환 |

> [!warning] 지문이 'P와 R이 함께일 때 Q'인데 선지가 'P만으로 Q'라고 하면 **과강도**.

#### 필요조건 표지어 ('이것 없이는 앞이 안 된다')

| 표지어 | 변환 | 처리 |
|---|---|---|
| **P하려면 Q가 필요 / P이기 위해서는 Q여야** | P이면 Q | Q가 넓은 쪽 |
| **Q 없이는 P 불가능 / Q가 전제되어야 P** | P이면 Q | Q 없으면 P 제거(숨은전제 후보) |
| **P는 Q를 요구한다** | P이면 Q | P가 Q를 필요로 함 |
| **Q인 경우에만 P / 오직 Q일 때 P** | P이면 Q | '만'·'오직' 뒤가 필요조건 |
| **Q가 아닌 한 P 아님** | P이면 Q | 부정 방향 확인 |

#### 필요충분조건 표지어

| 표지어 | 변환 |
|---|---|
| **P와 Q는 동치다 / P는 Q의 필요충분조건이다** | P이면 Q **그리고** Q이면 P |
| **P인 경우 그리고 그 경우에만 Q** | P이면 Q, Q이면 P (양방향) |
| **P와 Q가 정확히 일치한다** | P집합과 Q집합이 같음 — 예외 하나면 거짓 |

> [!warning] 한국어 조건문 5대 함정
> 1. **'P만 Q'는 보통 Q이면 P**다. '학생만 입장 가능'은 '입장 가능하면 학생'이지 '학생이면 모두 입장'이 아니다.
> 2. 'P이면 Q'에서 **'P 아니다'**가 나오면 **아무 결론도 못 낸다.** (전건 부정)
> 3. 'P이면 Q'에서 'Q이다'가 나와도 **P라고 못 한다.**
> 4. 'P하지 않는 한 Q'는 'P 아니면 Q'다. 'P하면 Q가 반드시 아니다'는 자동으로 안 나온다.
> 5. **'P가 있어야 Q'(필요조건)와 'P만 있으면 Q'(충분조건)는 반대 방향이다.** 가장 잘 틀리는 짝.

### 1.3 보조사의 논리 기능 — 빈출 함정표

> [!note] 조건·양화 문항의 함정은 대개 한 글자짜리 보조사에 숨어 있다. 보조사를 보면 즉시 논리 기능으로 변환한다.

| 보조사 | 논리 기능 | 변환·함축 | 대표 함정(빈출) |
|---|---|---|---|
| **만 / 뿐** | 한정(only) | 'P여야(만) Q'는 P가 Q의 **필요조건** -> Q이면 P | **'P만 Q'를 'P이면 Q'(충분조건)로 뒤집는 정반대 오독** |
| **밖에** | 한정+부정결합 | 'P밖에 없다' = 오직 P뿐 | 부정 결합을 빠뜨려 '다른 것도 있다'로 오독 |
| **도** | 첨가(also) | 'P도 Q'는 다른 것도 Q라는 함축 | **'P도'를 'P만'으로 좁혀 한정으로 뒤집기** |
| **조차 / 마저** | 극단 첨가(even) | 'P조차 Q'면 의외인 P까지 Q -> 나머지는 당연 | 극단 사례를 **전칭으로 키우거나** 첨가를 한정으로 좁힘 |
| **까지** | 척도 끝(up to) | 범위를 P 끝까지 확장 | 끝값만 보고 중간 범위 누락 |
| **은 / 는** | 주제·대조 | 'P는 Q'는 '다른 것은 Q가 아닐 수 있음' 함축 | **대조를 전칭('모두 Q')으로 비약** |
| **마다** | 분배 전칭(각각=모든) | 'P마다 Q' = 모든 P가 각각 Q | **분배 전칭을 특칭('어떤 P는 Q')으로 약화** |
| **(이)나** | 선택/근사 | 'P나 Q' = 둘 중 적어도 하나 | 선택을 둘 다로 키움 |
| **(이)라도** | 양보(even if) | 'P라도 Q' = P여도 Q. 충분조건 아님 | **양보를 충분조건('P이면 Q')으로 격상** |

> [!tip] 양분해 외운다: **만·뿐·밖에·은는 = 한정/대조(뒤집어 읽기)** / **도·조차·마저·까지·마다 = 첨가/전칭(다른 것도 포함)**.

### 1.4 양화 — 모든·어떤·대부분·없음

> [!note] 집합 그림은 필요 없다. 아래 네 문장만 정확히 구분한다.

| 표현 | 시험장 번역 | 함정 |
|---|---|---|
| **모든 P는 Q** | P인 것은 빠짐없이 Q | P가 실제로 존재한다는 말은 아닐 수 있음 |
| **어떤 P는 Q** | P이면서 Q인 사례가 **적어도 하나** | '대부분'이라는 뜻이 아님 |
| **어떤 P도 Q가 아니다** | P이면서 Q인 사례가 없음(전부 부정) | '일부는 아니다'와 다름 |
| **모든 P가 Q인 것은 아니다** | P인데 Q 아닌 사례가 **적어도 하나**(일부 부정) | **'어떤 P도 Q가 아니다'(전부 부정)로 바꾸면 오답** |
| **대부분 P는 Q** | 절반 초과·높은 비율 | 정확한 수치 없으면 수리화 금지 |
| **적어도 n개 / 많아야 n개** | n개 이상 / n개 이하 | '정확히 n개' 아님 |
| **일부** | 하나 이상 | '소수'라는 뜻 아님 |

> [!warning] 분배 범위 함정 (빈출)
> '모든 학생이 책 한 권을 읽었다'는 두 가지로 갈린다.
> - **학생마다 다른 책**일 수 있다: 각 학생에게 책이 하나씩.
> - **같은 책 한 권**일 수 있다: 어떤 책 하나를 모든 학생이.
>
> 선지에 '동일한'·'각각'·'서로 다른'·'공통으로'·'적어도 하나의 같은'이 붙으면 이 차이를 묻는 것이다. **'모든 P가 어떤 Q를 가진다'를 '어떤 Q를 모든 P가 가진다'로 양화사 순서를 바꾸면 대개 오답**('모든 위원이 어떤 안건에 찬성' -> '어떤 안건은 모든 위원의 찬성을 받았다'는 비약).

#### 양화 추론 판정표

| 주어진 추론 | 판정 |
|---|---|
| **모든 P는 Q, 어떤 R은 P -> 어떤 R은 Q** | 가능 |
| **모든 P는 Q, 어떤 Q는 R -> 어떤 P는 R** | 안 됨 |
| **어떤 P는 Q, 모든 Q는 R -> 어떤 P는 R** | 가능 |
| **어떤 P도 Q 아님, 모든 R은 P -> 어떤 R도 Q 아님** | 가능 |
| **모든 P가 Q인 것은 아니다 -> 어떤 P는 Q가 아니다** | 가능(동치) |

### 1.5 논증구조 — 주장·근거·숨은전제

> [!tip] 논증평가는 지문 암기가 아니라 **세 요소 분리**다
> - **주장(결론)**: 글쓴이가 최종적으로 받아들이라고 미는 말.
> - **근거(전제)**: 주장을 받치려고 제시한 말.
> - **숨은전제(다리)**: 근거에서 주장으로 넘어가는, 말로 안 드러난 연결고리.

> [!warning] 강화·약화·가정·오류 문항의 정답은 대부분 **'다리'를 건드린다.** 근거를 그대로 반복하는 선지는 매력적이지만 약하다 — 정답은 근거와 주장 사이의 빈칸을 메우거나 끊는다.

| 결론 표지어 | 근거 표지어 |
|---|---|
| **따라서 / 그러므로 / 결국 / 이로부터** | 왜냐하면 / 그 이유는 / 실제로 |
| **그래서 / 해야 한다 / 타당하다** | 조사 결과 / 연구에 의하면 |
| **인정된다 / 볼 수 있다 / 가장 합리적이다** | P라는 점에서 / Q이기 때문이다 |

> [!check] 숨은전제 찾는 질문
> - 근거가 참이어도 결론이 거짓일 수 있는 경우는 무엇인가?
> - 결론이 나오려면 어떤 **범위 제한**이 필요한가?
> - 비교 대상이 정말 같은가? 표본이 전체를 대표하는가?
> - 원인으로 지목한 것 말고 **다른 원인**이 가능한가?
> - 규범 판단을 하려면 어떤 **가치 기준**이 전제되어야 하는가?

#### 필요전제 대 충분전제

| 구분 | 판정법 | 특징 |
|---|---|---|
| **필요전제(필요가정)** | 선지를 **부정**했을 때 논증이 무너지면 정답 | 결론을 증명하지 않아도 됨. '없으면 안 되는 최소 조건'. **너무 강한 선지는 대개 오답** |
| **충분전제(충분가정)** | 선지를 넣으면 결론이 **반드시 따라오면** 정답 | 강해도 됨. 결론을 보장하면 됨. 범위·단정이 넓은 경우 많음 |

### 1.6 대표 오류 — 이름보다 기능

> [!warning] 오류 문항은 오류명 암기가 아니다. **선지가 지적한 결함이 실제 논증의 약점과 일치하는지**만 본다. 지문이 실제로 저지르지 않은 오류를 지적한 선지는 오답이다.

#### 조건 오류

| 오류 | 형태 |
|---|---|
| **후건긍정(역 오류)** | 'P이면 Q'와 'Q'에서 'P'를 결론 |
| **전건부정(이 오류)** | 'P이면 Q'와 'P 아님'에서 'Q 아님'을 결론 |
| **필요-충분 혼동** | 'Q가 필요하다'를 'Q만 있으면 충분하다'로 바꿈 |

> [!note] 인과 오류
> - 시간상 먼저 일어났다는 이유만으로 원인이라고 본다.
> - **상관관계를 인과관계로 본다.**
> - 대안 원인을 배제하지 않는다.
> - 역인과(결과가 원인을 만들었을 가능성)를 무시한다.
> - 공통원인(둘 다 제3의 원인 X의 결과일 가능성)을 무시한다.

> [!note] 통계 오류
> - 표본이 대표적이지 않다 / 표본 수가 너무 작다.
> - 생존자만 조사했다 / 자기보고에 의존했다.
> - **비율과 총량을 혼동한다.** ('합격률 상승 -> 합격자 수 증가'는 분모가 줄었을 수 있어 비약)
> - 평균만 보고 분산을 무시한다 / 기준 시점이 달라졌다.

> [!note] 언어·개념 오류
> - 같은 단어를 앞뒤에서 **다른 뜻으로** 쓴다(의미 이동).
> - 부분의 성질을 전체로(결합), 전체의 성질을 부분으로(분해) 옮긴다.
> - **규범 판단을 사실 판단으로** 바꾼다('해야 한다' -> '실제로 한다').
> - **가능성을 필연으로** 바꾼다('일 수 있다' -> '반드시 그렇다').
> - 주장자의 믿음을 사실로 바꾼다('A가 P라고 주장' -> 'P이다').

> [!tip] LEET의 '개념 구분' 문항은 용어 정의 문제가 아니라 **동일어의 의미 이동** 문제다. 선지 단어가 본문 단어와 같아도 쓰인 층위가 다르면 오답이다.

> [!example] 규칙·예외 적용 — 2025 Q4 (정답 ③)
> [규칙] (1) 내란죄·살인죄 -> 사형, 배우자 유배. (3) 사형수는 사면되면 유배, 배우자 자원 시 함께. **다만, 내란죄 죄인의 배우자는 자원하지 않더라도 함께 유배.**
> [선지 ①] "갑(내란죄)의 배우자는 자원하지 않으면 함께 유배되지 않는다."
> [논리] **'다만' 예외를 빠뜨린 함정.** 내란죄는 예외 조항이 자원 여부와 무관하게 함께 유배시키므로 선지 ①은 틀림. 규칙형은 **본칙보다 '다만·단서'를 먼저** 읽는다.
> [정답 ③]: ① 거짓(내란죄 예외로 자원 없이도 유배), ② 거짓(살인죄 배우자는 자원해야 함께), ③ 참(병=유배형 사면+이송 중이라 배우자도 석방), ④·⑤ 거짓(도망 죄인엔 사면 효력 없음 / 사망 확인 시 자원 배우자 석방).

## 2. 양상논리학

> [!tip] 시험장 코어
> - 양상 = 명제 P에 얹힌 **강도**(반드시 / 가능 / 안다 / 해야 / 할 수 있다). 참·거짓이 아니라 강도를 본다.
> - **5종만 구분**: 진리(필연·가능) · 인식(앎·믿음) · 당위(의무·허용·금지) · 능력.
> - **제1원칙(1순위 빈출): 양상이 한 칸 옮겨가면 오답** — 가능->사실, 당위->사실, 능력·허용->의무. 지문에 근거가 명시될 때만 전환 허용.
> - **제2원칙: 표지 하나 = 양상 하나로 고정 금지** — '할 수 있다'·'-어야 한다'는 문맥마다 갈린다.
> - 형식(가능세계, 공리 K/D/T)은 시험장에서 안 쓴다. 직관만 챙긴다 — 필연 = 모든 경우, 가능 = 한 경우라도.

### 2.1 양상 5종 — 무엇에 상대화되나
| 양상 | 묻는 것 | 강한 쪽 | 약한 쪽 | 대표 함정 |
|---|---|---|---|---|
| **진리** | 논리·물리적 필연·가능 | 모든 경우 참(반드시) | 한 경우라도 참 | '이다'를 '해야 한다'로 |
| **인식** | 지식·증거에 비추어 | 안다 = 사실 함축 | 믿는다·주장한다 = 사실 아님 | 주장을 입증·사실로 |
| **당위** | 규범상 의무·허용·금지 | 의무·금지 | 허용 | 의무를 사실로 / 허용을 의무로 |
| **능력** | 주체가 실제 할 힘 | — | 능력 = 실현할 힘 | 능력을 의무로 / 가능과 혼동 |

> [!warning] 공통 함정 — 누구의 양상인지부터 박아라
> **안다 -> P를 사실로 둬도 됨. 믿는다·주장한다·여긴다·간주한다 -> P를 사실로 두면 오답.** 학설 지문은 'A·B·C 중 누구 입장인가'를 패러프레이즈로 흔든다. '복권 당첨 가능성'은 있어도 '당첨할 능력'은 아니다(가능과 능력 분리).

### 2.2 한국어 표지어 — 양상은 표지로 잡는다
| 양상 | 한국어 표지 | 시험장 처리 |
|---|---|---|
| **필연** | 반드시, 필연적으로, 불가피하다, 일 수밖에 없다, 예외 없이, 항상 | 근거 없으면 **과강도 선지**. '대체로'와 혼동 금지 |
| **가능** | 할 수 있다, 가능하다, 일 수도, 개연성, 배제할 수 없다 | 가능은 사실도 필연도 아니다. '배제할 수 없다'는 **약화 신호**일 수 있음 |
| **인식-지식** | 알다, 밝혀지다, 입증·확인·관찰되다 | P를 참으로 둠. 반박은 **증거 신뢰성** 공격 |
| **인식-믿음** | 생각·여기다·간주·주장·추정·가정 | **주장자 입장으로만**. P로 비약 금지 |
| **당위** | -어야 한다, 의무, 허용, 금지, 위법 | 의무는 실제 이행이 아니고, 허용은 의무가 아니다 |
| **능력** | 할 수 있다, 역량, 기술적으로 가능, 실현할 수 있다 | 능력은 실제 실현도 법적 허용도 아니다 |

### 2.3 보조사가 양상에 붙으면 강도가 바뀐다 (빈출 함정)
| 결합형 | 실제 의미 | 시험장 처리 |
|---|---|---|
| **해야'만' 한다** | 당위 + 한정 | **필요조건**. 'P해야만 Q'는 P가 Q의 필요조건 — 충분조건('P이면 Q')으로 **오독 금지** |
| **할 수'도' 있다** | 가능 + 첨가 | 가능성을 **추가 제기**할 뿐 확정 아님. 'A도 가능'을 'A만 가능'으로 뒤집기 금지 |
| **할 수'밖에' 없다** | 한정(밖에+부정) | 다른 가능성 배제 = **사실상 필연**. 가능으로 약하게 읽으면 오독 |
| **-라도 (P라도 Q)** | 양보 | **충분조건 아님**. 'P라도 Q'는 'P이면 Q'가 아니다 |
| **-어야 한다고 본다** | 당위 + 믿음 | 화자가 '의무라고 믿는' 것일 뿐. **이중으로 약한 강도** |

### 2.4 양상 전환 오답표 — 이 표가 핵심 (직결 빈출)
선지가 지문의 양상을 한 칸 옮기면 거의 오답이다. **옮긴 방향만 보고 즉시 친다.**

| 지문 양상 | 오답 선지 | 전환 방향 |
|---|---|---|
| **A일 가능성이 있다** | A이다 | **가능 -> 사실** |
| **A여야 한다** | A이다 | **당위 -> 사실** |
| **A가 P라고 주장한다** | P이다 | 주장 -> 사실 |
| **A가 P를 안다** | P가 아닐 수 있다 | 지식의 사실성 무시 |
| **A할 수 있다** | A해야 한다 | **능력 -> 의무** |
| **A해도 된다** | A해야 한다 | **허용 -> 의무** |
| **A일 수 있다** | A이다 | 가능 -> 필연(강도 키우기) |

> [!note] 전환 허용 단서 / OIC·흄의 법칙
> 다음이 지문에 **명시**되면 전환 허용: ① 이상화 전제('규범 준수는 항상 보장') ② 사실성 표현('입증·확인·알다') ③ 가능 종류 고정('법적·물리적으로 가능') ④ 모형화 선언('이론적으로 정의·환원').
> **흄의 법칙**(사실->당위 금지)과 **T 붕괴**(당위->사실 금지)는 방향만 반대, 결론은 같다 — **사실과 당위 사이를 근거 없이 건너뛴 선지는 친다.** OIC('해야 함은 할 수 있음')도 당연한 공리가 아니라서 '의무가 있으니 능력도 있다'를 전제하는 선지는 의심.

(보충: '-겠-' = 의지 또는 추측 / '-(으)ㄹ 수 있다' = 인식적 가능 또는 능력. 주어·맥락으로 가른다.)

## 3. 과학철학 — 귀납·확증·반증·인과

> [!tip] 시험장 코어
> 과학 지문은 지식이 아니라 **검증 구조**를 묻는다 — 선지가 무엇을 하는지만 본다.
> - 강화 신호: 가설이 예측한 게 실제로 나옴 / 경쟁가설(다른 설명)이 줄어듦 / 가설일 때만 잘 나오는 증거.
> - 약화 신호: 예측 실패(보조조건 정상일 때) / 다른 설명이 가능·우세 / 음성 결과가 가짜 음성.
> - 귀납 결론은 항상 **반례·표본**으로 약화 가능. 보편명제는 **반례 한 건이면 거짓**.
> - 상관은 인과가 아니다 — **대체원인·역인과·공통원인·대조실패·측정결함** 5종을 먼저 떠올린다.
> - 형식 이론(베이즈 수식·반증 공리)은 시험장에서 안 씀. 직관 3개(사전·우도·사후)만.

| 개념 | 한 줄 핵심 | 출제 축(강화/약화) |
|---|---|---|
| **귀납 대 연역** | 연역은 전제 참이면 결론 보장, 귀납은 사례->일반이라 보장 없음 | 귀납은 항상 **반례·표본**으로 약화 가능 |
| **확증(증거->가설)** | 증거가 가설을 더 믿게 하면 확증, 덜 믿게 하면 반확증 | 가설이 예측한 관찰이 실제 나오면 강화 |
| **반증(포퍼)** | 보편명제는 입증 불가, **반례 한 건이면 무너진다** | '못 찾았다'를 '없다'로 만들려면 탐지능력이 핵심 |
| **패러다임(쿤)** | 정상과학은 변칙을 누적하다 위기에서 전환 | 변칙 한 건만으론 폐기 안 됨, 대안 패러다임 필요 |
| **베이즈 직관** | 사전 그럴듯함 + 증거의 우도 = 사후 그럴듯함 | 가설일 때만 잘 나오는 증거일수록 강한 강화 |
| **인과추론** | 상관은 인과가 아니다 | **대체원인·역인과·공통원인·대조실패·측정결함** 5종 |
| **최선의 설명(귀추)** | 여러 가설 중 가장 잘 설명하는 것 채택 | 경쟁가설 제거가 강화, 더 나은 경쟁가설이 약화 |
| **미결정성** | 같은 증거를 여러 이론이 똑같이 설명 가능 | 증거만으론 결론 못 가른다 |

---

### 3.1 귀납 대 연역

연역은 전제가 참이면 결론이 반드시 참(타당성 문제), 귀납은 사례에서 안 본 경우로 넘어가 결론이 보장되지 않음(지지 정도 문제).

| 구분 | 연역 | 귀납 |
|---|---|---|
| **보장** | 전제 참이면 결론 참 | 결론은 그럴듯할 뿐 |
| **약화 방식** | 전제 거짓 또는 형식 오류 | 반례, 표본 편향, 표본 부족 |
| **시험 표지** | '반드시', '필연적으로' | '대체로', '관찰된 바로는', '경향이 있다' |

> [!warning] 과강도 함정
> 지문의 귀납 결론('대체로 A는 B')을 선지가 **'반드시·모든 A는 B'(전칭·필연)**로 키우면 과강도 오답. 귀납 결론은 반례 하나로 정도만 줄지만, 연역 결론은 **반례 한 건이면 타당성 자체가 깨진다**.

### 3.2 가설검증과 확증

확증은 "증거 E가 가설 H를 얼마나 지지하는가". 구조는 H(가설)->P(예측)->E(관찰)이며, 보조조건 A(장비·표본)와 경쟁가설 R을 함께 점검한다.

| 선지 기능 | 강화/약화 | 이유 |
|---|---|---|
| **H가 예측한 새 관찰이 실제로 나왔다** | 강화 | 예측 성공 |
| **H가 틀렸다면 나오기 어려운 결과가 나왔다** | **강한 강화** | 위험한 예측 성공(가설일 때만 잘 나오는 증거) |
| **경쟁가설 R이 같은 현상을 설명 못 한다** | 강화 | H의 상대적 설명력 증가 |
| **H가 예측한 결과가 나오지 않았다** | 약화 | 보조조건이 정상이면 특히 강함 |
| **H가 결과 뒤에 사후적으로 끼워 맞춰졌다** | **약화** | 예측력 없으면 지지 약함 |

> [!warning] 사후 조정 함정
> '예측 성공'은 강화지만 **결과를 보고 나서 가설을 맞춘 것(사후 조정)**은 강화가 아니다. '관찰되었다'는 사실성을 함축하지만 '주장되었다'는 아니다(인식 양상 구별).

### 3.3 반증주의(포퍼)

과학 명제의 자격은 입증가능성이 아니라 **반증가능성**. 어떤 결과로도 반박 안 되는 주장은 과학이 아니다.

| 명제 종류 | 한 사례의 무게 |
|---|---|
| **보편명제(모든 A는 B)** | 확증 백 건도 입증 못 함, **반례 한 건이면 거짓** |
| **존재명제(어떤 A는 B)** | 사례 한 건이면 입증, 반증은 매우 어려움 |

> [!note] 출제 포인트
> - '모든 A는 B' 약화에는 **A인데 B 아닌 사례 한 건**이면 충분 — 그 한 건이 강화 선지보다 무겁다.
> - '없다'를 주장하려면 "**찾을 수 있었는데도 못 찾았다**"가 필요. 탐지능력·측정 민감도·검정력이 강화 포인트. 장비가 둔감하면 음성 결과(못 찾음)의 의미가 사라진다.

> [!warning] 보조가설(뒤엠) 함정 — 매우 중요
> 예측이 빗나가도 곧 주가설 반박은 아니다. 실험장치·측정조건 같은 **보조가설이 틀렸을 수 있기** 때문. 따라서 "예측 실패가 가설을 반증한다"는 선지는 **보조조건이 정상이었다는 정보가 함께 있을 때만** 강한 약화가 된다.

### 3.4 패러다임(쿤)

정상과학은 패러다임 안에서 퍼즐을 풀다가 **변칙(설명 안 되는 현상)**이 쌓이면 위기에 빠지고, **대안 패러다임**이 나타나야 전환된다.

| 단계 | 내용 | 시험 함정 |
|---|---|---|
| **정상과학** | 기존 틀로 퍼즐 풀이 | — |
| **변칙** | 틀로 설명 안 되는 관찰 | 변칙 한 건을 곧 '폐기 사유'로 비약 금지 |
| **위기·전환** | 변칙 누적 + 대안 등장 | **대안 없으면 전환 안 됨**(반증주의와 대비) |

> [!warning] 포퍼 vs 쿤 대비
> "변칙이 관찰되었으므로 이론을 즉시 폐기해야 한다"는 쿤 관점에서 **과강도**. 포퍼식(반례 한 건이 결정적)과 쿤식(변칙이 쌓여도 대안 없으면 유지)을 대비시켜 묻는다. 패러다임 전환은 증거만으로 강제되지 않는다(미결정성과 연결).

### 3.5 베이즈 확증 직관

수식 불필요. 직관 3개만 — 사전 그럴듯함(증거 전 가설 신뢰도), **우도(가설이 참일 때 그 증거가 나올 확률, likely-hood)**, 사후 그럴듯함(증거 후 신뢰도).

> [!note] 핵심 직관
> 강하게 강화하는 증거 = **'가설이 참일 때는 잘 나오지만, 거짓이면 잘 안 나오는 증거'**. 아무 가설에서나 똑같이 나오는 증거는 가설을 거의 구별 못 하므로 강화가 약하다(미결정성·무관 선지와 연결).

> [!warning] 우도 함정
> "그 증거는 경쟁가설에서도 똑같이 기대된다"는 선지는 **강화를 무력화**(양쪽 우도 동일). 반대로 "그 증거는 H가 아니면 나오기 매우 어렵다"는 **강한 강화**.

### 3.6 인과추론

**상관은 인과가 아니다.** 'A 때문에 B'를 주장하면 아래 다섯 공격을 먼저 떠올린다.

| 인과 결론 공략 5법  | 약화하는 정보                        |
| ------------ | ------------------------------ |
| **대체원인**     | B는 A가 아니라 다른 C 때문일 수 있다        |
| **역인과**      | A가 B를 만든 게 아니라 B가 A를 만들었을 수 있다 |
| **공통원인(교란)** | A와 B가 서로 원인·결과가 아니라 둘 다 X의 결과다 |
| **대조 실패**    | A가 없는 비교집단과 비교하지 않았다           |
| **측정 결함**    | B가 실제로 변한 게 아니라 측정 방식만 바뀌었다    |

| 강화하는 정보 | 이유 |
|---|---|
| **A가 없는 비교집단에서는 B가 안 나타났다** | 대조군 보강 |
| **A를 인위적으로 조작하자 B가 변했다** | 개입 증거 |
| **A가 증가할수록 B도 일정하게 증가했다** | 용량-반응 |
| **A가 먼저 변하고 그 뒤 B가 변했다** | 시간 선후 |
| **B를 만드는 다른 원인이 통제되었다** | 경쟁가설 제거 |
| **A가 B를 일으키는 중간 기제가 확인되었다** | 메커니즘 제시 |

> [!warning] 인과 단정 함정
> '함께 나타남(상관)'만으로 인과를 단정하는 것이 전형적 오류. **시간상 먼저라는 이유만으로 원인이라 보는 것**도 오류(공통원인 가능).

### 3.7 최선의 설명 추론(귀추)

관찰 현상을 여러 가설이 설명할 수 있을 때 **가장 잘 설명하는 것**을 잠정 채택. 결론은 보장이 아니라 잠정적. 좋은 설명일수록 현상을 직접 설명하고, 비슷한 현상도 함께 설명하며, **경쟁가설보다 예외가 적고**, 예상된 새 관찰이 실제로 나온다.

| 선지 기능 | 강화/약화 |
|---|---|
| **경쟁가설이 설명 못 하는 현상을 이 가설이 설명한다** | 강화 |
| **가설의 작동 기제가 발견되었다** | 강화 |
| **더 적은 가정으로 같은 현상을 설명하는 경쟁가설이 있다** | **약화** |
| **가설이 적용 안 되는 곳에서도 같은 현상이 나타났다** | 약화(독점적 설명력 깨짐) |

> [!warning] 과강도·누락 함정
> 귀추 결론은 '유일하게 옳다'가 아니라 '현재 가장 낫다'. 선지가 '이 가설이 참임이 증명되었다'로 키우면 과강도. **경쟁가설을 빠뜨리고 결론낸 논증**은 약점이 크다.

### 3.8 미결정성

같은 증거를 **서로 다른 이론이 똑같이 잘 설명**할 수 있어, 증거만으로는 어느 이론이 옳은지 결정되지 않는다.

> [!note] 출제 연결
> - 귀추의 약점: 경쟁가설이 같은 증거를 똑같이 설명하면 그 증거는 가설을 **구별하지 못한다**(베이즈로 양쪽 우도 동일).
> - 강화·약화 판정: "그 관찰은 두 이론 모두에서 똑같이 기대된다"는 **무관 또는 강화 무력화** 선지의 전형.
> - 약화 도구: 다른 설명이 '가능하다'를 넘어 **그 설명이 더 낫거나 같다**를 보여야 결정력이 생긴다.

### 3.9 과학철학 표지어·양상 함정 통합표

과학 지문은 양상·보조사의 강도를 미세하게 바꿔 오답을 만든다.

| 지문 표현 | 오답 선지 변형 | 왜 틀리는가 |
|---|---|---|
| **A일 가능성이 있다** | A이다 | 가능을 사실로 바꿈 |
| **A일 수 있다(조건부)** | 항상 A이다 | 조건을 빼고 단정 |
| **대체로 A는 B** | 반드시 A는 B / 모든 A는 B | 귀납 경향을 전칭·필연으로 강화 |
| **A가 P라고 주장한다** | P가 사실이다 | 주장을 사실로(인식 간극) |
| **P가 확인·입증되었다** | (반박하려면) 증거 신뢰성 공격 필요 | 사실성 함축이라 단순 부정 불가 |
| **A가 B와 함께 나타났다** | A가 B의 원인이다 | 상관을 인과로 |
| **A가 B보다 먼저다** | A가 B의 원인이다 | 선후를 인과로(공통원인 가능) |
| **변칙이 관찰됨** | 이론을 즉시 폐기해야 한다 | 쿤: 대안 없으면 전환 안 됨 |
| **측정에서 검출 안 됨** | 대상이 존재하지 않는다 | 장비 민감도 확인 필요('못 찾음'은 '없음'이 아님) |

#### 보조사 함정(과학 지문 빈출)

| 보조사 | 논리 기능 | 과학 지문 함정 |
|---|---|---|
| **만 / 뿐 / 밖에** | 한정(오직) | 'A 조건에서만 B'는 A가 B의 **필요조건**, 'A이면 B'(충분)로 뒤집지 말 것 |
| **도** | 첨가(또한) | '대조군에서도 B'는 A 없이도 B 가능 -> 인과 **약화**, 이를 'A만'으로 좁히지 말 것 |
| **조차 / 마저** | 극단 첨가 | '가장 민감한 장비로조차 검출 안 됨'이면 나머지는 당연히 검출 못 함 -> 음성 결과 강화 |
| **까지** | 척도 끝 | '먼 거리까지 검출한 적 있다'는 탐지 범위를 끝까지 확장 -> '못 찾음=없음' 강화 |
| **은 / 는** | 주제·대조 | '이 조건에서는 B다'는 다른 조건은 다를 수 있음 함축, 전칭으로 비약 금지 |
| **마다** | 분배 전칭(모든) | '실험마다 같은 결과'는 모든 시행 -> 재현성 강화, 특칭으로 약화 오독 금지 |
| **(이)나** | 선택·근사 | 'A나 C가 원인'은 원인 후보가 둘, 하나로 단정 금지 |
| **라도** | 양보(even if) | 'A라도 B'는 A가 충분조건이 아님, 'A이면 B'로 강화 금지 |

## 4. 강화·약화 통일 판정법

> [!tip] 시험장 코어
> - **타깃 T 고정**: 무엇을 강화/약화하는지부터 한 문장으로 적는다. T가 흔들리면 다 틀린다.
> - T 유형 분류: 인과·실험·일반화·조건·유비·설명가설·규범·통계 중 하나 (아래 '먼저 찾을 것' 표).
> - E와 T의 관계: 반례·대안설명을 줄이면 강화 / 만들면 약화 / T 아닌 주변만 건드리면 무관.
> - 강화는 '증명'까지, 약화는 '완전 반박'까지 갈 필요 없다. 시험은 **'믿을 정도의 변화'**만 묻는다.
> - 무관 판정 한 줄: '이 선지가 참이어도 결론의 원인·결과·조건·범위가 그대로인가?' -> 그대로면 무관.

> [!warning] 최빈 함정
> 같은 주제·같은 방향이라 정답처럼 보이지만, **T의 비교축·인과고리를 안 건드리는 무관 선지**.

### 4.1 무엇을 강화·약화하는가 — 타깃 T부터 고정

> [!note] 순서
> 선지를 보기 전에 T를 한 문장으로 쓰고, 그 T가 어느 유형인지부터 정한다. 유형이 정해지면 강화/약화 포인트가 자동으로 좁혀진다.

**결론유형별 먼저 찾을 것**

| T의 유형 | 강화하는 E | 약화하는 E |
|---|---|---|
| **인과 (A 때문에 B)** | A 변화 뒤 B 변화, 대조군 비교, 무작위화, 용량-반응, 기제 제시 | 역인과, 공통원인, 표본편향, 측정오류 |
| **실험·과학가설 (H가 현상 설명)** | H의 새 예측 성공, 경쟁가설 제거, 측정 민감도 확인 | 경쟁가설이 더 잘 설명, 예측 실패, 표본·측정 결함 |
| **일반화 (모든·대부분 A는 B)** | 대표성 있는 표본, 여러 시기·지역에서 반복 | A인데 B 아닌 반례, 표본 편향·과소 |
| **조건 (A이면 B)** | A인 사례가 B임, A인데 B 아닌 경우 부재, 기제 | A인데 B 아닌 사례 제시 |
| **유비 (사례1이 이러니 사례2도)** | 결론과 관련된 유사성 추가 | 결론과 관련된 차이 추가 |
| **설명가설 (이 가설이 잘 설명)** | 위험한 예측 성공, 경쟁가설이 설명 못함 | 경쟁가설이 같은 현상을 더 잘 설명 |
| **규범 (A해야 한다·정당하다)** | 가치기준 명시, 사례가 적용 대상임, 우선순위 제시 | 적용요건 불충족, 예외조항, 더 우선하는 규범 충돌 |
| **통계 (자료로 결론)** | 표본 대표성·충분한 크기·비교가능성 | 표본 편향, 작은 표본, 다른 모집단 |

> [!note] 발문 처리 순서
> 강화/약화/가정/오류/추론/원리 중 무엇인지 5초 안에 정한 뒤 T 유형을 분류한다. **결론이 여러 문장이어도 답은 보통 하나의 결론·하나의 가설·하나의 규범명제에 걸려 있다.**

> [!example] 약화 — 2025 Q1 (의무복무기간 논쟁)
> [갑의 논거] 장교·부사관의 복무기간이 긴 이유는 **국가 비용으로 장기 훈련**을 거쳐 임용되기 때문이다.
> [보기 ㄱ] "정보기술 발달로 직무역량 강화에 드는 시간·비용이 대폭 절감되었다면 갑의 견해는 약화된다."
> [논리] 결론을 직접 치지 않고 **논거의 전제(장기·고비용 훈련)를 깎으면 약화.** 강화·약화는 결론과 같은 주제인지가 아니라 **전제·대안설명을 건드리는지**로 판정한다.

> [!example] 강화·약화 — 2024 Q1 (불법행위법 견해 A/B) · 정답 ④(ㄴ,ㄷ)
> [견해] A = 불법행위 이전 상태로의 **완전 회복**(정의·윤리 기초). B = 손해 회복 + **예방**(공동체 효용·인센티브).
> [보기] ㄱ 수리비가 교환가치를 초과해도 전액 배상 -> 완전 회복이므로 **A 강화**(보기는 'A 약화'라 거짓). ㄴ 손해 없이 얻은 이득을 배상 -> 억지·예방이라 **B 강화**(참). ㄷ 피해자 용서에도 제3자에 배상(자유토론 보호) -> 피해자 회복 아님(**A 약화**) + 공동체 효용(**B 강화**)(참).
> [논리] 같은 사실이 한 견해는 강화·다른 견해는 약화. **'무엇을 강화/약화하는지' 타깃부터 고정**(4.1).

### 4.2 강화 3종 (이것만 만들면 강화)

| 종류 | 하는 일 | 판별 한 줄 |
|---|---|---|
| **직접강화** | 결론이 예측한 바로 그 결과가 관찰됨 | '예상 현상이 더 잘 나타나는가?' |
| **간접강화** | 결론을 위협하는 대안설명을 제거 | '결론 말고 다른 설명이 줄어드는가?' |
| **구조강화** | 전제와 결론 사이 빈 연결고리를 메움 | '적용조건·숨은 전제가 충족되는가?' |

> [!note] 세부 작동 (7가지 모두 위 3종에 들어감)
> 빈 연결고리 메우기 / 대안설명 제거 / 표본 신뢰도 올리기(크다·무작위·대표성·대조군) / 측정 신뢰도 올리기(정확·무편향·반복일치) / 예측 성공 / 기제 제시 / 범위 일치(지문 대상=선지 대상).

> [!example] 강화(일반화) — 2025 Q16 (상황 대 성격)
> [가설 ㉠] 사람의 행동을 좌우하는 결정 요인은 성격보다 **상황**(빵 냄새)이다.
> [보기 ㄷ] "빵 냄새 대신 '고가 경품 당첨'으로 설정을 바꿔도 도움 비율이 유사하다면 ㉠은 강화된다."
> [논리] **변수(상황 요인)를 바꿔도 결과가 유지 = 일반화 성공 -> 강화.** 특정 자극이 아니라 '상황 요인 일반'이 작동함을 보여 대안설명(성격)을 줄인다.

### 4.3 약화 5종 (이 중 하나면 약화)

| 종류 | 하는 일 | 판별 한 줄 |
|---|---|---|
| **반례** | A인데 B 아닌 사례 | '같은 결과가 깨지는 경우가 있나?' |
| **대체원인** | B는 A 아니라 C 때문일 수 있음 | '결과를 다른 원인으로 설명되나?' |
| **역인과** | A가 B를 낳은 게 아니라 B가 A를 낳음 | '시간 선후가 거꾸로 가능한가?' |
| **표본·측정 공격** | 자료 편향, 측정 둔감 | '비교가 깨지나? 측정이 못 잡았나?' |
| **적용조건 불충족** | 논증 성립에 필요한 조건이 사실은 없음 | '필요한 전제가 사례에 없나?' |

> [!note] 묶음·확장
> 공통원인(A와 B 둘 다 X의 결과)은 대체원인의 한 형태로 같이 묶는다. 규범 T에서 '적용조건 불충족'은 곧 적용요건 미충족·예외조항·상위규범 충돌로 나타난다. **'사실 판단에서 규범 판단으로 비약(가능->당위, 바람직->실재)'도 약화 포인트다.**

### 4.4 무관 선지 전형 (매력적이지만 0점)

| 무관 선지형 | 왜 무관한가 |
|---|---|
| **같은 주제지만 다른 변수만 말함** | T의 원인·결과·조건을 안 건드림 |
| **사례는 있는데 모집단이 다름** | 일반화 대상이 아님 |
| **결과는 같은 방향인데 시간 순서 없음** | 인과를 못 받침 |
| **원인만 말하고 결과 변수 없음 / 결과만 말하고 원인 변수 없음** | 비교축 미충족 |
| **지문은 사실판단인데 가치판단만 함** | 양상 전환 (사실<->규범) |
| **일부 사례만 말하는데 결론은 전칭** | 강화가 너무 약하거나 무관 |
| **평균을 말하는데 결론은 개인 사례 / 그 반대** | 수준이 다름 |
| **과거 자료인데 결론은 제도 변경 이후** | 시점이 다름 |

> [!warning] 무관 선지의 본질
> **'결론과 같은 주제'라는 이유만으로 정답으로 끌리는 것**이 무관 선지의 함정이다. T의 비교축(원인·결과·조건·범위)에 닿는지로 끊는다.

### 4.5 강화·약화 10초표 (빈출 볼드)

> [!tip] 쓰는 법
> 선지를 아래 기능 중 하나로 환산해 즉시 판정한다. 원문 암기가 아니라 **기능** 암기다.

| 선지 기능 | 판정 |
|---|---|
| **A 없는 비교집단에서는 B가 안 나타났다 (대조 성공)** | **강화** |
| **실험군·대조군이 원인 A 외에는 같았다** | 강화 (대체원인 제거) |
| **A가 늘수록 B도 일정하게 늘었다 (용량-반응)** | 강화 |
| **A를 인위적으로 조작하자 B가 변했다 (개입)** | 강화 |
| **독립 연구에서 같은 결과가 반복됐다 (재현성)** | 강화 |
| **가설이 틀렸다면 나오기 어려운 결과가 나왔다 (위험한 예측 성공)** | **강한 강화** |
| **측정장비는 B가 있었다면 검출할 만큼 민감했다** | 강화 (음성 결과 의미 보강) |
| **결론에 필요한 숨은 조건이 실제 충족됐다** | 강화 (간극 보강) |
| **A 없는데도 B가 나타났다** | **약화** (A 필요성) |
| **A 있는데도 B가 안 나타났다** | **약화** (A 충분성) |
| **B가 A보다 먼저 나타났다** | **약화** (역인과) |
| **A와 B 모두 제3요인 C의 결과였다** | **약화** (공통원인) |
| **실험군이 원래 B가 높을 집단이었다** | 약화 (선택편향) |
| **탈락자가 한쪽 집단에 몰렸다** | 약화 (생존자 편향) |
| **측정도구가 B를 정확히 못 잡았다 / 측정 기준이 도중 바뀌었다** | 약화 (측정오류) |
| **표본이 결론의 모집단과 다르다** | **약화** (일반화) |
| **규범 적용 요건이 충족되지 않았다** | 약화 (규범 적용) |
| **지문은 '가능'인데 결론은 '필연'으로 비약** | **약화** (양상 과장) |
| **결과 B와 비슷한 다른 결과 D만 말함 / 같은 주제 도덕평가만 함** | 무관 |

### 4.6 보조사 첨가가 '추가 증거'로 작동할 때

| 선지 표지 | 논리 기능 | 강화/약화 판정 |
|---|---|---|
| **'A도 B'·'A조차 B'·'A마저 B' (첨가·극단첨가)** | A를 포함해 다른 것까지 B라는 함축 -> 사례 범위가 넓어짐 | **일반화 T 강화**(반례 줄고 대표성 늘어남), 단 A가 결론 범위 밖이면 무관 |
| **'A만 B'·'A뿐'·'A밖에' (한정)** | A가 B의 필요조건 | 'A만 B'를 'A이면 B'(충분조건)로 읽으면 **오판** — 강화 강도 과대평가 |
| **'A는 B' (대조)** | 다른 것은 B 아닐 수 있음 함축 | 이를 전칭·한정으로 비약해 강화로 오독하는 함정 |
| **'A마다 B' (분배 전칭)** | 모든 A가 B -> 반례 한 건이면 무너짐 | 특칭으로 약화해 읽으면 약화 선지를 놓침 |

> [!warning] 한 줄 요약
> **'도·조차·마저'가 붙으면 '예상 밖의 것까지 포함'**이라 일반화·인과 결론의 추가 증거(강화)로 작동한다. 반대로 **'만·뿐·밖에'는 한정**이라 범위를 좁히며, 충분조건으로 뒤집어 읽는 것이 대표 함정이다.

## 5. 계산문제 — 수리추리·자료해석

> [!tip] 시험장 코어
> - 계산형은 산수가 아니라 논리다 — **선지를 죽일 만큼만 계산**하고 전부 펼치지 않는다.
> - 1단계 앵커: **총합·분모·단위·불변량** 중 안 변하는 것부터 고정한다.
> - 2단계 방향: 극값은 방향부터 — **최대=큰 값 구조 고정 / 최소=작은 값 구조 고정**.
> - 3단계 분기: 경우가 둘이면 두 템플릿, 셋 이상이면 강한 조건부터.
> - 4단계 컷: 정확계산 전에 대소부터 — **'두 배 이상'은 상한·하한으로 먼저 거른다**.

| 단계 | 행동 | 한 줄 |
|---|---|---|
| **1. 앵커** | 고정된 수치부터 잡는다 | **총합·분모·단위·불변량** 중 안 변하는 것 |
| **2. 방향** | 극값은 방향부터 정한다 | **최대=큰 값 구조 고정 / 최소=작은 값 구조 고정** |
| **3. 분기** | 갈림은 둘로만 쪼갠다 | 경우가 둘이면 템플릿, 셋 이상이면 강한 조건부터 |
| **4. 컷** | 정확계산 전에 대소부터 | **'두 배 이상'은 상한·하한으로 먼저 거른다** |

> [!warning] 3대 함정축
> - 비율: **분모**가 바뀌었는가.
> - 평균: **총합과 개수**를 같이 봤는가.
> - 기준: **시점·모집단**이 같은가.

---

### 5.1 계산형 표준 절차 — 앵커 먼저

> [!note] 첫 동작은 계산이 아니라 앵커 잡기
> 변하지 않는 양을 먼저 고정하면 경우의 수가 준다. 순서: **①앵커 확정 -> ②극값이면 방향(최대/최소) 결정 -> ③분기 기준으로 경우 나눔 -> ④물어본 선지를 죽일 만큼만 계산**.

| 앵커 종류 | 무엇을 고정하나 | 시험장 행동 |
|---|---|---|
| **총합** | 전체가 일정하면 합이 불변 | 한쪽이 늘면 다른 쪽은 그만큼 준다 |
| **비율의 분모** | 분모가 무엇인지부터 확정 | **분모를 못 잡으면 비율 선지를 판단하지 않는다** |
| **단위** | %인지 명수인지 금액인지 | 단위가 다른 두 값을 직접 비교하지 않는다 |
| **불변량** | 어떤 조작에도 안 변하는 양 | 보존되는 양을 등식으로 쓴다 |
| **등호 조건** | 등호가 성립하는 경계 | '이상·이하'에서 경계값을 따로 본다 |
| **분기 기준** | 경우를 가르는 단 하나의 축 | 둘로만 갈리면 두 템플릿을 만든다 |

---

### 5.2 극값 만들기 — 최소·최대

> [!tip] 최소·최대는 계산보다 경계와 방향
> - **최대 얼마인가 -> 큰 값을 만드는 구조부터 고정**.
> - **최소 얼마인가 -> 작은 값을 만드는 구조부터 고정**.
> - 최소형은 가장 적게 써도 충족되는 구성, 최대형은 가장 많이 넣어도 충돌 없는 구성을 찾는다.

| 표지어 | 논리 기능 | 극값에 주는 효과 |
|---|---|---|
| **적어도 n** | n개 이상(아래쪽 차단) | **최소값을 올린다** |
| **많아야 n** | n개 이하(위쪽 차단) | **최대값을 낮춘다** |
| **최소 n / 최대 n** | n 이상 / n 이하 | 적어도·많아야와 동일 |
| **정확히 n** | n 고정, 위아래 모두 차단 | 경계가 점 하나로 닫힌다 |

> [!warning] 극값 함정
> - **중복 가능 여부를 먼저 확인한다** — 같은 대상을 여러 번 쓸 수 있으면 최대가 크게 벌어진다.
> - '적어도 n개'를 **정확히 n개**로 굳혀 읽으면 최소형에서 답이 어긋난다. '적어도 n'은 n 이상일 뿐이다.

---

### 5.3 비율·평균·가중치 함정

> [!note] 비율·평균은 분모와 개수를 분리해야 풀린다
> 수치가 움직인 이유를 분자·분모 어느 쪽 탓인지 가른다.
> - 평균은 **총합 나누기 개수** — 평균이 올랐다고 모든 값이 오른 건 아니다.
> - 비율이 올랐다고 분자가 증가한 건 아니다 — **분모가 줄었을 수 있다**.
> - 총량이 늘어도 비율은 줄 수 있다. 비율 비교는 **분모가 같은지 먼저** 확인.
> - 가중평균은 항목 수가 많은 쪽으로 끌린다 — 두 집단을 합칠 때 단순평균을 쓰면 틀린다.

| 함정 | 왜 틀리나 | 시험장 대응 |
|---|---|---|
| **비율 증가 -> 분자 증가로 단정** | 분모가 줄어도 비율은 오른다 | **분자와 분모를 분리해서 본다** |
| **평균 상승 -> 모든 값 상승으로 단정** | 한 값만 크게 올라도 평균은 오른다 | 총합과 개수를 같이 확인한다 |
| **총량 증가 -> 비중 증가로 단정** | 다른 항목이 더 늘면 비중은 준다 | 전체 분모의 변화를 본다 |
| **비율끼리 직접 비교** | **분모가 다르면 비교 불가** | 분모가 같은지부터 확인한다 |
| **평균만 보고 판단** | 분산·분포를 무시함 | 평균 같아도 분포는 다를 수 있다 |
| **단순평균과 가중평균 혼동** | 항목별 크기(가중치)가 다름 | 큰 집단 값이 평균을 끌어당긴다 |

> [!example] 대표 오답 문장
> **"합격률이 상승했으므로 합격자 수가 증가했다."** -> 분모(응시자)가 줄었을 수 있어 바로 결론낼 수 없다.

### 5.4 자료해석 표·그래프 읽기

> [!tip] 무엇을 묻는지 먼저 보고 표로 돌아간다
> 읽기 순서: **①발문이 묻는 값을 본다 -> ②그 값이 표의 어느 칸인지 찾는다 -> ③단위·분모·시점 확인 -> ④필요한 칸만 계산.** 표 전체를 다 읽지 않는다.

| 점검 항목 | 확인 질문 |
|---|---|
| **단위** | %인가 명수인가 금액인가. 천 단위·만 단위 |
| **분모** | 비율의 기준 모집단이 무엇인가 |
| **기준 시점** | **언제 대비 언제인가.** 시점이 바뀌면 비교 불가 |
| **모집단 범위** | 같은 지역·집단·대상을 비교하는가 |
| **항목 정의** | '증가율'인가 '증가량'인가. 누적인가 당기인가 |

> [!warning] 자료형 통계 함정
> 표본이 대표적이지 않다 / 표본 수가 작다 / 생존자만 조사했다(탈락자 제외) / 비율과 총량 혼동 / **기준 시점이 달라졌다**.

### 5.5 계산형 선지 패턴 — 함정 사전

> [!note] 발문 유형마다 처리법이 고정돼 있다
> 패턴을 알면 계산 없이도 절반은 걸러진다.

| 선지형 | 처리 |
|---|---|
| **최대 얼마인가** | 큰 값을 만드는 구조부터 고정 |
| **최소 얼마인가** | 작은 값을 만드는 구조부터 고정 |
| **항상 참인가** | **반례 하나** 찾기 |
| **가능한가** | **사례 하나** 만들기 |
| **평균이 증가했다** | 총합과 개수를 같이 확인 |
| **비율이 증가했다** | **분자와 분모를 분리** |
| **두 배 이상이다** | **정확계산 전 상한·하한으로 컷** |
| **순위가 올랐다** | **값 증가와 순위 증가를 구별** |
| **전체는 감소, 비중은 증가** | **분모 감소 여부 확인** |
| **A가 B보다 크다** | **정확값보다 대소관계 먼저** |

> [!warning] 5대 바꿔치기 함정 (빈출 — 선지가 슬쩍 기준을 바꾼다)

| 바꿔치기 | 정체 | 적발법 |
|---|---|---|
| **분모 바꿔치기** | 비율의 기준 모집단을 다른 것으로 교체 | 분모가 같은지 확인 |
| **기준 시점 바꿔치기** | 비교 시점을 슬쩍 옮김 | 언제 대비 언제인지 확인 |
| **수치 역전** | 값 증가를 순위 증가로(또는 반대) 둔갑 | 값과 순위를 분리 |
| **평균<->개인 혼동** | 집단 평균을 개인 사례로(또는 반대) 적용 | '수준이 다르다'로 컷 |
| **비율<->총량 혼동** | 비율 변화를 총량 변화로 단정 | 분자·분모·총합을 분리 |

> [!check] 마무리 점검 3줄
> - **최소·최대는 경계값부터** 잡았는가.
> - **비율은 분모부터** 확인했는가.
> - 순위·시점·모집단을 선지가 바꿔치기하지 않았는가.

## 6. 논리게임(그루핑·배치·순서)

> [!tip] 시험장 코어
> - 유형부터 판별: 순서·배열 / 그룹·짝짓기 / 배치(속성). 유형이 축을 정한다.
> - **가장 고정된 정보**를 축으로 박는다. 순서가 있으면 순서를 가로축.
> - 조건은 확정 / 금지(부정) / 연결(블록·조건문) / 분기로 갈라 적는다.
> - 처리는 **확정 -> 연쇄(블록·앵커) -> 마지막에 경우분기**. 강한 규칙부터.
> - 모든 경우를 펼치지 않는다 — **물어본 선지를 죽일 만큼만** 경우를 만든다.
> - 양상 판정: **반드시 참**=모든 표에서 성립 / **가능**=표 하나면 끝 / **불가능**=어느 표에도 모순.

| 단계 | 행동 | 한 줄 요령 |
|---|---|---|
| **1** | 유형 판별 | 순서·배열 / 그룹·짝짓기 / 배치(속성) 중 무엇인지 먼저 정한다 |
| **2** | 축 잡기 | 가장 고정된 정보를 행·열로. 순서가 있으면 순서를 가로축 |
| **3** | 조건 분류 | 확정 / 금지(부정) / 연결(블록·조건문) / 분기로 갈라 적는다 |
| **4** | 처리 순서 | 확정 먼저 -> 연쇄(블록·앵커) -> 마지막에 경우분기 |
| **5** | 선지 검증 | 물어본 선지를 죽일 만큼만 경우를 만든다 |

> [!note] 표는 한 번만
> 선지마다 새 표를 그리지 않는다. 확정 템플릿에서 **가능성만 지운다**.

---

### 6.1 먼저 유형을 정한다

축을 잘못 잡으면 표가 꼬여 시간이 사라진다. 표를 그리기 전 유형을 박는다.

| 유형 | 내용 | 대표 축 |
|---|---|---|
| **순서·배열형** | 자리, 순위, 시간표, 줄서기 | 순서(위치)를 가로축 |
| **그룹·짝짓기형** | 1대1·1대다 대응, 같은 조·팀으로 분류 | 고정 집합을 세로축, 대응 대상을 가로축 |
| **배치·속성형** | 개체에 색·직업·지역·점수 속성을 붙임 | 개체를 세로축, 속성을 칸 안에 |

> [!note]
> 진실·거짓형(발화자 일부만 참)과 최소·최대·비율형은 계산형에 가깝다. 표 작성 원리는 공유하되 양상 판정과 분기 처리에 집중한다.

### 6.2 표 잡는 법 (축 선택)

> [!warning] 1순위 실점 원인
> 기준축을 잘못 잡는 것. 머리로 굴리지 말고 가장 고정된 정보를 먼저 축으로 박는다.

- 순서가 있으면 **순서를 가로축**으로 둔다.
- 개체(사람·대상)가 고정되어 있으면 **개체를 세로축**으로 둔다.
- 장소·시간·물건 중 하나가 1대1 대응이면 그것을 중심축으로 둔다.
- 범주가 셋 이상이면 두 축만 먼저 잡고 나머지는 칸 안에 적는다.
- '서로 다르다 / 같다 / 인접 / 앞 / 뒤 / 바로 전 / 적어도 / 많아야'는 별도로 표시한다.

> [!example]
> 개체 a,b,c를 자리 1,2,3에 앉히는 순서형이면 가로축=자리(1,2,3), 각 자리 칸에 개체를 적는다(세로축 없음). 그룹 A,B에 나누는 묶기형이면 세로축=그룹(A,B), 각 칸에 소속 개체를 적는다.

### 6.3 조건 처리 순서 (확정 먼저 -> 연쇄 -> 경우분기)

LEET·PSAT 대부분 선지 검증형이다. **모든 경우를 펼치지 않고** 물어본 선지를 죽일 만큼만 경우를 만든다.

| 순서 | 처리할 조건 | 설명 |
|---|---|---|
| **1** | **확정조건** | 'a는 1번'처럼 위치·소속이 즉시 박힘. 가장 먼저 고정 |
| **2** | 금지조건(부정) | 'a는 2번이 아니다', 'a와 b는 같은 조 아님'. 칸에 X |
| **3** | 연결조건(블록·조건문) | 'a와 b는 붙는다', 'a면 b도'. 강한 연결부터 묶음 |
| **4** | **분기조건** | 둘로만 갈리는 조건. 마지막에 경우를 나눔(템플릿 2개) |

> [!tip]
> 강한 규칙(확정·블록)부터 배치하면 칸이 빠르게 줄어 **분기 수가 작아진다**. 둘로만 갈리면 템플릿 2개를 만들고, 선지는 두 템플릿 위에서만 확인한다.

### 6.4 앵커 · 금지쌍 · 블록 (세 가지 핵심 장치)

| 장치 | 정의 | 표 처리 | 함정 |
|---|---|---|---|
| **앵커** | 위치·소속이 한 곳으로 못박히는 개체 | 즉시 고정하고 그 칸을 다른 개체에서 배제 | 늦게 잡아 분기를 키움 |
| **금지쌍** | 같이 못 오는 두 개체 | 한 칸에 넣으면 모순 — 둘을 갈라놓는 분기 | **금지쌍을 조건문으로 착각** |
| **블록** | 반드시 붙는 묶음 (인접) | a-b 또는 b-a 덩어리로 이동하며 자리 탐색 | **'앞선다'(순서)와 '바로 앞선다'(인접=블록) 혼동** |

> [!note]
> 거리 조건 'a와 b 사이에 하나가 있다'는 a_b 형태의 간격 블록으로 처리한다(사이 칸 1개 고정, 방향 미정이면 분기).

### 6.5 그룹 선지 패턴 — 양상별 판정

> [!warning] 양상 틀리면 표가 맞아도 오답
> 선지의 양상(반드시 / 가능 / 불가능)에 따라 검증법이 정반대다.
> - **반드시 참** 선지는 **반례 한 개**로 깬다.
> - **가능** 선지는 **사례 한 개**로 세운다 — 방향이 반대.
> - '적어도 하나'는 둘 다 거짓만, '많아야 하나'는 둘 다 참만 막는다. 이 둘 뒤집기가 **빈출**.

| 선지형 | 양상 | 처리 |
|---|---|---|
| **반드시 a가 1번이다** | **반드시 참** | 모든 가능한 표에서 성립해야 참. 반례 표 하나면 거짓 |
| **a가 1번일 수 있다** | **가능** | 가능한 표 하나만 찾으면 참 |
| **a와 b는 함께 올 수 없다** | 불가능 | 같은 표에 넣어 모순이 나면 참(금지쌍) |
| **a가 오면 b도 온다** | 조건문 | a를 넣은 모든 경우에서 b가 따라오는지 확인 |
| **a와 b 중 정확히 하나** | 양상 결합 | 둘 다 참·둘 다 거짓이면 불가. 한쪽만 참 |
| **a와 b 중 적어도 하나** | 양상 결합 | **둘 다 거짓만 불가**. 한쪽이라도 참이면 만족 |
| **a와 b 중 많아야 하나** | 양상 결합 | **둘 다 참만 불가**. 한쪽만 또는 둘 다 거짓 허용 |
| **a가 b보다 앞선다** | 순서 | 순서만 확정, 인접 아님 |
| **a가 b 바로 앞선다** | 순서+블록 | 인접까지 확정(블록) |
| **a와 b 사이에 하나가 있다** | 거리 | 간격 블록(사이 1칸) |

### 6.6 보조사가 만드는 조건 (게임 룰 번역표)

문제 조건은 보조사 한 글자로 논리가 바뀐다. 조건문에 박힌 보조사를 정확히 번역해야 표가 맞는다.

| 표지 | 기능 | 조건 번역 | 함정 |
|---|---|---|---|
| **만 / 뿐 / 밖에** | 한정(only) | 'a여야(만) 1번'은 a가 1번의 **필요조건**(1번이면 a, a라고 1번은 아님) | **'a만 1번'을 '충분조건'으로 오독** |
| **도** | 첨가(also) | 'a도 A조'면 a 외에 다른 것도 A조에 있음 | 'a도'를 'a만'으로 뒤집어 단독으로 봄 |
| **조차 / 마저** | 극단 첨가(even) | 'a조차 탈락'이면 나머지는 당연히 탈락 | 극단 사례를 일반 사례로 평탄화 |
| **까지** | 척도 끝 | 범위를 a 끝까지 확장 | 끝점 포함 여부 누락 |
| **은 / 는** | 주제·대조 | 'a는 1번'은 다른 것은 1번이 아닐 수 있음을 함축 | **대조를 전칭·한정으로 비약** |
| **마다** | 분배 전칭(each) | '조마다 두 명'은 모든 조가 두 명 | 특칭('어떤 조는')으로 약화 오독 |
| **(이)나** | 선택/근사 | 'a나 b가 1번'은 둘 중 하나(배타 여부 별도 확인) | — |
| **라도** | 양보(even if) | 'a라도 가능'은 충분조건 아님 | **양보를 충분조건으로 격상** |

### 6.7 강한 단서 — 한 수로 전체를 가른다

> [!tip] 강한 단서란
> 하나를 박으면 나머지가 줄줄이 정해지는 조건. 이걸 **가장 먼저** 처리하면 표가 단번에 닫힌다. 핵심 둘은 **완전 고정(쌍조건)**과 **이분 분기**다. (이 둘은 논리게임뿐 아니라 정의·견해 분석 문항에도 그대로 나온다.)

#### 가) 완전 고정 — 쌍조건 (a와 b가 한 묶음)
- 형태: 'a이면 b, 그리고 b이면 a' = **'a일 때 그리고 오직 그 때만 b'**. 두 값이 **항상 같이** 움직인다(둘 다 참이거나 둘 다 거짓).
- 처리: a와 b를 **한 칸으로 묶는다**. a가 정해지면 b도 즉시 정해진다. 정의문('X는 …할 때 X이다')은 거의 쌍조건이다.
- 신호어: **'그리고 그 경우에만'**, '~인 한 그리고 ~인 경우에만', 필요충분 정의.
- 기출 예시 (2025 추리논증):
  - **Q15(위선자)**: "X가 …했을 경우, **그리고 그 경우에만** X는 위선자이다." -> 위반·비난 조건과 위선 여부가 1:1로 묶임. 한쪽이 정해지면 다른 쪽도 확정.
  - **Q39(종 정의)**: "다른 집단과 생식적으로 격리되어 상호교배가 가능한 개체군의 집단" -> 정의가 필요충분으로 주어지면 조건 충족 여부가 곧 종 여부.
- 함정: 쌍조건을 **한쪽 방향('a이면 b')으로만** 읽으면 역방향(b이면 a)을 놓쳐 오답.

> [!example] 쌍조건(완전 고정) — 2025 Q15 (위선자 정의)
> [원리] X가 위선자가 **아닐 경우, 그리고 그 경우에만** 타인을 비난할 자격이 있다 (+ 'X는 …할 경우, 그리고 그 경우에만 위선자').
> [논리] **'그 경우에만' = 필요충분(쌍조건).** 위선 여부와 비난 자격이 한 묶음으로 고정되어, 정의(A/B/C) 하나를 넣으면 각 인물의 자격이 일괄 결정된다. 한쪽 방향으로만 읽으면 오답(6.7 가 참조).

> [!example] 쌍조건(완전 고정) — 2024 Q18·Q26 ('오직 그 경우에만')
> [Q18] "대상 X가 그 생각을 야기하고 **X가 있을 때만** 그 생각이 야기되면, 그 생각은 X에 관한 것" -> 지향 관계를 **필요충분(쌍조건)**으로 정의.
> [Q26] 칸트 격률 "목적을 욕구하면서 수단을 욕구하지 않을 **경우 그리고 오직 그 경우에만** 위반" -> 위반 조건을 쌍조건으로 못박음.
> [논리] '오직 그 경우에만'이면 양방향이 모두 성립. 한쪽만 적용한 선지는 오답(6.7 가). 정의·격률 문항의 단골.

#### 나) 이분 분기 — 둘로 갈라 전체를 고정
- 형태: 어떤 변수가 **딱 두 경우**뿐이고, 각 경우가 나머지를 거의 다 정한다.
- 처리: 그 변수에서 **템플릿 A/B 두 개**를 만들고 각 안에서 나머지를 채운다. 선지는 두 템플릿 위에서만 검증.
- 신호: '둘 중 하나', '~이거나 아니거나', **'X만 같다/다르다'**(나머지는 모두 다름), 제약이 가장 많은 개체.
- 기출 예시 (2025 추리논증):
  - **Q34(구금·석방 순서)**: "갑이 최소, 정이 최대, **을과 병만 구금 일수가 같다**" -> 같은 값이 정확히 한 쌍이라는 제약이 순서를 소수 경우로 가른다.
  - **Q33(사과·진술)**: "1개 먹은 사람 말은 **참**, 2개 먹은 사람 말은 **거짓**" -> 각자의 개수(1 또는 2)가 진술의 참·거짓을 고정. 진리값으로 역추적하면 경우가 급감.
- 함정: 분기를 셋 이상으로 늘리면 시간이 사라진다. **가장 강한 제약**을 분기축으로 잡아 둘로 줄인다.

#### 다) 배치 강제·금지쌍 (그루핑)
- '한 묶음을 어디에 몇 명', '같이 못 오는 쌍(금지쌍)', '최소 몇 명' 같은 조건은 자리를 강하게 못박는다. **금지쌍과 인원 하한을 먼저** 박는다.
- 기출 예시 (2025 추리논증) **Q35(법무법인 팀 배정)**: 'P 3명을 C팀에' + 'S가 있는 팀엔 R 없음(**금지쌍**)' + 'S 팀엔 P 최소 2명'이 맞물려 배치가 소수로 좁혀진다.

> [!example] 논리게임 강한 단서 — 2024 Q34 (LED 전광판) · 정답 ④(ㄴ,ㄷ)
> [규칙] 전광판 P1{A,B,C,E} P2{A,C,D,F} P3{B,D,E,G} P4{C,E,F,G}. 각 판의 켜진 수 = 0·2·4(짝수). 같은 종류는 동시 점멸. **A·B·C 중 켜진 종류는 정확히 하나.**
> [강한 단서 작동] P1은 'A·B·C 중 하나'(1개)를 품으므로 짝수가 되려면 **E가 강제로 켜진다**. 이후 패리티로 A·B가 켜진 경우는 모순 -> **C 켜짐 확정**, 해는 {C,E,F,G}와 {C,D,E} 둘뿐.
> [보기] ㄱ A 켜짐? 두 해 모두 A 꺼짐 -> 거짓. ㄴ 켜진 종류 3가지({C,D,E})면 D 켜짐 -> 참. ㄷ F 켜지면({C,E,F,G}) G도 켜짐 -> 참.
> [논리] **제약 하나(ABC 중 하나 + 짝수)가 E를 강제하고 경우를 둘로 고정** = 6.7 완전 고정·이분 분기의 전형.

> [!warning] 처리 순서
> 강한 단서를 **완전 고정 -> 배치 강제·금지쌍 -> 이분 분기** 순으로 먼저 처리한다. 약한 조건부터 손대면 경우의 수가 폭발한다.

### 6.8 실전 운영 원칙

> [!check] 표 채우기 전·분기 직전 점검
> - 표는 한 번만. 선지마다 새 표 금지 — 확정 템플릿에서 **가능성만 지운다**.
> - 경우가 둘로 갈리면 두 템플릿을 동시에 든다. 셋 이상이면 더 강한 확정조건을 먼저 박는다.
> - '반드시 참' 발문이면 **깨는 표**(반례), '가능' 발문이면 **세우는 표**(사례)를 노린다.
> - 금지쌍·블록·앵커를 표 옆에 약물로 적고, 분기 직전 다시 훑어 위반을 거른다.
> - 머리로 굴리지 않는다 — 가장 고정된 정보를 축으로 박고 손으로 채운다.

## 7. 발문별 풀이 알고리즘

> [!tip] 시험장 코어
> - 발문을 5초 안에 분류하고, 타깃 주장 T를 한 문장으로 잡는다.
> - 발문마다 정해진 **"먼저 보는 것" 하나**부터 본다(아래 표).
> - 공통 1순위 흐름: 발문 판별 -> T 확정 -> 표지어 체크 -> 선지 기능 판정 -> **강도 맞추기**.
> - 표지어 후보: 만·오직·없이는·않는 한·반드시·가능·알다·주장하다·해야 한다·할 수 있다.
> - 어느 발문이든 **범위·강도를 키운 선지는 의심**부터 한다.

| 발문 | 먼저 보는 것 (한 줄) |
|---|---|
| **반드시 참** | 지문에 **직접 있거나 대우·양화 변환으로 따라오는가** (현실적 그럴듯함 금지) |
| **추론 가능** | 지문이 말한 **범위를 넘지 않는가** (숨은 상식 주입 금지) |
| **강화** | T를 공격할 **대안설명을 줄이는가** |
| **약화** | T의 숨은 전제를 부정하는가 (인과면 역인과·공통원인·표본·측정 먼저) |
| **필요가정** | 선지를 **부정하면 논증이 무너지는가** |
| **충분가정** | 선지를 **넣으면 결론이 반드시 따라오는가** |
| **오류 찾기** | 선지가 말한 결함이 지문의 실제 약점과 일치하는가 |
| **원리 적용** | 사례가 원리의 조건을 충족하는가 (예외·우선순위·양상 확인) |
| **계산·그룹** | **고정축(앵커)부터** 잡고 확정 조건 먼저, 선지별로만 경우 분기 |

---

### 7.1 반드시 참 / 추론 가능

두 발문은 "지문이 보장하는 최소 결론"을 묻는다. 핵심은 **범위와 강도를 키우지 않는 것**이다.

| 단계 | 반드시 참 | 추론 가능 |
|---|---|---|
| **1** | 결론 후보를 지문 문장과 대조한다 | T가 지문 범위 안에 있는지 본다 |
| **2** | 직접 진술·대우·양화 변환으로 따라오는지 확인한다 | 여러 문장을 연결하되 숨은 상식이 끼면 탈락 |
| **3** | 강도·범위를 키운 선지를 제거한다 | 조건문은 대우까지만 안전 |

> [!warning] 대표 함정
> - '대부분·가능·일부'를 '**모든·필연·전부**'로 키우면 즉시 제거. ('마다'=분배 전칭이므로 이를 특칭으로 약화한 선지도 오답)
> - 현실적으로 그럴듯하다는 이유로 고르지 않는다. 지문이 그 정도까지 말했는지만 본다.
> - 'A이면 B'에서 'A가 아니다'(**전건부정**)·'B이다'(**후건긍정**)가 나오면 아무 결론도 못 낸다.

---

### 7.2 강화

| 단계 | 행동 |
|---|---|
| **1** | 결론 T를 한 문장으로 찾는다 |
| **2** | T가 조건문·인과·일반화·유비·설명가설·규범 중 무엇인지 분류한다 |
| **3** | T를 공격할 **대안설명을 먼저 예상**한다 |

> [!note] 강화 선지의 정체
> 대안설명을 줄이거나, 전제·결론의 빈 연결고리를 메우거나, 표본·측정 신뢰도를 올리거나, 예측을 성공시키거나, 기제를 제시하거나, 범위를 맞추는 선지가 강화다. 강화는 T를 **증명할 필요가 없고**, 믿을 정도만 올리면 된다.

> [!warning] 대표 함정
> - **결과만 반복하는 선지**는 약한 강화 또는 무관.
> - **다른 변수** 이야기는 무관.

---

### 7.3 약화

| 단계 | 행동 |
|---|---|
| **1** | 결론 T를 찾고, T가 성립하려면 필요한 **숨은 전제**를 잡는다 |
| **2** | T 유형별 1순위 공격을 찾는다 (아래) |
| **3** | 숨은 전제를 부정하는 선지를 고른다 |

| T 유형 | 약화 1순위 |
|---|---|
| **인과** | **역인과·공통원인·대체원인·표본편향·측정오류** |
| **조건문** | A인데 B가 아닌 사례 |
| **일반화** | 표본 편향·작은 표본·반례 |
| **유비** | 결론을 좌우하는 핵심 조건의 차이 |
| **설명가설** | 경쟁가설이 더 잘 설명·예측 실패 |
| **규범** | 적용요건 불충족·예외조항·우선 규범 충돌 |

> [!note] 강도와 양상
> - T를 완전히 반박할 필요 없다 — 믿을 정도만 낮추면 충분.
> - **양상 비약 공격**: 지문은 '가능'인데 결론이 '필연'으로 갔음을 보이면 약화.

---

### 7.4 필요가정 (필요전제)

| 단계 | 행동 |
|---|---|
| **1** | 결론을 찾는다 |
| **2** | 선지를 **부정해 본다** |
| **3** | 부정했을 때 결론이 무너지면 필요가정, 버티면 아니다 |

> [!warning] 대표 함정
> **너무 강한 선지는 대개 오답.** 필요가정은 '없으면 논증이 무너지는 최소 조건'이면 되고, 결론을 증명할 필요가 없다.

> [!check] 단골 후보
> - 표본이 모집단을 대표한다
> - 앞뒤 'A'가 같은 의미다
> - 대안 원인이 결정적이지 않다
> - 비교 두 집단이 문제 요인 외에는 같다
> - 원칙 적용 범위에 사례가 포함된다

---

### 7.5 충분가정 (충분전제)

| 단계 | 행동 |
|---|---|
| **1** | 근거 P와 결론 T 사이의 **빈칸**을 찾는다 |
| **2** | 선지를 넣었을 때 **결론이 반드시 따라오는지** 본다 |
| **3** | 결론의 주어·범위·양상이 그대로 연결되는지 확인한다 |

> [!note] 강도 직관을 버려라
> **충분가정은 강해도 된다** — 필요가정보다 범위가 넓거나 단정적인 경우가 많다. '강해서 오답'이라는 직관을 여기서는 버린다. 핵심은 다리 놓기: '사람이 진보적'에서 '행위가 비보수적'으로 넘어가는 연결을 완성하면 정답.

> [!warning] 필요 vs 충분 — 판정 방향이 반대
> 필요는 **부정하면 무너지는가**, 충분은 **넣으면 따라오는가**.

---

### 7.6 오류 찾기

| 단계 | 행동 |
|---|---|
| **1** | 결론이 무엇인지 찾는다 |
| **2** | 전제가 결론을 보장하는지 묻는다 |
| **3** | 오류 후보를 순서대로 체크하고, **선지의 결함 설명이 지문 약점과 정확히 대응**하는지 본다 |

> [!check] 오류 후보 빠른 체크리스트
> - **필요조건·충분조건 혼동** / 후건긍정 / 전건부정(역·이 오류)
> - 상관을 인과로 / 원인·결과 역전 / 대안설명 미배제
> - 대표성 없는 표본 일반화 / 평균과 개인 혼동 / 전체와 부분 혼동
> - **가능을 사실로, 당위를 사실로, 주장을 사실로** 바꿈 / 같은 단어를 앞뒤 다른 뜻으로 사용(의미 이동)
> - 결론보다 강한 선지 선택

> [!warning] 대표 함정
> **그럴듯하지만 지문이 실제로는 저지르지 않은 오류를 지적한 선지는 오답.** 선지가 묘사한 기능이 지문의 실제 약점과 맞아야 한다.

---

### 7.7 원리 적용

| 단계 | 행동 |
|---|---|
| **1** | 원리를 **조건·효과·예외·우선순위**로 쪼갠다 |
| **2** | 사례가 조건을 충족하는지 확인한다 |
| **3** | 예외·충돌 원리를 먼저 보고, 결론 **양상을 맞춘다** |

> [!warning] 대표 함정
> - 가치판단 문구('바람직하다')에 끌리지 말고 적용요건을 본다.
> - '해야 한다(의무)·할 수 있다(능력/가능)·금지된다·허용된다'를 서로 바꾸면 오답. 특히 **허용을 의무로 키우는** 함정이 잦다.

> [!note] 원리 추출형 (사례->원칙)
> 결과가 같은 사례를 묶지 말고, 허용/금지를 **가른 판정 기준**을 뽑는다. 예외 사례가 있으면 예외 조건까지 포함한다.

---

### 7.8 계산·그룹

| 단계 | 행동 |
|---|---|
| **1** | 유형 판별(배열·속성·연결·묶기·진실거짓·최소최대·비율평균) 후 **가장 고정된 정보를 축**으로 잡는다 |
| **2** | 확정 조건 -> 부정 조건 -> 강한 연결 조건 -> 분기 조건 순으로 처리한다 |
| **3** | **선지마다 새 표를 그리지 말고**, 물어본 선지를 죽일 만큼만 경우를 나눈다 |

> [!note] 앵커 후보
> 총합 / 분모 / 단위 / 극값(최대·최소)을 만드는 방향 / 불변량 / 등호 성립 조건 / 경우 분기 기준.

> [!note] 선지 처리
> - '반드시 A다' = 모든 가능한 표에서 확인
> - 'A일 수 있다' = 가능한 표 하나만 찾으면 됨
> - '항상 참인가' = 반례 하나 탐색

> [!warning] 대표 함정
> - **최소·최대는 계산보다 경계.** '적어도'는 최소값을 올리고, '많아야'는 최대값을 낮춘다. 중복 가능 여부 먼저 확인.
> - **비율·평균은 분모부터.** 합격률 상승이 곧 합격자 수 증가가 아니다(분모가 줄었을 수 있음). 총량 증가가 곧 비율 증가도 아니고, 평균 상승이 모든 값 상승도 아니다.

## 8. 예문 은행 — 지문·선지·판단·함정

> [!tip] 시험장 코어
> - 모든 예문은 **[지문 요지] -> [선지] -> [판단] -> [함정]** 4줄로 읽는다. 선지 원문을 외우지 말고 '이 선지가 무슨 논리 기능을 하는가'만 본다.
> - 출처 셋: (1) **LSAT식 번역형 10종**(v2 6장) — 견해불일치·유비·추론가능·강화·오류·원리보강·충분전제·필요전제·역설해소·병렬오류 / (2) **분석본 기출 제재**(docx 4장) — 평가원·리트 실제 제재, 양상·인과·범위 함정 예시로만 인용 / (3) **형식 예시** — 출처 없는 자작 골격.
> - 판단 약어: '가능'=논리적으로 따라옴 / '안 됨'=따라오지 않음(역·이·후건긍정) / '강화·약화·무관'은 타깃 주장 T를 더·덜 믿게 만드는지로 통일.
> - **1순위 함정은 양상 대치**(가능->사실, 당위->사실, 조건부->단정), 그다음 **역·이 오류**, **범위(전칭<->특칭) 비약**. 아래 블록·표에서 볼드가 그 자리다.

### 8.1 LSAT식 번역형 10종 (출처: v2 6장 재정리)

각 항목은 쟁점 한 줄 뒤에 정답형 선지 1개와 대표 오답 1~2개를 4줄 형식으로 압축한다.

#### 8.1.1 견해불일치형 — 순수연구의 가치

> [!example] 견해불일치형
> - [지문 요지] 두 사람이 '순수연구의 가장 큰 가치가 어디에 있는가'를 다르게 본다. 한쪽은 생명구호를 최고가치로, 다른 쪽은 지식확장을 더 높게 둔다.
> - [선지] (정답형) '순수연구의 가장 가치 있는 성과는 의학적 응용에 있다' — 둘이 반드시 갈라지는 축.
> - [판단] 정답. 가치 순위·최상급에서 충돌하므로 불일치 지점.
> - [함정] '순수연구는 신기술을 제공한다'처럼 **둘 다 인정하는 명제**를 불일치로 착각. 동의 여부가 아니라 '반드시 갈라지는 축'을 찾는다.

#### 8.1.2 유비추론형 — 웹 광고로 인쇄 광고 추론

> [!example] 유비추론형
> - [지문 요지] 직접자료가 있는 웹광고 성과로, 직접자료가 없는 인쇄광고 성과를 추론한다.
> - [선지] (정답형) '직접증거가 있는 사례를 이용해 직접증거가 없는 유사사례를 추론한다'.
> - [판단] 정답. 비슷한 두 사례 중 하나의 자료로 다른 하나를 판단 = 유비추론.
> - [함정] '많은 구체사례로부터 통계 일반화'(표본 일반화)나 '과거 유사사건으로 미래 예측'으로 **추론 종류 바꿔치기**. 강화는 관련 유사성 추가, 약화는 관련 차이 추가.

#### 8.1.3 추론가능형 — 교량 붕괴와 수학적 분석

> [!example] 추론가능형
> - [지문 요지] 사고 이후 경험칙이 폐기되고 더 엄밀한 수학적 분석으로 전환되었다.
> - [선지] (정답형) '당시 경험칙의 분석 수준은 공사 중 안전을 완전히 보장하기에 부족했다' — 지문에서 따라오는 최소 결론.
> - [판단] 정답. 추론가능형 정답은 대개 더 약한 문장이다.
> - [함정] '더 엄밀한 분석만이 붕괴를 막을 유일한 방법'(**유일성 과강도**), '1907년 이전 교량은 모두 위험'(**과도한 일반화**). '유일한·모두·원인이다'가 보이면 지문이 그 정도까지 말했는지 확인.

#### 8.1.4 강화형 — 초신성 뒤 중성자별이 안 보임

> [!example] 강화형
> - [지문 요지] 이론상 특정 크기 초신성 뒤 중성자별이 남아야 하는데 관측되지 않았다. '이론이 틀렸다'를 강화하려면 '못 본 이유가 장비 한계가 아님'을 보여야 한다.
> - [선지] (정답형) '사용된 민감한 장비는 그 위치보다 더 먼 중성자별도 검출한 적이 있다'.
> - [판단] 강화(정답). 장비 한계라는 대안설명을 제거한다.
> - [함정] '현 이론은 그 초신성의 여러 특징을 맞혔다'는 **오히려 이론 강화**라 역방향. '없다'를 주장하려면 '찾을 수 있었는데도 못 찾았다'(탐지능력·측정민감도)가 필요하다.

#### 8.1.5 오류형 — 민주주의와 정치적 자유

> [!example] 오류형
> - [지문 요지] 민주주의가 자유를 보장하지 않는 사례와, 민주주의가 아니어도 자유가 있는 사례를 들어 '민주주의는 자유를 증진하지 않는다'고 결론낸다.
> - [선지] (정답형) '민주주의가 필요조건도 충분조건도 아니어도 자유를 증진할 수 있음을 간과한다'.
> - [판단] 정답. 'A가 B의 필요조건 아님'과 'A가 B의 충분조건 아님'을 합쳐도 'A가 B를 촉진 안 함'은 안 나온다.
> - [함정] '필요조건과 충분조건을 혼동했다'처럼 **그럴듯하지만 실제 저지르지 않은 오류** 라벨에 끌림. 결론이 건너뛴 지점을 정확히 짚는다.

#### 8.1.6 원리보강형 — 약값 차등정책

> [!example] 원리보강형
> - [지문 요지] 제약사가 가난한 나라엔 낮은 가격, 부유한 나라엔 높은 가격을 매기는 정책이 정당한가. 쟁점은 아픈 사람들 '사이의' 배분 기준.
> - [선지] (정답형) '특별 배려는 소속 사회가 아니라 개인의 필요에 따라야 한다' — 국가 평균이 아니라 개인 필요로 기준 전환.
> - [판단] 정답. 사실과 결론 사이의 규범 기준을 연결한다.
> - [함정] '아픈 사람은 건강한 사람보다 더 고려받아야 한다'는 **쟁점 밖 배분 축**(아픈 사람 vs 건강한 사람). 원리문항은 '왜 그 사실이 결론을 정당화하는가'를 잇는 원리를 고른다.

#### 8.1.7 충분전제형 — 형식시와 정치적 보수성

> [!example] 충분전제형
> - [지문 요지] '형식시를 쓰는 현대 시인은 정치적으로 보수적 행위를 한다'는 일반화를 반박하려면, 형식시를 쓰면서도 보수적 행위를 하지 않는 사례가 필요하다.
> - [선지] (정답형) '정치적으로 진보적인 사람은 보수적 행위를 할 수 없다' — '사람이 진보적'에서 '행위가 비보수적'으로 가는 다리.
> - [판단] 정답. 충분전제는 결론이 반드시 따라오도록 빈칸을 메우면 되고, 강해도 무방하다.
> - [함정] '자유시를 쓰는 시인은 보수적이지 않다'는 **대상이 다름**(형식시 아님). 결론의 주어·범위가 그대로 이어지는지 본다.

#### 8.1.8 필요전제형 — 호수 퇴적층의 뼈

> [!example] 필요전제형
> - [지문 요지] 특정 시기에 존재한 호수 바닥 퇴적층에서 조상 뼈가 나왔으므로, 그 시기 그 지역에 살았다고 결론낸다.
> - [선지] (정답형) '뼈는 호수가 마르기 전에 이미 퇴적층에 있었다'.
> - [판단] 정답. 부정해 보면(뼈가 나중에 들어왔다면) 시기 추론이 무너지므로 필요전제.
> - [함정] '호수에 먹을 물고기가 있었다'는 **왜 거기 살았는지 설명일 뿐 결론에 불필요**. 필요전제는 선지를 부정해 결론이 무너지는지로 가른다.

#### 8.1.9 역설해소형 — 전조등 의무화

> [!example] 역설해소형
> - [지문 요지] 자발적으로 전조등을 켜는 운전자는 사고가 적다. 그런데 전조등 의무화는 전체 사고를 줄이지 못한다(두 문장 모두 참).
> - [선지] (정답형) '법적 의무가 없을 때 전조등을 켜는 사람은 매우 조심스러운 운전자뿐이다' — 효과는 전조등이 아니라 운전자 성향.
> - [판단] 정답. 두 문장을 모두 살린다.
> - [함정] '의무화 법은 집행하기 어렵지 않다'는 **한쪽 문장만 설명**해 역설 해소 실패. 두 문장을 동시에 살리지 못하면 오답.

#### 8.1.10 병렬오류형 — 르네상스 화가와 붉은색

> [!example] 병렬오류형
> - [지문 요지] '대부분의 A는 B, 이 대상은 B, 그러므로 A일 것이다'(후건긍정형 통계오류)와 같은 골격의 논증을 고른다.
> - [선지] (정답형) '초기 피렌체 그림 대부분은 템페라이므로, 템페라 그림인 이 작품은 초기 피렌체 그림일 것이다' — '대부분 A는 B, 이 B는 A'.
> - [판단] 정답. 소재가 아니라 골격이 같다.
> - [함정] '대부분 A가 B, 이 대상은 A, 그러므로 B'(비교적 합리적)와 **방향을 헷갈림**. 병렬논증은 소재를 버리고 'B를 보고 A로 가는지'만 본다.

### 8.2 기출 제재 적용형 (출처: 분석본 기출 제재 — docx 4장)

분석본 4장의 평가원·리트 제재를 양상·인과·범위 함정의 예시로 재구성한다. 선지는 분석본이 정리한 '선지 변형 방식'을 따른다. 사건번호·점수는 원자료에 없으므로 적지 않는다.

#### 8.2.1 조건부 의무형 — 유류분 제도 (출처: 분석본 기출 제재)

> [!example] 조건부 의무형 — 유류분 제도
> - [지문 요지] 돈 이외의 재산이라면 처분된 재산 자체가 반환 대상이 되는 것이 '원칙'이고, 예외 조건이 의무의 내용을 바꾼다(일응의 의무 + 예외).
> - [선지] '돈 이외의 재산은 언제나 그 재산 자체를 반환해야 한다'.
> - [판단] 안 됨. '원칙이다'를 예외 없는 단정으로 바꿨다(조건부->단정).
> - [함정] **조건부 의무의 예외 삭제**. '원칙적으로'·'~인 경우에는'이 붙은 당위는 무조건 당위가 아니다. 보조사 '면/라면'(조건)을 빼고 전칭처럼 읽으면 함정.

#### 8.2.2 행정입법 양상강화형 — 위임명령 (출처: 분석본 기출 제재)

> [!example] 행정입법 양상강화형 — 위임명령
> - [지문 요지] 전문성이 필요한 경우 위임의 구체성 요건이 '완화될 수 있다'(가능). 행정규칙은 원칙적으로 위임 없이 가능하고 예외적으로 위임이 필요하다.
> - [선지] '전문성이 필요한 경우 위임의 구체성 요건은 완화되어야 한다'.
> - [판단] 안 됨. '완화될 수 있다(가능)'를 '완화되어야 한다(당위)'로 올렸다.
> - [함정] **양상 강화(가능->당위)**. 그리고 '행정규칙은 위임이 있어야만 가능'은 원칙과 예외를 뒤집은 **조건 전도**. 한정 보조사 '만'이 붙으면 필요조건 주장인지 먼저 확인.

#### 8.2.3 인과 역전형 — 트리핀 딜레마 (출처: 분석본 기출 제재)

> [!example] 인과 역전형 — 트리핀 딜레마
> - [지문 요지] 경상수지 적자가 달러 공급을 늘리고, 그 적자 지속이 준비자산 신뢰도를 떨어뜨린다(적자가 원인, 신뢰도 하락이 결과). 유동성 공급과 신뢰도 유지는 동시에 달성 불가.
> - [선지] '준비자산 신뢰도 하락이 경상수지 적자를 일으킨다'.
> - [판단] 약화/오류. 인과 방향을 뒤집었다(결과를 원인으로).
> - [함정] **인과 역전**. 딜레마형 지문은 'A이면 B가 아니다'식 역관계를 'A와 B가 무관'으로 약화하거나 화살표 방향을 뒤집는 선지가 단골.

#### 8.2.4 사고실험 주체전이형 — 중국어방·확장인지 (출처: 분석본 기출 제재)

> [!example] 사고실험 주체전이형 — 중국어방·확장인지
> - [지문 요지] 중국어를 전혀 모르는 사람이 방 안에서 규칙서대로 기호를 배열한다(구문 처리는 하되 의미 이해는 없다 — 기능주의 반박). 확장인지는 '주체와 통합될 때' 인지가 외부로 확장될 수 있다고 본다.
> - [선지] '노트북이 정보를 기억한다' / '방 안의 사람은 중국어를 이해한다'.
> - [판단] 안 됨. 주체성을 외부 사물에 귀속하거나, 구문 처리를 의미 이해로 비약했다.
> - [함정] **주체 전이 + 조건 누락**. 확장인지 성립조건(주체와의 통합)을 빼고 무조건 확장으로 단정. '할 수 있다(가능·조건부)'를 '한다(사실)'로 바꾸는 양상 대치가 겹친다.

#### 8.2.5 가능성 과장형 — 블록체인 무결성 (출처: 분석본 기출 제재)

> [!example] 가능성 과장형 — 블록체인 무결성
> - [지문 요지] 과반수 연산력을 가진 공격자가 '없다면' 데이터 변경이 사실상 불가능하다(조건부 불가능). 해시 연산을 수행해야만 블록을 생성할 수 있다.
> - [선지] '블록체인 데이터는 언제든 손쉽게 변경될 수 있다'.
> - [판단] 안 됨. 이론적으로 가능한 해킹을 현실적으로 빈번한 것으로 과장(가능성 과장).
> - [함정] **가능 양상 과장 + 조건 삭제**. '~가 없다면'이라는 전제(필요조건)를 떼고 무조건 가능으로 읽음. '해야만'의 한정 보조사를 무시하면 '작업증명 없이도 합의 가능'식 오답에 걸린다.

#### 8.2.6 범위·범주 혼동형 — 클라이버의 법칙 (출처: 분석본 기출 제재)

> [!example] 범위·범주 혼동형 — 클라이버의 법칙
> - [지문 요지] 체중이 늘면 대사량도 늘지만 증가율(기울기)은 1보다 작아, '체중 당 대사량'은 오히려 줄어든다.
> - [선지] '체중이 늘수록 체중 당 대사량도 늘어난다'.
> - [판단] 안 됨. '대사량'과 '체중 당 대사량'을 뒤섞은 범주 오류.
> - [함정] **개념 대치(범주 오류)**. 절댓값과 단위당 값을 같은 것으로 처리. 분배 보조사 '마다/당'이 붙은 지표는 전체값과 분리해서 읽는다.

#### 8.2.7 시제·절차 위배형 — 3D 모델링·렌더링 (출처: 분석본 기출 제재)

> [!example] 시제·절차 위배형 — 3D 모델링·렌더링
> - [지문 요지] '모델링 -> 시점 변환 -> 투영 -> 렌더링' 순서는 불가역적이고, 뒤 단계 계산은 앞 단계 데이터에 의존한다(앞 단계가 뒤 단계의 필요조건).
> - [선지] '질감(화솟값) 처리는 모델링 단계에서 이루어진다'.
> - [판단] 안 됨. 렌더링 단계 작업을 모델링 단계로 옮겨 절차 논리를 위배.
> - [함정] **시제 양상 왜곡**. 'A 후에 B', 'A에 앞서'의 순서 표지를 뒤섞음. 보정이 촬영 전인지 후인지(영상 안정화 지문류)도 같은 함정.

### 8.3 형식 예시 — 보조사·조건문 골격 (출처: 형식 예시, 자작)

소재 없이 보조사·조건문의 논리 기능만 보여주는 골격 패턴. 표지어 표(2장·3장)와 짝지어 읽는다.

| 지문 골격 요지 | 선지 | 판단 | 함정 |
|---|---|---|---|
| **'a여야(만) b이다' (a는 b의 필요조건)** | 'a이다. 따라서 b이다' | 안 됨 | **한정 '만'을 충분조건으로 오독.** 'a만 b'는 'b이면 a'지 'a이면 b'가 아니다 |
| **'a도 b이다' (a를 포함해 다른 것도 b)** | '오직 a만 b이다' | 안 됨 | 첨가 '도'를 한정 '만'으로 뒤집음. '도'는 다른 것도 b임을 함축 |
| **'a조차 b이다' (가장 의외인 a까지 b)** | '오직 a만 b이고 나머지는 b가 아니다' | 안 됨 | 극단 첨가 '조차'를 한정으로 비약. a가 b면 나머지는 당연히 b |
| **'A는 b이다' (대조 — 다른 것은 b 아닐 수 있음)** | '모든 것이 b이다' | 안 됨 | **대조 보조사 '는'을 전칭으로 비약.** 'A는'은 'B는 다를 수 있음'을 함축 |
| **'대상마다 c를 충족한다' (분배 전칭=모든 대상)** | '어떤 대상은 c를 충족한다' | 안 됨(약화 오독) | 분배 '마다'(모든)를 특칭으로 약화 |
| **'a이면 b이다. b이다'** | '따라서 a이다' | 안 됨 | **역 오류**(후건긍정). 가장 그럴듯한 오답의 단골 |
| **'a이면 b이다. a가 아니다'** | '따라서 b가 아니다' | 안 됨 | **이 오류**(전건부정) |
| **'a이면 b이다. b가 아니다'** | '따라서 a가 아니다' | 가능 | 대우. 원문과 항상 같이 간다 |
| **'a하지 않는 한 b이다. a하지 않았다'** | '따라서 b이다' | 가능 | '~않는 한'은 'a 아니면 b'. 단, a가 있으면 b가 반드시 없다는 뜻은 아님 |
| **'a라도 b이다' (양보)** | 'a이면 반드시 b이다(충분조건)' | 안 됨 | 양보 '라도'를 충분조건으로 격상 |
| **'많아야 n개이다'** | '정확히 n개이다' | 안 됨 | 상한을 정확값으로 고정 |
| **'적어도 한 사람이 모든 책을 읽었다'** | '각 사람이 책을 한 권씩 읽었다' | 안 됨 | **범위(양화사 순서) 함정.** '같은 한 사람'과 '사람마다 다름'을 구별 |

### 8.4 양상 대치 빠른 오답표 (출처: v2 4장 + 분석본 5장 통합)

가장 자주 나오는 양상 대치를 '지문 -> 오답 선지' 한 줄로 모았다. **전부 고빈도 함정**이다.

| 지문이 말한 것 | 오답 선지가 바꾼 것 | 왜 틀리나 |
|---|---|---|
| **a일 가능성이 있다** | a이다 | 가능을 사실로 |
| **a여야 한다(당위)** | a이다(사실) | 당위를 사실로 |
| **a가 P라고 주장한다** | P이다 | 주장을 사실로 |
| **a가 P를 믿는다** | P이다 | 믿음을 사실로(믿음은 사실성 없음) |
| **a가 P를 안다** | P가 아닐 수 있다 | 지식의 사실성 무시(앎은 P를 함축) |
| **a할 수 있다(능력·허용)** | a해야 한다(의무) | 능력·허용을 의무로 |
| **a해도 된다(허용)** | a해야 한다(의무) | 허용을 의무로 |
| **a가 불가피하다(필연)** | a가 바람직하다(가치) | 필연을 가치평가로 |
| **a의 가능성을 배제 못 한다** | a가 가장 유력하다 | 잔여 가능성을 우세로 과장 |
| **조건이 충족되면 b이다(조건부)** | 항상 b이다(단정) | 조건을 무시 |
