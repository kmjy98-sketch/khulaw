## 1. 글 종류(제재) 8분류와 종류별 알면 좋은 것

> [!tip] 시험장 코어
> - 제재마다 **독해 진입점(읽기 골격)**이 정해져 있다 — 표의 '한 줄 핵심'을 진입 시 떠올린다.
> - **법·법철학(매년 2~3지문)·경제(거의 매년)·생명과학**이 빈출 3축. 이 셋은 무조건 출제 가정.
> - 모든 제재 공통 1순위 점검: 선지가 본문의 **관계(주체·인과·조건·범위·태도)**를 보존하는가 — 단어 일치가 아니라 기능 일치.
> - 보조사는 본문이 깔아둔 신호: '~는'(대조, 전칭 비약 금지) / '~만·~여야'(한정=필요조건) / '~도·~조차'(첨가, '~만'으로 뒤집기 함정).
> - 1순위 오답은 항상 **양상(가능/필연)·수량(일부/모두)·조건(필요/충분)을 바꾼 선지**.

| 제재 | 빈도 | 한 줄 핵심(독해 진입점) | 1순위 함정 |
|---|---|---|---|
| ① 법·법철학 | **매년 2~3지문** | 원칙->요건->예외->형량. '해야/된다/안 된다'(의무·허용·금지) 추적 | **원칙·예외 전도**, 요건 일부만 충족 |
| ② 윤리·도덕철학 | 자주 | 행위 자체 평가(의무론) vs 결과 평가(공리주의) 축 | '그러하다'(사실)를 '그래야 한다'(당위)로 |
| ③ 인식론·과학철학 | 자주 | '안다(참 함축)' vs '믿는다/주장한다(참 보장 안 됨)' 분리 | 주장을 사실로, 가능을 필연으로 |
| ④ 정치·사회 | 자주 | 분석 단위 — 개인·행위 vs 구조·제도 | **층위 이동**(구조 설명을 개인 책임론으로) |
| ⑤ 경제 | **거의 매년** | 가정->변수->예측->한계. 모형 안에서만 성립 | 모형 결론을 현실 일반으로, 상관을 인과로 |
| ⑥ 과학(생명·물리·화학) | **생명과학 빈출** | 입력->단계->변환->출력->피드백. 화살표 방향·조건 | **인과 역전·단계 생략**, 비례 단선화 |
| ⑦ 기술·공학 | 자주 | 절차의 순서가 불가역. 'A한 후 B' 시간 양상 | 단계 혼합, 두 방식 장단점 교차 |
| ⑧ 역사·문학비평·예술 | 자주 | 작품 사실 vs 해석자 주장 분리 / 연속 vs 단절 | 작품 사실과 해석 혼동, 시간 착오 |

### 1.1 ① 법·법철학 (매년 2~3지문, 최빈출)

| 항목 | 내용 |
|---|---|
| 빈출 소재 | 위임명령·행정규칙, 재판매가격유지행위(공정거래법), 유류분 반환, 기본권 제한·비례성, 자연법 vs 법실증주의, 형식주의 vs 법현실주의 |
| 꼭 아는 배경개념 | 원칙(IM·금지)과 예외(조건부 허용), 요건-효과 구조, 입증책임의 소재, 무효(효력 없음), 형량(충돌 가치 비교) |
| 자주 나오는 구조 | 원칙 -> 요건 -> 효과 -> 예외 -> 사례 적용 -> 형량·결론 (법리 논문형) |
| 대표 선지 함정 | **원칙과 예외를 뒤섞음** / 요건 A·B·C 중 일부만 보고 결론 / '완화될 수 있다(가능)'를 '완화되어야 한다(필연)'로 강화 / 권장가격과 강제가격의 구분을 모호하게 |

> [!example] 기출 제재 (docx 4장)
> - **유류분 제도 (2023학년도 11월)**: 반환 청구 '권리(허용)'와 반환 의무자의 '의무'를 함께 다룸. 일응의 의무를 세운 뒤 예외 조건으로 의무 내용을 변경하는 조건부 의무 구조.
> - **위임명령·행정규칙 (2021학년도 9월)**: 포괄적 위임은 금지, 전문성 필요 시 구체성 요건 완화(조건부 허용), 위임 범위 벗어나면 무효. 함정은 '행정규칙은 위임이 있어야만 제정 가능'처럼 원칙(위임 없이 가능)과 예외를 뒤바꿈.
> - **재판매가격유지행위·공정거래법 (2025학년도 9월)**: 원칙적 금지지만 소비자 후생 증대 효과가 경쟁 제한 폐해보다 크면 허용. 정당한 사유의 입증책임은 사업자. '모든 가격 지정은 위법'은 조각 사유 무시 오답.

> [!note] 보조사 신호
> '구체적으로 범위를 정하지 않은 채 위임하는 것**은** 저촉된다'의 '은'은 **대조** — 범위를 정한 위임은 다를 수 있다는 함축. 이를 전칭('모든 위임은 위법')으로 비약시키는 선지가 함정. '정당한 사유가 있어**야만** 허용'은 한정 — 정당한 사유가 **필요조건**(있으면 무조건 허용이라는 충분조건 아님).

### 1.2 ② 윤리·도덕철학

| 항목 | 내용 |
|---|---|
| 빈출 소재 | 의무론 vs 공리주의, 덕윤리, 정서주의·이모티비즘, 권리 vs 전체 후생, 응보 vs 예방 |
| 꼭 아는 배경개념 | 행위 자체 평가 vs 결과 평가, 보편주의 vs 특수주의, 명제(참·거짓 가능) vs 감정 표출, 처벌 정당화 기준 |
| 자주 나오는 구조 | 통념 -> 반례 -> 기준 수정 (개념 재구성형) / 두 입장 형량 (가치 형량형) |
| 대표 선지 함정 | 의도와 결과를 동일시 / '무엇인가'(사실)를 '무엇이어야 하나'(당위)로 / 한 가치를 절대 우위로 과장(조건부 우위인데) |

> [!example] 기출 제재 (docx 3장)
> - **에이어의 정서주의·프레게-기치 문제 (2025학년도 6월)**: 전건 긍정 형식('살인이 나쁘다면 돕는 것도 나쁘다 / 살인은 나쁘다 / 따라서 돕는 것도 나쁘다')에서, 정서주의에 따르면 '살인은 나쁘다'가 명제가 아니라 감정 표출이라 논증이 성립하지 않는다는 난점. **사실/가치, 명제/표출의 구분**이 핵심.

> [!note] 보조사 신호
> '살인을 돕는 것**도** 나쁘다'의 '도'는 **첨가** — 살인 자체도 나쁘고 돕는 것도 나쁘다는 포함 함축. 이를 '돕는 것만 나쁘다'로 뒤집으면 오답.

### 1.3 ③ 인식론·과학철학

| 항목 | 내용 |
|---|---|
| 빈출 소재 | 합리론 vs 경험론, 토대주의 vs 정합주의, 심신문제(이원론·물리주의·기능주의), 과학적 실재론 vs 도구주의, 누적주의 vs 패러다임 전환, 귀납 vs 반증 |
| 꼭 아는 배경개념 | '안다'는 참을 함축(사실성), '믿는다·주장한다'는 참을 보장하지 않음 / 다중 실현 가능성 / 환원주의 vs 창발 / 이론은 진리인가 도구인가 |
| 자주 나오는 구조 | 기존 개념 -> 설명 실패 -> 새 개념·모형 -> 귀결 (이론 논문형) / 사고 실험·반례를 통한 반박 |
| 대표 선지 함정 | 인식의 주체·대상을 뒤섞음 / 특정 학자의 '주장'을 보편 '사실'로 둔갑 / 가능(다중 실현될 수 있다)을 필연으로 / 조건 누락한 무조건적 확장 |

> [!example] 기출 제재 (docx 2·3장)
> - **기능주의·중국어 방·확장 인지 (2024학년도 6월)**: 동일론(심적 상태=뇌 상태), 기능주의(=기능적 역할, 다중 실현 가능), 로랜즈의 확장 인지(인지가 신체 외부로 확장될 수 있음). 존 설의 '중국어 방'은 기능(구문)과 이해(의미)를 분리하는 사고 실험. 함정은 주체성을 외부 사물에 귀속('노트북이 기억한다' vs '주체가 노트북을 통해 기억한다'), 확장 성립 조건(주체와의 통합) 누락.
> - **앙드레 바쟁의 영화 이론 (2025학년도 9월)**: 바쟁의 '믿음'과 정신분석학적 이론가들의 '주장' 대비. 오인(인식의 실패)을 다루며, 선지는 인식의 주체·대상을 뒤섞거나 바쟁의 '신념'을 영화의 '객관적 속성'으로 단정.
> - **에이어의 도덕주의·논리학 (2025학년도 6월)**: 전건 긍정·후건 부정 같은 논증 형식의 타당성을 직접 검증.

> [!note] 보조사 신호
> 'A는 ~라고 믿었으나, B는 ~라고 주장한다'에서 '~는'의 **대조**가 곧 화자 분리 신호. '안다'와 '믿는다/여긴다/간주한다/주장한다/본다'를 동사 단위로 추적.

### 1.4 ④ 정치·사회

| 항목 | 내용 |
|---|---|
| 빈출 소재 | 자유주의 vs 공동체주의, 개인주의 vs 구조주의, 현실주의 vs 자유주의(국제정치), 기능론 vs 갈등론, 본질주의 vs 구성주의(정체성), 문화자본·상징권력 |
| 꼭 아는 배경개념 | 분석 단위(개인·행위 vs 사회·제도·구조), 무연고적 자아 vs 연고적 자아, 통합 vs 지배·불평등, 변화 주체(엘리트 vs 대중) |
| 자주 나오는 구조 | 개인 행위 -> 제도 -> 집합 결과 (제도분석) / 쟁점 -> A -> B·반론 -> 저자 평가 (대립형) |
| 대표 선지 함정 | **층위 이동**(구조 설명을 개인 책임론으로, 미시를 거시로) / 특수 조건을 보편 명제로 / 부분과 전체 혼동 |

> [!warning] 핵심 함정 — 분석 수준의 이동
> 사회 영역은 '규범(해야 한다)과 인센티브(이익을 극대화한다)의 논리'다. 가장 자주 조작되는 지점은 **분석 수준의 이동** — 개인의 선택을 설명한 대목을 제도·구조의 결정으로, 또는 그 반대로 옮긴다.

> [!note] 보조사 신호
> 'A는 구조에 의해 결정된다'의 '는'을 전칭으로 비약시키지 말 것 — 본문이 한 측면만 대조한 것일 수 있다.

### 1.5 ⑤ 경제 (거의 매년)

| 항목 | 내용 |
|---|---|
| 빈출 소재 | 기축통화·트리핀 딜레마, 시장 효율 vs 시장 실패, 완전합리성 vs 제한된 합리성, 정보비대칭(역선택·도덕적 해이), 효율성 vs 형평성, 외부효과(피구세 vs 코즈 협상) |
| 꼭 아는 배경개념 | 모형은 가정 안에서만 성립, 변수 종속성(증가율·기울기), 단기 효율 vs 장기 안정성, 인과적 필연성과 상관관계의 구분 |
| 자주 나오는 구조 | 현상 단순화 -> 가정 -> 변수 -> 예측 -> 한계 (모형·가정형) / 두 목표의 모순 (딜레마형) |
| 대표 선지 함정 | 모형 결론을 현실 일반 명제로 / **상관을 인과로** / 인과 방향 역전 / 변수의 비례·반비례 관계를 반대로 |

> [!example] 기출 제재 (docx 4장)
> - **트리핀 딜레마·브레턴우즈 (2022학년도 11월)**: 기축통화국이 유동성 공급하려면 적자를 봐야 하고(A), 적자 지속되면 신뢰도 하락(B)하여 두 목표 동시 달성 불가능. 인과 사슬 '경상수지 적자 -> 달러 공급 증가 -> 준비 자산 신뢰도 하락'. 함정은 신뢰도 하락을 적자의 원인으로 역전하거나, 환율·통화 가치 관계를 반대로 서술.
> - **클라이버의 법칙·기초 대사량 (2023학년도 11월)**: 대사량은 체중의 0.75제곱에 비례. 체중이 늘면 대사량도 늘지만 증가율(기울기)은 1보다 작아 '체중 당 대사량'은 감소. 함정은 기울기 0.75를 '체중 비례(1.0)'나 '반비례'로 오독하고, '대사량'과 '체중 당 대사량'을 혼동(범주 오류). (수리·생물 경계 제재)

> [!note] 보조사 신호
> '유동성을 공급하려면 적자를 봐**야** 한다'의 '여야/야'는 **한정** — 적자가 유동성 공급의 **필요조건**. 이를 '적자면 유동성이 공급된다'(충분조건)로 뒤집으면 오답.

### 1.6 ⑥ 과학(생명·물리·화학) — 생명과학 빈출

| 항목 | 내용 |
|---|---|
| 빈출 소재 | 촉매·고분자 중합, 기초 대사량(상대 성장), 영상 안정화(OIS·DIS), 유전정보(DNA->RNA->단백질), 신호전달, 복제·PCR |
| 꼭 아는 배경개념 | 인과적 필연성(물리 법칙), 활성화 에너지·반응 속도, 환원주의적 설명(거시 물성 -> 미시 구조), 적절한 세기(단조 증가 아님), 음성·양성 피드백 |
| 자주 나오는 구조 | 입력 -> 단계 -> 변환 -> 출력 -> 피드백·오류 (과정·메커니즘형) / If-Then 조건문 연쇄 |
| 대표 선지 함정 | **인과 단계 누락·비약** / 비례 관계의 단선화·역전 / 단계 혼합 / 발현과 존재 혼동 / 피드백 방향 반전 |

> [!example] 기출 제재 (docx 4장)
> - **촉매·고분자 중합 (2025학년도 6월·2024학년도 6월)**: 개시제 분해 -> 불안정 원자 생성 -> 이중 결합 공격 -> 사슬 성장의 인과 기제. 거시 물성(단단함·녹는점)을 미시 분자 구조로 환원. 함정은 '촉매가 반응물의 화학적 성질을 변화시킨다'(실제로는 반응 경로·에너지만 변화)처럼 단계 비약, '흡착 세기가 강할수록 좋다'는 단선적 사고(적절한 세기 필요).
> - **클라이버의 법칙 (2023학년도 11월)**: 위 ⑤ 참조 — 수학적 모델링 기반 생물 제재.
> - **영상 안정화 OIS·DIS (2021학년도 6월)**: OIS는 렌즈 이동으로 빛 경로 굴절(물리적 보정, 화질 저하 없으나 범위 제한), DIS는 센서 이동·크롭으로 좌표 보정(소프트웨어, 범위 넓으나 화질·화각 손실). 함정은 두 방식 장단점을 교차시키거나, 보정과 촬영의 시간 순서를 왜곡.

> [!note] 보조사 신호
> 과정형에서는 보조사보다 동사·접속이 핵심이지만, '촉매**조차** 성질을 바꾼다'처럼 '조차'(극단 첨가)가 나오면 예상 밖 강한 단정이므로 본문 확인 대상.

### 1.7 ⑦ 기술·공학

| 항목 | 내용 |
|---|---|
| 빈출 소재 | 블록체인 합의 알고리즘, 3D 모델링·렌더링 파이프라인, 통신 부호화·변조·오류정정, 제어·피드백 시스템 |
| 꼭 아는 배경개념 | 절차의 불가역적 순서, 각 단계 데이터가 다음 단계의 필요조건, 무결성, 작업증명, 트레이드오프 |
| 자주 나오는 구조 | A단계 -> B단계 -> C단계 (시제·절차형, 순서 불가역) |
| 대표 선지 함정 | **단계 혼합**(뒤 단계 작업을 앞 단계에서 한다고) / 시간 순서 왜곡 / 가능성의 과장(이론상 가능을 빈번한 것으로) / 인과 단절 |

> [!example] 기출 제재 (docx 4장)
> - **블록체인 합의 알고리즘 (2025학년도 9월)**: 과반수 연산력 가진 공격자가 없다면 데이터 변경 불가능. 해시값 찾는 연산을 수행해야만 블록 생성 가능(절차적 필연성). '데이터가 무단 변경되기 어렵다'는 성질이 무결성. 함정은 이론적으로 가능한 해킹을 현실적으로 빈번한 것으로, 또는 작업증명 없이 합의 가능한 것처럼 인과 단절.
> - **3D 모델링·렌더링 (2021학년도 12월)**: 모델링(정점 좌표) -> 시점 변환 -> 투영 -> 렌더링(화솟값)의 순서가 불가역. 렌더링 계산은 모델링 데이터에 의존. 함정은 렌더링 단계의 질감 처리를 모델링 단계에서 한다고 서술하는 단계 혼합.

> [!note] 보조사 신호
> '연산을 수행해**야만** 블록을 생성할 수 있다'의 '야만'은 **한정** — 연산 수행이 블록 생성의 필요조건. '공격자가 없**다면**'의 '~면'은 조건절이므로 무조건 단정으로 바꾸면 오답.

### 1.8 ⑧ 역사·문학비평·예술

| 항목 | 내용 |
|---|---|
| 빈출 소재 | 예술의 정의(모방론·표현론·형식론·제도론), 아도르노 예술관, 헤겔 변증법·미학, 한비자의 노자 해석, 역사 서술(객관 복원 vs 관점 구성) |
| 꼭 아는 배경개념 | 작품 사실 vs 해석자 주장, 반례에 의한 정의 논파, 정-반-합(지양), 자율성 vs 사회성, 연속 vs 단절, 직관(예술)·표상(종교)·사유(철학) 대응 |
| 자주 나오는 구조 | 대상 -> 기존 해석 -> 한계 -> 새 해석 기준 -> 근거 (해석·비평형) / 초기 -> 전환 -> 현재 의미 (역사발전형) |
| 대표 선지 함정 | 작품 사실과 해석 혼동 / **시간 착오**(후대 개념을 전대 입장으로) / 관점 혼재(원사상 vs 재해석) / 위상 교란(대응 관계 뒤섞기) / 가치 판단 전도 |

> [!example] 기출 제재 (docx 3·4장)
> - **예술의 정의 (2021학년도 9월)**: 모방론·표현론·형식론이 반례에 의해 논파되는 과정. 뒤샹의 '샘'은 형식론의 필요조건(미적 형식)을 충족하지 않지만 예술로 인정받으므로 형식론은 예술의 필요조건이 아님이 증명됨(분석철학적 논증).
> - **아도르노의 예술관 (2023학년도 9월)**: 예술은 사회의 부조리를 드러내야 한다(당위), 대중예술은 '동일성(표준화)'을 강요해 비판 의식을 마비. 예술은 사회적 산물이면서 사회와 거리를 둬야 하는 역설(자율성). 함정은 아도르노가 비판한 것이 '기술적 완성도'가 아니라 '이데올로기적 기능'임을 간과, 또는 조화롭고 아름다운 예술을 아도르노에게 긍정적인 것으로 오인.
> - **헤겔 변증법·미학 (2022학년도 11월)**: 정-반-합의 지양, 직관(예술)·표상(종교)·사유(철학) 체계와 그 비판. 함정은 세 대응 관계를 뒤섞는 위상 교란, '종합'을 단순 '절충'이나 '병렬'로 왜곡.
> - **한비자와 노자 (2024학년도 11월)**: 한비자가 노자의 '도' 개념을 가변적·시비 판단의 근거로 재해석. 함정은 노자의 원래 사상과 한비자의 재해석을 구분 못하게 함('한비자는 도가 불변한다고 보았다'는 오답 — 한비자는 가변성 주장).

> [!note] 보조사 신호
> '한비자**는** 도가 가변적이라 보았다'의 '는'은 **대조**(노자와 갈림)의 신호. 화자별 입장을 '~는'으로 끊어 분리. '예술**조차** 동일성에 포섭된다'의 '조차'는 극단 첨가 — 가장 의외인 것까지 포함된다는 강한 단정.

### 1.9 제재 공통 — 보조사를 독해 신호로 쓰는 법

| 보조사 | 논리 기능 | 독해 신호 | 함정 |
|---|---|---|---|
| 은 / 는 | 주제·**대조** | 화자·입장 분리, '다른 것은 다를 수 있음' | 대조를 전칭이나 한정으로 비약 |
| 만 / 뿐 / 밖에 / 여야 | 한정(only) | 'A여야 B'에서 A는 **필요조건** | 'A만 B'를 'A이면 B'(충분조건)로 오독 |
| 도 | 첨가(also) | 'A도 B'면 다른 것도 B(포함 함축) | 'A도'를 'A만'으로 뒤집기 |
| 조차 / 마저 | 극단 첨가(even) | 가장 의외인 것까지 — 강한 단정, 본문 확인 | 예상 밖 단정을 무조건 일반으로 |
| 까지 | 척도 끝(up to) | 범위를 끝까지 확장 | 범위 과장 |
| 마다 | 분배 전칭(each) | '모든' 함축 | 특칭('어떤')으로 약화 오독 |
| (이)나 / 라도 | 선택·양보 | '라도'는 양보(충분조건 아님) | 양보를 충분조건으로 |

> [!check] 1순위 점검 순서
> - **양상(가능/필연)·수량(일부/모두)·조건(필요/충분)**을 바꾼 선지가 모든 제재의 1순위 오답이다.
> - 보조사는 본문이 이미 깔아둔 한정·대조·첨가 신호 — 선지가 그 신호를 **반대로 뒤집었는지**를 먼저 점검한다.
