## 3. 선지 조작 패턴

> [!tip] 시험장 코어
> - 오답은 본문 어휘를 그대로 쓰되 **관계·범위·태도·주체**를 바꾼다.
> - 판정 질문: "본문에 나온 말인가"가 아니라 "그 말이 맡은 **기능이 같은가**".
> - 5대 조작만 외운다: 양상 대치 / 범위 조작 / 인과 재구성 / 인식론적 간극 / 메타인지 함정.
> - 소거 순서: 주체 -> 관계(인과·조건) -> 범위 -> 태도 -> 층위.
> - 마지막 둘이 남으면 **본문 구조를 더 보존한 쪽**이 정답.

| 조작 | 한 줄 | 핵심 신호어 |
|---|---|---|
| **양상 대치** | 가능을 필연으로, 조건을 단정으로 격상 | ~일 수 있다 -> 반드시 / ~면 -> 항상 |
| **범위 조작** | 어떤을 모든으로, 부분을 전체로 확장 | 어떤·일부·대체로 -> 모든·항상·전부 |
| **인과 재구성** | 화살표 역전·공통원인 무시·단계 비약 | ~때문에 / ~의 결과 / 따라서 |
| **인식론적 간극** | 주장·믿음을 사실로 격상 | 주장한다·여긴다 -> 밝혀졌다·이다 |
| **메타인지 함정** | 비교·지칭·전략 판단을 미세하게 비틂 | 전자·이러한 / 전략을 유지·수정 |

---

### 3.1 정답 선지의 일반형

> [!note] 정답은 본문을 **추상화하거나 제한**한다. 강한 단정보다 조건부·유보 표현이 정답 확률이 높다.

| 정답 유형 | 특징 | 통과 기준 |
|---|---|---|
| 추상화형 | 본문 표현을 더 추상적인 말로 치환 | **관계가 보존되면** 정답 가능 |
| 재배열형 | 여러 문단 정보를 묶음 | 순서·조건이 보존되어야 함 |
| **제한형** | 강한 표현 대신 조건부 표현 사용 | 지문의 유보와 일치하면 정답 |
| 구조형 | 문단 기능(배경/문제/반론/결론)을 물음 | 기능이 맞는지 확인 |
| 적용형 | 새 사례를 지문 원리에 맞춤 | 사례 요소가 어느 변수에 대응하는지 |
| 함의형 | 직접 표현은 없으나 구조상 따라 나옴 | 전제에서 필연 또는 강하게 지지되는지 |

> [!tip] 정답 감별 한 줄
> 정답은 본문보다 **약하거나 같고**, 오답은 본문보다 **강하거나 다르다**. 양상어·수량어가 본문보다 세지면 오답을 의심한다.

---

### 3.2 양상 대치 (가능->필연, 조건->단정)

> [!note] 지문의 양상 표현을 한 칸 격상해 진리 조건을 바꾼다. **가장 흔한 변형**.

| 세부 조작 | 설명 | 신호어 (이렇게 바뀌면 의심) |
|---|---|---|
| **가능의 필연화** | 'P일 수 있다'를 '반드시 P'로 | ~을 수 있다·~일지 모른다·개연성 -> 반드시·필연적·~일 수밖에 없다 |
| **조건의 단정화** | 'C면 P'를 '항상 P'로 (조건 삭제) | ~면·~경우에 -> 항상·언제나·무조건 |
| 빈도 과장 | '대체로·일부'를 '항상·모두'로 | 흔히·주로·대개 -> 늘·예외 없이 |
| 허용의 의무화 | '해도 된다'를 '해야 한다'로 | ~어도 된다·허용된다 -> ~어야 한다·의무가 있다 |
| 한계의 전면화 | '일부 한계'를 '전면 무효'로 | 다만·일부 미흡 -> 폐기·전면 부정 |

> [!warning] 즉시 소거 질문
> **"양상어가 본문보다 강해졌나?"** 본문이 '가능·시사·~수 있다'였는데 선지가 '반드시·항상'이면 거의 오답.

---

### 3.3 범위 조작 (전칭·특칭, 부분·전체)

> [!note] 명사가 가리키는 집합의 크기를 바꾼다. **보조사**가 이 조작의 표지가 된다.

| 세부 조작 | 설명 | 신호어 |
|---|---|---|
| **적용 범위 확대** | 특정 조건의 명제를 일반 명제로 | 어떤·일부 -> 모든·전부 |
| 적용 범위 축소 | 일반 주장을 특정 사례로 한정 | 모든·일반적으로 -> 그 경우에만 |
| **전칭·특칭 혼동** | '어떤 X는 P'를 '모든 X는 P'로 (또는 반대) | 어떤·있다 <-> 모든·마다 |
| **부분·전체 혼동** | 부분 속성을 전체 속성으로 둔갑 | 렌즈가 움직인다 -> 카메라가 움직인다 |
| 표본·모집단 혼동 | 제한 표본을 전체로 일반화 | 조사 대상에서 -> 일반적으로·전체 |
| 유사성 과장 | 일부 유사를 본질 동일로 | 비슷하다 -> 같다·동일하다 |
| 차이성 과장 | 차이 하나를 완전 대립으로 | 다른 점도 있다 -> 정반대·양립 불가 |

> [!warning] 즉시 소거 질문
> **"수량어가 바뀌었나? 부분이 전체로 커졌나?"**

보조사 함정 (범위·한정의 표지) — 표에 항상 대입한다:

| 보조사 | 논리 기능 | 대표 함정 |
|---|---|---|
| 만 / 뿐 / 밖에 | 한정(only). 'A여야(만) B'는 A가 B의 **필요조건** | 'A만 B'를 'A이면 B'(충분조건)로 오독. '밖에'는 부정과 결합('A밖에 없다'=오직 A) |
| 도 | 첨가(also). 'A도 B'는 **다른 것도 B**라는 함축 | 'A도'를 'A만'으로 뒤집기 |
| 조차 / 마저 | 극단 첨가(가장 의외인 것까지). 'A조차 B'면 나머지는 당연히 B | 부정·예상밖 맥락을 일반 긍정으로 처리 |
| 까지 | 척도 끝. 범위를 A 끝까지 확장 | 확장 끝점을 시작점·일부로 축소 |
| 은 / 는 | 주제·대조. 'A는 B'는 '다른 것은 아닐 수 있음' 함축 | 대조를 전칭·한정으로 비약 |
| 마다 | 분배 전칭(each=모든) | 특칭(어떤)으로 약화 오독 |
| (이)나 | 선택·근사 | 근사치를 확정치로 |
| 라도 | 양보(even if). **충분조건 아님** | 양보를 충분조건으로 격상 |

> [!warning] 핵심
> **'만·여야'를 보면 그것은 필요조건이지 충분조건이 아니다.** 'A여야 B'에서 'A이면 B'를 끌어내면 오답.

### 3.4 인과 재구성 (역전·공통원인 무시·단계 비약)

> [!note] 인과 사슬의 방향을 바꾸거나 중간을 생략해 비약을 만든다. **과학·과정형 지문의 주력 함정**.

| 세부 조작 | 설명 | 신호어 |
|---|---|---|
| **인과 역전** | 'A가 B를 일으킨다'를 'B가 A를 일으킨다'로 | ~때문에·~의 결과·따라서 (방향 확인) |
| **상관의 인과화** | 함께 변한 것을 원인으로 단정 | 함께·동시에·비례하여 -> ~때문에·원인 |
| 결과의 원인화 | 결과를 원인처럼 제시 | 시간 순서 역전 |
| **매개 단계 생략** | 'A->중간->B'를 'A->B'로 단순화 | 곧바로·직접·따라서 (중간 조건 누락) |
| 공통원인 무시 | A가 B·C의 공통 원인인데 B가 C의 원인인 양 서술 | ~가 ~를 낳는다 (제3 원인 확인) |
| 피드백 방향 오류 | 억제<->촉진, 음성<->양성 되먹임 반전 | 줄인다 <-> 늘린다·증폭한다 |
| 단계 순서 바꿈 | 절차의 선후를 뒤섞음 | ~한 후에·먼저·앞서 (순서 확인) |

> [!warning] 즉시 소거 질문
> **"화살표 방향이 맞나? 중간 단계가 빠졌나?"** 상관을 본문이 인과라고 단정했는지도 확인.

---

### 3.5 인식론적 간극 (주장->사실)

> [!note] '사실'과 '주장·믿음' 사이의 간극을 이용한다. **주체를 뒤섞는 것**이 핵심.

| 세부 조작 | 설명 | 신호어 |
|---|---|---|
| **주장의 사실화** | 특정 학자의 '주장·믿음'을 보편 '사실'로 격상 | 주장한다·여긴다·본다 -> 밝혀졌다·입증되었다·이다 |
| **주체 바꾸기** | A 견해를 B 견해로 제시 | 누가 말했나 (학자명 대응) |
| **저자 귀속 오류** | 소개된 견해를 저자 주장으로 둔갑 | 저자가 지지했나, 소개만 했나 |
| 관점 혼합 | A 결론에 B 전제를 섞음 | 한 사람 입장으로 일관되나 |
| 관찰·해석 혼동 | 자료 결과와 연구자 해석을 뒤섞음 | 측정값인가 설명인가 |
| 사실·가치 혼동 | 'X이다'를 'X여야 한다'로 | 그러하다 -> 그래야 한다·바람직하다 |
| 원인·이유 혼동 | 발생 원인을 정당화 이유로 | 왜 생겼나 vs 왜 옳은가 |
| 방법·결론 혼동 | 방법이 우수하니 결론이 참이라고 | 방법이 무엇을 보장하나 |

> [!warning] 지식 vs 믿음
> '안다·밝혀지다·입증되다'는 참을 함축하지만, '믿는다·주장한다·여긴다'는 참을 보장하지 않는다. 선지가 **믿음 표지를 지식 표지로 바꿨으면** 오답.

> [!warning] 즉시 소거 질문
> **"이건 사실인가, 누군가의 주장인가? 누가 말했나?"**

---

### 3.6 메타인지 함정

> [!note] 독해 전략·비교·지칭 자체를 미세하게 비튼다. **최근 고난도 지문의 변별 포인트**.

| 세부 조작 | 설명 | 신호어 |
|---|---|---|
| **지시어 오인** | '이러한·전자의·이 과정'의 지칭 대상을 가장 가까운 명사로 단정 | 이·이러한·전자·후자·그 (실제 선행 내용 확인) |
| **비교 기준 변경** | A와 B를 서로 다른 기준으로 비교 | 비교 축이 같나 |
| 특성의 교차 | A의 장점을 B의 장점으로 옮김 | A는~ B는~ (대조 표지 확인) |
| 층위 이동 | 개인 설명을 제도 설명으로, 관찰을 해석으로 이동 | 분석 단위가 맞나 |
| 전략 판단 전도 | '수정해야 할 상황'에서 '유지'를, 또는 반대를 제시 | 전략을 유지·수정·점검 |
| 쟁점 이탈 | 논쟁 질문과 다른 질문에 답함 | 같은 물음에 답하나 |
| 형량의 절대화 | 가치 비교를 한 가치의 절대 우위로 | 조건부 우위인가 |
| 원칙·예외 전도 | 예외를 원칙처럼 제시 | 원칙적으로 vs 예외적으로 |

> [!warning] 즉시 소거 질문
> **"전자·이러한이 가리키는 게 정말 가장 가까운 명사인가, 앞 문장 전체 구조인가?"** 지칭 대상은 보통 직전 문장 전체이거나 앞 단락의 핵심 관점이다.

### 3.7 발문별 선지 처리

| 발문 | 먼저 볼 것 | 우선 소거 대상 |
|---|---|---|
| 주제·제목 | 마지막 회수 구조, 문제-결론 대응 | 너무 좁은 예시형 / 너무 넓은 배경형 |
| 구조 | 단락 기능 | 내용은 맞지만 **기능이 틀린** 선지 |
| 세부 일치 | 지문 위치와 조건 | 단어는 같은데 **관계가 다른** 선지 |
| 추론 | 명시 전제와 조건 | **가능성을 필연화**한 선지 |
| 적용(보기) | 보기 요소와 지문 변수 대응 | 변수 매핑 오류 |
| 평가 | 근거의 취약점 | 대안 원인·표본 편향·통제 실패 무시 |
| 비교 | 공통 쟁점과 차이 축 | 한 글 용어를 **다른 글에 무단 이전** |
| 태도 | 평가어·양상어 | 중립을 지지·비판으로 과장 |

### 3.8 한 줄 결론

> [!check] 선지는 **양상·범위·인과·주체·지칭** 다섯 자리 중 하나를 바꿔 오답이 된다.
> - 단어 일치가 아니라 **그 단어가 본문에서 맡은 기능의 보존 여부**로 판정한다.
> - 본문보다 강해지거나(양상·범위), 방향이 뒤집히거나(인과·주체), 가리키는 대상이 어긋나면(지칭) 소거한다.
