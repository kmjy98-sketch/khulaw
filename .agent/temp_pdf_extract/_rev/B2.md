## 2. 전개 방식 압축 지도

> [!tip] 시험장 코어
> - 첫 문단에서 단 하나만 가른다: 이 글이 '정보 흐름형'인가 '관점 충돌형'인가. 충돌형이면 즉시 **대립형 모드**.
> - 흐름형이면 전개 엔진 9개 중 하나로 좁힌다(과정 / 논문 / 정의분류 / 문제해결 / 역사발전 / 모형가정 / 단일이론 / 해석비평 / 법리규범). 열 번째 비교융합형은 두 글이 나란히 나올 때.
> - 유형이 정해지면 다음 문단이 무엇을 할지 예측된다. 내용 암기가 아니라 **선지가 그 관계를 보존했는지**만 검사.
> - **빈출 3대 엔진**: 과정·메커니즘형(자연과학·기술), 논문형(전 분야), 대립형(인문·사회). 이 셋을 먼저 자동화.
> - 대립형은 단 셋만: **화자 분리 · 쟁점 축 · 저자 태도**.

### 2.1 첫 문단 30초 판별 흐름

위에서 아래로 묻고, 먼저 걸리는 곳에서 멈춘다.

1. 두 입장·학자·"그러나/반면/비판"이 보이는가? -> **대립형**. (이 신호가 최우선. 보이는 즉시 다른 판별 중단.)
2. 연구·자료·실험·가설·결과를 말하는가? -> **논문형**.
3. 현상·장치·원리가 단계로 움직이는가? -> **과정·메커니즘형**.
4. 정의·유형·기준·구분을 세우는가? -> **정의·분류형**.
5. 문제·난점·한계·대안을 말하는가? -> **문제해결형**.
6. "과거에는·이후·전환·변화"로 시간이 흐르는가? -> **역사발전형**.
7. 가정·변수·모형을 설정하는가? -> **모형·가정형**.
8. 작품·해석·비평·평가가 대상인가? -> **해석·비평형**.
9. 원칙·요건·예외·형량이 보이는가? -> **법리·규범 적용형**.
10. 하나만 깔끔하게 잡히고 반대 견해가 없으면 -> **단일 이론 전개형**.
11. 두 글이 나란히 제시되면 -> **비교·융합형**(각 글을 따로 잡고 관계 설정).

> [!warning] 법학 지문 함정
> 단일이론형처럼 보여도 실제는 요건-효과·예외가 핵심인 **법리형**인 경우가 많다. "원칙·요건·예외"가 한 번이라도 보이면 법리형으로 읽는다.

### 2.2 전개 엔진 압축 표 (대립형 제외)

각 유형을 '핵심 흐름 + 마킹 포인트 + 대표 함정'으로 압축. '->'는 '그다음'으로 읽는다.

| 유형 | 핵심 흐름 | 마킹 포인트 | 대표 함정 |
|---|---|---|---|
| **과정·메커니즘형** (빈출) | 입력·자극 -> 수용·탐지 -> 매개·전달 -> 변환·처리 -> 출력·반응 -> 피드백·조절 -> 오류·예외 | 명사 뜻이 아니라 동사·방향·순서·조건을 추적. 'A가 B를 일으킴', 순서 1·2·3, 'C가 있어야 작동', 억제 지점, 피드백이 원인을 줄이는지 늘리는지 | **인과 역전**, **단계 생략**(매개 빼고 직접 원인화), **조건 역전**(A가 필요조건인데 A만 있으면 B), 억제 지점 오류, **피드백 방향 반전** |
| **논문형** (빈출) | 연구 문제 -> 선행 연구·통념 -> 한계·공백 -> 방법·자료 -> 결과 -> 해석 -> 함의·한계 | 연구 질문과 결론이 대응하는가. 자료(관찰)와 해석(설명)을 분리. 표본 범위, 독립·종속변수, 통제·대안 원인 | **결과와 해석 혼동**, **상관을 인과로 단정**, **표본을 모집단으로 일반화**, 방법 우수함을 결론의 참으로 확대, **선행 연구 주장을 저자 결론으로 둔갑** |
| **단일 이론 전개형** | 현상·문제 -> 핵심 개념 -> 작동 원리 -> 사례·적용 -> 적용 범위·한계 -> 함의 | 핵심 명제와 적용 조건. '조건 C에서 결과 R'. 한계·예외가 어디서 걸리는지 | **적용범위 확대**("특정 조건에서만"을 보편 법칙으로), 전제-결론 위치 바꾸기, **예시의 일반화**, 배경을 중심 주장으로 |
| **정의·분류형** | 개념 도입 -> 기존 정의·통념 -> 기준 제시 -> 하위 유형 분류 -> 경계 사례 -> 의의 | "용어를 아는가"가 아니라 분류 기준을 지키는가. 기준이 하나인지 둘 이상인지, 필요/충분조건인지, 애매 사례를 어디 넣는지 | **기준 바꿔치기**(기능 기준인데 발생 원인 기준으로), 상위·하위 혼동, **필요조건의 충분조건화**, 경계 사례를 명백 사례로 처리 |
| **문제해결형** | 문제·난점 -> 원인 -> 기존 해법의 한계 -> 새 해법·대안 -> 평가 -> 남은 문제 | 반드시 문제와 해법의 대응 확인. 새 해법이 어떤 원인을 겨냥하는지, 성공 조건과 부작용 | **문제-해법 불일치**, 원인·증상 혼동, 기존 해법 장점 삭제(부분 인정을 전면 부정으로), 새 해법 조건 누락·일반화 |
| **역사발전형·통시형** | 초기 상태 -> 변화 압력·전환 계기 -> 중간 단계 -> 새 체계 -> 현재적 의미 | 단순 연표 아님. 무엇이 왜 바뀌었는지, 지속된 것과 폐기된 것, 발전으로 보는지 왜곡으로 보는지 | **시대 착오**(후대 개념을 전대 입장으로), 원인·결과 위치 바꾸기, **연속/단절 혼동**, 역사적 설명과 규범적 평가 뒤섞기 |
| **모형·가정형** | 현상 단순화 -> 가정 설정 -> 변수 정의 -> 작동 원리 -> 예측 -> 가정 완화·한계 | 모형은 특정 측면용 장치. 가정과 결론의 연결, 변수 방향(X가 늘면 Y는?), 가정이 깨지면 결론도 약화 | **가정 삭제**(가정 성립 시 결론을 현실 일반으로 확장), 변수 방향 반전, **모형 목적 오독**(예측 모형을 규범 주장으로), 상호작용을 단선 인과로 단순화 |
| **해석·비평형** | 작품·현상 -> 기존 해석 -> 기존 해석의 한계 -> 새 해석·비평 기준 -> 근거 -> 의의 | 해석 기준이 무엇인지(형식·표현·사회성·역사성·작가 의도·독자 수용), 저자가 전면 부정인지 보완인지 | **작품 사실과 해석 혼동**, 해석 기준 바꾸기, **비판 강도 과장**(보완을 전면 부정으로), 대상 혼동(작품·작가·독자·시대) |
| **법리·규범 적용형** | 규범·원칙 -> 요건 -> 효과 -> 예외 -> 사례 적용 -> 형량·결론 | 요건-효과·예외·형량이 핵심. 요건이 모두 충족됐는지, 사례 사실이 어느 요건에 대응하는지, 충돌 가치가 무엇인지 | **원칙과 예외 뒤섞기**, **요건 일부 충족을 전체 충족으로**(A·B·C 모두 필요한데 A만 보고 결론), 규칙 판단과 가치 형량 혼동, **현행법과 당위론 혼동** |
| **비교·융합형** | A 글 중심 주장·구조 -> B 글 중심 주장·구조 -> 공통 주제 -> 차이의 축 -> 상호 평가 | 두 글을 한꺼번에 외우지 않음. 각 구조를 따로 잡은 뒤 관계 설정(동의·부분동의·정면대립·원칙-사례·이론-비판·방법차이·수준차이) | A 글 용어가 B 글에서도 같은 뜻이라 가정, B가 A 전체를 비판하는지 일부만인지 놓침, **지시어 오인**("전자의 견해"를 가까운 명사로 착각), 두 글이 다른 질문에 답하는데 같은 질문으로 봄 |

### 2.3 빈출 분야 템플릿 — 과정형 하위 (자연과학·기술)

과정형 중 다음 흐름이 반복 출제된다. 단계별 방향성과 함정이 다르므로 분리한다.

| 분야 흐름 | 핵심 흐름 | 대표 함정 |
|---|---|---|
| **유전 정보형** | DNA -> RNA -> 단백질 -> 기능·형질 | **유전자 존재와 발현 혼동**, 전사량과 단백질 기능을 무조건 비례시킴 |
| **DNA 복제형** | 주형 분리 -> 상보 결합 -> 새 가닥 합성 -> 오류 수정 -> 산출 | **주형 가닥과 새 가닥 뒤바꿈**, 상보 결합 규칙 역적용, 효소 작용 단계 오류, 오류 수정 시점(복제 전/후) 혼동 |
| **PCR·시퀀싱형** | 가열 분리 -> 프라이머 결합 -> 중합효소 연장 -> 반복 증폭 -> 표지·판독 -> 원서열 추론 | 프라이머가 표적 구간을 정한다는 점 누락, **증폭의 누적성 무시**, 관찰 신호와 원래 DNA 혼동, 역추론 방향 반전 |
| **세포 신호전달형** | 리간드·자극 -> 수용체 결합 -> 세포 내 전달 연쇄 -> 증폭·분기 -> 표적 반응 -> 종료·피드백 | 신호가 수용체 '안으로 들어간다'고 오해(실제는 결합이 변화를 유발), 증폭을 1대1로 단순화, 분기 경로 하나를 전체로 일반화, **피드백 방향 반전** |
| **통신·정보형** | 정보원 -> 부호화·압축 -> 변조 -> 채널 전송 -> 잡음·손실 -> 수신 -> 복조·복호화 -> 오류정정 -> 피드백 | 신호 세기 증가를 정보량 증가로 오해, 압축·암호화·부호화 혼동, 채널 용량과 실제 전송률 혼동, **암호화가 오류를 고친다고 오해**, 중복성을 비효율로만 이해 |
| **제어·피드백 시스템형** | 목표값 -> 센서 측정 -> 제어기 비교 -> 구동기 작동 -> 출력 -> 피드백 -> 안정화 또는 진동 | **음성 피드백(오차 감소·안정화)과 양성 피드백(변화 증폭) 반전**, 피드백 지연 효과 누락, 측정 잡음이 실제 상태를 왜곡함을 무시 |

### 2.4 대립형 — 핵심만

대립형의 본질은 '내용'이 아니라 **입장의 위치 관계**다. 누가 무엇을 주장하고 누구를 비판하며 저자가 어느 정도 개입하는지를 분리한다. 시험장에서는 다음 셋만 잡으면 된다.

> [!check] 화자 분리 — 여백에 즉시 적는다 (관점 혼동 오답 차단)
> - 쟁점 Q: 두 입장이 실제로 같은 질문에 답하는가?
> - A: 결론 / 근거 / 약점
> - B: 결론 / 근거 / **A의 어디를 비판하는가**(결론인가 전제인가 방법인가)
> - 저자: 지지 / 비판 / 중립 / 양쪽 비판 / 종합 / 유보 중 하나

> [!note] 쟁점 축 — A·B를 길게 적기 전에 '무엇으로 갈리는지' 한 줄 먼저
> 거의 모든 대립은 다음 보편 축 중 하나로 환원된다: 실재/구성, 보편/특수, 내부/외부, 구조/행위, 의도/결과, 규칙/원리, 사실/가치, 원인/이유, 환원/창발, 형식/내용, 효율/형평, 자유/질서, 예측/설명.

**변증법 3구조** — '정·반·합'은 단일하지 않다. 셋으로 갈린다.

| 변증법 세부형 | 구조 | 읽는 법 |
|---|---|---|
| **보완적 합** | A가 놓친 점을 B가 보완해 새 이론 C가 됨 | C가 A와 B 중 무엇을 각각 수용했는지 표시 |
| **초월적 합** | A와 B가 공유한 전제 자체를 넘어섬 | "둘 다 틀린 이유"가 핵심 |
| **조건부 합** | 상황에 따라 A·B가 각각 타당 | 적용 조건을 분리 |

> [!warning] 대립형 대표 함정
> - **합을 단순 절충(반반 섞기)으로 오해**. 실제 합은 쟁점의 차원 자체를 바꾸는 경우가 많다(특히 초월적 합).
> - **반론이 정설 전체를 부정한다고 과장**. 많은 지문은 정설의 일부만 수정한다.
> - **소개와 지지를 혼동**. 저자가 B를 소개했다고 B를 지지하는 것은 아니다.
> - A의 한계를 말했어도 A의 모든 내용을 버리는 것은 아니다.
> - **저자 태도 귀속 오류**. 양쪽 비판형인데 저자를 A나 B 한쪽으로 귀속시킨다.

**대립형 하위 구조 빠른 식별**

| 하위형 | 흐름 | 저자 태도 | 대표 함정 |
|---|---|---|---|
| 단순 양자 대립 | A 주장, B 반박 | 한쪽 지지 또는 중립 | A 주장에 B 전제 섞기 |
| 정설-수정형 | 정설, 한계, 수정 이론 | 수정 지지 | **정설 전면 폐기로 과장** |
| 변증법형 | 정, 반, 합 | 제3안 제시 | **합을 절충으로 오해** |
| 논쟁 소개형 | A·B·C 병렬 소개 | 중립 | 저자 입장 있다고 착각 |
| 비판-방어형 | A 비판, A 방어·재구성 | A의 세련된 형태 지지 | 원래 A와 수정 A 혼동 |
| 양쪽 비판형 | A 한계, B 한계, 새 기준 | 양쪽 모두 비판 | 저자를 A나 B로 귀속 |
| 가치 형량형 | 가치 A 대 가치 B | 균형·우선순위 제시 | 한 가치를 절대화 |

### 2.5 표지어·보조사로 전개를 잡는다

전개 방식과 화자 전환은 표지어가 신호한다. **보조사의 논리 기능**까지 읽어야 선지 조작을 잡는다.

| 표지어·보조사 | 신호 기능 | 함정 |
|---|---|---|
| 그러나·반면·하지만 | 전환·대립 진입 | 전환 뒤 입장이 **저자 결론인지 반대 견해인지** 분리 실패 |
| 따라서·그러므로·결국 | 결론·함의 도출 | 중간 결론을 최종 결론으로 오인 |
| 예컨대·가령 | 예시(근거 보조) | **예시를 원리 전체로 일반화** |
| 즉·다시 말해 | 환언(재진술) | 재진술을 새 주장으로 오인 |
| 만 / 뿐 / 밖에 | 한정(오직). 'A여야(만) B'는 A가 B의 **필요조건** | **'A만 B'를 'A이면 B'(충분조건)로 오독** |
| 도 | 첨가(또한). 'A도 B'는 A를 포함해 다른 것도 B | 'A도'를 'A만'으로 뒤집기 |
| 조차 / 마저 | 극단 첨가(가장 의외인 것까지). 'A조차 B'면 나머지는 당연히 B | 극단 사례를 일반 사례로 평탄화 |
| 까지 | 척도 끝(범위를 A 끝까지 확장) | 범위 끝점을 전체 범위로 오인 |
| 은 / 는 | 주제·대조. 'A는 B'는 '다른 것은 B가 아닐 수 있음'을 함축 | **대조를 전칭이나 한정으로 비약** |
| 마다 | 분배 전칭(각각=모든) | **특칭으로 약화 오독** |
| (이)나 | 선택·근사 | 근사치를 정확값으로 처리 |
| 라도 | 양보(설령 그렇더라도). **충분조건이 아님** | 양보절을 충분조건으로 오독 |

### 2.6 한 줄 정리

> [!tip] 한 줄 정리
> 첫 문단에서 **정보 흐름형인가 관점 충돌형인가**를 가르고, 흐름형이면 9개 엔진 중 하나로 좁혀 '핵심 흐름·마킹·함정'을 적용한다. 충돌형이면 **화자 분리 · 쟁점 축 · 저자 태도** 셋만 잡고, 변증법은 **보완적 합 · 초월적 합 · 조건부 합** 셋으로 나눠 읽는다. 끝까지 검사할 것은 하나 — 선지가 본문의 관계(주체·인과·조건·범위·태도)를 보존했는가.
