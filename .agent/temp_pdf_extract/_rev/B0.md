## 0. 시험장 최상위 알고리즘

> [!tip] 시험장 코어
> 지문을 받으면 같은 순서로 처리한다.
> - **첫 문단으로 글 종류·축 판별** -> 축 먼저 읽기 -> 판정 가능한 꼴(규칙·전제·함수)로 메모 -> 선지 8항목 검사 -> 소거
> - 내용을 다 이해하려 들지 말고, **선지가 본문의 관계를 보존하는지**만 빠르게 판정한다.
> - 한 문장 요약: 첫 문단으로 종류·축을 잡고, 축을 먼저 읽고, 판정 가능한 꼴로 메모한 뒤, 선지가 주체·관계·범위·태도를 보존하는지만 본다.
> - 고득점은 지식이 아니라 **방향을 안 뒤집고, 강도를 안 키우고, 주체를 안 섞는 것**에서 나온다.

| 단계 | 한 줄 행동 | 5초 체크 |
|---|---|---|
| 1 글 종류·축 판별 | 첫 문단 + 첫 문제 선지로 전개 엔진과 축을 못박는다 | 무엇과 무엇이 갈리는가 |
| 2 축 먼저 읽기 | A·B 내용보다 **갈리는 기준(축)**을 먼저 적는다 | 'A는 뭐, B는 뭐'를 길게 쓰지 않는다 |
| 3 판정 가능한 꼴로 메모 | 주장·근거·조건·양화·양상·변수만 표시 | 전부 기호화하지 않는다 |
| 4 선지 8항목 검사 | 주체·관계·조건·양상·층위·시간·평가·쟁점 중 무엇을 바꿨나 | 본문 관계를 보존하나 |
| 5 소거 | 본문보다 센 선지·주체 섞인 선지부터 제거 | **가능<->필연, 일부<->전부** |

> [!note] 시간 큰 그림 (70분·30문항)
> 평균 문항당 약 2분 20초. 단, 운영은 문항이 아니라 **지문 묶음 단위**로 한다. 지문 1개 = 첫 30초 판별 + 독해 + 묶인 문항 일괄 풀이. **축이 안 잡히는 고난도는 표시 후 손절**, 회수 단계에서 재검토한다.

### 0.1 지문 받자마자 5단계 (상세)

#### [1단계] 글 종류·축 판별 — 첫 30초

본문을 정독하기 **전에**, 첫 문단과 첫 문제 선지만으로 두 가지를 못박는다.

(가) 전개 엔진 — 글이 움직이는 방식:

| 전개 엔진 | 첫 문단 신호 | 먼저 잡을 것 |
|---|---|---|
| 논문형 | 연구 질문·기존 한계 제시 | 문제-방법-결과-해석 대응 |
| 과정·메커니즘형 | 단계·인과·작동 설명 | A이면 B 연쇄, 조건·억제·피드백 |
| 정의·분류형 | 개념 규정·유형 나눔 | 기준·경계 사례 |
| 문제해결형 | 문제 진단 -> 해법 | 문제와 해법의 대응 |
| 역사발전형·통시형 | 시대·단계 변화 | 시점·전후 순서 |
| 모형·가정형 | 가정 위 모델 전개 | 가정 안에서만 성립 |
| 법리·규범형 | 원칙·요건·예외 | 요건 충족·예외 해당 |
| 해석·비평형 | 텍스트·작품 해석 | 해석 층위·근거 |
| 비교읽기·융합형 | 두 글·관점 병치 | 공통 쟁점·차이 |
| **대립형** | A 주장 vs B 주장 | **쟁점 Q와 축** |

(나) 축 — 정보가 갈라지는 기준. 첫 문단에서 "무엇과 무엇이 갈리는가"를 한 줄로 적는다.

빈출 축: **실재/구성, 보편/특수, 구조/행위, 사실/가치, 규칙/원리, 효율/형평, 예측/설명, 상관/인과, 객관/해석**.

> [!warning] 고난도는 축을 숨긴다
> 고난도 지문은 내용을 많이 넣어 어렵게 만드는 게 아니라, **축을 숨기거나 두 축을 겹쳐** 어렵게 만든다. 축을 못 잡으면 정독해도 선지에서 흔들린다.

#### [2단계] 축 먼저 읽기 — A·B 내용 나열 금지

대립형이 나오면 곧바로 'A는 무엇, B는 무엇'을 길게 적지 않는다. 먼저 **갈리는 기준(축)**을 적고, 그 뒤에 결론·근거를 채운다.

```text
쟁점 Q: ________?
축: ________ vs ________
A: 결론 / 근거 / 약점
B: 결론 / 근거 / A 비판점
저자: 지지 / 비판 / 보완 / 종합 / 유보
```

> [!warning] 저자 위치 바꿔치기
> 저자의 위치(지지·비판·보완·종합·유보)를 반드시 표시한다. **저자 견해를 A나 B 견해로 바꿔치기하는 선지가 빈출 함정**이다.

#### [3단계] 판정 가능한 형식으로 메모 — 규칙·전제·함수 꼴

긴 지문을 전부 기호화하지 않는다. 다음만 표시한다 — **주장 / 근거 / 조건(A이면 B) / 양화(모든·어떤·없음·전부는 아님) / 양상(반드시·가능·알다·믿다·해야 한다·할 수 있다) / 변수(원인·결과·대조집단·측정값·예외)**. 이 단계에서 보조사의 논리 기능을 함께 반영한다(아래 0.3 표).

전개 엔진별 메모 최소형:

```text
[논문형]   Q 연구질문 / Old 기존한계 / M 방법·자료 / R 결과 / I 해석 / L 한계
[과정형]   A이면 B 이면 C 이면 D / 조건: C 필요 / 억제: X가 B를 막음 / 피드백: D가 A로 되돌아감
[대립형]   쟁점 Q / 축: ___ vs ___ / A 결론·근거 / B 결론·A비판 / 저자 위치
[법리형]   원칙 P / 요건 A 그리고 B 그리고 C / 예외 E / 사례 대응 / 결론
```

> [!note] 메모의 목적
> 핵심은 "줄글을 줄이는 것"이 아니라 **참·거짓을 판정할 수 있는 꼴**로 바꾸는 것이다. 조건문은 'A이면 B'로, 인과는 '원인이 결과를 일으킴'으로, 분류는 '기준에 따라 갈림'으로 적는다.

#### [4단계] 선지 8항목 검사 — `S-R-C-M-L-T-E-Q`

선지는 아래 8개 중 **하나를 바꿔** 오답이 된다. 선지마다 무엇을 건드렸는지 분류한다.

| 코드 | 검사 항목 | 질문 | 대표 오답 조작 |
|---|---|---|---|
| `S` | 주체(Source) | 누구의 말인가 | **저자 견해를 기존 견해로**, A 견해를 B 견해로 바꿈 |
| `R` | 관계(Relation) | 무엇이 무엇을 일으키거나 지지하나 | **인과 역전**, 근거-결론 뒤바꿈 |
| `C` | 조건(Condition) | 어떤 조건에서만 성립하나 | 필요조건을 충분조건화, 조건 누락 |
| `M` | 양상(Modality) | 가능·필연·대체로·항상 중 무엇인가 | **가능을 필연으로**, 일부를 전부로 과장 |
| `L` | 층위(Level) | 개인·제도·사회, 관찰·해석 중 어디인가 | 분석 수준 이동 |
| `T` | 시간(Time) | 전후·변화 단계가 맞나 | 시대착오, 원인·결과 시점 전도 |
| `E` | 평가(Evaluation) | 저자 태도 강도가 맞나 | 보완을 전면 부정으로, 유보를 지지로 과장 |
| `Q` | 쟁점(Question) | 같은 질문에 답하나 | 논점 이탈, 다른 문제의 답을 끼워 넣음 |

> [!warning] 무관 선지가 빈출 오답
> 본문 단어가 다 들어 있어도 **쟁점 Q를 벗어나면 오답**이다. 단어 매칭으로 고르지 않는다.

#### [5단계] 소거 — 센 선지부터 제거

본문과 선지의 **강도(양상·범위)**를 맞춘다. 본문보다 강한 선지가 가장 흔한 함정이다. 아래 순서로 제거한다.

1. **주체 오류 제거** — 누가 말했는지 틀린 선지(저자<->기존, A<->B).
2. **관계 오류 제거** — 인과·조건·근거-결론 방향이 틀린 선지(역·이).
3. **범위 오류 제거** — 일부·조건부를 전체·무조건으로 만든 선지.
4. **태도 오류 제거** — 보완·유보를 전면 찬반으로 과장한 선지.
5. **층위 오류 제거** — 개인<->제도, 관찰<->해석, 사실<->가치가 이동한 선지.
6. **마지막 비교** — 남은 두 선지 중 본문 구조를 더 잘 보존한 것을 택한다.

> [!check] 강도 맞추기 10초 기준
> - 본문이 **가능**인데 선지가 **반드시**면 제거
> - 본문이 **어떤(일부)**인데 선지가 **모든(전부)**이면 제거
> - 본문이 **주장·믿음**인데 선지가 **사실**로 단정하면 제거(주체 바꿔치기)

### 0.3 표지어·보조사 논리 기능표 (3단계 필수)

조건·양상·범위를 고정할 때 **보조사 하나**가 방향과 강도를 바꾼다. 이 표를 3단계에서 그대로 적용한다.

| 표지어 | 논리 기능 | 시험장 번역 | **빈출 함정** |
|---|---|---|---|
| 만 / 뿐 / 밖에 | 한정(오직) | 'A여야(만) B'는 A가 B의 필요조건 ('A만 B' = B이면 A) | **'A만 B'를 'A이면 B'(충분조건)로 오독** |
| 도 | 첨가 | 'A도 B'는 A를 포함해 다른 것도 B | 'A도'를 'A만'으로 뒤집기 |
| 조차 / 마저 | 극단 첨가 | 'A조차 B'면 나머지는 당연히 B(예상 밖·부정 맥락) | 특칭 강조를 전칭으로 키움 |
| 까지 | 척도 끝 | 범위를 A 끝까지 확장 | 범위 끝을 일반화로 비약 |
| 은 / 는 | 주제·대조 | 'A는 B'는 다른 것은 B 아닐 수 있음을 함축 | **대조를 전칭이나 한정으로 비약** |
| 마다 | 분배 전칭(각각=모든) | 'A마다 B'는 모든 A가 B | 특칭으로 약화 오독 |
| (이)나 | 선택·근사 | 둘 중 하나 또는 대략 | 정확 수치로 단정 |
| 라도 | 양보 | 'A라도 B'(양보) — 충분조건 아님 | **양보를 충분조건으로 격상** |
| 반드시 | 필연 | 반례 하나면 깨진다 | **가능을 필연으로 키움** |
| 가능 | 가능(일 수 있다) | 사실로 바꾸지 말 것 | **가능을 사실로 단정** |
| 해야 한다 / 할 수 있다 | 의무 / 허용·능력 | 실제로 한다가 아님, 문맥에서 분리 | 당위를 사실로 바꿈 |
| 알다 / 주장하다 | 사실성 함축 / 사실성 없음 | '알다'는 보통 사실 함축, '주장·믿다'는 사실성 없음 | **주장·믿음을 사실로 바꿔치기** |

> [!note] 조건문 방향 10초 복습
> 'A이면 B' = A는 충분조건, B는 필요조건. 안전한 변형은 **대우('B 아니면 A 아니다')뿐**이다. 역('B이면 A')과 이('A 아니면 B 아니다')는 금지. 'A일 때에만 B'·'오직 A만 B'·'B 없이는 A 불가'·'A하려면 B 필요'는 모두 **B이면 A 또는 A이면 B 방향**을 가리키므로 'A이면 B'와 절대 섞지 않는다. **시험의 가장 그럴듯한 오답은 거의 역 또는 이다.**

### 0.4 손절·회수 운영 (시간 큰 그림)

| 구간 | 목표 | 행동 |
|---|---|---|
| 첫 30초 | 글 종류·축 판별 | 첫 문단 + 첫 문제 선지 확인 |
| 지문 독해 | 구조 지도 작성 | 문단 기능·축·전환점 표시 |
| 문항 풀이 | 선지 8항목 검사 | `S-R-C-M-L-T-E-Q` 순서로 소거 |
| 막힘 발생 | **손절** | **축이 안 잡히면 표시 후 다음 지문**으로 |
| 회수 | 남은 고난도 처리 | 표시한 축·조건 문항만 재검토 |

> [!warning] 손절이 시간을 만든다
> 60문항 안정권의 시간 자원은 **손절로 확보**한다. 한 지문에 매달려 묶인 다른 지문을 못 푸는 손실이 가장 크다. 축이 30초 안에 안 잡히면 표시하고 넘어가, 쉬운 지문을 먼저 확보한 뒤 회수 단계에서 돌아온다.
