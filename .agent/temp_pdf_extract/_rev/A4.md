## 4. 강화·약화 통일 판정법

> [!tip] 시험장 코어
> - **타깃 T 고정**: 무엇을 강화/약화하는지부터 한 문장으로 적는다. T가 흔들리면 다 틀린다.
> - T 유형 분류: 인과·실험·일반화·조건·유비·설명가설·규범·통계 중 하나 (아래 '먼저 찾을 것' 표).
> - E와 T의 관계: 반례·대안설명을 줄이면 강화 / 만들면 약화 / T 아닌 주변만 건드리면 무관.
> - 강화는 '증명'까지, 약화는 '완전 반박'까지 갈 필요 없다. 시험은 **'믿을 정도의 변화'**만 묻는다.
> - 무관 판정 한 줄: '이 선지가 참이어도 결론의 원인·결과·조건·범위가 그대로인가?' -> 그대로면 무관.

> [!warning] 최빈 함정
> 같은 주제·같은 방향이라 정답처럼 보이지만, **T의 비교축·인과고리를 안 건드리는 무관 선지**.

---

### 4.1 무엇을 강화·약화하는가 — 타깃 T부터 고정

> [!note] 순서
> 선지를 보기 전에 T를 한 문장으로 쓰고, 그 T가 어느 유형인지부터 정한다. 유형이 정해지면 강화/약화 포인트가 자동으로 좁혀진다.

**결론유형별 먼저 찾을 것**

| T의 유형 | 강화하는 E | 약화하는 E |
|---|---|---|
| **인과** (A 때문에 B) | A 변화 뒤 B 변화, 대조군 비교, 무작위화, 용량-반응, 기제 제시 | 역인과, 공통원인, 표본편향, 측정오류 |
| **실험·과학가설** (H가 현상 설명) | H의 새 예측 성공, 경쟁가설 제거, 측정 민감도 확인 | 경쟁가설이 더 잘 설명, 예측 실패, 표본·측정 결함 |
| **일반화** (모든·대부분 A는 B) | 대표성 있는 표본, 여러 시기·지역에서 반복 | A인데 B 아닌 반례, 표본 편향·과소 |
| **조건** (A이면 B) | A인 사례가 B임, A인데 B 아닌 경우 부재, 기제 | A인데 B 아닌 사례 제시 |
| **유비** (사례1이 이러니 사례2도) | 결론과 관련된 유사성 추가 | 결론과 관련된 차이 추가 |
| **설명가설** (이 가설이 잘 설명) | 위험한 예측 성공, 경쟁가설이 설명 못함 | 경쟁가설이 같은 현상을 더 잘 설명 |
| **규범** (A해야 한다·정당하다) | 가치기준 명시, 사례가 적용 대상임, 우선순위 제시 | 적용요건 불충족, 예외조항, 더 우선하는 규범 충돌 |
| **통계** (자료로 결론) | 표본 대표성·충분한 크기·비교가능성 | 표본 편향, 작은 표본, 다른 모집단 |

> [!note] 발문 처리 순서
> 강화/약화/가정/오류/추론/원리 중 무엇인지 5초 안에 정한 뒤 T 유형을 분류한다. **결론이 여러 문장이어도 답은 보통 하나의 결론·하나의 가설·하나의 규범명제에 걸려 있다.**

### 4.2 강화 3종 (이것만 만들면 강화)

| 종류 | 하는 일 | 판별 한 줄 |
|---|---|---|
| **직접강화** | 결론이 예측한 바로 그 결과가 관찰됨 | '예상 현상이 더 잘 나타나는가?' |
| **간접강화** | 결론을 위협하는 대안설명을 제거 | '결론 말고 다른 설명이 줄어드는가?' |
| **구조강화** | 전제와 결론 사이 빈 연결고리를 메움 | '적용조건·숨은 전제가 충족되는가?' |

> [!note] 세부 작동 (7가지 모두 위 3종에 들어감)
> 빈 연결고리 메우기 / 대안설명 제거 / 표본 신뢰도 올리기(크다·무작위·대표성·대조군) / 측정 신뢰도 올리기(정확·무편향·반복일치) / 예측 성공 / 기제 제시 / 범위 일치(지문 대상=선지 대상).

---

### 4.3 약화 5종 (이 중 하나면 약화)

| 종류 | 하는 일 | 판별 한 줄 |
|---|---|---|
| **반례** | A인데 B 아닌 사례 | '같은 결과가 깨지는 경우가 있나?' |
| **대체원인** | B는 A 아니라 C 때문일 수 있음 | '결과를 다른 원인으로 설명되나?' |
| **역인과** | A가 B를 낳은 게 아니라 B가 A를 낳음 | '시간 선후가 거꾸로 가능한가?' |
| **표본·측정 공격** | 자료 편향, 측정 둔감 | '비교가 깨지나? 측정이 못 잡았나?' |
| **적용조건 불충족** | 논증 성립에 필요한 조건이 사실은 없음 | '필요한 전제가 사례에 없나?' |

> [!note] 묶음·확장
> 공통원인(A와 B 둘 다 X의 결과)은 대체원인의 한 형태로 같이 묶는다. 규범 T에서 '적용조건 불충족'은 곧 적용요건 미충족·예외조항·상위규범 충돌로 나타난다. **'사실 판단에서 규범 판단으로 비약(가능->당위, 바람직->실재)'도 약화 포인트다.**

### 4.4 무관 선지 전형 (매력적이지만 0점)

| 무관 선지형 | 왜 무관한가 |
|---|---|
| 같은 주제지만 **다른 변수**만 말함 | T의 원인·결과·조건을 안 건드림 |
| 사례는 있는데 **모집단이 다름** | 일반화 대상이 아님 |
| 결과는 같은 방향인데 **시간 순서 없음** | 인과를 못 받침 |
| 원인만 말하고 결과 변수 없음 / 결과만 말하고 원인 변수 없음 | 비교축 미충족 |
| 지문은 사실판단인데 **가치판단**만 함 | 양상 전환 (사실<->규범) |
| 일부 사례만 말하는데 결론은 전칭 | 강화가 너무 약하거나 무관 |
| 평균을 말하는데 결론은 개인 사례 / 그 반대 | 수준이 다름 |
| 과거 자료인데 결론은 제도 변경 이후 | 시점이 다름 |

> [!warning] 무관 선지의 본질
> **'결론과 같은 주제'라는 이유만으로 정답으로 끌리는 것**이 무관 선지의 함정이다. T의 비교축(원인·결과·조건·범위)에 닿는지로 끊는다.

---

### 4.5 강화·약화 10초표 (빈출 볼드)

> [!tip] 쓰는 법
> 선지를 아래 기능 중 하나로 환산해 즉시 판정한다. 원문 암기가 아니라 **기능** 암기다.

| 선지 기능 | 판정 |
|---|---|
| **A 없는 비교집단에서는 B가 안 나타났다 (대조 성공)** | **강화** |
| 실험군·대조군이 원인 A 외에는 같았다 | 강화 (대체원인 제거) |
| A가 늘수록 B도 일정하게 늘었다 (용량-반응) | 강화 |
| A를 인위적으로 조작하자 B가 변했다 (개입) | 강화 |
| 독립 연구에서 같은 결과가 반복됐다 (재현성) | 강화 |
| **가설이 틀렸다면 나오기 어려운 결과가 나왔다 (위험한 예측 성공)** | **강한 강화** |
| 측정장비는 B가 있었다면 검출할 만큼 민감했다 | 강화 (음성 결과 의미 보강) |
| 결론에 필요한 숨은 조건이 실제 충족됐다 | 강화 (간극 보강) |
| **A 없는데도 B가 나타났다** | **약화** (A 필요성) |
| **A 있는데도 B가 안 나타났다** | **약화** (A 충분성) |
| **B가 A보다 먼저 나타났다** | **약화** (역인과) |
| **A와 B 모두 제3요인 C의 결과였다** | **약화** (공통원인) |
| 실험군이 원래 B가 높을 집단이었다 | 약화 (선택편향) |
| 탈락자가 한쪽 집단에 몰렸다 | 약화 (생존자 편향) |
| 측정도구가 B를 정확히 못 잡았다 / 측정 기준이 도중 바뀌었다 | 약화 (측정오류) |
| **표본이 결론의 모집단과 다르다** | **약화** (일반화) |
| 규범 적용 요건이 충족되지 않았다 | 약화 (규범 적용) |
| **지문은 '가능'인데 결론은 '필연'으로 비약** | **약화** (양상 과장) |
| 결과 B와 비슷한 다른 결과 D만 말함 / 같은 주제 도덕평가만 함 | 무관 |

### 4.6 보조사 첨가가 '추가 증거'로 작동할 때

| 선지 표지 | 논리 기능 | 강화/약화 판정 |
|---|---|---|
| 'A도 B'·'A조차 B'·'A마저 B' (첨가·극단첨가) | A를 포함해 다른 것까지 B라는 함축 -> 사례 범위가 넓어짐 | **일반화 T 강화**(반례 줄고 대표성↑), 단 A가 결론 범위 밖이면 무관 |
| 'A만 B'·'A뿐'·'A밖에' (한정) | A가 B의 필요조건 | 'A만 B'를 'A이면 B'(충분조건)로 읽으면 **오판** — 강화 강도 과대평가 |
| 'A는 B' (대조) | 다른 것은 B 아닐 수 있음 함축 | 이를 전칭·한정으로 비약해 강화로 오독하는 함정 |
| 'A마다 B' (분배 전칭) | 모든 A가 B -> 반례 한 건이면 무너짐 | 특칭으로 약화해 읽으면 약화 선지를 놓침 |

> [!warning] 한 줄 요약
> **'도·조차·마저'가 붙으면 '예상 밖의 것까지 포함'**이라 일반화·인과 결론의 추가 증거(강화)로 작동한다. 반대로 **'만·뿐·밖에'는 한정**이라 범위를 좁히며, 충분조건으로 뒤집어 읽는 것이 대표 함정이다.
