## 4. 시간 운영·소거·오답 루틴

> [!tip] 시험장 코어
> - 70분·30문항이면 문항당 약 2분 20초. 단 **문항이 아니라 지문 묶음 단위**로 운영한다.
> - 한 지문에 막히면 **손절**이 점수를 지킨다. 축이 30초 안에 안 잡히면 표시하고 다음 지문으로.
> - 선지는 **주체 -> 관계 -> 범위 -> 태도 -> 층위** 순서로 소거하고, 남은 둘은 **본문 구조를 더 보존한 쪽**을 택한다.
> - 오답노트는 문제 내용이 아니라 **선지 조작 방식**을 기록한다.

### 4.1 시간 운영 원칙 (지문 묶음 단위)

| 구간 | 목표 | 행동 |
|---|---|---|
| 첫 30초 | 유형·축 판별 | 첫 문단 + 첫 문제 선지 확인 |
| 지문 독해 | 구조 지도 작성 | 문단 기능, 축, 전환점 표시 |
| 문제 풀이 | 선지 조작 검사 | 아래 소거 순서로 처리 |
| **막힘 발생** | **손절** | 축이 안 잡히면 표시 후 다음 지문 |
| 회수 | 남은 고난도 처리 | 표시한 축·조건 문항만 재검토 |

> [!note] 형식(문항 수·시간)이 바뀌어도 비율은 유지한다. **쉬운 지문을 먼저 확보**한 뒤 회수 단계에서 어려운 것을 돌아본다.

### 4.2 지문 유형별 메모 최소형

유형이 잡히면 골격만 키워드로 채운다(문장으로 쓰지 않는다).

| 유형 | 채울 골격 |
|---|---|
| **논문형** | 연구질문(Q) / 기존설명·한계(Old) / 방법·자료(M·D) / 결과(R) / 해석(I) / 한계(L) |
| **과정형** | a 다음 b 다음 c 다음 d / 조건: c 필요 / 억제: X가 b를 막음 / 피드백: d가 a로 되돌아감 |
| **대립형** | 쟁점 Q / 축: ___ 대 ___ / A의 결론·근거 / B의 결론·A 비판점 / 저자 태도(지지·비판·보완·종합·유보) |
| **법리형** | 원칙 P / 요건 a 그리고 b 그리고 c / 예외 E / 사례 대응 / 결론 |

### 4.3 선지 소거 순서 (위에서 아래로)

1. **주체 오류**: 누가 말했는지 틀린 선지(주장자·학파 바꿔치기).
2. **관계 오류**: 인과·조건·근거-결론 방향이 틀린 선지.
3. **범위 오류**: 일부·조건부를 **전체·무조건**으로 키운 선지.
4. **태도 오류**: 보완·유보를 **전면 찬반**으로 과장한 선지.
5. **층위 오류**: 개인<->제도, 관찰<->해석, 사실<->가치가 이동한 선지.
6. **마지막 비교**: 남은 둘 중 본문 구조를 더 잘 보존한 것을 선택.

> [!warning] 선지는 **단어 일치가 아니라 관계 보존**으로 판단한다. 본문에 있는 단어라도 그 단어가 맡은 기능이 어긋나면 오답이다.

### 4.4 오답노트 — 내용이 아니라 조작을 적는다

문제를 베끼지 말고 다음만 기록한다.

> [!note]
> - 지문 유형(전개 엔진 / 축 / 문단 기능)
> - 발문 / 내가 고른 선지 / 정답 선지
> - **오답 조작 유형**(주체·관계·범위·태도·층위·양상 중 무엇)
> - 재발 방지 규칙 한 줄

### 4.5 점수대별 우선순위

| 현재 약점 | 먼저 보완 | 하지 말 것 |
|---|---|---|
| **시간 부족** | 첫 문단 판별·손절 기준 | 모든 문장 완전 이해 시도 |
| 세부 일치 약함 | 조건·범위·양상어 표시 | 단어 매칭으로 선지 선택 |
| 추론 약함 | 전제-결론 연결, 적용형 매핑 | 배경지식 동원 |
| 대립형 약함 | 쟁점 Q와 축 먼저 작성 | A·B 내용 나열만 |
| 과학형 약함 | 흐름(다음·조건·피드백) 메모 | 전문용어 뜻 암기 |
| **고득점 정체** | **오답 선지 조작 코드화** | 해설 읽고 납득만 하기 |

### 4.6 최종 체크리스트

> [!check] 지문 다 읽고 문제 들어가기 전
> - 전개 엔진을 잡았는가
> - 핵심 축을 하나 이상 적었는가
> - (논문형) Q·M·R·I·L 분리
> - (과정형) 흐름 방향·조건 표시
> - (대립형) 주체·쟁점·태도 분리

> [!check] 정답 고르기 직전
> - 선지의 주체가 맞는가
> - 인과·조건·단계 방향이 맞는가
> - **범위·양상어가 지문보다 세지 않은가**
> - 저자 태도를 과장하지 않았는가
> - 예시·배경을 중심 주장으로 착각하지 않았는가
