# NotebookLM 전사문 통합 워크플로우

## 개요

**단일 에이전트 최적화 모드**:
한 번의 브라우저 세션으로 `추출`하고, 결과를 `단일 파일`에 통합 저장합니다.

```
NotebookLM → [브라우저 자동화 (One-Shot)] → 통합 파일(_processed.md)
```

| 파일명 | 내용 |
|--------|------|
| `*_processed.md` | 메타데이터 + 교정 로그 + 발췌 후보 + 원본 전사문 |

---

## 분할 파일 병합 규칙

NotebookLM에서 긴 오디오가 분할 업로드된 경우 (예: `1-3.1`, `1-3.2`), **소수점 단위를 합쳐서 하나의 전사문으로 처리**합니다.

| 소스 파일 | 저장 파일명 |
|-----------|-------------|
| `송영곤_민법입문_1-3.1.m4a` + `1-3.2.m4a` | `송영곤_민법입문_1-3_processed.md` |
| `김강사_행정법_2-1.1.m4a` + `2-1.2.m4a` + `2-1.3.m4a` | `김강사_행정법_2-1_processed.md` |

**처리 방법:**

1. `.1`, `.2`, `.3` ... 순서대로 각각 전사문 추출
2. 추출된 텍스트를 순서대로 병합
3. 병합된 전체 텍스트에 대해 구조화/교정 수행
4. 소수점 없는 파일명으로 저장 (예: `1-3_processed.md`)

## 전제 조건

1. **NotebookLM 로그인**: Google 계정 로그인 상태
2. **노트북 준비**: 대상 노트북 및 오디오 파일 준비 완료

## 통합 워크플로우 단계

### Step 1: 전사문 추출 (브라우저 자동화)

// turbo

```
browser_subagent:
  Task: |
    1. https://notebooklm.google.com 으로 이동하여 "[노트북 이름]" 클릭
    2. 왼쪽 패널에서 "[소스 파일명]" 클릭하고 "전사본" 보기
    3. 아래 JavaScript 실행하여 전체 텍스트 추출 (자동 스크롤 포함)
    4. 텍스트 반환
  JavaScript:
    (async () => {
      const container = document.querySelector('.scroll-area');
      if (!container) return "ERROR: 전사문 영역을 찾을 수 없음";
      
      let lastHeight = 0;
      while (container.scrollHeight > lastHeight) {
        lastHeight = container.scrollHeight;
        container.scrollTop = container.scrollHeight;
        await new Promise(r => setTimeout(r, 500));
      }
      return container.innerText;
    })()
```

### Step 2: 구조화 (소제목 삽입)

추출된 전사문의 **내용 흐름을 분석**하여 주제 전환점에 소제목을 삽입합니다.

**분석 기준:**

1. **주제 전환 신호**: "자, 이제", "다음으로", "그러면", "여기서" 등
2. **법률 개념 전환**: 새로운 조문/판례/요건 언급 시
3. **시간 간격**: 타임스탬프 간격이 큰 경우
4. **강조 표현**: "중요한 것은", "핵심은", "포인트는" 등

**소제목 형식:**

```markdown
### [HH:MM] 주제명
```

### Step 3: 교정 및 발췌 (메모리 내 처리)

추출된 텍스트를 바탕으로 **메모리 내에서** 교정과 발췌를 수행합니다.

1. **교정**: 명백한 오탈자/기계적 오류 수정 (로그 생성)
2. **발췌**: 정의/요건/판례 등 핵심 문장 선별

### Step 4: 통합 파일 저장

저장 경로: `G:\내 드라이브\법\민법\전사문\[파일명]_processed.md`

```markdown
---
title: "[오디오 파일명]"
source: NotebookLM
date: YYYY-MM-DD
status: processed
---

# [오디오 파일명]

## 목차
- [00:00] 강의 소개
- [05:30] 민법의 체계
- [12:45] 권리능력의 개념
- ...

---

## 1. 이터레이션 로그

### 1-1. 전사문 교정 (Correction)
| 원문 | 교정 | 근거 |
|------|------|------|
| ... | ... | ... |

### 1-2. 핵심 발췌 (Excerpts)
[EXCERPT CANDIDATES]
E1. [00:12:30] "..."
E2. [00:15:00] "..."

---

## 2. 전사문 본문 (Transcript)

### [00:00] 강의 소개
(내용)

### [05:30] 민법의 체계
(내용)
...
```

## 대용량 파일 대응 (분할 추출)

만약 파일이 너무 커서(16k 토큰 초과) 한 번에 안 될 경우:

1. **메타데이터 확인**: 길이 체크
2. **2분할**: `0 ~ 50%` / `50% ~ 100%` 두 번 호출
3. **병합**: 메모리에서 합쳐서 하나의 파일로 저장

## 에러 처리

| 상황 | 대응 |
|------|------|
| 로그인 필요 | 사용자에게 로그인 요청 후 중단 |
| 선택자 불일치 | `.scroll-area` 등 CSS 선택자 업데이트 필요 |
