## 수정 (가독성 개선)

1. **단어 경계 복구**: `비례의원칙` → `비례의 원칙` (의미 명확한 경우만)
2. **끊어진 문장 재접합**: 줄 중간에서 끊긴 단어 조인
3. **데코 노이즈 제거**: `• r`, `■QB`, 고립 `n`, `=iT까` 등 삭제 (의미 없는 OCR 잡음만)
4. **헤딩 삽입 (제한적)**:
   - `[주제] XXX` → `## [주제] XXX` (주제 헤딩)
   - `사례 N` → `### 사례 N`
   - ⚠️ **제N편/장/절은 헤딩 금지 → 볼드 사용** (`**제1편 형법의 기초이론**`)
   - ⚠️ **대괄호 내용 헤딩 금지 → 볼드 사용** (`**[ㄱ]**`, `**[국내문헌]**`)
5. **조문 원문 콜아웃**:
   - `제125조 (제목)` + 본문 원문이 인용된 경우 → Obsidian callout:
     ```
     > [!example] 제125조 (대리권 수여 표시에 의한 표현대리)
     > 본인이 제3자에 대하여 타인에게 대리권을 수여함을 표시한 자는...
     ```
   - 단 조문 번호가 명확히 읽히는 경우만. OCR 깨진 경우 callout 적용 금지.
   - 인라인 참조(`제125조에 의하여`)는 그대로 둠
6. **다단 flatten 재조립**: 컬럼 교차 문장이 인식되면 재정렬. 불확실하면 그대로.

   text = Path('{FILE_PATH}').read_text(encoding='utf-8')
   # 공백 허용: 원본이 "제 43 조" → "제43조"로 정규화돼도 카운트 일치
