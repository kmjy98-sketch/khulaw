# 법학 교재 구조적 Reflow 프롬프트 (v4, 2026-04-12)

치환: `{FILE_PATH}`, `{BOOK_FULL_NAME}`, `{CHAPTER_TOPIC}`

---

## 역할

법학 교재 마크다운 가독성 **구조 에디터**. 단순 텍스트 정리가 아니라, Obsidian에서 렌더링했을 때 **학습에 직접 도움이 되는 구조**를 만드는 것이 목표.

## 파일
`{FILE_PATH}`
교재: {BOOK_FULL_NAME}. 주제: {CHAPTER_TOPIC}.

## 절대 보존

1. **frontmatter** 전체 (byte-for-byte)
2. **판례번호**: `대판 YYYY.M.D, NN다/도/헌가/헌바/헌마NN`
3. **조문번호**: `제N조`, `§N`
4. **OCR 깨진 조문은 절대 복구 금지** — 외부 지식 추측 = FABRICATION
5. 당사자 라벨(갑·을·병), 기호(§ ①②③ 「」《》), 인용판시문, `[[위키링크]]`
6. 원책 `[]` 표기 보존 (무차별 삭제 금지)

## 처리 순서 (이 순서대로 수행)

### Step 1: 전체 읽기 → 논리 구조 파악

파일 전체를 읽고 다음을 식별:
- 편/장/절/관/항 계층
- 각 섹션의 패턴: 개념 정의 → 요건 → 효과 → 학설 → 판례
- 페이지 헤더/푸터 위치
- 마진 주석(학습 메모) 위치

### Step 2: 페이지 경계 정리

- **페이지 헤더/푸터 삭제**: `620 I Part 2. 민법가족법`, `제7장 개별적채권관계 973` 등
- **중복 섹션 헤더**: 페이지마다 반복되는 동일 제목 → 1번만 남김
- **페이지 경계 문장 접합**: 줄 끝에서 잘린 단어 재접합
- **페이지 번호**: frontmatter `포함_페이지`가 있으므로 본문 내 `<!-- page N -->` 주석은 **삽입하지 않음** (불필요)

### Step 3: OCR 노이즈 제거 + 단어 경계

- 고립 무의미 문자 제거 (`• r`, `■QB`, `흐☆決#!` 등)
- 단어 경계 복구: `할수있다` → `할 수 있다`
- 문장 재접합: 줄바꿈으로 끊긴 단어 조인

### Step 4: 내용 구조화 (핵심)

#### 4-1. 논리 단위 줄바꿈
긴 문단을 논리적 구분점에서 분할:
- 마침표 + 전환어("한편", "다만", "그러나", "이에 대해", "한편으로") 앞에서 빈 줄
- 결론/소결 앞 빈 줄
- 새로운 쟁점 시작 시 빈 줄

#### 4-2. 위계식 분류 → 마크다운 리스트
```
원본: (가) 요건사실 — 원고 입증  (나) 항변사유 — 피고 입증
변환:
- **(가) 요건사실** — 원고 입증
- **(나) 항변사유** — 피고 입증
```

```
원본: ① 물건 존재 ② 타인 점유 ③ 점유 침탈
변환:
- ① 물건이 존재할 것
- ② 타인의 점유일 것
- ③ 점유가 침탈되었을 것
```

**주의**: 원문의 번호 체계(①②③, (1)(2)(3), 가.나.다, I.II.III)는 그대로 보존하되, 각 항목을 별도 줄 + 마크다운 리스트(`-`)로 만든다.

#### 4-3. 학설 대립 → 비교 표
문장 속에 긍정설/부정설/판례가 섞여 있으면 반드시 표로:
```markdown
| 학설 | 내용 | 근거 |
|------|------|------|
| 긍정설 | 소멸시효 적용 | 제162조 제2항 |
| 부정설 | 시효 불적용 | 침해 계속 시 청구권 발생 |
| **판례** | 부정설 | 대판 YYYY.M.D |
```

#### 4-4. 판례 개별 분리
여러 판례를 하나로 뭉치지 말고 각각 분리:
```markdown
> [!cite] 판례 — 물상보증인의 동의
> 「물상보증인이 채무인수에 관하여 하는 동의는...」(대판 2000.12.26, 2000다56204)

> [!cite] 판례 — 근저당권 변경등기
> 「면책적 채무인수에 따른...」(대판 1999.9.3, 98다40657)
```

#### 4-5. 조문 원문 → callout
```markdown
> [!example] 제214조 (소유물방해제거·예방청구권)
> 소유자는 소유권을 방해하는 자에 대하여 방해의 제거를 청구할 수 있으며...
```

#### 4-6. 편·장·절 → 마크다운 헤딩
```
## 제3편 물권법
### 제1장 물권법 총론
#### 제1절 물권의 의의
##### I. 물권의 개념
```

## 금지

- ❌ 외부 지식으로 OCR 깨진 조문/판례 복구
- ❌ 요약·의역·재작성 (원문 내용을 자기 말로 바꾸지 않음)
- ❌ 법률 내용 삭제
- ❌ 원책 `[]` 표기 무차별 삭제
- ❌ `[!판례]`, `[!case]` 커스텀 callout (Obsidian 기본 타입만: `[!example]`, `[!cite]`, `[!quote]`, `[!tip]`)
- ❌ 본문 중간에 `<!-- page N -->` 주석 삽입 (불필요)
