# Weekly Review Skill (주간 리뷰)

> 학습과학상 **주간리뷰는 시스템 신뢰성을 유지하는 최대 ROI 갭**(GTD: 시스템 방치는 캡처실패가 아니라 리뷰중단에서 옴). daily-drill이 '오늘'이라면 이 스킬은 '이번 주 → 다음 주'를 잇는다.
> 원칙: **코드는 상태 집계만, 판단·계획은 LLM(이 스킬).** 추측 금지·실제 상태파일 근거. 자동 상태쓰기 금지(#16, 사용자 확정 시만 갱신).

## 0. 적용 시점
- 매주 1회(권장 토요일; 일요일은 자유). "주간리뷰" 발화 또는 schedule/Routines 주간 트리거.

## 1. 입력 (상태 — 정본만)
- `.agent/state/progress.json` — 진도 **보조 snapshot**(수동, 정본 아님). ※진도 정본 = 논점 frontmatter(`sync/위키/{과목}/{쟁점}.md`의 회독·선택·사례·약점·진도, #19-B 2026-06-30). `진도_현황.json`도 대시보드 snapshot일 뿐 정본 아님.
- `.agent/state/srs_log.json` — SRS 큐(SM-2). due·overdue·repetitions.
- `.agent/state/learning.json` — weak_points(wrong_count), 완료/진행 topics.
- `.agent/state/drill_log.jsonl` — 이번 주 완료 드릴(없으면 "측정 베이스라인 0"으로 보고).
- `.agent/state/goals.json` — 시험 D-day(final/intl/ethics 등). 없으면 사용자에게 1회 확인.
- (있으면) `6.진도관리/사례답안/` 최근 채점 결과.

## 2. 절차
1. **집계(결정적)**: 위 상태에서 이번 주(최근 7일) 완료 드릴 수·정답률·사례 채점 O/△/X·신규 약점·SRS 처리/누락(overdue)을 수치로 모은다. 가능한 부분은 기존 스크립트(daily-drill/spaced-repetition) 재사용, 없으면 Read로 직접 집계.
2. **약점 종합(LLM)**: 반복 약점(2회+)·과목 편중·미열람 SRS(죽은 큐)를 의미 단위로 묶는다. 단순 카운트가 아니라 "무엇을 왜 못하는지" 맥락 해석.
3. **시험일 역산 페이싱(deadline-aware) — 중요**: goals.json D-day에서 역산.
   - **간격은 '시험일에 목표 recall 이상 유지'(desired-retention) 기준으로 설정.** 막판 인출이 망각곡선 바닥에 떨어지지 않게.
   - ❌ '시험 임박하니 무조건 간격 축소(cap)'는 쓰지 않는다 — 학술근거 약함(Cepeda 2008 충돌, 보고서 개선종합_카드SRS_룰감사_2026-06-21.md). 대신 deadline-aware desired-retention.
   - 마지막 3~4주는 복습·모의 선점, 잔여범위는 배점×난이도 가중으로 주별 분배, 2개월당 버퍼 1주.
4. **다음주 계획(LLM)**: 과목별 **구체 토픽 3개**(추상 'X공부' 금지 — 예 "민법 Ch.5 정의 백지인출 성공"). 인출강도 단계 적용(회독0=객관식+모범답안분석 / 회독1+=백지사례+피드백+SRS). 혼동 쟁점은 인터리빙.
5. **롤포워드**: 이번 주 미완 항목을 다음 주로 이월(소실 방지).
6. **약점→SRS 연동 제안**: 반복 약점을 SRS 우선순위/카드 후보로 **제안만**(silent write 금지, 사용자 확정 시 spaced-repetition·card 연동).

## 3. 산출
- 리뷰 노트: `6.진도관리/주간리뷰/{YYYY-Www}.md` 또는 `9.작업중/클로드/`. 형식:
  - `## 이번 주 집계`(수치) / `## 약점 종합` / `## 시험 페이싱(D-day)` / `## 다음 주 과목별 3토픽` / `## 롤포워드` / `## SRS·카드 제안(확정 대기)`
- 파일 이동 발생 시 #16-C 로그.

## 4. 경계
- 이 스킬은 **계획·점검**. 실제 출제·채점은 daily-drill/case-answer-review, 간격관리는 spaced-repetition가 담당(중복 실행 금지, 호출·참조만).
- #21 소크라틱과 충돌 시: 학습 질문은 소크라틱, 주간 점검·계획은 이 스킬.
- 근거는 상태파일·교재(#1). 외부 추정 금지.
