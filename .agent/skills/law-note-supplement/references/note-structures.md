# Note Structure Templates

## 형법 블록 템플릿

### 쟁점 집중형
```
## [쟁점명]

### 쟁점의 정리
[쟁점 한 줄 요약]

### 학설
- 긍정설: [요지]
- 부정설: [요지]

### 판례
"판례요지 한 줄"[^형1-XX]

### 검토
[결론 한 줄]

### 모답형
[모범 답안 문장 1~2줄]
```

### 조문 집중형
```
## 제○조 [조문명]

### 조문·요건
① [요건1]
② [요건2]
③ [요건3]

### 원칙 → 예외
- 원칙: [원칙 내용]
- 예외: [예외 내용 + 근거]

### 판례
"판례요지"[^형1-YY]

### 검토
[적용 시 유의점]

### 모답형
[모범 답안 문장]
```

## 민법 블록 템플릿

### 청구권 구조형
```
## [청구권명/법률효과]

### 요건 (판례 한 문장 최우선)
- **판례 문장형** (최우선): 쟁점노트에서 확인 가능하면 판례 원문 한 문장으로 대체
  예) "미성년자가 법정대리인의 동의 없이 법률행위를 한 경우 이를 취소할 수 있고,
      취소권은 제한능력자 본인 또는 법정대리인이 행사한다."
- **목차형 나열 금지**: ① 법정대리인 동의 없을 것 ② 취소원인 소멸 전일 것 형태는 사용하지 않음
- **문장형 변환**: 쟁점노트 확인 후 판례 문장 → 검증된 경우에만 해당 판례 발췌 사용

### 포섭 (사례형)
[사실관계 → 요건 대입 문장]

### 판례
"판례요지 한 문장"[^민1-XX]

### 학설 대립 (있는 경우)
- Controlling source: [우선 소스 입장]
- 보조 source 대립: [상충 내용 — 자료상 대립으로 분리]
```

### 요건 변환 우선순위 (사용자 지시 반영)
1. **판례 한 문장** (쟁점노트에서 확인) — 최우선
2. **쟁점노트 문장형 요약** → ①②③ 문장으로 변환
3. **목차형 명사 나열** → 사용 금지 (기존 노트 보완 시 변환 대상)

## 쟁점 중심 목차 구조 (issue-priority restructure용)

issue_frequency.json 빈도 데이터를 반영한 목차 재배치 기준:

```
## 0. 소스 범위                          ← 항상 최상단
## 0-1. 독법 / 요건사실론                ← 항상 최상단
## 범위 체계도                           ← 항상 최상단
## 1. 빈출 쟁점 순위표                   ← 빈도 데이터로 갱신 (★ → 실제 빈도)
  | 순위 | 쟁점 | 빈도 | 조문 |
## 2. [빈출 쟁점 #1: 물권변동]           ← 빈도 1위 섹션
## 3. [빈출 쟁점 #2: 매매]               ← 빈도 2위 섹션
## 4. [빈출 쟁점 #3: 담보물권]           ← 빈도 3위 섹션
  ...
## N. [저빈도 / 미매핑 섹션]             ← 기존 순서 유지
```

### 빈출 쟁점 섹션 내부 구조 (과목 공통)
```
## N. [쟁점명] (빈도: XX, 순위: #Y)

> 관련 조문: §A, §B, §C

### 요건/법리 정리
[과목별 블록 템플릿 적용: 형법=쟁점 집중형, 민법=청구권 구조형, 헌법=객관식 중심형]

### 판례
[빈도 데이터의 problem_ids와 연결된 판례 우선 배치]

### 모답형/선지판단형
[빈출 쟁점은 모답형 또는 선지판단형 문장 필수 배치]
```

### 순위표 갱신 형식
기존 ★★★/★★/★ 대신 실제 빈도 수치 사용:
```
| 순위 | 쟁점 | 빈도 | 연결 조문 |
|------|------|------|-----------|
| 1 | 물권변동 | 483 | §186, §187, §188 |
| 2 | 매매 | 405 | §563, §568, §580 |
```

## 사례형 공방구조 — 과목별 형식

2열 표 사용 금지, → 화살표 서술도 금지. 과목별 구조에 따라 작성.

---

### 민법·헌법·국제법 — 청구권기초 포섭형

```
**1. 청구권기초**: [원고]의 [피고]에 대한 §XX [청구권명]

**2. 요건**: ① [요건1](O/X/?) ② [요건2](O/X/?) ③ [요건3](O/X/?)

**3. 쟁점 — [쟁점명]**
- **학설**: [긍정설 한 줄] vs **[부정설 한 줄]**
- **판례** ([사건번호]): "판시 핵심 한 문장"
- **검토**: [채택 입장] 타당 — [이유 한 줄]

**4. 포섭**: [사안 사실관계] → [요건 대입] → [결론]

**5. 결론**: [청구 인용/기각]
```

과목별 용어 차이:
- **민법**: 청구권기초 = 청구권/법률효과
- **헌법**: 1=심판대상 / 2=심사기준 / 5=합헌·위헌
- **국제법**: 1=책임기초 / 2=요건(귀속+의무위반) / 3=위법성조각 / 5=책임 성립·부정

---

### 형법 — 범죄체계론형

형법은 청구권 구조가 아닌 **범죄 성립 3단계**(구성요건→위법성→책임)에 따라 작성.

```
**1. 죄명**: 甲의 乙에 대한 [죄명] (§조문)

**2. 객관적 구성요건**:
   ① 행위 (O/X)
   ② 결과 (O/X)
   ③ 인과관계 (O/X/?)

**3. 주관적 구성요건**:
   ① 고의 (O/X/?)
   ② 쟁점 — [미필적 고의/착오/개괄적 고의 등]
   - 학설: vs
   - 판례 ([사건번호]): "한 문장"
   - 검토: 타당 —

**4. 위법성**: 위법성조각사유 존부
   ① 쟁점 — [정당방위/긴급피난/오상방위 등]
   - 학설: vs
   - 판례: "한 문장"
   - 검토:

**5. 책임**: 책임조각사유 존부

**6. 결론**: 甲은 [죄명]의 죄책을 진다/지지 않는다
```

## 챕터별 페이지 마커 규칙

모든 `##` 수준 섹션(쟁점/개념 단위)에 **페이지 마커 주석**을 삽입한다.
`sync/_교재원문/` 챕터 파일의 frontmatter(`페이지:`·`챕터번호:`)와 qmd 검색 결과 메타데이터를 활용한다.

### 형식

```markdown
## N. [쟁점명/개념명]
<!-- 📖 교재별 페이지
  - 송영곤_논점민법_본책 ch.01 p.13-42 → [[송영곤_논점민법_본책_ch01_p013-042]]
  - 송영곤_쟁점노트 ch.02 p.55-60 → [[송영곤_쟁점노트_ch02_p055-060]]
-->
```

### 규칙

1. **`##` 섹션 바로 아래**에 HTML 주석(`<!-- -->`)으로 삽입
2. 교재별 1줄씩: `교재ID ch.NN p.시작-끝 → [[chunk_stem]]`
3. 페이지 범위는 `sync/_교재원문/{교재}/{교재}_chNN_pXXX-YYY.md` 파일명과 frontmatter에서 추출
4. 교재가 3종 이상이면 주 교재 2종 + "외 N종"으로 축약
5. RAG 검색에서 페이지 정보가 없으면 `(페이지 미확인)` 표기
6. qmd 검색 시 이 주석이 함께 반환되어 교재 페이지 참조 가능

### 교재 약칭 규칙

| 약칭 | 교재 | book_code 패턴 |
|------|------|----------------|
| 기본민강 | 송영곤 기본민법강의 | 1-01~1-0N |
| 쟁점정리 | 민법 쟁점정리 | civ 계열 |
| 형총(서보학) | 서보학 형법총론 | 서보학 계열 |
| 형총(홍형철) | 홍형철 쟁점정리 | 홍형철 계열 |
| 형총(김성돈) | 김성돈 형법총론 | 김성돈 계열 |
| 헌법(이진) | 이진 헌법 | 헌법 계열 |

*약칭은 source_title_registry.json의 citation_title에서 파생. 신규 교재 추가 시 이 표도 갱신.*

## 각주(Footnote) 규칙

### 기본 원칙

모든 인용은 마크다운 각주 문법을 사용한다. `근거 발췌:/근거 위치:` 인라인 패턴은 폐기.
인라인에 `"발췌 문장"[^id]`를 배치하고, 파일 맨 밑에 `[^id]: 출처` 정의를 모은다.

### 변환 형식

**Before (폐기 패턴):**
```
근거 발췌: "진정명의회복을 원인으로 한…"
근거 위치: 《전경운_민법》 p.153
```

**After (마크다운 각주):**
```
"진정명의회복을 원인으로 한…"[^민3-18]

<!-- 파일 맨 밑 각주 정의 영역 -->
[^민3-18]: 《전경운_민법》 p.153
```

### ID 네이밍 규칙

`[^{과목약칭}-{섹션번호 또는 식별자}]`

| 과목 | 약칭 | 예시 |
|------|------|------|
| 민법1(총칙) | 민1 | `[^민1-60-1]` |
| 민법3(물권) | 민3 | `[^민3-18]` |
| 형법1 | 형1 | `[^형1-r5]` |
| 헌법1 | 헌1 | `[^헌1-45]` |
| 국제법총론 | 국총 | `[^국총-12]` |

- 기존 고아 각주(`[^60-1]` 등)는 위 네이밍으로 마이그레이션하거나, 정의를 추가하여 해소
- 중복 ID 금지: 동일 파일 내에서 유일해야 함

### 정의 배치 (위키식: 파일 맨 밑)

- 각주 정의(`[^id]: ...`)는 **파일 맨 밑**에 모아서 배치 (위키 스타일)
- 파일 끝에 `<!-- footnotes -->` 주석으로 각주 블록 시작점 표시
- 정의 형식: `[^id]: 《교재명》 p.XX` 또는 `[^id]: 《교재명》 p.XX | "짧은 맥락"`
- 섹션별 분산 배치는 하지 않음 (가독성·유지보수 우선)

### 고아 각주 금지

- 참조(`[^id]`)에는 반드시 대응하는 정의(`[^id]: ...`)가 존재해야 함
- 정의에는 반드시 대응하는 참조가 존재해야 함
- `audit_footnotes.py`로 정기 감사 (auto-index 스킬)

## 백링크(Backlink) 규칙

### 적용 범위

**과목 내 링크만** 허용. 과목 간 교차 링크는 사용하지 않는다.

| 허용 | 예시 |
|------|------|
| 같은 과목 내 노트 간 | 민법1 ↔ 민법3, 형법1 중간 ↔ 기말 |
| 같은 파일 내 섹션 간 | `[[#물권변동의 요건]]` |

| 금지 | 예시 |
|------|------|
| 과목 간 교차 | 민법 → 형법, 헌법 → 민법 |

### 링크 형식

| 유형 | 형식 | 용도 |
|------|------|------|
| 타 파일 섹션 | `[[파일명#섹션명]]` | 정밀 교차참조 |
| 타 파일 (별칭) | `[[파일명#섹션명\|표시텍스트]]` | 자연스러운 인라인 |
| 같은 파일 섹션 | `[[#섹션명]]` | 내부 참조 |

### 배치 방식

1. **`> 관련:` 블록** (권장): 섹션 상단 또는 하단에 관련 링크 모음
   ```markdown
   > 관련: [[민법3_전경운_중간_정리노트#물권변동의 요건]] (§186)
   ```

2. **인라인** (자연스러운 맥락이 있을 때):
   ```markdown
   표현대리 3유형은 [[민법1_강혜림_기말_정리노트#표현대리|기말 범위]] 참조.
   ```

3. **중간↔기말 연결**: 범위 계속 시 섹션 상단에 명시
   ```markdown
   > 기말 범위 계속: [[민법1_강혜림_기말_정리노트#무효·취소]]
   ```

### 제한

- `##` 섹션당 백링크 최대 **3개** (과도한 링크 방지)
- 링크 대상은 실제 존재하는 `##` 또는 `###` 헤딩이어야 함
- 깨진 링크(대상 헤딩 변경/삭제)는 `suggest_backlinks.py` 감사로 탐지

## 공통 규칙

- 각주 없는 법리 단정 금지 (`"발췌"[^id]` + `[^id]: 출처` 필수)
- 도표는 바로 아래 문장 블록이 동일 내용을 설명할 때만 유지
- 요건은 반드시 ①②③ 번호 문장형
- 예외 중심 법리는 `원칙 → 예외` 구조
- 서브개념도 개념 한 줄 또는 판례요지 한 줄 최소 유지
- **페이지 마커**: 모든 `##` 섹션에 챕터별 페이지 마커 주석 필수 (위 규칙 참조)
- **각주**: 마크다운 각주 필수, 정의는 파일 맨 밑에 배치 (위 각주 규칙 참조)
- **백링크**: 과목 내 관련 쟁점 간 `[[]]` 링크 필수 (위 백링크 규칙 참조)
