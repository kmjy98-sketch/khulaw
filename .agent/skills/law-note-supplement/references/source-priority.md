# Source Priority Rules

## 기본 우선순위 (높음 → 낮음)

1. **교수 교재 / 강의안** — 직접 소스. 최우선.
2. **조문 원문 / 판례 원문** — 국가법령정보센터, 대법원, 헌재 공식 원문.
3. **사례형 교재** — 교수 집필 사례 문제집.
4. **사례형 자료** — 수업 배포 사례 자료.
5. **선택형 자료** — OX, 기출 선지 자료.
6. **정리 자료** — 동료 노트, 단권화 요약본.

## 충돌 처리 규칙

- 소스 간 충돌 발생 시: 충돌 사실을 명시한다. 묵묵히 어느 쪽을 선택하지 않는다.
  - 형식: `[소스 충돌: 《A》p.X vs 《B》p.Y — 보류]`
- 소스가 주장을 뒷받침하지 않으면:
  - `소스에서 확인할 수 없습니다` 또는 `자료 부족—보류`
- 페이지 번호, 판례 번호를 추정하거나 임의 생성 금지.

## 단권화(통합본) 관련

- 원본 노트와 단권화가 충돌 시: 원본 노트 우선.
- 단권화는 원본 노트가 안정된 후 동기화.
- 동기화 시 해시 또는 섹션 번호 기준으로 검증.
