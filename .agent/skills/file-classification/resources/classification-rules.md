## 1. 폴더 구조 수정 원칙

> **핵심 원칙 1**: 별도 중간 루트를 두지 않고, 현재 듣고 있는 주 강사/교수의 폴더를 **루트로 승격**시킵니다. 정렬 가독성을 위해 현재 수강 강의 폴더는 낮은 번호 prefix(`10.`, `20.`...)를 붙입니다. (예: `1.민사/송영곤_기본민법/`)
> **핵심 원칙 1-1**: subject root 직하의 표준 분류 폴더는 `기출/`, `91.보관/`, `92.개념/`, `93.참고/`, `94.교재/`, `95.기타자료/`, `96.기타/`처럼 높은 번호를 붙여 강의 폴더 아래에 정렬합니다. 강의/교수 폴더 하위의 `기출/`, `보관/`, `참고/`, `교재/`, `기타/`는 기존 이름을 유지합니다.
> **핵심 원칙 2**: 그 외 종전 타 강사나 내신 교수 자료는 모두 `{과목}/보관/{교수명_과목명}/`에 배치합니다.
> **핵심 원칙 3**(2026-07-04 사용자 확정 — 4분류 정합): `기출/` = **변시모고/**(변호사시험 모의고사·채점기준표) + **진급시험/**(법전원 진급시험 문제·답안). **md 정리·해설본은 `내신/마크다운/`으로 분리**(선배 정리본·내신 md도 `내신/`). 특정 교수 귀속이 명확한 학교시험 원자료는 종전대로 그 교수의 `_보관/_강의/{교수}/기출(학교시험)/` 유지 가능.
> **핵심 원칙 4**: HWP/HWPX 원본 파일은 `_원본보관/`에 보관합니다.
> **핵심 원칙 5**: (구 `스터디 답안지/` — 2026-06-15 해체. `.hwp` 원본은 `_원본보관/hwp_전체/`로 통합, 핵심원칙4와 일원화.)

## 2. 분류 Flow

```text
0. 제외 경로 확인
   ├─ 공유드라이브/ 하위 경로인가? → 대상에서 제외 (작업 종료)
   ├─ (구 스터디 답안지/ — 2026-06-15 해체 → .hwp 원본 _원본보관/hwp_전체/)
   ├─ _원본보관/ 하위인가? → 대상에서 제외
   └─ NO → 1단계로 진행

1. 파일명 인식 가능?
   ├─ NO → `5.기타/_inbox/` (사용자 확인)
   └─ YES → 2단계

1a. HWP 원본 판별
   ├─ .hwp/.hwpx 파일인가?
   │   └─ YES → `_원본보관/{과목}/`으로 보관 (분류 완료)
   └─ HWP 아닌 파일 → 2단계로

1b. 노트앱 파일 판별
   ├─ GoodNotes/Notability 관련 파일/폴더? → `5.기타/_노트앱/`으로 이동
   └─ NO → 2단계로

1c. 전사원본 판별
   ├─ 전사원본 파일 (.m4a 등 녹음 원본)? → `_원본보관/전사원본/`으로 이동
   └─ NO → 2단계로

2. 키워드 매칭 + 과목 판단
   ├─ 민사 키워드 → 2a단계
   ├─ 형사 키워드 → 2a단계
   ├─ 공법 키워드 → 2a단계
   ├─ 선택법 키워드 → 선택법/{과목}/
   ├─ LEET/논리 키워드 → 9.로스쿨입시/LEET/
   ├─ 입시 키워드 → 9.로스쿨입시/입시/
   ├─ 노트앱/GoodNotes/Notability → 5.기타/_노트앱/
   ├─ 파일명이 `pXXX-XXX.md` 패턴의 추출본이거나 `transcript.txt`, `part.md` 등 강의 전사문인가?
   │   └─ YES → `5.기타/_RAG_데이터/{과목}/{해당교수_과목}/` 하위(`교재_추출/` 또는 `전사문/`)로 이동
   ├─ 파일명(또는 내용)에 진행중 강사(강성민, 김기용, 전경운, 이진, 강혜림, 송영곤, 국제법총론) 키워드 존재?
   │   └─ YES → `{명칭_번호.과목}/{해당강사_과목}/` (루트 승격)
   ├─ 파일명(또는 내용)에 진행중 강사 목록에 없는 다른 교수/강사 키워드 존재? (예: 서보학, 박승수, 박수곤 등 특정 가능한 내신 교수 포함)
   │   └─ YES → `{과목}/보관/{해당교수_과목}/`
   │       └─ 만약 그 파일이 해당 교수의 학교시험/내신 기출이라면? → `{과목}/보관/{해당교수_과목}/학교시험/` 또는 `기출/` 하위
   ├─ 교수/강사 이름은 없으나 변시/모의고사 관련 키워드 존재?
   │   └─ YES → `{과목}/기출/` (과목별 공통 기출)
└─ NO (강사 불특정) → 공통 개념일 시 `{과목}/92.개념/`, 또는 `{과목}/91.보관/기타/`

3. (2단계 매칭 성공 시) 자료 유형 분류 (폴더 내 하위)
   ├─ [주요 자료]
   │   ├─ 교재 PDF / 교안 / 강의자료(.zip) → 교재/
   │   ├─ 교재 추출 텍스트 (.md, _pXXX 패턴) → 교재_추출/
   │   ├─ 전사문 (_partXX.md) / transcript.txt → 전사문/
   │   ├─ 기출/학교시험/모의고사/모의답안 → 기출/
   │   └─ 수업정리/정리/노트/요약본/필기노트 → 정리/
   ├─ [기타 자료] (주요 외 모두)
   │   ├─ 사례형 문제/풀이 → 기타/
   │   ├─ 선택형/DT 문제 → 기타/
   │   ├─ 기록형 문제 → 기타/
   │   ├─ 참고 자료 → 기타/
   │   └─ 그 외 분류 불명 → 기타/
   └─ 녹음 파일 (.m4a) → _원본보관/전사원본/

3a. 교재 중심 교수/강사 폴더 처리
   ├─ 해당 교수 폴더에 기출/정리 등이 없고 교재 PDF만 존재?
   │   └─ YES → 하위에 `교재/` 폴더 신설 후 교재 파일 이동
   └─ 기출/정리 등 다른 자료도 있다면 → 주요 + 기타 구조로 정리
```

## 3. 자료 유형 세부 분류표

### 주요 폴더 (5종)

| 폴더명 | 포함 자료 | 파일 패턴/키워드 |
|--------|----------|--------------------|
| `교재/` | 교재 PDF, 교안, 강의자료(.zip), 보충자료 PDF | `논점민강_*.pdf`, `*교재*.pdf`, `*강의자료*.zip`, `*보충자료*.pdf` |
| `교재_추출/` | 교재에서 추출한 텍스트 (OCR/변환) | `*_pXXX-XXX.md`, `*_p001-030.md`, chunks_index.json |
| `전사문/` | 강의 전사 교정본, 전사 원본 텍스트 | `*_partXX.md`, `*_transcript.txt` |
| `기출/` | 내신 기출, 변시/모의고사, 모의답안 | `*기말*`, `*중간*`, `*고사*`, `*모답*`, `*답안*` |
| `정리/` | 수업정리, 필기노트, 요약본, 쟁점노트 | `*정리*`, `*필기노트*`, `*요약*`, `*쟁점*`, `*노트*` |

### 기타 폴더

| 폴더명 | 포함 자료 | 키워드 |
|--------|----------|--------|
| `기타/` | 사례형, 선택형, 기록형 문제, 참고자료, 분류 불명 | 사례, 선택형, 기록형, 참고, 템플릿 |

### 교수/강사 폴더별 하위 구조 예시

```text
{교수명}_{과목명}/
├── 교재/          # 교재 PDF, 교안, 강의자료 zip
├── 교재_추출/     # 교재 텍스트 추출 (.md, _pXXX 패턴)
├── 전사문/        # 전사 교정본 (_partXX.md), transcript.txt
├── 기출/          # 내신 기출, 모의답안
├── 정리/          # 정리본, 필기노트, 요약본
└── 기타/          # 사례, 선택형, 참고 등
```

> **참고**: 교재 PDF만 있는 교수 폴더(기출/정리 없음)의 경우에도 `교재/` 하위 폴더를 만들어 정리합니다.

## 4. 원본보관 규칙

### HWP 원본 보관

* **모든** HWP/HWPX 파일은 `_원본보관/{과목}/`에 보관
* 과목 판별은 파일명 키워드 기준으로 하위 폴더에 정리

### 전사원본 보관

* 각 강사 폴더 하위의 `전사원본/` 파일은 `_원본보관/전사원본/`으로 이전
* .m4a 등 녹음 원본 파일도 `_원본보관/전사원본/`으로 통합
