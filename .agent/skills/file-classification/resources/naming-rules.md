# 파일명 명명 규칙

> ⚠️ 괄호 `()` 사용 금지 - 검색/인덱싱 인식 오류 방지
> ⚠️ 공백 사용 금지 — 밑줄 `_` 대체
> ⚠️ **약어 사용 금지** - 전체 단어로 작성
> ⚠️ **새 파일 작성 시 명명/분류 규칙 위반 금지** - (AI 에이전트 생성 파일 포함)
> ⚠️ 원제에 괄호가 있어도 파일명에서는 괄호를 제거하고 의미만 남김
> 운영 메모(2026-06-15): 하단의 오래된 예시 중 `{과목}/{교수명_과목명}/교재/` 구조는 레거시다. 실제 이동·신규 생성은 "폴더 구조 (2026-06-15 책 중심 전환)" 문단을 우선하여, 책은 과목 직속 책이름 폴더에 두고 강의 부속은 `{과목}/_강의/{강의}/` 하위에 둔다.

## 1. 파일명 핵심 원칙

> **핵심 원칙: 파일명은 폴더 구조와 독립적으로 식별 가능해야 한다.**

책 제목의 고유성에 따라 **일반명사**와 **고유명사**를 구분하여 파일명을 결정합니다.

### A. 고유명사 책이름 (원칙)

- **대상**: 조어, 브랜드명, 합성어 등으로 해당 책을 유일하게 식별 가능한 경우
  - 예: `민법의맥`, `반반형법`, `논점민법강의`, `형법요론`
- **형식**: `책이름_분야_연도` (저자명 생략)
  - 예: `민법의맥_물권_25.pdf`, `형법요론_총론보충_24.pdf`
- **동일 책이름이 여러 저자에 존재하는 경우에만** 저자명을 맨 앞에 추가
- 형식: `저자_책이름_분야_연도`
- 현재 해당 목록: **없음** (표지 확인 결과 모든 책이름 고유)
  - ~~`민법1`~~ → 폴더명이었으며, 실제 책이름은 각각 다름 (민법강의, 민법총칙 등)

### B. 일반명사 책이름 (저자명 필수)

- **대상**: 과목명 자체이거나 서술적 제목이라 파일명만으로 특정 책을 식별할 수 없는 경우
  - 예: `사례연습`, `형법총론`, `형법각론`, `민법입문`
- **형식**: `저자_책이름_분야_연도`
  - 예: `곽낙규_사례연습_물권_24.pdf`, `서보학_형법총론_25.pdf`, `이주원_형법총론_26.pdf`

- **사용자에게 질문** (임의 판단 금지)

## 구성 요소

### 1. 책이름 또는 강사명_세부과목 (필수)

- 고유명사: **PDF 표지의 실제 제목** 사용 (강의명·과목명 아님)
- 일반명사: **강사명_세부과목** (원래 책 제목 대신 축약)
- **전체 단어로 작성 (약어 금지)**
- 단, **고유명사 교재의 분철/발췌본**은 표지·목차 기준으로 의미가 분명하면 **2~4글자 수준 세부 제목** 허용
  - 예: `논점민법강의_권리대리_26.pdf`, `논점민법강의_계약각론_26.pdf`, `논점민법강의_채권각론_26.pdf`
- `복사`, `_1`, `_2`, `part-2` 같은 **사본/임시 표기**는 최종 파일명에 두지 않음

### 2. 분야 (선택)

- 세부 영역 (물권, 채권, 총칙 등)
- 회차: `_1회`, `_15회` 등 (강의 보충자료 등에 적용)
- 분철본인데 **공식 분권명은 없고 전체본 일부만 확인되는 경우**: 페이지 범위 표기 허용
  - 예: `논점민법강의_채권관계1_p001-050_26.pdf`
- 없으면 생략

### 3. 연도 (필수)

- **강의 연도** 기준 2자리 (출판 연도·대비 연도 아님)
  - 예: "민법의맥 2026 대비" → 강의가 24년이면 `_24`
- 제목에 `20XX 대비` 표기가 있어도 그 숫자를 파일명 연도로 직접 쓰지 않음
- `20XX 대비` 교재는 **반드시** 표지·머리말·판권지에서 출판연도를 먼저 확인
- 별도 강의연도 근거가 없으면 **출판연도 2자리**를 파일명 연도로 사용
  - 예: "작은 변사기 형법 2026 대비", 머리말이 `2025. 3. 10.`이면 `_25`
- 맨 끝에 표기: `_24`, `_25`, `_26`
- 판차(edition)는 책이름에 포함: `논점민법강의_12판` (연도와 별개)
- **연도 예외**: 전사문(`전사문`, `교정문`, `수업노트/수업정리`), 기출문제(`기출`), 질문답안 등은 명확한 연도가 종속적이지 않은 특성상 연도 표기(`_YY`) 부분 생략 허용
- **연도 판단 불가 시**: 임의 표기 금지, 연도 표기(`_YY`) 생략 허용
- **자동 검사 원칙**: 연도를 확정할 근거가 파일명/경로에서 확인되지 않으면 `연도 표기(_YY) 누락` 경고를 내지 않음

> **과목**은 폴더가 결정하므로 파일명에 포함하지 않음
> 민사/ → 민법, 형사/ → 형법, 공법/ → 헌법·행정법, 선택법/ → 개별과목
>
> **유형**도 폴더가 결정하므로 파일명에 기재 금지
> 예: `교재/` 폴더 안에 있으면 파일명에 `_교재` 붙이지 않음
> 단, 책 제목 자체에 "사례""기록" 등이 포함된 경우는 책이름의 일부이므로 유지
> 예: `민법사례연습_물권_24.pdf` ("사례연습"은 책 제목)
>
> **폴더명**은 `교수명_과목명/` 형식을 유지 (파일명 규칙과 무관)

## 폴더 구조 (2026-06-16 **하이브리드** 전환 — 사용자 확정. 구 '책 중심' 일부 수정)

> **핵심: 강의 듣는 책 vs 안 듣는 책을 구분해 다르게 배치**(강의자료를 무조건 책에서 분리하면 오히려 찾기 어렵다는 피드백).
> **① 현행 강의(송영곤·김기용·강성민) = 강의 중심**: `{과목}/_강의/{교수_강의}/`에 **교재(책)·강의자료·전사문·정리·기출 함께**. 교재는 `{강의}/교재/{책이름}/`. 예) `1.민사/_강의/30.송영곤_기본민법/교재/논점민법강의/`, `2.형사/_강의/10.김기용_형법교안/교재/김기용형총/`, `3.공법/_강의/10.강성민_헌법/교재/강성민헌법OX/`.
> **② 그 외 = 책만**: 과목 직속 `{과목}/{책이름}/` 단독. 예) `1.민사/김준호민법강의/`, `1.민사/신민사법선택형/`, `2.형사/반반형법/`, `3.공법/헌법300/`.
> **③ 지난학기**: `{과목}/_강의/1-1_지난학기/{교수_강의}/`. 같은 책 중복 분할 1형태(1차 편/장 우선, 2차 작업용은 불필요 시 정리), 완전원본 통권 → 루트 `10.도서관/`.
> ④ 책 폴더명 = 책이름(고유명사) 또는 강사명_책이름(일반명사·동명이서). 파일명은 여전히 `책이름_분야_연도`(아래 규칙). 강의 폴더 안에서 `교재/정리/사례/선택형/전사문/` 유형 하위 사용.

| 유형 폴더 | 설명 | 예시 경로 |
|-----------|------|-----------|
| `교재/` | 기본서, 교재 원본 | `민사/송영곤_기본민법/교재/` |
| `정리/` | 주요쟁점 정리, 기초법리, 요약 | `민사/송영곤_기본민법/정리/` |

| `선택형/` | 선택형, DT 문제 포함 | `민사/송영곤_기본민법/선택형/` |
| `기록형/` | 실무 기록형 문제 | `민사/송영곤_기본민법/기록형/` |

## 녹음파일 및 전사문 네이밍

### 녹음파일명 (업로드 시)

> 녹음 시 빠른 저장을 위해 **약어 허용**. 전사 파이프라인에서 풀네임으로 자동 변환.

**형식**: `{과목약어} {주차}-{차시}[.파트].{확장자}`

**예시:**

- `헌1 1-2.m4a` → 헌법1 이진, 1주차 2차시
- `형1 1-3.m4a` → 형법1 서보학, 1주차 3차시
- `민1 1-1.m4a` → 민법1 강혜림, 1주차 1차시
- `민3 1-1.m4a` → 민법3 전경운, 1주차 1차시

### 약어 → 풀네임 매핑

| 약어 | 강의 | 교수/강사 | 과목 폴더 | 상태 |
|------|------|----------|----------|------|
| `헌1` | 헌법1 | 이진 교수 | `공법/이진_헌법1/` | 참고/보관 |
| `형1` | 형법1 | 서보학 교수 | `형사/서보학_형법/` | 참고/보관 |

## 파일명 확정 절차

> 파일명 변경·분류 작업 시 반드시 순서대로 수행

### 1. 책 유형 식별

- PDF 표지·목차를 보고 아래 유형 판별 → **유형 폴더** 결정

| 유형 | 판별 기준 | 대상 폴더 |
|------|-----------|-----------|
| 기본서 | 체계적 법리 서술, 판수 표기, 출판사 명시 | `교재/` |
| 사례집 | "사례연습", "사례형", 청구권 체계 구성 | `사례/` |
| 선택형 자료 | "DT", "선택형", 5지선다 문제 포함 | `선택형/` |
| 기록형 자료 | "기록형", 실무 서류 작성 문제 | `기록형/` |
| 모의답안 | "모답", "모의답안", 답안 양식 | `모의답안/` |
| 강의 보충자료 | 강의계획서, 보충자료, 진도표, 주요쟁점 정리 | `정리/` |
| 전사문 | `_raw.md`, `_processed.md`, 강의 녹취 | `전사문/` |

- **판단이 어려운 경우** → 사용자에게 질문 (임의 판단 금지)

### 2. 고유명사/일반명사 판정

- PDF 표지의 책 제목을 확인하여 구분
- **고유명사**: `책이름_분야_연도`
- **일반명사** (예: 사례연습, 형법총론): `저자_책이름_분야_연도`
- 판단 어려우면 → 사용자에게 질문

### 3. PDF 표지 확인 → 책이름 결정

- **PDF 첫 1-2페이지(표지)를 열어** 실제 제목·저자·판차 확인
- 스크립트: `python .agent/skills/pdf-ingest/scripts/pdf_reader.py <pdf> --pages 1-2`
- 확인 항목: 책 제목, 저자/강사명, 출판연도, 판차
- 파일명과 표지 정보가 불일치 시 → **표지 기준**으로 파일명 결정
- **표지에서 제목 확인이 불가능한 경우** → 사용자에게 질문

### 4. 중복파일 확인

- 파일명이 유사한 경우 **실제 내용(표지·목차)을 비교**하여 동일 파일 여부 판단
- 파일 크기만으로 판단 금지 — 분철·페이지 범위 차이 가능
- **우선순위 판정 로직**:
  1. OCR 여부: 한쪽만 OCR 처리가 되어 있다면 **OCR 파일**을 우선시
  2. 최신 여부: 내용 갱신이 있는 최신 파일
- 동일 내용 확인 시 → 우선순위 버전 유지, 나머지(구 버전/non-OCR)는 `5.기타/_trash/` 폴더로 이동
- 동일 내용인데 **폴더/이름만 어긋난 오배치 사본**도 원본 유지 후 `5.기타/_trash/`로 이동
