## 5단계 하강식 스캐폴딩 [law]

> **예시**: 매매계약 기반 소유권이전등기청구권

```
L0 (청구권 식별)
│   "甲은 乙에게 무엇을 청구할 수 있나요?"
│   ↓ 막힘
L1 (요건 나열)
│   "소유권이전등기청구권의 요건은 무엇인가요?"
│   ↓ 막힘
L2 (요건 정의)
│   "유효한 매매계약이란? 어떤 조건이 필요하죠?"
│   ↓ 막힘
L3 (하위 개념)
│   "성립요건(청약+승낙)과 효력요건의 차이는?"
│   ↓ 막힘
L4 (기초 정의)
│   "'청약'과 '승낙'은 각각 무엇인가요?"
│   ↓ 해결
│
L3 복귀 → L2 복귀 → L1 복귀 → L0 복귀
```

### 레벨 구조

| 레벨 | 유형 | 질문 패턴 | 목적 |
|------|------|----------|------|
| L0 | 청구권 식별 | "누가 누구에게 무엇을?" | 쟁점 발견 |
| L1 | 요건 나열 | "~의 요건은?" | 요건 체계화 |
| L2 | 요건 정의 | "~란 무엇인가?" | 요건 이해 |
| L3 | 하위 개념 | "~와 ~의 차이는?" | 개념 구분 |
| L4 | 기초 정의 | "~이란?" | 기초 지식 |

### 복귀 질문

L4 해결 후 상위로 단계별 복귀:

```
L4 해결 → L3 복귀: "그렇다면, 甲의 말은 청약인가요?"
        → L2 복귀: "매매계약은 성립한 건가요?"
        → L1 복귀: "다음 요건은?"
        → L0 복귀: "청구는 인용될까요?"
```

## 통합 힌트 시스템

> **원칙**: 오답/모르겠다 → **바로 정답 제공 금지**. 간접 힌트부터 단계별 진행.

### Fading 모드 (세션/쟁점 유형 단위)

| 조건 | Fading 모드 | 허용 힌트 |
|------|------------|----------|
| 첫 등장 | Full | 위치→조문→부분 |
| 같은 유형 재등장 | Partial | 위치→조문 |
| 2회 이상 정답 경험 | Minimal | 위치 힌트만 |
| 3회 연속 정답 | Independent | 힌트 없음 |

### 오답/모르겠다 대응 Flow

> [!IMPORTANT]
> **오답(2) 또는 모르겠다(3) 입력 시 동일한 스캐폴딩 적용**

```
[오답/모르겠다 시 Flow]
1. "왜 그렇게 생각했나요?" ← 자기 설명 유도 (선택)
2. 간접 힌트 제공 (위치/범위)
3. 재시도 기회 제공
4. 그래도 못 맞추면 → 다음 단계 힌트
5. 최종 실패 → 정답 + 해설 + SRS 점수 0~1
```

| 시도 | 대응 | SRS 점수 |
|------|------|----------|
| 1회 오답/모름 | **간접 힌트** (《교재》 p.XX 참고) + 재시도 | - |
| 2회 오답/모름 | **조문 힌트** (제○○조 확인) + 재시도 | - |
| 3회 오답/모름 | **부분 힌트** (핵심어 초성) + 재시도 | - |
| 4회+ 또는 포기 | 정답 + 상세 해설 제공 | 0~1 |

### 힌트 유형 (간접→직접 순서)

1. **위치 힌트** (가장 간접): "《기본민강》 제3장을 참고해보세요."
2. **조문 힌트**: "민법 제○○조를 찾아보세요."
3. **부분 힌트** (가장 직접): "'변__기'가 빠졌습니다."
4. ~~선택 힌트~~: A/B 선택지 제공은 사고를 방해하므로 **금지**
