# 과목별 편차 감지

> 상위 문서: [SKILL.md](../SKILL.md)

---

## 감지 신호

| 과목 | 키워드 신호 | 분석 단위 차이 |
|------|------------|---------------|
| **민법** | 청구권, 항변, 계약, 물권, 채권 | 청구권/항변 체계 |
| **형법** | 구성요건, 위법성, 책임, 공범 | 범죄체계론 (Tb-Rw-S) |
| **민사소송법** | 소송요건, 변론, 증거, 판결 | 소송절차 단계 |
| **형사소송법** | 수사, 공소, 공판, 증거법칙 | 절차 단계 |

---

## 자동 감지 규칙

```
1. 파일명/폴더에서 과목 키워드 매칭
2. 문서 내용에서 분석 단위 키워드 스캔
3. 감지된 과목에 따라 분석 구조 자동 전환
```

---

## 과목별 분석 구조

### 민법 (기본)

```
청구권 → 요건 → 포섭 → 항변 → 재항변 → 결론
```

### 형법

```
행위 → 구성요건해당성 → 위법성조각사유 → 책임조각사유 → 결론
```

### 민사소송법

```
소송요건 → 본안판단 → 입증책임 → 증거평가 → 판결
```

### 형사소송법

```
소송조건 → 위법수집증거 → 증거능력 → 증명력 → 판결
```

## 편차 알림

과목이 감지되면 다음 알림 출력:

```
[과목 감지] {과목}법 분석 구조 적용
분석 단위: {analysis_unit}
기본 구조: {structure}
```
