# 소크라틱 세션 로더 Skill

> 소크라틱 학습 세션 시작 시 자동으로 자료 준비 + 세션 초기화

---

## Phase 0: 세션 초기화 (필수)

세션 시작 시 다음 단계 실행:

### Step 0-1: 상태 파일 확인

1. `.agent/state/progress.json` - 현재 전사문/교재 진도
2. `.agent/state/learning.json` - 학습 진도, 취약점
3. **SRS 복습 조회** (자동 실행):

```bash
python .agent/skills/spaced-repetition/scripts/srs_scheduler.py --today
```

### Step 0-2: qmd 벡터/BM25 검색 (RAG 2.0)

**Concept 기반 검색** (helper: `.agent/lib/qmd_search.py`):

```bash
python -c "import sys; sys.path.insert(0, '.agent/lib'); from qmd_search import qmd_search; [print(h['title'], h['path'], h['score']) for h in qmd_search('[현재 쟁점]', k=5)]"
```

**검색 흐름:**

1. `curriculum.json` → 현재 unit의 `concept_ids` 확인
2. `alignment.json` → 해당 Concept의 페이지 범위 확인
3. qmd 검색 (law-notes 컬렉션, 정리노트 + `sync/_교재원문/` 통합) → 관련 청크 반환
4. 반환된 청크에서 근거 인용

> [!IMPORTANT]
> 소크라틱 문답 시 **qmd 검색 결과**에서 근거 인용.
> 인용 형식: `《교재명》 p.XX` 또는 `[[chunk_stem]]`

### Step 0-3: Auto-Loader 실행

```bash
python .agent/skills/socratic-loader/scripts/socratic_loader.py <전사문> --textbook <교재PDF> --cache <캐시폴더>
```

**자동 추출 단계:**

1. 전사문에서 `(페이지 X)` 패턴 파싱 → 페이지 범위 추출
2. 교재 PDF → 해당 페이지 텍스트 추출 → `교재_추출/` 캐싱
3. `problem_index.json` → 관련 문제 검색

### Step 0-3-1: 법령 API 가용 확인 (law_api.py)

`.agent/lib/law_api.py`(법제처 직접 API)가 동작하는지 확인한다(`search-law "민법"` 1건).
- 사용 가능 → 세션 배너에 `법령 API: 사용 가능` 표시. socratic-core가 정답 공개 시 조문 원문 자동 조회 가능.
- 미설정/불가 → `법령 API: 미설정` 표시. qmd 검색 청크 근거만 사용.

### Step 0-4: 세션 시작 출력

```
[세션 시작]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📅 마지막 학습: YYYY-MM-DD

🆕 미해결 쟁점: Y개

⚖️ 법령 API: 사용 가능 / 미설정

👉 "복습" / "새 주제" / "[쟁점명]" 선택
```

## 자료 구조 원칙 (Source Structure)

> **핵심**: 교재 중심 개념 전개 + 전사문 진도 확인 + 문제집 완전 소화

### 소스 역할 분담

| 역할 | 소스 유형 | 활용 목적 | 파일 패턴 |
|------|-----------|----------|-----------|
| **메인** | 교재 (1-N) | 개념 전개, 체계적 법리 | `(1-*)_*_(교재).pdf` |
| **보조** | 전사문 (5-N) | 진도 확인, 빈출 표시, 교재 보충 | `(5-*)_*_전사문*.md` |
| **문제** | 문제집 전체 | 관련 문제 **전부** 풀이 | `(3-*), (4-*)` |

### 파일 필터링 규칙 (필수)

> [!CAUTION]
> **유형번호 `(2-*)`와 `필기/` 폴더는 참조 금지**.
> 수업정리/필기 파일(part01, part02...)은 학습자의 2차 가공물이므로 인용 불가.

**허용 (검색 대상):**

- `교재/` 폴더의 `(1-*)` 파일 → 개념 근거
- `전사문/` 폴더의 `(5-*)` 파일 → 진도/빈출 확인
- `교재/` 폴더의 `(3-*)`, `(4-*)` 파일 → 문제 출제

**제외 (검색에서 배제):**

- ❌ `필기/` 폴더 전체
- ❌ `(2-*)` 유형번호 파일 전체
- ❌ 파일명에 `수업정리`, `part` 포함 파일

**검색 시 폴더 경로 필터:**

```
검색 허용: */교재/*, */전사문/*
검색 제외: */필기/*
```

### 자료 활용 흐름

```
[학습 흐름]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 교재 (메인)
   └─ 개념 정의, 요건 체계, 판례 법리
   └─ 소크라틱 질문의 정답 근거

2. 전사문 (보조)
   └─ 현재 진도 범위 확인
   └─ 교재에서 넘어간 부분 보충
   └─ 빈출/중요 표시 확인
   └─ 강사 설명 스타일 참조

3. 문제집 (전부)
   └─ 해당 쟁점 관련 문제 **전부** 검색
   └─ 선택형(DT) + 사례형 혼합 출제
   └─ 오답 → 취약점 등록 → SRS 연동
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 개념-문제 혼합 원칙

> **목표**: 개념 학습과 문제 풀이가 자연스럽게 혼합

1. **개념 Q&A 1~2회** → 관련 **선택형 1문제**
2. **요건 정리 완료** → 관련 **사례형 1문제**
3. **쟁점 종료 전** → 해당 쟁점 **남은 문제 전부**

```
[혼합 예시]
Q1. 동시이행항변권의 요건은? (개념)
Q2. 견련성이란? (개념)
→ [DT 선택형] 동시이행 관련 5지선다 (문제)
Q3. 이행제공의 종류는? (개념)
→ [사례형] 동시이행 적용 사례 (문제)
→ [남은 문제 전부] 해당 쟁점 관련 미풀이 문제
```

### 문제 전량 풀이 규칙

> **원칙**: 해당 쟁점 관련 문제는 **건너뛰지 않고 전부** 풀이

```
[문제 검색]
1. 현재 쟁점 키워드 추출 (예: 동시이행, 제536조)
2. 문제 파일 전체 검색:
   - (4-*) 선택형: 해당 키워드 포함 문제
   - (3-*) 사례형: 해당 쟁점 적용 문제
   - (1-*) 사례 교재: 해당 범위 문제
3. 검색된 문제 **전부** 순차 출제
4. 미풀이/오답 문제 우선
```

## 자료 참조 우선순위

> 파일명 형식: 고유명사 → `책이름_분야_연도`, 일반명사 → `강사명_세부과목_연도`, 동일 책이름 → `강사명_책이름_분야_연도` (연도 필수, 유형은 폴더로 분류)

### 개념 참조 우선순위 (소크라틱 문답용)

> **핵심**: 교재가 메인, 전사문은 보조. 수업정리(정리)는 참조하지 않음.

| 순위 | 유형번호 | 역할 | 활용 |
|------|----------|------|------|
| **1순위** | (1) | 교재 | 개념 정의, 요건 체계, 판례 법리 |
| **2순위** | (5) | 전사문 | 진도 확인, 빈출 표시, 교재 보충 |
| ~~제외~~ | ~~(2)~~ | ~~수업정리~~ | ~~참조 불가 - 2차 가공물~~ |

> [!IMPORTANT]
> 소크라틱 문답 시 **교재(1-N)에서 근거**를 찾고, 전사문(5-N)은 진도/빈출 확인용으로만 사용.
> 수업정리(2-N) 필기 파일은 **인용 금지** (학습자가 직접 작성한 2차 가공물).

### 문제 참조 우선순위

| 순위 | 유형번호 | 조건 | 설명 |
|------|----------|------|------|
| **1순위** | (1) | 사례형 교재 | 곽낙규/박승수 등 사례연습 교재 |
| **2순위** | (3) | 사례형 자료 | 사례 문제/풀이 자료 |
| **3순위** | (4) | 선택형 자료 | DT 포함 선택형 문제 |
| **4순위** | (5) | 기타 | 그 외 자료 |

### 사례형 교재 판별

```
(1-N) 파일 중 다음 키워드 포함 시 → 사례형 교재로 분류:
  - 사례연습, 사례, 기본사례, 사례의맥
  - 곽낙규, 박승수, 윤동환 (저자명)
```

### 사례형 교재 참조

| 교재 | 강조점 | 활용 시점 |
|------|--------|----------|
| 곽낙규 | 청구권→항변→재항변 체계 | 청구권 목차 작성 |
| 박승수 | 유형별 분류 + 쟁점 표시 | 쟁점 분류 |
| 윤동환 | 쟁점간 연결관계 | 복합 쟁점 분석 |
| 송영곤 | 진도별 쟁점 배열 | 범위 설정 |

**유사 문제 검색:**

```
[쟁점 발견: 동시이행항변권]
→ 1순위 자료 (1-N 사례형 교재) 검색
→ 발견 시: "유사 문제가 《곽낙규》 p.XX에 있습니다. 먼저 요건을 정리해볼까요?"
```

## 주요 기능

### 1. 전사문 페이지 파싱

전사문에서 `## N. 제목 (페이지 X)` 패턴 자동 추출

```powershell
python scripts/socratic_loader.py "전사문_part01.md" --json
```

**출력:**

```json
{
  "pages": [["체력 관리", 2], ["공부 방법", 3], ["민사집행법 기초", 6]],
  "page_range": [2, 9]
}
```

### 2. 교재 PDF 텍스트 추출 + 캐싱

```powershell
python scripts/socratic_loader.py "전사문.md" --textbook "교재.pdf" --cache "30.송영곤_기본민법/교재_추출"
```

- 추출된 텍스트: `교재_추출/{교재명}_p{start}-{end}.md`
- 캐시 재사용: 동일 범위 재추출 시 캐시 반환

### 3. 문제 인덱스 연동

```powershell
python scripts/socratic_loader.py "전사문.md" --index ".agent/state/problem_index.json"
```

### 4. RAG 검색 옵션

```powershell
# RAG 검색 활성화
python scripts/socratic_loader.py "전사문.md" --rag --json
```

**출력 예시:**

```json
{
  "rag_chunks": [
    {"chunk_id": "1-01_p013", "page": 13, "chapter": "제1장 자연인", "score": 0.78}
  ]
}
```

## 전사문-교재 매핑

전사문 파일 패턴에서 교재를 자동 매핑:

| 전사문 패턴 | 교재 패턴 |
|------------|----------|
| `(5-NN)_*_전사문(X~Y)` | `(1-NN)_*_<권리주체/법률행위 등>` |

> 실제 매핑: `progress.json` 또는 `curriculum.json`에서 관리

## 배치 추출 (RAG 2.0용)

### 전체 교재 청킹

```powershell
python scripts/batch_extract.py "1.민사/30.송영곤_기본민법/교재" "1.민사/30.송영곤_기본민법/교재_추출" --chunk-size 30
```

**기능:**

- 모든 `(1-*)` 교재 PDF → 30페이지 단위 청크 추출
- 법률 키워드 자동 추출 (조문, 판례)
- `chunks_index.json` 인덱스 생성

**출력:**

```
교재_추출/
├── chunks_index.json          # 청크 인덱스
├── (1-01)권리주체_p001-030.md
├── (1-01)권리주체_p031-060.md
└── ...
```

### 인덱스 구조

```json
{
  "chunks": [
    {
      "id": "(1-01)권리주체_p1-30",
      "source": "(1-01)권리주체.pdf",
      "pages": "1-30",
      "keywords": ["제1조", "관습법", "80다3231"]
    }
  ]
}
```
