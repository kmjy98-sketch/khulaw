# Consensus Scoring Workflow (합의형 병렬 채점 파이프라인)

본 워크플로우는 Antigravity 에이전트가 사용자로부터 서술형 답안 채점이나 법무 문서 검토를 요청받았을 때 수행해야 하는 다중 에이전트 오케스트레이션의 표준 절차입니다.
단순 역할 분할(분업)을 지양하고, **독립 중복 전수 채점 후 교차 검증(Cross-Validation)**을 통해 LLM의 환각(Hallucination)을 최소화하고 신뢰도 높은 평가를 도출합니다.

## 1. 실행 조건
- 사용자가 사례형 학생 답안, 모의고사 답안, 또는 법무 검토 문서의 평가를 요청할 때 트리거됩니다.
- "채점해줘", "패널 리뷰 시작" 등의 명령으로 실행됩니다.

## 2. 오케스트레이션 1단계: 병렬 독립 스폰 (Spawn)
Antigravity 메인 에이전트는 `invoke_subagent` 도구를 사용하여 3명의 서브에이전트를 동시 스폰합니다.
- **중요**: 3명의 서브에이전트는 각기 다른 역할을 맡지 않습니다. 모두가 **"완전히 동일한 기준과 권한"**을 가진 독립적인 전수 채점관입니다.
- **프롬프트 템플릿**:
  ```text
  당신은 독립된 수석 민법 채점관입니다. 제공된 [답안 파일 경로]를 읽고, 처음부터 끝까지 50점 만점 기준으로 전수 채점하세요.
  누락된 요건, 잘못된 법리(논리적 모순), 판례의 태도 위반, IRAC 구조의 완결성을 모두 독자적으로 평가하여 강점과 약점, 그리고 예상 점수를 제출하세요. 다른 채점관의 의견은 존재하지 않는 것으로 간주합니다.
  ```

## 3. 오케스트레이션 2단계: 결과 수신 및 교차 검증 (Cross-Validation)
- 서브에이전트 3인으로부터 비동기 응답(메시지)이 모두 도착하면, 메인 에이전트가 이를 취합합니다.
- **교집합 분석 (Consensus)**: 3명 중 2명 이상이 공통으로 지적한 오류나 강점은 "확정된 사실"로 간주하여 높은 가중치를 부여합니다.
- **차집합 분석 (Outlier/Edge Case)**: 1명만 지적한 특이 논점(예: 구석진 판례 누락 등)은 메인 에이전트가 직접 법리적 타당성(또는 워크스페이스 내 교재 소스)을 교차 검증하여 채택 여부를 결정합니다. 만약 환각(Hallucination)으로 의심되면 기각합니다.

## 4. 오케스트레이션 3단계: 리포트 생성 및 학습 기록
1. 메인 에이전트는 검증이 완료된 결과물을 바탕으로 `_진단_YYYYMMDD.md` 아티팩트(진단 리포트)를 작성합니다.
2. 진단 리포트에는 최종 합의된 점수, 공통 지적 사항, 그리고 보완해야 할 약점(Weak Points)이 포함됩니다.
3. 도출된 약점을 `.agent/state/learning.json`의 `weak_points`에 추가하여 향후 `spaced-repetition` 워크플로우와 연동되게 합니다.
