## 3. 자료 유형 세부 분류표

### 주요 폴더 (6종)

| 폴더명 | 포함 자료 | 파일 패턴/키워드 |
|--------|----------|-----------------|
| `교재/` | 교재 PDF, 교안, 강의자료(.zip), 보충자료 PDF | `논점민강_*.pdf`, `*교재*.pdf`, `*강의자료*.zip`, `*보충자료*.pdf` |
| `교재_추출/` | 교재에서 추출한 텍스트 (OCR/변환) | `*_pXXX-XXX.md`, `*_p001-030.md`, chunks_index.json |
| `전사문/` | 강의 전사 교정본, 전사 원본 텍스트 | `*_partXX.md`, `*_transcript.txt` |
| `기출/` | 내신 기출, 변시/모의고사, 모의답안 | `*기말*`, `*중간*`, `*고사*`, `*모답*`, `*답안*` |
| `정리/` | **내가 만든** 정리노트(.md·도표추가본·쟁점노트·요약본) | `*정리*`, `*요약*`, `*쟁점*`, `*노트*` (교수 배포 필기·판서 PDF는 `강의자료/`) |
| `강의자료/` | 교수 배포 강의 산출물(강의계획서·교안·필기/판서·수업 PPT·회차 보충자료) | `*강의계획서*`, `*교안*`, `*필기*`, `*판서*`, `*N주*`, `*N회차*`, `*강의안*` |

### 기타 폴더

| 폴더명 | 포함 자료 | 키워드 |
|--------|----------|--------|
| `기타/` | 사례형, 선택형, 기록형 문제, 참고자료, 분류 불명 | 사례, 선택형, 기록형, 참고, 템플릿 |

### 교수/강사 폴더별 하위 구조 예시

```text
{교수명}_{과목명}/
├── 교재/          # 출판 교재 PDF
├── 교재_추출/     # 교재 텍스트 추출 (.md, _pXXX 패턴)
├── 강의자료/      # 교수 배포: 강의계획서·교안·필기판서·수업PPT·회차보충 (하위 유형폴더)
├── 전사문/        # 전사 교정본 (_partXX.md), transcript.txt
├── 기출/          # 내신 기출, 모의답안
├── 정리/          # 내가 만든 정리노트(.md·도표추가본)
└── 기타/          # 사례, 선택형, 참고 등
```

> **참고**: 교재 PDF만 있는 교수 폴더(기출/정리 없음)의 경우에도 `교재/` 하위 폴더를 만들어 정리합니다.
> **참고 2**: 진행중 강의의 레거시 `보관/{동명이름}/` 폴더가 남아 있으면, `교재/교재_추출`은 루트 강의 폴더로 우선 통합하고 남은 빈 폴더만 루트 `_trash/{YYYY-MM-DD}/`로 이동합니다(운영 메모 6).
