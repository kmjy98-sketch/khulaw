# LEET 문제 풀이 워크플로우

> 언어이해/추리논증 기출 및 모의고사 분석 특화
> 참조: [AGENTS.md](../../AGENTS.md) (Global Rules 준수)

---

## 1. 사전 분석 (Pre-Analysis)

문제를 풀기 전, 지문과 선지를 먼저 스캔하여 유형을 파악합니다.

### 1-1. 언어이해 (Reading)

- **지문 유형**: 인문 / 사회 / 과학 / 기술 / 예술 / 법학
- **구조 분석**:
  - 통념 반박형 / 논쟁 나열형 / 원리 설명형
  - 핵심 문장(Topic Sentence) 식별

### 1-2. 추리논증 (Reasoning)

- **문제 유형**: 규범 / 논법 / 도식 / 수리 / 과학
- **논리 구조**:
  - 전제 찾기 / 논지 강화·약화 / 반드시 참·거짓
  - 도식화 가능 여부 판단

---

## 2. Dual-Path 풀이 전략

문제 해결 시 두 가지 경로 중 하나를 선택하거나 병행합니다.

### Path A: 실전 모드 (Time Attack)

- **목표**: 빠른 정답 도출
- **방법**:
  - 지문 전체 독해 대신 발췌독 활용
  - 선지 소거법 적극 사용
  - "보류 전략" 사용 (확실치 않으면 세모 표시 후 이동)

### Path B: 분석 모드 (Deep Dive)

- **목표**: 완벽한 논리 구조 파악
- **방법**:
  - **지문 구조도** 작성
  - **모든 선지(①~⑤)**에 대한 정오 판단 근거 작성
  - 출제자의 의도 및 함정 패턴 분석

### 내부 추론 구조 (Thinking)

> Global Rules #10 Structured Thinking 적용

복잡한 추론 시 내부적으로 다음 단계 수행 (출력에는 결과만):

1. **지문 핵심 논지** 파악
2. **각 선지별** 지문 근거 매칭
3. **소거법** 적용 (확정 오답 제거)
4. **최종 판단** 및 근거 정리

## 3. 답변 형식 (Output Format)

### 선지 분석형 (기본)

```markdown
## [연도] [과목] [번호] 분석

### 1. 지문 구조
- **핵심 논지**: ...
- **문단별 요약**:
  1. ...
  2. ...

### 2. 정답 및 해설
- **정답**: ⑤
- **해설**: ...

### 3. 오답 분석 (모든 선지)
- ① [X] : 지문 2문단 "..."에 위배됨 (내용 일치 불능)
- ② [X] : 인과관계의 비약 (A→B 근거 없음)
- ③ [X] : ...
```
