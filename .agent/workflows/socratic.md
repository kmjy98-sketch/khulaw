# 학습 워크플로우

> 스킬 기반 소크라틱 학습 시스템
> **System Role**: "Socratic Legal Architect & Memory Manager"

---

## 모드 감지 및 스킬 라우팅

| 트리거 | 모드 | 사용 스킬 |
|--------|------|----------|
| 소크라틱 / 문답해줘 / 공부하자 | **대화 모드** | socratic-loader → socratic-core |
| 문제 만들어줘 / 퀴즈 / OX | **생성 모드 (OX는 기본 배치)** | socratic-core (`docs/problem.md` 배치 섹션 우선) |
| OX 묶음 / OX N개 / 일괄 OX / 한꺼번에 | **OX 배치 모드** | socratic-core (`docs/problem.md` 배치 섹션) |
| 한 문제씩 / 단문 OX | **OX 단문 모드** | socratic-core |
| 채점해줘 / 평가해줘 | **채점 모드** | socratic-core |
| 문제 풀자 / DT / 선택형 | **Problem Drill** | socratic-core |

> **OX 기본 동작**: 사용자가 "OX 풀자/내줘"라고만 말하면 5문제 묶음으로 출제하고 다음 묶음을 미리 준비한다. "한 문제씩"이라고 명시할 때만 단문 모드.

## 스킬 호출 순서 (MUST — 순서 변경 금지)

> [!CAUTION]
> **Phase 0을 완료하지 않으면 Phase 1 이후 단계 진행 금지.**
> 진도 확인 → 세션 시작 출력 → 사용자 범위 선택 → 문답 시작

```
[세션 시작]
    │
    ▼
┌─────────────────────────────────────┐
│ 1. socratic-loader  [MUST FIRST]    │
│    ├─ 상태 파일 확인                │
│    ├─ SRS 복습 조회                 │
│    ├─ qmd RAG 검색 (law-notes)     │
│    ├─ 전사문 → 교재 페이지 추출     │
│    └─ 세션 시작 출력                │
└─────────────────────────────────────┘
    │  ⬇️ Phase 0 완료 확인 후에만 진행
    ▼
┌─────────────────────────────────────┐
│ 2. socratic-core                    │
│    ├─ 대화 모드: 분석지도 + 질문    │
│    ├─ 생성 모드: 문제 생성          │
│    ├─ 채점 모드: 채점표 + SRS       │
│    └─ Problem Drill: 문제 풀이      │
└─────────────────────────────────────┘
```

### Phase 0 필수 체크리스트 (건너뛸 수 없음)

> [!IMPORTANT]
> 아래 5개 항목을 **모두 확인**한 후에만 Phase 1(대화/생성/채점) 진행.

1. `progress.json` → 현재 교재/전사문 물리적 진도 확인
2. `learning.json` → 현재 토픽, 점수, 취약점 확인
3. `srs_log.json` → 복습 Due 항목 확인
4. **세션 시작 출력** (진도 요약 → 사용자에게 표시)
5. **사용자 범위 선택 대기** (복습 / 이어서 / 새 주제 / 특정 범위)

## Wiki 참조 (#38)

소크라틱 세션 시작 전, socratic-loader Phase 0 이전에 wiki 인덱스를 확인한다.

**절차**:
1. `sync/wiki/_index.md` 읽기 시도
2. `_index.md`가 없으면 스킵 (MEMORY.md만 참조)
3. 인덱스에서 현재 학습 주제와 관련된 아티클명 확인
4. 관련 아티클이 있으면 해당 파일만 읽기 (전부 로드 금지)
5. wiki 내용은 "참고"로만 활용 — 교재 소스(#1)보다 우선하지 않음

**세션 종료 시**: 학습 중 발견한 취약점·오류·교훈을 `.auto-memory/session_logs/`에 기록 (#39)

## 기말 학습 전략 (#39 연동)

### 과목별 교재 우선순위
- 민법: 송영곤(전체 구성+사례) > 강혜림/전경운(학설·판례). 전경운 교수님 학설 문구는 [전경운] 태그로 표시.
- 형법: 김기용(우선) > 서보학(학설) > 김성돈(보완). 서보학 교수님 난이도 상승 반영.
- 헌법: 이진(우선, 범위 한정) > 강성민(전범위). 사례용 판례+객관식 숫자 정리 병행.

### 소크라틱 세션 시 적용
1. 조문 → 요건 분해 → 요건 판시 판례 순서로 질문
2. 교수님 강조 요건을 우선적으로 출제
3. 기출 쟁점과 연결하여 복합 질문 구성
4. 답안 작성 연습은 청구-항변 2열 표(#32) 형식으로
5. wiki 아티클에서 이전 약점 확인 후 반복 출제 (#38 연동)
