#16-D PDF 분할 및 목차·색인 분리 원칙:
- 대용량 PDF 교재를 단원별로 분할할 때, 책 앞부분의 '목차(TOC)'와 뒷부분의 '색인(Index, 판례색인 등)'은 본문과 분리하여 각각 단독 파일로 분할 보관한다.
- 물리 페이지 확인 의무: PDF 교재의 표기 페이지(논리)와 실제 PDF 리더의 페이지(물리)가 일치하지 않으므로, 반드시 직접 PDF 내부 구조나 아웃라인을 분석하여 실제 물리 페이지 범위를 정밀히 검증한 후 분할 기준점을 정해야 한다.
- 표준 명명 규칙:
  * 목차 파일: `[교재명_접두사]_00_목차.pdf`
  * 색인 파일: `[교재명_접두사]_99_색인.pdf` (판례색인 등)
  * 본문 분할 파일: `[교재명_접두사]_[2자리순번]_[단원명].pdf` (예: `논점민집_01_이론정리.pdf`)
- 폴더 분류 및 라우팅: **`10.도서관` = 통권 원본 PDF만**(책 단위 평면). **분할 산출(본문·목차·색인)은 도서관이 아니라 해당 과목 폴더의 봉투 `[과목]/[교재명]/`**(예: `1.민사/논점민집/`)에 저장한다. **구 `_원본보관/`은 폐기** — 신규 배치 금지, 잔존분은 #16/#49로 정리. `10.도서관` 외 통권 PDF는 정본 아님.
- 분할 골자 — **목차 / 대단원 / 색인** 3분할: 본문은 **기본서(교재) 목차의 '대단원' 단위**로 분할한다(목차에서 각 대단원의 페이지 범위를 포섭). 임의 소제목·기계적 청크 금지. 목차(`_00_목차`)·색인(`_99_색인`)은 본문과 분리해 단독 분할. 분할 명명·소제목은 기본서 목차 표기를 그대로 따른다.
- 도구 규율 — PDF 분할·페이지수 확인·텍스트 추출에 **파이썬(pypdf 등) 사용 금지**. 분할·열람은 **PDF 플러그인 / `pdf` 스킬**, 본문 추출은 **LlamaParse**만 쓴다.
- 폴더 규율 — **폴더 임의 생성 금지.** `10.도서관`은 **전체 원본 PDF(통권)** 보관소다. 책을 분할하면 그 산출은 **해당 과목 폴더 하위의 '봉투' `[과목]/[교재명]/`** 에만 담는다. 도서관 밑에 봉투를 만들지 않는다. 그 외 어떤 폴더도 임의 생성하지 않는다. 활성(보는) 책은 접근 쉬운 위치, 구분은 **활성 vs 지난것·안 보는 것** 둘로만.
- 완전성 게이트(#45-C 검토게이트 연동) — 원문 OCR·분할은 **책 목차 PDF의 전 대단원·전 페이지를 커버**해야 한다. OCR 최종 페이지 < 책 PDF 페이지수(−20p 초과)면 '잘림'으로 보류·재추출한다(예: 쟁점노트 재산법 616p인데 OCR 390p → 물권 누락 = 무효). 검토게이트가 책 목차 대비 누락0을 검증한 뒤에만 위키화로 넘어간다.
- 무결성 로그: PDF 분할 후 파일 배치 시 #16-C에 의거해 `.agent/file_ops_log/master.{csv,jsonl,md}`에 sha256 포함 이동 로그를 남긴다.

#44 PDF 추출 폴백 체인: PDF 텍스트가 필요하면 **추출 전에 기존 마크다운 추출본부터 확인한다(#46)**. 이미 md가 있으면 재추출하지 않는다. 새 추출이 필요할 때만 순서대로 시도, 실패 시 자동으로 다음 단계 후 결과 보고:
1. Read 도구 (작은 PDF, 1MB 미만)
2. **pdfplumber (Python)** — 한글 추출 가장 안정적 (권장; 단 교재 분할·추출은 #16-D 도구 규율이 우선 — LlamaParse)
3. pdftotext → pdftotext -raw (빠르나 한자·기호 일부 깨짐)
4. pypdf
5. 사용자에게 수동 변환 요청
