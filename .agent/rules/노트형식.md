# 룰 모듈: 노트·답안 형식 (#32~#37 전문)

> 커널(CLAUDE.md)의 강제 포인터로 로드. 사례형 답안·정리노트·위키 아티클 작성 전 필독. 적용 범위: 전 과목.

#32 청구-항변 구조: 사례형 청구-항변 구조는 2열 표(원고|피고)로 정리한다. 트리거: 사용자가 사례문제를 풀거나 청구-항변 구조를 요청할 때. 형식: `| **원고 (甲)** | **피고 (乙)** |` + 행 단위로 청구→항변→재항변 주고받기, 빈 셀은 `—`. 3열 표, 볼드 블록, 줄글형은 사용하지 않는다.

#33 모답형/보강포인트 배치: 사례형 답안 연습(모답형), 보강 포인트, 교차검증 결과 등은 해당 쟁점 섹션 안에 배치한다. 부록 성격(암기 문장, 시험 직전 접근순서, 판례 총정리표 등)은 별도 유지한다.

#34 판례 문구 원칙: 판례의 태도/입장을 기술할 때는 교재·판례 원문에 확인된 표현만 사용한다. 전사본이나 요약에서 온 비공식 표현은 교재 원문 표현으로 대체한다. 판례 사건번호를 함께 표기한다. OCR 교정에서도 동일 적용. anchor(조문번호·사건번호·한자)는 LLM 교정 대상에서 제외한다.

#35 백링크 규칙: 노트 내에서 판례, 조문, 핵심 개념에 옵시디언 스타일 백링크를 사용한다.
- 판례: [[대판 YYYY.M.DD, YYdaXXXX]] 또는 [[헌재 YYYY.M.DD, YYYYhunmaXXXX]]
- 조문: [[§XXX]] (§10 이상만. §1~§9는 섹션번호 오탐 방지를 위해 제외)
- 핵심 개념: [[선의취득]], [[물권적청구권]] 등
- 표·각주·코드블록 안에서는 백링크를 걸지 않는다
- 적용 범위: 정리노트, 압축본, 교재 추출본, wiki 아티클
- 연결 사슬(약점보드 실연결): 백링크는 단방향 표기에 그치지 않고 **옵시디언 백링크 → 쟁점 노트 → 카드 간 연결 → 카드**로 이어지는 연결 사슬을 형성해야 한다. (1)원문 노트의 [[판례]]·[[조문]]·[[개념]]은 해당 쟁점 노트로 수렴하고, (2)쟁점 노트는 관련 카드(`outputs/02_cards_v37/`)로 연결되며, (3)**약점보드(`learning.json` weak_points) 항목은 쟁점 노트와 실제로 연결**되어 약점→쟁점→원문 역추적이 가능해야 한다. 고아 백링크·결손 매핑은 #45-C 검토 게이트가 보류·보고. 연결 대상 판정은 LLM 의미판단.

#36 교수님 고유 표현 태그: 각 교수님만의 독특한 표현·용어는 [전경운], [서보학], [강혜림] 등 태그로 별도 표시한다. 적용 범위: 전 과목 정리노트 및 압축본.

#37 외국어 금지: 노트 본문에 라틴어·독일어·한자 등 외국어 표현을 사용하지 않는다. 한국어 대역만 기재한다. 교재 인용 시에도 한국어로 번역하여 기재한다.
