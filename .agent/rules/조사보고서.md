# 룰 모듈: 조사보고서 (#53, 2026-07-05 신설)

> 커널(CLAUDE.md #0)의 강제 포인터로 로드되는 상세 모듈. **웹·문헌·판례 조사 산출물(보강·보완조사·자료조사·딥리서치 보고서) 작성 전 필독.**
> 신설 계기: 2026-07-05 사용자 피드백 — 과도한 단문·표, 원문 출처 누락, 사실관계도 부재(코리안리 보완조사 v1).

#53-1 서술 형식 — **문단형 산문이 기본.** 개조식 단문 나열 금지(목록은 순수 열거적 사실에만 허용). **#8 Output Minimalism은 채팅 응답에 적용되는 규칙**이며, 조사 산출물에는 완결성·서사적 가독성이 우선한다. 독자가 문서만 읽고 맥락을 재구성할 수 있어야 한다.

#53-2 표 제한 — 문서당 표 **3개 이하**, 수치 대조·서지 목록 등 표가 명백히 우월한 경우에만. 논증·사실관계·평가를 표로 대체하지 않는다.

#53-3 출처 인라인 의무 — **모든 사실 단정에 각주로 출처(매체명·URL·게재일)를 단다.** "원시데이터 참조"로 갈음 금지. 단일출처·업계주장·확인불가 등급은 해당 문장에 직접 표기.

#53-4 원시데이터 볼트 이관 — Workflow/조사의 원시 출력(임시폴더 `tasks/*.output`)은 산출 직후 **`9.작업중/클로드/조사원시_{주제}_{날짜}.json`**(현 정본 경로 기준, 폴더 신설 금지)으로 복사 보존하고(#16-C 로그), 보고서 말미에 그 볼트 경로를 기재한다. 임시폴더 경로 인용 금지(세션 종료 시 소실).

#53-5 사실관계도 — 행위자·행위 구조가 있는 조사는 **mermaid 사실관계도 1개 이상 포함**. design-md 스킬 규칙 전면 적용(TB 세로·주체 팔레트·라벨 제한·mmdc 렌더 검증 후 산출).

#53-6 검증 표기 — 조문·판례 사건번호는 law_api 검증 결과를 각주에 병기하고, 문서 전체 verify-text를 통과시킨 뒤 산출한다. 미검증·보류 항목은 감추지 않고 본문에 명시한다.

#53-7 분량 — 조사 보고서는 최소주의 대상이 아니다. 사실의 맥락(경위·수치의 기준·한계)을 담을 만큼 충분히 쓰되, 동일 내용 반복만 금지.
