#38 세션 시작 시 Wiki 참조(상세): 세션 시작 시 **쟁점 위키 `sync/위키/{과목}/`**(#50-B 정본)에서 질문 관련 쟁점 아티클을 먼저 읽은 후 응답한다. 원문(전문)은 `outputs/`(비동기).
- _index.md가 없으면 MEMORY.md만 참조 / _index.md는 25KB 이하 유지
- 개별 wiki 아티클은 필요할 때만 읽는다 (전부 로드하지 않는다)
- wiki는 이전 세션의 작업 기록이므로 "사실"이 아닌 "참고"로 취급한다 — 교재 소스(#1)보다 우선하지 않는다

#39 세션 종료 시 자동 기록: 세션에 다음 내용이 있었으면 `.auto-memory/session_logs/session_{YYYY-MM-DD}_{HHMM}.md`로 기록: 노트 수정/보강 결과 요약 · 새로 확인된 판례·학설·교수님 입장 · 사용자가 지적한 오류와 수정 · 작업 중 발견한 교훈.

#40 Wiki 아티클 원칙: 아티클은 교재 소스(#1~#5)를 대체하지 않는다 · 확인 내용도 교재 원문과 대조 후 사용 · 아티클 내 판례·조문은 반드시 소스 재확인 · [[백링크]] 사용(#35). 경로 정본은 #50-B.

#41 정기 정비:
- 진입점: "메모리 정비"·"lint"·"메모리 컴파일" → memory-maintenance (Skill). ①lint.py 전수 정합점검 ②consolidate-memory ③포인터 무결성 점검.
- 메모리 모델: 인간뷰 정본=**쟁점 위키 `sync/위키/{과목}`**(sync), 원문 전문=`outputs/`(비동기). MEMORY.md=클로드뷰 자동로드 색인. 링크 MEMORY→위키 단방향. 법학지식=위키/원문, 운영맥락=메모리.
- flush.py·compile.py는 은퇴 검토(동결). 자가학습은 #45-C 헤르메스 루프로 이관. 부활 시 LLM 기반 재설계(정규식 금지).
- 오래된 아티클은 삭제하지 않고 _trash로 이동(#16). 증분이 기본. schedule 스킬로 주기 정비 자동화 가능.

#49 기능 은퇴 프로토콜: 자산을 active → deprecated → retired 수명주기로 관리해 미사용 자산 누적(드리프트 근본원인)을 차단한다.
- **active**: 진입점(룰 트리거·dispatch·#17/#48)에 연결돼 실사용.
- **deprecated**: 대체재 생겼으나 잠정 존치. description에 `[DEPRECATED — 사유·후속]` 1줄.
- **retired**: 진입점 차단 + 격리. ①묘비명 — 제자리 존치 스킬은 description 앞 `[RETIRED YYYY-MM-DD — 명시 요청 시에만]`; 이동 격리분은 `_RETIRED_INDEX.md` 대장 기록 ②`.agent/_retired/{YYYY-MM-DD}/`로 이동(삭제 아님·복원 가능) ③이동은 `log_file_op.py --op move --execute`(#16-C) ④`_RETIRED_INDEX.md`에 1행(파일·사유·후속).
- **복원**: _retired에서 원위치 move(로그). 가역.
- 공유드라이브(#16-B)·교재·정본 산출물은 은퇴 대상 아님. 은퇴 후보 자동탐지는 lint.py·#45-C 교정루프가 '목록'까지만, 실제 이동은 사용자 승인 후(#16).
