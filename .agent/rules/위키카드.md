# 룰 모듈: 위키·카드 (#50·#51 전문)

> 커널(CLAUDE.md)의 강제 포인터로 로드. 위키화·쟁점추출·사례노트·카드 생성 작업 전 필독.

#50 위키 닫힌루프·2층 분리 정본:
- **(A) 목차 고정점 닫힌루프**: 학습 루프의 불변 고정점은 **목차**다. 순환은 `목차(고정점) → 쟁점추출(누락0, #45-C) → 카드화(누락0, #51) → 드릴(daily-drill) → 진도보드(논점 frontmatter·옵시디언 Bases/board_server_v2) → 약점(.agent/state/learning.json weak_points) → 다시 목차`로 닫는다. 사례노트(#51)는 쟁점에 백링크로 연결. 각 단계 산출은 다음 단계 입력 키로 정합해야 하며(**키 표준 `과목|대분류|논점`** — board_server_v2 실구현; 구 `subj|중분류|단원` 폐기), 루프 단선(drill_log 공백·srs_log≠learning·progress null·wiki_card_mapping 고아/결손)은 검증자가 보류·보고한다.
- **(B) 위키(쟁점)와 원문을 별도 보관 — 섞지 않는다**:
  * **위키 = 논점(쟁점) 층** = `sync/위키/{과목}/{쟁점}.md`(과목 폴더 직접: 민법·민사소송법·민사집행법·형사소송법·형법총론·형법각론·행정법·헌법 — **과목 약칭 금지**, 민소법/민집법 X). **각 노트 = 해당 논점의 원문 전체 보존 + 다듬기(OCR 교정) + 백링크. 요약·압축 금지.** 목차(논점) 단위 분할, 카드 roll-up 금지. **압축본(요약·찌라시)은 별도 산출**(#17 07찌라시) — 위키 논점 노트와 섞지 않는다.
  * **사례 = sync/위키/사례/{과목}/{사례}.md**(위키 3층의 사례층). 5섹션: 문제(사실관계 전문)·풀이순서(절차 골격)·**포섭격자(요건×사실×증명책임, claim-chart 한국화)**·모범답안(채점 전용·미리노출 금지)·채점포인트/함정. frontmatter `쟁점:`=**실재 논점노트 백링크만**(백링크 무결 게이트 대상), 본문 [[개념/§NNN/대판]]=표기형 placeholder 허용. 사례↔쟁점 양방향 백링크. 모범답안은 채점 시에만 read(#51).
  * **원문 = sync 밖 비동기 보관** = `outputs/01_ocr_llamaparse/`(OCR 정본, 기본서 목차 **대단원 단위** 메타·원문복제+백링크). **sync에 원문을 두지 않는다 — 옵시디언 싱크 1GB 한계.** 위키(쟁점)가 이 원문을 인용/transclusion.
  * **경로 정본**: 쟁점=`sync/위키/{과목}/`(sync 대상) · 원문(전문)=`outputs/`(비동기). 영문 `sync/wiki/`·`sync/위키/원문`·옛 혼재 경로 폐기. 생성은 LLM(정규식 스크립트 폐기).
- **(C) 의미생성 강제, 정규식 신뢰 금지**: 쟁점 경계 판정·원문 분할·목차 대응·백링크 대상 결정은 **LLM 의미판단**으로 한다. 정규식·키워드 매칭은 1차 후보 추출 보조로만 쓰고 최종 채택·검증은 LLM이 한다(누락0 보증은 #45-C 검토게이트의 LLM 의미대조).
- **(F) 정본 스냅샷·증분 약점 덱**(2026-07-04): apkg 정본 = v37 스냅샷(빌드 리포트에 표기). **임포트 후 기존 카드파일 내용 수정 금지**(GUID 보존 — 수정 시 안키 학습기록 단절). 이후 신규는 ①`약점포섭_{과목}_v37.md`(채점 누락 파생, 덱 '약점') ②새 책 카드파일 추가만 허용 — 둘 다 별개 파일·별개 apkg라 증분 임포트 안전. **고반복 태그**: 같은 내용이 2권+ 책에 등장하면 빌더가 `고반복` 태그 자동 부여(고빈출 신호 — 안키에서 태그 필터로 우선 학습 가능).
- **(E) 포섭사전**(2026-07-03 파일럿): `sync/위키/_포섭사전/{과목}_포섭사전.md` = 사례노트 포섭격자 역집계(요건문구·발동사실패턴·판시연결구·결론·판례·출처백링크 6열). 용도: G2 채점 루브릭 대조·드릴 사실→규범 역방향 출제·포섭 트리거 암기. 갱신: 사례노트 추가·교정 시 해당 과목 사전 증분 재집계.
- **(D) 원본 정본**: 책 원본 PDF 정본은 `10.도서관`(책 단위, #16-D). `_원본보관`은 폐기.

#51 카드 3역할 + 포섭격자 (근거 `9.작업중/클로드/카드_사례_설계확정_2026-06-28.md`·`연구_claude-for-legal_종합_2026-06-28.md`):
- **카드 3역할**:
  ① **A 실질 atom**(룰·요건·판례·조문·표) = 논점노트에서 **전수 카드화·누락0 게이트**(`카드검증: 완료 (누락0, 날짜)` 마커, #45-C 재개·파일럿→전체). 메타축: `단계::`(쟁점/규범/포섭/결론) + 요건사실·`증명책임::`(원고/피고, 법률요건분류설) + 대응 항변.
  ② **풀이순서 카드** = 사례노트 `## 풀이순서`만 cloze(절차 통목차 암기).
  ③ **사례 전문** = **카드화 비대상**(far-transfer). 격리 채점/드릴 자산. → 안키(v37 apkg)=A+풀이순서. 사례 풀이실력=`## 포섭격자`(요건×사실×증명책임)+드릴(풀기→case-answer-review).
- **마커 정의(혼동 금지)**: `카드감사`=누락 탐지(감사) 작업 마커(`완료 (누락 N건…)`) / `카드검증: 완료 (누락0, 날짜)`=카드 생성·보충 완료 마커. **skip·집계 기준은 오직 `카드검증`**(`카드감사:완료` 오기 금지; 값 따옴표 표기 혼재 허용 — 집계는 따옴표 무시). 카드파일명 = 논점노트 frontmatter `원문`(outputs/01_ocr_llamaparse/{책}_llamaparse_p{범위}.md) 대응 `outputs/02_cards_v37/{책}_llamaparse_p{범위}_암기장_v37.md`(또는 _v37.md) — glob로 실파일 확인 후 append. **명명 예외**: `법조윤리_01~15.md`(v37 접미 규약 이전 생성)는 **개명 금지** — 빌더 GUID가 파일 stem 기반이라 개명 시 안키 학습기록 단절·중복 노트 발생(BOOK 매핑으로 정상 빌드 중).
- **암기장 선참고(중복방지·필수)**: 카드 생성·보충 시 **기존 암기장(`outputs/02_cards_v37/*_암기장_v37`) 먼저 읽어** 이미 카드화·압축된 부분 재사용·중복 제거 → **카드감사 누락목록 기반 누락분만 보충**. 전체 재생성 금지.
- **강조=우선순위**: OCR 볼드/밑줄 = A 카드 핵심·우선순위 태그 + 풀이순서 추출 신호(별도 카드 양산 X, 단순 키워드는 A에 흡수).
- **사례형 전수 카드화 비대상**(풀이순서만). cardaudit 사례 누락은 누락0 게이트 면제(보고만).
- **닫힌루프 편입(#50-A)**: 목차→쟁점→A카드↔사례(백링크)→드릴→보드→약점→목차. 채점·SRS·페이딩은 case-answer-review 유지(외부 claim-chart는 격자·갭검출만 차용, 미국법 내용·인용 차용 금지 #1·#48).
