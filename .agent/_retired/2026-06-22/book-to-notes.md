# 교재 전체 노트화 워크플로우

> PDF 교재 1권을 챕터 단위로 분할하여 Obsidian 볼트에 구조화된 학습노트를 생성한다.
> 각 섹션에 교재별 페이지 마커를 자동 삽입한다.

---

## 실행 프롬프트

아래 프롬프트를 복사하여 사용하거나, 교재명과 범위를 지정하여 호출한다.

```
[교재명]을 챕터별로 노트화해줘.

조건:
1. sync/_교재원문/{과목}/{교재}/ 의 챕터 파일(ch01~chNN.md)을 순회
2. 챕터마다 독립된 ## 섹션으로 정리
3. 각 ## 섹션에 페이지 마커 주석 삽입
4. 과목별 블록 템플릿 적용 (민법=청구권구조형, 형법=쟁점집중형/조문집중형, 헌법=객관식중심형)
5. 판례는 사건번호 + 판시 핵심 한 문장
6. 요건은 ①②③ 문장형 (민법은 판례 한 문장 최우선)
7. 완성된 노트를 Obsidian 볼트에 저장

출력 위치: _4과목_도표추가본_통합본_모음/
파일명: {과목}{N}-{강사}-{교재약칭}-정리노트.md
```

---

## 단계별 실행 절차

### Phase 1: 교재 구조 파악

```bash
# 1-1. 해당 교재의 목차(챕터 목록) 조회
# sync/_교재원문/{과목}/{교재}/_교재목차.md 파일을 읽어 전체 챕터 구조 확보
# 파일명 규칙: {교재ID}_ch{NN}_p{start}-{end}.md
```

출력 예시:
```
sync/_교재원문/민법/송영곤_논점민법_본책/_교재목차.md
  ch01 (p.1-30) 민법 서론
  ch02 (p.31-60) 권리의 주체
  ch03 (p.61-90) 법률행위
  ...
```

### Phase 2: 챕터별 원문 로드 + 교차 검색 + 노트 생성

각 챕터에 대해 반복:

```bash
# 2-1. 해당 챕터 원문 직접 로드 (Read 도구)
# sync/_교재원문/민법/송영곤_논점민법_본책/송영곤_논점민법_본책_ch03_p061-090.md

# 2-2. 교차 교재 검색 (동일 쟁점의 다른 교재 청크) — qmd helper
python -c "
import sys
sys.path.insert(0, '.agent/lib')
from qmd_search import qmd_search
for h in qmd_search('{쟁점 키워드}', k=5, mode='search'):
    print(h['path'], h['title'])
"
```

- 메인 원문은 파일 직접 읽기(정확도 우선), 교차 교재만 qmd 벡터/BM25 검색
- qmd helper: `.agent/lib/qmd_search.py` (내부에서 `qmd` CLI 호출)

### Phase 3: 노트 작성

각 챕터의 RAG 결과를 바탕으로 마크다운 노트를 작성한다.

**노트 구조:**

```markdown
# {과목} {교재명} 정리노트

> **과목**: {과목명} | **교재**: {교재 전체 이름} | **범위**: 전범위
> **생성일**: {YYYY-MM-DD} | **방식**: sync/_교재원문/ 챕터 파일 기반 생성 (qmd 교차검색)

---

## 전체 체계도

| 편 | 장 | 주요 쟁점 | 페이지 |
|---|---|----------|--------|
| 제1편 ... | 제1장 ... | ... | p.XX-YY |

---

## 1. {제1장 제목}
<!-- 📖 교재별 페이지
  - {주교재약칭} ch.01 p.13-42 → [[송영곤_논점민법_본책_ch01_p013-042]]
  - {교차교재약칭} ch.N p.XX-YY → [[교차교재_chNN]]
-->

### 핵심 개념

[과목별 블록 템플릿 적용]

### 요건
① ...
② ...
③ ...

### 판례
- **대판 YYYY.M.D. 20XX다XXXXX**: "판시 핵심 한 문장"[^{과목약칭}-{N}-1]

<!-- footnotes -->
[^{과목약칭}-{N}-1]: 《{교재명}》 p.XX

### 쟁점 — [쟁점명]
[학설 대립 + 판례 + 검토]

---

## 2. {제2장 제목}
<!-- 📖 교재별 페이지
  - ...
-->

[반복]
```

### Phase 4: 조문/판례 보강

```
korean-law-mcp 자동 호출:
- 조문 번호만 있고 원문 없으면 → get_law_detail
- 판례 사건번호만 있고 요지 없으면 → search_precedent_tool
```

### Phase 5: 저장 + 인덱싱

```bash
# 5-1. Obsidian 볼트에 저장
# 파일 경로: sync/{과목}/{카테고리}/{파일명}.md 또는 sync/_4과목_도표추가본_통합본_모음/{파일명}.md

# 5-2. qmd 인덱싱 갱신 (law-notes 컬렉션 — 정리노트 + 교재원문 통합)
qmd update
qmd embed
```

### Phase 5 보충: PDF 산출물 저장 규칙

- **마크다운 노트**: `sync/` 볼트 내부 (`qmd` 인덱싱 대상)
- **PDF 산출물**: `5.기타/정리노트PDF/{YYYY-MM-DD}/` (볼트 외부, `qmd` 인덱싱 대상 아님)
- **금지**: `sync/**.pdf` 경로에 PDF 생성·복사·저장 금지. 기존 파일은 `5.기타/정리노트PDF/{오늘 날짜}/` 로 이동.
- **md_to_pdf.py**: 자동으로 위 규칙을 따르도록 하드코딩됨 (`sync/md_to_pdf.py`의 `OUTPUT_BASE` 참조, 실행 시점 날짜 폴더 자동 생성).
- **하위 폴더 구조**: 학기 구분이 필요한 경우 `5.기타/정리노트PDF/{YYYY-MM-DD}/1-1_중간/`, `.../1-1_기말/` 처럼 서브폴더 분리.

## 교재 지정 방식

### 방법 1: 교재ID로 지정
```
송영곤_논점민법_본책 전체를 노트화해줘
```

### 방법 2: 범위 지정
```
송영곤_논점민법_본책 ch01~ch05만 노트화해줘
```

### 방법 3: 과목 전체 (교차 교재 통합)
```
민법 전 교재를 통합해서 챕터별 노트화해줘
```
→ 이 경우 같은 챕터/쟁점에 대해 여러 교재의 페이지를 마커에 병기 (qmd 교차검색)

---

## 페이지 마커 생성 로직

1. 주교재 `_교재목차.md` 에서 챕터 파일명·페이지 범위 확보
2. 교차 교재는 `qmd_search(쟁점 키워드)` 결과의 `path`·`title`에서 교재ID·챕터 stem 추출
3. `<!-- 📖 교재별 페이지 -->` 주석에 교재·페이지·챕터 stem 조합

**예시:**
```markdown
## 3. 표현대리
<!-- 📖 교재별 페이지
  - 송영곤_논점민법_본책 ch.03 p.81-120 → [[송영곤_논점민법_본책_ch03_p081-120]]
  - 송영곤_쟁점노트 ch.05 p.142-155 → [[송영곤_쟁점노트_ch05_p142-155]]
-->
```

## 각주·백링크 적용

- **각주 형식**: 인라인 `"발췌"[^id]` + 정의 `[^id]: 출처`. ID: `[^{과목약칭}-{섹션번호}]`. 정의는 **파일 맨 밑**에 모아 배치 (위키식). `근거 발췌:/근거 위치:` 인라인 패턴 폐기
- **백링크**: 같은 과목 내 기존 노트가 있으면 `[[파일명#섹션명]]` 링크 삽입. 과목 간 교차 금지, 섹션당 최대 3개
- 상세: `law-note-supplement/references/note-structures.md` "각주/백링크 규칙"

---

## 주의사항

- **임의 페이지 번호 금지**: 교재원문 파일명(`_p{start}-{end}`) 또는 frontmatter `페이지:`에서 확인된 범위만 기재
- **교재 원문 복사 금지**: 요약·구조화만 수행, 원문 발췌는 마크다운 각주 형식으로
- **기존 노트 충돌 시**: 기존 노트가 있으면 `law-note-supplement` augment 모드로 전환
- **대량 작업 시**: 챕터 3~5개 단위로 끊어서 진행, 중간 저장
