### 개인 070 — 장물죄 일반
원문: `sync/위키/형법각론/장물죄 일반.md`
카드: p391-420 카드 53~63 (11장)
조문 §362·§364: 카드에 조문 독립 카드 없음(요건 카드로 흡수 — 허용).

대조 결과 — 원문엔 있으나 카드엔 없는 핵심:
1. **대판 1999.3.26, 98도3030** (본범과 공동하여 장물 운반 시 본범은 장물죄 불성립·그 외의 자는 장물운반죄 / 절취차량 운전해준 자 = 강도예비 + 장물운반죄) — 카드 없음. '자기의 범죄' 범위(카드 54)와 별개의 공동운반 법리·죄수.
2. **§362②·V절 알선의 취득 무상포함·취득·양도·운반 개념 + 대판 2004.12.16, 2004도5904 (회사자금 주식매각대금 = 횡령 영득 장물·업무상횡령 기수와 동시에 장물)** — 2004도5904는 고의 카드(61)에만 사용, 'V절 횡령행위 제공물 vs 영득 장물 구별' 법리는 미카드화.
3. **대판 2004.4.16, 2004도353 (재산범죄 후 불가벌적 사후행위로 취득한 물건도 장물 가능)** — 노트 II절. 카드 58은 2004도353을 환전통화 장물성(IV절)에만 사용, '불가벌적 사후행위 취득물의 장물성'(II절) 법리는 미카드화.
4. **대판 1987.10.13, 87도1633 (모르고 보관 중 장물임을 알고 반환 가능함에도 계속 보관 → 장물보관죄)** — 노트 VI-보관 ②. 카드 62는 2004도6084(점유권한 있으면 불성립)만 커버, 87도1633(반환 가능성 있는데 계속 보관 → 성립) 대조 사안 미카드화.

품질: 카드 53~63 내용·cloze 정확. 왜곡·오류 없음.
참고(중복성): 68도1474·99도5275(미필적 고의·본범 구체적 인식 불요)는 카드 61(2004도5904)이 동일 법리 커버 → 실질 누락 아님.
