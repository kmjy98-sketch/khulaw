**카드에 있는 내용 (커버됨)**:

- 일괄경매 우선변제범위(토지대금 한정)
- §364 제3취득자 변제권(주체·종기·면책채무인수 제외·이행인수는 적용)
- §367 비용상환청구권(배당요구 방법 필요, 직접청구 불가)
- 물권적 청구권(건물신축공사중지 청구)
- §360 피담보채권 범위(조문)
- 담보물보충청구권(§362) — 설정자 책임 있는 사유
- 저당권부채권 양도 요건(물권적 합의+채무자·물상보증인 합의 불요)
- 피담보채권 양도 후 배당표 경정 불가(2001다77888)
- 소유권 상실한 저당권설정자의 채권적 말소등기청구권 — **카드에 있음(94다16338)** ← 이전 분석에서 누락이라 했으나 실제로는 있음
