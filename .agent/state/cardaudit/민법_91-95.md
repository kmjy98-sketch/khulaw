## 품질 이슈 (카드 오류·왜곡)

- 논점 92: 신민사법선택형_물적담보_p061-080의 [가담법 불적용 시 약한 의미의 양도담보] 카드 — "가담법이 적용되지 않는 경우(피담보채무가 차용원리금 이상인 경우 제외)"라는 전제 조건이 논점 93의 규율 범위와 혼동될 수 있음. 가담법 적용 제외 이유(피담보채무 종류 요건 불충족)를 명확히 해야 함.
- 논점 95: 신민사법선택형_물권_p001-030의 문17 카드에 "피상속인의 의사 존중 의무는 도의적 의무에 그치고…법률적 의무는 없다"를 "O (법적 의무 없다는 것이 옳음)"이라고 기술하여 O/X 혼동 가능. 앞면 문제가 "법적 의무가 생기는가"인데 정답을 'O'로 표기하면 '법적 의무가 생긴다'로 오독할 수 있음.
