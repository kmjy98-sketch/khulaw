## 1. 공무집행방해죄 (국가 012)

  - 위법 공무집행 → 구성요건 불충족 + 저항상해 정당방위(2006도2732) [예외-10]
  - 적법성 체계적지위 = 판례 구성요건요소설(2006도2732) [포섭-20]
  - 적법성 착오 = 적법성자체 법률착오(§16) / 기초사실 사실착오(2023도16951) [포섭-21]
  - 폭행 = 간접유형력 포함(98도662) / 경미·개의치않을정도 제외(2006도4449) [OX-3][일반론-16]
  - 추상적 위험범(2017도21537) [일반론-17]
  - 죄수: 여러 공무원 상상적경합(2009도3505) [포섭-22] / 공무집행방해+상해 상상적경합(2009도591) [포섭-23]

- **누락(원문엔 있고 카드엔 없음)**:
  1. **[중요] 고의 (94도1949)** — 직무집행 공무원 인식 + 폭행·협박 인식으로 족하고, **직무집행을 방해할 의사는 불요**. 미필적 고의로 충분. (변시·모의 빈출 [모사25]) → 카드 전무.
  2. **[중요] 협박 정의 (70도1121)** — 공포케 할 해악 고지로 족하고 **현실로 공포심 생김은 불요**. → 카드 전무. (폭행 카드만 있고 협박 정의·정도 카드 없음)
  3. **'직무를 집행하는'의 의미 (2021도13883)** — 직접 필요행위 현실수행뿐 아니라 **직무수행 위해 근무 중 상태 포괄**(소란민원인 제지·퇴거도 직무) + 추상권한 법령명시 불요. → 카드 없음.
  4. **윤활유·철판조각 부재중 살포 (2010도7412)** — 면전 방해의도 살포가 아닌 경찰관 부재중 미리 살포는 폭행 부정. → 카드 없음.
  5. **차량 출발 시 유리창 잡음 (96도281)** — 정차 후 면허증 요구 불응·재출발, 경찰관이 잡은 유리창 놓지않고 진행하다 놓은 것만으로는 폭행 부정. → 카드 없음.
  6. **적법성 착오의 효과 — 4견해 학설대립** — 원문 III-3-나는 ①구성요건요소설(사실착오·고의조각) ②구성요건요소설(적법성자체=법률착오/기초사실=사실착오) ③위법성요소설(법률착오 or 위전착) ④처벌조건설(착오 무관) 등 4견해 + 적법성 기초사실 사실착오 시 고의조각 TIP(구속영장 이미 제시) 상세. 카드는 판례입장만 압축([포섭-21]), 견해 대립 자체는 빠짐(사례형 변사25 직접 논점).
- **품질**: 카드 자체 품질 양호(사건번호 정확, 요건 정리 충실). 다만 **고의·협박 정의는 변시 빈출 기본카드인데 누락** — 보완 필요.

## 4. 뇌물죄의 죄수관계 (국가 011)

- **논점노트 성격**: 뇌물범죄 죄수관계 **전용** 논점(I 죄수관계 / II 뇌물+사기 / III 뇌물+공갈). CASE 2개(사기형·공갈형).
- **카드 위치**: 죄수 관련은 p481-510 §[뇌물죄] [포섭-18](사기 상상적경합)·[포섭-19](공갈)·[OX-1,2]에 일부만.
- **커버됨**:
  - 뇌물수수+사기 상상적경합(2015도12838) [포섭-18][OX-1]
  - 직무집행의사·대가관계 없이 공갈 → 공갈죄만, 뇌물수수죄 불성립(94도2528) + 공여자 뇌물공여죄 불성립 [포섭-19][OX-2]

- **누락(원문엔 있고 카드엔 없음) — 죄수관계 핵심 대부분 빠짐**:
  1. **[중요] 공범자간 횡령금 분배 (2020도3972)** — 공무원 공범자들이 국가자금 횡령 후 그 돈을 공범끼리 수수 = 내부분배에 불과 → 별도 뇌물죄 불성립. (변22·23) → 카드 전무.
  2. **[중요] 수뢰후부정처사죄 + 공무상비밀누설죄 = 상상적경합 (70도562)** — 직무상 지득 구술시험 문제를 돈받고 알려줌. (변26·17, 모사25) → 카드 전무.
  3. **허위공문서작성죄 + 부정처사후수뢰죄 = 실체적경합 (2003도7762)** — 공무원 의사 부탁받고 허위진단서 작성+대가 금품. (p421-450 카드는 '허위공문서 vs 허위진단서' 다른 논점, 죄수 관점 아님) → 죄수 카드 없음.
  4. **뇌물공여의사표시 비흡수 (2013도9003)** — 거절 후 수개월 뒤 다른 명목 공여 시 종전 의사표시는 공여에 흡수 안 됨. (변24) → 카드 없음.
  5. **[중요] 제3자뇌물수수죄 + 직권남용권리행사방해죄 = 상상적경합 (2016도19659)** — 직무관련자에게 제3자와 계약 체결 요구. (변20) (카드는 [요건-6] 제3자뇌물수수'방조'만, 죄수 관점 없음) → 죄수 카드 없음.
  6. **뇌물+사기 章(II) 추가판례** — ①청탁·알선 의사·능력 없이 기망 금품 → 사기죄+변호사법위반 상상적경합(2005도8704, 변21·20) ②특가법알선수재·특경법알선수재 + 사기 상상적경합(2007도10004, 2012도3927). → 모두 카드 없음.
  7. **뇌물+공갈 章(III) 학설·공여자 죄책** — ①공무원 죄책 학설(직무집행의사+대가 모두 필요 다수설 vs 대가만 필요설) ②뇌물수수죄·공갈죄 **모두 성립** 시 공여자 뇌물공여죄 학설(부정설 vs 긍정설, 노트 긍정설 채택) ③직무빙자 갈취 공갈죄만(65도1166) ④TIP 공갈죄vs뇌물수수죄 상상적경합 견해. → 카드 없음([포섭-19]는 '공갈죄만 성립'하는 경우만, 모두 성립 시 공여자 논점·학설 빠짐).
- **품질**: **이 논점은 죄수관계 전용임에도 카드는 사기·공갈 2개 죄수만 산발 커버. 죄수관계 I章 핵심 5개판례(2020도3972·70도562·2003도7762·2013도9003·2016도19659)와 III章 학설구조가 전부 누락** — 4논점 중 카드-노트 정합도 최저(논점 자체의 카드 부재에 가까움).
