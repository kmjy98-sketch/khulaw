## 형총 011 — 개괄적 고의와 개괄적 과실

### 카드 현황

compact OX p031-060 카드 2개 존재:
- 포섭 카드: 88도650 (살해의도+매장으로 사망 → 살인죄)
- 포섭 카드: 94도2361 (상해 후 베란다 투하 → 상해치사죄)

### 누락 항목

1. **학설 4가지 비교표 카드 없음**
   - 경합범설 (살인미수+과실치사 경합)
   - 개괄적 고의설 (전체지배 개괄적 고의)
   - 인과관계착오설 (비본질적 착오 → 기수, 타당설)
   - 객관적 귀속설 (생활경험칙상 전형적 행위)
   - 논점노트 I.1. 참조

2. **시체은닉죄 성부 카드 없음**
   - 흡수설 vs 상상적 경합설 대립
   - 노트: 살인기수죄 인정 시 시체은닉불능미수죄 상상적 경합 성립(추상적 위험설)
   - 논점노트 I.2. 참조

3. **증거인멸죄 자기사건 불성립 카드 없음**
   - 타인 형사사건 대상, 자기 사건은 불성립
   - 논점노트 I.3. 참조

### 품질 이슈

- 기존 2개 카드는 결론만 수록(판례 사건번호 포함), 학설 대립 구조 카드 부재
- 개괄적 과실 94도2361 카드는 '상해치사죄(단일)' 결론 있으나, 경합범설과의 대비 없음

### 카드 현황

- 인식없는 과실 정의 (83도3007) ✓
- 중과실 정의 (4292형상761) ✓
- 행정단속법규 (2009도9807) ✓ (카드 3·4)
- 의료과실 일반원칙 ✓ (카드 9~15)
- 신뢰의 원칙 행위불법 측면 ✓ (카드 16)
- 수직적 분업 주된의사 감독의무 ✓ (카드 17)
- 수평적 분업 신뢰 원칙 적용 ✓ (카드 18)
- 교통사고 신뢰원칙 일반론 ✓ (카드 19~23)

### 누락 항목

1. **신뢰의 원칙 한계 3가지 카드 없음**
   - ①행위자 스스로 규칙위반, ②상대방 위반 인식, ③상대방 준수 기대 어려운 사정
   - 논점노트 II. 한계 항목

2. **수평적 분업 구체 판례 카드 없음**
   - 내과의사-신경과 협의진료 신뢰 (대판 2001.7.27, 2001도3292)
   - 약사가 의약품 표시 신뢰 (대판 1974.12.10, 74도2046) [변13]
   - 논점노트 III. 2. 가. 참조

3. **수직적 분업(의사-간호사) 구체 판례 카드 없음**
   - 수혈 일임 과실 (대판 1998.2.27, 97도2812)
   - 간호실습생 주사 감독의무 (대판 2003.1.10, 2001도3667) [변22]
   - 간호사 처방 재확인 의무 (대판 2006.4.13, 2005도8980)는 카드 13으로 있음 ✓
   - 논점노트 III. 2. 다. 참조

4. **차 vs 차 판례 3건 카드 없음**
   - 중앙선 침범 대향차량(비정상운행 목격 후 주의의무) — 85도2651 [변26 관련]
   - 자기차로 다른 차선 근접 운전 과실 부정 — 98도297
   - 야간 무등화 자전거 무단횡단 예견의무 없음 — 84도1695
   - 논점노트 IV. 2. 참조 (차vs차 판례 5건 중 98도1854·94도548만 카드화)

5. **제14조 조문 자체 카드 없음**
   - '법률에 특별한 규정이 있는 경우에만 처벌' 요건
   - 과실위험범(실화죄 제170조) 언급도 카드 없음

## 형총 013 — 과실범의 공동정범과 동시범

### 카드 현황

compact OX p061-090 카드 5~8:
- 범죄공동설 성립범위 (카드 5) ✓
- 행위공동설 성립범위 (카드 6) ✓
- 판례 4294형상598 공동정범 O (카드 7) ✓
- 공동의 목표·의사연락 없는 경우 공동정범 불성립 (카드 8) ✓

공동정범 인과관계(97도1740 교량붕괴)는 compact OX p031-060 카드 존재

### 누락 항목

1. **기능적 행위지배설(부정설) 별도 카드 없음**
   - 과실범 공동정범 부정 논거: 기능적 행위지배 불가 + 피고인에 증명책임 전가=책임주의 위반
   - 학설 3자 구조(행위공동설·범죄공동설·기능적행위지배설)를 카드화할 필요
   - 논점노트 I. 참조

2. **2024도1856 카드 없음**
   - 의사의 연락이나 주의의무위반에 대한 공동 인식 없으면 공동정범 불성립
   - 논점노트 I. 참조

3. **동시범 처리 전용 카드 없음**
   - 동시범에서 각자의 과실과 결과 사이 인과관계를 개별 검토
   - 각 과실이 '하나의 조건'이 되면 책임 면할 수 없다(2022도16120)
   - 원인행위 불명 → 동시범 → 미수범 → 과실범 미수 불벌의 흐름
   - 위 내용이 compact OX p031-060 인과관계 섹션(카드 462~482)에 산재하나, 동시범 논점과 연결이 없음

## 형총 014 — 교통사고와 운전자·동승자의 책임

### 카드 현황

compact OX p061-090 및 p031-060에서 교통사고 신뢰의 원칙 카드(카드 19~23)는 형총 012 범위로 수록.

형총 014 전용 카드(도주·동승자 책임 관련): **카드 없음(카드없음에 해당)**

### 누락 항목 (전항목)

1. **도주차량죄 성립요건** — 과실있는 운전자 한정 (대판 1991.11.26, 91도711)
2. **사고후미조치 의무** — 고의·과실·유책 여부 불문 (대판 2016.10.13, 2015도12451)
3. **유기죄와 사고후미조치 특별법 관계** — 사고후미조치죄가 형이 더 중하여 유기죄 불성립 (서울고등법원 2013노2492)
4. **유기치사상죄 성립 요건** — 추가적 사상 결과 발생 시 + 사고후미조치와 상상적 경합
5. **동승자 §33 본문 적용** — 진정신분범(운전자·승무원)에 비신분자 동승자 공동정범 성립
6. **도주차량죄 공동정범 요건** — 교통사고 자체에 과실범 공동정범 인정된 경우에 한함 (대판 2007.9.20, 2007도2919)
7. **교특법위반 + 사고후미조치 → 도주차량죄 흡수** (대판 1992.4.14, 91도253)
8. **동승자 사고후미조치 공동정범** — 승계부정설 적용 (대구지방법원 2006노2898)
9. **동승자가 교통사고에 과실범 공동정범 되는 경우** — 의사연락 하여 교통사고 발생시킨 경우

## 형총 015 — 결과적 가중범 일반

### 카드 현황

compact OX p061-090 카드 24~40:
- 결과적 가중범 기수요건 (카드 24) ✓
- 예견가능성 없으면 중한 죄 불가(88도178) (카드 25) ✓
- 공동정범 기본행위 공동의사만 필요(2013도1222) (카드 26·27) ✓
- 미수범 처벌규정 없는 경우(강도치사상, 특수강간치상) (카드 28~31) ✓
- 부진정결과적 가중범 기본법리(카드 32~37) ✓
- 현주건조물방화치사죄 관련(카드 38~40) ✓

### 누락 항목

1. **§15② 조문 카드 없음**
   - "결과 때문에 형이 무거워지는 죄의 경우에 그 결과의 발생을 예견할 수 없었을 때에는 무거운 죄로 벌하지 아니한다"
   - 결과적 가중범의 헌법적 근거 조문으로 카드화 가치 높음

2. **기본범죄 위법성·책임조각 시 결과적 가중범 불성립 카드 없음** [변25]
   - "기본범죄의 위법성 또는 책임이 조각되면 결과적 가중범 성립 불가, 중한 결과에 대한 과실범만 문제"
   - 논점노트 I. 두번째 항목

3. **현주건조물방화치사상 방화미수+치상 → 기수 판례 카드 없음**
   - 방화 목적 휘발유 살포 후 피해자 몸에 불 붙은 경우 방화착수 → 현주건조물방화치사상죄 성립
   - 대판 2002.3.26, 2001도6641 [매개체설]
   - 논점노트 III. 1. 참조

4. **주거침입강간치상 미수범 문제 카드 없음** [변사21, 모사19]
   - 동일 법리 적용(2023도10405와 같은 결론) 언급이 노트에 있으나 카드 없음
   - 논점노트 IV. 1. 마지막 항목
