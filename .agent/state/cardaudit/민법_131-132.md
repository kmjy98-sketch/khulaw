## G09 — 한정승인 (131번)

### 카드 있음 (확인)
- 한정승인 의의·유한책임 개념
- 심판 고지로 효력 발생 (2013다73520) + 미비 신고서 수리(76스10) 합산
- 특별한정승인 사유·기간 §1019③ (제3호 제외, 3월)
- 특별한정승인 기간 성질 — 제척기간·불변기간 아님 (2003스32)
- 가정법원 심리범위 — 형식적 요건만 (2004스74)
- 특별한정승인 수리심판 효력 + 민사법원 선결문제 심리 (2002다21882, 2017다289651)
- 미성년자 특별한정승인 종전 입장 vs §1019④ 신설 (2019da232918)
- 한정승인 항변·기판력 차단효 배제 (2006da23138)
- 이행판결 — 전부판결 + 주문 집행제한 명시 (2003da30968)
- 고유재산 집행시 청구이의소 불가 (2005그128)
- §1031 조문 (재산상 권리의무 불소멸)
- 한정승인 시 상계권 — 소급 효력 상실·부활 (2022다254154)
- 한정승인 청산 변제순서 (우선채권자 → 일반채권자 → 수유자)
- '한정승인자가 알고 있는 채권자' 기준시점 — 배당변제시 (2015다75308)
- 형식적 경매 시 배당 — 한정승인자에게 배당 (2012다33709)
- 임의(담보권실행)경매시 배당요구 가능 (2010다14599)
- 상속채권자 vs 담보권 취득 고유채권자 — 일반원칙 (2007다77781)
- 담보권 없는 고유채권자 강제집행 불가 (2015da250574)

### 누락 (원문에 있으나 카드에 없음)

1. **§1030 조문 카드 없음** — 한정승인 방식(상속재산 목록 첨부 신고, 특별한정승인시 처분재산 목록·가액 제출) 원문 카드 미생성
2. **증명책임 — 상속채무 초과사실 알지 못함** — 2003다30517, 2015다59801: 증명책임이 '피상속인의 상속인'에게 있다는 판례 카드 없음
3. **§1019④ 제2문 내용 미세분** — 법정대리인이 특별한정승인을 하지 않았거나 할 수 없었던 경우에도 성년 후 3개월 가능한 제2문(§1019④ 문2)이 카드에서 종전 입장 카드에 묻혀 별도 처리 안 됨
4. **기판력 전소 한정승인 후 법정단순승인 주장 차단** — 대판 2012.5.9. 2012다3197: 전소에서 상속재산 한도 지급 판결 확정 후 상속채권자가 법정단순승인 등 한정승인과 양립 불가 사실 주장 불허 판례 카드 없음
5. **물적 유한책임 일반론** — §1028·§1029 조문 카드 없음; '임의변제 시 유효한 변제(비채변제X)' 내용 카드 없음
6. **§1022 관리의무** — 상속개시시부터 청산 종료시까지 관리 계속 조문 카드 없음
7. **§1040 공동상속재산 관리인 선임** — 조문 및 관리인 권한 카드 없음
8. **§1032 채권자 공고·최고 조문** — 한정승인 후 5일 이내 공고, 2월 이상 기간 카드 없음
9. **§1033 변제거절권** — 조문 카드 없음
10. **§1035 변제기전 채무 변제, §1036 수증자 변제, §1039 불신고자 변제** — 조문 카드 없음
11. **§1038 부당변제 등 책임** — 조문 카드 없음 (공고·최고 해태 또는 변제순서 위반시 손해배상, 상계 알고 수령한 채권자 구상관계 포함)

### 품질 이슈
- 2005그128 카드: 집행권원 확정 후 피전부채권 중 '아직 추심하지 않은 부분 → 채권 양도 청구' 부분이 카드에 반영되지 않음(불완전)
- §1019③ 카드: '처분재산 목록·가액 제출 의무(§1030②)' 연계 설명이 누락

## G10 — 유류분 (132번)

### 카드 있음 (확인)

- 유류분 산정기초재산 산식
- 유류분침해액 산식

### 누락 (원문에 있으나 카드에 없음)

1. **유류분제도 시행(1979.1.1.) 이전 증여계약** — 2010다78722, 2017다278422: 시행 전 계약+이행 완료 → 기초재산 제외(단 반환청구자 수령분은 특별수익 공제); 시행 전 계약+시행 후 이행 → 산입 등 구분 카드 없음
2. **상속채무 공제대상 구체적 항목** — 2012다21720: 유증에 의한 채무·사전증여 미이행분·상속재산 관련 비용(상속세·소송비용 등)이 공제대상에 포함된다는 카드 없음 (현행 카드는 연대보증 제외만)
3. **상속포기자는 §1114 적용** — 2022da267620, 2022da219465: '피상속인으로부터 특별수익인 생전 증여를 받은 공동상속인이 상속을 포기한 경우' §1114 적용되어 기간 제한 받는다는 카드 없음; 피대습인 대습원인 전 증여 + 대습상속인 상속포기 경우도 동일 법리 카드 없음
4. **대결 2024스525 별도 사실관계** — 카드(2012다31802)에 합산 언급만 있고 '피대습인을 피보험자·대습상속인을 보험수익자로 지정한 보험수익자 지정일 = 증여시점' 논리가 별도 카드로 분리되지 않음
5. **반환의무자 상속채무 분담액 대신변제 → 구상권** — 2010da42624: '별도의 구상권 행사로 해결'이라는 법리 카드 없음
6. **공동상속인 증여+유증 혼합 기준①②** — 2010da42624: 수인의 공동상속인이 증여·유증을 혼합 수령한 경우 분담 기준①(유증 총액 > 부족액이면 수증재산 반환 불요)·기준②(초과비율 안분, 분담액 부족시 다른 공동상속인 대신 반환) 카드 없음
7. **유류분반환청구권 행사방법** — 2000da66430: 재판상·재판외 의사표시 모두 가능, 목적물 구체 특정 불요, 침해 유증·증여행위 지정으로 족하다는 카드 없음
8. **유류분반환청구와 소멸시효 중단** — 1993da11715: 재판상·재판외 의사표시로 §1117 소멸시효 진행이 중단된다는 카드 없음
9. **원물반환 원칙 + 가액반환 예외** — 2005다71949, 2025다210352: 원물반환 불가시 가액상당액 반환, 가액 기준시 '사실심변론종결시' 카드 없음 (수개부동산 지분산정 카드와 별개)
10. **이전등기청구권의 소멸시효 별도 판단** — 2011다55092: 유류분반환청구권 행사로 발생하는 이전등기청구권 등은 §1117 소멸시효 적용 없고 별도 판단 카드 없음

### 품질 이슈
- 제3자 보험수익자 기준일 카드(2020da247428): '보험수익자로 지정하거나 변경한 일자'가 기준일이라는 점이 카드에 명시되지 않음 — 편입시기 제한 카드에 흡수되지 않아 gap 발생
- 대결 2024스525: 2012다31802 카드에 '대결 2024.6.13. 2024스525'를 괄호 병기만 했으나 독자 사건(피대습인 피보험자·대습상속인 보험수익자 사안)의 법리 적용이 누락
