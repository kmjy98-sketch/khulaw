## 개인 006 — 독립행위 경합과 상해 동시범 특례 (p202)

**상태:** 감사완료 (논점노트 카드감사: 완료 기재)

**카드 커버리지:** 양호. 핵심 쟁점(요건3개, 이시긍정, 사망긍정, 미적용2종, 증명책임전환, 혼재시처리) 모두 수록.

**누락 (2건):**
1. **84도488** — "가해행위 자체가 분명치 않은 사람에게는 동시범 적용불가" 판례. 논점노트 II항에 명시되어 있으나 카드 없음.
2. **2022도16120** — 실화죄 공동과실경합 시 인과관계 판명되어 §19 미적용 판례. 논점노트 II항 '원인행위 판명됨' 케이스이나 카드 없음.

**품질 이슈:** 없음.

## 개인 007 — 폭행의 개념 (p205)

**상태:** 감사완료 (논점노트 카드감사: 완료 기재)

**카드 커버리지:** 4유형 정의·협의폭행 판례·차량전진·고성폭언·광의폭행(강요죄)·특수폭행치상 수록. 단, 최협의 항목은 정의만 있고 개별 판례 카드 없음.

**누락 (4건):**
1. **최협의폭행 판례** — 준강도 반항억압정도(90도193), 강간죄 착수(91도288) 판례. 최협의 정의 카드는 있으나 판례별 카드 미수록.
2. **72도2201** — "어린애를 업은 사람을 넘어트린 행위 → 어린애에 대해서도 폭행" 판례. 논점노트 II항에 있으나 카드 없음.
3. **2015도13345(특가법 운전자폭행)** — 직접 운전자 상해에도 특가법 적용. 카드 없음.
4. **헌재 2020헌마1308·대판 2005도174** — '다중' 및 '위력'의 의미(특수폭행치상 다중 요건). 카드 없음.

**품질 이슈:** 없음.

## 개인 008 — 유기죄와 학대죄 (p208)

**상태:** 감사완료 (논점노트 카드감사: 완료 기재)

**카드 커버리지:** 보호의무(부정설), 사실혼요건, 주점운영자계약부조, 강간치상방치불성립, 유기행위(장소이전불요), 학대죄(상태범) 수록.

**누락 (8건) — 고누락:**
1. **§271 조문** — 유기죄 조문(4항 포함, 중유기·존속중유기) 카드 없음.
2. **§273 조문** — 학대죄(1·2항) 카드 없음.
3. **§275 조문** — 유기등 치사상(치사상·존속 변형포함) 카드 없음.
4. **79도1387** — 생모가 11세 딸 수혈 거부 → 유기치사죄 성립. 카드 없음.
5. **2015도6809** — 유기죄 추상적 위험범 판례("보호 가능성이 전혀 없을 것을 요하지 않는다"). 카드 없음.
6. **67도1151** — 치사량 청산가리 음독 피해자 유기 → 인과관계 없어 유기치사죄 불성립. 카드 없음.
7. **86도225** — 유기죄 고의 요건 판례 + 사망 미필적 고의 시 살인죄 흡수. 카드 없음.
8. **2025도12963** — 존속학대죄 최신 판례(직계비속의 존속학대). 카드 없음.

**품질 이슈:** 없음.

3. **2010도14316** — 거동에 의한 협박(칼로 자해 시늉 = 협박 해당). 카드 없음.
