1. **허위유가증권작성죄(III) 전부 누락 — 큰 빠짐.** 노트의 허위유가증권작성 소목차 2건 모두 무카드:
   - 발행 위하여 은행신고 외 다른 인장 날인해도 발행인 인장인 이상 어음효력 무관 → 허위유가증권작성죄 불성립([[대판 ... 2000도883]])

4. **유가증권 위조 포섭사례 2건 누락**:
   - 폐지된 약속어음 파지면 조합하여 어음 외형 작출 → 유가증권위조(74도3442)

5. **유가증권 변조 누락**: 자기명의 유가증권에 무단변경은 (문서손괴·허위유가증권작성 별론) 유가증권변조죄 아님(78도1904); 이미 변조된 부분 재변경 불성립(2010도15206). (카드 048은 '이미 위조된 어음 변경 불성립 2005도4764'만 수록)
6. **부수법-무고 실체적경합 누락**: 거짓신고 부수법위반죄와 무고죄 실체적 경합(2013도12064).
7. (경미) 수표요건 결한 무효수표도 진정오신 외관이면 위조죄 성립(72도1796) — 카드 미수록.
