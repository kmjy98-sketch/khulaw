## 논점 45 — 임대차보증금 (p.197)

처리: 감사 완료 (audited)

### 카드 대조 결과

**원문 핵심항목:**
- 피담보채권 물적·시적 범위(명도시, §495 유추, 약정채무 구별)
- 당연공제: 존속 중(소극) / 종료+미명도(소극) / 종료+명도(적극)
- 임대차보증금반환채권 양도 + §451 관계(당연공제 vs 약정채무 이분)
- 차임채권 압류·추심 시 당연공제 (2004다56554)
- 차임채권 양도 후 임차인 공제 주장 가능 (2015다230020)
- 저당부동산 압류·차임채권에 저당권 효력, 채권집행 미실행 시 잔존 차임 공제 (2016다230020)
- 임차권 양도 시 보증금 이행기·공제대상
- 보증금반환채권 양도 후 채권자대위권 행사방법(88다카4253)
- 묵시적 갱신 합의가 보증금반환채권 양수인에게 미치지 않음(88다카4253)
- 수인 임차인=불가분채권 / 수인 임대인=불가분채무
- 주장·증명책임
- 대항력 없는 경우: 원칙·승계특약·면책적채무인수
- 동시이행: 명도의무 vs 보증금반환의무
- §621 임차권등기 말소의무와 보증금반환의무 동시이행(2024다261989)
- 유치권 불인정

**카드에 있는 것(대조 통과):**
- 당연공제 대상 3가지 ✓
- 임대차 존속 중 당연공제 X ✓
- 임대차 종료+목적물 반환 시 당연공제 ✓
- 임대차보증금반환채권 양도 — 당연공제 + §451 (당연공제 vs 약정채무 이분) ✓
- 임대인 동의 있는 임차권 양도 — 이행기·공제대상 ✓
- 수인의 임차인·임대인 불가분채권·채무 ✓
- 대항력 없는 임차권 보증금반환 (승계특약, 면책인수) ✓
- 명도의무 vs 보증금반환의무 동시이행 ✓
- 동시이행항변권에 기한 점유 불법점유 X ✓
- 유치권 불인정 ✓

**누락 항목(원문에 있고 카드에 없는 핵심, 7건):**

1. **보증금 시적 범위 — 원칙: 임차물 명도시** (대판 1987.6.9, 87다68)
   - 원문: "시적 범위: 원칙적으로 '임차물 명도시'"
   - 카드: 없음

2. **임대차 종료 후 목적물 미명도 시 당연공제 소극**
   - 원문: "임대차계약이 종료되었더라도 목적물이 명도되지 않았다면 임차인은 보증금이 있음을 이유로 연체차임의 지급을 거절할 수 없음" (대판 1999.7.27, 99다24881)
   - 카드: 존속 중 소극만 있고, 종료+미명도 소극 카드 없음

3. **차임채권 압류·추심 시 당연공제**
   - 원문: "임대보증금이 수수된 임대차계약에서 차임채권에 관하여 압류 및 추심명령이 있었다 하더라도... 그때까지 추심되지 아니한 채 잔존하는 차임채권 상당액도 임대보증금에서 당연히 공제" (대판 2004.12.23, 2004다56554)
   - 카드: 없음

4. **차임채권 양도 후 임차인의 공제 주장 가능**
   - 원문: "차임채권이 양도되더라도 임차인은 임대차계약이 종료되어 목적물을 반환할 때까지 연체한 차임 상당액을 보증금에서 공제할 것을 주장할 수 있음" (대판 2015.3.26, 2013다77225)
   - 카드: 없음

5. **저당부동산 압류 + 차임채권 채권집행 미실행 시 잔존 차임 보증금 당연공제**
   - 원문: 대판 2016.7.27, 2015다230020 — 저당권자가 차임채권에 대해 채권집행을 별개로 실행하지 않은 경우 잔존 차임도 보증금에서 당연공제
   - 카드: 없음

6. **보증금반환채권 양도 후 양수인의 채권자대위권(임차목적물인도청구) 행사방법**
   - 원문: "양수인은 양수금채권 보전을 위하여 임대인이 임차인에 대해 갖고 있는 임차목적물 반환청구권을 대위행사" (대판 1989.4.25, 88다카4253)
   - 카드: 없음

7. **§621 임차권등기 말소의무와 보증금반환의무 동시이행**
   - 원문: "임차인의 임차권등기 말소의무는 동시이행관계에 있으므로, 임차인은 임차권등기 말소의무를 이행하거나 이행제공을 하여 상대방을 이행지체에 빠뜨려야 비로소 임차보증금에 대한 지연손해금 청구 가능" (대판 2024.12.12, 2024다261989)
   - 카드: 없음
