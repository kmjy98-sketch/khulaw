# 고동성 15회 변시 수기 · 사례풀이 주의사항 — 내용 정리

> 출처: `고동성/_추출/` (수기 hwpx + 사례풀이 주의사항 7과목). SRS는 Anki 이관 예정이라 **공부법 내용 정리**만. 두문자 방식은 사용자 미채택.

---

## 1. 수기 (전국 2등) — 공부법 핵심

### 교재·강의 (★등급)
- **민법** 사례: 로민정(★★, 회독 쌓이면 1권으로 선택형+사례형) / 정연석 민사 사례형 기출해설(★★, 오류 적고 현출 분량 적절) · 기록형: 정연석 민사기록형 기출해설(★★) · 최판: 김남훈 민사법 최판(★★, 민·민소·상 통합)
- **민소** 박승수 암기장(★★, 1권으로 선택형+사례형)
- **상법** 공태용 핵심상법의맥 / 장원석 작은변사기(진도별 풀이용, 해설 부족)
- **형사** 반반형법·반반형소(★★★) — "이것만 회독해도 선택형+사례형 거의 대비"
- **공법** 강성민 헌법 시그니처 암기장 / 정선균 행정법 엑기스
- **환경법** 정선균 핸드북·연습 (총론=기존개념, 각론=특별법 조문찾기)
- **객관식** 전 과목 유니온 변시 기출(진도별·전년도)+모의(5개년)만. 별도 OX 안 봄.

### 시기별 흐름 (회독 누적)
- 방학마다 다음학기 과목 선행 인강 → 학교수업 2회독 → 시험준비 3회독
- 로3~6모: 기록형은 학교 기출풀이 수업으로 갈음, 로민정 회독 + 유니온 선택형 기출
- 6모~8모: 과목별 암기장 1회독씩 (과목당 3~8일)
- 8모~10모: 최판 위주 1회독
- 10모 이후 변시까지 ~75일 = **865(민형공 8·6·5일)–532 직전 플로우 30일 + 나머지 45일**(민21·형13·공8·환2일 배분) → 암기장·사례집·찌라시 계속 회독

### 과목별
- **민사**: 암기장 회독 기본 + 사례형/객관식 기출로 문제풀이 감각. 최판 3회독↑.
- **형사**: 반반형법·형소·최판 4회독↑면 선사기 대부분 대비. 특별형법은 반반에 빈출분 포함(교통범죄만 보충).
- **공법**: 사례형은 "모르는 사람에게 개념부터 설명하듯" 작성. **법리보다 포섭 배점이 높음 → 논거 2~3개로 풍부하게**. 기록형은 회의록이 쟁점 제시 → 형식적 기재례(청구취지 등)만 암기.
- **환경법**: 각론은 특별법 조문찾기가 핵심, 개정 잦아 5개년 기출로 출제례+조문위치 익히기.

### 핵심 교훈 (7)
1. **객관식·사례형 복습**: 오답 선지를 낱말카드(퀴즐렛)로 → **다음날 아침 + 3일 후** 복습 → 1회독으로 2~3회독 장기기억. 사례형도 "실전 현출용 기재례"로 낱말카드化.
2. **찌라시/두문자**: 사례형 풀며 누락·오포섭·자주 틀린 부분만 별도 정리해 틈틈이 회독. (두문자는 본인 방식 — 우리 시스템 미채택)
3. **회독**: "깨진 독에 물 채우기". 3회독부터 빨라지고 5회독↑면 대부분 앎. 1달 안 보면 휘발 → 끝없는 회독.
4. **사례형/기록형 현출**: 익숙한 쟁점도 **머릿속에서 목차 끄집어내는 훈련**, 안 익숙하면 직접 써보기. 직전엔 비주류 보충하느라 주류 현출력 떨어짐 → 주기적 문제풀이.
5. **최판**: 적어도 3~4회독. 단 대부분 암기장에 반영돼 있어 8월 이후 본격 대비도 충분.
6. **점수 주워먹기**: 아는 쟁점도 긴장해서 누락(5~10점 날림). 빈출 기재례(물상보증인 계산, 공소시효 도과 등) 정리로 방지.
7. **부동심**: "나에게 어려운 문제는 모두에게 어렵다", 침착하게.

### 우리 시스템 시사점 (적용 후보)
- 복습 스케줄(다음날+3일) → **Anki FSRS로 이관**(우리가 구현 X).
- "실전 현출용 기재례" 낱말카드 = **사례형 카드의 핵심 컨셉**(A3에 반영).
- 포섭 논거 2~3개 강조 = **포섭용 카드에 논거 넘버링**(A4).
- 점수주워먹기 빈출 기재례 = **찌라시/주의사항 카드**.

## 2. 사례풀이 주의사항 7과목 — 성격과 활용

**장르**: "사례 풀이 시 자주 틀리는 함정 · 검토 누락 포인트 · 빈출 기재례"를 쟁점별로 압축한 체크리스트. (형·민 전문 정독, 민소·형소·상·행·헌 동일 장르)

- 구성 예(형): `0.반복된 실수`(주거침입 누락·착수시기) → 형총(객관적귀속·구성요건착오·공범과신분·합동절도…) → 형각 → 특별형법(폭처법·성범죄·교통). 각 쟁점마다 **검토 누락 경고("☞누락 유의!!")** + 결론.
- 구성 예(민): 민총→물권→채총→채각→가족법. **CASE별 함정**(간접점유자 물권적청구 기각, 중간생략등기 유효요건, 명의신탁 구제수단, 법정지상권 성립기준, 변제자대위 계산…) + 조문 원문 + 判 결론.
- 본인 두문자 다수 포함(예지위규·구구결험구 등) — **카드化 시 두문자는 제외**, 함정·체크포인트·기재례만 사용.

**카드 활용(후속)**:
- 사례형 **"함정/검토누락 체크" 카드** 소스로 최적(점수주워먹기 직결).
- **찌라시** 1차 소스(과목별 빈출 함정).
- 단, 본인 정리물(2차 가공)이므로 조문·판례는 원문/ law-mcp 재확인 후 사용(순환인용 금지).

**미독 5과목**(민소·형소·상·행·헌)도 동일 구조 — 카드화 단계에서 정독 예정.
