# Part 2. 공통 풀이 원칙

## 2-1. 메타 학습법 (전 과목 공통)

**회독 = 깨진 독에 물 채우기**

- 1~2회독은 막막한 게 정상. **3회독부터 빨라지고, 4회독부터 매우 빨라지며, 5회독↑면 대부분 아는 내용**이 됨.
- 단, **1달 이상 미접촉 과목은 지식이 휘발**됨 → 비주류 과목도 주기적 회독 필요(마라톤).
- 방학 활용법: 다음 학기 과목을 **인강으로 선(先)1회독 → 학교수업 2회독 → 시험준비 3회독** 구조.

**복습(장기기억 형성) — 자투리 10~20분 활용이 핵심**

- 유니온 기출 **오답 선지를 낱말카드(Quizlet 등)로** 만들어 다음날 아침·이동 중 풀고, **3일 뒤 재복습** → 1회독으로 2~3회독 효과.
- **사례형도 동일 적용**: 그날 공부한 사례 중 현출해야 할 판례·법리 문구를 **내게 익숙한(실전 그대로 쓸) 기재례로** 낱말카드화.
- **두문자**: 학설·중요 판례 문구는 두문자화 → **TTS(txt→음성)** 로 이동 중 청취.

**찌라시(나만의 오답노트)**

- 누락·오포섭·자주 틀리는 부분을 별도 정리해 틈틈이 회독. **틀린 부분은 계속 틀린다** → 약점 집중.

**현출(現出) 훈련**

- 익숙한 쟁점도 **대략적 목차라도 머릿속에서 꺼내는** 훈련, 익숙지 않으면 **간결하게라도 직접 써보는** 훈련.
- 변시 직전 비주류·최판 보충하다 보면 **주류 과목 현출력이 떨어짐** → 주기적 문제풀이로 감각 유지.

**최신판례**

- 최소 **3~4회독**. 다만 대부분 암기장에 반영 + 학교수업 커버 → **8월 이후 본격 대비해도 충분**.

## 2-2. 답안 작성 공통 수칙 (7과목 횡단)

**① 배점을 먼저 보고 누락 쟁점을 의심**

- 헌법: 기본권(5) + 과잉금지(10) = 15점. **15점 미만 배점이면 기타 원칙 쟁점 의심**.
- 형소: **10점 초과 배점이면 누락 쟁점 유의**.
- 행정법: 행정계획 폐지 = 형량명령(9) + 신뢰보호(8) 둘 다, 부작위 국배 등 **복수 쟁점 배점** 확인.

**② 구제수단·죄책 문제 → 청구권/항변(또는 죄별) 블록으로 망라**

- 빠뜨리기 쉬운 경합 청구권을 **체계적으로 나열**(예: 계약상대방 구제 = 하자담보·채불·일반불법·공작물·사기/착오취소·대상청구 → **경합 긍정** 명시).
- 상법 회사법 구제수단, 형법 죄책도 동일하게 **블록화**.

**③ 학설 대립 → 양설 서술 후 “판례 기준”으로 포섭**

- 예: 위헌결정 소급효 — 양설 서술하되 **대법원 사건이면 대법원 견해로 포섭**.

**④ 법리보다 “포섭”에 배점이 높다 → 풍부하게**

- 공법: 채점기준표도 법리<포섭. **최소 2~3개 논거**로 포섭.

**⑤ 공법 사례형은 “개념부터 차근히”**

- 상대방이 당연히 안다고 전제해 생략하지 말고, **기초 개념부터 설명하듯** 작성(행정법·헌법 공통).

**⑥ 점수 주워먹기 — 쉬운 쟁점 누락 방지**

- 긴장하면 **아는 쟁점도 놓쳐 5~10점**을 날림(수기 작성자도 민사기록 물상보증인 공동담보 계산, 형사기록 축소사실 공소시효 도과 판단 누락). 조금만 신경 쓰면 챙기는 점수.

**⑦ 부동심**

- **나에게 어려운 문제는 모두에게 어렵다**. 지레 겁먹지 말고 침착하게 할 수 있는 선에서 최선.

  - 물상보증인은 시효원용권자지만 직접 채무부담 X → **물상보증인 청구에 응소해도 시효중단효 X**.

  - 재판상 청구 각하 → 보완조치(소송계속 중 보완 포함)로 중단 유지.

### 채권총칙

- **채권자대위**: 대위청구(피대위자 知)했는데 피대위채권에 압류·전부명령 → **전부명령 무효 / 압류는 유효(추심금지효만, 인용)**. 이중매매 제1매수인이 매도인 말소청구권 대위 — 사회통념상 이행불능이나 피대위권리 인정(제746조 배제설/불법개념축소설/불법성비교설 대립, 判 특별 논거 없이 인정).
- **채권자취소**: *(가액배상)* 피보전채권액과 비교. 무효 명의신탁 사해취소 — 전득자 丁은 부실법 제3자로 선악 불문 취득하나, K는 수익자·전득자 상대로 **명의신탁약정을 사해취소해 원상회복 可**(매도인 명의로 복귀).
- **계약 성립(제531조)**: 격지자간 계약은 승낙 통지 **발송 시** 성립.
- **이행지체(제392·401조)**: 이행지체 → 책임가중(무과실 멸실책임) / 채권자지체 → 주의의무 감소(경과실 멸실면책).
- **채권자지체**: 성질(判 귀책 不要, 해제·손배 X → 법정책임설), 요건(협·제·수·수). 효과 = 면(지체)·공 / 감(멸실)·이·비·위. 수령거절+이행거절 동시 문제(계약취소 의사표시) 시 ① 채권자지체 효과(해제 불가) ② 이행거절 효과(해제 가능) **둘 다 검토**.
- **채권양도**: 매매 소유권이전등기청구권 양도 — ① 중간생략등기는 전원 합의 要 ② 성질상 신뢰관계 → **채무자 동의·승낙 없이 대항 X**(유효 명의신탁 해지 원인 이전등기청구권 양도에도 적용).
- **해제**
  - 제3자를 위한 계약의 제3자: 해제의 제3자 X → 법정해제 대항 X(청산은 당사자간), 단 **합의해제는 대항 O**(제541조).
  - *(누락 유의)* 해제로 보호되는 제3자 = ① 등기·인도 등 완전 권리 갖춘 자 ② 해제 후 제3자(후·원·전·양·선·해·주 — 선의 要).
  - 원상회복: 원물반환 불가 시 **가액배상(가액+법정이자)**.
  - 이행기와 해제권 행사 간 시간차 → **원시적 시효 검토**. 원채권 시효소멸 시 채무불이행 시점 불문 소급소멸 → 해제권 행사 X.
  - 제556조①2호 부양의무 미이행 증여 해제 → 제974조 부양의무(직계혈족·배우자·생계 같이 친족 한정).
- **보증(제428조의2)**: ‘보증인의 서명’은 원칙 직접 자서(타인 대신 X), 단 **‘기명날인’은 타인 대행 무방**.
- **계약 상대방 구제수단**: ① 하자담보 ② 채불 ③ 일반 불법(제750조) ④ 공작물(제758조) ⑤ 사기·착오 취소 ⑥ 대상청구 → **경합 긍정** 서술. [숙박업자 과실] ① 채불 ② 750 ③ 758.
- **위험부담**: 쌍방 무귀책 → ① 계약소멸(부동산 인도·반환) ② **대상청구권 둘 다 검토**.
- **변제자대위(보증+물상보증 겸유)**: 1인의 보증인으로 봄. [예] 주채무 12억, 丙·丁 연대보증, 丁·戊·己 물보(4·6·3억), 丙이 3.9억 변제 → 부담비율 3:3:4:2, 자기 부담 3억 초과 0.9억을 3:4:2로 대위.
- **상계**: 제3채무자가 전부채권자에 상계 대항 → 소급소멸(전부명령 무효, 압류 유효, 집행채권 부활). 양도 통지 후 상계 — (원·아·후·적) 양도 당시 상계 원인 있으면 그 후 상계적상 이르러도 可. *(주의)* **고의 불법행위 손배채권은 수동채권으로(사용자도) 상계 不可**.

### 채권각론

- **매매(제587조)**: 미인도 과실은 매도인 귀속. 소유권이전등기해줘도 대금 미완납 시 매도인 사용수익권 O. 인도받은 날부터 대금 이자 지급(기한 있으면 예외) — 단 동시이행 등 대금거절권능 있으면 이자 X(실익 의문).
- **도급**: 수급인 공사대금채권 항변 = ① 유치권 ② 동시이행 **둘 다**. 제665조(보수=완성물 인도와 동시). 도급인이 비용지출자 → **수급인 제203조 비용상환청구 X**(전용물소권 X).
- **임대차**: 대항력 없는 임차인 유익비 지출 후 양수인 인도청구 → ① 임대차 유익비상환 X(대항력 X) ② 점유자 유익비상환 X(계약관계 O) ③ 부당이득 X(전용물소권 X). **지상물매수청구(소·당·소·임 / 소·후·3·양 / 신·대)**: 원칙 소멸 당시 토지소유자인 임대인에게, 단 소멸 후 제3자 양도돼도 **대항력 있는 임차권이면 신소유자에게 可**. (제588조) 행사 당시 건물 시가에 근저당 피담보채무 공제 X, 단 임대인은 근저당 말소까지 채권최고액 상당 지급거절 可.
- **화해(제732·733조)**: 창설적 효력. **착오 취소 불가**(단 당사자 자격·분쟁 외 사항 착오는 예외, 사기취소는 可).
- **부당이득 반환**: 취득시효 완성자엔 소유자가 이전등기의무 있어 부당이득반환청구 X. 선의 점유자 과실수취권 — 단 **소장 부본 송달일 당일 악의 의제**. 정기적 지급청구는 미청구분 검토. 회사자금 횡령자가 은행 편취금으로 횡령금 보전 → (편·변·악·중·원). 직접·간접점유 = 부진정연대, 건물 공유자 토지점유 = 불가분.
- **불법행위**: [숙박업소 화재 사망] (상속채권) 불완전이행·공작물·일반불법 / (고유채권) 제752조(判 태아 정신적 고통 인정). [호의동승] ① 피해자측 과실이론(신·생·일·체) ② 호의동승 감경(매·불) ③ 공동의 의미 — 각 운전자 공동불법행위.
- **사용자책임(제756조)**: 피용자+제3자 공동불법행위 시 사용자도 제3자와 부진정연대 → 사용자가 피용자 부담부분 이상 배상 시 **제3자에 구상 可(제3자 부담부분 한정)**. *cf)* 피용자엔 전액 구상 可(신의칙상 제한). [예] 제3자 1800·피용자 200, 사용자 1500 배상 → 제3자에 1300(=1500−200) 구상.

  - *↔* 소유권 귀속이 **상속을 원인**으로 하는 이상 청구원인 불문 상속회복청구의 소.
- **상속**: A–B(망)–{C(망)·D(망)}–{E·F / G}. ① A 사망 → **대습상속** E·F/G = 1:1:2 / ② A 사망 후 B·C·D 상속포기 → **본위상속** E·F/G = 1:1:1.
- **가분 채권·채무**: 상속개시와 동시에 법정상속분대로 분할귀속 → **분할협의 대상 X**(예: 소유권이전등기청구권 각 분할귀속, 준공유 X). (채무) 자기 상속분 초과 부담 = 면책적 채무인수 → 채권자 승낙 要(소급효 X). (채권) 단 초과특별수익자·가분채권만 있는 특사 시 분할 대상 O.
- **상속결격(제1004조)**: 상속개시 후 결격사유 발생해도 소급무효(상속회복청구 문제). 判 **동순위 태아 낙태도 결격 O**(상속에 유리하다는 인식 不要).
- **유언**: 자필증서(제1066조) — 주소는 다른 장소와 구별될 정도(부정 “암사동에서” / 긍정 예명 O·봉투에 O). 비밀증서(제1069조) 방식 흠결 시 자필증서 요건 갖추면 자필증서로 전환(제1071조).

## 3-2. 민사소송법

- **관할**: [영업에 관한 채무] 의무이행지 = **현영업소**(주소지 X, 민467②), 영업소 소재지 특별재판적(민소12). *cf)* 불법행위채권은 행위지·결과지(단 의무이행지 적용 X 고법 판례). [변론관할] 사물관할도 가능, **진술간주로는 X**. 반소기각 답변만으론 본안변론 X(항소심 반소 동의의제 X).
- **소익**: 계속적 점유 정기금 청구 → 장래이행청구 적법성(기·존·의·이·확 / 임). 임대인 인도청구에 대한 임차인 보증금채권 존재확인 반소 → **이행청구 반소가 더 유효적절 → 확인의 이익 X**.
- **송달**: 소장에 대표자 기재 있으면 소장각하 X. 법인 소재지 = 사무소·대표이사 근무장소. [보충송달] 동거인=동일세대·생계 / 사무원=경비원 묵시적 위임 / **무효=본인·수령인 간 당해사건 이해대립(채무자·제3채무자)**. 근무장소는 거부 안 해야 보충송달 可(유치송달 X).
- **소송수계**: 실종자 판결확정 후 실종선고 → 판결 유효, 상속인 수계인으로 **추완상소 可**. 소송계속 중 사망 간과 → (판결) 위법하나 유효, 대리권 흠결 준해 재심·상소 / (송달) 무효 / (상속인 조치, 선택설) 수계 후 통상항소 or 항소 후 수계.
- **추완상소**: 책임질 수 없는 사유 = 일반적 주의 다해도 준수 불가(공시송달 O). ‘사유 없어진 때’ = 공시송달 된 것을 안 때(통상 기록열람·판결정본 수령), 단 판결 존재 알고 경위 알아본 특사 시 통상 소요기간 경과 시(공·방·열·새 / 존·경·특·기).
- **입증책임/변론주의**: 심증형성 → 법률요건분류설·입증책임 언급.
- **통상공동소송**: 직접·간접점유자 부당이득반환 = 부진정연대(불가분 X) → 통상공동소송.
- **예비적 공동소송인 추가**: 乙 청구와 양립불가한 丙 청구 추가 시 쟁점은 청구변경 가부 아니라 **“예비적 공동소송 추가”**.
- **소송물**: 근저당설정계약 취소 원인 말소청구 ≠ 피담보채무 변제 원인 말소청구(**후자는 해지 원상회복청구권**).
- **기판력**: 기판력 부정돼도 **증명효로 “합리적 이유” 없는 한 전소 이유 중 판단 배척 불가**. (채권자대위, 제218③) 判 채무자가 “알았다면” 미침. (화해) 1억을 0.7억으로 조정 후 1억 청구 → 0.7억 소각하(권리보호이익 X)·0.3억 기각(창설효). (소촉법) 법률·판례 변경은 새로운 사유 X — 시효중단 위한 이행청구는 구 소촉법, 일부인용은 판결선고 다음날부터 소촉법.
- **인낙**: 성질 — 사법행위설/소송행위설/양성설, 判 **소송행위설**.
- **항소 이익**: 청구취지·주문 형식적 비교. [소각하판결에 원고 항소] 청구기각해야 하나 소각하한 위법 있어도 **불이익변경금지로 항소기각(각하 아님)**. [시가 오인 소액청구=묵시적 일부청구] 잔부 기판력 미침 → 예외적 청구취지 확장 인정. [상계항변 인정 원고패소·피고만 항소] ① 항소이익(출혈적·예비적) ② 불변금(항소심 상계항변 배척 불가).
- **상소불가분**: 본소·반소 1개 판결 중 일부 불복 → 전부 이심, 불복 부분만 심판(단순병합).
- **보조참가 vs 공동소송적 보조참가**: 상소기간 — 피참가인 기준 / **참가인 기준**. 참가인 상소를 피참가인이 취하 — 可(어긋나는 행위) / **不可(1인에 불리한 행위)**. 단 피참가인이 공동소송적 보조참가인 동의 없이 한 소취하는 유효.
- **추가적 인수**: 전혀 다른 청구의 추가적 인수 **부적법**(건물철거소송 중 제3자 말소등기청구 추가 사안). *cf)* 건물철거청구권 보전 처분금지가처분 可(당사자 항정효).
- **전부명령**: 가압류 제3채무자 송달·집행 완료 후 취하 → 장래효(**압류경합으로 전부명령 무효면 가압류 취하돼도 무효**).
- **민사집행(컴팩트 보충)**: 집행법원 항고장각하결정=1차 처분 → 즉시항고는 최초 항고. 비법인사단 → 선정당사자 표시정정 허용(제1심 인정·항소심 부정해 제1심 취소 시 진정 당사자에 판결 無 → 상고 아닌 기일지정신청). 채권자대위소송을 채무자가 알았다면 기판력이 채무자·다른 대위채권자에 미침 → 공동 대위소송은 **유사필수적 공동소송**.

## 3-3. 상법

### 상법총론

- **지배권·대표권 체크리스트**: 「권·제·남·표 / 등 / 자·특」 = ① 권리능력 범위 ② 대표권 제한 ③ 남용 ④ 표현대표 ⑤ 부실등기(or 상업등기 소극적 효력) ⑥ 자기거래 ⑦ 특별이해관계.
- **상호**: 폐지청구 / 손해배상청구.
- **채무면탈 목적 현물출자로 주식회사 설립**: ① 상호속용 책임 — *(주의)* 현물출자 시 상호속용책임 유추적용하되 **양도인은 2년 경과 시 책임 소멸** ② 법인격 남용.
- **소멸시효**: 일방적·보조적 상행위도 상사시효 / 채무불이행 채권은 원채권 변형이라 상사시효. [예] 대표이사 A가 은행 B로부터 대여 → 은행의 보조적 상행위(**상사시효 5년**).
- **익명조합 손해분담**: 손해분담 필수 X, 특약 없으면 수익분배비율 추정(민711②유추).
- **조합**: 조합원 단독 명의 계약도 조합사업 위한 것이면 전원 위한 것 → **연대책임**.
- **유치권**
  - 상사유치권(쌍·쌍·변·점·소·배 / 견): 채무자에 대한 상행위로 점유.
  - 대리상·위탁매매인: 채무자 소유 不要, **견련성 不要(가장 유리)**.
  - 운송인·운송주선인: 채무자 소유 不要, **견련성 要**(운송물 일부 유치해도 그 운송 운임채권 전체 견련성 O, 그 전 운임채권엔 X).
- **화물상환증 상환 없이 비소지인에 인도**: (운송인) 채무불이행 + 고의·중과실 권리침해 불법행위 / (비소지인) 공동불법행위.

### 회사법 — 설립·주식

- **설립**: 납입대금 부족 시 통설(설립무효구제설)상 흠결 경미해 **설립무효 X**, 발기인 **납입담보책임 O**. 가장납입과 달리 손배책임 별도 검토 불요(?).
- **타인명의 주식인수**(구체적 언급 시만): 제332②는 납입책임만 규정 → 귀속은 의사해석. 判 ① 가설인은 명의자 의사 없어 **납입자** ② 회사 승낙 사정 없는 한 명의자 이해 → **명의자**.
- **명의개서 미필주주**(대부분 CASE): 형식주주 권리행사 = 형식설 vs 실질설 / 실질주주 권리행사 = 편면적 vs 쌍면적 구속설 / 양수·양도취소 후 미개서 = 서두에 권리추정력·대항력·면책력 언급. **절취·위조 명의개서**는 위법(2017 전합 적용 X) → 종전 명의인이 주체(회사 악의·중과실 없으면 면책력 O).
- **주권발행 전 주식양도(제335③)**: 회사에 효력 X, 단 **6개월 경과 시 예외**(회사 승인해도 효력 X). 주식병합도 동일(효력발생=주권제출기간 만료 후 6개월). 지명채권 양도 일반원칙, 당사자 합의로 효력 발생·단독 증명 명의개서 청구 可. 양도 해제 시 통지 없이 양도인에 당연복귀.
- **자기주식취득**: 배당가능이익 범위·주주평등 방식으로 제한(자본충실·지배구조 왜곡 방지). 출연·손익이 회사 귀속해야 자기주식 → **무상취득은 자본충실 우려 없어 유효**.
- **상호주 의결권 제한(제369③ — 누락 유의)**: 회사+모회사+자회사(또는 자회사)가 10% 초과 보유 시 상대회사 보유 주식 의결권 X. **모자 합산 10%↑면 “모회사”에 대해 의결권 제한**, 명의개서 不要(사실상 영향력). 의결권 위임받아 대리행사는 유추적용 X.
- **영업양도/중요재산 양도**: 각 부문이 독자 영위 시 “영업의 일부”(중요한 경우만 특별결의). 중요재산 양도는 **① 이사회 결의사항 여부 ② 주총특별결의 여부(영업폐지·중단 초래) 둘 다 검토**.
- **종류주식(제344③)**: 정관 정함 없어도 신주·병합·분할·소각 등 특수 정함 可, 단 불리하면 **종류주주총회 要**(흠결 시 감자무효사유). 종류주총 흠결 성질 — 주총 절차하자(취소)/효력발생요건(불발효)/정관변경 특별요건(判 정관변경무효확인).
- **주식병합**: 자본금 감소 초래 → 결손보전 아니면 특별결의, 다툼은 **감자무효소송(소급효)**.

### 회사법 — 신주발행·배당

- **신주발행**: 배정기준일 경과 시 “구체적 신주인수권” 발생(양도 정하지 않으면 양도 가부 — 부/긍/判 지명채권). 청약 시 “권리주” 발생 → **권리주 양도는 회사에 효력 X(제319, 승인해도 X)**. 인수인 납입기일 미납 시 권리 상실(손배청구 영향 X). [출자전환] ① 채권 현물출자(제422② — 변제기 도래 금전채권, 장부가액 이하면 검사 면제) ② 납입채무를 채권으로 상계(회사 동의).
- **신주발행무효소송**: 납입기일 경과 전이면 효력 발생 전 → **유지청구도 검토**. 무효사유(判 위현/기·주·경/중·단·묵): (무효) 현물출자 과대평가 / (유효) 검사절차 X·이사회 결의 흠결. 전환사채·신주인수권부사채 무효소송 — 명문 없지만 유추 인정(정관에 신주발행 주총결의로 정한 경우 전환사채도 주총결의).
- **배당 종류**: ① 이익배당 — 주총결의(정관상 이사회 승인 예외) ② 중간배당 — 정관+이사회결의 ③ 현물배당 — 정관+이익배당 결의방식 ④ 주식배당(1/2까지) — 주총결의(성질: 주식분할설/이익배당설, 문리상 이익배당설).
- **위법배당 구제(계산 유의)**: 이익준비금이 자본금 1/2 될 때까지 **배당액의 1/10 적립**. 무배당이익 배당 = 내용 법령위반 무효(선결 不要, 부이반). ① 회사 부이반 ② 채권자 채권자대위·462③ 반환청구 ③ (주식배당) 신주발행무효소송.

- **추심위임배서**: [숨은 추심위임배서] “양도배서 형식으로” → 신탁적 이전 → 피배서인에 대한 항변 대항 O, 숨은 것 입증하면 인적항변 절단으로 배서인 항변도 대항 O. 추심위임배서 후 반환받아 통상 배서 시 → 배서 연속성 X·권리추정력 X(절단 부분 입증 주장 可). 공연한 추심위임배서는 권리이전효 X(인적항변 절단 X).
- **기한후배서**: 지급거절증서 작성·지급제시기간 경과 후 배서 → 지명채권 양도 효력만(만기 있으면 만기후제시 유의).
- **지급거절증서 작성 면제(제46)**: 무비용상환·거절증서 불필요 문구.
- **선일자수표(수표법 제28②)**: 발행일 도래 전 제시돼도 **제시된 날 지급**(判 선일자수표 유효).

### 보험

- **소급보험·승낙 전 보험**: [청약 전 사고] 소급보험(제643·644 — 객관적 확정 무효, 단 쌍방·피보험자 부지 예외). [청약 후 승낙 전 사고] 제638의2③ — 거절사유 없는 한 책임(인보험 신체검사 미필 예외). 判 ① 거절사유는 약관 등 객관적 기준 ② 보험사고 미고지는 거절사유 X ③ 제644로 무효 안 됨.
- **보험자대위**
  - 피보험자 면제·변제 후 보험자 지급: 피보험자 자유로이 면제·변제 可, 단 判 그 한도에서 보험금 지급책임 면함 → 이후 받았으면 부이반.
  - 보험자 지급 후 피보험자 면제·변제: 보험자대위로 법률상 이전 → 무권리자 행위 무효(단 선의·무과실이면 준점유자 변제 可).

## 3-4. 형법

> **반복된 실수**: 살인·절도·폭행 문제 → **주거침입 검토**(누락 주의). 주거침입 착수시기 = 문을 당기는 등 침입의 현실적 위험성 있는 행위 한 때.

### 형법총론

- **합법칙적조건설·객관적 귀속**(예·지·위·규): (합법칙적조건) 자연과학법칙 / (객관적 귀속) ① 예견가능성 ② 지배가능성 ③ 위험창출·증대 ④ 규범 보호목적 내.
- **가중적 구성요건 착오**: [보통살인 인식→존속살인 결과] 제15①로 중한 죄 벌할 수 없고, 구성요건적 착오 견해 검토 → 법정적부합(죄질부합)이면 고의 전용 인정 → 보통살인죄. [존속살인 인식→보통살인 결과]도 견해 검토 후 동일 결론.
- **개괄적 고의·과실**: 시체은닉죄 불능미수 — ① 추상적 위험설로 긍정설 있으나 ② 살인죄 가벌적 평가에 포함돼 흡수가 타당.
- **강간치상·상해치사**: **결과적 가중범의 공동정범 인정 여부 누락 유의** — 判 기본행위 공동 의사 + 중한 결과 예견가능성 있으면 O.
- **타인 범행 인식·방치**: ① 남편 살해되는 현장(실행 중) 목격·미신고 = 실행지배 X → 방조범 ② 쓰러진(실행 완료) 현장 목격·미신고 = 실행지배 O → 정범.
- **부진정부작위범 착수시기**(구·구·결·험·구): 학설(최초/최후 구조가능시설), 判 결과발생 위험 구체화된 상황의 부작위.
- **외연적 과잉방위**: 원칙 침해 종료 후 방위행위는 정당방위·과잉방위 X, but 연속된 불가분 결합이면 **전체로 1개 과잉방위 인정 可**.
- **의무의 충돌**: 긴급피난 특수형태 → 비교형량해 더 높은 가치 이행.
- **추정적 승낙**: 현실 승낙 없으나 객관적 사정상 당연 승낙 추정 → 위법성조각.
- **절도범행 중 폭행·상해**: 判 절도 공모 중 1인 폭행·상해 시 예견가능성 있으면 준강도·준강도상해 O. [책임 X] 집 비어있는 줄 알고 폭행 전 이미 현장 떠남.
- **공범과 신분**
  - [공무상비밀누설] 필요적 공범인 **대향범은 총칙 규정 적용 X 검토**.
  - [거래상대방의 횡령교사] ① 제33조 본문(보관자 지위) ② 장물취득죄.
  - [동승자의 도주교사] ① 특가법 공동정범 X(승계적 공동정범 가담 이후 제한) ② 제33조 본문(운전자 지위)·사고후미조치 교사범 可.
- **합동절도**(주·합·특·공): ① 폭처법(공동주거침입) ② 합동의 의미(공·가·현·현 — 공모공동정범/가중적 공동정범/현장설/현장적 공동정범) ③ 특수준강도(폭행협박시설) ④ 합동범의 공동정범 — 현장에 없어도 정범성 표지 갖추면 O(배후자 처벌 필요성).
- **살인계획 알고 부하 내보낸 경우**: ① 정범배후정범 부정(간접정범 X) ② 실행지배 X(직접정범 X) ③ **편면적 종범 O**.
- **성립·과형 구별설**: [이중적 신분] 구성적 신분 취득하되, 判(성립·과형 구별설)으로 **업무상배임 성립·단순배임으로 처단**.
- **소극적 신분**: 의료법 위반 — 명문 없고 判 제한적 공범종속성으로 해결. 무고죄 — 무고교사죄 성부(자기무고 불벌·공동정범 불벌로 부정설 vs 공범종속성 긍정설, 判 긍정). (공동정범 O) 부정수표단속법 — 발행명의인·직접발행자 아니어도 공모면 공동정범 / (X) 범인도피·증거은닉.

### 형법각론

- **신체에 대한 죄**: 식칼로 찌르려다 빼앗김 → **특수상해미수**. (특수) 위험한 물건 = 사회통념상 살상 위험 느낄 정도 / 휴대 = 범행 사용 의사 소지·널리 이용.
- **재물죄**
  - 마약 편취 → ① 금제품의 재물성 ② 불법원인급여에 대한 사기죄 성부.
  - 술집 주인이 술값 절취 → [구성요건] 절도죄 불법의 의미(영득의 불법 vs 절취의 불법) / [위법성] 자구행위·정당행위.
  - 채무면탈 목적 살인하고 상속인 채권 존재 확인 방법 확보 → **강도살인 X, 단순살인 O**.
  - 야간 침입이나 2인 이상 합동절도 → 견해대립, 判 주간 합동절도는 실경합·야간은 입장 불명, 생각건대 합동절도에 야주절도 포함 → **합동절도만 성립**.
  - 보이스피싱 조직원 → ① 사기죄 ② 범죄단체활동죄.
  - 컴퓨터등사용사기 → 타인 전화 사용·인터넷 접속은 정보처리 X → **컴사 X**.
  - 위법사실 은폐 목적 허위공문서작성·위계공무집행방해·증거인멸 → 작위범에 직무유기 위법상태 포함 → **직무유기 성립 X**.
- **장물**: “이러한 사정 말하고” 교부 시 수령자 → ① 장물보관죄 ② (피해자에 대한) 횡령죄 X(이미 소유물추구권 침해). **장물 처분 대가는 장물성 상실**(물건⇒현금). *↔* 장물 현금·자기앞수표 예치 후 인출한 현금은 장물 O(현금⇒현금). 처분대가는 장물 X지만 장물 숨기고 판매 시 사기죄·편취금은 장물 O.
- **문서죄**: 변조 = 동일성 유지한 채 새 증명력 작출 + 일반인 오신 외관. 등기 경료 → 공전자기록불실기재죄·동행사죄.
- **뇌물·사기·공갈**: 기망해 뇌물 수수 = **상상적 경합**(피해자=뇌물공여 O). 직무집행 의사·대가관계 없이 공갈 = **공갈죄만**(피해자 무죄, 상경 시 견해대립).
- **범인도피·증거인멸·위증**: 자기 도피/인멸/위증교사 — 방어권 연장(부정) vs 남용(긍정). 判 (도피·은닉) 도움 요청 X·방어권 남용 O / (위증) O.

### 특별형법

- **폭처법(2인 이상) 검토**: (존속)폭행·협박·체포감금·강요·공갈·주거침입·퇴거불응·재물손괴.
- **촬영물 이용 범죄**: 촬영·제공·협박·강요 검토. 강제추행하도록 → 성폭법(촬영물제공)·성폭법(촬영물이용강요)·강제추행(상경). 공갈 → 성폭법(촬영물제공)·성폭법(촬영물이용협박, 강요 X)·공갈(상경).
- **성범죄**: 13~19세 미만 → 아청법 / 13세 미만 → 성폭법. **2인 이상 합동 → 성폭법(특수강간)·성폭법(강간등치상)**.
- **교통(누락 유의)**: 특가법(위험운전치상) → **도교법(음주운전) 누락 유의**, 특가법(위험운전치상) > 교특법. 특가법(도주치상)·사고후미조치 → **도교법상 사고후미신고죄 누락 유의(실체적 경합)**.

## 3-5. 형사소송법

> **배점**을 항상 보고 누락 쟁점 유의(10점 초과 배점).

### 서론

- **관할**
  - 동일사건 같은 법원 중복기소 → 공소기각판결.
  - 동일사건 다른 법원: 사물관할 異 → 합의부(제12) / 토지관할 異 → 선기소(제13, 예외 검사·피고인 신청).
  - 다른 사건 병합심리: 사물관할 異 → 합의부 可(제10, **형소규칙 제4① 토지관할 달라도 적용 — 기재**) / 토지관할 異 → 직근상급법원 결정(제6).
- **제척**(재·환·기 / 선·정·적·구·보): 약식명령 관여 판사가 정식재판 관여 → 예단형성(긍정) vs 동일심급 X(부정), 判 **부정설**(단 항소심은 전심관여라 제척 O).
- **성명모용/위장출석**
  - [성명모용] 判 검사 정정 시 모용상태 해소 → 피모용자 공소기각은 위법. 판결확정 효력은 모용자에게만(모용자=판결경정 / 피모용자=재심설·비상상고설·전과말소설, 判 비상상고 사례, 검토 전과말소설).
  - [위장출석] 판결확정 효력은 사실상 소송계속 발생한 위장출석자(위장출석자=재심설·비상상고설, 검토 재심설 / 실질적 피고인=제1심 소환·심리).
- **변호인선임서(제32)**: 심급마다 서면 제출. 소송행위 후 추완 가부 — 긍정/부정설, 判(절충) 제출기간 경과 후 추완은 부정.

### 수사와 공소제기

- **체포 적법성**: ① 체포 당시 기준 ② 상당한 재량 ③ 현저히 불합리하지 않으면 적법.

### 공판

- **공소장 변경**: [포괄일죄] 동종 확정판결 있으면 사실심 선고시 기준 분단 → 동일성 X. [상습범] 처벌규정 신설 → 신설 전 범행 상습범 X → 실경 → 동일성 X.
- **이중기소**: [선기소 상습범 + 비상습 추가] 판결선고시까지 범행에 효력 미침 → **공소기각(제327①3호)**. [선기소 비상습 + 상습 추가] 공소기각/의제/석명후판단설, 검토 의제설(실질적 불이익 없어 소송경제).
- **무단퇴정·퇴정명령(제330·318②)**: 진술 없이 판결 可. 출정 없는 증거조사 시 동의 간주(대리인·변호인 출정 시 예외). 증거동의 범위 — 판결선고만/사실심리도/증거동의도, 判 **변호권 포기·방어권 남용으로 증거동의 의제**.
- **증인신문 시 증인 보호**: ① 피고인등 퇴정(제297) ② 비디오 중계(제165의2) ③ 신뢰관계인 동석(제163의2 — 13세 미만·장애 시 필요적).
- **위수증**: 압수조서는 2차증거. 임의동행 위법이면 이에 기초한 피의자신문·긴급체포도 위법.
- **사인의 위법수집증거**: 몰래 녹음·촬영 / 음향 녹음 → ① 통비법 위반(X) ② 사인의 위수증(X) 검토.
- **전문법칙**: [협박문자 사진(사·전·사)] ① 사본 사진 = 判 구별설(원본 성질) ② 진술내용 존재가 요증사실 → 전문 X ③ 사본 증거능력(존재·곤란·동일성). [사인 협박진술 녹음·현장영상] ① 통비법·위수증 ② 현장녹음 증거능력(사실 보고/지각 X/조작 우려).
- **증거동의**: 위수증 증거동의 가부 — 처분권설(긍정)/반대신문포기설(부정), 判·검토 **부정설**.
- **탄핵증거**: 자백 피신조서·법정 부인 시 탄핵 가부 — 긍정/부정, 判 긍정설. 증명력 다툼 의미(감쇄만/회복도, 검토 회복도). 탄핵증거 범위(자기모순 한정/+보조사실/비한정, 검토 비한정).
- **자백보강법칙**: 상습범·실경은 각 범행마다 보강증거 要(↔영업범), 단 소변검출결과는 인접시기 수죄 공통 보강 可. 범위 — 죄체설/진실성담보설, 判 **진실성담보설(간접·정황증거도 O)**.
- **판결 선고(위헌결정)**: 위헌결정 → 소급 효력상실 → **전부무죄**(잠정적용 헌법불합치도 동일). 종전 합헌 후 위헌 → 합헌결정일 다음날 소급 상실 → 그 이전 범죄는 ‘폐지’와 마찬가지 → **면소**.
- **형종상향**: 정식재판사건 + 별도사건 병합해도 형종상향금지 적용 → 징역형 선택 시 불변금 위배 아니라도 형종상향금지 위반.

## 3-6. 헌법

> **배점 고려**: 기본권(5) + 과잉금지(10) = 15점 → **15점 미만이면 기타 원칙 쟁점 의심**.

- **재판의 전제성**: 헌법불합치 결정으로 **더 엄격한 기준** 개정 시 승소 가능성 → 전제성 O.
- **위헌결정 소급효**: 양설 서술하되 **대법원 사건이면 대법원 견해(당·동·병·일)로 포섭**.
- **권리구제형 헌법소원**
  - 공권력 행사: 행정지도는 한계 넘어 규제적 성격 강하면 O.
  - 직접성: 별도 집행행위 없이 의무부과·자유제한·권리박탈. 하위법령 시행 예정(위임규정)은 직접성 X, 단 불가분 규율이면 “전체” 심판대상 可. 처벌규정은 고유 위헌성 주장 없으면 직접성 X.
  - 보충성: 구제절차 없거나 불확실해 기대가능성 없는 경우.
  - 청구기간: ① 시행과 동시 침해 = 안 날 90일·시행일 1년 ② 시행 후 사유 발생 = 사유 발생 안 날 90일·발생일 1년(判 구체적·현실적 적용 최초의 날).
- **권한쟁의심판**: 사보임행위 → 자율권 쟁점. 당사자능력 — 국가기관(예시적)/지자체(열거적). (긍정) 구 선관위 / (부정) 소위원회(장)·안건심의위원회(장)·교섭단체. 권리보호이익 — 공익적 성격이라 의사진행 방해해도 남용 X(↔취하 可). 피청구인 특정 — 법률안 제출은 “정부”.
- **기본권 충돌**: 대립당사자 甲·乙 기본권 제한 판단 후 위헌 논할 때 — 상위기본권 우선·규범조화적 해석 → **결국 과잉금지 포섭**.
- **제한되는 기본권**: 법인형태 약국·의료기관 개설 금지 → ① 직업수행의 자유 ② 결사의 자유(단체결성·활동).
- **정당해산심판(제8④)**: 절차(국무회의 심의) / 실체(민주적 기본질서 협소 해석·비례원칙). 위원직 상실 — 국회의원은 判 지역구·비례 불문 상실(실효성) / 지방의회의원은 공직선거법 제192④ ‘해산’에 강제해산 포함 → 해산 외 당적이탈 X(비례대표 지방의원 당연퇴직 X).
- **정당기속성(교섭단체 요청 개선행위)**: ① 국회의원 심의표결권(제40·41①·49) ② 자유위임 위배 여부(제45·46②, 국회 자율권 제64와 비교형량, 의장 개선행위 광범위 재량) ③ 정당기속성(당론 반대 의원 제명·개선 요청은 사실상 강제로 허용) ④ 소결(원활한 운영·독자표결 금지 아님 → 위반 X). 국회법 제48⑥ — 임시회 회기 중 개선 불가, 정기회 선임·개선 후 30일 내 불가(재임기간 보장).

## 3-7. 행정법

> **공통**: 개념부터 차근히 설명해주는 느낌으로.

- **대상적격**(이원설/개념요소 서술): 判 권리의무 직접 영향 염두에 두고 주체·내용·절차·형식, 견련성, 태도 등 개별·구체 판단. 강학상 특허인 위탁계약 해지 → 특허 취소(철회). 부적합통보 → 거부처분 아니라 처분성 검토(적합통보 받은 자만 허가신청 → 처분성 O). 정비구역지정 → 행정계획 아닌 **일반처분**. 택지개발지구지정 → 행정계획. 즉시강제 → 권력적 사실행위 처분성(① 사실행위 부정 ② 수인하명+사실행위 결합 ③ 준하는 행정작용).
- **원고적격**
  - 외국인: 거부처분은 보통 대상적격에서 신청권·원고적격은 직접상대방이라 별도 검토 X지만 외국인은 특수 검토 — 入國 전 외국인은 법적 이해관계 X, **재외동포·거주자는 법률상 이익 O**.
  - 행정청의 원고적격(국민권익위 → 소방청장 조치요구): 원칙 당사자능력 X지만, 기관소송·권쟁심판으로 다툴 수 없고 권리보호 필요 시 인정.
  - 제3자 인정 사례: 협약해지통보→연구팀장 / 급여환수·호봉정정명령→사립학교 교원 / 사업비 환수→비위 지목 교수 / 채용승인 거부→사무원.
  - 수혜적 조항 다툴 주민(지자법 제17②).
- **경원자소송**: 일방 허가·타방 불허 귀결 → 법률상 이익 O(처음부터 허가가능성 없으면 소익 X). 자신에 대한 거부처분 취소소송 — 인용 시 재처분의무로 경원자 허가 직권취소 가능 → 소익 O. 거부처분취소재결 — 재처분 기다려 다투는 게 적절 → 재결 다툴 소익 X.
- **제소기간**: 제3자는 처분 바로 알 수 없어 심판청구기간(180일) 내 미청구해도 “정당한 사유” O(쉽게 알 수 있던 특사 없는 한). 일반처분 → 효력발생일 악의의제(특별규정 없으면 공고일 5일 뒤), 단 연번별 규율이면 개별(判 개별토지가격결정). 송달일·소제기일 명시 시 제소기간 의심.
- **인가의 법적성질**(허가/특허 구별): 허가=명령적(자연적 자유 회복·기속) / 특허=형성적(공익상 필요·재량). 구별 상대화.
- **이의신청(행정기본법)**: 결과 통지일 90일 내 종전 처분 다툼. 새로운 신청으로 선해 가능 시 기각은 새 거부처분(처분성 O).
- **부작위**: 결정을 하고 있지 않음 → 부작위 검토(거부처분 X).
- **피고적격**: 사업시행자(공무수탁사인) = 행정주체+행정청.
- **위법판단 기준시**: 처분시(단 부작위는 판결시, 사정판결 공공복리는 판결시).
- **행정계획 폐지 위법성**: ① 형량명령이론(9) ② 신뢰보호 원칙(8) **둘 다**.
- **신뢰보호 원칙**: 적정통보 — 사전결정 구속력설 있으나 判 신뢰보호로 해결. (위반 X) 폐기물적정통보→국토이용계획변경 승인 견해표명 X / (위반 O) 폐기물적정통보→폐기물불허가. (부정) 착오·사정변경 시 적용 X.
- **부관 위법성**: 부관 가능성 검토 — 재량행위 O·기속행위는 근거 要(단 요건충족적 부관 可). 요건충족적 부관 = 부담 X·조건 O(해석상).
- **법령보충적 행정규칙**: 제재처분 기준 아니면 일단 법령보충적 행정규칙으로 보는 게 좋음.
- **부분인허가의제(행기법 제25)**: [인정 여부] 判 일괄협의 불요 시 인정. [관련인허가 실재] 관련 인허가 요건으로 주된 인허가 거부 시 관련 인허가 실재 X → **주된 인허가 거부처분 대상 항고소송** / 부분 인허가의제 허용 시 의제된 인허가 실재 O.
- **행정절차법 적용**: (긍정) 직권면직·정규임용취소·한국방송공사장 해임 / (부정) 직위해제. 직위해제 사전통지 안 함 → **행정절차법 적용 X가 논점**. 변호사 선임(제12①②·11④) → 모든 행위 可(제11④ — 끝맺는 행위는 동의).
- **병합 CASE**
  - [취소소송 + 부이반] 부이반=민사소송, 선결문제(구성요건적 효력 — 취소 전 유효, 단독청구 시 기각): 당연무효는 제11조로 판단 / 취소사유는 취소 전 부인 불가. 병합청구(발·공·선) — 취소판결 확정 전에도 취소판결하며 부이반 인용 可.
  - [무효확인 + 부이반] 무효확인 보충성 — 判 민사소송과 기능 다름·기속력 실효성 → 보충성 不要. 부이반 선결문제 효력유무 판단 可.
- **당사자소송**: 권리관계 구체적 형성 → 당사자소송 지급청구(국가 피고, 법률상 대표자 법무부장관) / 처분으로 형성 → 거부처분취소소송(행정청 피고). 환급결정·거부결정(처분성 X) / 환급금청구(당사자소송) / 과오납금 부이반(민사소송).
- **의회에 대한 불복**: 지자체장 재의결 불복 → 제120③ / 상위기관 재의결 불복 → 제192④.
- **자치사무/기관위임사무**: (조치) 자치사무=시정명령·취소·정지/감사(190) / 기관위임=지도감독(185)·이행명령·대집행. (단체장 불복) 자치사무 취소·정지는 제소 可(시정명령 X) / 이행명령은 제소+집행정지 可.
- **공유수면 매립지 귀속(지자법 제5)**: 매립지·지적공부 누락 토지는 행정안전부장관 결정.
- **부작위 국가배상**: 요건(공·직·위·고·손·인). 부작위 — 작위의무·사익보호성 要, 사익보호성 없으면 인과관계 X(判). 작위의무·사익보호성(법령상 작위의무 X면 검토 X).
- **법관 재판에 대한 국배**: 법적 안정성(부정)/직무행위·기판력 위반 X(긍정), 判 위법·부당 목적·법령 현저 위반 특사 없으면 책임 X(불복절차 미거치면 X).
- **기판력**: 취소소송 소송물=처분 위법성 / 무효확인 소송물=처분 효력.
  - [취소 인용 확정 → 국배] 기판력 발생(주·객·시 — 위법·취소 점) → 작용 여부(취·기·고·단·개념 달리 → 전부기판력부정설).
  - [취소 기각 확정 → 국배] 선결문제(위·예·추·열) → 기판력(적법·유효) 작용.
  - [취소·무효확인 관계] 취소 기각 후 무효확인 — 적법·유효 기판력 → 무효확인 기각 / 무효확인 기각 후 취소 — 무효 X 기판력 → 취소소송 실체판결.
- **대집행**: (부정) 금지(중지)명령 위반 = 부작위의무.
