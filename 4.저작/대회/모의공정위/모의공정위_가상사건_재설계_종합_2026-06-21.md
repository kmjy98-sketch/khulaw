# 후보 1 — 「데이터 고속도로의 통행료」
## ISP의 종단망 독점을 이용한 중소 CP 압박 사건

### 1. 한 줄 콘셉트
초고속인터넷 가입자망(종단망)을 보유한 ISP가, 협상력이 약한 **국내 중소 콘텐츠제공사업자(CP)**에 대해 차별적 고율의 망 이용대가를 강요하고 연결품질을 저하시키면서, 자사 계열 OTT는 우대한 사건. → 시장지배적지위 남용 + 거래상지위 남용 복합.

### 2. 가상 당사자·사실관계 골격
- **피심인**: (가칭)「한빛텔레콤」 — 국내 초고속인터넷 가입자망 점유 상위, 자사 가입자에 도달하는 유일 경로(종단 독점). 계열사로 OTT「한빛플레이」 보유.
- **피해자(신고인)**: (가칭)「온스트림」 — 국내 중소 스트리밍 CP. 글로벌 빅테크와 달리 협상력이 약함.
- **행위사실**:
  1. 온스트림에 글로벌 빅테크 대비 현저히 높은 망 이용대가 요구(차별)
  2. 피어링·연결용량 증설 거부·지연 → 트래픽 혼잡·화질 저하 유발(거래거절·사업활동방해)
  3. 자사 계열 OTT「한빛플레이」에는 무상·우대 정산(자사우대)
  4. 대가 미수용 시 연결 해지 압박(불이익 강제)

### 3. 관련시장 획정
- **종단 접속시장**: "한빛텔레콤 가입자에게 콘텐츠를 전달하기 위한 망 접속·연결 시장"으로 협소 획정 → 각 ISP는 자사 가입자 도달의 유일 경로이므로 **종단 독점(terminating monopoly)** 인정 → 제6조 시지 추정.
- 광의의 인터넷접속 시장으로 보면 ISP 3사 과점이나, 종단 도달 관점에서는 사업자별 100% 독점이라는 점이 핵심 논거.

### 4. 위법성 구성 (심사관 측)
| 조문 | 행위 | 구성 |
| :-- | :-- | :-- |
| 제5조1항3호 | 연결 거부·지연 | 부당한 거래거절(필수설비 유사) |
| 제5조1항3호·제45조 | 빅테크 대비 차별 대가 | 차별적 취급 |
| 제5조1항3호 | 자사 OTT 우대 | 부당한 자사우대형 남용 |
| 제45조1항6호 | 우월적 지위로 과다대가 강요 | 거래상지위 남용(불이익제공) |

### 5. 피심인 항변 (대칭 공방)
1. **제116조 면책**: 상호접속고시(발신자 종량·상호정산, 2016.1.1~)에 따른 정당한 정산이다.
2. **시지 부정**: 광의 인터넷접속 시장에서는 과점일 뿐 단독 시지 아님.
3. **거래상지위 부정**: CP가 콘텐츠 협상력을 가져 우월적 지위 아님.
4. **합리적 이유**: 트래픽 유발자 부담 원칙·망 증설비용 회수.

### 6. 심판부 판단 방향
- 시장을 **종단 접속시장**으로 획정해 시지 인정.
- 제116조는 대법원 엄격해석(법령 범위 내 "**필요·최소한**")상, 자사 OTT 우대·차별대가는 고시가 허용한 범위를 벗어나 면책 부정.
- 빅테크가 아닌 **중소 CP를 피해자로 설정**했으므로 거래상지위 남용 인정 용이.

### 7. 실제사건·비교법 근거 (확정)
- 넷플릭스 vs SKB: 서울중앙지법 2021.6.25. 선고 2020가합533643(넷플릭스 패소) → 2023.9.18 소취하·파트너십(합의내용 비공개). **민사·합의종결이라 공정위 처분선례 아님** → "공정위가 개입했다면" 구도로 차별화.
- 상호접속고시: 2016.1.1 동일계위 상호정산·트래픽 종량제(과기정통부 고시 제2022-25호).
- 망무임승차방지법: 22대 국회 재발의(2024.10.21 이정헌 의원 등).
- 미국 FCC 망중립성: 2024.5 재도입 → 2025.1.2 제6순회 무효화(Loper Bright). EU fair share는 Digital Networks Act(2026.1.21 제안)에서 제외·분쟁중재로 대체.

### 8. 차별점·약점
- **차별점**: 통신 인프라(ISP)를 경쟁법으로 포섭하는 미개척 영역 + 전기통신사업법(과기정통부) vs 공정거래법(공정위) **관할 경합** + 제116조 면책이라는 절차·실체 동시 고난도.
- **약점**: 실제 공정위 처분례 부재 → 가상 처분 구도의 설득력에 서면 완성도가 좌우됨.
- **평가**: 검증 완료·신선도 최상 → **최우선 출품**.

# 후보 4 (재설계) — 「클라우드의 모래지옥」
## 클라우드 1위 사업자의 라이선스 차별·약정할인을 통한 멀티클라우드 봉쇄

> **재설계 사유**: 2024년 Google(1월)·AWS(3.5)·Azure(3월)가 **전환용 egress 수수료를 모두 폐지**해, 'egress 록인' 단독 프레임은 현실성이 사라졌다. 따라서 사건의 무게중심을 ① **소프트웨어 라이선스 차별**, ② **약정할인(committed spend discount)에 의한 사실상 배타조건부거래**, ③ **기술적 전환장벽**으로 이동한다. egress는 "상시 멀티클라우드 트래픽은 여전히 과금"이라는 보조논거로만 잔존.

### 1. 한 줄 콘셉트
국내 클라우드 인프라(IaaS/PaaS) 1위 사업자가, 자사 핵심 소프트웨어를 경쟁 클라우드에서 차별 과금하고, 대규모 약정할인과 기술적 비호환으로 고객의 멀티클라우드·전환을 봉쇄한 사건.

### 2. 가상 당사자·사실관계 골격
- **피심인**: (가칭)「님버스클라우드」 — 국내 IaaS/PaaS 점유 1위(시지). 널리 쓰이는 자사 DB엔진·운영체제 라이선스 보유.
- **피해자(신고인)**: (가칭) 국내 중소 CSP「클라우드원」 + 멀티클라우드 전환을 시도한 기업고객.
- **행위사실**:
  1. **라이선스 차별**: 자사 클라우드에서는 자사 DB엔진을 저가/번들 제공하면서, 경쟁 클라우드에 올리면 동일 라이선스를 고율 과금(BYOL 제한) → 경쟁 클라우드의 가격경쟁력 박탈.
  2. **약정할인 봉쇄**: 대규모 약정할인(일정 지출 약정 시 대폭 할인)을 미끼로 사용량 전부를 자사에 집중하도록 유도 → 멀티호밍·이탈 시 할인 박탈로 사실상 배타조건.
  3. **기술적 전환장벽**: 독자 API·데이터 포맷 비호환, 전환 지원·상호운용 거부 → 전환비용 인위적 상승.
  4. **(보조) 상시 egress 과금**: 전환용 전부 반출은 무상이나, 일상적 멀티클라우드 연동 트래픽은 계속 과금 → 멀티클라우드 운영 자체를 억제.

### 3. 관련시장 획정
- **IaaS/PaaS 클라우드 인프라 시장**(SaaS와 구분). 국내 매출기준 1위 사업자의 시지 추정(제6조).
- CMA가 영국시장에서 "AWS·MS 각 30~40%, 전환장벽으로 경쟁 부작동" 판단한 분석틀을 한국시장에 차용.

### 4. 위법성 구성 (심사관 측)
| 조문 | 행위 | 구성 |
| :-- | :-- | :-- |
| 제5조1항3호 | 자사 SW 경쟁클라우드 차별과금 | 차별적 취급 / 사업활동방해 |
| 제5조1항5호 | 독자 API·전환지원 거부 | 경쟁사업자 배제·사업활동방해 |
| 제45조1항7호 | 약정할인으로 전량 집중 유도 | 배타조건부거래 |
| 제45조1항5호 | 자사 클라우드+자사 SW 결합 | 끼워팔기 |
| 제45조1항8호 | 비호환·전환방해 | 사업활동방해 |

### 5. 피심인 항변 (대칭 공방)
1. **효율성 항변**: 약정할인은 규모의 경제·소비자 후생 증대(가격 인하)다.
2. **지식재산권 행사**: 자사 SW 라이선스 정책은 정당한 IP권 행사다.
3. **보안·안정성**: 전환·상호운용 제한은 데이터 보안·서비스 안정성 사유다.
4. **egress 무상화**: 이미 전환 egress를 폐지해 봉쇄 의도 없다.

### 6. 심판부 판단 방향
- 개별 행위는 정당화 여지가 있으나, **라이선스 차별 + 약정할인 + 기술적 비호환의 누적적 봉쇄효과**로 전환비용을 인위적으로 높여 경쟁 CSP를 배제한 점에서 위법.
- 효율성·IP·보안 항변은 봉쇄효과를 정당화할 정도의 필요·최소성을 결여.
- egress 폐지는 면책이 아니라 "다른 봉쇄수단으로 대체"된 정황으로 해석.

### 7. 실제사건·비교법 근거 (확정)
- **영국 CMA 2025.7.31 최종결정**: UK IaaS/PaaS 2024 매출 £10.5bn, AWS·MS 각 30~40%(합산 70~90%), 3대 AEC(전환장벽·시장집중·라이선스), DMCCA상 AWS·MS **SMS 지정 권고**(회부 2026 연기).
- **Microsoft-CISPE 2024.7.10 합의**: €20m + Azure Local 개발 + 2년 감사유예(라이선스 차별 시정), AWS·Google·Alibaba 제외.
- **EU Data Act**(2024.1.11 발효, 2027.1.12 이익성 egress 전면금지) → 3사 egress 폐지의 직접 동인.
- 한국: 2024 퍼블릭클라우드 매출 6.23조, 매출기준 AWS 22%·삼성SDS 11.3%·MS 9.6%·네이버 5%·KT 2%. 공정위 '클라우드 실태조사 연구'(2019~2021).

### 8. 차별점·약점
- **차별점**: 보유텍스트의 CUDA(AI 가속 생태계)와 달리 **범용 클라우드 인프라의 라이선스·약정할인 봉쇄**. 해외 규제(CMA·CISPE·Data Act)를 한국 법리로 번역하는 구도.
- **약점**: 국내 집행례가 실태조사 단계에 그쳐 위법성 포섭 난도가 후보1보다 높음.
- **평가**: 재설계로 현실성 확보 → **안정적 고득점 후보(2순위)**.
