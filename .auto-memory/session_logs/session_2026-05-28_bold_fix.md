## 알고리즘

**보수적 Opening-Bold 수정 알고리즘**:
1. `bold_count` 홀짝으로 현재 `**`가 여는(opening) 마커인지 닫는(closing) 마커인지 판별
2. Opening 마커일 때, 바로 앞 문자가 한글이고 그 앞 문자가 비한글(공백/구두점)인 경우에만 해당 한글을 볼드 안으로 이동
3. 조건: `result[-1]`이 한글 AND `result[-2]`가 비한글 → 한 글자만 이동

**수동 처리가 필요한 패턴**:
- **2음절 접두어**: `성취**가능성`, `당해**소송`, `조항**과`, `기회**를` — 앞 글자가 한글이어서 보수적 알고리즘이 건너뜀
- **TYPE-2 (닫힘 마커 오위)**: `주**장에`, `경**우에도` — 닫힘 마커가 단어 중간에 배치됨
