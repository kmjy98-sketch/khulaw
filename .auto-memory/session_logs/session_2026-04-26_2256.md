# 세션 로그: 2026-04-26 22:56 (Cowork Dispatch 트러블슈팅)

## 작업 요청
> 코워크 디스패치가 읽기만 하고 작동이 안되는데 해결책이 뭐야

증상: Dispatch 세션이 채팅(요청)은 받지만 도구 실행(Edit/Write/Bash)은 전혀 일어나지 않음.

## 진단 — 4개 원인 후보

1. **Plan mode 강제 시작** — Dispatch 세션이 사용자의 `defaultMode` 설정을 무시하고 plan(읽기 전용)으로 시작 (Anthropic Issue [#39889](https://github.com/anthropics/claude-code/issues/39889))
2. **프로젝트 컨텍스트 미상속** — Dispatch 세션이 워크트리/프로젝트의 `settings.local.json`을 못 읽음 (Issue [#37713](https://github.com/anthropics/claude-code/issues/37713))
3. **defaultMode 미명시** — 글로벌·프로젝트 settings 모두 `defaultMode` 키 없음 → 안전 기본값(plan) 적용
4. **Edit/Write 권한 부재** — `permissions.allow`에 개별 Bash 명령은 86개 있으나 `Edit`/`Write` 광범위 허용 없음

## 적용한 변경

### 1) 글로벌 `C:\Users\111\.claude\settings.json`
```json
{
  "autoUpdatesChannel": "latest",
  "permissions": {
    "defaultMode": "acceptEdits"
  }
}
```

### 2) 프로젝트 `H:\내 드라이브\.claude\settings.local.json`
`permissions.allow` 끝에 추가:
```
"Edit", "Write",
"Bash(python:*)", "Bash(git status)", "Bash(git diff:*)", "Bash(git log:*)",
"Bash(claude mcp list)"
```

## 교훈

- **Self-Modification 차단은 채팅 인가로 풀리지 않음**: 사용자가 plan 승인 후 "진행해" 명시해도 settings 파일 수정은 차단됨. **사용자가 직접 편집해야 함** — 향후 권한 변경 요청 시 처음부터 직접 수정 안내가 효율적.
- **`acceptEdits` ≠ Auto mode**: `acceptEdits`는 파일 편집만 자동 허용, 위험 Bash는 여전히 묻기. "Auto mode"는 별개의 세션 단위 기능.
- **JSON 수동 편집 함정**: 사용자가 직접 권한 추가 시 마지막 항목 콤마 누락/중복 라인이 발생 → 검증 필수.
- **알려진 Anthropic 버그 2건**: #37713(권한 미상속), #39889(모드 무시) — 위 settings 변경으로도 해결 안 되면 Anthropic 수정 대기.
