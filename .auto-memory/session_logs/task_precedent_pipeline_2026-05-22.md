# 판례색인 종합 테이블 생성 및 문제-소스 역추적 파이프라인 구축 지시서

## 1. 목적
- 백업된 `_판례색인` 폴더 하위의 과목별(`민법`, `형법`, `헌법`) 판례 데이터를 수집하여 학습 편의성을 위한 **과목별 판례 종합 관리 표**를 생성합니다.
- 문제 은행(`precedent_problems_ox_*.json` 및 `precedent_problems_blank_*.json`)의 정답오류 발생 시 사용자가 이를 신속하게 추적 및 교정할 수 있도록, 문제 데이터에 **판례색인 마크다운 파일 링크** 및 **소스 교재 출처 정보**를 메타데이터로 매핑하는 파이프라인을 고도화합니다.

---

## 2. 세부 작업 요구사항

### 태스크 A: 과목별 판례 종합 관리 표 생성 스크립트 작성
- **스크립트 위치**: `.agent/scripts/_gen_precedent_summary_table.py` (신규 작성)
- **기능**:
  - `H:/내 드라이브/sync/_백업/교재원문_문서_백업_2026-05-22/_판례색인/` 내의 과목별 폴더(`민법`, `형법`, `헌법`)를 순회하며 개별 판례 마크다운 파일을 파싱합니다.
  - 마크다운 파일의 Frontmatter(사건번호, 선고일, 상태 등)와 본문 내 `## 참조조문`, `## 출현 교재 (상위 20건)` 영역을 파싱합니다.
  - 과목별로 종합 테이블을 생성하여 `H:/내 드라이브/.auto-memory/wiki/` 하위에 마크다운 표 파일로 저장합니다 (예: `판례종합표_민사.md`, `판례종합표_형사.md`, `판례종합표_헌법.md`).
  - **표의 칼럼 구조**:
    `[순위 | 사건번호 (위키링크) | 선고일 | 총 빈도 | 관련 조문 | 상태 (Stub/Filled) | 주요 출현 교재]`

### 태스크 B: 문제 생성 스크립트 개정 (역추적 메타데이터 매핑)
- **개정 대상 파일**: 
  - [_gen_precedent_ox.py](file:///H:/.agent/scripts/_gen_precedent_ox.py)
  - [_gen_precedent_blank.py](file:///H:/.agent/scripts/_gen_precedent_blank.py)
- **기능 추가**:
  - 기존에는 단순히 파일의 상대 경로(`'소스'`)만 수집하였으나, 문제 생성 시 해당 판례 마크다운의 `## 출현 교재 (상위 20건)` 아래에 기술된 교재 목록을 읽어옵니다.
  - 각 문제 데이터(JSON) 내에 다음과 같은 형식의 메타데이터를 추가 바인딩합니다:
    ```json
    "references": {
      "case_stub_link": "[[사건번호]]",
      "sources": [
        {
          "book_name": "교재 파일명",
          "context_path": "맥락 경로"
        }
      ]
    }
    ```
  - 추가로, 각 `맥락 경로` 파일의 내용을 조회하여 해당 판례번호 주변(예: 앞뒤 200자 또는 동일 문단)에 `[p.123]` 또는 `p. 123` 형식의 페이지 마커가 존재하는지 정규식으로 매칭하여 `"page"` 정보를 파싱 시도하고, 존재할 경우 `"page": "p.123"` 형태로 함께 바인딩하도록 로직을 고도화합니다.

### 태스크 C: 교정 프로세스 문서화
- 사용자가 오답/오류 문제를 만났을 때, 어떻게 원천 데이터(판례 스텁 파일 또는 교재 파일)를 찾아가서 고치고 재빌드하는지 안내하는 절차서를 `H:/내 드라이브/.auto-memory/session_logs/how_to_correct_problems.md`에 작성합니다.
