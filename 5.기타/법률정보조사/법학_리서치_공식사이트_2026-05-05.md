| `site:law.go.kr` | 특정 사이트 한정 검색 | `반사회질서 site:law.go.kr` |
| `site:glaw.scourt.go.kr` | 종합법률정보 한정 | `2012다94643 site:glaw.scourt.go.kr` |
| `filetype:pdf` | PDF만 검색 | `LEET 추리논증 filetype:pdf site:leet.or.kr` |
| `"…"` | 정확한 구절 검색 | `"표현의 자유의 본질적 내용"` |
| `intitle:` | 제목에 포함 | `intitle:법령해석 토지` |
| `-키워드` | 제외 | `소유권 -양도담보` |

### 2.2 판례 빠른 검색 워크플로

1. **사건번호를 안다** → 종합법률정보 통합검색에 `2012다94643` 직접 입력 → 본문 + 참조법령 + 후속 인용 판례 확인.
2. **사건번호를 모른다** → 키워드 + 연도로 종합법률정보 디렉토리검색 → 후속으로 법률신문·리걸타임즈에서 평석 확인.
3. **헌재결정** → 사건유형(`헌마`/`헌가`/`헌바`/`헌라`)을 키워드와 같이 isearch.ccourt.go.kr에 입력.
4. **법령해석과 판례 충돌 의심** → 같은 키워드로 종합법률정보(판례) ↔ 법제처 법령해석례 양쪽 검색.
