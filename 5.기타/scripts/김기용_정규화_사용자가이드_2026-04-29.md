## 5. 자동 적용 패턴 (형법 교안 특화)

### 5.1 단독 라인 삭제

| 패턴 | 정규식 (Python) | 위험도 |
|---|---|---|
| 페이지 헤더 (편-장-페이지) | `^\s*제\s*\d+\s*편\.\s*\S+\s+제\s*\d+\s*장\.\s*\S+\s+\d+\s*$` | 낮음 (안전) |
| 페이지 헤더 (편-페이지) | `^\s*제\s*\d+\s*편\.\s*\S+\s+\d+\s*$` | 낮음 |
| 페이지 헤더 (장-페이지) | `^\s*제\s*\d+\s*장\.\s*.+?\s+\d+\s*$` | 중간 |
| 페이지 번호 dash | `^\s*-\s*\d{1,4}\s*-\s*$` | 낮음 |

### 5.2 인라인 치환 (사건번호 + 각주 마커 — 번호는 보존)

김기용 OCR은 두 가지 형식 혼재. 둘 다 처리.

**형식 (a) OUTSIDE — 번호 마커 앞 (송영곤 호환)**: 예 `98도356[^5]` → `98도356`
**형식 (b) INSIDE — 번호 마커 안 (김기용 주된 패턴)**: 예 `98도[^356]` → `98도356`

| 패턴 | 정규식 OUTSIDE | 정규식 INSIDE | 형법 빈도 |
|---|---|---|---|
| 형법 사건번호 (도) | `(\d+도\d+)\[\^\d+\]` → `\1` | `(\d+도)\[\^(\d+)\]` → `\1\2` | **매우 높음** (핵심) |
| 헌재 사건번호 | `(\d+헌[가-힣]+\d+)\[\^\d+\]` → `\1` | `(\d+헌[가-힣]+)\[\^(\d+)\]` → `\1\2` | 높음 |
| 민사 사건번호 (다) | `(\d+다\d+)\[\^\d+\]` → `\1` | `(\d+다)\[\^(\d+)\]` → `\1\2` | 낮음 (인용 시) |
| 군법/특수 (모/오) | `(\d+[모오]\d+)\[\^\d+\]` → `\1` | `(\d+[모오])\[\^(\d+)\]` → `\1\2` | 매우 낮음 |
| 결정 (그/마) | `(\d+[그마]\d+)\[\^\d+\]` → `\1` | `(\d+[그마])\[\^(\d+)\]` → `\1\2` | 낮음 |

적용 순서: OUTSIDE 전부 → INSIDE 전부 (OUTSIDE가 더 구체적이므로 우선).

### 5.3 보존 (보수적)

자동 처리 **안 함** — 위험 패턴 (CLAUDE.md #34 anchor 보호):

- 한자 깨짐 (`■`, `傑`, `祭` 등): anchor 위반 위험
- 의미불명 기호 (`■`, `丰`, `仲`, `©`, `J EO`): 단독 본문 위치라면 의미 추정 위험
- 띄어쓰기 깨짐: 의미 변경 가능 (예: `결과적가 중범` → `결과적 가중범`)
- callout 내부 라인: 조문·판례 본문 보호 (`[!example]`, `[!조문]`, `[!판례]` 등)
- 단독 숫자 라인: 본문 안 숫자일 수 있어 보존 (page_num_bare_kept 카운트만)
- 본문 결합 페이지 헤더: `제2편. 범죄론 제3장. 위법성론 159 0 형법 **제20조**...` — 단독 라인 아니라 보존

→ 이들은 별도 task에서 LLM 검증 + korean-law-mcp 교차 검증으로 처리.

## 8. 김기용 특화 주의사항

### 8.1 callout 보호 패턴 차이

송영곤은 `[!조문]` `[!판례]` 위주, 김기용은 **`[!example]`** 빈도 매우 높음 (조문 callout 용도). 정규식에 추가됨:

```python
re.match(r"^>\s*\[!(조문|판례|정의|예시|주의|참고|example|note|warning|info|tip)\]", stripped)
```

### 8.2 사건번호 우선순위

형법 본문에서 **`\d+도\d+`** 형식이 압도적. 헌재 인용은 `\d+헌가\d+`, `\d+헌마\d+`, `\d+헌바\d+` 등 다양 → 정규식이 한자 모음 `[가-힣]+`로 포괄.

### 8.3 본문 결합 페이지 헤더 (정규식 한계)

샘플에서 발견된 위험 패턴:
```
제1편. 형법의 일반이론 제2장. [[죄형법정주의]] 21 | 제2절. 성문법 헌법 **제75조** 대통령은 ...
```
→ 단독 라인이 아니므로 **자동 처리 안 함**. Claude가 별도 task에서 처리.

### 8.4 _교재목차.md 제외

`collect_files()`에서 `_`로 시작하는 메타 파일은 자동 제외. 백업에는 포함(보수적), 정규화 대상에서는 제외.

### 8.5 OCR 띄어쓰기 깨짐

샘플에서 발견:
- `결과적가 중범` → `결과적 가중범` (front matter tag와 본문 모두)
- `방조전이미` → `방조 전 이미`
- `검토하여야하되` → `검토하여야 하되`

→ 의미 추정 위험, **자동 처리 금지**. Claude가 본문 검수 시 별도 처리.
