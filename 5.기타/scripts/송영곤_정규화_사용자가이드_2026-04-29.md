## 5. 자동 적용 패턴 (B형 템플릿 §6 기반)

### 5.1 단독 라인 삭제

| 패턴 | 정규식 (Python) | 위험도 |
|---|---|---|
| 페이지 헤더 (관) | `^\s*제\s*\d+\s*관\s+...\s+\d+\s*$` | 낮음 (안전) |
| 페이지 헤더 (장) | `^\s*제\s*\d+\s*장\s+.+?\s+\d+\s*$` | 낮음 |
| 페이지 헤더 (부) | `^\s*\[?\s*제\s*[OoO0\d]+\s*부\s+...$` | 중간 (대괄호 깨짐 검사) |
| 페이지 번호 dash | `^\s*-\s*\d{1,4}\s*-\s*$` | 낮음 |

### 5.2 인라인 치환

| 패턴 | 정규식 | 치환 |
|---|---|---|
| 사건번호 끝 각주 (다) | `(\d+다\d+)\[\^\d+\]` | `\1` |
| 사건번호 끝 각주 (민) | `(\d+민[가-힣]+\d*)\[\^\d+\]` | `\1` |
| 사건번호 끝 각주 (그/마) | `(\d+[그마]\d+)\[\^\d+\]` | `\1` |
| 사건번호 끝 각주 (헌) | `(\d+헌[가-힣]+\d+)\[\^\d+\]` | `\1` |

### 5.3 보존 (보수적)

자동 처리 **안 함** — 위험 패턴:

- 한자 깨짐 (`傑里` → `조리`, `祭主` → `제주`): anchor — CLAUDE.md #34 위반 위험
- 의미불명 기호 (`■`, `丰`, `仲판`, `©`): 단독 본문 위치라면 의미 추정 위험
- 띄어쓰기 깨짐: 의미 변경 가능
- callout 내부 라인: 조문·판례 본문 보호 (in_callout_skipped 카운트만)
- 단독 숫자 라인 (페이지 번호 추정): 본문 안 숫자일 수 있어 보존 (page_num_bare_kept 카운트만)

→ 이들은 별도 task에서 LLM 검증 + korean-law-mcp 교차 검증으로 처리.
