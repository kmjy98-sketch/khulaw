## 2. 처리 패턴 4종

| 코드 | 패턴 | 예 |
|------|------|-----|
| A | 단일줄 front matter | `--- tags: [...]\n과목: 형법 주제: ... ---` → 정상 YAML 블록 |
| B | collapsed 표 | `\| h \| h \| \|---\|---\| \| 001 \| ... \|` → 행 단위 분리 |
| C | 볼드 마커 분할 | `- **\n- ① 긍정설**:` → `- **① 긍정설**:` |
| D | 헤더+본문 같은 줄 | `#### 3. 판례의 태도 판례는 …` → 헤더/본문 분리 |

## 3. 실행 순서

```powershell
# 1단계 — 사전 백업 (필수)
cd "H:\내 드라이브\5.기타\scripts"
.\backup_홍형철_2026-04-29.ps1            # 실제 백업
.\backup_홍형철_2026-04-29.ps1 -DryRun    # 진단만

# 2단계 — dry-run (변경 미적용, 보고서만 생성)
python normalize_홍형철_미세조정.py --dry-run

# 3단계 — apply (실제 쓰기)
python normalize_홍형철_미세조정.py --apply

# 단일 파일만 검증
python normalize_홍형철_미세조정.py --dry-run --file 홍형철_쟁점정리_형법_25_p001-030.md
```

보고서 위치:
- dry-run: `sync/_meta/홍형철_정규화_dry_run_2026-04-29.md`
- apply  : `sync/_meta/홍형철_정규화_apply_2026-04-29.md`
- 백업 매니페스트: `sync/_meta/홍형철_백업_manifest_2026-04-29.json`

## 4. 보호 대상 (스크립트가 손대지 않음)

- callout(`> [!판례]`, `> [!tip]`) **내부** 라인의 표/헤더 패턴 — 의도된 형식으로 간주
- anchor: 조문번호(§XXX), 사건번호([[YYda…]]), 한자
- 정상 다중줄 front matter (이미 분해된 파일)
