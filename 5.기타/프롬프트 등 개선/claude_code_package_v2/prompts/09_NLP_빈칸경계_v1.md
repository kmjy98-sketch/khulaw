# 09. NLP 빈칸 경계룰 v1 (2026-06-12) — B1

> v1(자유추출)·v2(정규식 normalize)의 실패: 주술/성분 넘는 빈칸, "없다/않는다" 결론 누락.
> 이 룰은 **LLM이 직접 형태소·문장성분 분석**을 수행해 빈칸 경계를 정한다. Kiwi/정규식 불필요(정규식은 안전망으로만).

## 1. 빈칸 단위 (둘만 허용)
- **(A) 명사구**: (관형어)* + 체언. 끝은 반드시 **체언(명사)**.
- **(B) 결론·효과 술어**: 긍정/부정 판단 — 성립한다/성립하지 않는다, 무효/유효, 위헌/합헌, 인정/부정, 대항하지 못한다, 취소할 수 있다 등.

## 2. 경계 규칙
1. 어절 시작에서 시작. 단어 중간 절단 금지.
2. **조사·어미는 빈칸 밖**: "죄형법정주의에 어긋나므로" → 빈칸 `죄형법정주의`(또는 `죄형법정주의 원칙`).
3. **연결용 서술어는 빈칸 밖**: ~므로/~하면서/~인 경우/~한바/~여 등 다음 절로 잇는 술어.
4. **결론용 서술어는 빈칸 대상**(B): 그 자체가 법적 결론이면 빈칸.
5. **주어/목적어/부사어 + 서술어를 한 빈칸에 섞지 말 것**(성분 걸침 금지).
6. 빈칸 가린 뒤에도 문장 골격(누가/무엇이 ~하면 ~이다)이 남아야 함.

## 3. "없다/않는다"의 두 얼굴 (의미로 판별 — POS로 불가)
- **연결**: "…에 반하지 않는다" 중 명사가 핵심이면 명사만 빈칸, 술어는 노출.
- **결론**: 긍정/부정 자체가 쟁점이면 술어를 빈칸. (예: "대항하지 {{c1::못한다}}", "권리능력이 {{c1::없다}}")
- 개념+결론 둘 다 핵심이면 **다층**: `{{c1::선의취득}}이 {{c2::인정되지 않는다}}`

## 4. 사례형/포섭 추가 규칙
- **사안 고유명사(갑·을·병·X토지·날짜)는 빈칸 금지** — 법리어·결론어만.
- **빈칸 주변 3어절 내 정답 단서 금지**(유추 차단). 단서가 있으면 그 부분도 함께 빈칸.
- 빈칸 2개는 **상호 독립**(한쪽 알아도 다른쪽 유추 불가).
- 배점 큰 포섭은 단어가 아니라 **논거 구절 통째** 빈칸(논거 2~3개 현출 강제).
- 원문 `<u>밑줄</u>`·`**볼드**` 구간이 빈칸 타겟 1순위(A2).

## 5. 안전망 (기계, 빌드 단계)
`anki_keyword_merge.py`의 normalize_kw(어절 스냅·관형연결 제거·격조사 트리밍)는 **LLM 산출 후 잔여 오류만** 보정. '의/가/이/로/에'는 어말 혼동으로 트리밍 제외.

## 6. 자가검증 (카드 생성 에이전트가 출력 전 점검)
각 빈칸에 대해: ①체언 또는 결론술어로 끝나는가 ②조사·연결어미가 빈칸에 포함됐는가(→제거) ③성분 걸침인가(→분리/축소) ④주변 단서로 유추되는가(→확장 또는 위치변경) ⑤사안 고유명사인가(→제외).
