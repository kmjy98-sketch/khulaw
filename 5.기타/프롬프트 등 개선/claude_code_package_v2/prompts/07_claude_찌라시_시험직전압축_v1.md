# 07 — 찌라시(시험 직전 A4 압축) 생성 프롬프트 v1
# 생성: 2026-06-11 — 구 D-4(찌라시 스킬)·D-7(기말 작업프롬프트) 대체. 시험마다 재사용하는 범용 프롬프트.
# 실행: Claude (Code/Project). 트리거: "찌라시", "시험장 압축" (CLAUDE.md #17)

## 입력 (사용자 지정)
- 과목 + 시험명/날짜 + 범위 (주제 목록 또는 쟁점 아티클 파일 목록)
- 모드(택1): **요건골격**(기본) / 키워드 / 판례결론
- 분량: A4 1장(~60줄) 또는 2장(~120줄)

## 소스 우선순위 (외부 지식 금지 — #1·#2)
1. `sync/wiki/쟁점/{주제}.md` — 쟁점 아티클 (요건·일반론·예외 이미 압축됨, 1차 소스)
2. `outputs/anki/v4/*.tsv` — 해당 주제 난이도::A 카드 (`grep "주제::{X}"`)
3. `sync/{과목}/` 정리노트
- 모든 줄은 위 소스 문장의 압축이어야 한다. 새 단정 금지. 소스 불확실 시 그 줄을 뺀다(#2).

## 출력 형식 — `sync/_찌라시/{과목}_{시험명}_{날짜}.md`
- **인쇄 전제**: 백링크 `[[...]]`·표·frontmatter·cloze 마커 금지, 한자·외국어 금지(#37)
- 쟁점당 최대 3줄:
  - ① 요건 골격: `쟁점명 (N가지): ①키워드 ②키워드 ③키워드`
  - ② 핵심 판례 결론 1줄 (사건번호만, 선고일 생략)
  - ③ 함정·예외 1줄 (객관식 X지문 포인트 — 카드의 함정 키워드)
- 말미: **"시험 직전 10초 체크"** — 가장 헷갈리는 대비쌍 10개 이내 (예: 원칙↔예외, 인정례↔부정례)
- 출처는 쟁점 끝 괄호 1회 (책약어-pN 또는 아티클명). 줄마다 반복 금지.

## 생성 절차
1. 범위의 주제별로 쟁점 아티클 존재 확인 → 있으면 §2(요건)·§3~4(판례·예외)에서 압축
2. 아티클 없는 주제만 v4 카드 grep (난이도::A 우선)
3. 분량 한도 맞춰 빈출 낮은 쟁점부터 삭제 (잘린 주제는 말미에 "미수록: ..." 1줄)
4. 자체 점검: 분량 한도 / 소스 없는 단정 0건 / 사건번호는 `anchor_verify_results.jsonl` 기준 verified 우선(미검증은 번호 생략 가능)
