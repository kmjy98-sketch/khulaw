## 아티클 스키마
```markdown
---
type: 쟁점아티클 / 과목: {과목} / 주제: {쟁점명} / 생성: {날짜} / anchor검증: 미검증|완료
---
# {쟁점명}
## 1. 조문        — 카드에 원문 있으면 인용, 조문번호만 있으면 "(원문 미포함 — law-mcp 보강 대상)" (#5)
## 2. 요건        — 문장형 연결 서술. 인접 요건 클러스터(예: 사해행위요건·사해의사)는 링크로 미루지 말고 본문에 포함. 요약 문장 끝에 원문 각주 [^N]
## 3. 일반론 설시 판례 — 요건·판단기준 자체를 설시한 판시 선별 5~8개
## 4. 예외·주요 케이스 — 일반론의 예외 설시 판례 + 변시·사례집 주요 사안 3~6개
## 5. 관련 태그 클러스터 — 하위/인접 주제:: 태그 + 카드 수 + Anki 필터 쿼리
```

## 생성 규칙
1. 소스 = `outputs/02_cards_v37/*.md`의 해당 주제 카드만. 외부 지식·추측 금지(#1·#2). 모든 단정에 출처 표기
2. 주제 매칭 = 정확 일치 + 클러스터 접두 매칭(예: `사해행위*`). 인벤토리 `.agent/state/wiki_topic_inventory.json` 참조
3. 분량 40~70줄 — 교재 재현 금지(#40, sync/_교재원문과 중복 방지)
4. 일반론/예외 분류 기준: 요건·판단기준 자체를 설시 = 일반론 / "예외적으로"·단서·반대결론 = 예외 / 불명확 = 주요 케이스로

7. 저장: `sync/wiki/쟁점/{쟁점명}.md` (#40 — sync/wiki/ 하위). `_index.md`에는 과목별 묶음 1줄만 추가(25KB 한도 #38)
