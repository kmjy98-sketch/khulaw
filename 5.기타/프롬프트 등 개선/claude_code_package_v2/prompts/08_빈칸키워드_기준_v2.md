# 08. 빈칸·형광 키워드 기준 v2 (2026-06-11)

> v1(자유 추출)의 실패: "시행령이 형사처벌에 관한"처럼 주어+관형구를 가로지르거나 "범위를"처럼 조사 붙은 파편이 빈칸이 됨.
> v2는 **사례형 답안 목차 구성요소**를 키워드 단위로 삼고, **한국어 어절·조사 경계**를 강제한다.
> 적용: anki 키워드 추출 에이전트 프롬프트 + `anki_keyword_merge.py`의 기계 검증기(이중 게이트).

## 1. 키워드 단위 — 답안 목차 구성요소만 허용

사례형 답안 목차(I./㉠/① 항목)는 `[쟁점·청구권명] → [요건 포섭] → [근거] → [결론]`로 구성된다.
빈칸·형광 대상은 이 구성요소의 핵심구만:

| 분류 | 내용 | 예 |
|---|---|---|
| K1 개념어·쟁점명 | 목차 제목이 되는 법률개념 명사구 | 죄형법정주의, 표현대리, 위임입법의 한계, 대표권 제한 |
| K2 요건 표지 | 요건 항목 명사구 | 고의 또는 과실, 보증인적 지위, 정당한 신뢰, 현존이익 한도 |
| K3 기준·학설 | 판단 기준 문구, 학설명 | 상당인과관계, 침해의 최소성, 형식적 판단설 |
| K4 결론·효과 | 효과 술어 핵심 | 무효, 취소할 수 있다, 성립하지 않는다, 위헌, 대항하지 못한다 |

근거(조문·사건번호)는 빈칸 대상이 아니다(색상 강조로 처리).

## 2. 한국어 경계 규칙

1. 어절 시작에서 시작한다. 단어 중간에서 끊지 않는다.
2. 조사·어미는 빈칸 밖에 둔다: "죄형법정주의에 어긋나므로" → 키워드 `죄형법정주의` (빈칸 뒤 "에 어긋나므로"가 남아 어순 단서가 된다)
3. `~에 관한/대한/의한/따른/인한/위한` 등 관형 연결어로 끝내지 않는다.
4. 주어+목적어처럼 서로 다른 문장 성분을 하나의 키워드로 묶지 않는다.
5. 빈칸을 가린 뒤에도 문장 골격(누가/무엇이 ~하면 ~이다)이 남아야 한다.
6. 카드당 빈칸 2~4개(짧은 문장 1개). 형광(Basic)은 개수 제한 없음(파편 금지 동일).

## 3. 표준 예시

원문: "시행령이 형사처벌에 관한 사항을 규정하면서 법률의 명시적 위임 범위를 벗어나 처벌 대상을 확장하는 것은 죄형법정주의에 어긋나므로, 그러한 시행령은 위임입법의 한계를 벗어나 무효이다"

- 좋음: `법률의 명시적 위임 범위` `죄형법정주의` `위임입법의 한계` `무효`
- 나쁨: `시행령이 형사처벌에 관한`(성분 걸침·연결어 끊김) `사항을 규정하면서 법률의`(성분 걸침) `범위를`(조사 파편)

## 4. 기계 검증기 (merge 단계, 모델 무관 안전망)

`anki_keyword_merge.py`의 `normalize_kw()`:
- 시작이 어절 중간이면 다음 어절로 스냅, 끝이 내용어 중간이면 직전 어절로 스냅 (스냅 불가 시 폐기)
- 꼬리 기능 어절(관한·대한·따른·인한·위한·관하여 등, 단독 조사 어절) 반복 제거
- 마지막 어절 끝 격조사 1자(을를이가은는의) 트리밍 (3자 이상 어절, 2자 이상 잔존 시)
- 머리 지시·접속어(그/이/그러한/또한/즉 등) 제거
- 불용어(경우/때/것/수/등) 단독 폐기, 2자 미만 폐기

빌드(`anki_deck_build_v4.py`)의 `good_kw()`(≤4자+조사끝 파편 차단, cloze 추가 빈칸 상한 4)와 이중 게이트.
