## 1. 파이프라인 (4단계 · 2모델)

```
[원본 PDF / 기존 마크다운]
        │
   ① 01 OCR ......... 안티그래비티(Gemini)   ← 마크다운 없을 때만
        │             마킹·헤더·조문 추출 (Mode B 전체추출)
        ▼
   ② 02-wiki ........ 안티그래비티(Gemini)   ← 모든 소스 공통 진입점
        │             책유형 식별 + <!-- 속성 --> 라벨 + callout + [[backlink]]
        │             본문 보존율 ≥ 0.90 (요약 아님)
        ▼
   ┌──────────────┬───────────────┐
   ③a 02-card     ③b 06a / 06b    ... Claude Opus 4.8
   단권화 카드     사례집 카드
   rule/case_law  06a=정밀(검증無)
   /mcq 자동분기   06b=자동(검증필요 태그)
   └──────────────┴───────────────┘
        │
   ④ Anki Import ... 사용자 직접 (TSV → Import)
        │            FSRS + 태그 2축 필터
        ▼
   [변시 덱 / 과목별 sub-deck]
```

- **태그 2축**: `과목::` + `속성::`(정의/요건/효과/학설/판례/사례/객관식정지문/표/조문/검토) + `주제::` + `난이도::` + `출처::`
- **비용 논리**: Opus는 위키(구조화 텍스트)만 입력 → PDF 재OCR 불필요, 입력 토큰 최소화.

## 3. 소스별 실행 로드맵

### 3-A. 쟁점노트 (민법) — 02-wiki → 02-card

```
입력: sync/_백업/교재원문_문서_백업_2026-05-22/1.민사/33.송영곤_쟁노/교재_추출/*.md
  (재산법 p001-616 / 가족법 p001-058 / 소송집행 p001-341 / 목차)
  │
① 02-wiki (안티그래비티)
   - book_type_hint: 단권화
   - 30p 청크 단위로 위키화 → outputs/02_wiki/쟁점노트_재산법_chunk_NNN_wiki.md
   - 검증: 책유형 신뢰도 ≥90%, 속성라벨, callout, 보존율 ≥90%
  │
② 02-card (Claude Opus)
   - note_type: auto, difficulty: A
   - scope: (선택) 현재 학습범위 민법1 → 범위밖은 보류::범위밖
   - → outputs/02_cards/쟁점노트_재산법_TSV.txt
  │
③ Anki Import → 변시::01_민법
```
- 전권 일괄: 재산법 → 가족법 → 소송집행 전부 카드화(scope 비움 — 보류 태그 없음).

### 3-B. 반반형법 (형법) — 02-wiki → 02-card

```
입력: .agent/data/ocr_chunks_reviewed/형법/반반형법/*.md (p1~480 검수완료)
       + 반반형법_p0481-0495.md (미검수 — 위키화 전 1회 확인)
  │
① 02-wiki (안티그래비티) — book_type_hint: 단권화
   → outputs/02_wiki/반반형법_chunk_NNN_wiki.md
  │
② 02-card (Claude Opus) — note_type: auto
   → outputs/02_cards/반반형법_TSV.txt
  │
③ Anki Import → 변시::02_형법
```
- reviewed 청크가 chunk_000/001로 2분할되어 있으므로 위키화 시 30p 단위로 재결합 권장.
- 전권 일괄: 총론 → 각론 전부(scope 비움).

### 3-C. 핵심정리헌법 (헌법) — 01 OCR → 02-wiki → 02-card(mcq 비중↑)

```
입력: 3.공법/_분할/핵심정리300_01_헌법재판.pdf
       3.공법/_분할/핵심정리300_03_기본권_나머지_헌법총론.pdf
       (기본권 단독 분할 없음 → 03에 포함)
  │
① 01 OCR (안티그래비티) — Mode B, media_resolution high
   → outputs/01_ocr/핵심정리헌법_01·03_chunk_NNN.md
   (기존 .agent/temp_pdf_extract/*.txt는 품질 미검증 → 재OCR 권장)
  │
② 02-wiki (안티그래비티) — book_type_hint: 단권화 (또는 혼합 — OX·정지문 多 시)
   → outputs/02_wiki/핵심정리헌법_chunk_NNN_wiki.md
  │
③ 02-card (Claude Opus) — note_type: auto
   - 핵심정리류는 객관식 정지문(mcq)·판례(case_law) 비중 높음 → 자동 분기 확인
   → outputs/02_cards/핵심정리헌법_TSV.txt
  │
④ Anki Import → 변시::03_헌법
```
- 전권 일괄: 헌법재판(분할01) + 기본권·헌법총론(분할03) 전부(scope 비움).

### 3-D. 사례집 (송영곤 2종 확정) — 06b → 06a

```
사례집① 민사법사례연습2 (md 보유):
  06b: 교재_추출 md + 정식해설본 풀이 통째 입력

   → 주 1회 정식해설본과 대조 검증 → 06a 재정리

사례집② 사례연습 26 (PDF만 → md 추출 선행):
  ① 01 OCR(안티그래비티)로 과목별 분할 PDF → md
  ② 06b → 06a (①과 동일)
   → outputs/06_cases/사례연습26_06b_TSV.txt

06a (정밀·검증무, 변시 직전):
  입력: inputs/cases/문제N.md (IRAC 풀이 후 user_issue_list 작성)
   → outputs/06_cases/문제N_06a_TSV.txt
```
- 두 책 모두 정식해설본(풀이) 보유 → 06b 1차 카드화 가능.
- Anki Import → 변시::06_사례집 (검증 완료 후 활성화).

## 6. 검증 · 안전 게이트

### 02-wiki 산출 검증 (안티그래비티 출력 회수 시)
1. YAML frontmatter(source·book_type·attribute_distribution) 존재
2. `INTEGRITY: 보존율 ≥ 90%` anchor
3. 책유형 추정 신뢰도 ≥ 90%
4. 모든 소목차 `<!-- 속성: X -->` 라벨
5. callout 변환(`[논점정리]`→`> [!summary]`)·`{불명}` 변환
6. 한자 병기 없음(#37), 외국어 없음

### 02-card / 06 산출 검증 (Claude 출력)
1. TSV 컬럼 수 행별 일치
2. 태그 2축(`과목::`+`속성::`+`난이도::`) 필수
3. 구버전 `유형::`·`쟁점::` 잔존 경고
4. cloze 무결성(c1부터 연속, 외부 누설 없음)
5. abstention `{불명}` 비율 50% 초과 시 경고
6. 06b: `검증필요::AI추출` 자동 부착
7. 한국법학 가드(변형결정·상소심·학설 enum) 보존
