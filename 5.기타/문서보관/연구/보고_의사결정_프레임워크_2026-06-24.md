# 보고·의사결정 프레임워크

## A. 보고 양식 (모든 보고)
1. **답 먼저 (Answer-first / Pyramid Principle)**: 한 줄 결론을 맨 위에. 근거는 그 아래로 내려갈수록 상세.
2. **SCQA**: 상황(Situation) → 복잡성(Complication) → 핵심질문(Question) → 답(Answer).
3. **MECE**: 발견·옵션을 상호배타·전체포괄로 그룹핑(중복·누락 없이).
4. **근거 2단**: 각 단정에 근거(데이터·소스·file:line). #1·#3 준수.
5. **So-what**: 각 발견 끝에 함의 1줄("그래서 뭐").
6. 표·불릿 우선, 장문 지양(#8). 이모지 금지.

## B. 결정 보고 기준 (사용자 결정 필요 시)
1. **옵션 명시**: 2~4개, MECE(서로 겹치지 않게).
2. **가중 평가 매트릭스**:

| 기준(가중) | 옵션 A | 옵션 B | 옵션 C |
|---|---|---|---|
| 영향 Impact (×3) | | | |
| 노력 Effort (×2, 낮을수록 ↑) | | | |
| 리스크 Risk (×2, 낮을수록 ↑) | | | |
| 가역성 Reversibility (×2) | | | |
| 비용 토큰·시간 (×1) | | | |
| 전략 정합 (×2) | | | |
| **가중합** | | | |

   - 각 칸 1~5점. 권고는 최고 가중합 + 정성 판단.
3. **2×2** (해당 시): Impact×Effort 사분면 — Quick wins(고영향·저노력) 우선.
4. **권고 + 이유**: why this · why not others(반대 옵션 기각 사유).
5. **트레이드오프·전제·리스크** 명시. 불확실은 #2("확인 필요").
6. **결정권자·가역성**: 누가 결정 / 되돌리기 가능한가.

## C. 도구 (필요 시 호출)
Pyramid Principle · MECE · SCQA · Hypothesis-driven · 2×2 매트릭스 · Weighted scoring · 80/20(파레토) · Issue tree · Driver tree.

## D. 적용 분기
- **일반 진행보고** = A.
- **결정 필요** = A(답먼저) + B(매트릭스 또는 2×2) + 권고.
- **사소·자명·대화성** = 1줄(프레임워크 미적용, #8·#45-C 과잉방지).
