# 재연구 종합 — 카드 구조 · 진도보드

## A. 카드 구조 (연구1)
**핵심**: '전수 카드화' 실패의 본질은 카드 SCHEMA가 아니라 **원문항목 → 카드 1:N 추적·누락0 게이트의 부재 + 파싱 부재**. 현 02-card는 coverage 개념은 있으나 강제 메커니즘이 없어 LLM이 '중요해 보이는 것'만 뽑는다.

**누락 집중 위치(전수감사 1867건 근거)**:
1. 판례 나열 — 각 holding이 별개인데 일부만 카드화(사건번호 anchor 소실).
2. 표의 행/셀 — 통짜 누락(부분 카드화).
3. 조문 원문 카드 — 아예 빠짐.

**카드화 단위 유형**: 룰(정의·요건·효과) / 요건세트 / 표 / 판례holding / 학설 / 절차 / 조문.

**처리 원칙(제안)**:
- **파싱 선행**: OCR 마크다운(논점노트)을 항목 단위로 분해(판례 줄·표 행·요건 항·조문)해 **체크리스트**를 만들고, 그 체크리스트 대비 카드 1:N 매핑·누락0 대조.
- **표**: 행별(또는 의미셀별) 카드로 전개. "표 일부만" 금지 — 표는 전수 전개가 원칙.
- **요건**: 요건 세트는 묶되(1논점=요건 묶음 카드) + 개별 요건 인출 카드 병행. 요건끼리 묶어 비교가능하게.
- **판례**: 사건번호별 1카드(holding+사건번호 anchor 보존).
→ #51은 "전수 카드화" 선언이 아니라 **파싱→항목 enumerate→카드매핑→누락0 대조** 메커니즘으로 재설계해야 함. (상세 `연구_카드구조.md`)

## B. 진도보드 (연구3·4, 수치 검증완료)
**'쟁점 넘버 누락'의 진짜 원인 = 노트 결손 0(695 전부 존재) BUT frontmatter 스키마 불일치**:
- **type 불일치**: `쟁점`(428) vs `논점노트`/없음(263). 보드 필터 `type=="쟁점"`이 **행정234·민집4·민소25를 통째 탈락**.
- **논점 필드 비표준**: 과목마다 제각각 — 헌법 깨끗번호 2/106("[041]제목" 혼입), 형총 "형총 011"(접두사), 행정 "A192"/결손, 민집 필드없음, 민법 일부 "[72]제목(p)".
- **계층속성 0개**: 대분류/중분류 없음 → groupBy 과목 1단계만 → 목차 대분류(민총·채권·물권·가족 등) 붕괴 → 평면 132줄.
→ **보드 문제 = 데이터(frontmatter) 문제**. 뷰만 고쳐선 안 되고 **스키마 통일 + 계층속성**이 선행.

**근본 배경(반복된 회귀)**: frontmatter 스키마가 과목별 재구축 배치마다 따로 생성돼 통일 안 됨. 목차↔노트 단일 키 규약 미강제. → 자동화(보드·카드·드릴) 전반의 공통 장애.

## C. 공통 선행조건 — frontmatter 스키마 통일 (보드 방향 무관 필수)
모든 논점노트 통일 규약:
- `type: 쟁점` (전 과목 통일)
- `논점: <목차번호>` (목차 체계 그대로: 민법 01~122·G01~10, 형총 형총001~060, 행정 A001~A234 등 — 제목·페이지 혼입 제거, 목차와 1:1)
- `대분류: <목차 대분류>` + (선택)`중분류` — MOC에서 추출, 계층 그룹용
- 기존 진도속성(회독·약점·진도…) 유지.
근거=각 과목 `_{과목}_목차.md`(일관된 `[NN] [[제목]] (p)`). LLM 의미대조로 노트↔목차 매핑(#50-C, 정규식 금지).

## D. 진도보드 방향 (선택)
- **(나) Bases 목차계층 미러** [연구4 1차추천]: C 스키마통일 후 대분류 중첩 groupBy/대분류별 뷰. board_server 은퇴 가능, #50/#49 정합, 모바일 가능. 미확인 2건(중첩 groupBy·bool/숫자 필터 렌더) 외부검증 필요.
- **(가) 서버보드 유지 + 논점 상호연동** [사용자 lean]: 기존 3계층·약점·드릴 완성도 활용. 단 localhost/모바일불가, #49은퇴·#50논점통일에 역행. 연동=단원(202)↔논점(695) 1:N 매핑 필요.
- **(다) 혼합**: 서버=입력, Bases=열람/약점. 유지면적 2배.
