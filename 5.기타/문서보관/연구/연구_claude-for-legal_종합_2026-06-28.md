# claude-for-legal 비교 연구 종합

## Q1. 사례형을 전부 카드로 만들어야 하나 → **아니오(NO)**
5클러스터 만장일치. 외부 레포에는 **암기카드·SRS 개념으로 사례를 박제하는 설계가 아예 없다** — 사례=학습 이벤트(work product), 카드=사례에서 추출된 atom(룰·요건·판례·조문·표). 철학: **anti-ghostwriting + far-transfer**(사례를 카드로 박으면 인출·포섭 학습이 죽는다). 우리 현행(02-card 사례형 원문보존·비분해 + daily-drill 2트랙)과 이미 정합.

**정책 확정(2분기)**:
1. **룰/요건/판례/조문/표** = 전수 카드화 대상(누락0 게이트 유지 — 연구_카드구조 R1~R4, 1867 누락이 전부 이 유형).
2. **사례형(CASE)** = 전수 카드화 **비대상**. 대신 ①원문 비분해 보존 ②사례당 IRAC 종합카드 1장(far-transfer 닻, 모범답안 전문은 뒷면 비박제) ③**사례→약점 요건사실 추출 → 그 요건 카드 SRS 가중**(case-answer-review 연동).
- **교정 필요**: 현 cardaudit이 사례형 누락도 '누락'으로 집계 → 정책과 어긋남. 사례형은 누락0 게이트 면제(보고만, 자동수정 금지 #45-C).

## Q3. IRAC를 기본으로 + 한국 요건사실론 반영 — 통합 설계
외부 = IRAC/CRAC 단일골격(요건사실·증명책임·청구원인/항변 **전무** = 우리 고유 영역). 핵심 발견: **claim-chart 민사모드 = 요건사실론의 영미판**(요건×증거→셀상태+갭). 한국화:

- **격자**: 행=**요건사실**, 열=**원고(청구원인)/피고(항변)/재항변** = 우리 #32 2열 그대로. 셀=요건사실×사실증거.
- **셀 상태머신**: 자백·다툼없음(supported) / 다툼(disputed) / 입증부족(gap) / 증거조사필요. (현 우리는 포섭점수만)
- **입증책임 = 한국 고유축**(법률요건분류설: 권리근거/장애/소멸/저지): 카드 SCHEMA에 **`증명책임:: 원고/피고`** 필드 신설 → IRAC의 R을 "요건 + 그 증명책임자"로 확장. (침해부당이득 요건사실표가 이미 이 구조 — 연구_카드구조 line 54.)
- **갭리스트** = "입증책임 진 당사자가 입증 못한 요건사실" = claim-chart 갭검출의 직역.
- **IRAC↔요건사실 매핑**: R=요건사실 열거+증명책임 분배 / A=요건사실별 사실대입(포섭 4슬롯=한 셀의 내부구조) / I=쟁점(어느 요건사실이 다툼) / C=결론.
- **드릴**: socratic "룰진술→적용 분리"로 결론직행(E2: "기망이 있으니까") 교정 → "어느 사실이 기망 요건 충족?". weak 태깅을 **요건사실 슬롯 단위**로(권리남용→권리남용 주관요건). outline flowchart=요건충족 트리(청구원인→충족?→항변→성립?→재항변).
- **우리가 이미 앞선 것 유지**: #32 2열·포섭 4슬롯·E1~E3·페이딩 Lv1~4·결론캡·과목별 구조. 외부에서 가져올 건 격자·갭·상태머신 + 계획·예측·개인화·신뢰등급뿐.

## 카드 #51 재설계와의 연결
지난 결론(단계별 사고) + 연구_카드구조(atom 파싱·누락0) + 본 연구(요건사실 격자·증명책임)를 합치면 **#51의 완성형**:
- 카드 axis = (가)atom 유형(룰/요건/판례/표/조문) + (나)**추론단계 role**(쟁점/규범/포섭/결론) + (다)**요건사실 메타**(요건사실 명제·증명책임 귀속·대응 항변).
- 사례형은 카드화 비대상(Q1) → 격자+종합카드+약점연동.

## 권고 우선순위
1. **#51 카드 재설계 확정**(atom + 단계role + 요건사실/증명책임) → 그 위에 카드 작업(신규/부분개선).
2. **사례형 카드화 정책 분기** 명문화 + cardaudit 사례 면제 교정.
3. **학습자 개인화 레이어**(cold-start식) 신설 — 최대 격차.
4. **exam-forecast 스킬** 신설 → 닫힌루프 "기출경향→목차 가중".
5. study-plan phase 레이어 + 신뢰등급/GAP 마커 + 요건사실 weak 세분.
> 차용은 **구조·메커니즘**에 한정. 미국법 내용·인용규칙(FRCP·Bluebook 등)은 차용 금지(#1·#48). 외부는 한국 요건사실론·전수카드·SRS·백링크가 없음 — 우리 강점은 유지.
