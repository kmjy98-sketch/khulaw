## A. 목표·범위

- **대상 시험**: LEET 70문항 = 언어이해 30 + 추리논증 40
- **목표 수준**: 70문항 중 60문항(약 86%) 안정 득점권
- **산출 성격**: 시험장에서 바로 꺼내쓰는 **압축 추린본**. 학습 상세본(기존 종합본)은 그대로 두고, 추린본은 그 위에 얹는다.
- **두 축**:
  - 언어이해 → **글 종류(제재) + 종류별 알면 좋은 것** + (기존) 전개 방식
  - 추리논증 → **기초 논리학 / 양상논리학 / 과학철학 / 계산문제 / 논리게임(그루핑) / 강화·약화** + 실제 선지-지문 예문

## E. 표기 규칙 (사용자 지정 — 기호 깨짐 방지)

- 명제: P, Q, R / 개체: a, b, c / 집합·그룹: A, B, C
- 조건문: "P이면 Q" (화살표 기호 미사용). 대우: "Q 아니면 P 아니다"
- 부정: "not P" 또는 "P 아니다" (¬ 미사용)
- 연결: "그리고 / 또는" (∧ ∨ 미사용)
- 양화: "모든 / 어떤 / 없음" (∀ ∃ 미사용)
- 양상: "반드시(필연) / 가능 / 알다 / 해야 한다 / 할 수 있다" (□ ◇ 미사용)
- 표·코드블록 안에서는 백링크·기호 미사용(CLAUDE.md #35)

**선지-지문 예문 형식(템플릿 예시 — 실제 내용은 기출에서 추출):**
```
[지문 요지]  X이면 Y이다. 그런데 어떤 경우 Y가 아니었다.
[선지]      따라서 그 경우 X가 아니었다.
[판단]      타당. 대우 추론(Y 아니면 X 아니다)에 해당.
[함정]      "X가 아니면 Y가 아니다"로 바꿔치기하면 '이'의 오류.
```
