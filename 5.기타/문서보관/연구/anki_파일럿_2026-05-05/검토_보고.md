## 1. 품질 평가

### A. 사안 기반 설계 (case_law_scenario)
- 단순 "판례번호 → 판시사항" 암기 대신 구체적 사실관계 + 질문 → 법리 + 결론 구조 적용
- 1사건 다문항 분할: 대판 2012다92258(보험금청구권 질권 부당이득)을 2개 문항으로 원자화
- 커버된 판례: 18개 (2017다207499, 2013다32574, 96다22648, 2016다235411, 2025다212005, 2003다55059, 2012다92258, 2023다315155, 2020da296840, 2013da76192, 2018다201610, 2018da21326, 2020da223781 등)

### B. 전질권 표 복원 (rule_comparison)
- 원본 마크다운의 포맷 훼손된 책임전질/승낙전질 비교 표를 3개 카드(설정요건·책임가중·변제효과)로 분해

### C. 핵심 조문 카드 (statute)
- 제329·334·335·338·345·347·348·349·352·353조 원문 보존
- 축약 없이 원문 그대로 수록 (#34 준수)

### D. Cloze 카드
- 빈칸 수 최대 3개로 제한 (c1·c2·c3)
- 핵심 법리 키워드 중심 설계

## 3-2. 수동검수 — "문제 풀고 피드백" 방식 결과

passive 읽기가 아니라 앞면만 보고 실제 인출 → 뒷면 대조 방식으로 47장 검수. (세부 방법론은 `자동화_검토.md` 4절)

### 검수 결과 요약 (O/△/X)

| 노트 타입 | O | △ | X | 핵심 결함 |
|---|:--:|:--:|:--:|---|
| Statute (10) | 7 | 3 | 0 | 열거형·복합제도 1카드 과부하 |
| Case Law (대표 7) | 5 | 2 | 0 | 질문 2쟁점 결합, 숫자 과부하 |
| Cloze (16) | 13 | 3 | 0 | 문장 전체 빈칸(회상 단서 부족) |

폐기(X) 카드 0장 — 전 카드 사용 가능, 일부 보완 권장.

### 수정 리스트 (△ 항목, 보완 권장)

1. **제334조(피담보채권 6항목)·제353조(직접청구권 4항)** → overlapping cloze 보조 카드 추가
2. **제338조(경매+간이변제충당)** → 2장으로 분리 (별개 제도)
3. **Cloze 문장 전체 빈칸 3건**(정기예금 부존재 / 채권양도 유효 / 묵시갱신 제352조) → 원자 빈칸 재분할
4. **Case Law 질문 결합 2건**(2013다76192·2018다21326) → 단답 대비 시 쟁점별 분리 옵션
5. **보험금 사안(2012다92258)** → 숫자(15억/11억/4억) 간소화, 초과분 비율만 강조
6. (선택) **조문 역방향 카드**(내용→조문번호) 보강 — 시험의 조문번호 인출 요구 대응

### 검증으로 입증된 강점
- 사건명 단순암기 탈피 설계가 실제 작동 (사안→쟁점 인출 성공)
- 1사건 다문항 분할이 독립성 유지 (섞여도 단독 이해)
- cloze 누설 0건, 빈칸 상한(3개) 준수

## 4. 프로세스 개선점 및 자동화 권고

### 자동화 가능
| 작업 | 방법 |
|------|------|
| 조문 카드 생성 | `> [!조문]` 블록을 파싱하여 rule_schema TSV 자동 생성 가능 |
| frontmatter 태그 추출 | YAML frontmatter의 `쟁점`, `페이지` 필드를 태그로 자동 매핑 |
| Cloze 키워드 마킹 | `**강조**` 텍스트를 cloze 후보로 자동 식별 |

### 수동 검수 필요
| 작업 | 이유 |
|------|------|
| 판례 사실관계 적절성 | 사안 요약이 출제 의도를 담았는지 확인 필요 |
| 1사건 다문항 분할 적정성 | 분할된 카드가 단독으로 이해되는지 독립성 검수 필요 |
| Cloze 위치 타당성 | 핵심 키워드인지 vs. 너무 일반적인 단어인지 판단 필요 |
