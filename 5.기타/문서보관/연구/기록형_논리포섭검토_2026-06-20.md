# 기록형 논리·포섭 검토 (v1, 2026-06-20)

> **용도**: 기존 검토(날조·인용·정형·분량)가 못 잡는 **논증 자체의 타당성**을 점검한다. 3가지로 사용 — (a) 자가점검 체크리스트(A절) (b) 적대검증 프롬프트(B절) (c) verify 워크플로우 dimension(C절).
> **원칙**: 이 검토는 사실·판례의 *진위*가 아니라 **요건→포섭→결론의 논리**를 본다. 진위는 R3·R4·korean-law-mcp가 담당(중복 금지).
> **관계**: `기록형풀이_룰`(R8 IRAC·R9 상대반박), `본선_복붙마스터_v2`(C·D절), `참고서면작성_룰프롬프트`(논증 규칙), `sync/가인 역대 우수 답안.md`(논증 밀도 기준). (룰은 R1~R10만 존재 — R11·R12 없음)

## A. 5축 체크리스트 (작성 직후 자가점검)

### ① 요건-사실 대응 완전성 (최우선)
- [ ] 각 청구권/범죄(주위·예비 포함)의 **성립요건을 빠짐없이 열거**했는가
  - 예: 불법행위=가해행위·위법성·고의/과실·손해·인과관계 / 배임=타인의 사무처리자·임무위배·재산상 이익·본인 손해·고의·불법이득의사 / 부당이득=이득·손실·인과·법률상 원인 없음
- [ ] 요건마다 충족/불충족 판단이 있고, **충족 근거를 기록 인용으로 포섭**했는가
- [ ] 다툼 요건과 다툼없는 요건을 구분했는가(다툼없는 건 간략히)
- [ ] (피고/변호인 측) 청구를 무너뜨리는 **'급소 요건' 하나를 명확히 타격**했는가
- ▶ 적발 시: 요건 누락은 **최우선 보강** — 누락은 채점표 항목 통째 0점 위험

### ② 삼단논법 타당성
- [ ] 법리(대전제)→포섭(소전제)→소결의 연결에 **비약 없음**(전제에서 결론이 실제로 도출되는가)
- [ ] **과잉 일반화**(판례 사안의 무리한 확장)·**과소 포섭**(사실 일부만 평가) 없음
- [ ] **충분조건/필요조건을 뒤집지 않음**(참고서면 룰 8 연동)
- [ ] **순환논증**(결론을 전제로 재사용) 없음
- [ ] "~라 할 것이다 / 명백하다"로 **포섭을 건너뛴 단정**이 없음(단정이 포섭을 대체하지 않음)

### ③ 반대논거·구별 논리
- [ ] 상대 최강 논거·재판례를 **정면 처리**(회피 없음)
- [ ] **distinguishing이 '사실관계 차이' 또는 '후행 대법원 판례'에 근거**(막연한 "사안이 다르다" 금지)
- [ ] **다중 안전망(주위·예비/①②③)의 각 단계가 앞 단계 없이도 독립적으로** 결론을 지지
- [ ] **정반대 사실에 같은 결론을 "법리 동일"로 복붙하지 않음** ← 예) 거래소 매개 有(BTC)와 직접 점유(GDX 직거래)는 보관자성 평가가 달라야 하는데 동일 논리를 차용하면 오히려 불리. distinguishing은 사실별로 따로 세울 것
- [ ] 불리 판례·사실의 적용 배제 논리가 실제 배제 효과를 가짐

### ④ 내부 일관성
- [ ] 같은 사실을 두 쟁점에서 **모순되게 평가하지 않음**
- [ ] **주위적 주장이 예비적 주장의 전제를 부정하지 않음**(예비는 주위 패소 가정 위에서 성립)
- [ ] **주위적 논거가 예비적 약점을 자초하지 않음** ← 자가당착 빈출: 예) 횡령 재물성 부정을 위해 "재산상 이익 해당"을 적극 인정하면, 예비적 배임의 객체성(재산상 이익) 요건을 스스로 충족시킴. 약화("재물도 이익도 아닐 여지")하거나 충돌을 명시 차단할 것
- [ ] **인부(인정/부인)와 본문 항변이 일치**(인정한 사실을 본문에서 다투지 않음)
- [ ] 피고별·청구별 논리가 상호 충돌하지 않음

### ⑤ 결론 정합
- [ ] 각 쟁점 소결이 **종합 결론으로 모순 없이 수렴**
- [ ] 결론(청구취지/무죄·유죄)이 **소장 청구취지·문제 지시와 정확히 일치**(청구취지 변경 금지 준수)
- [ ] 일부 인용/기각 시 그 범위가 본문 논증과 정합

## B. 적대검증 프롬프트 (별도 AI/세션이 초안을 공격)

> 작성자와 다른 시각으로 "포섭 구멍"을 깐다. 봐주지 말 것.

===

당신은 한국 기록형 법률서면의 **논리·포섭 검수자**다. 아래 서면(과 있으면 쟁점·법리 표)을 받아, 사실·판례의 *진위*가 아니라 **요건→포섭→결론의 논리**만 적대적으로 검토한다. 5축으로 약점을 모두 들춰라.

- **① 요건-사실 대응**: 누락된 성립요건이 있는가? 포섭 없이 단정한 요건은? 급소 요건을 놓쳤나?
- **② 삼단논법**: 비약·과잉일반화·과소포섭·충분/필요조건 혼동·순환논증·"명백하다"식 건너뜀.
- **③ 반대논거**: 상대 최강논거 회피? distinguishing이 사실차이/후행판례에 근거하나? 다중안전망 각 단계가 독립 성립하나?
- **④ 일관성**: 모순 평가·주위/예비 충돌·인부와 본문 불일치.
- **⑤ 결론 정합**: 청구취지=결론인가? 각 쟁점 소결이 종합 결론으로 수렴하나?

출력: 발견마다 `{축 | 위치(항·쟁점 번호) | 문제 | 심각도(치명/중/경) | 보강안}`. **치명=요건 누락·논리 비약을 우선**한다. 마지막에 "최우선 3건"과 총평(이 서면이 논증만으로 이길 수 있는가)을 적는다. 사실·판례 진위는 별도 검토 소관이므로 여기서 다루지 않는다.

[입력]
- 서면: {붙여넣기}
- (선택) 쟁점·법리 표: {붙여넣기}

===
