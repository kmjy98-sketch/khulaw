## 모듈 1 — dedup_cluster.py (중복:: 태그)

**목적**: 여러 책에 흩어진 동일 쟁점 카드를 묶어 `중복::` 태그 부착(삭제 아님). Anki 필터덱으로 한 클러스터만 학습/병합 후보 식별.

**입력**: `outputs/02_cards_v37/*.md` (또는 빌드된 노트의 Front/Text + 태그).

**알고리즘**:
1. 정규화: Front/Text에서 cloze 마커·HTML·조사·공백 제거 → 시그니처.
2. 1차 군집: `속성::`(요건/일반론/OX 등) + 핵심 명사 키워드(소제목) 동일군.
3. 2차 유사도: 군 내 텍스트 유사도(자카드/문자 n-gram ≥ 임계) → 클러스터.
4. 교차책 탐지: 같은 클러스터에 `출처::` 다른 카드 2+ → 중복 후보(예: 채권자취소권 = 쟁점노트+신민사+사례연습).

**출력 태그**: `중복::{clusterid}` (또는 `중복::교차책`). 대표카드 1장 `중복::대표`.

**★ 결정 필요(#5 중복강도)**: ① 태그만(비파괴, 권장) / ② 비대표 카드 `suspend`까지. → 1안 기본, 2안은 명시 승인 시.

**재활용**: 2026-04 `_dryrun_dedup` 로직.

## 모듈 2 — frequency_import.py (빈도:: 태그)

**목적**: 빈출 쟁점에 `빈도::` 태그 → 우선순위 학습·찌라시 선별.

**입력(★ 결정 필요 #4 — 빈출 소스)**:
- (가) **외부 빈출표**: 변시 기출 빈도 데이터 제공 시 직접 매핑(가장 정확).
- (나) **고동성 종합정리** Part1/3의 별점(★★★/★★/★)·빈출 표기 추출(`8.찌라시/고동성/변시 사례풀이 종합정리.md`).
- (다) **교차책 등장빈도 프록시**: 모듈1 클러스터에서 한 쟁점이 등장한 책 수 = 빈출 근사(소스부재 시 차선).

**출력 태그**: `빈도::변시빈출` / `빈도::상(중/하)` / `빈도::N회`.

**의존**: (다)는 모듈1 선행. (가) 없으면 (나)+(다)로 진행.

## 모듈 3 — 찌라시 의미병합 (07 프롬프트 확장)

**목적**: 산재 동일쟁점 카드를 "교집합 + 예외" 1장으로 병합한 시험직전 압축 찌라시 생성.

**입력**: 모듈1 클러스터 + 기존 찌라시 카드 + 약점(`learning.json`).

**방법**:
1. 모듈1 클러스터(교차책 동일쟁점)를 07 찌라시 프롬프트에 투입.
2. 공통 법리(교집합) + 책별 예외/추가 논거(차집합)를 1장으로 병합.
3. 약점(learning.json 오답 누적) 쟁점 우선 병합.

**출력**: `outputs/02_cards_v37/찌라시_{과목}_병합.md` (회독그룹=찌라시). 기존 찌라시 보존, 병합본 추가.

**의존**: 모듈1.
