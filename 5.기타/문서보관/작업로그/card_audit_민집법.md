- **카드 대응**:
  - 전합 판결요지(병행형) → 카드 `[판례] 추심명령과 채무자 원고적격 — 전합 판결요지` O
  - 논거② 포섭 → 카드 `[포섭] 전합 논거 — 추심채권자에게 부당하지 않은 이유` O
  - 비교표 중복소송 변경 → 카드 `[포섭] 병행형 전합으로 수정된 주요논점 — 중복소송` O
  - 소송참가 → 카드 `[포섭] 병행형 전합으로 수정된 주요논점 — 소송참가` O
  - 기판력 변경 → **카드 없음** (원문: "집행채무자가 받은 본안판결의 기판력은 추심채권자에게도 미침" 부분)

## 4. 품질 분석

### 4-1. 앞/뒤/빈칸 정형 여부

- 형식: `앞:`/`뒤:`/`빈칸:` 3종 + 태그(`과목::` `속성::` `주제::` `난이도::` `출처::`) 일관 적용 → **정형 준수**
- 빈칸은 `{{c1::…}}`, `{{c2::…}}` cloze 형식 → **Anki cloze 표준 준수**
- 사례형(흡수설·가압류배당·이전등기청구권재매도)은 `[A][B][C]` 단계 분할 → **구조적 적절**

### 4-2. 원문 일치·완전성

**일치 양호 사례:**
