# 송영곤 B형 정리 표준템플릿 v1

A형(raw OCR 추출본)을 B형(정리본)으로 변환하기 위한 형식 규칙. **본문 의미는 0% 변경**, 형식 정리만 수행.

## §0 적용 범위·원칙

- **적용**: `sync/_교재원문/민법/송영곤_논점민법_본책/` + `송영곤_논점민법_보충/` + `송영곤_객관식/` 의 모든 .md
- **본문 보존**: CLAUDE.md #1 (소스 보존). 의미 변경·축약·재서술 금지.
- **anchor 보존**: CLAUDE.md #34 — 조문번호·사건번호·한자는 LLM 교정 대상에서 제외. 정규식 치환에서도 제외.
- **삭제 금지**: CLAUDE.md #16 — 원본 폐기 금지. 백업은 `_백업/{YYYY-MM-DD}/` 하위.
- **버전 관리**: 본 템플릿 v1 → v2 갱신 시 `_meta/` 에 별도 파일 신설 (덮어쓰기 금지).

## §1 front matter (YAML 정상화)

A형은 첫 줄에 `--- tags: [...]` + 메타 필드가 한 줄로 압축된 비표준 형태. B형은 다음 표준 yaml로 변환:

```yaml
---
tags:
  - 교재원문
  - 민법
  - 송영곤_논점민법_본책
  - {쟁점태그1}
  - {쟁점태그2}
교재: 송영곤 《논점민법강의 본책》
판: 12
과목: 민법
서브책자: 재산법
원본_chunk: 송영곤_논점민법_본책_ch{NN}_p{XXXX-XXXX}
페이지_범위: "31-60"
포함_페이지: [31, 32, 33, ..., 60]
쟁점:
  - 민법 법원
  - 신의칙
  - 자연인 권리능력
  - 태아의 권리능력
정리일: 2026-04-29
정리_버전: B-v1
---
```

**규칙**:
- 키는 한국어 유지 (`교재`, `판`, `과목`, `서브책자`, `쟁점`).
- `판`은 정수 (따옴표 없음). `페이지_범위`는 문자열로 따옴표.
- `포함_페이지`는 정수 배열. 누락된 페이지(공란·도판)도 원본 그대로 유지.
- 신규 필드: `정리일`, `정리_버전` 추가.
- 파싱 검증 필수 (yq, python-yaml).

## §2 헤더 계층 규칙

송영곤 교재 목차 구조: **편 > 장 > 절 > 관 > 항 > 호**.

| 깊이 | 마크다운 | 예시 |
|---|---|---|
| 1 | `#` | 송영곤 《논점민법강의 본책》 — 재산법 - {챕터} (p.X-Y) |
| 2 | `##` | 제O부 / 제O편 / 제O장 |
| 3 | `###` | 제O관 / I., II., III. (대단원) |
| 4 | `####` | 1., 2. / 가., 나. (중단원) |
| 5 | `#####` | (1), (2) / ①, ② (소단원) |

**규칙**:
- A형의 본문 한 줄에 섞인 헤더 텍스트(예: `제2관 [[신의칙]] 5`)는 페이지 헤더이므로 **제거**. 정규 헤더는 별도 라인 `### 제2관 [[신의칙]]`로 승격.
- callout 안에 헤더 들어가는 깨짐(`> 1 .의 의`)은 callout 밖으로 빼서 별도 헤더로 정리.
- 동일 깊이 헤더는 같은 `#` 개수 사용. 깊이 건너뛰기 금지.

## §3 callout (Obsidian) 형식

| 종류 | 마크다운 | 용도 |
|---|---|---|
| 조문 | `> [!조문] 제X조 【제목】` | 민법·상법 등 조문 원문 인용 |
| 판례 | `> [!판례] 대판 YYYY.M.DD, 사건번호` | 판례 요지·판시사항 |
| 정의 | `> [!정의] 용어` | 학설·교재상 정의 |
| 예시 | `> [!예시]` | 사례·예제 |
| 주의 | `> [!주의]` | 함정·반대 입장 |
| 참고 | `> [!참고]` | 보충 설명 |

**규칙**:
- callout 본문은 모든 줄에 `> ` 접두 유지.
- callout 안에 헤더(`#`) 사용 금지. callout 안에 표·코드블록은 허용.
- 조문 callout은 한 조문당 하나의 callout. 두 조문이 한 callout에 섞이지 않도록 분리.
- 판례 callout 헤더에는 `대판/대결/대결(전합)/헌재` + `YYYY.M.DD` + `사건번호` 표기 필수.

## §4 표 형식 (PDF 표 → 마크다운)

A형은 PDF 표가 줄글로 합쳐져 있거나 callout 안에 들어가 있음. B형은 표준 마크다운 표로 변환.

```
| 열1 | 열2 | 열3 |
|---|---|---|
| 셀1 | 셀2 | 셀3 |
```

**규칙**:
- 헤더 행 분리선 `|---|---|` 필수.
- 표 안에서는 백링크 `[[...]]` 사용 금지 (CLAUDE.md #35). 사건번호는 텍스트만 표기.
- 셀 안에 줄바꿈 필요 시 `<br>` 사용. 다단 표는 가능한 평탄화.
- 사례형 청구-항변 구조는 **2열 표** (CLAUDE.md #32) — 원고|피고. 빈 셀은 `—`.
- 표 변환이 의미 변경을 유발하는 경우(원문 의도 불명) 변환 보류, 원문 텍스트 유지 + `<!-- 표 변환 보류: 원문 의도 확인 필요 -->` 주석.

## §5 각주 처리

A형에 `[^N]` 마커가 있으나 정의부가 누락된 경우 다수 (OCR이 페이지 번호를 각주처럼 추출).

**판별 기준**:
- `[^숫자]` 가 사건번호 끝에 붙어 있으면(예: `4293민재항[^349]` → `4293민재항349`): 사건번호 일부로 인식 → **각주 마커 제거하고 본문에 합침**.
- `[^숫자]` 가 본문 단어 끝에 붙어 있고 정의부가 없으면: 페이지 번호 OCR 노이즈 → **제거**.
- 진짜 각주(저자가 본문 보충한 것)는 문서 말미에 `[^N]: 정의 본문` 형태로 매핑부 작성.

**현재 샘플 3개 분석 결과**: 모두 사건번호 OCR 노이즈 또는 페이지 번호 → 단순 제거 대상.

## §6 OCR 노이즈 패턴 (정규식)

**자동 batch 적용 가능 (안전)**:

| 패턴 | 설명 | 정규식 (Python) | 치환 |
|---|---|---|---|
| 페이지 헤더 라인 | "제N관 ... 숫자" 단독 라인 | `^제\d+관\s+\[?\[?[가-힣]+\]?\]?\s+\d+\s*$` | (삭제) |
| 페이지 헤더 라인 | "제N장 ... 숫자" 단독 라인 | `^제\d+장\s+.+\s+\d+\s*$` | (삭제) |
| 페이지 헤더 라인 | "제N부 ..." 단독 라인 | `^\[?제\s*[OoO0]?부\s+.+$` | (삭제) |
| 페이지 번호 | 단독 라인 숫자 (3자리 이하) | `^\s*\d{1,3}\s*$` | (삭제) |
| 사건번호 끝 각주 | `\d+다\d+\[\^\d+\]` | `(\d+다\d+)\[\^\d+\]` | `\1` |
| 사건번호 끝 각주 | `\d+민[가-힣]+\[\^\d+\]` | `(\d+민[가-힣]+)\[\^\d+\]` | `\1` |

**보류 (LLM 검증 필요·자동화 위험)**:
- 한자 깨짐 (`傑里` → `조리`, `祭主` → `제주`): anchor — CLAUDE.md #34에 따라 LLM 교정 제외.
- 잘못된 기호 (`■`, `丰`, `仲판`, `©`, `9`): 단독 본문 위치라면 의미 추정 위험. 사용자 검수 후 교정.
- 띄어쓰기 깨짐: 의미 변경 가능 → 보류.

**원칙**: 정규식은 **삭제 또는 명백한 패턴 매칭만**. 추정 치환 금지.

## §7 인용문 통일

**조문 인용**:
- callout 안 본문: 원문 그대로 (조사·띄어쓰기 보존).
- 본문 중 조문 참조: `**제XXX조**` 굵게 (조문번호 강조).
- 항·호 참조: `**제XXX조 제Y항 제Z호**`.

**판례 인용**:
- 본문: `(대판 YYYY.M.DD. [[YYdaXXXX]])` 형식. 사건번호는 백링크 처리.
- callout: `> [!판례] 대판 YYYY.M.DD, [[YYdaXXXX]]` 헤더 + 본문.
- 사건번호 형식 통일:
  - `YY다XXXX` (예: `94다53006`)
  - `YYYY다XXXXX` (예: `2018다228868`)
  - `YYY그XXX`, `YY마XXX`, `YYYY민재항XXX` 등
- **CLAUDE.md #35**: 백링크는 본문에만. 표·callout·코드블록 안 백링크 금지.

## §8 백링크 규칙 (CLAUDE.md #35 재확인)

- 판례: `[[대판 YYYY.M.DD, YYdaXXXX]]` 또는 약식 `[[YYdaXXXX]]`
- 헌재: `[[헌재 YYYY.M.DD, YYYYhunmaXXXX]]`
- 조문: `[[§XXX]]` (§10 이상만. §1~§9는 섹션번호 오탐 방지로 제외)
- 핵심 개념: `[[신의칙]]`, `[[권리남용]]`, `[[사정변경의 원칙]]`, `[[대리권남용]]` 등
- **금지 위치**: 표 안, callout 안, 각주 안, 코드블록 안

## §10 적용 절차

1. **백업**: `_백업/{YYYY-MM-DD}/` 하위에 원본 복사 (PowerShell 1회 실행 권장).
2. **A형 자동 정규화** (정규식 batch — Python 또는 PowerShell):
   - §6 표의 "자동 batch 적용 가능" 패턴만 적용.
   - 적용 전·후 line count·word count 비교 → 변동량 logging.
3. **C형 Claude 직접 정리**:
   - front matter yaml 정상화 (§1).
   - callout 깨짐 보정 (§3).
   - 표 변환 (§4) — 의도 명확한 표만.
   - 헤더 계층 보정 (§2).
4. **검증**:
   - yaml 파싱 정상 (yq).
   - line count 변동량 ≤ §6 정규식 적용 라인수 (그 외 변동은 수동 정리분).
   - word count 변동량 < 1% (변동량 큰 경우 의미 변경 의심 → 재검토).
   - OCR 노이즈 잔존 검색: `grep -E "페이지 헤더 정규식"` → 0건 확인.
5. **로그**: `_meta/` 또는 `.auto-memory/session_logs/` 에 변경 사항 기록.
