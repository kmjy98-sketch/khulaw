# H드라이브 전수 백업 계획서

## 0. 목적·원칙
- **목적**: `H:\내 드라이브`(개인 볼트) 전수를 독립 백업한다. E: 이주(P3)의 전제이자 일상 안전장치. Google Drive는 백업이 아니며(공식 "sync≠backup"), 우리 워처가 silent_drop 5건 실측 → **독립 단방향 백업 필수**.
- **원칙**: ①원본 H: 불변(단방향 copy, 이동 아님) ②비삭제(미러 `/MIR` 금지 — copy만) ③#16-C 로그/매니페스트 ④0.공유드라이브는 read·copy만(#16-B, 이동·쓰기 금지) ⑤자격증명·개인정보(.env·API키·사진) 유출 차단.

## 1. 핵심 제약 (이 세션 실측)
- **스트리밍 placeholder는 바이트 복사 불가**(.gdoc가 OSError 22로 실패한 것과 동일 메커니즘). → **복사 전 전체 오프라인 pin 필수**(Drive 앱 GUI). pin 안 하면 온라인전용 파일이 **조용히 누락**된다(백업 최대 위험).
- **용량**: H:는 수십 GB(예: `5.기타/_백업` 19GB, `_원본보관/pdf_전체` 1.13GB, 교재 PDF·outputs·.agent 등). E:는 **190GB 여유** → 수용 가능. (정확 용량은 §3 Step 0에서 pin 후 실측.)
- **0.공유드라이브**: 복사는 허용되나 타인 공동소유 → **별도 분리 백업**(또는 제외), 이동·쓰기 절대 금지(#16-B).
- **자격증명·개인정보**: `.env`·API키·사진은 백업 포함 시 분리/암호화. (khulaw git은 `add -A` 금지·`-f` .env 주의 — 기존 방침.)

## 2. 백업 계층 (3-2-1)
| 계층 | 위치 | 방법 | 비고 |
|---|---|---|---|
| 1차(정본) | `H:\내 드라이브`(Drive 스트림) | 현행 | 백업 아님 |
| **2차(로컬 전수)** | `E:\백업\법학볼트_YYYY-MM-DD\` | robocopy/rclone **copy**(단방향·비삭제) | 핵심 백업 |
| 3차(텍스트) | git `khulaw` | 룰·스킬·스크립트·노트 md 선별 커밋 | `add -A` 금지(유출) |
| (선택) 4차 | 외장 HDD 또는 별도 클라우드 | rclone copy | 오프사이트 |

## 3. 절차 (★사용자 GUI / ☆Claude Code)
- **0. ☆ 사전 인벤토리(pin 후 실측)**: 폴더별 파일수·용량 + sha256 매니페스트 생성(`.agent/state/`) → 백업 후 대조 기준.
- **1. ★ 전체 오프라인 pin**: Drive 앱에서 `H:\내 드라이브` → "오프라인 사용 설정" → 동기화 아이콘 전부 ✓(초록)까지 대기. (placeholder 제거 — 최우선)
- **2. ★ 앱 종료 + 동기화 0 확인**: Obsidian 등 종료, Drive "최신 상태/업로드·다운로드 0" 확인.
- **3. ☆ 전수 복사**: 개인 폴더 → `robocopy "H:\내 드라이브" "E:\백업\법학볼트_2026-06-22" /E /COPY:DAT /R:1 /W:1 /XJ /TEE /LOG:E:\백업\_robocopy_2026-06-22.txt /XD "H:\내 드라이브\0.공유드라이브"`. (copy, **미러 아님**. 정션/심볼릭 `/XJ`로 회피.)
- **3b. ☆ 공유드라이브 분리 복사(선택)**: `0.공유드라이브`는 read-only 별도 `robocopy ... "E:\백업\_공유드라이브_2026-06-22" /E`(이동·쓰기 금지, 복사만).
- **4. ☆ 무결성 검증**: 사전(Step0) 대비 파일수·총용량 일치 / sha256 표본 대조 / robocopy 로그 **Skipped·Failed=0** / **0바이트 의심분 점검**(placeholder 누락 신호).
- **5. ☆ 매니페스트·로그 저장**: `.agent/state/backup_manifest_2026-06-22.{csv,json}` + robocopy 로그 보존(#16-C 정신).

## 4. 범위 — 포함/제외
- **포함(전수)**: `1.민사`~`10.도서관`, `sync`, `outputs`, `.agent`, `6.진도관리`, `7.대회`, `8.찌라시`, `9.로스쿨입시`, `_원본보관`, 루트 문서 등 개인 데이터 전부.

## 5. 주기·자동화 (1회 전수 후)
- **증분**: `rclone copy`(비삭제) 또는 `robocopy /XO`(최신만) 주간. **`/MIR`(미러=원본삭제 반영) 절대 금지.**

- 자동화 수단: Windows 작업스케줄러(무인) 또는 Claude Code Routines.
