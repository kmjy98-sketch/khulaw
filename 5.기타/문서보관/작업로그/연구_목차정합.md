# 연구3 — 목차-논점 정합

## 0. 결론 (한 줄)

"목차에 있는 쟁점 넘버가 보드에서 상당수 누락"의 **진짜 원인은 논점노트 결손이 아니라, 논점노트 frontmatter의 메타데이터 불일치(`type`·`논점` 필드)가 옵시디언 Bases 보드(`진도보드.base`)의 필터·그룹·정렬을 깨뜨린 것**이다. 7개 과목 전부에서 **목차 항목 수 = 노트 파일 수, 제목 기준 1:1 완전 일치(진짜 결손 0건)**임을 확인했다. 즉 "뷰 문제(메타데이터 문제)"이지 "노트 결손"이 아니다.

근거: 제목(파일명) 기준 대조 결과 7과목 모두 "목차 제목인데 노트 없음 0건 / 노트인데 목차 없음 0건"
(`/tmp/title_match.py` 실행 결과, 아래 §3).

## 1. 보드의 작동 방식 — 무엇이 누락을 만드는가

`sync/위키/진도보드.base` (Read 확인):

```
filters:
  and:
    - note.type == "쟁점"      ← (a) type이 정확히 "쟁점"이 아니면 행 자체가 제외
properties:
  논점: { displayName: 논점 }   ← (b) note.논점 필드를 컬럼으로 사용
views:
  - 진도표(과목별): order=[note.논점, ...] groupBy=note.과목   ← (c) 논점으로 정렬
  - 미착수: filters: note.진도 == "미착수"
  - 회독진행: filters: note.회독 > 0
```

보드가 한 항목을 정상 표시하려면 **세 가지 메타데이터**가 모두 맞아야 한다:
1. `type: 쟁점` (필터 통과) — 틀리면 **행 자체가 보드에서 사라짐** = "누락"의 1차 원인.
2. `논점` 필드 존재 + 목차 번호와 동일 형식 — 틀리면 정렬·식별이 깨져 "번호 누락"처럼 보임.
3. `진도`/`회독` 등 보조 필드 — 부가 뷰(미착수·회독진행) 노출 여부.

→ **보드에서 "쟁점 넘버가 안 보인다"의 메커니즘은 ①type 필터 탈락 또는 ②논점 필드 결손/오형식**이다. 노트 파일은 디스크에 멀쩡히 존재한다.

## 2. 과목별 목차 넘버링 체계 (TOC 자체는 일관)

목차 파일 7종 모두 `[NN] [[제목]] (p)` 패턴으로 일관되며, 과목별 접두사만 다르다:

| 과목 | 목차 항목수 | 넘버링 체계 | 예시 | 비고 |
|---|---|---|---|---|
| 민법 | 132 | 재산법 `01`~`122` + 가족법 `G01`~`G10` | `[72]`, `[G03]` | 2계열(숫자+G) |
| 민소법 | 49 | `01`~`49` (제로패딩 2자리) | `[01]`, `[40]` | |
| 민집법 | 4 | `01`~`04` | `[01]` | 보완 예정 명시 |
| 행정법 | 234 | `A01`~`A234` (A접두사) | `[A105]` | 단일 계열 |
| 헌법 | 106 | `001`~`106` (제로패딩 3자리) | `[041]`, `[098]` | |
| 형법총론 | 60 | `형총 001`~`형총 060` (한글접두사+공백) | `[형총 001]` | 접두사에 공백 |
| 형법각론 | 110 | `개인 001~076`·`사회 001~013`·`국가 001~021` | `[개인 042]` | **3계열 혼합** |

**목차 자체의 넘버링은 비연속·중복·건너뜀 없음**(연속 검증 통과). 문제는 전적으로 노트 쪽 `논점` 필드가 이 체계를 따르지 않는 데 있다.

> _MOC.md(허브)와 각 과목 목차 헤더의 "논점 수" 표기는 노트 파일 수와 일치(민법 132, 민소법 49, 민집법 4, 헌법 106, 형총 60, 형각 110, 행정법 234). 단 _MOC.md는 민법을 "재산법 122+가족법 10=132"로, 민소법을 "49", 헌법 목차 헤더는 "106 논점"으로 적어 허브-목차-노트 3자 카운트는 정합.

## 3. 핵심 대조 — 결손 vs 번호불일치 vs 뷰문제

### 3-A. 제목(파일명) 기준 — 진짜 결손은 0건

| 과목 | 목차 항목 | 노트 파일 | 목차O 노트X (결손) | 노트O 목차X (드리프트) |
|---|---|---|---|---|
| 민법 | 132 | 132 | **0** | **0** |
| 민소법 | 49 | 49 | **0** | **0** |
| 민집법 | 4 | 4 | **0** | **0** |
| 행정법 | 234 | 234 | **0** | **0** |
| 헌법 | 106 | 106 | **0** | **0** |
| 형법총론 | 60 | 60 | **0** | **0** |
| 형법각론 | 110 | 110 | **0** | **0** |

→ **모든 과목이 제목 기준 완전 1:1.** 노트 자체는 빠짐없이 생성돼 있다. "보드 누락"은 노트 결손이 아니다.

### 3-B. frontmatter 건강도 — 여기서 전부 깨진다

| 과목 | 노트 | `type=쟁점`(필터통과) | `type` 다름(보드탈락) | `논점`필드 존재 | `논점`=깨끗한 목차번호 |
|---|---|---|---|---|---|
| 민법 | 132 | 132 | 0 | 132 | **124** (8건 오형식) |
| 민소법 | 49 | **24** | **25** | **24** | **16** |
| 민집법 | 4 | **0** | **4** | **0** | **0** |
| 행정법 | 234 | **0** | **234** | **0** | **0** |
| 헌법 | 106 | 106 | 0 | 106 | **6** (100건 오형식) |
| 형법각론 | 110 | 106 | **4** | 106 | **50** |
| 형법총론 | 60 | 60 | 0 | 60 | **52** |
| **합계** | **635** | **428** | **267** | **522** | **252** |

(근거: `/tmp/counts.py`. "깨끗한 목차번호" = `^(형총|개인|사회|국가)\s*\d+$` 또는 `^[AG]?\d+$` 정규형식과 일치)

**해석**
- **267개 노트(42%)가 `type` 필터에서 탈락** → 보드에 행 자체가 안 뜸. 특히 **행정법 234개 전부, 민집법 4개 전부**가 보드에서 통째로 사라짐.
- `type` 통과한 428개 중에서도 **논점 필드가 깨끗한 번호인 것은 252개(40%)뿐**. 나머지는 정렬·식별이 어긋남.
- 따라서 보드에 "정상 번호로" 보이는 것은 산술상 극소수. = 사용자가 본 "쟁점 넘버 상당수 누락" 현상.

## 4. 과목별 불일치 상세

### 4-1. 행정법 — 전멸 (가장 심각)
- **노트 234개 전부 `type`이 "쟁점"이 아님.** frontmatter 키가 `유형: 논점노트`(예: 가행정행위) 또는 `type: 논점노트`. → 보드 필터 `note.type=="쟁점"`에 **0개 통과 = 보드에서 행정법 전체가 사라짐.**
- **`논점` 필드 자체가 없음**(234개 모두). 목차 번호 `A01`~`A234`가 노트에 전혀 기재되지 않음.
- 누락 번호(목차에 있으나 매칭 0): `A01`~`A234` **전부**.
- 근거: `행정법/가행정행위.md` frontmatter — `유형: 논점노트`, `논점` 키 없음.

### 4-2. 민집법 — 전멸
- 노트 4개 전부 `type` 미지정 또는 다름. `금전채권에 대한 집행.md`는 frontmatter 첫 줄이 `상태:`로 시작, `tags: [민집법, 논점, …]`만 있고 `type`·`논점` 둘 다 없음.
- 누락 번호: `01`,`02`,`03`,`04` 전부.

### 4-3. 민소법 — 절반 탈락 + 번호 형식 분열
- `type=쟁점` 24개 / `type=논점노트`(또는 빈값) 25개 → **25개 보드 탈락.**
- 번호 필드가 **두 갈래로 분열**: 일부는 `논점번호: 40`(키 이름이 `논점`이 아니라 `논점번호`!), 일부는 `논점: "[01] 토지관할·사물관할"`(번호+제목 혼입), 다수는 `논점` 키 자체 없음.
  - `공동소송.md`: `type: 논점노트`, `논점번호: 40` (→ 보드는 `note.논점`을 보므로 **40이 안 잡힘**).
- "논점 필드(`논점` 키)" 보유 24개 중 깨끗한 번호는 16개.
- 보드에서 누락처럼 보이는 번호(노트의 `논점` 키 기준 매칭 실패): `25`~`49` 등 다수 (대부분 `논점번호` 키로 들어가 있거나 키 없음).

### 4-4. 헌법 — type은 OK, 논점 필드가 거의 다 오형식
- `type=쟁점` 106개 전부 통과(필터는 정상).
- 그러나 **`논점` 필드가 깨끗한 번호인 것은 단 6개.** 나머지 100개가 오형식:
  - `논점: "[041] 거주·이전의 자유"` (번호+제목, 다수)
  - `논점: 098 국가긴급권` / `논점: 075 국민주권 및 민주주의의 원리` (번호+제목, 따옴표 없음)
  - `논점: 국무총리와 국무위원` / `논점: 대의제의 원리` / `논점: 사법권의 독립` (**제목만, 번호 없음**)
- → 보드 행은 뜨지만 `논점` 컬럼/정렬이 제각각 → "번호가 없는/뒤섞인 것처럼" 보임.
- 근거: `헌법/국무총리와 국무위원.md` — `논점: 국무총리와 국무위원`(번호 누락).

### 4-5. 형법총론 — type OK, 번호 체계 드리프트
- `type=쟁점` 60개 전부 통과.
- 목차는 `형총 001`~`형총 060`인데, **노트는 접두사 없이 `논점: 001`로 저장**(예: 죄형법정주의 `논점: 001`). → 목차 `형총 001`과 문자열 불일치(번호불일치).
- 일부는 제목만: `논점: 부작위범 일반`, `논점: 작위 정범에 부작위로 가담한 경우`, `논점: 자수·자복, 외국에서 집행된 형의 산입`.
- 목차-노트 번호 매칭 실패 항목(목차 표기 기준): `형총 001~004, 형총 017~020, 형총 057~060` 등 — 실제로는 노트가 `001`·`제목`으로 들어가 있어 접두사·형식만 다른 것(진짜 결손 아님).

### 4-6. 형법각론 — 3계열 혼합, 절반 이상 형식 깨짐
- `type=쟁점` 106개 / `type=논점노트` 4개(공문서·사문서부정행사, 공정증서원본불실기재죄, 사서명위조 및 동행사, 위조 등 문서의 행사죄) → **4개 보드 탈락.**
- 목차는 `개인 001~076`/`사회 001~013`/`국가 001~021` 3계열. 노트 `논점`은:
  - 일부 정상: `논점: "[개인 042] 사기죄 일반"`(번호 추출 가능), 
  - 다수 제목만: `논점: 사람의 시기와 종기`, `논점: 배임죄 일반`, `논점: 무고죄` 등(번호 없음),
  - 혼입형: `논점: 개인 069 배임수·증재죄`(접두사+번호+제목 한 줄).
- 깨끗한 번호 50/110개뿐. 목차 번호 매칭 실패 56건(접두사·형식 불일치 또는 제목저장)이나 **파일 자체는 110개 전부 존재**.

### 4-7. 민법 — 가장 양호하나 8건 오형식
- `type=쟁점` 132개 전부, `논점` 필드 132개 전부 존재. 깨끗한 번호 124개.
- 오형식 8건: `논점: "[72] 계약해제"`, `"[69] 과실상계"`, `"[70] 대상청구권"`, `"[84] 물상대위권 (p424)"`, `"[82] 보증채무 (p408)"`, `"[81] 부진정연대채무 (p403)"`, `"[83] 분할채권·불가분채권 (p421)"`, `"[71] 손해배상액의 예정"` — 번호+제목(+페이지) 혼입. 번호 추출은 되나 정렬 불안정.

## 5. 논점 필드 ↔ 목차 번호 일치 여부 (질문 ③)

**대부분 불일치.** 일치(깨끗한 번호 그대로) = 252/635(40%). 불일치 유형 4가지:
1. **`논점` 키 자체 부재** (행정법 234·민집법 4·민소법 25 등) — 키가 없거나 `논점번호`로 잘못 명명.
2. **번호+제목(+페이지) 혼입** — `논점: "[72] 계약해제"`, `"[84] 물상대위권 (p424)"` (민법·헌법·형각).
3. **제목만 저장(번호 소실)** — `논점: 국무총리와 국무위원`, `논점: 배임죄 일반` (헌법·형총·형각 다수).
4. **접두사 체계 드리프트** — 목차 `형총 001`/`개인 042` vs 노트 `001`/제목 (형총·형각).

## 6. 보드 누락의 진짜 원인 (질문 ④ 종합)

| 원인 유형 | 해당 여부 | 규모 |
|---|---|---|
| **노트 결손** (파일 자체 없음) | **아니오 (0건)** | 7과목 전부 제목 기준 1:1 |
| **번호 불일치** (논점 필드 오형식/번호 소실) | **예** | `논점`키 보유 522개 중 깨끗번호 252개 → 270개 오형식; 행정법·민집법은 키 자체 부재 |
| **뷰 문제** (보드 필터 탈락) | **예 (1차 원인)** | `type≠쟁점` 267개가 보드에서 행 자체 소멸 (행정법 234·민소법 25·형각 4·민집법 4) |

**정리**: 
- (1차) **`type` 필드 비표준** → 267개(특히 행정법 전량) 보드 미표시. → 사용자 체감 "상당수 누락"의 최대 원인.
- (2차) **`논점` 필드 비표준**(키명·번호형식·번호소실) → 표시되더라도 번호 정렬·식별 붕괴.
- 노트 파일은 모두 존재하므로 **데이터 손실이 아니라 메타데이터 정규화 문제**다.

근본 배경: frontmatter 스키마가 과목별로 따로 만들어짐 — `type`(쟁점/논점노트) 혼용, `유형`/`type` 키 혼용, `논점`/`논점번호` 키 혼용, 번호 표기(접두사 유무·제목 혼입) 비통일. 목차(`[형총 001]` 등)와 노트 frontmatter 사이에 **단일 키 규약이 강제되지 않았다.** (#50-A 닫힌루프가 요구하는 "단원 키 정합"이 frontmatter 레벨에서 미구현.)

## 7. 구체 누락(보드 미표시) 번호 — 과목별

> "노트 파일은 있으나 보드에 번호로 안 잡히는" 목차 번호. (파일 결손이 아님에 유의)

- **행정법**: `A01`~`A234` **전 항목**(type 탈락 + 논점필드 부재).
- **민집법**: `01`,`02`,`03`,`04` **전 항목**(type 탈락 + 논점필드 부재).
- **민소법**: type 탈락 25건 + `논점`키 부재/오형식으로 `25`~`49` 대다수 미표시(예: 공동소송=40은 `논점번호:40`이라 미포착). type 통과·번호정상은 16건뿐.
- **헌법**: 번호 정상 6건 외 **100건**이 논점 컬럼 오형식(제목만 또는 번호+제목). 번호 소실 대표: `국무총리와 국무위원`, `대의제의 원리`, `사법권의 독립`, `문화국가의 원리`, `국제평화주의 및 국제법존중주의`, `대통령의 권한행사에 대한 통제`, `사회국가원리 및 경제질서`.
- **형법총론**: 접두사 드리프트로 목차 `형총 001~060` 전부 문자열 불일치(노트는 `001` 또는 제목). 제목저장 3건: 부작위범 일반·작위 정범에 부작위로 가담한 경우·자수·자복, 외국에서 집행된 형의 산입.

## 8. 미확인 / 한계

- **본 조사는 frontmatter 키-값 파싱 기준**이다. 옵시디언 Bases가 `유형:`(한글키)·`논점번호:` 등을 별도 매핑으로 인식하는지는 `.base` 정의상 `note.type`·`note.논점`만 참조하므로 미인식으로 판단했으나, 옵시디언 런타임 실제 렌더 결과는 본 도구로 직접 관측하지 못함(미확인).
- 보드의 다른 뷰(미착수=`진도=="미착수"`, 회독진행=`회독>0`)의 표시 여부는 `진도`/`회독` 값 분포까지 별도 조사 필요(본 연구 범위 밖, 미확인).
- 일부 노트의 `논점` 값에 책 페이지·제목이 함께 들어간 경우 번호 추출은 했으나, 옵시디언 정렬에서 문자열로 처리될지 숫자로 처리될지는 미확인.
- 본 문서는 읽기 전용 조사 결과이며 어떤 노트·목차·.base도 수정하지 않았다.
