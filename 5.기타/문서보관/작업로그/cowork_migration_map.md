# Cowork 이관 마스터 플랜 (코드 인계용)

> **Cowork 에이전트에게**: 이 워크스페이스는 OCR→위키→Anki카드→apkg로 이어지는 법학 학습 파이프라인입니다.
> 능력 재검증(deep-research) 결과 Cowork는 오케스트레이션·문서·LLM판단작업에 충분하나, **3개 미검증 위험** 중 하나(H:\ 마운트)가 이번 세션에서 **실패로 확정**됐습니다(§2). 그래서 "최대 이관"이 아니라 **범주별 분류 이관**입니다. §3 분류표가 핵심입니다.

---

## 1. 배경 — 왜 v2이고 무엇이 확정됐나

v1("Cowork 약함→로컬 주축")을 사용자가 의심 → deep-research 적대적 재검증(103 에이전트·21 소스·25 주장)으로 **능력 면에서 사용자 주장이 대체로 옳음** 확인.

- [확정] Cowork = 독립 워크스페이스+컨텍스트+메모리 모델 + 자율 작업분해 + 멀티 서브에이전트 병렬.
- [확정] Dispatch = 작업 자동 분류·라우팅(개발→Claude Code / 지식→Cowork). 단 1-레벨, 실행은 데스크톱 ON 전제.
- [확정] claude.ai·Cowork 네이티브가 Python/JS 실행 + .xlsx/.pptx/.docx/PDF 생성 + pip/npm 설치 → **다수 로컬 Python 작업 네이티브 대체 가능**.
- [반증] 환경 영속성("한 번 설치 후 재호출")은 미확증. VM=per-session 격리, 메모리는 Project 내부만.
- [미확정→이번 세션 확정] H:\ Drive 마운트 안정성 (아래 §2에서 **실패 확정**).

출처: support.claude.com/articles 13345190·14116274·13947068·12111783·13521390·14604416, claude.com/docs/cowork/guide/dispatch, anthropic.com/engineering/how-we-contain-claude, anthropic.com/news/claude-design-anthropic-labs.

## 2. Phase 0 게이트 실측 결과 (이번 세션, 2026-06-21)

| 측정 | 방법 | 결과 | 판정 |
|---|---|---|---|
| **H:\ 마운트 안정성** | Cowork에서 `H:\내 드라이브` 연결 → 디렉터리 열거(Glob/Grep)·bash 마운트·직접 Read 시도 | **디렉터리 열거 전면 실패** — Glob `*` 타임아웃(20s), `5.기타/**`·`*.md` 0건, bash 마운트는 루트에 빈 폴더 1개만 노출. **단, 알려진 절대경로의 직접 Read는 성공**(CLAUDE.md·build_v37_apkg.py·번들 문서 등 모두 정상 판독) | **❌ 부분 실패** |
| 공유드라이브 가드 | `0.공유드라이브/` 접근 회피 확인 | 열거 자체가 안 되므로 자동 격리(스트리밍 placeholder). #16-B 자연 충족 | ✅ |
| genanki 부트스트랩 | (미측정 — 사용자 Cowork 세션 수행 필요) | — | ⏳ |
| 사용량 풀 | (미측정 — 사용자 수행 필요) | — | ⏳ |

**해석(결정적)**: Google Drive File Stream의 placeholder 구조 때문에 에이전트 도구가 **트리 탐색을 못 한다**. 직접 Read만 가능 = "경로를 미리 알아야만 읽힌다". 결과:
- 전수 자동 감사·일괄 파일조작·이동로그 파이프라인(#16-C)을 **Cowork에서 Drive 스트림 위로 돌릴 수 없다.**
- 이는 v2 플랜이 우려한 "H:\ 마운트 stale 위험"의 **실증**이며, 매핑표의 "미션크리티컬 파일조작 = 로컬 유지" 결정을 **확정 근거로 승격**시킨다.
- **안3(Drive 밖 E: 로컬 이주)** 전제가 더 타당해짐: 로컬 일반 파일시스템이면 열거·일괄조작·sha256 로그가 정상 동작.

## 8. 검증 (end-to-end)

1. **Phase 0 게이트**: 마운트 ❌확정 / genanki·사용량 ⏳(§6) → 통과 항목만 확대.
2. **문서 파일럿**: 가인 대회 서면 1건 Cowork 네이티브 docx → 서식(A4·폰트) 요건 확인.
3. **디자인 라우팅 파일럿**: 사실관계도 1건 Figma 다이어그램 + 발표 1건 Claude Design → 라우팅 동작 확인.
4. **오케스트레이션 파일럿**: Dispatch에 "오늘 드릴 구성+사례채점" → 자동 분배·실행 확인.
5. 통과분만 매핑표대로 확대. 미통과는 로컬 유지.
