## 4. 품질 이슈

### 4-1. 형식 불일치 (심각)

**cloze 문법 혼용**: 교재별로 cloze 문법이 다름.
- 헌법핵심정리300 카드: `{{답}}` 형식 — Anki 미호환 (c1:: 없음)
- 강성민OX, 유니온, 해커스사례: `{{c1::답}}` 형식 — Anki 호환

예시: 헌법핵심정리300_p001-030_암기장_v37.md, 쟁점 001:
```
② {{재판의 전제성}}이 있어야 한다
```
→ Anki에서 `{{재판의 전제성}}`은 cloze 삭제로 인식 안 됨. `{{c1::재판의 전제성}}`이어야 함.

**앞면/뒷면 레이블 혼용**: 
- 헌법핵심정리300: `**앞면:**` / `**뒷면:**` / `**빈칸:**` (볼드)
- 유니온, 강성민OX: `앞:` / `뒤:` / `빈칸:` (소문자)
- 해커스사례: `[A]`, `[B]` 섹션 라벨 후 `앞:` / `뒤:`

이 혼용은 apkg 빌드 시 파싱 오류를 유발할 수 있음.

### 4-2. 중복 카드 (중간)

**헌법핵심정리300 p001-030 vs llamaparse_p031-060 이중 카드화**:
- `헌법핵심정리300_p001-030_암기장_v37.md` (TOC 기반): 쟁점 001-070 모두 포함
- `헌법핵심정리300_llamaparse_p031-060_암기장_v37.md` (원문 기반): 쟁점 001-007 재카드화

쟁점 001 비교:
```
p001-030 v1: "위헌법률심판(헌법재판소법 §41)의 적법요건을 구성하는 핵심 3요소는?"
llamaparse v2: "위헌법률심판이 적법하기 위한 요건 3가지는? (3요건)"
```
→ 내용 중복, 어느 버전이 정본인지 불명확. v2(원문 기반)가 더 상세.

### 4-3. 통치구조 영역 쟁점 번호 헤더 부재 (중간)

논점 071-104(PART3 헌법총론·PART4 통치구조)는 `## 쟁점 NNN` 헤더 없이 `## Theme NNN` 헤더만 존재. MOC 논점 번호와 카드 간 직접 연결 안 됨. 학습 시 논점별 추적이 어려움.

예시: 논점 [076] 법치국가의 원리
- MOC: `[076] [[법치국가의 원리]] (p236)`
- 카드: `## [일반론] Theme 361 진정소급입법과 부진정소급입법 개념 구별` (`헌법핵심정리300_llamaparse_p271-300_암기장_v37.md`)
- 논점 076과 Theme 361의 연결을 알려면 논점 노트(`법치국가의 원리.md`)를 거쳐야 함.

### 4-4. 원문 일치 확인 (양호)

카드 내용이 논점 노트 원문과 대조한 결과, 오류·왜곡 없음.

예시 — 재판의 전제성 3요건 (논점 003):
- 원문(위헌법률심판의 요건.md): "당해 사건이 법원에 적법하게 계속 중이어야 하고, 위헌여부가 문제되는 법률이 당해 재판에 적용되어야 하며, 그 법률의 위헌여부에 따라 다른 내용의 재판을 하게 되는 경우이어야 한다"
- 카드(쟁점 003): "①당해 사건이 법원에 {{적법하게 계속 중}}이어야 하고, ②위헌여부가 문제되는 법률이 당해 재판에 {{적용}}되어야 하며, ③그 법률의 위헌 여부에 따라 {{다른 내용의 재판}}을 하게 되는 경우이어야 한다"
→ 원문 충실, 왜곡 없음.

예시 — 위헌정당해산 실질적 요건 (논점 084, Theme 398):
- 원문(위헌정당의 해산.md): Theme 398 — 실질적 요건 3가지
- 카드(p271-300, Theme 398): "앞면: 위헌정당해산의 실질적 요건을 3가지로 말하시오." — 내용 일치

### 4-5. cloze 적절성 (부분 이슈)

- 헌법핵심정리300: `{{...}}`만 사용. Anki 호환 불가 상태.
- 일부 카드는 빈칸이 과도하게 적음 (단답형 1개만 cloze).

예시 — 쟁점 056 재판청구권:
```
앞면: 재판청구권(헌법 §27)의 내용과, 대법원의 재판을 받을 권리·헌법재판을 받을 권리의 포함 여부는?
뒷면: {{법원에 의한 재판을 받을 권리}} / 대법원의 재판 {{포함되지 않는다}} / 헌법재판 {{포함된다}}
```
→ Theme 289-296을 1개 카드에 통합, 세부 판례(헌재 1995.9.28. 92헌가11 특허심판 사건 등) 빈칸 없음. 변시 출제 빈도 높은 논점임에도 세부 포인트 카드화 미흡.
