# v37 카드 → .apkg 빌드 계획 (2026-06-15)

## Context
v37 카드 ~12,000장(288 md)이 readable 포맷으로 생성됨. 커버리지 100%(29책)·찌라시 7과목 완비. 그러나 ①포맷 3종 혼재 ②암기장 cloze 무효문법 ③한자 미변환 ④경계 1% ⑤junk·empty·중복으로 **임포트가 불가**. TSV 파서는 8,772장만 잡아 ~3,400 손실. → **genanki로 과목별 .apkg** 빌드 + 결함 일괄 해결.

## 손실 원인 (규명됨)
1. 블록당 1카드 가정 + 암기장 `빈칸:`줄 처리 미흡
2. **논점민소 cloze 신본 = 제3포맷**(`## [속성]` → `**카드NN**` 구분자) 미분할 → 헤더당 다카드 뭉침
3. **찌라시 deck 매핑 누락** → 상법·행정법·형소 전량 누락 위험(치명)

## 빌드 설계 (신규 `.agent/scripts/build_v37_apkg.py`)
- **포맷 3종 라우터**: 사례형(`### [A~D]`) / 암기장(`### [속성]`+앞/뒤/빈칸) / 논점민소cloze(`**카드NN**` 분할)
- **카드 모델 2종**: Basic(Front/Back/출처) + Cloze(Text/Extra/출처). 암기장 `빈칸:`→cloze(번호부여), `앞:`→Extra(질문·사건번호 보존). cloze 채점면에 질문 안 섞음
- **일괄 정규화**: 한자→한글 / `**볼드**`→`<b>` / 표→`<table>` / bare`{{}}`→`{{cN::}}` / 경계 트림(연결어미·조사·관형 종결) / 사건번호 anchor 보존
- **dedup/제외**: junk(H·H:·*.py·*_TEMP) / empty(<30줄) / 논점민소 구OX21(cloze신 채택) / `_llamaparse` 중복은 **GUID 수렴**(출처 정규화 해시)
- **genanki**: Model 고유ID 고정, Note GUID=출처+헤더+본문 해시(재임포트 회독보존), Deck=`{회독그룹}::{과목}`
- **과목별 .apkg 7개**: `outputs/anki/v37/apkg/{과목}_v37.apkg` (민법·민사소송법·형법·헌법·상법·행정법·형사소송법), 내부 회독그룹 서브덱
- **CSS**: 한글폰트·cloze 파랑·볼드 빨강·표 테두리

## 검증 (빌드 후)
1. 과목×그룹 카드수 매트릭스, 합계 11.5k~12.5k (8,772 대비 회복)

3. GUID 유일성 / 스모크 임포트(1과목 apkg) c1·c2 분리 확인
