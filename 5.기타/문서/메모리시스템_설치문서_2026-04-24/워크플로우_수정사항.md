## 6. 기존 .auto-memory 구조와의 통합

### 파일 역할 정리:
```
.auto-memory/
├── MEMORY.md           ← 빠른 참조 인덱스 (1페이지 요약, 기존)
├── user_profile.md     ← 사용자 프로필 (기존)
├── feedback_*.md       ← 피드백 메모리 (기존)
├── project_*.md        ← 프로젝트 메모리 (기존)
├── reference_*.md      ← 참조 메모리 (기존)
├── session_logs/       ← 세션별 자동 캡처 (신규, #43)
├── daily/              ← flush된 일별 요약 (신규)
├── wiki/               ← 컴파일된 주제별 아티클 (신규)
│   └── _index.md       ← wiki 인덱스 (신규, #42에서 참조)
├── .compile_state.json ← 컴파일 상태 추적 (신규)
└── lint_report.json    ← 마지막 lint 결과 (신규)
```

### 핵심 원칙:
- 기존 메모리 파일(user/feedback/project/reference)은 **그대로 유지**
- wiki는 "세션 작업 기록의 주제별 통합본"으로 별도 운영
- MEMORY.md는 빠른 참조용, wiki/_index.md는 상세 검색용
- 두 인덱스는 독립적으로 유지하되, consolidate-memory 실행 시 교차 확인
