# 사례답안 인박스 (daily-drill)

여기에 **사례형 답안 파일**을 저장하고 채팅에 **"올렸어"** 라고 하면 daily-drill이 채점합니다.

- 올릴 것: 직접 쓴 답안(txt·md·pdf·docx·이미지 등)
- 채점: `case-answer-review` 스킬(루브릭: 쟁점·키워드·구조·결론·포섭)
- 질문지·모범답안·해설이 있으면 같이 올리면 정밀 채점, 없으면 초벌 평가
- 채점 결과는 `_채점_<날짜>.md` 로 이 폴더에 저장(원본은 보존 #16)

> 파일명에 과목·쟁점을 넣으면 자동 매칭이 쉬움. 예: `민법_점유권_사례답안_0618.md`
