## 2. 헌법소원심판 — 적법요건

### 핵심 요건 (§68① 권리구제형)

| 요건 | 핵심 |
|------|------|
| 자기관련성 | 직접 상대방이 원칙; 제3자도 **직접·법적** 이해관계 있으면 예외적 인정 |
| 현재성 | 기본권 침해가 현재 존재해야 |
| 직접성 | 법령이 **집행행위 매개 없이** 직접 기본권 침해할 것 |
| | 예외: 집행행위 있어도 구제 기대불가, 법령이 일의적·명백하여 재량 없는 경우 |
| 보충성 | 다른 구제절차를 먼저 거칠 것 (법원에서 직접 다툴 수 없는 경우 예외) |

### §68② (위헌심사형) 특이점

- 자기관련성·현재성·직접성·청구기간 요건 **별도 불요** (당해 사건 재판 계속 중이면 족함)
- 보충성 원칙 **적용 없음**

> ⚠ "§68② 헌법소원도 직접성 요건을 갖춰야" → **X**

### 직접성 함정 (반복)

- "법령이 일의적이고 명백하여 재량의 여지가 없는 경우 직접성이 부정된다" → **X** (이 경우 오히려 **예외적으로 직접성 인정**)

## 3. 위헌법률심판 — 재판의 전제성·효력

### 심판 대상 (함정)

| 대상 O | 대상 X |
|--------|--------|
| 형식적 법률 | **헌법 조항** |
| 긴급명령·긴급재정경제명령 | **명령·규칙** |
| 법률 효력 조약 | — |
| 관습법 | — |

> ⚠ "명령·규칙도 위헌법률심판 대상" → **X** (대법원이 최종 심사)

### 재판의 전제성

- 법원에 사건 계속 중일 것
- 당해 사건에 해당 법률이 **적용**될 것
- 위헌 여부에 따라 **재판의 결론(주문)이 달라지거나, 이유가 달라지는 경우** 포함

> ⚠ "이유만 달라지는 경우는 전제성 없음" → **X** (이유 변경도 포함)

### 위헌결정의 효력

| 유형 | 효력 |
|------|------|
| 원칙 | **장래효** (소급 없음) |
| 형벌 규정 위헌 | **소급** (형사처벌받은 자 재심 가능) |
| 헌법불합치 잠정적용 | 시한 만료 후 **자동 실효** |
| 헌법불합치 적용중지 | 결정 즉시 적용 금지 |

> ⚠ "헌법불합치 잠정적용형은 시한 만료 후 입법 있어야 실효" → **X** (자동 실효)

### 위헌결정과 행정처분 (반복 함정)

- 위헌인 법률에 근거한 **행정처분** → **당연무효 아님** (취소사유)
- 예외: 처분 근거 법률이 헌법에 명백히 위반되고, 그 하자가 중대·명백한 경우에만 무효

> ⚠ "위헌결정이 난 법률에 근거한 행정처분은 당연 무효" → **X** (취소사유)

## 4. 권한쟁의심판

- 청구기간: 안 날 **60일**, 있은 날 **180일**
- 인용결정: **일반 정족수(과반수)** — 6인 아님
- 국가기관 간 + 지방자치단체 간 + 국가기관-지방자치단체 간 모두 헌재 관장
- 국회 소위원회·소위원장 = 헌법상 설치기관 아님 → 당사자능력 없음
- 헌재법 §62 당사자 열거 = **예시 규정** (한정 열거 X) → 국회의원 vs 국회의장 간 권한쟁의도 인정

> ⚠ "헌재법에 열거된 기관 사이에서만 권한쟁의 가능" → **X** (예시규정)

## 4-1. 정당 제도

### 정당 개념표지 (함정)

우리 헌재 = **독일과 동일하게** "상당한 기간 또는 계속해서", "상당한 지역에서" 국민의 정치적 의사형성에 참여 요구

> ⚠ "우리 헌재는 독일과 달리 '상당한 기간·상당한 지역' 개념표지를 요구하지 않는다" → **X**

### 정당 관련 핵심 정리

| 사항 | 결론 |
|------|------|
| **외국인**·사립대학 교원 | 정당의 발기인·당원 **될 수 없음** (정당법 §22) |
| 소속 국회의원 **제명** | 당헌 절차 + 소속 국회의원 **전원 1/2 이상** 찬성 (정당법 §33) |
| 경찰청장 퇴직 후 2년 정당가입 금지 | **위헌** (수단의 적합성 × — 99헌마135) |
| 5개 시·도당 + 각 1천인 당원 요건 | **합헌** (정당의 개념표지 구현, 자의적 판단 ×) |
| 국회의원선거 의석 X·득표율 2% 미달 → 정당등록 취소 | **위헌** (침해의 최소성·법익균형성 위반) |
| 교섭단체 구성 여부에 따른 보조금 차등 | 평등원칙 위반 × **(합헌)** |
| 초·중등학교 교원 정당가입 금지 | 정치적 자유권·평등권 침해 × **(합헌)** |

> ⚠ "외국인 사립대학 교원은 당원이 될 수 있다" → **X**  
> ⚠ "경찰청장 정당가입 제한은 직무 중립성을 위한 합리적 제한이다" → **X** (위헌)

## 5. 탄핵심판·정당해산심판

### 탄핵소추 정족수

| 대상 | 발의 | 의결 |
|-----|-----|-----|
| 대통령 | 재적 **과반수** | 재적 **3분의 2** 이상 |
| 그 외 (국무총리, 법관 등) | 재적 **3분의 1** 이상 | 재적 **과반수** |

> ⚠ 대통령 탄핵 의결 = "재적 과반수" → **X** (재적 3분의 2)

### 대통령 권한대행 국무총리 탄핵 (2025 헌나9)

- 국무총리가 대통령 권한대행 중이어도 탄핵소추 정족수는 **국무총리 기준** 적용
- (재적 3분의 1 발의 + 재적 과반수 의결)

### 탄핵·정당해산 공통

- 탄핵 결정의 효력 = **파면** (형사·민사 책임 면제 효과 없음)
- 정당해산 결정 시 소속 의원 **의원직 상실** (통합진보당 사건)
- 정당해산 가처분: 직권 또는 청구인 신청으로 **활동 정지** 가능

## 6. 국회 — 정족수·특권·입법절차

### 의결 정족수 비교

| 사항 | 정족수 |
|------|-------|
| 일반 의결 | 재적 과반수 출석 + 출석 과반수 찬성 |
| 헌법개정안 의결 | 재적 **3분의 2** 이상 찬성 |
| 법률안 재의결 | 재적 과반수 출석 + 출석 **3분의 2** 이상 찬성 |
| 의원 제명 | 재적 **3분의 2** 이상 찬성 |
| 임시회 소집 요구 | 재적 **4분의 1** 이상 연서 |
| 국회의원 **석방 요구** | 재적 **4분의 1** 이상 ← 소집과 동일, 함정 |
| 계엄 해제 요구 | 재적 **과반수** 찬성 |
| 신속처리안건 지정 | 재적 **5분의 3** 이상 |
| 무제한토론 종결 | 재적 **5분의 3** 이상 |
| 무제한토론 요구 | 재적 **3분의 1** 이상 |

> ⚠ "임시회 소집 요구 = 재적 3분의 1" → **X** (**4분의 1**)  
> ⚠ "계엄 해제 요구 = 재적 3분의 2" → **X** (**과반수**)  
> ⚠ "신속처리안건 지정 = 재적 과반수" → **X** (**5분의 3**)

### 면책특권 (§45)

- 적용 범위: 국회에서의 **직무상 발언과 표결** → 국회 **외에서** 책임 없음
- 회기 요건 **없음** (회기 중에 한한다는 규정 아님)
- 함정: "발언 내용이 허위라는 점을 인식하지 못한 경우" → **면책 O** (허위임을 알면서 발언한 경우만 면책 X)

> ⚠ "면책특권은 회기 중에 한한다" → **X** (회기 요건 없음)  
> ⚠ "민사상 책임에는 미치지 않는다" → **X** (민사·형사 모두 면책)

### 불체포특권

- 회기 중 국회 동의 없이 체포·구금 불가 (현행범 제외)
- 회기 전 체포된 경우 국회 요구 시 회기 중 석방

> ⚠ "동의 없이 체포된 경우 그 구금 자체가 당연 무효" → **X** (절차 하자이나 당연 무효 아님)

### 입법절차

- 법률안 수정동의: 의안 + 이유 + **20인 이상** 찬성·연서
- 본회의 표결 결과: 재적 300, 출석 280, 찬성 140이면? → 재적 과반수(151) 출석 충족, 출석 과반수(141) 찬성 미달 → **부결**
- 국회부의장이 표결을 진행한 경우 → 그 표결로 가결된 법률안의 효력에 문제 있을 수 있음 (국회의장만 가결 선포 권한)

## 7. 대통령·행정부

### 긴급재정경제명령 vs 긴급명령 (§76)

| 구분 | 긴급재정경제명령 (§76①) | 긴급명령 (§76②) |
|------|------------------|--------------|
| 상황 | 내우외환·천재지변·중대한 재정·경제상 위기 | 국가 안위에 관계되는 **중대한 교전상태** |
| 국회 집회 | 기다릴 **여유가 없을 때** | **불가능**한 때 |
| 기본권 제한 범위 | 경제적 생활에 관련된 기본권 | **제한 없음** |
| 국회 통제 | 보고 후 **승인** 필요 | 보고 후 **승인** 필요 |

> ⚠ "긴급재정경제명령은 국회 승인 불요" → **X** (승인 필요)  
> ⚠ "긴급재정경제명령은 위기 발생 우려만으로 사전적·예방적으로 발할 수 있다" → **X** (현실적 위기 발생 후에만)  
> ⚠ "긴급재정경제명령으로 공공복리 증진 등 적극적 목적 달성 가능" → **X** (기존 질서 유지·회복 목적만)

### 대통령 국회 관계

- 대통령은 국회에 **출석하여 발언하거나 서한으로 의견 표시** 가능 (§81)
- 대통령은 국회의 요구에 따라 **출석·답변할 헌법상 의무 없음**
- 출석·답변 의무 있는 자: 국무총리·국무위원·정부위원

### 대통령의 성실한 직책수행의무

- 헌법 §69에 명시된 **헌법적 의무**이나
- **원칙적으로 사법적 판단의 대상 아님** (헌재 2004헌나1)
- 탄핵소추 사유는 "헌법이나 법률에 위배한 때"로 한정 → 성실의무 위반은 탄핵사유 아님

### 계엄

- 비상계엄: 전시·사변 또는 이에 준하는 국가비상사태
- 경비계엄: 사회질서가 교란될 우려가 있는 때 (전시·사변 필요 없음)
- 계엄 해제 요구: 국회 재적의원 **과반수** 찬성으로 요구 가능
- 대통령은 국회의 계엄해제 요구에 따라야 함 (거부 불가)

> ⚠ "비상계엄은 전시·사변이 발생한 경우에만" → **X** (이에 준하는 국가비상사태도 포함)  
> ⚠ "대통령은 국회의 해제 요구를 거부할 수 있다" → **X**

### 대통령의 법률안 거부권 (§53)

- 거부권(환부거부): 법률안 전체에만 행사 가능
- **일부거부·수정거부 불가** (§53③)
- **예산안에는 거부권 없음** (예산은 법률이 아님)

> ⚠ "대통령은 법률안의 일부에 대해 거부권을 행사할 수 있다" → **X**  
> ⚠ "대통령은 예산안에 대해 거부권을 행사할 수 있다" → **X**

### 긴급명령·긴급재정경제명령 — 국회 미승인 효과 (함정)

- 국회 미승인 → **그때부터** 효력 상실 (**장래효**, 소급하여 무효 아님)

> ⚠ "국회가 승인을 거부하면 긴급명령은 소급하여 무효가 된다" → **X** (장래효 상실)

### 계엄 — 국회 관계

- 계엄 선포 시: 국회에 **통고** (동의 필요 없음, §77④)
- 계엄 해제 요구: 국회 재적 **과반수** → 대통령은 반드시 해제해야 함 (거부 불가)

> ⚠ "계엄 선포 시 국회 동의가 필요하다" → **X** (통고만)

### 사면 — 국회 동의 유무

| 종류 | 국회 동의 | 국무회의 심의 |
|------|---------|------------|
| **일반사면** | **필요** (§79②) | 필요 |
| **특별사면** | **불요** | 필요 |

> ⚠ "일반사면은 국회 동의 없이 가능하다" → **X** (동의 필수)  
> ⚠ "특별사면도 국회 동의가 필요하다" → **X** (불요)

### 대통령 형사 불소추 특권 (§84)

- 재직 중 **형사소추**만 면제
- 적용 외: 민사책임, 탄핵, 행정상 책임
- 재직 중 소추 불가 → **공소시효 정지** (진행 정지, 소멸 아님)

> ⚠ "재직 중 민사소송도 제기 불가" → **X** (형사소추만)

### 국무총리·국무회의

- 국무총리: 대통령의 **첫째 가는 보좌기관**, 독자적 권한 없음, 대통령 명령을 받아 행정각부 통할
- 국무회의: **심의기관** (의결기관 아님, 자문기관도 아님)
- 국무회의 구성: 대통령(의장) + 국무총리(부의장) + 국무위원 15~30인

> ⚠ "국무회의는 의결기관이다" → **X** (심의기관)

### 대통령 임기 개정 특칙 (§128②)

- 대통령 임기 연장·중임 변경을 위한 헌법개정은 **그 헌법개정 제안 당시의 대통령에게는 효력 없음**

> ⚠ "헌법 개정으로 중임 가능하게 된 경우, 제안 당시 대통령도 이를 이용할 수 있다" → **X**

### 감사원

- 감사원장: **국회 동의** + 대통령 임명 / 임기 4년 / 1차 중임
- 감사위원: **원장 제청** + 대통령 임명 (국회 동의 없음) / 임기 4년 / 1차 중임
- 감사원: 대통령 소속 + 직무상 독립

> ⚠ "감사원장 임기 4년, 중임 불가" → **X** (1차 중임 가능)  
> ⚠ "감사위원도 국회 동의로 임명" → **X** (원장 제청으로 임명, 국회 동의 없음)

## 8. 법원 — 신분보장·위헌심사

### 법관 임기

| 직위 | 임기 | 중임/연임 |
|-----|-----|---------|
| 대법원장 | 6년 | **중임 불가** |
| 대법관 | 6년 | **연임 가능** |
| 판사 (일반) | 10년 | **연임 가능** |
| 헌법재판소 재판관 | 6년 | **연임 가능** |

> ⚠ "대법관은 연임할 수 없다" → **X** (연임 가능)  
> ⚠ "대법원장은 1차에 한해 중임 가능" → **X** (중임 자체가 불가)

### 법관의 신분보장

- 탄핵 또는 **금고 이상의 형** 선고에 의하지 않고는 파면 불가
- 탄핵·형사 외에는 **징계처분에 의하지 않으면 정직·감봉·기타 불이익 처분 불가**
- **법관 정년**: 헌법 아닌 **법원조직법**에 규정 (대법원장·대법관 70세, 판사 65세)

> ⚠ "법관은 품위유지 위반을 이유로 파면될 수 있다" → **X** (징계 가능하나, 파면은 탄핵·금고형만)  
> ⚠ "법관 정년은 헌법에 직접 규정된다" → **X** (법원조직법에 규정)

### 양형기준 (반복 함정)

- 법관은 양형기준을 **존중하여야** 하나, **법적 구속력 없음**
- 양형기준 벗어난 판결 → 판결서에 **합리적·설득력 있는 양형이유** 기재해야 함

> ⚠ "양형기준은 법적 구속력을 가지므로 반드시 따라야 한다" → **X** (구속력 없음)

### 국민참여재판

- 국민참여재판을 받을 권리 = **법률상 권리** (헌법상 기본권 아님)
- 입법자가 일정 사건에서 배제하더라도 **재판청구권 침해 아님**

> ⚠ "국민참여재판을 받을 권리는 헌법상 보장된 기본권이다" → **X** (법률상 권리)

### 위헌심사권 배분

| 대상 | 심사기관 |
|-----|---------|
| 법률의 위헌 여부 | 헌법재판소 |
| 명령·규칙의 위헌 여부 (재판 전제) | **대법원**이 최종 심사 (§107②) |
| 명령·규칙이 기본권 **직접** 침해 | 헌법소원 대상 (헌재) |

> ⚠ "대법원규칙·헌재규칙·중앙선거관리위원회규칙은 헌법소원 대상이 되지 않는다" → **X** (대상 됨)

### 정부형태론 비교 — 반복 출제 함정

- 영국 의원내각제: **처음에 의회우위, 현재는 내각우위(내각책임제)**

## 11. 법치주의 (의회유보·신뢰보호·포괄위임)

### 의회유보 범위

- 방송수신료 **금액·징수대상** = 본질적 사항 → **의회유보 O**
- 방송수신료 구체적 **징수방법** = 의회유보 사항 **아님** (위임 가능)

### 포괄위임금지원칙 적용 범위 (함정)

| 위임 대상 | 적용 여부 |
|---------|---------|
| 대통령령·총리령·부령 | 적용 O (§75) |
| 대법원규칙 | 적용 O (수권법률에서도 준수) |
| 조례에 대한 위임 | 원칙적으로 **적용 X** (주민자치, 포괄위임 가능) |
| 정관에 대한 위임 (비행정부 공법기관) | 원칙적으로 **적용 X** |

> ⚠ "대법원규칙에 위임 시 포괄위임금지원칙 적용 안 된다" → **X** (적용 O)  
> ⚠ "조례에도 포괄위임금지원칙 그대로 적용" → **X** (원칙 적용 X)

### 신뢰보호원칙·소급입법

| 유형 | 원칙 | 예외 |
|-----|-----|-----|
| 진정소급입법 | 원칙 **금지** | 중대한 공익상 이유 있으면 허용 |
| 부진정소급입법 | 원칙 **허용** | 신뢰보호 원칙에 의해 제한 가능 |

- **진정소급입법**: 이미 완료된 과거의 사실관계·법률관계에 신법 적용
- **부진정소급입법**: 현재 진행 중인 사실관계에 신법 적용

### 소급입법금지 — 추가 함정

- **시혜적 소급입법** (국민에게 유리): 소급입법금지원칙 적용 **X** → 입법재량
- **보안처분** (전자발찌 등): 형벌적 성격이 강한 예외적 경우가 아닌 한 소급입법금지 원칙 **적용 안 됨**
- **체계정당성 위반**: 그 자체로 바로 위헌 아님 — 비례원칙·평등원칙 위반의 **징후**일 뿐

> ⚠ "시혜적 소급입법도 소급입법금지원칙 위반이 될 수 있다" → **X** (적용 없음)  
> ⚠ "체계정당성 위반 자체가 위헌" → **X** (하나의 징후)  
> ⚠ 대리점법 부칙 소급적용 → 헌재가 **진정소급입법**으로 분류, 공익 우월하여 예외적 합헌  
> ⚠ "진정소급이 아닌 부진정소급이어서 합헌" → 이 사건에서는 **X**
