## 0-1. 한국 대륙법식 읽는 순서

### 📊 헌1 독법
```mermaid
flowchart LR
    A["헌법 조문 원문"] --> B["개념 정의"]
    B --> C["심사기준·판단단계"]
    C --> D["숫자기준·비교기준"]
    D --> E["원칙 → 예외"]
    E --> F["결정례 한 줄"]
    F --> G["맞는 선지 / 틀린 선지"]
```

1. 헌1은 **조문 원문 또는 핵심 문언**을 먼저 본다.
2. 그다음 **개념 정의**와 **심사기준**을 짧게 붙여 본다.
3. 숫자기준이나 비교기준이 있으면 별도로 묶어 외운다.
4. 판례는 긴 사실관계보다 **무슨 기준으로 합헌/위헌을 가른 것인지** 위주로 읽는다.
5. 마지막에 **맞는 선지 문장**으로 닫아 객관식 회독이 가능하게 읽는다.
